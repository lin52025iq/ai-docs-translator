如果你想请求更改 ESLint，请在 GitHub 上[创建一个新议题](https://github.com/eslint/eslint/issues/new/choose)。请务必包含以下信息：

1. 你使用的 ESLint 版本。
2. 你想解决的问题。
3. 你认为正确的问题解决方案。

如果你请求更改某条规则，也请提供以下信息：

1. 你做了什么。
1. 你希望发生什么。
1. 实际发生了什么。

请尽可能详细地描述，以帮助我们妥善处理你的问题。如果我们需要为议题分类，并不断要求大家补充信息，就会占用原本用于解决问题的时间。请在议题中提供尽可能多的细节，帮助我们提高效率。

**注意：**如果你只是有问题，不一定会因此要求更改 ESLint，例如想了解某项功能的工作原理或如何参与贡献，请发起[讨论](https://github.com/eslint/eslint/discussions)，或访问我们的 [Discord 服务器](https://eslint.org/chat)，而不是提交议题。
