ESLint [技术指导委员会](../contribute/governance#technical-steering-committee-tsc)（TSC）可以组建工作组，专注于项目的特定领域。

<a id="create-a-working-group"></a>

## 创建工作组

工作组通过向团队邮件列表发送电子邮件来组建。每个工作组：

1. 必须在顶级 GitHub 团队“ESLint Team”下设有一个 GitHub 团队。（GitHub 团队名称应以“WG”结尾，以区别于其他类型的团队。）
1. 必须至少有一名 TSC 成员。
1. 可以有任意数量的提交者和审查者。
1. 必须至少有两名成员。

活跃的工作组列于[团队页面](https://eslint.org/team)。

<a id="how-working-groups-work"></a>

## 工作组如何运作

每个工作组负责自己的内部运作。工作组可以自行决定规模（但成员至少为两人）、何时以及增删哪些成员，以及如何实现目标。

工作组可以是临时的，也可以是永久的。

如果工作组计划对 ESLint 项目做出重大更改，提案仍须经 TSC 批准。
