本指南面向希望通过 ESLint API 将 ESLint 的功能集成到其他应用中的用户。

集成 ESLint 前，建议你：

- 了解 JavaScript，因为 ESLint 是用 JavaScript 编写的。
- 对 Node.js 有一定了解，因为 ESLint 运行在 Node.js 上。

如果你符合上述条件，请继续阅读并开始使用。

<a id="integrate-with-the-nodejs-api-tutorial"></a>

## [Node.js API 集成教程](integration-tutorial)

本教程将引导你使用 Node.js API 创建一个基本的 ESLint 集成。

<a id="nodejs-api-reference"></a>

## [Node.js API 参考](nodejs-api)

如果你有兴趣编写使用 ESLint 的工具，可以通过 Node.js API 以编程方式访问相关功能。
