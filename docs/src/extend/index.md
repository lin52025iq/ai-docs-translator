本指南面向希望扩展 ESLint 功能的读者。

要扩展 ESLint，建议你：

- 了解 JavaScript，因为 ESLint 是用 JavaScript 编写的。
- 熟悉一些 Node.js，因为 ESLint 运行于 Node.js 之上。
- 能够熟练使用命令行程序。

如果你符合这些条件，请继续阅读，开始了解如何扩展 ESLint。
