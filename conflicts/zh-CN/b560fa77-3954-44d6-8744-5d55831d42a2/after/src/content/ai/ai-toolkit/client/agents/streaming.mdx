## 主要改动

要为我们在[上一份指南](/ai/ai-toolkit/client/agents/ai-agent-chatbot)中构建的 AI 智能体聊天机器人添加流式处理功能，需要将 `executeTool` 方法替换为 `streamTool` 方法。

首先，在工具调用进行流式处理时，每收到一个新的流式数据片段，都可以重复调用 `streamTool`。这样可以逐步更新文档。

```tsx
const aiToolkit = getAiToolkit(editor)

const result = aiToolkit.streamTool({
  toolCallId: 'call_123',
  toolName,
  // Content is still streaming, so we pass a partial JSON object.
  input,
  // This parameter indicates that the tool streaming has not finished yet
  hasFinished: false,
})
```

然后，工具调用完成后，再次调用 `streamTool` 方法，并设置 `hasFinished: true`，以表明工具调用的流式处理已完成。这样会使用最终内容更新文档。

```tsx
const result = aiToolkit.streamTool({
  toolCallId: 'call_123',
  toolName,
  // Streaming is complete, so we can pass the full JSON object
  input,
  // This parameter indicates that the tool streaming has finished
  hasFinished: true,
})
```

要在我们[上一份指南](/ai/ai-toolkit/client/agents/ai-agent-chatbot)中构建的 AI 智能体聊天机器人中实现此流程，请按以下步骤操作：

### 1. 处理流式更新

添加一个 `useEffect` hook，在工具调用进行期间处理流式更新。在此 hook 中，每收到一个新的流式数据片段，我们都会重复调用 `streamTool`。

```tsx
// While the tool streaming is in progress, we need to update the document
// as the tool input changes
useEffect(() => {
  if (!editor) return

  // Find the last message
  const lastMessage = messages[messages.length - 1]
  if (!lastMessage) return

  // Find the last tool that the AI has just called
  const toolCallParts = lastMessage.parts.filter((p) => p.type.startsWith('tool-')) ?? []
  const lastToolCall = toolCallParts[toolCallParts.length - 1]
  if (!lastToolCall) return

  // Get the tool call data
  interface ToolStreamingPart {
    input: unknown
    state: string
    toolCallId: string
    type: string
  }
  const part = lastToolCall as ToolStreamingPart
  if (!(part.state === 'input-streaming')) return
  const toolName = part.type.replace('tool-', '')

  // Apply the tool call to the document, while it is streaming
  const toolkit = getAiToolkit(editor)
  toolkit.streamTool({
    toolCallId: part.toolCallId,
    toolName,
    input: part.input,
    // This parameter indicates that the tool streaming has not finished yet
    hasFinished: false,
  })
}, [addtoolOutput, editor, messages])
```

### 2. 处理流式处理完成

在演示中，我们使用 [Vercel AI SDK](https://ai-sdk.vercel.app/) 的 `useChat` hook 来实现 AI 智能体聊天机器人。该 hook 包含一个 `onToolCall` 事件处理程序，会在工具调用完成流式处理时运行。

在此处理程序中，我们调用 `streamTool` 并设置 `hasFinished: true`，以表明工具调用的流式处理已完成。

```tsx
const { messages, sendMessage, addtoolOutput } = useChat({
  transport: new DefaultChatTransport({ api: '/api/chat' }),
  sendAutomaticallyWhen: lastAssistantMessageIsCompleteWithToolCalls,
  async onToolCall({ toolCall }) {
    if (!editor) return

    const { toolName, input, toolCallId } = toolCall

    // Use the AI Toolkit to stream the tool
    const toolkit = getAiToolkit(editor)
    const result = toolkit.streamTool({
      toolCallId,
      toolName,
      input,
      // This parameter indicates that the tool streaming is complete
      hasFinished: true,
    })

    addtoolOutput({ tool: toolName, toolCallId, output: result.output })
  },
})
```

<Callout title="在所有 streamTool 调用中传入相同的属性" variant="warning">
  所有 `streamTool` 调用都应传入相同的属性值。例如，在首次调用 `streamTool` 方法时，如果向 `reviewOptions` 参数传入 `{mode: 'preview'}`，那么后续所有 `streamTool` 调用也应传入相同的值（`{mode: 'preview'}`）。
</Callout>

## 完整实现

以下是包含工具流式处理功能的完整更新组件：

```tsx
'use client'

import { DefaultChatTransport, lastAssistantMessageIsCompleteWithToolCalls } from 'ai'
import { useChat } from '@ai-sdk/react'
import { EditorContent, useEditor } from '@tiptap/react'
import StarterKit from '@tiptap/starter-kit'
import { useEffect, useState } from 'react'
import { AiToolkit, getAiToolkit } from '@tiptap-pro/client-ai-toolkit'

export default function Page() {
  const editor = useEditor({
    immediatelyRender: false,
    extensions: [StarterKit, AiToolkit],
    content: `<h1>AI Agent Demo</h1><p>Ask the AI to improve this.</p>`,
  })

  const { messages, sendMessage, addtoolOutput } = useChat({
    transport: new DefaultChatTransport({ api: '/api/chat' }),
    sendAutomaticallyWhen: lastAssistantMessageIsCompleteWithToolCalls,
    async onToolCall({ toolCall }) {
      if (!editor) return

      const { toolName, input, toolCallId } = toolCall

      // When the tool streaming is complete, we need to apply the tool call to the document
      // Use the AI Toolkit to execute the tool
      const toolkit = getAiToolkit(editor)
      const result = toolkit.streamTool({
        toolCallId,
        toolName,
        input,
        // This parameter indicates that the tool streaming is complete
        hasFinished: true,
      })

      addtoolOutput({ tool: toolName, toolCallId, output: result.output })
    },
  })

  const [input, setInput] = useState(
    'Insert, at the end of the document, a long story with 10 paragraphs about Tiptap',
  )

  // While the tool streaming is in progress, we need to update the document
  // as the tool input changes
  useEffect(() => {
    if (!editor) return

    // Find the last message
    const lastMessage = messages[messages.length - 1]
    if (!lastMessage) return

    // Find the last tool that the AI has just called
    const toolCallParts = lastMessage.parts.filter((p) => p.type.startsWith('tool-')) ?? []
    const lastToolCall = toolCallParts[toolCallParts.length - 1]
    if (!lastToolCall) return

    // Get the tool call data
    interface ToolStreamingPart {
      input: unknown
      state: string
      toolCallId: string
      type: string
    }
    const part = lastToolCall as ToolStreamingPart
    if (!(part.state === 'input-streaming')) return
    const toolName = part.type.replace('tool-', '')

    // Apply the tool call to the document, while it is streaming
    const toolkit = getAiToolkit(editor)
    toolkit.streamTool({
      toolCallId: part.toolCallId,
      toolName,
      input: part.input,
      // This parameter indicates that the tool streaming has not finished yet
      hasFinished: false,
    })
  }, [addtoolOutput, editor, messages])

  if (!editor) return null

  return (
    <div>
      <EditorContent editor={editor} />
      {messages?.map((message) => (
        <div key={message.id} style={{ whiteSpace: 'pre-wrap' }}>
          <strong>{message.role}</strong>
          <br />
          {message.parts
            .filter((p) => p.type === 'text')
            .map((p) => p.text)
            .join('\n')}
        </div>
      ))}
      <form
        onSubmit={(e) => {
          e.preventDefault()
          sendMessage({ text: input })
          setInput('')
        }}
      >
        <input value={input} onChange={(e) => setInput(e.target.value)} />
      </form>
    </div>
  )
}
```

你可以添加 `AiCaret` 扩展，以显示一个光标，指示 AI 在流式处理期间插入内容的位置。这能为用户提供实时的视觉反馈。

```tsx
import { AiCaret, AiToolkit, getAiToolkit } from '@tiptap-pro/client-ai-toolkit'

const editor = useEditor({
  extensions: [StarterKit, AiToolkit, AiCaret],
})
```

## 显示审阅界面

在审阅界面中显示更改，让用户可以接受或拒绝这些更改。

有两种方式：

- 使用 [**修订跟踪**](/tracked-changes/getting-started/overview)扩展来呈现审阅界面。更改会作为文档的一部分保留，并对其他用户可见。
- **AI Toolkit 建议**：基于装饰的临时界面，仅对当前文档用户可见。

通过设置 `reviewOptions` 参数来配置审阅界面。每次调用 `streamTool` 方法时，该参数都应保持相同的值。

```ts
toolkit.streamTool({
  // ... other options

  // Show the review UI with Tracked Changes
  reviewOptions: { mode: 'trackedChanges' },

  // Show the review UI with AI Toolkit suggestions
  reviewOptions: { mode: 'review' },
})
```

如需了解有关审阅界面的更多信息，请参阅[审阅更改](/ai/ai-toolkit/client/agents/review-changes)指南。

查看 [AI Toolkit 演示](https://github.com/ueberdosis/ai-toolkit-demos)，了解如何将 AI Toolkit 流式处理与审阅界面结合使用。
