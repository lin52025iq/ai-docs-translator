使用 Tiptap 的 `@tiptap-pro/extension-export-odt` 将编辑器内容导出为 `.odt` 文件。此扩展会将文档发送到 Tiptap 转换服务进行转换，从而将 ODT 导出功能集成到编辑器中。

如果希望自行处理转换，也可以改用 [REST API](/conversion/export/odt/rest-api)。

## 安装 ODT 导出扩展

Conversion 扩展发布在 Tiptap 的私有 npm 注册表中。请按照[私有注册表指南](/guides/pro-extensions)集成这些扩展。

完成后，即可安装并导入 **Export ODT** 扩展包。

```bash
npm i @tiptap-pro/extension-export-odt
```

```js
import { ExportOdt } from '@tiptap-pro/extension-export-odt'
```

## 配置扩展

`ExportOdt` 扩展可通过 `configure` 方法配置。该方法接受一个 `ExportOdtOptions`（`object`）参数，包含以下属性：

```ts
import { ExportOdt } from '@tiptap-pro/extension-export-odt'

const editor = new Editor({
  extensions: [
    // Other extensions ...
    ExportOdt.configure({
      region: 'eu', // 'eu' or 'us'
      token: 'YOUR_TOKEN',
      styleOverrides: {},
      headers: {},
      footers: {},
      pageSize: { width: '21cm', height: '29.7cm' },
      pageMargins: { top: '1cm', bottom: '1cm', left: '1cm', right: '1cm' },
      customNodes: [],
      onCompleteExport: (result) => {
        // Handle the exported Blob
      },
    }),
    // Other extensions ...
  ],
})
```

| 参数                 | 类型                     | 说明                                                                                               | 默认值                       |
| ------------------ | ------------------------ | ------------------------------------------------------------------------------------------------ | ------------------------------------- |
| `endpoint`         | `string`                 | 用于转换的 Tiptap API 端点。设置后会覆盖 `region`                          | `undefined`                           |
| `region`           | `'eu' \| 'us'`           | 未设置 `endpoint` 时使用的 Tiptap Cloud 区域                                          | `'eu'`                                |
| `token`            | `string`                 | 用于身份验证的 Tiptap JWT，参见[身份验证](/authentication)                                                                | `''`                                  |
| `styleOverrides`   | `Record<string, string>` | 应用于导出内容的样式覆盖                                                           | `undefined`                           |
| `headers`          | `HeaderConfig`           | 导出文档的页眉配置                                                   | `undefined`                           |
| `footers`          | `FooterConfig`           | 导出文档的页脚配置                                                   | `undefined`                           |
| `pageSize`         | `PageSize`               | 页面尺寸配置                                                                          | `undefined`                           |
| `pageMargins`      | `PageMargins`            | 页边距配置                                                                       | `undefined`                           |
| `customNodes`      | `CustomNodeDefinition[]` | 基于 DOCX 的转换所用的自定义节点定义（需要 `@tiptap-pro/extension-export-docx`） | `undefined`                           |
| `onCompleteExport` | `(result: Blob) => void` | 接收导出文件 Blob 的回调                                               | 未提供时会抛出错误          |

## 导出 ODT 文件

安装扩展后，可以使用 `exportOdt` 命令将编辑器内容导出为 `.odt` 文件。

```ts
/**
 * 通过 Tiptap 转换服务将当前文档导出为 ODT 文件。
 *
 * @param options - 每次调用时都可以覆盖所有扩展级选项
 * @example editor.commands.exportOdt({ onCompleteExport: (result) => {} })
 */
exportOdt: (options?: ExportOdtCommandOptions) => ReturnType
```

`ExportOdtCommandOptions` 接口扩展了 `ExportOdtOptions`，因此每次调用命令时都可以覆盖所有配置选项：

| 属性                 | 类型                     | 说明                                               |
| ------------------ | ------------------------ | --------------------------------------------------------- |
| `endpoint`         | `string`                 | 覆盖本次导出所用的 API 端点        |
| `region`           | `'eu' \| 'us'`           | 覆盖本次导出所用的区域              |
| `token`            | `string`                 | 覆盖本次导出所用的 JWT 令牌           |
| `styleOverrides`   | `Record<string, string>` | 覆盖本次导出的样式覆盖项         |
| `headers`          | `HeaderConfig`           | 覆盖本次导出的页眉配置    |
| `footers`          | `FooterConfig`           | 覆盖本次导出的页脚配置    |
| `pageSize`         | `PageSize`               | 覆盖本次导出的页面尺寸               |
| `pageMargins`      | `PageMargins`            | 覆盖本次导出的页边距            |
| `customNodes`      | `CustomNodeDefinition[]` | 覆盖本次导出的自定义节点定义 |
| `onCompleteExport` | `(result: Blob) => void` | 覆盖本次导出的回调            |

```js
import { ExportOdt } from '@tiptap-pro/extension-export-odt'

const editor = new Editor({
  extensions: [
    // Other extensions ...
    ExportOdt.configure({
      token: 'YOUR_TOKEN',
      onCompleteExport(result) {
        // Download the ODT file
        const url = URL.createObjectURL(result)
        const a = document.createElement('a')

        a.href = url
        a.download = 'document.odt'
        a.click()

        URL.revokeObjectURL(url)
      },
    }),
    // Other extensions ...
  ],
})

// Use the extension-level callback
editor.chain().exportOdt().run()

// Or override options for a specific export
editor
  .chain()
  .exportOdt({
    pageSize: { width: '8.5in', height: '11in' },
    onCompleteExport(result) {
      // Custom handling for this specific export
      const url = URL.createObjectURL(result)
      window.open(url)
    },
  })
  .run()
```

### 工作原理

调用 `exportOdt` 时，扩展会将编辑器文档及配置的选项（样式覆盖、页面布局、页眉、页脚）发送到 Convert 服务。服务会返回生成的 `.odt` 文件二进制 Blob。`onCompleteExport` 回调会直接接收该 Blob。错误会以异常形式抛出，而不会通过回调传递。

## 预期情况

- **需要身份验证**（`token` JWT）。请在服务器端生成 JWT。参见 [Conversion 安装指南](/conversion/getting-started/install)。
- **需要处理的 HTTP 响应：** `401`（缺少或无效的 JWT）、`403`（应用无权执行该操作——通常是因为计划不包含此格式）、`5xx`（暂时性的服务器端错误；请采用退避策略重试）。
- **每个请求都会在响应前完成端到端处理。** 处理大型文档时，请预留更长的往返时间。

## 不应期待的情况

- **与 Word 往返转换后完全一致。** ODT 是 LibreOffice 和 OpenOffice 使用的 OpenDocument Text 格式；某些 Word 专属的页眉/页脚功能和样式细节在导出后可能无法保留。
- **Word 转 ODT 后布局像素级完全一致。** 如果需要便于移植的开放格式文件，请使用 ODT；如果优先考虑与 Word 的一致性，请使用 [DOCX](/conversion/export/docx/editor-extension)。
