使用通用数据库扩展，将数据存储到你现有的任意数据存储中。
它只需要一个用于获取数据的 Promise，以及另一个用于存储数据的 Promise。其余工作都由 Hocuspocus 处理。

## 安装

按如下方式安装数据库扩展：

```bash
npm install @hocuspocus/extension-database
```

## 配置

**fetch**

需要一个异步函数（或 Promise），用于返回兼容 Y.js 的 Uint8Array（或 null）。
请确保返回的是之前在 store() 中保存的同一个 Uint8Array，不要创建新的 Ydoc，
否则会产生新的历史记录（并导致内容重复）。

如果你想根据原始文本或 JSON 初始创建 Ydoc，可以在此处使用你选择的转换器来实现
（例如 `TiptapTransformer.toYdoc` 或 `ProsemirrorTransformer.toYdoc`）。

**store**

需要一个异步函数（或 Promise），用于将 Y.js 二进制数据持久化到某处。

## 用法

以下示例使用 SQLite 存储和读取数据。你可以将这部分替换为你现有的任意数据存储。只要返回一个 Promise，就可以使用 PostgreSQL、MySQL、MongoDB、S3 等存储数据……如果你确实想使用 SQLite，可以查看 [SQLite 扩展](/hocuspocus/server/extensions/sqlite)。

```js
import { Server } from "@hocuspocus/server";
import { Database } from "@hocuspocus/extension-database";
import sqlite3 from "sqlite3";

const server = new Server({
  extensions: [
    new Database({
      // Return a Promise to retrieve data …
      fetch: async ({ documentName }) => {
        return new Promise((resolve, reject) => {
          this.db?.get(
            `
            SELECT data FROM "documents" WHERE name = $name ORDER BY rowid DESC
          `,
            {
              $name: documentName,
            },
            (error, row) => {
              if (error) {
                reject(error);
              }

              resolve(row?.data);
            }
          );
        });
      },
      // … and a Promise to store data:
      store: async ({ documentName, state }) => {
        this.db?.run(
          `
          INSERT INTO "documents" ("name", "data") VALUES ($name, $data)
            ON CONFLICT(name) DO UPDATE SET data = $data
        `,
          {
            $name: documentName,
            $data: state,
          }
        );
      },
    }),
  ],
});

server.listen();
```
