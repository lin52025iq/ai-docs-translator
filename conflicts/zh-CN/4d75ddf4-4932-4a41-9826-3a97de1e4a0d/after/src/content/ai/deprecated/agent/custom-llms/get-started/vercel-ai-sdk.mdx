[Vercel AI SDK](https://ai-sdk.dev) 可让你使用多个 [AI 模型提供商](https://ai-sdk.dev/providers/ai-sdk-providers)构建 AI 代理。你可以轻松切换提供商，逐一尝试并选出最适合自己的提供商。

<Callout title="提供代码演示" variant="info">
  本指南附有代码演示，帮助你快速入门。请参阅 [GitHub
  仓库](https://github.com/ueberdosis/ai-agent-custom-llm-demos)。
</Callout>

## 客户端设置

首先，安装 AI Agent 扩展。

```bash
npm install @tiptap-pro/extension-ai-agent
```

然后，导入扩展并使用 `AiAgentProvider` 类进行配置。

```tsx
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import AiAgent, { AiAgentProvider } from '@tiptap-pro/extension-ai-agent'

const provider = new AiAgentProvider()

const editor = new Editor({
  extensions: [
    StarterKit,
    AiAgent.configure({
      provider,
    }),
  ],
})
```

在 `AiAgentProvider` 中，定义一个用于调用后端的 `resolver` 函数。

```tsx
import AiAgent, { AiAgentProvider } from '@tiptap-pro/extension-ai-agent'

const provider = new AiAgentProvider({
  // The `chatMessages` property contains the chat messages of the conversation
  resolver: async ({ chatMessages, schemaAwarenessData }) => {
    // Call the API endpoint of your backend
    const response = await fetch('/api-endpoint', {
      method: 'POST',
      body: JSON.stringify({ chatMessages, schemaAwarenessData }),
    })
    return await response.json()
  },
})
```

下一节将介绍如何实现 API 端点，使其以正确的格式返回响应。

## 服务端设置

首先，安装 AI Agent 扩展、Vercel AI SDK 和你选择的 AI 提供商（本例中使用 OpenAI）。

```bash
npm install @tiptap-pro/extension-ai-agent-server ai @ai-sdk/openai
```

从请求参数中获取聊天消息和 schema 感知数据。

```ts
// Code inside your API endpoint. Code depends on your backend framework
const { chatMessages, schemaAwarenessData } = request
```

然后，在 API 端点中创建一个 `AiAgentToolkit` 实例。通过它可以配置可供 AI 模型使用的工具。

<Callout title="与 Vercel AI SDK v4 配合使用" variant="info">
  若要使用 Vercel AI SDK v4 而不是 v5，请导入 `vercelAiSdkV4Adapter`，而不是
  `vercelAiSdkAdapter`。
</Callout>

```ts
import { AiAgentToolkit, vercelAiSdkAdapter } from '@tiptap-pro/extension-ai-agent-server'

const toolkit = new AiAgentToolkit({
  adapter: vercelAiSdkAdapter,
  schemaAwarenessData,
})
```

还要定义一个 `ChatMessagesFormatter` 实例。它可以将聊天消息转换为 Vercel AI SDK 所需的格式。

```ts
import {
  AiAgentToolkit,
  vercelAiSdkAdapter,
  ChatMessagesFormatter,
} from '@tiptap-pro/extension-ai-agent-server'

const formatter = new ChatMessagesFormatter({
  initialMessages: chatMessages,
  adapter: vercelAiSdkAdapter,
})
```

创建好 toolkit 和 formatter 后，使用 Vercel AI SDK 向 AI 提供商发送请求。

```ts
import {
  AiAgentToolkit,
  vercelAiSdkAdapter,
  ChatMessagesFormatter,
} from '@tiptap-pro/extension-ai-agent-server'
import { generateText } from 'ai'
import { openai } from '@ai-sdk/openai'

const { chatMessages, schemaAwarenessData } = request

const toolkit = new AiAgentToolkit({
  adapter: vercelAiSdkAdapter,
  schemaAwarenessData,
})

const formatter = new ChatMessagesFormatter({
  // Get the chat messages from the request body
  initialMessages: chatMessages,
  adapter: vercelAiSdkAdapter,
})

// Call the Vercel AI SDK
const response = await generateText({
  model: openai('gpt-4.1'),
  messages: [
    {
      role: 'system',
      content: `
<Your system prompt>
${toolkit.getSystemPrompt()}
`,
    },
    ...formatter.format(),
  ],
  // Provide the tools that the AI model can call
  tools: toolkit.format(),
})
```

在系统提示词的末尾，加入 `AiAgentToolkit` 实例生成的系统提示词，例如：`toolkit.getSystemPrompt()`。其中包含有关如何使用工具的说明。

编写系统提示词时，请参阅[系统提示词指南](/ai/deprecated/agent/configure/system-prompt)。其中提供了一个示例系统提示词，可供你作为起点。

最后，使用 `formatter` 将响应转换为 AI Agent 扩展所需的格式。

```ts
formatter.addAiResponse(response)

const response = formatter.getResolverResponse()
```

`formatter.getResolverResponse()` 返回的值应作为 API 端点的响应，也是 resolver 函数的返回值。
