本指南将介绍如何为一个小型原子行内节点添加 Markdown 支持，该节点可以渲染 Emoji 简码（例如 `:smile:`）。我们将分为四个步骤，并在每一步提供完整示例，确保你始终能了解完整上下文：

1. 创建基础 `emoji` 节点（不含 Markdown 支持）。
2. 添加分词器，将 `:name:` 转换为令牌。
3. 添加解析器，将令牌转换为 Tiptap JSON。
4. 添加渲染器，将 Tiptap JSON 序列化回 Markdown。

我们将支持以下简写形式：

```md
Hello :smile: world!
```

---

## 第 1 步：创建基础 `emoji` 节点

首先，定义一个小型原子行内节点，用于存储 `name` 属性，并在 HTML 中渲染 Emoji。

```js
import { Node } from '@tiptap/core'

const emojiMap = {
  smile: '😊',
  heart: '❤️',
  thumbsup: '👍',
  fire: '🔥',
  // add more mappings as needed
}

export const Emoji = Node.create({
  name: 'emoji',

  group: 'inline',
  inline: true,
  atom: true,

  addAttributes() {
    return {
      name: { default: 'smile' },
    }
  },

  parseHTML() {
    return [{ tag: 'span[data-emoji]' }]
  },

  renderHTML({ node }) {
    const emoji = emojiMap[node.attrs.name] || node.attrs.name || 'smile'
    return ['span', { 'data-emoji': node.attrs.name }, emoji]
  },
})
```

**注意：**
- 节点设置了 `atom: true` 和 `inline`，因此它的行为就像不可拆分的行内内容。
- `emojiMap` 用于将简短名称映射为实际的 Emoji 字符，以便输出 HTML。

## 第 2 步：添加自定义 Markdown 分词器

分词器会识别行内 Markdown 中的 `:name:` 简码，并返回包含 Emoji 名称的令牌。下面是包含分词器的完整扩展，以便你了解它如何与基础 Node 集成。

```js
import { Node } from '@tiptap/core'

const emojiMap = {
  smile: '😊',
  heart: '❤️',
  thumbsup: '👍',
  fire: '🔥',
  // add more mappings as needed
}

export const Emoji = Node.create({
  name: 'emoji',

  group: 'inline',
  inline: true,
  atom: true,

  addAttributes() {
    return {
      name: { default: 'smile' },
    }
  },

  parseHTML() {
    return [{ tag: 'span[data-emoji]' }]
  },

  renderHTML({ node }) {
    const emoji = emojiMap[node.attrs.name] || node.attrs.name || 'smile'
    return ['span', { 'data-emoji': node.attrs.name }, emoji]
  },

  // define a Markdown tokenizer to recognize :name: shortcodes
  markdownTokenizer: {
    name: 'emoji',
    level: 'inline',
    // Fast hint for the lexer
    start: (src) => src.indexOf(':'),
    tokenize: (src, tokens, lexer) => {
      // Match :name: where name can include letters, numbers, underscores, plus signs
      const match = /^:([a-z0-9_+]+):/i.exec(src)
      if (!match) return undefined

      return {
        type: 'emoji',
        raw: match[0],      // full match like ":smile:"
        emojiName: match[1], // captured name like "smile"
      }
    },
  },
})
```

**实现说明：**
- `start` 是一种优化，供词法分析器快速查找候选位置。
- 分词器会返回包含 `type`、`raw` 和 `emojiName` 字段的令牌对象，解析器将使用这些字段。
- 将分词器设为行内级别（`level: 'inline'`），使其能够参与行内解析。

## 第 3 步：添加解析器

`parseMarkdown` 函数会将分词器生成的令牌转换为 Tiptap 节点。对于原子行内节点，应返回一个包含 `type` 和 `attrs` 的节点对象。下面是包含分词器和解析器的完整扩展。

```js
import { Node } from '@tiptap/core'

const emojiMap = {
  smile: '😊',
  heart: '❤️',
  thumbsup: '👍',
  fire: '🔥',
  // add more mappings as needed
}

export const Emoji = Node.create({
  name: 'emoji',

  group: 'inline',
  inline: true,
  atom: true,

  addAttributes() {
    return {
      name: { default: 'smile' },
    }
  },

  parseHTML() {
    return [{ tag: 'span[data-emoji]' }]
  },

  renderHTML({ node }) {
    const emoji = emojiMap[node.attrs.name] || node.attrs.name || 'smile'
    return ['span', { 'data-emoji': node.attrs.name }, emoji]
  },

  markdownTokenizer: {
    name: 'emoji',
    level: 'inline',
    // Fast hint for the lexer
    start: (src) => src.indexOf(':'),
    tokenize: (src, tokens, lexer) => {
      // Match :name: where name can include letters, numbers, underscores, plus signs
      const match = /^:([a-z0-9_+]+):/i.exec(src)
      if (!match) return undefined

      return {
        type: 'emoji',
        raw: match[0],      // full match like ":smile:"
        emojiName: match[1], // captured name like "smile"
      }
    },
  },

  // Parse token into a Tiptap node
  parseMarkdown: (token, helpers) => {
    return {
      type: 'emoji',
      attrs: { name: token.emojiName },
    }
  },
})
```

**注意：**
- `parseMarkdown` 函数应返回一个对象，其中 `type` 与节点的 `name` 相匹配。
- 原子节点不提供 `content`；它们是带属性的独立节点。

## 第 4 步：添加渲染器

要支持将编辑器状态序列化回 Markdown 简码，请实现 `renderMarkdown` 函数。该函数接收一个 Tiptap 节点，并应返回表示该节点的 Markdown 字符串。下面是包含分词、解析和渲染功能的完整扩展。

```js
import { Node } from '@tiptap/core'

const emojiMap = {
  smile: '😊',
  heart: '❤️',
  thumbsup: '👍',
  fire: '🔥',
  // add more mappings as needed
}

export const Emoji = Node.create({
  name: 'emoji',

  group: 'inline',
  inline: true,
  atom: true,

  addAttributes() {
    return {
      name: { default: 'smile' },
    }
  },

  parseHTML() {
    return [{ tag: 'span[data-emoji]' }]
  },

  renderHTML({ node }) {
    const emoji = emojiMap[node.attrs.name] || node.attrs.name || 'smile'
    return ['span', { 'data-emoji': node.attrs.name }, emoji]
  },

  markdownTokenizer: {
    name: 'emoji',
    level: 'inline',
    // Fast hint for the lexer
    start: (src) => src.indexOf(':'),
    tokenize: (src, tokens, lexer) => {
      // Match :name: where name can include letters, numbers, underscores, plus signs
      const match = /^:([a-z0-9_+]+):/i.exec(src)
      if (!match) return undefined

      return {
        type: 'emoji',
        raw: match[0],       // full match like ":smile:"
        emojiName: match[1], // captured name like "smile"
      }
    },
  },

  // Parse token into a Tiptap node
  parseMarkdown: (token, helpers) => {
    return {
      type: 'emoji',
      attrs: { name: token.emojiName },
    }
  },

  // Render Tiptap node back to Markdown
  renderMarkdown: (node, helpers) => {
    // Serialize back to :name: shortcode. Use the stored name attribute.
    return `:${node.attrs?.name || 'unknown'}:`
  },
})
```

## 用法

使用包含 Emoji 简码的 Markdown 设置编辑器内容。根据你的 Markdown 集成方式，传入 `contentType: 'markdown'`，或使用所配置环境提供的 API：

```js
editor.commands.setContent('Hello :smile: :heart: :thumbsup:', { contentType: 'markdown' })
```

这将生成带有相应 `name` 属性的行内 `emoji` 节点；HTML 渲染时会显示映射后的 Emoji 字符（通过 `emojiMap`）。

## 测试与边缘情况

- 未知名称：如果某个简码不在 `emojiMap` 中，当前节点会在 span 中渲染原始 `name`（你也可以选择显示备用内容或移除该节点）。如有需要，可在 `markdownTokenizer` 或 `parseMarkdown` 中验证或规范化名称。
- 大小写敏感性：分词器使用 `i` 标志，因此名称不区分大小写；请确保 `emojiMap` 键符合你选择的命名约定，或使用 `.toLowerCase()` 将其统一为小写。
- 行内解析：由于这是一个行内分词器，它会在段落和行内上下文中尝试匹配。请确保它不会与其他行内分词器（例如强调语法）冲突；必要时可调整正则表达式，或检查周围空白字符。
- 原子行为：该节点是原子的，因此不能作为文本进行编辑。这适用于 Emoji 元素，但如果需要编辑简码，可能就需要采用不同的行为。
