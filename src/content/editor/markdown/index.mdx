Markdown 扩展为 Tiptap 编辑器提供双向 Markdown 支持：将 Markdown 字符串解析为 Tiptap 的 JSON 格式，并将编辑器内容序列化回 Markdown。

## 核心功能

- **Markdown 解析**：将 Markdown 字符串转换为 Tiptap JSON
- **Markdown 序列化**：将编辑器内容导出为 Markdown
- **自定义分词器**：支持自定义 Markdown 语法
- **可扩展架构**：每个扩展都可以定义自己的解析和渲染逻辑
- **简化自定义语法创建的实用工具**：`createBlockMarkdownSpec`、`createInlineMarkdownSpec` 等
- **HTML 支持**：使用 Tiptap 现有的 HTML 解析功能解析 Markdown 中嵌入的 HTML

## 工作原理

Markdown 扩展充当 Markdown 文本与 Tiptap JSON 文档结构之间的桥梁。

它通过覆盖现有方法和属性，并替换为适用于 Markdown 的实现来扩展编辑器的基础功能，从而实现 Markdown 与 Tiptap 富文本编辑器的无缝集成。

```js
// Set initial content
const editor = new Editor({
  extensions: [StarterKit, Markdown],
  content: '# Hello World\n\nThis is **Markdown**!',
  contentType: 'markdown',
})

// Insert content
editor.commands.insertContent('# Hello World\n\nThis is **Markdown**!')
```

### 架构

```
Markdown 字符串
      ↓
   MarkedJS 词法分析器（分词）
      ↓
   Markdown 令牌
      ↓
   扩展解析处理程序
      ↓
   Tiptap JSON
```

反向转换过程如下：

```
Tiptap JSON
      ↓
   扩展渲染处理程序
      ↓
   Markdown 字符串
```

## 局限性

当前版本的 Markdown 扩展存在一些局限性：

- **暂不支持评论**：Markdown 不支持评论等一些高级功能。将 Markdown 内容解析到包含评论的文档时请务必**谨慎**，因为如果用 Markdown 内容替换文档，评论可能会丢失。
- **表格中的多个子节点**：支持 Markdown 表格，但每个单元格只允许一个子节点，因为 Markdown 语法无法表示多个子节点。

## 为什么选择 MarkedJS？

此扩展集成了 [MarkedJS](https://marked.js.org) 作为解析器：

- **快速轻量**：现有 Markdown 解析器中速度最快的解析器之一
- **可扩展**：自定义分词器可支持非标准的 Markdown 语法
- **符合 CommonMark 规范**：遵循 CommonMark 规范
- **经过实战检验**：广泛用于生产环境，并持续积极开发

词法分析器 API 会将 Markdown 拆分为令牌，这些令牌与 Tiptap 的节点结构天然对应，使集成过程简洁且易于维护。该扩展在浏览器和服务器环境中的工作方式完全一致。
