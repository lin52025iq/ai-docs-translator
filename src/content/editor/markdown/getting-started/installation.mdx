本指南将介绍如何在 Tiptap 编辑器中安装和设置 Markdown 扩展。

## 安装

使用你偏好的包管理器安装 Markdown 扩展：

```bash
npm install @tiptap/markdown
```

## 基本设置

将 Markdown 扩展添加到编辑器：

```typescript
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import { Markdown } from '@tiptap/markdown'

const editor = new Editor({
  element: document.querySelector('#editor'),
  extensions: [StarterKit, Markdown],
  content: '<p>Hello World!</p>',
})
```

完成！现在，编辑器已支持 Markdown 解析和序列化。

### 将初始内容设为 Markdown

创建编辑器时加载 Markdown 内容：

```typescript
const editor = new Editor({
  extensions: [StarterKit, Markdown],
  content: '# Hello World\n\nThis is **Markdown**!',
  contentType: 'markdown',
})
```

## 配置选项

Markdown 扩展支持多种配置选项：

### 缩进样式

配置序列化 Markdown 中嵌套结构（列表、代码块）的缩进方式：

```typescript
Markdown.configure({
  indentation: {
    style: 'space', // 'space' or 'tab'
    size: 2, // Number of spaces or tabs
  },
})
```

**示例：**

```typescript
// Use 4 spaces for indentation (default: 2 spaces)
Markdown.configure({
  indentation: { style: 'space', size: 4 },
})

// Use tabs for indentation
Markdown.configure({
  indentation: { style: 'tab', size: 1 },
})
```

### 自定义 Marked 实例

如果需要使用自定义版本的 marked，或预先配置它：

```typescript
import { marked } from 'marked'

// Configure marked
marked.setOptions({
  gfm: true,
  breaks: true,
})

// Use custom marked instance
Markdown.configure({
  marked: marked,
})
```

### Marked 选项

你也可以直接向扩展传入 marked 选项：

```typescript
Markdown.configure({
  markedOptions: {
    gfm: true, // GitHub Flavored Markdown
    breaks: false, // Convert \n to <br>
    pedantic: false, // Strict Markdown mode
  },
})
```

所有可用选项请参阅 [marked 文档](https://marked.js.org/using_advanced#options)。

## 验证安装

验证扩展是否已正确安装：

```typescript
// Check if Markdown manager is available
console.log(editor.markdown) // Should log the MarkdownManager instance

// Try parsing
const json = editor.markdown.parse('# Hello')
console.log(json)
// { type: 'doc', content: [...] }

// Try serializing
const markdown = editor.markdown.serialize(json)
console.log(markdown)
// # Hello
```

## 常见问题

### 找不到扩展

如果出现找不到 `@tiptap/markdown` 的错误：

1. 确认已安装该包：`npm list @tiptap/markdown`
2. 清除构建缓存和 node_modules
3. 重新安装依赖

### Markdown 无法解析

如果 Markdown 无法解析：

1. 设置初始内容时，请确认使用了 `contentType: 'markdown'`
2. 或者调用 `setContent()` 时使用 `contentType: 'markdown'` 选项

### TypeScript 错误

如果出现 TypeScript 错误：

1. 确认已安装 `@tiptap/core`（其中包含类型定义）
2. 将这两个包都更新到最新版本
3. 检查 `tsconfig.json` 是否包含正确的模块解析配置

```json
{
  "compilerOptions": {
    "moduleResolution": "node",
    "esModuleInterop": true
  }
}
```
