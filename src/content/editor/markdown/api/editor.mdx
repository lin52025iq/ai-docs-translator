Markdown 包不会导出新的 Editor 类，而是扩展现有的 Tiptap Editor 类。这意味着你可以使用 Tiptap Editor 的所有标准方法和选项，以及 Markdown 包提供的附加功能。

## 方法

### `Editor.getMarkdown()`

以 Markdown 格式获取编辑器的当前内容。

- **返回值**：`string`

```js
const markdown = editor.getMarkdown()
```

## 属性

### `Editor.markdown`

访问 MarkdownManager 实例。

```typescript
editor.markdown: MarkdownManager
```

#### 示例

```typescript
// Parse Markdown to JSON
const json = editor.markdown.parse('# Hello')

// Serialize JSON to Markdown
const markdown = editor.markdown.serialize(json)

// Access marked instance
const marked = editor.markdown.instance
```

## 选项

### `Editor.content`

编辑器内容支持 **HTML**、**Markdown** 或 **Tiptap JSON** 格式。

> **注意**：如果初始 `content` 值为 Markdown，请设置 `contentType: 'markdown'`。

- **类型**：`string | object`
- **默认值**：`''`
- **必填**：`false`

```js
const editor = new Editor({
  content: '<h1>Hello world</h1>',
})
```

```js
const editor = new Editor({
  content: [
    { type: 'heading', attrs: { level: 1 }, content: [{ type: 'text', text: 'Hello world' }] },
  ],
})
```

```js
const editor = new Editor({
  content: '# Hello world',
  contentType: 'markdown',
})
```

### `Editor.contentType`

定义传入编辑器的内容类型。默认值为 `json`。如果设置了无效的组合（例如，内容是 JSON 对象，但 `contentType` 设置为 `markdown`），编辑器会自动回退到 `json`，反之亦然。

- **类型**：`string`
- **默认值**：`json`
- **必填**：`false`
- **可选值**：`json`、`html`、`markdown`

```js
const editor = new Editor({
  content: '# Hello world',
  contentType: 'markdown',
})
```

## 命令选项

### `setContent(content, options)`

使用 Markdown 设置编辑器内容。

```typescript
editor.commands.setContent(
  content: string,
  options?: {
    contentType?: string,
    emitUpdate?: boolean,
    parseOptions?: ParseOptions,
  }
): boolean
```

#### 参数

- **`content`**：要设置的 Markdown 字符串
- **`options.contentType`**：插入内容的类型，可以是 `json`、`html` 或 `markdown`。如果格式不匹配，则自动检测（默认值：`json`）
- **`options.emitUpdate`**：是否触发更新事件（默认值：`true`）
- **`options.parseOptions`**：其他解析选项

#### 返回值

`boolean` - 命令是否成功

#### 示例

```typescript
editor.commands.setContent('# New Content\n\nThis is **bold**.', { contentType: 'markdown' })
```

---

### `insertContent(value, options)`

在当前选区插入 Markdown 内容。

```typescript
editor.commands.insertContent(
  value: string,
  options?: {
    contentType?: string,
    parseOptions?: ParseOptions,
    updateSelection?: boolean,
  }
): boolean
```

#### 参数

- **`value`**：要插入的 Markdown 字符串
- **`options.contentType`**：插入内容的类型，可以是 `json`、`html` 或 `markdown`。如果格式不匹配，则自动检测（默认值：`json`）
- **`options.updateSelection`**：插入后是否更新选区
- **`options.parseOptions`**：其他解析选项

#### 返回值

`boolean` - 命令是否成功

#### 示例

```typescript
editor.commands.insertContent('**Bold text** at cursor', { contentType: 'markdown' })
```

---

### `insertContentAt(position, value, options)`

在指定位置插入 Markdown 内容。

```typescript
editor.commands.insertContentAt(
  position: number | Range,
  value: string,
  options?: {
    contentType?: string,
    parseOptions?: ParseOptions,
    updateSelection?: boolean,
  }
): boolean
```

#### 参数

- **`position`**：位置（数字）或范围（`{ from, to }`）
- **`value`**：要插入的 Markdown 字符串
- **`options.contentType`**：插入内容的类型，可以是 `json`、`html` 或 `markdown`。如果格式不匹配，则自动检测（默认值：`json`）
- **`options.updateSelection`**：插入后是否更新选区
- **`options.parseOptions`**：其他解析选项

#### 返回值

`boolean` - 命令是否成功

#### 示例

```typescript
// Insert at position
editor.commands.insertContentAt(10, '## Heading', { contentType: 'markdown' })

// Replace range
editor.commands.insertContentAt({ from: 10, to: 20 }, '**replacement**', { contentType: 'markdown' })
```

## 扩展规范

扩展规范还会添加以下选项：

### `markdownTokenName`

用于 Markdown 解析的 token 名称。

- **类型**：`string`
- **默认值**：`undefined`
- **必填**：`false`

```typescript
const CustomNode = Node.create({
  // ...

  markdownTokenName: 'custom_token',
})
```

### `parseMarkdown`

用于自定义将 Markdown token 解析为 ProseMirror 节点的函数。

- **类型**：`(token: MarkdownToken, helpers: MarkdownParseHelpers) => ProseMirrorNode[] | null`
- **默认值**：`undefined`
- **必填**：`false`

```typescript
const CustomNode = Node.create({
  // ...

  parseMarkdown: (token, helpers) => {
    return {
      type: 'customNode',
      attrs: { type: token.type },
      content: helpers.parseChildren(token.tokens || [])
    }
  },
})
```

### `renderMarkdown`

用于自定义将 ProseMirror 节点渲染为 Markdown token 的函数。

- **类型**：`(node: JSONContent, helpers: MarkdownRenderHelpers, context: RenderContext) => string | null`
- **默认值**：`undefined`
- **必填**：`false`

```typescript
const CustomNode = Node.create({
  // ...

  renderMarkdown: (node, helpers, context) => {
    const content = helpers.renderChildren(node.content, context)

    return `[${context.parentType}] ${content}`
  },
})
```

### `markdownTokenizer`

用于创建自定义分词器的配置对象，可将 Markdown 字符串转换为 token。

- **类型**：`object`
- **默认值**：`undefined`
- **必填**：`false`

```typescript
const CustomNode = Node.create({
  // ...

  // example tokenizer that matches ::custom text::
  markdownTokenizer: {
    name: 'custom_token',
    level: 'inline',
    start(src) { return src.indexOf('::') },
    tokenizer(src, tokens) {
      const rule = /^::(.*?)::/
      const match = rule.exec(src)
      if (match) {
        return {
          type: 'custom_token',
          raw: match[0],
          text: match[1].trim(),
        }
      }
    },
  },
})
```

### `markdownOptions`

用于向 Markdown 解析器和序列化器传递其他选项的可选对象。

- **类型**：`object`
- **默认值**：`undefined`
- **必填**：`false`

```typescript
const CustomNode = Node.create({
  // ...

  markdownOptions: {
    indentsContent: true, // this setting will cause the indent level in the render context to increase inside this node
  }
})
```
