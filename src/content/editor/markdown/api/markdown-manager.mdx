`MarkdownManager` 类是一个独立的类，可用于将 Markdown 内容解析并序列化为 Tiptap 文档模型。

## 方法

### 构造函数

```typescript
new MarkdownManager(options?: {
  marked?: typeof marked,
  markedOptions?: MarkedOptions,
  indentation?: {
    style?: 'space' | 'tab',
    size?: number,
  },
})
```

### `MarkdownManager.hasMarked()`

根据 `marked` 库是否可用，返回 `true` 或 `false`。

- **返回值**：`boolean`

```js
const manager = new MarkdownManager()
manager.hasMarked() // true or false
```

### `MarkdownManager.registerExtension()`

注册一个用于解析和序列化 Markdown 内容的 Tiptap 扩展。

- **返回值**：`void`
- **参数**：
  - `extension`：要注册的 Tiptap 扩展。

```js
const manager = new MarkdownManager()
manager.registerExtension(MyCustomExtension)
```

### `MarkdownManager.parse()`

将 Markdown 字符串解析为 Tiptap 文档。

- **返回值**：`JSON` - JSON 格式的 Tiptap 文档。
- **参数**：
  - `markdown`：包含要解析的 Markdown 内容的字符串。

```js
const manager = new MarkdownManager()
const doc = manager.parse('# Hello World')
```

Markdown 解析会保留连续的空段落：必要时结合常规空行分隔和 `&nbsp;` 标记。例如，一组连续空段落中的第一个空段落以空行表示，而同一组中后续的空段落则以 `&nbsp;` 表示，从而确保往返转换为 JSON 时这些段落不会丢失。

### `MarkdownManager.serialize()`

将 Tiptap 文档或 JSON 内容序列化为 Markdown 字符串。

- **返回值**：`string` - 序列化后的 Markdown 字符串。
- **参数**：
  - `content`：要序列化的 Tiptap 文档或 JSON 内容。

```js
const manager = new MarkdownManager()
const markdown = manager.serialize(doc)
```

### `MarkdownManager.renderNodeToMarkdown()`

将单个 ProseMirror 节点渲染为对应的 Markdown 表示形式。

- **返回值**：`string` - 给定节点对应的 Markdown 字符串。
- **参数**：
  - **node**：要渲染的 ProseMirror 节点。
  - **parentNode**：（可选）父级 ProseMirror 节点。
  - **index**：（可选）该节点在父级节点中的索引。
  - **level**：（可选）该节点的嵌套层级。

```
const manager = new MarkdownManager()
const markdown = manager.renderNodeToMarkdown(node)
```

渲染器会通过 `RenderContext.previousNode` 将同级节点的上下文传递给扩展。这对于依赖同一层级中前一个节点做出判断的场景很有用，例如保留连续的空段落。

### `MarkdownManager.renderNodes()`

将一组 ProseMirror 节点渲染为合并后的 Markdown 表示形式。

- **返回值**：`string` - 给定节点对应的合并后 Markdown 字符串。
- **参数**：
  - **nodes**：要渲染的 ProseMirror 节点数组。
  - **parentNode**：（可选）父级 ProseMirror 节点。
  - **separator**：（可选）用于分隔渲染后节点的字符串。默认为 `''`
  - **level**：（可选）节点的嵌套层级。默认为 `0`。
  - **level**：`number` - 节点的嵌套层级。默认为 `0`。

## 属性

### `Markdown.instance`

用于解析 Markdown 内容的 MarkedJS 实例。

### `Markdown.indentCharacter`

列表中用于缩进的字符。默认为空格（`' '`）。

### `Markdown.indentString`

列表中用于缩进的字符串。默认为两个空格（`'  '`）。
