### 构建自己的 UI

如果你更愿意构建自己的 UI，或者需要了解 Tiptap 中样式的工作方式，可以使用以下方法。

## 设置纯 HTML 的样式

整个编辑器都渲染在一个带有 `.tiptap` 类的容器中。你可以利用它，将样式限定在编辑器内容范围内：

```css
/* Scoped to the editor */
.tiptap p {
  margin: 1em 0;
}
```

<Callout title="使用 CSS Modules 设置样式" variant="warning">
  在 [CSS Modules](https://github.com/css-modules/css-modules) 中，类名会经过修改以实现局部作用域，可能导致针对 `.tiptap` 类的样式无法生效。请使用全局样式，或使用 `:global(.tiptap)` 修饰符，确保样式正确应用。
</Callout>

如果你在其他地方渲染已存储的内容，其中就不会有 `.tiptap` 容器，因此可以为相关 HTML 标签添加全局样式：

```css
/* Global styling */
p {
  margin: 1em 0;
}
```

## 添加自定义类

你可以控制整个渲染过程，包括为所有元素添加类。

### 扩展

大多数扩展都允许你通过 `HTMLAttributes` 选项为渲染出的 HTML 添加属性。你可以利用它添加自定义类（或其他属性）。使用 [Tailwind CSS](#style-using-tailwind-css) 时，这也非常实用。

```js
new Editor({
  extensions: [
    Document,
    Paragraph.configure({
      HTMLAttributes: {
        class: 'my-custom-paragraph',
      },
    }),
    Heading.configure({
      HTMLAttributes: {
        class: 'my-custom-heading',
      },
    }),
    Text,
  ],
})
```

渲染后的 HTML 如下所示：

```html
<h1 class="my-custom-heading">Example Text</h1>
<p class="my-custom-paragraph">Wow, that's really custom.</p>
```

如果扩展已经定义了类，你添加的类也会一并保留。

### 编辑器

你甚至可以为包含编辑器的元素传递类：

```js
new Editor({
  editorProps: {
    attributes: {
      class: 'prose prose-sm sm:prose lg:prose-lg xl:prose-2xl mx-auto focus:outline-none',
    },
  },
})
```

## 自定义 HTML

你也可以自定义扩展的标记。下面的示例会创建一个自定义粗体扩展，它渲染的不是 `<strong>` 标签，而是 `<b>` 标签：

```js
import Bold from '@tiptap/extension-bold'

const CustomBold = Bold.extend({
  renderHTML({ HTMLAttributes }) {
    // Original:
    // return ['strong', HTMLAttributes, 0]
    return ['b', HTMLAttributes, 0]
  },
})

new Editor({
  extensions: [
    // …
    CustomBold,
  ],
})
```

为了更好地组织代码，你应该将自定义扩展放在单独的文件中，不过大致思路就是这样。

## 使用 Tailwind CSS 设置样式

Tiptap 管理的内容是纯 HTML，默认不带 Tailwind CSS 类，因此可以通过几种方式为编辑器设置样式：

### 使用全局 CSS 文件和 `@apply`

尽管 Tailwind 的维护者建议不要使用 `@apply`，但我们认为，对于像 Tiptap 内容这样灵活、由用户编写的内容，它是定义样式的最佳方式。
你可以使用全局 CSS 文件，为编辑器中的 HTML 标签应用 Tailwind 样式。现在嵌套选择器已得到广泛支持，你可以将样式限定在 `.tiptap` 类的范围内：

```css
.tiptap {
  p {
    @apply my-4 first:mt-0 last:mb-0 text-base leading-relaxed;
  }

  h1 {
    @apply text-3xl font-bold mt-8 mb-4 first:mt-0 last:mb-0;
  }
}
```

### 为扩展添加类

如果你不想使用全局 CSS 文件，一种更复杂的做法是扩展现有组件，并在 `renderHTML` 输出中的 `HTMLAttributes` 里添加 Tailwind 类。

```js
import Paragraph from '@tiptap/extension-paragraph'

const TailwindParagraph = Paragraph.extend({
  renderHTML({ HTMLAttributes }) {
    return [
      'p',
      {
        ...HTMLAttributes,
        class: 'my-4 first:mt-0 last:mb-0 text-base leading-relaxed',
      },
      0,
    ]
  },
})
```

这种方法可行，但随着扩展变得更复杂，或使用 NodeViews 时，处理起来也会更加复杂。因此，在大多数情况下，我们仍建议使用全局 CSS 文件和 `@apply`。
