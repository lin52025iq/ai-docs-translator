Tiptap 开箱即用的功能相当基础，不过这反而是件好事。你可以完全掌控编辑器的外观。

我们所说的完全掌控，是真的完全掌控。你可以（也必须）自行构建菜单，不过 Tiptap 会帮你完成所有连接工作。

## 菜单

编辑器提供了流畅的 API，可用于触发命令和添加激活状态。你可以使用任意标记。为了简化菜单定位，Tiptap 提供了一些实用工具和组件。下面逐一介绍几种最常见的用法。

### 固定菜单

固定菜单是指始终停留在同一位置的菜单。例如，常见做法是在编辑器上方放置固定菜单。Tiptap 不附带固定菜单，但你可以创建一个 `<div>` 元素，并在其中放入 `<button>` 元素来构建菜单。[请参阅下文](#buttons)，了解这些按钮如何触发编辑器中的[命令](/editor/api/commands)，例如将文本设为粗体或斜体。

### 气泡菜单

[气泡菜单](/editor/extensions/functionality/bubble-menu)会在选中文本时出现。标记和样式完全由你决定。

### 浮动菜单

[浮动菜单](/editor/extensions/functionality/floatingmenu)会在你将光标放在空行时出现在编辑器中。同样，标记和样式完全由你决定。

### 斜杠命令（正在开发中）

虽然目前还没有官方扩展，但有一个[实验性功能](/examples/experiments/slash-commands)支持使用“斜杠命令”。使用斜杠命令时，在新行开头输入 `/` 会显示一个弹出菜单。

## 按钮

好了，你已经有了菜单。接下来要如何连接各项功能呢？

### 命令

假设你已经运行了编辑器，现在想添加第一个按钮。你需要一个带有点击处理程序的 `<button>` HTML 标签。根据你的配置，代码可能如下所示：

```html
<button onclick="editor.chain().focus().toggleBold().run()">Bold</button>
```

嗯，这条命令很长，对吧？实际上，它是一个[命令链](/editor/api/commands)。我们来逐一了解：

```js
editor.chain().focus().toggleBold().run()
```

1. `editor` 应该是一个 Tiptap 实例，
2. `chain()` 用于告知编辑器你想要执行多个命令，
3. `focus()` 将焦点重新设回编辑器，
4. `toggleBold()` 将选中的文本设为粗体。如果文本已经是粗体，则会移除粗体标记。
5. `run()` 会执行整个命令链。

换句话说，这就是文本编辑器中常见的**粗体**按钮。

可用命令取决于编辑器注册的扩展。大多数扩展都提供 `set…()`、`unset…()` 和 `toggle…()` 命令。请阅读扩展文档，了解实际可用的命令，或者直接使用代码编辑器的自动补全功能浏览。

### 保持焦点

你已经在上面的示例中看到了 `focus()` 命令。点击按钮时，浏览器会将焦点放在该 DOM 元素上，编辑器则会失去焦点。你很可能会想在所有菜单按钮中添加 `focus()`，以免打断用户的写作流程。

### 激活状态

编辑器提供了 `isActive()` 方法，用于检查选中文本是否已应用某项格式。在 Vue.js 中，你可以借助该函数切换 CSS 类：

**重要提示**：如果你使用 React，为避免性能问题，编辑器状态中的值不会自动保持响应式；这意味着 `isActive()` 始终会返回编辑器初始状态中的值。
若要订阅编辑器状态，可以使用 `useEditorState` hook，具体说明请参阅[此处](/editor/getting-started/install/react#reacting-to-editor-state-changes)。

```html
<button
  :class="{ 'is-active': editor.isActive('bold') }"
  @click="editor.chain().focus().toggleBold().run()"
>
  Bold
</button>
```

这会为节点和标记切换 `.is-active` 类。你甚至可以检查特定属性。以下示例使用 [`Highlight`](/editor/extensions/marks/highlight) 标记，但不区分不同属性：

```js
editor.isActive('highlight')
```

下面的示例则会比较指定的属性：

```js
editor.isActive('highlight', { color: '#ffa8a8' })
```

还支持正则表达式：

```js
editor.isActive('textStyle', { color: /.*/ })
```

你也可以检查节点和标记，但仅检查其属性。以下是使用 [`TextAlign`](/editor/extensions/functionality/textalign) 扩展的示例：

```js
editor.isActive({ textAlign: 'right' })
```

如果选区跨越多个节点或标记，或者只有选区的一部分带有某个标记，`isActive()` 就会返回 `false`，表示没有任何内容处于激活状态。这是有意为之，目的是让用户可以立即对选区应用新的节点或标记。

## 用户体验

设计出色的用户体验时，有几点值得考虑。

### 无障碍

- 确保用户可以使用键盘浏览菜单
- 使用 [title 属性](https://developer.mozilla.org/de/docs/Web/HTML/Global_attributes/title)
- 使用 [ARIA 属性](https://developer.mozilla.org/en-US/docs/Learn/Accessibility/WAI-ARIA_basics)
- 列出可用的键盘快捷键

### 图标

大多数编辑器菜单按钮都会使用图标。在我们的部分演示中，我们使用了开源图标集 [Remix Icon](https://remixicon.com/)。不过，你可以使用任何喜欢的图标集。以下是一些建议：

- [Remix Icon](https://remixicon.com/#editor)
- [Font Awesome](https://fontawesome.com/icons?c=editors)
- [UI icons](https://www.ibm.com/design/language/iconography/ui-icons/library/)
