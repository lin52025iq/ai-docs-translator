按照本指南中的步骤，将 Tiptap 集成到 Next.js 项目中。

### 要求

- 在计算机上安装 [Node](https://nodejs.org/en/download/)
- 具备 [React](https://reactjs.org/) 使用经验

## 创建项目（可选）

如果你已经有 Next.js 项目，也可以直接使用，跳过此步骤即可。

本指南将创建一个名为 `my-tiptap-project` 的新 Next.js 项目。运行以下命令即可完成所需的初始设置。

```bash
# create a project
npx create-next-app my-tiptap-project

# change directory
cd my-tiptap-project
```

### 安装依赖

现在，标准项目模板已经就绪，可以开始使用 Tiptap 了！首先需要安装三个包：`@tiptap/react`、`@tiptap/pm` 和 `@tiptap/starter-kit`。其中，`@tiptap/starter-kit` 包含了快速入门所需的所有扩展。

```bash
npm install @tiptap/react @tiptap/pm @tiptap/starter-kit
```

如果你已完成步骤 1 和 2，现在可以运行 `npm run dev` 启动项目，并在常用浏览器中打开 [http://localhost:3000/](http://localhost:3000/)。如果你使用的是现有项目，具体情况可能有所不同。

## 集成 Tiptap

要开始使用 Tiptap，需要在应用中添加一个新组件。首先创建一个名为 `components/` 的目录，然后创建名为 `Tiptap` 的组件。在 `components/Tiptap.jsx` 中添加以下示例代码。

```jsx
'use client'

import { useEditor, EditorContent } from '@tiptap/react'
import StarterKit from '@tiptap/starter-kit'

const Tiptap = () => {
  const editor = useEditor({
    extensions: [StarterKit],
    content: '<p>Hello World! 🌎️</p>',
    // Don't render immediately on the server to avoid SSR issues
    immediatelyRender: false,
  })

  return <EditorContent editor={editor} />
}

export default Tiptap
```

<Callout title="为什么要设置 immediatelyRender: false？" variant="hint">
  Next.js 默认使用服务器端渲染。设置 `immediatelyRender: false` 可阻止编辑器在服务器上渲染，从而避免 [React 水合不匹配错误](https://react.dev/errors/418)。水合完成后，编辑器将在客户端初始化。`'use client'` 指令可确保此组件仅在浏览器中运行。
</Callout>

### 将组件添加到应用

现在，将 `app/page.js`（如果使用 Pages 路由，则为 `pages/index.js`）中的内容替换为以下示例代码，以便在应用中使用 `Tiptap` 组件。

```jsx
import Tiptap from '../components/Tiptap'

export default function Home() {
  return <Tiptap />
}
```

现在，你应该能在浏览器中看到 Tiptap 了。给自己一个鼓励吧！:)
