本指南将详细介绍如何将 Tiptap 集成到 Vue 2 项目中。你也可以查看我们的 [Vue 文本编辑器示例](/examples/basics/default-text-editor)。

### 前置条件

- 已在本机安装 [Node](https://nodejs.org/en/download/)
- 已在本机安装 [Vue CLI](https://cli.vuejs.org/)
- 具备 [Vue](https://vuejs.org/v2/guide/#Getting-Started) 使用经验

## 创建项目（可选）

如果你已经有 Vue 项目，也可以直接使用，跳过此步骤即可。

本指南将从一个名为 `my-tiptap-project` 的全新 Vue 项目开始。Vue CLI 会为我们配置好所需的一切，只需选择默认的 Vue 2 模板即可。

```bash
# create a project
vue create my-tiptap-project

# change directory
cd my-tiptap-project
```

### 安装依赖

好了，繁琐的基础配置就到这里。现在终于可以安装 Tiptap 了！接下来的示例需要 `@tiptap/vue-2` 包、`@tiptap/pm`（ProseMirror 库）和 `@tiptap/starter-kit`。后者包含了最常用的扩展，可帮助你快速开始。

```bash
npm install @tiptap/vue-2 @tiptap/pm @tiptap/starter-kit
```

如果你已完成第 1 步和第 2 步，现在可以运行 `npm run dev` 启动项目，并在你常用的浏览器中打开 [http://localhost:8080](http://localhost:8080)。如果你使用的是已有项目，访问地址可能会有所不同。

## 集成 Tiptap

要开始使用 Tiptap，你需要在应用中添加一个新组件。我们将它命名为 `Tiptap`，并把以下示例代码放入 `components/Tiptap.vue`。

这是在 Vue 中快速运行 Tiptap 的最简单方法。它会提供一个不带任何按钮的基础版 Tiptap。别担心，你很快就能添加更多功能。

```html
<template>
  <editor-content :editor="editor" />
</template>

<script>
  import { Editor, EditorContent } from '@tiptap/vue-2'
  import StarterKit from '@tiptap/starter-kit'

  export default {
    components: {
      EditorContent,
    },

    data() {
      return {
        editor: null,
      }
    },

    mounted() {
      this.editor = new Editor({
        content: "<p>I'm running Tiptap with Vue.js. 🎉</p>",
        extensions: [StarterKit],
      })
    },

    beforeDestroy() {
      this.editor.destroy()
    },
  }
</script>
```

### 将组件添加到应用中

现在，将 `src/App.vue` 的内容替换为以下示例代码，在应用中使用新的 `Tiptap` 组件。

```html
<template>
  <div id="app">
    <tiptap />
  </div>
</template>

<script>
  import Tiptap from './components/Tiptap.vue'

  export default {
    name: 'App',
    components: {
      Tiptap,
    },
  }
</script>
```

现在，你应该能在浏览器中看到 Tiptap 了。是时候为自己鼓鼓掌啦！:)

### 使用 v-model（可选）

你可能已经习惯在表单中使用 `v-model` 绑定数据，Tiptap 也支持这种方式。下面是一个可直接使用的示例组件，你可以将它集成到项目中：

```html
<template>
  <editor-content :editor="editor" />
</template>

<script>
  import { Editor, EditorContent } from '@tiptap/vue-2'
  import StarterKit from '@tiptap/starter-kit'

  export default {
    components: {
      EditorContent,
    },

    props: {
      value: {
        type: String,
        default: '',
      },
    },

    data() {
      return {
        editor: null,
      }
    },

    watch: {
      value(value) {
        // HTML
        const isSame = this.editor.getHTML() === value

        // JSON
        // const isSame = JSON.stringify(this.editor.getJSON()) === JSON.stringify(value)

        if (isSame) {
          return
        }

        this.editor.commands.setContent(value, false)
      },
    },

    mounted() {
      this.editor = new Editor({
        content: this.value,
        extensions: [StarterKit],
        onUpdate: () => {
          // HTML
          this.$emit('input', this.editor.getHTML())

          // JSON
          // this.$emit('input', this.editor.getJSON())
        },
      })
    },

    beforeDestroy() {
      this.editor.destroy()
    },
  }
</script>
```
