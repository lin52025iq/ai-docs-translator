本指南介绍如何将 Tiptap 集成到 Nuxt 4 项目中，并附有代码示例。

import { CodeDemo } from '@/components/CodeDemo'

### 要求

- 已在计算机上安装 [Node](https://nodejs.org/en/download/)
- 具备 [Vue](https://vuejs.org/guide/introduction.html) 使用经验

## 创建项目（可选）

如果你已经有 Nuxt 项目，也可以直接使用，跳过此步骤即可。

本指南将从一个名为 `my-tiptap-project` 的全新 Nuxt 项目开始。运行以下命令即可完成所需设置：

```bash
# create a project
npx nuxi@latest init my-tiptap-project

# change directory
cd my-tiptap-project
```

### 安装依赖

现在来安装 Tiptap！以下示例需要 `@tiptap/vue-3` 包（包含一些组件）、`@tiptap/pm` 包，以及 `@tiptap/starter-kit`。后者包含了最常用的扩展，能帮助你快速上手。

```bash
npm install @tiptap/vue-3 @tiptap/pm @tiptap/starter-kit
```

如果你已完成第 1 步和第 2 步，现在可以运行 `npm run dev` 启动项目，并在常用浏览器中打开 [http://localhost:3000/](http://localhost:3000/)。如果你使用的是现有项目，实际操作可能会有所不同。

## 集成 Tiptap

要开始使用 Tiptap，你需要在应用中添加一个新组件。我们将它命名为 `TiptapEditor`，并把下面的示例代码放入 `components/TiptapEditor.vue`。

这是使用 Vue 启动 Tiptap 最快的方式。它提供了一个非常基础的 Tiptap 版本，不包含任何按钮。别担心，你很快就能为它添加更多功能。

```html
<template>
  <EditorContent :editor="editor" />
</template>

<script setup>
  import { useEditor, EditorContent } from '@tiptap/vue-3'
  import StarterKit from '@tiptap/starter-kit'

  const editor = useEditor({
    content: `<p>I'm running Tiptap with Vue.js. 🎉</p>`,
    extensions: [StarterKit],
  })
</script>
```

### 添加到应用中

现在，将 `app/app.vue` 的内容替换为以下代码，以使用新的 `TiptapEditor` 组件：

```html
<template>
  <TiptapEditor />
</template>
```

在 Nuxt 4 中，组件和 Vue 组合式函数（例如 `ref` 和 `watch`）都会自动导入，因此你无需手动导入或注册它们。

现在，你应该能在浏览器中看到 Tiptap 了。给自己一点掌声吧！:)

### 使用 v-model（可选）

你可能已经习惯在表单中使用 `v-model` 绑定数据。Tiptap 也支持这种方式。下面是一个可用的组件示例，你可以将它集成到项目中：

<CodeDemo path="/GuideGettingStarted/VModel" />

```html
<template>
  <EditorContent :editor="editor" />
</template>

<script setup>
  import { useEditor, EditorContent } from '@tiptap/vue-3'
  import StarterKit from '@tiptap/starter-kit'

  const emit = defineEmits(['update:modelValue'])
  const props = defineProps({
    modelValue: {
      type: String,
      default: '',
    },
  })

  const editor = useEditor({
    content: props.modelValue,
    extensions: [StarterKit],
    onUpdate: ({ editor }) => {
      // HTML
      emit('update:modelValue', editor.getHTML())

      // JSON
      // emit('update:modelValue', editor.getJSON())
    },
  })

  watch(
    () => props.modelValue,
    (value) => {
      // HTML
      const isSame = editor.value?.getHTML() === value

      // JSON
      // const isSame = JSON.stringify(editor.value?.getJSON()) === JSON.stringify(value)

      if (isSame) {
        return
      }

      editor.value?.commands.setContent(value, false)
    }
  )
</script>
```
