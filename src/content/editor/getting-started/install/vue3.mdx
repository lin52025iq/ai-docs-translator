本分步指南将介绍如何将 Tiptap 集成到 Vue 3 项目中。你也可以查看我们的 [Vue 文本编辑器示例](/examples/basics/default-text-editor)。

### 环境要求

- 在你的计算机上安装 [Node](https://nodejs.org/en/download/)
- 在你的计算机上安装 [Vue CLI](https://cli.vuejs.org/)
- 具备 [Vue](https://v3.vuejs.org/guide/introduction.html) 使用经验

## 创建项目（可选）

如果你已经有 Vue 项目，也可以直接使用，跳过此步骤即可。

本指南将从一个名为 `my-tiptap-project` 的全新 Vue 项目开始。Vue CLI 会为我们配置所需的一切，只需选择 Vue 3 模板即可。

```bash
# create a project
vue create my-tiptap-project

# change directory
cd my-tiptap-project
```

### 安装依赖

好了，样板工作到此为止。现在终于可以安装 Tiptap 了！在接下来的示例中，你需要安装 `@tiptap/vue-3`、`@tiptap/pm`（ProseMirror 库）和 `@tiptap/starter-kit`。后者包含了最常用的扩展，能帮助你快速上手。

```bash
npm install @tiptap/vue-3 @tiptap/pm @tiptap/starter-kit
```

如果你已完成第 1 步和第 2 步，现在可以运行 `npm run dev` 启动项目，然后在你喜欢的浏览器中打开 [http://localhost:8080](http://localhost:8080)。如果你使用的是现有项目，具体操作可能会有所不同。

## 集成 Tiptap

要开始使用 Tiptap，需要在应用中添加一个新组件。我们将它命名为 `Tiptap`，并把下面的示例代码放入 `components/Tiptap.vue`。

这是在 Vue 中快速运行 Tiptap 的最简单方法。它会提供一个非常基础的 Tiptap 版本，不包含任何按钮。别担心，很快你就能为它添加更多功能。

```html
<template>
  <editor-content :editor="editor" />
</template>

<script>
  import { Editor, EditorContent } from '@tiptap/vue-3'
  import StarterKit from '@tiptap/starter-kit'

  export default {
    components: {
      EditorContent,
    },

    data() {
      return {
        editor: null,
      }
    },

    mounted() {
      this.editor = new Editor({
        content: "<p>I'm running Tiptap with Vue.js. 🎉</p>",
        extensions: [StarterKit],
      })
    },

    beforeUnmount() {
      this.editor.destroy()
    },
  }
</script>
```

你也可以使用组合式 API 和 `useEditor` 方法。

```html
<template>
  <editor-content :editor="editor" />
</template>

<script>
  import { useEditor, EditorContent } from '@tiptap/vue-3'
  import StarterKit from '@tiptap/starter-kit'

  export default {
    components: {
      EditorContent,
    },

    setup() {
      const editor = useEditor({
        content: "<p>I'm running Tiptap with Vue.js. 🎉</p>",
        extensions: [StarterKit],
      })

      return { editor }
    },
  }
</script>
```

你也可以使用新的 [`<script setup>` 语法](https://v3.vuejs.org/api/sfc-script-setup.html)。

```html
<template>
  <editor-content :editor="editor" />
</template>

<script setup>
  import { useEditor, EditorContent } from '@tiptap/vue-3'
  import StarterKit from '@tiptap/starter-kit'

  const editor = useEditor({
    content: "<p>I'm running Tiptap with Vue.js. 🎉</p>",
    extensions: [StarterKit],
  })
</script>
```

### 将组件添加到应用中

现在，将 `src/App.vue` 的内容替换为以下示例代码，以便在应用中使用新建的 `Tiptap` 组件。

```html
<template>
  <div id="app">
    <tiptap />
  </div>
</template>

<script>
  import Tiptap from './components/Tiptap.vue'

  export default {
    name: 'App',
    components: {
      Tiptap,
    },
  }
</script>
```

现在，你应该能在浏览器中看到 Tiptap 了。给自己一点掌声吧！:)
