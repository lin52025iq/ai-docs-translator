通过本分步指南，了解如何将 Tiptap 集成到 SvelteKit 项目中。也可以查看我们的 [Svelte 文本编辑器示例](/examples/basics/default-text-editor)。

## 快速开始：使用 Tiptap 的 Svelte REPL

如果你想立即开始，可以试试这个[使用 Tiptap 的 Svelte 5 REPL](https://svelte.dev/playground/69fd35ee512d40f6a412004a7bdbf549?version=5.37.0)。

### 要求

- 已在本机安装 [Node](https://nodejs.org/en/download/)
- 具备 [Svelte](https://svelte.dev/docs#getting-started) 使用经验

## 创建项目（可选）

如果你已经有 SvelteKit 项目，也可以直接使用，跳过此步骤即可。

本指南将从一个名为 `my-tiptap-project` 的全新 SvelteKit 项目开始。运行以下命令即可完成所需的设置。过程中会出现很多问题，你可以选择自己偏好的选项，也可以使用默认值。

```bash
npm create svelte@latest my-tiptap-project
cd my-tiptap-project
npm install
npm run dev
```

### 安装依赖

基础项目搭建完成后，就来安装 Tiptap 吧！以下示例需要 `@tiptap/core` 包、几个组件、`@tiptap/pm`，以及 `@tiptap/starter-kit`。后者包含了常用扩展，助你快速上手。

```bash
npm install @tiptap/core @tiptap/pm @tiptap/starter-kit @tiptap/extension-bubble-menu
```

如果你已完成步骤 1 和 2，现在可以运行 `npm run dev` 启动项目，并在常用浏览器中打开 [http://localhost:3000/](http://localhost:3000/)。如果你使用的是现有项目，实际情况可能会有所不同。

## 集成 Tiptap

要开始使用 Tiptap，你需要在应用中添加一个新组件。我们将它命名为 `Tiptap`，并把以下示例代码添加到 `src/lib/Tiptap.svelte` 中。

这是在 SvelteKit 中快速运行 Tiptap 的最简方式。你将获得一个不带任何按钮的基础版 Tiptap。别担心，稍后你还可以添加更多功能。

```svelte
<script>
  import { onMount, onDestroy } from 'svelte'
  import { Editor } from '@tiptap/core'
  import { StarterKit } from '@tiptap/starter-kit'
  import BubbleMenu from '@tiptap/extension-bubble-menu'

  let bubbleMenu = $state()
  let element = $state()
  let editorState = $state({editor: null})

  onMount(() => {
    editorState.editor = new Editor({
      element: element,
      extensions: [
        StarterKit,
        BubbleMenu.configure({
          element: bubbleMenu,
        }),
      ],
      content: `
        <h1>Hello Svelte! 🌍️ </h1>
        <p>This editor is running in Svelte.</p>
        <p>Select some text to see the bubble menu popping up.</p>
      `,
      onTransaction: ({ editor }) => {
        // Update the state signal to force a re-render
        editorState = { editor }
      },
    })
  })
  onDestroy(() => {
    editorState.editor?.destroy()
  })
</script>

<div style="position: relative" class="app">
  {#if editorState.editor}
    <div class="fixed-menu">
      <button
        onclick={() => editorState.editor.chain().focus().toggleHeading({ level: 1 }).run()}
        class:active={editorState.editor.isActive('heading', { level: 1 })}
      >
        H1
      </button>
      <button
        onclick={() => editorState.editor.chain().focus().toggleHeading({ level: 2 }).run()}
        class:active={editorState.editor.isActive('heading', { level: 2 })}
      >
        H2
      </button>
      <button onclick={() => editorState.editor.chain().focus().setParagraph().run()} class:active={editorState.editor.isActive('paragraph')}>
        P
      </button>
    </div>
  {/if}

  <div bind:this={element}></div>
</div>

<style>
  button.active {
    background: black;
    color: white;
  }
</style>

```

## 将其添加到应用中

现在，将 `src/routes/+page.svelte` 中的内容替换为以下示例代码，在应用中使用新的 `Tiptap` 组件。

```svelte
<script>
  import Tiptap from '$lib/Tiptap.svelte'
</script>

<main>
  <Tiptap />
</main>
```

现在，你应该能在浏览器中看到 Tiptap 了。是时候给自己一点掌声了！:)

## 使用 Svelte 旧版语法进行设置

上面的示例使用了 [Svelte runes 语法](https://svelte.dev/docs/svelte/what-are-runes)。如果你的 Svelte 应用处于[旧版模式](https://svelte.dev/docs/svelte/legacy-let)，请改用以下代码作为 `Tiptap.svelte` 组件。

```svelte
<script>
  import { onMount } from 'svelte';
  import { Editor } from '@tiptap/core';
  import StarterKit from '@tiptap/starter-kit';

  let element;
  let editor;

  onMount(() => {
    editor = new Editor({
      element: element,
      extensions: [StarterKit],
      content: '<p>Hello World! 🌍️ </p>',
      onTransaction: () => {
        // force re-render so `editor.isActive` works as expected
        editor = editor;
      },
    });

    return () => {
      if (editor) {
        editor.destroy();
      }
    }
  });
</script>

{#if editor}
  <button
    on:click={() => editor.chain().focus().toggleHeading({ level: 1 }).run()}
    class:active={editor.isActive('heading', { level: 1 })}
  >
    H1
  </button>
  <button
    on:click={() => editor.chain().focus().toggleHeading({ level: 2 }).run()}
    class:active={editor.isActive('heading', { level: 2 })}
  >
    H2
  </button>
  <button
    on:click={() => editor.chain().focus().setParagraph().run()}
    class:active={editor.isActive('paragraph')}
  >
    P
  </button>
{/if}

<div bind:this={element} />

<style>
  button.active {
    background: black;
    color: white;
  }
</style>
```
