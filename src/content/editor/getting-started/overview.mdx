构建一款契合产品、具备所需功能的富文本编辑器。Tiptap 将久经验证的 ProseMirror 库封装在现代化、与框架无关的 API 中，并提供丰富的扩展和功能。

## 什么是 Tiptap？

Tiptap 是一个无头富文本编辑器框架，可让你构建完全满足自己和客户需求的自定义编辑器。
它基于 ProseMirror 构建，后者是一个经过充分实战检验的 Web 富文本编辑器开发库。
在底层，Tiptap 大量依赖[事件](/editor/api/events)、[命令](/editor/api/commands)
和[扩展](/editor/extensions/overview)，为编辑器开发提供灵活而强大的 API。

## 为什么选择 Tiptap？

- **默认采用模块化设计：** 只添加所需的扩展，从粗体和链接到复杂的表格和斜杠菜单。让打包体积保持精简，并掌控文档 Schema。
- **无头优先：** 将 Tiptap 接入 React、Vue、Svelte、原生 JS 或其他任何框架。也可以搭配 React 使用 [UI 组件和模板](/ui-components/getting-started/overview)。
- **开源与 Pro 扩展：** Tiptap 的开源代码以 MIT 许可证发布在 GitHub 上。需要评论或 AI 命令等高级功能时，可添加付费的 Tiptap 扩展。

想开始使用 Tiptap？请按照[安装指南](/editor/getting-started/install)设置你的第一个 Tiptap 编辑器。

### 扩展编辑器

通过开源扩展或 Pro 扩展来扩展 Tiptap 编辑器。Tiptap 套件提供更强大的功能，并可通过 [Tiptap Cloud 控制面板](https://cloud.tiptap.dev/v2/billing)免费试用 30 天。

- 从 [`StarterKit`](/editor/extensions/functionality/starterkit) 开始——它内置了一组核心标记和节点。
- 添加[功能扩展](/editor/extensions/functionality)——例如字符计数器、占位符和历史记录。
- 添加[内容扩展](/editor/extensions/overview)——例如图片、表格、图表和自定义节点。
- 按照[自定义扩展指南](/editor/extensions/custom-extensions)创建自己的扩展。
