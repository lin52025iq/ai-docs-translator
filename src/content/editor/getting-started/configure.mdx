配置 Tiptap 时，需要指定三个关键元素：
- 编辑器的渲染位置（`element`）
  - **注意**：如果使用 React 或 Vue 集成，则无需指定此项。
- 要启用的功能（`extensions`）
- 初始文档的内容（`content`）

虽然这种设置适用于大多数情况，但你也可以配置其他选项。

## 添加配置

要配置编辑器，请将[包含设置的对象](/editor/api/editor)传递给 `Editor` 类，如下所示：

```js
import { Editor } from '@tiptap/core'
import Document from '@tiptap/extension-document'
import Paragraph from '@tiptap/extension-paragraph'
import Text from '@tiptap/extension-text'

new Editor({
  // 将 Tiptap 绑定到 `.element`
  element: document.querySelector('.element'),
  // 注册扩展
  extensions: [Document, Paragraph, Text],
  // 设置初始内容
  content: '<p>Example Text</p>',
  // 初始化后将光标置于编辑器中
  autofocus: true,
  // 使文本可编辑（默认为 true）
  editable: true,
  // 阻止加载 Tiptap 自带的默认 ProseMirror CSS
  // 大多数情况下应保持为 `true`，因为其中包含
  // Tiptap 正常运行所需的样式
  injectCSS: false,
})
```

## 节点、标记和扩展

大多数编辑功能都封装为[节点](/editor/extensions/nodes)、[标记](/editor/extensions/marks)或[功能](/editor/extensions/functionality)。导入所需内容，并将它们作为数组传递给编辑器。

下面是仅包含三个扩展的最简配置：

```js
import { Editor } from '@tiptap/core'
import Document from '@tiptap/extension-document'
import Paragraph from '@tiptap/extension-paragraph'
import Text from '@tiptap/extension-text'

new Editor({
  element: document.querySelector('.element'),
  extensions: [Document, Paragraph, Text],
})
```

### 配置扩展

许多扩展都可以使用 `.configure()` 方法进行配置。你可以传入一个包含特定设置的对象。

例如，要将标题级别限制为 1、2 和 3，可以按如下方式配置 [`Heading`](/editor/extensions/nodes/heading) 扩展：

```js
import { Editor } from '@tiptap/core'
import Document from '@tiptap/extension-document'
import Paragraph from '@tiptap/extension-paragraph'
import Text from '@tiptap/extension-text'
import Heading from '@tiptap/extension-heading'

new Editor({
  element: document.querySelector('.element'),
  extensions: [
    Document,
    Paragraph,
    Text,
    Heading.configure({
      levels: [1, 2, 3],
    }),
  ],
})
```

可用设置请参阅扩展的文档。

### 包含常用扩展的套件

我们将一些最常用的扩展打包到了 [`StarterKit`](/editor/extensions/functionality/starterkit) 中。使用方法如下：

```js
import StarterKit from '@tiptap/starter-kit'

new Editor({
  extensions: [StarterKit],
})
```

传入一个对象，即可配置 [StarterKit](/editor/extensions/functionality/starterkit) 中包含的所有扩展。若要配置特定扩展，请在其配置项前加上扩展名称。例如，要将标题级别限制为 1、2 和 3：

```js
import StarterKit from '@tiptap/starter-kit'

new Editor({
  extensions: [
    StarterKit.configure({
      heading: {
        levels: [1, 2, 3],
      },
    }),
  ],
})
```

### 禁用 StarterKit 中的特定扩展

若要从 [StarterKit](/editor/extensions/functionality/starterkit) 中排除某些扩展，可以在配置中将它们设为 `false`。例如，要禁用 [`撤销/重做历史记录`](/editor/extensions/functionality/undo-redo)扩展：

```js
import StarterKit from '@tiptap/starter-kit'

new Editor({
  extensions: [
    StarterKit.configure({
      undoRedo: false,
    }),
  ],
})
```

使用自带历史记录扩展的 Tiptap [`协作`](/editor/extensions/functionality/collaboration)功能时，必须禁用 [StarterKit](/editor/extensions/functionality/starterkit) 中包含的`撤销/重做历史记录`扩展，以避免冲突。

### 其他扩展

[StarterKit](/editor/extensions/functionality/starterkit) 并未包含所有可用扩展。若要为编辑器添加更多功能，请将相应扩展列入 `extensions` 数组。例如，要添加 [`Strike`](/editor/extensions/marks/strike) 扩展：

```js
import StarterKit from '@tiptap/starter-kit'
import Strike from '@tiptap/extension-strike'

new Editor({
  extensions: [StarterKit, Strike],
})
```
