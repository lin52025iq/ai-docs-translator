## 结构

ProseMirror 使用严格的[模式](/editor/core-concepts/schema)来定义文档允许采用的结构。文档是一棵由标题、段落和其他元素组成的树，这些元素称为节点。标记可以附加到节点上，例如用于强调节点中的部分内容。[命令](/editor/api/commands)可以通过编程方式更改文档。

## 状态

文档存储在一个状态中。更改以事务的形式应用到状态。状态包含当前内容、光标位置和选区等信息。你可以监听[事件](/editor/api/events)，例如在事务应用之前对其进行修改。

## 内容

文档在内部存储为一个 [ProseMirror 节点](https://prosemirror.net/docs/ref/#model.Node)，并可通过调用 `editor.getJSON()` 获取为 Tiptap JSON 对象。

Tiptap JSON 是存储和处理文档的推荐格式。以下是一个 Tiptap JSON 文档示例：

```json
{
  "type": "doc",
  "content": [
    {
      "type": "paragraph",
      "attrs": {
        "textAlign": "center"
      },
      "content": [
        { "type": "text", "text": "Hello, " },
        {
          "type": "text",
          "text": "world",
          "marks": [{ "type": "bold" }, { "type": "italic" }]
        },
        { "type": "text", "text": "!" }
      ]
    }
  ]
}
```

Tiptap JSON 文档是一棵节点树。有些节点可以包含子节点，但只有文本节点（即 `type: 'text'` 的节点）可以包含文本。文本节点和其他内联节点可以应用标记。有些节点和标记可以带有属性。

有效 Tiptap JSON 内容的 JSON Schema 位于 [`/assets/schemas/tiptap-json-schema.json`](/assets/schemas/tiptap-json-schema.json)。你可以使用它在存储或处理 Tiptap JSON 之前对其进行验证。

## 扩展

扩展可以为编辑器添加[节点](/editor/extensions/nodes)、[标记](/editor/extensions/marks)和/或[功能](/editor/extensions/functionality)。其中许多扩展会将命令绑定到常用的[键盘快捷键](/editor/core-concepts/keyboard-shortcuts)。

## 术语

ProseMirror 有自己的一套术语，你时不时会遇到这些词。下面简要介绍了文档中最常用的一些词语。

| 术语 | 描述 |
| --- | --- |
| 模式（Schema） | 配置内容可以采用的结构。 |
| 文档（Document） | 编辑器中的实际内容。 |
| 状态（State） | 用于描述编辑器当前内容和选区的所有信息。 |
| 事务（Transaction） | 对状态的更改（例如更新选区或内容）。 |
| 扩展（Extension） | 注册新功能。 |
| 节点（Node） | 一种内容类型，例如标题或段落。 |
| 标记（Mark） | 可应用于节点，例如用于内联格式设置。 |
| 命令（Command） | 在编辑器中执行某项操作，从而以某种方式更改状态。 |
| 装饰（Decoration） | 应用于文档的样式，例如用于突出显示错误。 |
