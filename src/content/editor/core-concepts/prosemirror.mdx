Tiptap 构建于 ProseMirror 之上，后者提供了相当强大的 API。为便于访问该 API，我们提供了 `@tiptap/pm` 软件包。此软件包包含所有重要的 ProseMirror 软件包，例如 `prosemirror-state`、`prosemirror-view` 和 `prosemirror-model`。

在自定义开发中使用此软件包，可以确保你始终使用与 Tiptap 相同版本的 ProseMirror。这样，我们就能确保 Tiptap 与所有扩展彼此兼容，并避免版本冲突。

此外，你无需手动安装所有 ProseMirror 软件包，尤其是在使用不支持自动解析对等依赖的 npm 或其他软件包管理器时。

## 安装

```bash
npm i @tiptap/pm
```

安装后，你可以像这样访问所有内部 ProseMirror 软件包：

```js
// 此示例从 ProseMirror state 软件包中加载 EditorState 类
import { EditorState } from '@tiptap/pm/state'
```

## 集成软件包

以下软件包可供使用：

- `@tiptap/pm/changeset`
- `@tiptap/pm/commands`
- `@tiptap/pm/dropcursor`
- `@tiptap/pm/gapcursor`
- `@tiptap/pm/history`
- `@tiptap/pm/inputrules`
- `@tiptap/pm/keymap`
- `@tiptap/pm/model`
- `@tiptap/pm/schema-list`
- `@tiptap/pm/state`
- `@tiptap/pm/tables`
- `@tiptap/pm/transform`
- `@tiptap/pm/view`

如果你需要其他未由 `@tiptap/pm` 重新导出的 ProseMirror 软件包（例如 `prosemirror-collab`、`prosemirror-markdown`、`prosemirror-menu`、`prosemirror-schema-basic` 或 `prosemirror-trailing-node`），请直接从 npm 安装。

你可以在 [ProseMirror 文档](https://prosemirror.net/docs/ref)中了解这些库的更多信息。
