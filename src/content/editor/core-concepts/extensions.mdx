扩展可以为 Tiptap 添加新能力或修改编辑器的行为，从而增强 Tiptap。无论是添加新的内容类型、自定义编辑器外观，还是扩展其功能，扩展都是 Tiptap 的构建模块。

若要向编辑器添加新的内容类型，可以使用能够在编辑器中渲染内容的[节点](/editor/api/nodes)和[标记](/editor/extensions/marks)。

可选的 `@tiptap/starter-kit` 包含最常用的扩展，可简化设置。了解更多关于 [`StarterKit`](/editor/extensions/functionality/starterkit) 的信息。

使用 Tiptap 社区创建的扩展来扩展编辑器的功能。在 [Awesome Tiptap 资源库](https://github.com/ueberdosis/awesome-tiptap#community-extensions)中探索各种自定义功能和工具。如需围绕社区扩展进行协作和寻求支持，请到 [讨论帖](https://github.com/ueberdosis/tiptap/discussions/2973)与其他开发者交流。

## 主要功能

扩展的用途远不止添加新的内容类型。你可以：
- **为节点和标记添加属性**，以存储其他数据
- **应用全局属性**，一次应用于多个扩展（适用于文本对齐、行高和其他属性）
- **添加命令**，以执行自定义编辑器行为
- **监听事件**，例如焦点、失焦、更新等
- **添加键盘快捷键**，以便快速使用各项功能
- **添加[装饰](/editor/core-concepts/decorations)**，在不更改文档的情况下渲染仅供视图显示的高亮、注释和组件

## 什么是扩展？

尽管 Tiptap 尝试隐藏 ProseMirror 的大部分复杂性，但它是基于 ProseMirror 的 API 构建的。对于高级用法，我们建议你阅读 [ProseMirror 指南](https://ProseMirror.net/docs/guide/)。这样你会更好地了解其底层工作原理，也会更加熟悉 Tiptap 使用的许多术语和行话。

现有的[节点](/editor/extensions/nodes)、[标记](/editor/extensions/marks)和[功能](/editor/extensions/functionality)可以帮助你了解如何着手编写自己的扩展。为了方便你在文档和源代码之间切换，每个扩展文档页面都链接到了 GitHub 上对应的文件。

我们建议先从自定义现有扩展入手，积累经验后再创建自己的扩展。因此，下面的所有示例都会扩展现有扩展，不过这些示例同样适用于新创建的扩展。

## 创建新扩展

你可以自由地为 Tiptap 创建自己的扩展。以下是创建并注册扩展所需的样板代码：

```js
import { Extension } from '@tiptap/core'

const CustomExtension = Extension.create({
  // Your code here
})

const editor = new Editor({
  extensions: [
    // Register your custom extension with the editor.
    CustomExtension,
    // … and don’t forget all other extensions.
    Document,
    Paragraph,
    Text,
    // …
  ],
})
```

你可以通过我们的 CLI 轻松创建一个新扩展的初始模板。

```bash
npm init tiptap-extension
```

在我们的[指南](/editor/extensions/custom-extensions)中了解有关自定义扩展的更多信息。
