如果你习惯不使用 Vue 或 React，那么使用这类框架可能会觉得过于复杂。好消息是，你可以在标记视图中使用原生 JavaScript。只需要了解一些基础知识，接下来我们会逐步介绍。

## 使用 JavaScript 渲染标记视图

要在编辑器中渲染标记视图，你需要：

1. [创建标记扩展](/editor/extensions/custom-extensions/create-new/mark)
2. 使用 `addMarkView()` 注册新的标记视图
3. 编写渲染函数
4. [配置 Tiptap 使用新的标记扩展](/editor/getting-started/configure)

你的标记扩展可以这样编写：

```ts
import { Mark } from '@tiptap/core'

export default Mark.create({
  // Other options...
  addMarkView() {
    return ({ mark, HTMLAttributes }) => {
      const dom = document.createElement('b')
      const contentDOM = document.createElement('span')

      dom.appendChild(contentDOM)

      return {
        dom,
        contentDOM,
      }
    }
  },
})
```

这个标记视图甚至可以与编辑器交互。接下来看看如何实现这一点。

## 访问标记属性

编辑器会向渲染函数传入一些有用的数据，其中之一就是 `mark` 属性。你可以通过它在标记视图中访问标记属性。假设你已为标记扩展[添加了一个名为 `color` 的属性](/editor/extensions/custom-extensions/extend-existing#attributes)，可以这样访问：

```ts
addMarkView() {
  return ({ mark }) => {
    console.log(mark.attrs.color)
  }
}
```

## 添加可编辑内容

标记会包裹编辑器中的一段文本。如果你想让标记中的内容可编辑，可以为 `contentDOM` 元素添加 `contenteditable` 属性。

```ts
addMarkView() {
  return ({ mark, HTMLAttributes }) => {
    const dom = document.createElement('b')
    const contentDOM = document.createElement('span')

    contentDOM.contentEditable = 'true'
    dom.appendChild(contentDOM)

    return {
      dom,
      contentDOM,
    }
  }
}
```

明白了吗？你可以随心所欲地实现，只要返回一个用于标记视图的容器，以及另一个用于内容的容器即可。

## 更新标记视图属性

如果你想更新标记视图的属性，可以调用 MarkView 实例上的 `updateAttributes` 方法。

```ts
markView.updateAttributes({
  id: 'new-id',
  color: 'blue',
})
```
