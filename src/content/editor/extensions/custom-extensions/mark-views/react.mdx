如果你习惯使用 React，那么使用原生 JavaScript 可能会让你觉得复杂。好消息是，你也可以在标记视图中使用常规的 React 组件。只需了解一点内容，下面我们逐一介绍。

## 渲染 React 组件

要在编辑器中渲染 React 组件，请按以下步骤操作：

1. [创建标记扩展](/editor/extensions/custom-extensions/create-new/mark)
2. 创建 React 组件
3. 将该组件传递给提供的 `ReactNodeViewRenderer`
4. 使用 `addMarkView()` 注册组件
5. [配置 Tiptap 以使用新的节点扩展](/editor/getting-started/configure)

节点扩展可以这样编写：

```ts
import { Mark } from '@tiptap/core'
import { ReactMarkViewRenderer } from '@tiptap/react'

import Component from './Component.jsx'

export default Mark.create({
  // options…

  addMarkView() {
    return ReactMarkViewRenderer(Component)
  },
})
```

下面是一个 React 组件示例：

```tsx
import { MarkViewContent, MarkViewRendererProps } from '@tiptap/react'
import React from 'react'

export default (props: MarkViewRendererProps) => {
  const [count, setCount] = React.useState(0)

  return (
    <span className="content" data-test-id="mark-view">
      <MarkViewContent />
      <label contentEditable={false}>
        React 组件：
        <button
          onClick={() => {
            setCount(count + 1)
          }}
        >
          此按钮已被点击 {count} 次。
        </button>
      </label>
    </span>
  )
}
```

## 更新标记视图属性

更新标记视图的属性非常简单。你可以使用 `MarkViewRendererProps` 提供的 `updateAttributes` 方法来更新标记视图的属性。

```tsx
import { MarkViewContent, MarkViewRendererProps } from '@tiptap/react'
import React from 'react'

export default (props: MarkViewRendererProps) => {
  return (
    <span id={props.HTMLAttributes.id}>
      <MarkViewContent />
      <button onClick={() => props.updateAttributes({ id: Date.now() })}>更新 ID</button>
    </span>
  )
}
```
