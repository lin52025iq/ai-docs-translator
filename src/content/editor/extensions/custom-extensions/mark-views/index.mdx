[节点视图](/editor/extensions/custom-extensions/node-views)用于渲染节点，而标记视图用于渲染标记。标记视图稍微简单一些，因为它们无需处理节点的复杂性，而且 API 也更简单。

标记视图可以显著改善编辑器内的体验，也可以用于 Tiptap 的只读实例。按照设计，它们与 HTML 输出无关，因此你可以完全掌控编辑器内的体验_以及_输出。

### 渲染 JavaScript/Vue/React

但如果你想渲染实际的 JavaScript/Vue/React 代码，该怎么办？请使用[静态渲染器](/editor/api/utilities/static-renderer)。借助此工具，无需创建 Editor 实例，即可将内容渲染为 HTML、Markdown 或 React 组件。
