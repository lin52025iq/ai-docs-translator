你可以从头开始构建自己的扩展，而且你知道吗？它使用的语法与上文介绍的扩展现有扩展的语法相同。

### 创建扩展

扩展为 Tiptap 添加新功能。你会经常看到“扩展”这个词，甚至在介绍节点和标记时也会看到。但这里说的是狭义上的扩展。它们不能像标记和节点那样扩展 schema，但可以为编辑器添加功能或改变其行为。

[`TextAlign`](/editor/extensions/functionality/textalign) 是一个很好的学习示例。

```js
import { Extension } from '@tiptap/core'

const CustomExtension = Extension.create({
  name: 'customExtension',

  // Your code goes here.
})
```

你也可以使用回调函数来创建扩展。如果你想封装扩展的逻辑，例如定义事件处理程序或其他自定义逻辑，这种方式会很有用。

```js
import { Extension } from '@tiptap/core'

const CustomExtension = Extension.create(() => {
  // Define variables or functions to use inside your extension
  const customVariable = 'foo'

  function onCreate() {}
  function onUpdate() {}

  return {
    name: 'customExtension',
    onCreate,
    onUpdate,

    // Your code goes here.
  }
})
```

详细了解 [Extension API](/editor/extensions/custom-extensions/create-new/extension)。

### 创建节点

如果把文档看作一棵树，那么[节点](/editor/extensions/nodes)就是树中的一种内容。值得参考的示例包括 [`Paragraph`](/editor/extensions/nodes/paragraph)、[`Heading`](/editor/extensions/nodes/heading) 和 [`CodeBlock`](/editor/extensions/nodes/code-block)。

```js
import { Node } from '@tiptap/core'

const CustomNode = Node.create({
  name: 'customNode',

  // Your code goes here.
})
```

你也可以使用回调函数来创建节点。如果你想封装扩展的逻辑，例如定义事件处理程序或其他自定义逻辑，这种方式会很有用。

```js
import { Node } from '@tiptap/core'

const CustomNode = Node.create(() => {
  // Define variables or functions to use inside your extension
  const customVariable = 'foo'

  function onCreate() {}
  function onUpdate() {}

  return {
    name: 'customNode',
    onCreate,
    onUpdate,

    // Your code goes here.
  }
})
```

节点不一定是块级内容。它们也可以与文本一起以内联形式呈现，例如 [@mentions](/editor/extensions/nodes/mention)。

详细了解 [Node API](/editor/extensions/custom-extensions/create-new/node)。

### 创建标记

可以为[节点](/editor/extensions/nodes)应用一个或多个标记，例如添加行内格式。值得参考的示例包括 [`Bold`](/editor/extensions/marks/bold)、[`Italic`](/editor/extensions/marks/italic) 和 [`Highlight`](/editor/extensions/marks/highlight)。

```js
import { Mark } from '@tiptap/core'
```

## 发布独立扩展

如果你想为 Tiptap 创建并发布自己的扩展，可以使用我们的 CLI 工具来搭建项目。
只需运行 `npm init tiptap-extension` 并按照说明操作即可。CLI 会创建一个新文件夹，其中包含预配置的项目，以及使用 Rollup 运行的构建脚本。

如果想在本地测试扩展，可以在项目文件夹中运行 `npm link`，然后在你的项目中（例如 Vite 应用）运行 `npm link YOUR_EXTENSION`。
