Tiptap 的强大之处在于灵活性。你可以从头创建自己的扩展，打造符合需求的独特编辑器体验。

## 创建节点

节点是编辑器的构成模块。它们可以是块级节点，也可以是行内节点。可以参考 [`Paragraph`](/editor/extensions/nodes/paragraph)、[`Heading`](/editor/extensions/nodes/heading) 或 [`CodeBlock`](/editor/extensions/nodes/code-block) 来了解节点。

节点继承了 [Extension API](/editor/extensions/custom-extensions/create-new/extension) 中的所有选项和方法，并额外提供了一些节点专用的选项和方法。

下面添加一个简单的节点扩展，看看它是如何工作的。

```typescript
import { Node } from '@tiptap/core'

const CustomNode = Node.create({
  name: 'customNode',

  addOptions() {
    return {
      HTMLAttributes: {},
    }
  },

  parseHTML() {
    return [
      {
        tag: 'div',
      },
    ]
  },

  renderHTML({ HTMLAttributes }) {
    return ['div', HTMLAttributes, 0]
  },
})
```

你也可以使用回调函数创建节点。如果想封装扩展的逻辑，这种方式会很有用，例如定义事件处理程序或其他自定义逻辑。

```js
import { Node } from '@tiptap/core'

const CustomNode = Node.create(() => {
  // here you could define variables or function that you can use on your schema definition
  const customVariable = 'foo'

  function onCreate() {}
  function onUpdate() {}

  return {
    name: 'customNode',
    onCreate,
    onUpdate,

    // Your code goes here.
  }
})
```

这段代码创建了一个名为 `CustomNode` 的新节点扩展。它添加了 `addOptions` 方法，用于定义节点选项，用户可以对这些选项进行配置。它还添加了 `parseHTML` 和 `renderHTML` 方法，用于定义如何将节点解析为 HTML，以及如何将节点渲染为 HTML。

与其他扩展一样，只需将它添加到 `extensions` 数组中即可安装到编辑器。

```typescript
import { Editor } from '@tiptap/core'

new Editor({
  extensions: [CustomNode],
})

// Or if using React or Vue

const editor = useEditor({
  extensions: [CustomNode],
})
```

现在来详细了解节点可用的选项和方法。

## 节点选项

创建节点时，你可以定义供用户配置的选项。这些选项可用于自定义节点的行为或外观。

### `parseHTML`

`parseHTML` 方法用于定义如何从 HTML 中解析标记。它应返回一个数组，其中的对象表示标记的属性。

它对应 [ProseMirror schema](https://prosemirror.net/docs/ref/#model.MarkSpec.parseDOM) 中的 `parseDOM` 属性。

```typescript
const CustomMark = Mark.create({
  name: 'customMark',

  parseHTML() {
    return [
      {
        tag: 'span',
        getAttrs: (node) => {
          return {
            class: node.getAttribute('class'),
          }
        },
      },
    ]
  },
})
```

粘贴内容时，会使用此方法将 HTML 内容解析为标记。

### `renderHTML`

`renderHTML` 方法用于定义如何将标记渲染为 HTML。它应返回一个数组，表示标记对应的 HTML。

它对应 [ProseMirror schema](https://prosemirror.net/docs/ref/#model.MarkSpec.toDOM) 中的 `toDOM` 属性。

```typescript
const CustomMark = Mark.create({
  name: 'customMark',

  renderHTML({ HTMLAttributes }) {
    return ['span', HTMLAttributes, 0]
  },
})
```

复制内容时，会使用此方法将标记渲染为 HTML。更多详情请参阅[扩展现有扩展](/editor/extensions/custom-extensions/extend-existing#render-html)指南。

### `addAttributes`

`addAttributes` 方法用于定义标记的自定义属性。它应返回一个对象，其中包含属性名称及其默认值。

它对应 [ProseMirror schema](https://prosemirror.net/docs/ref/#model.MarkSpec.attrs) 中的 `attrs` 属性。

```typescript
const CustomMark = Mark.create({
  name: 'customMark',

  addAttributes() {
    return {
      customAttribute: {
        default: 'value',
        parseHTML: (element) => element.getAttribute('data-custom-attribute'),
      },
    }
  },
})
```

更多详情请参阅[扩展现有扩展](/editor/extensions/custom-extensions/extend-existing#attributes)指南。

### `topNode`

定义此节点是否应为顶层节点（doc）。

它对应 [ProseMirror schema](https://prosemirror.net/docs/ref/#model.NodeSpec.topNode) 中的 `topNode` 属性。

```typescript
const CustomNode = Node.create({
  name: 'customNode',

  topNode: true,
})
```

### `content`

此节点的内容表达式，详见[架构指南](/guides/invalid-schema#a-note-on-content-types)。如果未指定，节点将不允许包含任何内容。

更多信息请参阅 ProseMirror 文档[此处](https://prosemirror.net/docs/guide/#schema.content_expressions)。

```typescript
const CustomNode = Node.create({
  name: 'customNode',

  content: 'block+',
})
```

### `marks`

此节点内部允许使用的标记。可以是以空格分隔的标记名称或组名称字符串；`"_"` 表示明确允许所有标记，`""` 表示不允许任何标记。如果未指定，包含行内内容的节点默认允许所有标记，其他节点默认不允许标记。

它对应 [ProseMirror schema](https://prosemirror.net/docs/ref/#model.NodeSpec.marks) 中的 `marks` 属性。

```typescript
const CustomNode = Node.create({
  name: 'customNode',

  marks: 'strong em',
})
```

### `group`

此节点所属的组或以空格分隔的多个组，可在 schema 的内容表达式中引用。

默认情况下，Tiptap 使用 `block` 和 `inline` 作为节点组。你也可以使用自定义组，将特定节点归为一组，并在 schema 中进行处理。

它对应 [ProseMirror schema](https://prosemirror.net/docs/ref/#model.NodeSpec.group) 中的 `group` 属性。

```typescript
const CustomNode = Node.create({
  name: 'customNode',

  group: 'block',
})
```

### `inline`

行内节点应将此项设为 `true`。（文本节点会隐式设为 `true`。）

它对应 [ProseMirror schema](https://prosemirror.net/docs/ref/#model.NodeSpec.inline) 中的 `inline` 属性。

```typescript
const CustomNode = Node.create({
  name: 'customNode',

  inline: true,
})
```

### `atom`

可以设为 `true`，表示该节点虽然不是[叶节点](https://prosemirror.net/docs/ref/#model.NodeType.isLeaf)，但没有可直接编辑的内容，并且在视图中应作为一个整体处理。

它对应 [ProseMirror schema](https://prosemirror.net/docs/ref/#model.NodeSpec.atom) 中的 `atom` 属性。

```typescript
const CustomNode = Node.create({
  name: 'customNode',

  atom: true,
})
```

### `selectable`

控制此类型的节点是否可以作为[节点选区](https://prosemirror.net/docs/ref/#state.NodeSelection)选中。非文本节点默认为 `true`。

它对应 [ProseMirror schema](https://prosemirror.net/docs/ref/#model.NodeSpec.selectable) 中的 `selectable` 属性。

```typescript
const CustomNode = Node.create({
  name: 'customNode',

  selectable: false,
})
```

### `draggable`

决定此类型的节点是否可以在未选中的情况下拖动。默认值为 `false`。

它对应 [ProseMirror schema](https://prosemirror.net/docs/ref/#model.NodeSpec.draggable) 中的 `draggable` 属性。

```typescript
const CustomNode = Node.create({
  name: 'customNode',

  draggable: true,
})
```

### `code`

可用于指示此节点包含代码，这会使某些命令的行为有所不同。

它对应 [ProseMirror schema](https://prosemirror.net/docs/ref/#model.NodeSpec.code) 中的 `code` 属性。

```typescript
const CustomNode = Node.create({
  name: 'customNode',

  code: true,
})
```

### `whitespace`

控制解析此节点中空白字符的方式。默认值为 `"normal"`：在普通模式下，[DOM 解析器](https://prosemirror.net/docs/ref/#model.DOMParser)会折叠空白字符；在其他模式下，则会对空白字符进行规范化（例如将换行符替换为空格）。设为 `"pre"` 时，解析器会保留节点中的空格。如果未指定此选项，但 [`code`](https://prosemirror.net/docs/ref/#model.NodeSpec.code) 为 `true`，则 `whitespace` 默认值为 `"pre"`。

它对应 [ProseMirror schema](https://prosemirror.net/docs/ref/#model.NodeSpec.whitespace) 中的 `whitespace` 属性。

```typescript
const CustomNode = Node.create({
  name: 'customNode',

  whitespace: 'pre',
})
```

### `linebreakReplacement`

允许将**单个**节点设为换行符的等效节点（例如 `hardBreak`）。在 `whitespace` 设为 `"pre"` 且不支持换行节点（例如 `codeBlock`）的块类型与支持换行节点（例如段落）的其他块类型之间转换时，会使用此节点表示换行，而不是移除换行符。

它对应 [ProseMirror schema](https://prosemirror.net/docs/ref/#model.NodeSpec.linebreakReplacement) 中的 `linebreakReplacement` 属性。

```typescript
const CustomNode = Node.create({
  name: 'customNode',

  linebreakReplacement: true,
})
```

### `defining`

启用后，同时启用 [`definingAsContext`](https://prosemirror.net/docs/ref/#model.NodeSpec.definingAsContext) 和 [`definingForContent`](https://prosemirror.net/docs/ref/#model.NodeSpec.definingForContent)。

它对应 [ProseMirror schema](https://prosemirror.net/docs/ref/#model.NodeSpec.defining) 中的 `defining` 属性。

```typescript
const CustomNode = Node.create({
  name: 'customNode',

  defining: true,
})
```

### `isolating`

启用后（默认值为 `false`），此类型节点的两侧会被视为边界，常规编辑操作（如退格删除或提升节点）不会越过这些边界。表格单元格就是一种可能适合启用此选项的节点。

它对应 [ProseMirror schema](https://prosemirror.net/docs/ref/#model.NodeSpec.isolating) 中的 `isolating` 属性。

```typescript
const CustomNode = Node.create({
  name: 'customNode',

  isolating: true,
})
```

### `addNodeView`（高级）

对于需要在节点内部执行 JavaScript 的高级用例，例如在图像周围渲染复杂界面，你需要了解节点视图。

节点视图功能强大，但也比较复杂。简而言之，你需要返回一个父 DOM 元素，以及一个用于渲染内容的 DOM 元素。请看下面这个简化示例：

```js
import Image from '@tiptap/extension-image'

const CustomImage = Image.extend({
  addNodeView() {
    return () => {
      const container = document.createElement('div')

      container.addEventListener('click', (event) => {
        alert('clicked on the container')
      })

      const content = document.createElement('div')
      container.append(content)

      return {
        dom: container,
        contentDOM: content,
      }
    }
  },
})
```

关于节点视图还有很多内容需要学习。更多信息请参阅指南中[节点视图专属章节](/editor/extensions/custom-extensions/node-views)。如需查看实际示例，可以参考 [`TaskItem`](/editor/extensions/nodes/task-item) 节点的源代码。该节点使用节点视图来渲染复选框。

### `addDecorations`

节点继承了 [Extension API](/editor/extensions/custom-extensions/create-new/extension#adddecorations) 中的 `addDecorations` 钩子。可使用它添加**仅用于视图**的[装饰](/editor/core-concepts/decorations)，例如高亮、搜索结果、注释和轻量级小组件。这些内容会在编辑器中渲染，但不会修改或序列化文档。

<Callout title="装饰与节点视图" variant="info">
  当内容属于文档的一部分时，请使用[节点视图](#addnodeview-advanced)。当标记仅用于视觉呈现且位于文档之外时，请使用
  [装饰](/editor/core-concepts/decorations)。
</Callout>
