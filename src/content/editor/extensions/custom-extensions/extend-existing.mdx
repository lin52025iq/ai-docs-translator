每个扩展都有一个 `extend()` 方法，它接受一个对象，其中包含你想要修改或添加的所有内容。

假设你想更改项目符号列表的键盘快捷键。首先应查看该扩展的源代码，在本例中是 [`BulletList` 节点](https://github.com/ueberdosis/tiptap/blob/main/packages/extension-list/src/bullet-list/bullet-list.ts)。下面是重写键盘快捷键的示例代码：

```js
// 1. Import the extension
import BulletList from '@tiptap/extension-bullet-list'

// 2. Overwrite the keyboard shortcuts
const CustomBulletList = BulletList.extend({
  addKeyboardShortcuts() {
    return {
      'Mod-l': () => this.editor.commands.toggleBulletList(),
    }
  },
})

// 3. Add the custom extension to your editor
new Editor({
  extensions: [
    CustomBulletList,
    // …
  ],
})
```

除了名称之外，现有扩展的各个方面都可以用同样的方式修改。下面来看看可以通过 `extend` 方法更改哪些内容。每个示例只关注一个方面，但你也可以组合这些示例，在一次 `extend()` 调用中修改多个方面。

## 名称

扩展名称会在很多地方使用，因此更改起来并不容易。如果想更改现有扩展的名称，可以复制整个扩展，并修改其中所有出现的名称。

扩展名称也是 JSON 的一部分。如果你[将内容存储为 JSON](/guides/output-json-html#option-1-json)，也需要在那里修改名称。

## 设置

扩展的所有设置都可以配置。如果你想更改默认设置，例如，为其他开发者提供一个基于 Tiptap 的库，可以这样做：

```js
import Heading from '@tiptap/extension-heading'

const CustomHeading = Heading.extend({
  addOptions() {
    return {
      ...this.parent?.(),
      levels: [1, 2, 3],
    }
  },
})
```

## 存储

你可能会希望在扩展实例中保存一些数据。这些数据是可变的。在扩展中，可以通过 `this.storage` 访问这些数据。

```js
import { Extension } from '@tiptap/core'

const CustomExtension = Extension.create({
  name: 'customExtension',

  addStorage() {
    return {
      awesomeness: 100,
    }
  },

  onUpdate() {
    this.storage.awesomeness += 1
  },
})
```

在扩展外部，可以通过 `editor.storage` 访问这些数据。请确保每个扩展都有唯一的名称。

```js
const editor = new Editor({
  extensions: [CustomExtension],
})

const awesomeness = editor.storage.customExtension.awesomeness
```

## Schema

Tiptap 使用严格的 Schema 来配置内容的结构、嵌套方式、行为等。你[可以更改现有扩展的 Schema 的各个方面](/editor/core-concepts/schema)。下面来看几个常见用例。

默认的 `Blockquote` 扩展可以包含其他节点，例如标题。如果你希望引用块中只能包含段落，可以相应地设置 `content` 属性：

```js
// Blockquotes must only include paragraphs
import Blockquote from '@tiptap/extension-blockquote'

const CustomBlockquote = Blockquote.extend({
  content: 'paragraph*',
})
```

Schema 还允许你将节点设置为可拖动，这可以通过 `draggable` 选项实现。该选项默认为 `false`，但你可以覆盖它。

```js
// Draggable paragraphs
import Paragraph from '@tiptap/extension-paragraph'

const CustomParagraph = Paragraph.extend({
  draggable: true,
})
```

这只是两个简单示例，但[底层的 ProseMirror Schema](https://prosemirror.net/docs/ref/#model.SchemaSpec) 功能非常强大。

## 属性

你可以使用属性在内容中存储额外信息。假设你想扩展默认的 `Paragraph` 节点，让它支持不同的颜色：

```js
const CustomParagraph = Paragraph.extend({
  addAttributes() {
    // Return an object with attribute configuration
    return {
      color: {
        default: 'pink',
      },
    }
  },
})

// Result:
// <p color="pink">Example Text</p>
```

这样就足以让 Tiptap 识别这个新属性，并将 `'pink'` 设为默认值。默认情况下，所有属性都会渲染为 HTML 属性，并在内容初始化时从内容中解析。

继续使用颜色示例，假设你想添加内联样式来实际改变文本颜色。使用 `renderHTML` 函数可以返回将在输出中渲染的 HTML 属性。

下面的示例根据 `color` 的值添加一个 `style` HTML 属性：

```js
const CustomParagraph = Paragraph.extend({
  addAttributes() {
    return {
      color: {
        default: null,
        // Take the attribute values
        renderHTML: (attributes) => {
          // … and return an object with HTML attributes.
          return {
            style: `color: ${attributes.color}`,
          }
        },
      },
    }
  },
})

// Result:
// <p style="color: pink">Example Text</p>
```

你还可以控制如何从 HTML 中解析属性。比如，你可能想将颜色存储在名为 `data-color` 的属性中，而不是 `color`，可以这样做：

```js
const CustomParagraph = Paragraph.extend({
  addAttributes() {
    return {
      color: {
        default: null,
        // Customize the HTML parsing (for example, to load the initial content)
        parseHTML: (element) => element.getAttribute('data-color'),
        // … and customize the HTML rendering.
        renderHTML: (attributes) => {
          return {
            'data-color': attributes.color,
            style: `color: ${attributes.color}`,
          }
        },
      },
    }
  },
})

// Result:
// <p data-color="pink" style="color: pink">Example Text</p>
```

设置 `rendered: false` 可以完全禁用属性的渲染。

### 扩展现有属性

如果想为扩展添加属性，同时保留现有属性，可以通过 `this.parent()` 访问它们。

在某些情况下，它的值可能是 `undefined`，因此请确保处理这种情况，或者使用可选链 `this.parent?.()`。

```js
const CustomTableCell = TableCell.extend({
  addAttributes() {
    return {
      ...this.parent?.(),
      myCustomAttribute: {
        // …
      },
    }
  },
})
```

## 全局属性

属性可以同时应用于多个扩展。这对文本对齐、行高、颜色、字体系列以及其他样式相关属性很有用。

查看 [`TextAlign`](/editor/extensions/functionality/textalign) 扩展的[完整源代码](https://github.com/ueberdosis/tiptap/tree/main/packages/extension-text-align)，了解更复杂的示例。下面简要介绍其工作原理：

```js
import { Extension } from '@tiptap/core'

const TextAlign = Extension.create({
  addGlobalAttributes() {
    return [
      {
        // Extend the following extensions
        types: ['heading', 'paragraph'],
        // … with those attributes
        attributes: {
          textAlign: {
            default: 'left',
            renderHTML: (attributes) => ({
              style: `text-align: ${attributes.textAlign}`,
            }),
            parseHTML: (element) => element.style.textAlign || 'left',
          },
        },
      },
    ]
  },
})
```

### 将全局属性应用于所有扩展

除了将属性应用于特定类型之外，你还可以为 `types` 属性使用简写字符串选项，以便更广泛地应用属性。这些选项提供了明确且自说明的 API。

#### 应用于所有节点和标记

使用 `types: '*'` 将属性应用于所有节点类型（不包括内置的文本节点）和所有标记类型：

```js
import { Extension } from '@tiptap/core'

const UniversalAttribute = Extension.create({
  addGlobalAttributes() {
    return [
      {
        types: '*',
        attributes: {
          customAttribute: {
            default: 'default-value',
            renderHTML: (attributes) => ({
              'data-custom': attributes.customAttribute,
            }),
            parseHTML: (element) => element.getAttribute('data-custom') || 'default-value',
          },
        },
      },
    ]
  },
})
```

#### 应用于所有节点

使用 `types: 'nodes'` 将属性应用于所有节点类型（不包括内置的文本节点）：

```js
const NodeAttribute = Extension.create({
  addGlobalAttributes() {
    return [
      {
        types: 'nodes',
        attributes: {
          nodeClass: {
            default: null,
            renderHTML: (attributes) => ({
              class: attributes.nodeClass,
            }),
            parseHTML: (element) => element.className || null,
          },
        },
      },
    ]
  },
})
```

#### 应用于所有标记

使用 `types: 'marks'` 将属性应用于所有标记类型：

```js
const MarkAttribute = Extension.create({
  addGlobalAttributes() {
    return [
      {
        types: 'marks',
        attributes: {
          emphasis: {
            default: false,
            renderHTML: (attributes) => {
              if (!attributes.emphasis) return {}
              return { style: 'font-style: italic' }
            },
            parseHTML: (element) => element.style.fontStyle === 'italic',
          },
        },
      },
    ]
  },
})
```

#### 应用于特定类型

如果需要更精细的控制，仍然可以指定一个包含特定类型名称的数组：

```js
const TextAlignAttribute = Extension.create({
  addGlobalAttributes() {
    return [
      {
        types: ['heading', 'paragraph'],
        attributes: {
          textAlign: {
            default: 'left',
            renderHTML: (attributes) => ({
              style: `text-align: ${attributes.textAlign}`,
            }),
            parseHTML: (element) => element.style.textAlign || 'left',
          },
        },
      },
    ]
  },
})
```

<Callout title="提示">
与省略 `types` 属性相比，字符串简写选项（`'*'`、`'nodes'`、`'marks'`）提供了更明确且自说明的 API。如果你希望其他开发者能立即了解全局属性的作用范围，请使用这些选项。
</Callout>

## 渲染 HTML

使用 `renderHTML` 函数可以控制扩展如何渲染为 HTML。我们会向该函数传入一个属性对象，其中包含所有局部属性、全局属性以及已配置的 CSS 类。下面是 `Bold` 扩展中的一个示例：

```js
renderHTML({ HTMLAttributes }) {
  return ['strong', HTMLAttributes, 0]
},
```

数组中的第一个值应为 HTML 标签名称。如果第二个元素是对象，则会将其视为一组属性。此后所有元素都会作为子元素渲染。

数字 `0`（表示一个占位位置）用于指明内容应插入的位置。下面来看 `CodeBlock` 扩展中使用两个嵌套标签的渲染方式：

```js
renderHTML({ HTMLAttributes }) {
  return ['pre', ['code', HTMLAttributes, 0]]
},
```

如果想添加特定属性，可以从 `@tiptap/core` 导入 `mergeAttributes` 辅助函数：

```js
import { mergeAttributes } from '@tiptap/core'

// ...

renderHTML({ HTMLAttributes }) {
  return ['a', mergeAttributes(HTMLAttributes, { rel: this.options.rel }), 0]
},
```

## 解析 HTML

`parseHTML()` 函数会尝试从 HTML 加载编辑器文档。该函数会接收作为参数传入的 HTML DOM 元素，并预期返回一个包含属性及其值的对象。下面是 [`Bold`](/editor/extensions/marks/bold) 标记的简化示例：

```js
parseHTML() {
  return [
    {
      tag: 'strong',
    },
  ]
},
```

这定义了一条规则，用于将所有 `<strong>` 标签转换为 `Bold` 标记。你还可以进行更复杂的设置，下面是该扩展的完整示例：

```js
parseHTML() {
  return [
    // <strong>
    {
      tag: 'strong',
    },
    // <b>
    {
      tag: 'b',
      getAttrs: node => node.style.fontWeight !== 'normal' && null,
    },
    // <span style="font-weight: bold"> and <span style="font-weight: 700">
    {
      style: 'font-weight',
      getAttrs: value => /^(bold(er)?|[5-9]\d{2,})$/.test(value as string) && null,
    },
  ]
},
```

该规则会检查 `<strong>` 和 `<b>` 标签，以及任何通过内联样式将 `font-weight` 设为粗体的 HTML 标签。

如你所见，可以选择传入 `getAttrs` 回调，以执行更复杂的检查，例如检查特定 HTML 属性。该回调会接收 HTML DOM 节点；但在检查 `style` 属性时，接收的是属性值。

你可能会好奇 `&& null` 的作用。[如果检查成功，ProseMirror 要求返回 `null` 或 `undefined`。](https://prosemirror.net/docs/ref/version/0.18.0.html#model.ParseRule.getAttrs)

如果要解决与其他扩展之间的冲突，可以为规则[传入 `priority`](https://prosemirror.net/docs/ref/version/0.18.0.html#model.ParseRule.priority)。例如，你创建了一个自定义扩展，用于查找带有 class 属性的段落，但同时也使用了默认的段落扩展。

### 使用 getAttrs

你可能已经注意到，示例中的 `getAttrs` 函数有两个用途：

1. 检查 HTML 属性，以确定规则是否匹配（并根据该 HTML 创建标记或节点）。如果函数返回 `false`，则表示不匹配。
2. 获取 DOM 元素，并使用 HTML 属性相应地设置标记或节点属性：

```js
parseHTML() {
  return [
    {
      tag: 'span',
      getAttrs: element => {
        // Check if the element has an attribute
        element.hasAttribute('style')
        // Get an inline style
        element.style.color
        // Get a specific attribute
        element.getAttribute('data-color')
      },
    },
  ]
},
```

你可以返回一个对象，以属性为键、解析出的值为值，从而设置标记或节点属性。不过，我们建议在 `addAttributes()` 中使用 `parseHTML`，这样代码会更简洁。

```js
addAttributes() {
  return {
    color: {
      // Set the color attribute according to the value of the `data-color` attribute
      parseHTML: element => element.getAttribute('data-color'),
    }
  }
},
```

在 [ProseMirror 参考文档](https://prosemirror.net/docs/ref/#model.ParseRule)中了解更多关于 `getAttrs` 以及其他所有 `ParseRule` 属性的信息。
