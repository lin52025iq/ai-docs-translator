如果你习惯使用 Vue，原生 JavaScript 可能会让你觉得有些复杂。好消息是，你也可以在节点视图中使用常规 Vue 组件。你只需要了解一点相关知识，下面我们逐步介绍。

## 渲染 Vue 组件

要在编辑器中渲染 Vue 组件，请按以下步骤操作：

1. [创建节点扩展](/editor/extensions/custom-extensions)
2. 创建一个 Vue 组件
3. 将该组件传递给提供的 `VueNodeViewRenderer`
4. 使用 `addNodeView()` 注册它
5. [配置 Tiptap 以使用新的节点扩展](/editor/getting-started/configure)

节点扩展可以像这样编写：

```js
import { Node } from '@tiptap/core'
import { VueNodeViewRenderer } from '@tiptap/vue-2'
import Component from './Component.vue'

export default Node.create({
  // configuration …

  addNodeView() {
    return VueNodeViewRenderer(Component)
  },
})
```

要让这一切正常工作，需要一些特殊处理。不过不用担心，我们提供了一个包装组件，方便你快速上手。别忘了将它添加到自定义 Vue 组件中，如下所示：

```html
<template>
  <node-view-wrapper> Vue Component </node-view-wrapper>
</template>
```

明白了吗？来看看它的实际效果。你可以直接复制下面的示例开始尝试。

不过，这个组件还不能与编辑器交互。现在就来连接它们。

## 访问节点属性

在节点扩展中使用的 `VueNodeViewRenderer` 会向自定义 Vue 组件传递几个非常实用的 prop。其中一个是 `node` prop。在 Vue 组件中添加以下代码，即可直接访问节点：

```js
props: {
  node: {
    type: Object,
    required: true,
  },
},
```

这样你就可以在 Vue 组件中访问节点属性了。假设你已经为节点扩展[添加了一个名为 `count` 的属性](/editor/extensions/custom-extensions/extend-existing#attributes)（就像上面的示例那样），便可以这样访问它：

```js
this.node.attrs.count
```

## 更新节点属性

借助传递给组件的 `updateAttributes` prop，你甚至可以从节点视图中更新节点属性。只需在组件中添加以下代码：

```js
props: {
  updateAttributes: {
    type: Function,
    required: true,
  },
},
```

将包含更新后属性的对象传递给该函数：

```js
this.updateAttributes({
  count: this.node.attrs.count + 1,
})
```

没错，这些内容也都是响应式的。通信过程是不是非常顺畅？

## 添加可编辑内容

还有一个名为 `NodeViewContent` 的组件，可以帮助你在节点视图中添加可编辑内容。示例如下：

```html
<template>
  <node-view-wrapper class="dom">
    <node-view-content class="content-dom" />
  </node-view-wrapper>
</template>

<script>
  import { NodeViewWrapper, NodeViewContent } from '@tiptap/vue-2'

  export default {
    components: {
      NodeViewWrapper,
      NodeViewContent,
    },
  }
</script>
```

你不必添加这些 `class` 属性，可以直接删除它们，也可以换成其他类名。试试下面的示例：

<CodeDemo path="/GuideNodeViews/VueComponentContent" />

请注意，这些内容由 Tiptap 渲染。因此，你需要指定允许的内容类型，例如在节点扩展中设置 `content: 'inline*'`（上面的示例就是这样设置的）。

`NodeViewWrapper` 和 `NodeViewContent` 组件默认会渲染为 `<div>` HTML 标签（行内节点则渲染为 `<span>`），但你可以更改标签。例如，`<node-view-content as="p">` 会渲染为段落。不过有一个限制：运行时不能更改该标签。

## 在文本选区中更新 `selected`

默认情况下，只有在通过 `NodeSelection` 选中节点本身时，`selected` prop 才会变为 `true`。这对原子节点很有效，但当光标仅仅位于包含文本内容的节点内部时，不会触发。如果你希望这种情况也能反映在 `selected` 中，请在 `VueNodeViewRenderer` 上启用 `selectedOnTextSelection` 选项：

```js
return VueNodeViewRenderer(Component, { selectedOnTextSelection: true })
```

启用此选项后，只要 `TextSelection` 完全位于节点范围内，`selected` 也会变为 `true`——例如，光标位于节点内容中的某处时。仅与节点部分重叠的选区不会被视为选中。

## 跟踪节点位置

当装饰或位置发生变化、但内容没有变化时，节点视图不会重新渲染。ProseMirror 会在 contentDOM 上原生处理装饰；调用 `getPos()` 闭包时，它始终会返回当前的位置，即使没有重新渲染也是如此。

如果组件需要在渲染输出中响应式地获取 `getPos()`（例如，拖动手柄需要显示 `pos: 42`），请启用 `trackNodeViewPosition`：

```js
return VueNodeViewRenderer(Component, { trackNodeViewPosition: true })
```

启用后，每当位置发生变化，组件都会重新渲染。请谨慎使用，因为频繁重新渲染可能影响性能。

## 所有可用的 prop

对于高级用例，我们还会向组件传递一些其他 prop。

### editor

编辑器实例。

### node

访问当前节点。

### decorations

装饰数组。

### selected

当当前节点视图处于 `NodeSelection` 中时为 `true`。启用 [`selectedOnTextSelection`](#在文本选区中更新-selected) 选项后，如果 `TextSelection` 完全位于节点内，此值也为 `true`。

### extension

访问节点扩展，例如获取其选项。

### getPos()

获取当前节点在文档中的位置。

### updateAttributes()

更新当前节点的属性。

### deleteNode()

删除当前节点。

以下是你可能会用到的所有 prop：

```html
<template>
  <node-view-wrapper />
</template>

<script>
  import { NodeViewWrapper } from '@tiptap/vue-2'

  export default {
    components: {
      NodeViewWrapper,
    },

    props: {
      // the editor instance
      editor: {
        type: Object,
      },

      // the current node
      node: {
        type: Object,
      },

      // an array of decorations
      decorations: {
        type: Array,
      },

      // `true` when there is a `NodeSelection` at the current node view, or
      // when the `selectedOnTextSelection` option is enabled and a `TextSelection`
      // is fully inside the node
      selected: {
        type: Boolean,
      },

      // access to the node extension, for example to get options
      extension: {
        type: Object,
      },

      // get the document position of the current node
      getPos: {
        type: Function,
      },

      // update attributes of the current node
      updateAttributes: {
        type: Function,
      },

      // delete the current node
      deleteNode: {
        type: Function,
      },
    },
  }
</script>
```

如果你想一次性获取所有 prop（并获得 TypeScript 支持），可以导入所有 prop：

```js
// Vue 3
import { defineComponent } from 'src/content/editor/extensions/custom-extensions/node-views/vue.mdx'
import { nodeViewProps } from '@tiptap/vue-3'
export default defineComponent({
  props: nodeViewProps,
})

// Vue 2
import Vue from 'src/content/editor/extensions/custom-extensions/node-views/vue.mdx'
import { nodeViewProps } from '@tiptap/vue-2'
export default Vue.extend({
  props: nodeViewProps,
})
```
