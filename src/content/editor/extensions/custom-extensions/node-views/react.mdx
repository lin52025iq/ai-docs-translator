如果你习惯使用 React，那么使用原生 JavaScript 可能会让你觉得复杂。好消息是，你也可以在节点视图中使用常规的 React 组件。只需要了解一些内容，我们接下来逐一介绍。

## 渲染 React 组件

要在编辑器中渲染 React 组件，需要完成以下操作：

1. [创建节点扩展](/editor/extensions/custom-extensions)
2. 创建一个 React 组件
3. 将该组件传递给提供的 `ReactNodeViewRenderer`
4. 使用 `addNodeView()` 注册它
5. [配置 Tiptap 使用你的新节点扩展](/editor/getting-started/configure)

你的节点扩展可以如下所示：

```js
import { Node } from '@tiptap/core'
import { ReactNodeViewRenderer } from '@tiptap/react'
import Component from './Component.jsx'

export default Node.create({
  // configuration …

  addNodeView() {
    return ReactNodeViewRenderer(Component)
  },
})
```

要让这一切正常工作，需要一些特别的处理。不过别担心，我们提供了一个包装组件，方便你快速上手。别忘了像下面这样将它添加到自定义 React 组件中：

```jsx
<NodeViewWrapper className="react-component">React Component</NodeViewWrapper>
```

明白了吗？我们来看看实际效果。你可以复制下面的示例开始尝试。

<CodeDemo path="/GuideNodeViews/ReactComponent?inline=false&hideSource=false" />

不过，这个组件还没有与编辑器交互。现在来接入交互功能。

## 访问节点属性

在节点扩展中使用的 `ReactNodeViewRenderer` 会向自定义 React 组件传递一些非常有用的 props。其中一个就是 `node` prop。假设你已经为节点扩展[添加了一个名为 `count` 的属性](/editor/extensions/custom-extensions/extend-existing#attributes)（就像上面的示例一样），就可以这样访问它：

```js
props.node.attrs.count
```

## 更新节点属性

借助传递给组件的 `updateAttributes` prop，你还可以在节点中更新节点属性。将包含更新后属性的对象传递给 `updateAttributes` prop：

```js
export default (props) => {
  const increase = () => {
    props.updateAttributes({
      count: props.node.attrs.count + 1,
    })
  }

  // …
}
```

没错，这些操作也都是响应式的。通信过程非常流畅，对吧？

## 添加可编辑内容

还有一个名为 `NodeViewContent` 的组件，可以帮助你在节点视图中添加可编辑内容。示例如下：

```jsx
import React from 'react'
import { NodeViewWrapper, NodeViewContent } from '@tiptap/react'

export default () => {
  return (
    <NodeViewWrapper className="react-component">
      <span className="label" contentEditable={false}>
        React Component
      </span>

      <NodeViewContent className="content" />
    </NodeViewWrapper>
  )
}
```

你不必添加这些 `className` 属性，可以随意删除它们或传入其他类名。试试下面的示例：

<CodeDemo path="/GuideNodeViews/ReactComponentContent?inline=false&hideSource=false" />

请注意，这些内容由 Tiptap 渲染。这意味着你需要指定允许的内容类型，例如在节点扩展中使用 `content: 'inline*'`（上面的示例就是这样设置的）。

`NodeViewWrapper` 和 `NodeViewContent` 组件会渲染 `<div>` HTML 标签（对于行内节点则是 `<span>`），不过你可以更改标签。例如，`<NodeViewContent as="p">` 会渲染一个段落。需要注意的限制是：运行时不能更改该标签。

## 更改节点视图的默认内容标签

对于非叶节点视图，`ReactNodeViewRenderer` 会在包装元素内部创建一个可编辑内容元素。块级节点默认使用 `div`，行内节点默认使用 `span`。使用 `contentDOMElementTag` 可以覆盖其标签：

```js
// this will use a header tag for the editable content
return ReactNodeViewRenderer(Component, { contentDOMElementTag: 'header' })
```

## 更改外层包装元素

`ReactNodeViewRenderer` 创建的外层元素，块级节点默认使用 `div`，行内节点默认使用 `span`。使用 `as` 选项可以覆盖该元素。它与 `contentDOMElementTag` 不同，后者控制内部可编辑内容元素：

```js
import { Node } from '@tiptap/core'
import { ReactNodeViewRenderer } from '@tiptap/react'
import Component from './Component.jsx'

export default Node.create({
  // configuration …

  addNodeView() {
    return ReactNodeViewRenderer(Component, { as: 'main' })
  },
})
```

## 在文本选区中更新 `selected`

默认情况下，只有使用 `NodeSelection` 选中节点本身时，`selected` prop 才会变为 `true`。这对原子节点来说很合适，但当光标仅仅位于含有文本内容的节点内部时，不会触发此状态。如果你希望这种情况也能反映在 `selected` 中，请在 `ReactNodeViewRenderer` 上启用 `selectedOnTextSelection` 选项：

```js
return ReactNodeViewRenderer(Component, { selectedOnTextSelection: true })
```

启用此选项后，当 `TextSelection` 完全包含在节点范围内时，`selected` 也会变为 `true`，例如光标位于节点内容中的某处时。仅与节点部分重叠的选区不会被视为已选中。

## 跟踪节点位置

如果装饰或位置发生变化而内容没有变化，节点视图不会重新渲染。ProseMirror 会在 contentDOM 上原生处理装饰，而 `getPos()` 闭包在调用时始终会返回当前位置，即使没有重新渲染也是如此。

如果你需要 `getPos()` 在渲染输出中保持响应式（例如拖动手柄显示 `pos: 42`），请启用 `trackNodeViewPosition`：

```js
return ReactNodeViewRenderer(Component, { trackNodeViewPosition: true })
```

启用后，每当位置发生变化，组件都会重新渲染。请谨慎使用，因为频繁重新渲染可能会影响性能。

## 所有可用的 props

以下是你可能会用到的全部 props：

| Prop               | 说明                                                     |
| ------------------ | --------------------------------------------------------------- |
| editor             | 编辑器实例                                             |
| node               | 当前节点                                                |
| decorations        | 装饰数组                                         |
| selected           | 当前节点视图存在 `NodeSelection` 时为 `true`。启用 [`selectedOnTextSelection`](#在文本选区中更新-selected) 后，节点内部完全包含 `TextSelection` 时也为 `true`。 |
| extension          | 访问节点扩展，例如获取其选项        |
| getPos()           | 获取当前节点在文档中的位置                   |
| updateAttributes() | 更新当前节点的属性                           |
| deleteNode()       | 删除当前节点                                         |

## 拖动

要让节点视图支持拖动，请在扩展中设置 `draggable: true`，并将 `data-drag-handle` 添加到用作拖动手柄的 DOM 元素上。
