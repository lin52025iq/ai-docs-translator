如果你习惯于不使用 Vue 或 React，那么使用这些框架可能会让你觉得过于复杂。好消息是，你可以在节点视图中使用原生 JavaScript。需要了解的内容并不多，我们来逐一看看。

## 使用 JavaScript 渲染节点视图

要在编辑器中渲染节点视图，需要执行以下操作：

1. [创建节点扩展](/editor/extensions/custom-extensions/create-new/node)
2. 使用 `addNodeView()` 注册一个新的节点视图
3. 编写渲染函数
4. [配置 Tiptap 使用你的新节点扩展](/editor/getting-started/configure)

你的节点扩展可以像这样：

```js
import { Node } from '@tiptap/core'

export default Node.create({
  // configuration …

  addNodeView() {
    return ({ editor, node, getPos, HTMLAttributes, decorations, extension }) => {
      const dom = document.createElement('div')

      dom.innerHTML = 'Hello, I’m a node view!'

      return {
        dom,
      }
    }
  },
})
```

这个节点视图甚至可以与编辑器交互。下面来看看如何实现。

## 访问节点属性

编辑器会向渲染函数传入一些有用的信息，其中之一就是 `node` 属性。借助它，你可以在节点视图中访问节点属性。假设你已为节点扩展[添加了一个名为 `count` 的属性](/editor/extensions/custom-extensions/extend-existing#attributes)，可以这样访问它：

```js
addNodeView() {
  return ({ node }) => {
    console.log(node.attrs.count)

    // …
  }
}
```

## 更新节点属性

借助传递给渲染函数的 `getPos` 属性，你甚至可以从节点视图中更新节点属性。使用包含已更新属性的对象分发一个新事务：

```js
addNodeView() {
  return ({ editor, node, getPos }) => {
    const { view } = editor

    // Create a button …
    const button = document.createElement('button')
    button.innerHTML = `This button has been clicked ${node.attrs.count} times.`

    // … and when it’s clicked …
    button.addEventListener('click', () => {
      if (typeof getPos === 'function') {
        // … dispatch a transaction, for the current position in the document …
        view.dispatch(view.state.tr.setNodeMarkup(getPos(), undefined, {
          count: node.attrs.count + 1,
        }))

        // … and set the focus back to the editor.
        editor.commands.focus()
      }
    })

    // …
  }
}
```

觉得这有点复杂？如果你的项目中已经使用了 [React](/editor/extensions/custom-extensions/node-views/react) 或 [Vue](/editor/extensions/custom-extensions/node-views/vue)，不妨考虑使用它们。借助这两个框架，事情会简单一些。

## 添加可编辑内容

要在节点视图中添加可编辑内容，需要传入一个 `contentDOM`，也就是内容的容器元素。下面是一个简化示例，展示了包含不可编辑和可编辑文本内容的节点视图：

```js
// Create a container for the node view
const dom = document.createElement('div')

// Give other elements containing text `contentEditable = false`
const label = document.createElement('span')
label.innerHTML = 'Node view'
label.contentEditable = false

// Create a container for the content
const content = document.createElement('div')

// Append all elements to the node view container
dom.append(label, content)

return {
  // Pass the node view container …
  dom,
  // … and the content container:
  contentDOM: content,
}
```

明白了吗？只要返回一个节点视图容器和另一个内容容器，你就可以自由发挥。下面可以查看上述示例的实际效果：
