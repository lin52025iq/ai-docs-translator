使用此扩展来显示 ~~删除线文本~~。如果编辑器初始内容中包含 `<s>`、`<del>`、`<strike>` 标签，或设置了 `text-decoration: line-through` 的内联 `style` 属性，这些内容都会相应地显示为删除线。

输入 <code>~~波浪号之间的文本~~</code>，打字时文本就会神奇地 ~~加上删除线~~。

<Callout title="限制" variant="default">
    读取 `Editor` 实例的内容时，此扩展会生成相应的 `<s>` HTML 标签。无论使用哪种方式添加删除线，所有带删除线的文本都会统一转换为 `<s>` HTML 标签。
</Callout>

## 安装

```bash
npm install @tiptap/extension-strike
```

## 设置

### HTMLAttributes

要添加到渲染后 HTML 标签的自定义 HTML 属性。

```js
Strike.configure({
  HTMLAttributes: {
    class: 'my-custom-class',
  },
})
```

## 命令

### setStrike()

为文本添加删除线标记。

```js
editor.commands.setStrike()
```

### toggleStrike()

切换删除线标记。

```js
editor.commands.toggleStrike()
```

### unsetStrike()

移除删除线标记。

```js
editor.commands.unsetStrike()
```
