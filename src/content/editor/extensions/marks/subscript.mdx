使用此扩展可将文本渲染为 <sub>下标</sub>。如果在编辑器的初始内容中传入 `<sub>`，或传入带有 `vertical-align: sub` 行内样式的文本，两者都会相应地渲染。

<Callout title="限制" variant="default">
    读取 `Editor` 实例的内容时，此扩展会生成对应的 `<sub>` HTML 标签。无论使用哪种方式，所有下标文本都会统一转换为 `<sub>` HTML 标签。
</Callout>

## 安装

```bash
npm install @tiptap/extension-subscript
```

## 设置

### HTMLAttributes

要添加到渲染后 HTML 标签上的自定义 HTML 属性。

```js
Subscript.configure({
  HTMLAttributes: {
    class: 'my-custom-class',
  },
})
```

## 命令

### setSubscript()

将文本标记为下标。

```js
editor.commands.setSubscript()
```

### toggleSubscript()

切换下标标记。

```js
editor.commands.toggleSubscript()
```

### unsetSubscript()

移除下标标记。

```js
editor.commands.unsetSubscript()
```
