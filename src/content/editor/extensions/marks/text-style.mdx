此标记会渲染 HTML `<span>` 标签，并允许你添加一系列与样式相关的属性，例如 font-family、font-size 或 color。该扩展默认不会添加任何样式属性，但其他扩展会以它为基础，例如 [`FontFamily`](/editor/extensions/functionality/fontfamily) 或 [`Color`](/editor/extensions/functionality/color)。

## 设置字体大小

`TextStyle` 提供 `<span>` 标记，而 [`FontSize`](/editor/extensions/functionality/fontsize) 等扩展则会添加特定的样式属性。安装 text-style 包，并在包含文档 schema 的编辑器中加入这两个扩展，例如使用 `StarterKit` 提供的 schema：

```bash
npm install @tiptap/extension-text-style @tiptap/starter-kit
```

```ts
import { Editor } from '@tiptap/core'
import { TextStyle, FontSize } from '@tiptap/extension-text-style'
import StarterKit from '@tiptap/starter-kit'

const editor = new Editor({
  extensions: [StarterKit, TextStyle, FontSize],
})

editor.chain().focus().setFontSize('18px').run()
```

此命令会将选中的文本渲染为带有行内 `font-size: 18px` 样式的 `span`。

## 安装

```bash
npm install @tiptap/extension-text-style
```

## 命令

### removeEmptyTextStyle()

移除没有行内样式的 `<span>` 标签。

```js
editor.command.removeEmptyTextStyle()
```
