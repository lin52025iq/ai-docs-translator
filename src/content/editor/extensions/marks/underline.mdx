使用此扩展可将文本渲染为<u>带下划线</u>。如果在编辑器的初始内容中传入 `<u>` 标签，或带有将 `text-decoration: underline` 设为值的内联 `style` 属性的文本，它们都会按相应样式渲染。

请注意，在互联网上，带下划线的文本通常表示可点击的链接。使用带下划线的文本时，请避免让用户产生误解。

<Callout title="限制" variant="default">
    读取 `Editor` 实例的内容时，此扩展会生成对应的 `<u>` HTML 标签。所有标记为带下划线的文本，无论采用何种方式标记，都会统一转换为 `<u>` HTML 标签。
</Callout>

## 安装

```bash
npm install @tiptap/extension-underline
```

## 设置

### HTMLAttributes

要添加到渲染后的 HTML 标签中的自定义 HTML 属性。

```js
Underline.configure({
  HTMLAttributes: {
    class: 'my-custom-class',
  },
})
```

## 命令

### setUnderline()

为文本添加下划线标记。

```js
editor.commands.setUnderline()
```

### toggleUnderline()

切换下划线标记。

```js
editor.commands.toggleUnderline()
```

### unsetUnderline()

移除下划线标记。

```js
editor.commands.unsetUnderline()
```
