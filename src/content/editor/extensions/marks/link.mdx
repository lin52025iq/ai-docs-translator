链接扩展为编辑器添加了对 `<a>` 标签的支持。该扩展也是无头的，也就是说没有实际的 UI 用于添加、修改或删除链接。下面的用法示例使用原生 JavaScript prompt，演示了如何实现这一功能。

在实际应用中，你可能会添加更完善的用户界面。

粘贴的 URL 会自动转换为链接。

<CodeDemo path="/Marks/Link" />

## 安装

```bash
npm install @tiptap/extension-link
```

## 设置

### protocols

你希望识别为链接的其他自定义协议。

默认值：`[]`

```js
Link.configure({
  protocols: ['ftp', 'mailto'],
})
```

默认情况下，[linkify](https://linkify.js.org/docs/) 会在协议后添加 `//`，但你可以通过传入 `optionalSlashes` 选项来更改此行为。

```js
Link.configure({
  protocols: [
    {
      scheme: 'tel',
      optionalSlashes: true,
    },
  ],
})
```

### autolink

启用后，输入时会自动添加链接。

默认值：`true`

```js
Link.configure({
  autolink: false,
})
```

### openOnClick

启用后，点击链接时会打开链接。

默认值：`true`

```js
Link.configure({
  openOnClick: false,
})
```

### enableClickSelection

启用后，点击链接时会选中该链接。

默认值：`false`

```js
Link.configure({
  enableClickSelection: true,
})
```

### linkOnPaste

如果粘贴的内容仅包含 URL，则为当前选区添加链接。

默认值：`true`

```js
Link.configure({
  linkOnPaste: false,
})
```

### defaultProtocol

未指定协议时，`linkOnPaste` 和 `autolink` 使用的默认协议。

例如，默认情况下，example.com 生成的 href 为 http://example.com。此选项可用于自定义该协议。

默认值：`http`

```js
Link.configure({
  defaultProtocol: 'https',
})
```

### HTMLAttributes

要添加到渲染后 HTML 标签的自定义 HTML 属性。

```js
Link.configure({
  HTMLAttributes: {
    class: 'my-custom-class',
  },
})
```

#### 移除和覆盖现有 HTML 属性

你可以在 HTMLAttributes 中设置 `rel: null`，以移除默认的 `rel="noopener noreferrer nofollow"`。也可以通过设置 `rel: "your-value"` 来覆盖默认值。

此选项也可用于更改 `target` 的默认值 `_blank`。

```js
Link.configure({
  HTMLAttributes: {
    // 将 rel 更改为其他值
    // 允许搜索引擎跟踪链接（移除 nofollow）
    rel: 'noopener noreferrer',
    // 完全移除 target，使链接在当前标签页中打开
    target: null,
  },
})
```

### isAllowedUri

用于自定义链接验证并修改默认验证逻辑的函数。此函数接收 URL 和一个包含其他属性的上下文对象。

**参数：**

- `url`：要验证的 URL。
- `ctx`：包含以下内容的对象：
  - `defaultValidate`：执行默认 URL 验证的函数。
  - `protocols`：URL 允许使用的协议数组，例如 `["http", "https"]`。
  - `defaultProtocol`：默认协议（例如 `'http'`）。

**返回值：** `boolean` - 如果 URL 有效则为 `true`，否则为 `false`。

此函数可用于在 URL 自动链接时，强制执行允许的协议或域名规则。

```js
// 验证 URL，仅接受非相对 URL
Link.configure({
  isAllowedUri: (url, ctx) => ctx.defaultValidate(url) && !url.startsWith('./'),
})
```

### validate（已弃用）

此函数已弃用，建议改用名称更明确的 `shouldAutoLink` 函数。如果提供了 `validate` 函数，它将替代 `shouldAutoLink` 函数。

### shouldAutoLink

定义编辑器内容中的有效链接是否应自动转换为链接。

**参数：**

- `url`：已通过验证的 URL。

**返回值：** `boolean` - 如果应自动链接则为 `true`，否则为 `false`。

使用此函数可根据 URL 控制自动链接行为。

```js
// 示例：仅在 URL 使用安全协议时自动链接
Link.configure({
  shouldAutoLink: (url) => url.startsWith('https://'),
})
```

## 命令

### setLink()

为选中的文本添加链接。

```js
editor.commands.setLink({ href: 'https://example.com' })
editor.commands.setLink({ href: 'https://example.com', target: '_blank' })
```

### toggleLink()

为选中的文本添加或移除链接。

```js
editor.commands.toggleLink({ href: 'https://example.com' })
editor.commands.toggleLink({ href: 'https://example.com', target: '_blank' })
```

### unsetLink()

移除链接。

```js
editor.commands.unsetLink()
```

## 获取当前值

你知道可以使用 [`getAttributes`](/editor/api/editor#getattributes) 来查看当前设置的属性（例如 href）吗？不要把它和 [命令](/editor/api/commands)（会更改状态）混淆；它只是一个方法。用法如下：

```js
this.editor.getAttributes('link').href
```
