Ruby Text 扩展支持 [HTML ruby 注音标记](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/ruby)。Ruby 注音标记可为中日韩文字提供阅读指南，例如日语中的振假名。它与 Ruby 编程语言无关。

<CodeDemo path="/Marks/RubyText" />

## 安装

```bash
npm install @tiptap/extension-ruby-text
```

## 用法

将扩展添加到编辑器，然后为选中的文本添加注音。

```js
import { Editor } from '@tiptap/core'
import RubyText from '@tiptap/extension-ruby-text'

const editor = new Editor({
  extensions: [
    // Other extensions ...
    RubyText,
  ],
})

editor.commands.setRubyText({ rt: 'とうきょう' })
```

该扩展会将注音渲染为 HTML ruby 文本。

```html
<ruby><rb>東京</rb><rt>とうきょう</rt></ruby>
```

<Callout title="HTML 解析" variant="info">
  该扩展支持包含 `rb` 子元素或直接包含基底文本的 ruby 元素。它会忽略 `rp`
  回退元素。没有 `rt` 注音的 ruby 元素不会被解析为 Ruby Text 标记。
</Callout>

## 设置

### HTMLAttributes

添加到所渲染 `<ruby>` 元素的自定义 HTML 属性。

默认值：`{}`

```js
RubyText.configure({
  HTMLAttributes: {
    class: 'ruby-text',
  },
})
```

### allowClickToEdit

控制点击注音时是否打开内联编辑器。

默认值：`true`

```js
RubyText.configure({
  allowClickToEdit: false,
})
```

只有在 Tiptap 编辑器处于可编辑状态时，才能使用内联编辑器。禁用此选项后，注音只会显示，不支持交互式编辑。

### renderAnnotationEditor

渲染用于编辑注音的自定义元素。返回的元素会替代 `<rt>` 元素中的默认输入框。

回调会接收当前的 `annotation`、Tiptap `editor`，以及 `submit` 和 `dismiss` 函数。调用 `submit(value)` 可保存注音；调用 `dismiss()` 可关闭编辑器而不做更改。为返回的元素或其某个后代添加 `autofocus`，即可在打开编辑器时使其获得焦点。

```js
RubyText.configure({
  renderAnnotationEditor: ({ annotation, submit, dismiss }) => {
    const input = document.createElement('input')

    input.value = annotation
    input.setAttribute('autofocus', '')
    input.addEventListener('keydown', (event) => {
      if (event.key === 'Escape') {
        dismiss()
      }

      if (event.key === 'Enter') {
        submit(input.value)
      }
    })

    return input
  },
})
```

未设置此选项时，扩展会渲染一个文本输入框。按 <kbd>Enter</kbd> 保存注音；按 <kbd>Escape</kbd> 或让输入框失去焦点则会取消编辑。输入法组合输入期间，按 Enter 和 Escape 不会关闭输入框。

## 命令

### setRubyText()

为选中的文本添加 ruby 注音。

```js
editor.commands.setRubyText({ rt: 'かんじ' })
```

### toggleRubyText()

为选中的文本添加或移除 ruby 注音。

```js
editor.commands.toggleRubyText({ rt: 'かんじ' })
```

### unsetRubyText()

移除选中文本的 ruby 注音。

```js
editor.commands.unsetRubyText()
```
