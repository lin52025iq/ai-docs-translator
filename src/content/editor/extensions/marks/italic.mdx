使用此扩展可将文本渲染为_斜体_。如果编辑器的初始内容中包含 `<em>`、`<i>` 标签，或带有 `font-style: italic` 行内 `style` 属性的文本，这些内容都会相应地渲染。

输入 `*一个星号*` 或 `_一个下划线_`，文本便会在输入时自动转换为_斜体_。

<CodeDemo path="/Marks/Italic" />

<Callout title="限制" variant="default">
    读取 `Editor` 实例的内容时，此扩展会生成相应的 `<em>` HTML 标签。所有标记为斜体的文本，无论使用何种方式设置，都会统一转换为 `<em>` HTML 标签。
</Callout>

## 安装

```bash
npm install @tiptap/extension-italic
```

## 设置

### HTMLAttributes

要添加到渲染后 HTML 标签中的自定义 HTML 属性。

```js
Italic.configure({
  HTMLAttributes: {
    class: 'my-custom-class',
  },
})
```

## 命令

### setItalic()

将文本标记为斜体。

```js
editor.commands.setItalic()
```

### toggleItalic()

切换斜体标记。

```js
editor.commands.toggleItalic()
```

### unsetItalic()

移除斜体标记。

```js
editor.commands.unsetItalic()
```
