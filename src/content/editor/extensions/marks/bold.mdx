使用此扩展将文本渲染为**粗体**。如果在编辑器的初始内容中传入 `<strong>`、`<b>` 标签，或包含设置了 `font-weight` CSS 规则的内联 `style` 属性的文本，它们都会按相应方式渲染。

输入 `**two asterisks**` 或 `__two underlines__`，输入过程中它们会自动转换为**粗体**文本。

<CodeDemo path="/Marks/Bold" />

<Callout title="限制" variant="default">
    读取 `Editor` 实例的内容时，此扩展会生成相应的 `<strong>` HTML 标签。无论采用何种方式标记为粗体的文本，都会统一规范为 `<strong>` HTML 标签。
</Callout>

## 安装

```bash
npm install @tiptap/extension-bold
```

## 设置

### HTMLAttributes

要添加到渲染后 HTML 标签上的自定义 HTML 属性。

```js
Bold.configure({
  HTMLAttributes: {
    class: 'my-custom-class',
  },
})
```

## 命令

### setBold()

将文本标记为粗体。

```js
editor.commands.setBold()
```

### toggleBold()

切换粗体标记。

```js
editor.commands.toggleBold()
```

### unsetBold()

移除粗体标记。

```js
editor.commands.unsetBold()
```
