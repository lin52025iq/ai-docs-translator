Code 扩展使你可以在编辑器中使用 `<code>` HTML 标签。粘贴包含 `<code>` 标签的文本时，内容会相应地呈现。

输入一段用 <code>反引号括起来</code> 的内容，输入时它就会自动转换为 `行内代码`。

<CodeDemo path="/Marks/Code" />

## 安装

```bash
npm install @tiptap/extension-code
```

## 设置

### HTMLAttributes

要添加到渲染后 HTML 标签中的自定义 HTML 属性。

```js
Code.configure({
  HTMLAttributes: {
    class: 'my-custom-class',
  },
})
```

## 命令

### setCode()

将文本标记为行内代码。

```js
editor.commands.setCode()
```

### toggleCode()

切换行内代码标记。

```js
editor.commands.toggleCode()
```

### unsetCode()

移除行内代码标记。

```js
editor.commands.unsetCode()
```

## 键盘快捷键

| 命令         | Windows/Linux                     | macOS                         |
| ------------ | --------------------------------- | ----------------------------- |
