查找和替换扩展会搜索文档、高亮匹配项，并提供用于导航和替换的命令。它不包含界面，因此你可以自行构建控件，并将其放置在应用中的任意位置。

<CodeDemo path="/Extensions/FindAndReplace" />

## 安装

```bash
npm install @tiptap/extension-find-and-replace
```

## 用法

```js
import { Editor } from '@tiptap/core'
import FindAndReplace from '@tiptap/extension-find-and-replace'
import StarterKit from '@tiptap/starter-kit'

new Editor({
  extensions: [StarterKit, FindAndReplace],
})
```

如需完整的 React 和 Vue 示例，请参阅[自定义 UI 指南](/guides/find-and-replace)。

## 设置

这些选项用于设置初始状态。编辑器运行时，可使用下方的命令更新搜索内容。

### searchTerm

要搜索的初始文本。在正则表达式模式下，此值为正则表达式源文本。

默认值：`''`

```js
FindAndReplace.configure({
  searchTerm: 'Tiptap',
})
```

### replaceTerm

替换命令使用的初始文本。启用正则表达式模式时，替换内容可以引用完整匹配项或捕获组。

默认值：`''`

```js
FindAndReplace.configure({
  useRegex: true,
  searchTerm: '(color|colour)',
  replaceTerm: '[$1]',
})
```

### caseSensitive

搜索是否区分大小写。

默认值：`false`

```js
FindAndReplace.configure({
  caseSensitive: true,
})
```

### useRegex

是否将 `searchTerm` 视为正则表达式。

默认值：`false`

```js
FindAndReplace.configure({
  useRegex: true,
  searchTerm: 'colou?r',
})
```

正则表达式模式可以与 `caseSensitive` 和 `wholeWord` 组合使用。无效或被判定为不安全的模式不会返回结果。正则表达式模式使用兼容 RE2 的语法，因此搜索模式不支持环视和反向引用。

### wholeWord

是否要求匹配项两侧都具有 Unicode 单词边界。此选项适用于字面搜索和正则表达式搜索。Unicode 单词字符包括字母、组合标记、数字以及连接标点（例如 `_`）。

默认值：`false`

```js
FindAndReplace.configure({
  caseSensitive: true,
  useRegex: true,
  wholeWord: true,
  searchTerm: 'cat|catalog',
})
```

例如，此配置会匹配 `cat` 和 `catalog`，但不会匹配 `cats` 或 `Catalog`。如果较早的匹配结果不满足完整单词边界，正则表达式引擎可以尝试后续备选项或更长的匹配。

### searchDebounceMs

调用 `setSearchTerm()` 后，更新搜索结果前的延迟时间（毫秒）。设为 `0` 可立即更新结果。

默认值：`250`

```js
FindAndReplace.configure({
  searchDebounceMs: 0,
})
```

### injectCSS

是否注入默认的结果高亮样式。禁用此选项可使用自定义样式。

默认值：`true`

```js
FindAndReplace.configure({
  injectCSS: false,
})
```

### injectNonce

应用于注入样式元素的 nonce。如果内容安全策略要求提供 nonce，请设置此项。

默认值：`undefined`

```js
FindAndReplace.configure({
  injectNonce: 'your-nonce-here',
})
```

## 命令

### setSearchTerm()

设置搜索词并高亮所有匹配项。

```js
editor.commands.setSearchTerm('Tiptap')
```

### setReplaceTerm()

设置 `replace()` 和 `replaceAll()` 使用的文本。在正则表达式模式下，替换内容可以包含捕获组替换标记。

```js
editor.commands.setReplaceTerm('[$1]')
```

#### 正则表达式替换标记

启用正则表达式模式后，替换词支持以下 JavaScript 风格的标记：

| 标记       | 替换内容           |
| ---------- | ------------------ |
| `$$`       | 字面量 `$`         |
| `$&`       | 完整匹配项         |
| `$1`–`$99` | 对应编号的捕获组   |
| `$<name>`  | 对应名称的捕获组   |

未匹配的组会插入空字符串。超出模式捕获组数量的一位数字编号引用会保持不变。对于两位数字引用，将应用 JavaScript 风格的回退规则：如果不存在完整编号，但首位数字对应一个捕获组，则插入该捕获组，后接第二位数字。例如，模式只有一个捕获组时，`$12` 会插入捕获组 1，后接 `2`。像 `$01` 这样的前导零引用也遵循 JavaScript 语义，指向捕获组 1。如果模式中含有命名组，未知名称的引用会插入空字符串；否则会保持不变。

其他 `$` 序列保持不变。JavaScript 的匹配前标记（`$` 后接反引号）和匹配后标记（`$'`）不会展开。禁用正则表达式模式时，所有替换词都会按字面内容插入。

在正则表达式模式下，使用 `$$` 转义开头的美元符号，即可按字面保留受支持的标记。例如，`$$1` 会插入 `$1`。

```js
editor.commands.setUseRegex(true)
editor.commands.setSearchTerm('(color|colour)')
editor.commands.setReplaceTerm('[$1]')
editor.commands.replaceAll()
// "color and colour" becomes "[color] and [colour]"
```

### setCaseSensitive()

启用或禁用区分大小写的匹配。此选项适用于字面模式和正则表达式模式。

```js
editor.commands.setCaseSensitive(true)
```

### setUseRegex()

启用或禁用正则表达式匹配。正则表达式模式可以与“区分大小写”和“全词匹配”同时启用。

```js
editor.commands.setUseRegex(true)
```

### setWholeWord()

为字面搜索或正则表达式搜索启用或禁用基于 Unicode 的全词匹配。

```js
editor.commands.setWholeWord(true)
```

### goToNextResult()

选择下一个结果。从最后一个结果继续导航时，会循环到第一个结果。

```js
editor.commands.goToNextResult()
```

### goToPreviousResult()

选择上一个结果。从第一个结果继续导航时，会循环到最后一个结果。

```js
editor.commands.goToPreviousResult()
```

### replace()

替换选中的结果，并选择下一个可用结果。

```js
editor.commands.replace()
```

### replaceAll()

替换当前结果集中的所有结果。

```js
editor.commands.replaceAll()
```

### clearSearch()

清除搜索词并移除所有结果高亮。

```js
editor.commands.clearSearch()
```

## 存储

扩展会将当前状态保存在 `editor.storage.findAndReplace` 中。

### searchTerm

当前搜索词。

```js
editor.storage.findAndReplace.searchTerm
```

### replaceTerm

当前替换文本。

```js
editor.storage.findAndReplace.replaceTerm
```

### caseSensitive、useRegex 和 wholeWord

当前匹配选项。

```js
editor.storage.findAndReplace.caseSensitive
editor.storage.findAndReplace.useRegex
editor.storage.findAndReplace.wholeWord
```

### results

按文档顺序排列的匹配项。每个结果都包含 `from` 和 `to` 两个 ProseMirror 位置。

```js
editor.storage.findAndReplace.results
```

### currentIndex

选中结果的索引；未选中任何结果时为 `null`。

```js
editor.storage.findAndReplace.currentIndex
```

## 搜索行为

文档或搜索选项发生变化时，匹配结果会更新。匹配项可以跨越带有不同标记的文本节点，但不会跨越文本块或非文本内联节点（例如硬换行或提及节点）。

区分大小写、正则表达式和全词匹配是相互独立的选项，可以同时启用。在正则表达式全词匹配模式下，会围绕最终的正则表达式结果检查边界。这样一来，备选项和量词可以继续尝试，直到匹配出完整单词。连续匹配可以共用标点边界，因此，对 `cat` 使用全词匹配的正则表达式，会在 `cat-cat.cat` 中找到全部三个匹配项。

`replaceAll()` 会替换命令运行时存在的匹配项。如果替换文本也符合搜索条件，这些新匹配项会在事务完成后保留在存储中。

## 结果样式

默认情况下，结果会以黄色高亮显示，选中的结果会以橙色高亮显示。禁用 `injectCSS` 可替换这些样式。

```css
.find-and-replace-result {
  background-color: rgb(255 225 0 / 0.4);
}

.find-and-replace-result-current {
  background-color: rgb(255 165 0 / 0.55);
}
```
