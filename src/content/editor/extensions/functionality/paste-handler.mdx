`PasteHandler` 扩展会智能转换粘贴的 HTML，确保其与外部来源的内容兼容。它会对粘贴内容执行一系列转换，清理来源特有的格式问题，同时保留用户的原意。

## 支持的来源

| 来源 | macOS 桌面版 | Windows 桌面版 | Web（浏览器） |
| --- | :---: | :---: | :---: |
| Microsoft Excel | ✓ | ✓ | ✓（SharePoint） |
| Microsoft Word | ✓ | ✓ | ✓（SharePoint） |
| Microsoft Outlook | ✓ | ✓ | ✓（Outlook Web） |
| Google Docs | — | — | ✓ |
| Google Sheets | — | — | ✓ |

## 安装

```bash
npm install @tiptap-pro/extension-paste-handler
```

## 用法

此扩展无需配置，只需将它添加到编辑器中，即可自动生效。

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import PasteHandler from '@tiptap-pro/extension-paste-handler'

const editor = new Editor({
  extensions: [
    StarterKit,
    PasteHandler,
  ],
})
```

## 处理内容

此扩展会按特定顺序对粘贴的 HTML 执行一系列转换：

| 转换 | 说明 |
| --- | --- |
| CSS 类解析 | 将基于类的 CSS 格式（例如来自 Excel 的格式）解析为内联样式 |
| Office 标记清理 | 移除 Microsoft Office 特有的元素和属性，例如 `<o:p>` 标签和 `mso-*` 样式 |
| 移除书签 | 清除 Word 书签标记和空书签锚点 |
| 表格单元格文本样式 | 确保编辑器能够正确识别表格单元格中的文本格式 |
| 背景颜色转换 | 将 `background-color` 样式转换为 Highlight 扩展的高亮标记 |
| ARIA 标题转换 | 将 ARIA 标题元素（来自 SharePoint Word）转换为语义化 HTML 标题 |
| 水平线检测 | 检测基于文本的水平线（例如来自 Google Docs 的水平线），并将其转换为 `<hr>` 元素 |
| 合并软换行 | 将连续的零边距段落（来自 Google Docs）合并为正确的换行 |
| 重建嵌套列表 | 将扁平列表结构（来自 SharePoint）重建为正确嵌套的列表 |
| 有序列表规范化 | 移除内联 `list-style-type`，使编辑器的 CSS 控制列表样式 |
| 清理多余换行 | 移除块级元素之间导致意外间距的多余 `<br>` 标签 |

<Callout title="错误处理" variant="info">
  如果任何转换失败，扩展会平稳地回退到原始粘贴 HTML，确保粘贴功能始终可用。
</Callout>

## 已知限制

### Safari 剪贴板会剥除表格单元格样式

在 Safari 中从 SharePoint Excel（或类似来源）复制表格单元格并粘贴到编辑器时，单元格内的加粗、斜体、颜色和链接等格式会丢失。Safari 会将精简后的 HTML 数据写入剪贴板，其中只包含表格结构和单元格文本；样式信息在内容到达编辑器之前就已被移除。

这是 WebKit 层面的行为，Paste Handler 无法恢复这些信息。在 Safari 中粘贴到其他编辑器（例如 SharePoint Word）时也会出现相同情况。从基于 Chromium 的浏览器或 Firefox 复制则不受影响。
