此扩展可让你在编辑器中设置字体。它使用 [`TextStyle`](/editor/extensions/marks/text-style) 标记，并将其渲染为 `<span>` 标签。字体会以内联样式应用，例如 `<span style="font-family: Arial">`。

<CodeDemo path="/Extensions/FontFamily" />

<Callout title="注意！" variant="hint">
  请注意，`editor.isActive('textStyle', { fontFamily: 'Font Family' })` 返回的是根据[浏览器 CSS 规则](https://developer.mozilla.org/en-US/docs/Web/CSS/font-family#family-name)解析后的字体，而不是你设置字体时可能预期的值。
</Callout>

## 安装

```bash
npm install @tiptap/extension-text-style
```

此扩展需要 [`TextStyle`](/editor/extensions/marks/text-style) 标记。

```ts
import { Editor } from '@tiptap/core'
import { TextStyle, FontFamily } from '@tiptap/extension-text-style'

new Editor({
  extensions: [TextStyle, FontFamily],
})
```

此扩展默认随 `TextStyleKit` 扩展一同安装，因此无需单独安装。

```ts
import { Editor } from '@tiptap/core'
import { TextStyleKit } from '@tiptap/extension-text-style'

new Editor({
  extensions: [TextStyleKit],
})
```

## 设置

### types

要应用字体属性的标记列表。

默认值：`['textStyle']`

```js
FontFamily.configure({
  types: ['textStyle'],
})
```

## 命令

### setFontFamily()

以内联样式应用指定字体。

```js
editor.commands.setFontFamily('Inter')
```

### unsetFontFamily()

移除字体设置。

```js
editor.commands.unsetFontFamily()
```
