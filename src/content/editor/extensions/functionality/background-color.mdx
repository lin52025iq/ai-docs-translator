此扩展可让你在编辑器中设置背景颜色。它使用 [`TextStyle`](/editor/extensions/marks/text-style) 标记，该标记会渲染为 `<span>` 标签（且仅渲染此标签）。背景颜色随后会以内联样式的形式应用，例如 `<span style="background-color: #958DF1">`。

<CodeDemo path="/Extensions/BackgroundColor" />

## 安装

```bash
npm install @tiptap/extension-text-style
```

此扩展依赖 [`TextStyle`](/editor/extensions/marks/text-style) 标记。

```ts
import { Editor } from '@tiptap/core'
import { TextStyle, BackgroundColor } from '@tiptap/extension-text-style'

new Editor({
  extensions: [TextStyle, BackgroundColor],
})
```

此扩展默认随 `TextStyleKit` 扩展一起安装，因此无需单独安装。

```ts
import { Editor } from '@tiptap/core'
import { TextStyleKit } from '@tiptap/extension-text-style'

new Editor({
  extensions: [TextStyleKit],
})
```

## 设置

### types

需要应用颜色属性的标记列表。

默认值：`['textStyle']`

```js
BackgroundColor.configure({
  types: ['textStyle'],
})
```

## 命令

### setBackgroundColor()

将指定的背景颜色以内联样式的形式应用。

```js
editor.commands.setBackgroundColor('#ff0000')
```

### unsetBackgroundColor()

移除所有背景颜色。

```js
editor.commands.unsetBackgroundColor()
```
