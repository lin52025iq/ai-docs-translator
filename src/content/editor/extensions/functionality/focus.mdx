Focus 扩展会为获得焦点的节点添加 CSS 类。默认情况下，它会添加 `.has-focus`，但你可以更改此类。

请注意，它只会添加一个类，具体样式完全由你决定。下面的用法示例包含了该类的 CSS 样式。

<CodeDemo path="/Extensions/Focus" />

## 安装

```bash
npm install @tiptap/extensions
```

然后在编辑器中导入：

```ts
import { Editor } from '@tiptap/core'
import { Focus } from '@tiptap/extensions'

new Editor({
  extensions: [Focus],
})
```

## 设置

### className

应用于获得焦点的元素的类名。

默认值：`'has-focus'`

```js
Focus.configure({
  className: 'focus',
})
```

### mode

将类应用于 `'all'`（所有节点）、`'shallowest'`（最浅层节点）或 `'deepest'`（最深层节点）。

默认值：`'all'`

```js
Focus.configure({
  mode: 'deepest',
})
```
