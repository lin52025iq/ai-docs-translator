你是否曾想过将文件拖放或粘贴到编辑器中？我们也这么想过，因此开发了这个扩展。

`FileHandler` 扩展可让你轻松处理拖放到编辑器中的文件和粘贴到编辑器中的文件。你可以为这两种事件定义自定义处理程序，并管理允许的文件类型。

默认情况下，粘贴或拖放文件时，扩展不会显示上传的文件。它会触发一个事件，你可以通过向编辑器插入新节点来响应此事件。例如，要显示上传的图像文件，请使用[图像扩展](/editor/extensions/nodes/image)。

<Callout title="不提供服务器上传功能" variant="info">
  此扩展仅负责处理将文件拖放或粘贴到编辑器中的事件，不负责实现服务器文件上传。
</Callout>

## 安装

```bash
npm install @tiptap/extension-file-handler
```

## 设置

### onPaste

当文件粘贴到编辑器中时调用的回调函数。你可以访问编辑器实例和粘贴的文件。

默认值：`undefined`

```js
FileHandler.configure({
  onPaste: (editor, files, htmlContent) => {
    // do something with the files
    // and insert the file into the editor
    // in some cases (for example copy / pasted gifs from other apps) you should probably not use the file directly
    // as the file parser will only have a single gif frame as png
    // in this case, you can extract the url from the htmlContent and use it instead, let other inputRules handle insertion
    // or do anything else with the htmlContent pasted into here
  },
})
```

### onDrop

当文件拖放到编辑器中时调用的回调函数。你可以访问编辑器实例、拖放的文件，以及文件被放置的位置。

默认值：`undefined`

```js
FileHandler.configure({
  onDrop: (editor, files, pos) => {
    // do something with the files
    // and insert the file into the editor
  },
})
```

### allowedMimeTypes

此选项用于控制允许拖放或粘贴到编辑器中的文件类型。你可以定义 MIME 类型列表或文件扩展名列表。如果未定义 MIME 类型或文件扩展名，则允许所有文件。

默认值：`undefined`

```js
FileHandler.configure({
  allowedMimeTypes: ['image/jpeg', 'image/png', 'image/gif'],
})
```

### consumePasteEvent

设为 `true` 时，只要粘贴内容中包含文件，就会完全拦截粘贴事件，即使剪贴板中还包含 HTML 内容也一样。这样可以阻止其他扩展的粘贴规则处理同一事件，从而避免创建重复内容。

当 `onPaste` 回调负责插入文件，且你希望阻止其他扩展处理同一次粘贴时，请使用此选项（例如，避免文件处理器和图像扩展同时处理粘贴的图像，导致生成重复的图像节点）。

默认值：`false`

```js
FileHandler.configure({
  consumePasteEvent: true,
})
```
