在 Tiptap 中使用 Floating Menu 扩展，即可在空行上显示菜单。

<CodeDemo path="/Extensions/FloatingMenu" />

<Callout variant="warning">
    如果你使用 React 或 Vue 等框架，请使用框架专用的 `FloatingMenu` 组件，而不是该扩展。该组件提供了更便捷的 API，并会为你处理 DOM 元素。你可以在下文的[与框架搭配使用](#usage-with-frameworks)部分了解更多信息。
</Callout>

## 安装扩展

安装 Floating Menu 扩展和 [Floating UI](https://floating-ui.com) 库。

```bash
npm install @tiptap/extension-floating-menu @floating-ui/dom@^1.6.0
```

## 设置

### element

包含菜单的 DOM 元素。

类型：`HTMLElement`

默认值：`null`

### updateDelay

`FloatingMenu` 会对 `update` 方法进行防抖，避免每次选区更新时都更新浮动菜单。你可以通过毫秒数控制此延迟。
`FloatingMenuPlugin` 的默认延迟为 250ms。将延迟设为 `0` 可停用防抖。

类型：`Number`

默认值：`250`

### resizeDelay

`FloatingMenu` 会对调整大小和滚动事件处理程序进行防抖，避免每次调整大小或滚动时都更新浮动菜单。你可以通过毫秒数控制此延迟。

类型：`Number`

默认值：`60`

### appendTo

浮动菜单在 DOM 中追加到的元素。可以是 `HTMLElement`，也可以是返回 `HTMLElement` 的回调函数。

类型：`HTMLElement | (() => HTMLElement) | undefined`

默认值：`undefined`，菜单将追加到 `document.body`。

### options

`FloatingMenu` 底层使用 [Floating UI](https://floating-ui.com)。你可以通过这些选项控制浮动菜单的中间件和定位方式。

类型：`Object`

默认值：`{ strategy: 'absolute', placement: 'right' }`

| 选项            | 类型                                   | 描述                                                                                                                                                              |
| --------------- | -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `strategy`      | `string`                               | 定位策略。参见[此处](https://floating-ui.com/docs/computePosition#strategy)                                                                                      |
| `placement`     | `string`                               | 菜单的位置。参见[此处](https://floating-ui.com/docs/computePosition#placement)                                                                                   |
| `offset`        | `number`、`OffsetOptions` 或 `boolean` | [offset 中间件选项](https://floating-ui.com/docs/offset#options)。设为 `true` 时使用默认选项，设为 `false` 时停用该中间件。                                       |
| `flip`          | `FlipOptions` 或 `boolean`             | [flip 中间件选项](https://floating-ui.com/docs/flip#options)。设为 `true` 时使用默认选项，设为 `false` 时停用该中间件。                                           |
| `shift`         | `ShiftOptions` 或 `boolean`            | [shift 中间件选项](https://floating-ui.com/docs/shift#options)。设为 `true` 时使用默认选项，设为 `false` 时停用该中间件。                                          |
| `arrow`         | `ArrowOptions` 或 `false`              | [arrow 中间件选项](https://floating-ui.com/docs/arrow#options)。设为 `false` 时停用该中间件。                                                                     |
| `size`          | `SizeOptions` 或 `boolean`             | [size 中间件选项](https://floating-ui.com/docs/size#options)。设为 `true` 时使用默认选项，设为 `false` 时停用该中间件。                                            |
| `autoPlacement` | `AutoPlacementOptions` 或 `boolean`    | [autoPlacement 中间件选项](https://floating-ui.com/docs/autoPlacement#options)。设为 `true` 时使用默认选项，设为 `false` 时停用该中间件。                         |
| `hide`          | `HideOptions` 或 `boolean`             | [hide 中间件选项](https://floating-ui.com/docs/hide#options)。设为 `true` 时使用默认选项，设为 `false` 时停用该中间件。                                            |
| `inline`        | `InlineOptions` 或 `boolean`           | [inline 中间件选项](https://floating-ui.com/docs/inline#options)。设为 `true` 时使用默认选项，设为 `false` 时停用该中间件。                                         |
| `onShow`        | `Function` 或 `undefined`              | 菜单显示时调用的回调。可用于在菜单显示时添加自定义逻辑或样式。                                                                                                    |
| `onHide`        | `Function` 或 `undefined`              | 菜单隐藏时调用的回调。可用于在菜单隐藏时添加自定义逻辑或样式。                                                                                                    |
| `onUpdate`      | `Function` 或 `undefined`              | 菜单更新时调用的回调。可用于在菜单更新时添加自定义逻辑或样式。                                                                                                    |
| `onDestroy`     | `Function` 或 `undefined`              | 菜单销毁时调用的回调。可用于在菜单移除时添加自定义逻辑或样式。                                                                                                    |

### pluginKey

底层 ProseMirror 插件的键。如果添加多个实例，请确保使用不同的键。

类型：`string | PluginKey`

默认值：`'floatingMenu'`

### shouldShow

用于控制是否显示菜单的回调。

类型：`(props) => boolean`

## 在原生 JavaScript 中使用

```js
import { Editor } from '@tiptap/core'
import FloatingMenu from '@tiptap/extension-floating-menu'

new Editor({
  element: document.querySelector('#editor'),
  extensions: [
    StarterKit,
    FloatingMenu.configure({
      element: document.querySelector('#floating-menu'),
    }),
  ],
  content: '<p>Click on an empty line to see the floating menu.</p>',
})
```

在 HTML 中添加菜单元素：

```html
<div id="floating-menu" style="display: none; position: absolute;">
  <button onclick="editor.chain().focus().toggleHeading({ level: 1 }).run()">H1</button>
  <button onclick="editor.chain().focus().toggleBulletList().run()">List</button>
</div>
<div id="editor"></div>
```

光标位于空行时，Tiptap 会自动显示菜单元素并为其定位。

## 与框架搭配使用

### React

`@tiptap/react` 包提供了 `FloatingMenu` 组件，可从 `@tiptap/react/menus` 导入。它提供与该扩展相同的功能，同时采用适合 React 的 API。使用此组件时，无需将 `FloatingMenu` 扩展添加到编辑器中。

```jsx
import { FloatingMenu } from '@tiptap/react/menus'

function MyFloatingMenu({ editor }) {
  return (
    <FloatingMenu editor={editor}>
      <button onClick={() => editor.chain().focus().setHeading({ level: 1 }).run()}>
        H1
      </button>
      <button onClick={() => editor.chain().focus().setBulletList().run()}>
        List
      </button>
    </FloatingMenu>
  )
}
```

### Vue

`@tiptap/vue-3` 包提供了 `FloatingMenu` 组件，可从 `@tiptap/vue-3/menus` 导入。它提供与该扩展相同的功能，同时采用适合 Vue 的 API。使用此组件时，无需将 `FloatingMenu` 扩展添加到编辑器中。

```vue
<template>
  <FloatingMenu :editor="editor">
    <button @click="editor.chain().focus().setHeading({ level: 1 }).run()">
      H1
    </button>
    <button @click="editor.chain().focus().setBulletList().run()">
      List
    </button>
  </FloatingMenu>
</template>

<script setup>
  import { FloatingMenu } from '@tiptap/vue-3/menus'

  // 请确保将 editor 实例作为 prop 传递给 FloatingMenu 组件
  const { editor } = defineProps({
    editor: {
      type: Object,
      required: true,
    },
  })
</script>
```

**注意**：Tiptap 的 Vue 2 版本也提供相同的菜单，可从 `@tiptap/vue-2/menus` 导入。

### 自定义逻辑

使用 `shouldShow` 选项自定义菜单的显示逻辑。对于组件，可以将 `shouldShow` 作为 prop 传入。

```js
FloatingMenu.configure({
  shouldShow: ({ editor, view, state, oldState }) => {
    // 在任意段落中显示浮动菜单
    return editor.isActive('paragraph')
  },
})
```

### 多个菜单

设置不同的 `pluginKey`，即可使用多个菜单。

```js
import { Editor } from '@tiptap/core'
import FloatingMenu from '@tiptap/extension-floating-menu'

new Editor({
  extensions: [
    FloatingMenu.configure({
      pluginKey: 'floatingMenuOne',
      element: document.querySelector('.menu-one'),
    }),
    FloatingMenu.configure({
      pluginKey: 'floatingMenuTwo',
      element: document.querySelector('.menu-two'),
    }),
  ],
})
```

也可以传入 ProseMirror 的 `PluginKey`。

```js
import { Editor } from '@tiptap/core'
import FloatingMenu from '@tiptap/extension-floating-menu'
import { PluginKey } from '@tiptap/pm/state'

new Editor({
  extensions: [
    FloatingMenu.configure({
      pluginKey: new PluginKey('floatingMenuOne'),
      element: document.querySelector('.menu-one'),
    }),
    FloatingMenu.configure({
      pluginKey: new PluginKey('floatingMenuOne'),
      element: document.querySelector('.menu-two'),
    }),
  ],
})
```

### 强制更新浮动菜单的位置

如果浮动菜单在初始渲染后改变了大小，其位置不会自动调整。要解决此问题，可以在扩展上设置 `pluginKey`，并使用该键触发 `'updatePosition'` 事件，强制更新位置。

```ts
FloatingMenu.configure({
  pluginKey: 'myFloatingMenu',
  element: document.querySelector('.menu'),
})

editor.commands.setMeta('myFloatingMenu', 'updatePosition')
```

若要指定某个浮动菜单，请通过事务元数据触发 `'updatePosition'` 事件，并使用该菜单的 `pluginKey`：

```ts
FloatingMenu.configure({
  pluginKey: 'myFloatingMenu',
  element: document.querySelector('.menu'),
})
```

例如，如果有多个浮动菜单：

```ts
editor.commands.setMeta('floatingMenuOne', 'updatePosition')
```

如果你使用 React 或 Vue 的 `FloatingMenu` 组件，并希望从外部触发 `updatePosition`，请先向组件传入显式的 `pluginKey` prop。如果省略 `pluginKey`，组件会创建自己的 ProseMirror `PluginKey`，外部代码之后将无法可靠地引用它。

### 以编程方式显示或隐藏浮动菜单

你可以在扩展上设置 `pluginKey`，并使用该键分发包含 `'show'` 或 `'hide'` 元值的事务，以编程方式显示或隐藏浮动菜单。

```ts
// 显示浮动菜单
editor.commands.setMeta('myFloatingMenu', 'show')

// 隐藏浮动菜单
editor.commands.setMeta('myFloatingMenu', 'hide')
```

**注意：**分发 `'show'` 或 `'hide'` 会覆盖 `shouldShow` 中定义的行为。
