当编辑器失去焦点时，Selection 扩展会为当前选区添加一个 CSS 类。默认添加 `.selection`，但你可以更改它。

请注意，它只是一个类，具体样式完全由你决定。下面的用法示例包含了该类的一些 CSS 样式。

<CodeDemo path="/Extensions/Selection" />

## 安装

```bash
npm install @tiptap/extensions
```

然后在编辑器中导入：

```ts
import { Editor } from '@tiptap/core'
import { Selection } from '@tiptap/extensions'

new Editor({
  extensions: [Selection],
})
```

## 设置

### className

应用于当前选区的类名。

默认值：`'selection'`

```js
Selection.configure({
  className: 'selection',
})
```
