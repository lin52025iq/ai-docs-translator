你是否曾想过在基于 React 的编辑器中拖动节点？我们也有过这个想法，因此推出了这个扩展。

`DragHandleReact` 组件让你可以轻松处理在编辑器中拖动节点的操作。你可以定义自定义渲染函数、位置等。
它本质上是将 [DragHandle](/editor/extensions/functionality/drag-handle) 扩展封装在 React 组件中，并自动在编辑器中注册或注销该扩展。

## 安装

```bash
npm install @tiptap/extension-drag-handle-react @tiptap/extension-drag-handle @tiptap/extension-node-range @tiptap/extension-collaboration @tiptap/y-tiptap yjs y-protocols
```

## Props

所有 props 的结构都与 [DragHandle](/editor/extensions/functionality/drag-handle) 扩展相同。

### children

要显示在拖动手柄内部的内容。

```jsx
<DragHandle>
  <div>Drag Me!</div>
</DragHandle>
```

### computePositionConfig

使用 floating-ui/dom 包配置拖动手柄的位置计算。你可以传入 [floating-ui 文档](https://floating-ui.com/docs/computePosition)中提供的任意选项。

默认值：`{ placement: 'left-start', strategy: 'absolute' }`

```jsx
<DragHandle
  computePositionConfig={{
    placement: 'left',
    strategy: 'fixed',
  }}
>
  <div>Drag Me!</div>
</DragHandle>
```

### onNodeChange

当鼠标悬停在某个节点上时，返回该节点或 null。你可以用它突出显示当前悬停的节点。

默认值：`undefined`

```jsx
function Component() {
  const [selectedNode, setSelectedNode] = useState(null)

  return (
    <DragHandle
      onNodeChange={({ node, editor, pos }) => {
        setSelectedNode(node)
        // do something with the node
      }}
    >
      <div>Drag Me!</div>
    </DragHandle>
  )
}
```

### getReferencedVirtualElement

用于返回拖动手柄虚拟元素的函数。当菜单需要相对于特定 DOM 元素定位时，这很有用。

默认值：`undefined`

```jsx
<DragHandle
  getReferencedVirtualElement={() => {
    // Return a virtual element for custom positioning
    return null
  }}
>
  <div>Drag Me!</div>
</DragHandle>
```

### locked

锁定拖动手柄的位置和可见状态。如果拖动手柄当前可见，则在解除锁定前会一直显示；如果当前隐藏，则在解除锁定前会一直隐藏。

默认值：`false`

```jsx
<DragHandle locked={true}>
  <div>Drag Me!</div>
</DragHandle>
```

### pluginKey

用于在编辑器中存储插件的键。如果同一个编辑器中有多个拖动手柄，这个选项会很有用。

默认值：`undefined`

```jsx
<DragHandle pluginKey="myCustomDragHandle">
  <div>Drag Me!</div>
</DragHandle>
```

### onElementDragStart

元素开始拖动时调用的函数。你可以用它在拖动开始时添加自定义逻辑。

```jsx
<DragHandle
  onElementDragStart={(e: DragEvent) => {
    // do something when dragging starts
  }}
>
  <div>Drag Me!</div>
</DragHandle>
```

### onElementDragEnd

元素停止拖动时调用的函数。你可以用它在拖动结束时添加自定义逻辑。

```jsx
<DragHandle
  onElementDragEnd={(e: DragEvent) => {
    // do something when dragging ends
  }}
>
  <div>Drag Me!</div>
</DragHandle>
```

### nested

为列表项、引用块及其他嵌套结构等嵌套内容启用拖动手柄。

启用后，拖动手柄会显示在嵌套区块上，而不仅限于顶层区块。系统会根据光标位置和已配置的规则，使用基于规则的评分机制来确定目标节点。

默认值：`false`

```jsx
// Enable with defaults
<DragHandle nested={true}>
  <div>Drag Me!</div>
</DragHandle>

// Enable with custom edge detection
<DragHandle nested={{ edgeDetection: { threshold: -16 } }}>
  <div>Drag Me!</div>
</DragHandle>
```

#### 嵌套支持完整示例

```jsx
import DragHandle from '@tiptap/extension-drag-handle-react'
import { EditorContent, useEditor } from '@tiptap/react'
import StarterKit from '@tiptap/starter-kit'
import { useState } from 'react'

const NESTED_CONFIG = { edgeDetection: { threshold: -16 } }

export default function Editor() {
  const [nested, setNested] = useState(true)

  const editor = useEditor({
    extensions: [StarterKit],
    content: '<ul><li>Item 1</li><li>Item 2</li></ul>',
  })

  return (
    <>
      <button onClick={() => setNested(!nested)}>
        Toggle nested
      </button>
      <DragHandle editor={editor} nested={nested ? NESTED_CONFIG : false}>
        <div className="drag-handle" />
      </DragHandle>
      <EditorContent editor={editor} />
    </>
  )
}
```

<Callout title="性能提示" variant="info">
  使用 React 状态切换 `nested` prop 时，请在组件外将配置对象定义为常量，以避免不必要的重新渲染。
</Callout>

有关边缘检测、自定义规则和允许的容器等详细配置选项，请参阅 [DragHandle 嵌套文档](/editor/extensions/functionality/drag-handle#nested-drag-handle)。
