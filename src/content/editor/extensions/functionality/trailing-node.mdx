此扩展会在编辑器中最后一个块节点后添加一个节点。这适用于添加占位符或按钮等尾随节点。

<CodeDemo path="/Extensions/TrailingNode" />

## 安装

```bash
npm install @tiptap/extensions
```

## 用法

```js
import { Editor } from '@tiptap/core'
import { TrailingNode } from '@tiptap/extensions'

new Editor({
  extensions: [TrailingNode],
})
```

## 设置

### node

要在文档末尾插入的节点类型。如果未设置，Trailing Node 会从 ProseMirror schema 中获取其定义的备用节点（通常是默认块节点）；你也可以通过 `node` 选项覆盖此行为。自定义文档结构时，这一点尤为重要——请参阅[强制内容结构示例](/examples/advanced/forced-content-structure)，了解自定义文档可能如何影响默认备用节点。

默认值：`undefined`

```js
TrailingNode.configure({
  node: 'paragraph',
})
```

### notAfter

尾随节点不应插入其后的节点类型。

默认值：`['paragraph']`

```js
TrailingNode.configure({
  node: 'paragraph',
  notAfter: ['heading', 'blockquote'],
})
```

## 在事务中跳过尾随节点的创建

你可以在特定事务上设置 `skipTrailingNode` 元数据标志，以跳过自动插入尾随节点。

```ts
editor
  .chain()
  .command(({ tr }) => {
    tr.setMeta('skipTrailingNode', true)

    return true
  })
  .run()
```

如果你希望事务有意让文档不包含额外的尾随节点，这会很有用。
