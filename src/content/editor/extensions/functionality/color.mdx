此扩展支持在编辑器中设置字体颜色。它使用 [`TextStyle`](/editor/extensions/marks/text-style) 标记，该标记会渲染为 `<span>` 标签（且仅渲染为该标签）。字体颜色随后会以内联样式应用，例如 `<span style="color: #958DF1">`。

<CodeDemo path="/Extensions/Color" />

## 安装

```bash
npm install @tiptap/extension-text-style
```

此扩展需要 [`TextStyle`](/editor/extensions/marks/text-style) 标记。

```ts
import { Editor } from '@tiptap/core'
import { TextStyle, Color } from '@tiptap/extension-text-style'

new Editor({
  extensions: [TextStyle, Color],
})
```

此扩展默认随 `TextStyleKit` 扩展一起安装，因此无需单独安装。

```ts
import { Editor } from '@tiptap/core'
import { TextStyleKit } from '@tiptap/extension-text-style'

new Editor({
  extensions: [TextStyleKit],
})
```

## 设置

### types

需要应用颜色属性的标记列表。

默认值：`['textStyle']`

```js
Color.configure({
  types: ['textStyle'],
})
```

## 命令

### setColor()

将指定的字体颜色以内联样式应用。

```js
editor.commands.setColor('#ff0000')
```

### unsetColor()

移除字体颜色。

```js
editor.commands.unsetColor()
```
