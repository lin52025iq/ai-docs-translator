List Keymap 扩展会修改 ProseMirror 和 Tiptap 的默认行为。未使用此扩展时，在列表项开头按退格键，列表项内容会保留在同一行。使用 List Keymap 后，内容会提升到上方的列表项中。

<CodeDemo path="/Extensions/ListKeymap" />

## 安装

```bash
npm install @tiptap/extension-list
```

然后在编辑器中导入：

```ts
import { Editor } from '@tiptap/core'
import { ListKeymap } from '@tiptap/extension-list'

new Editor({
  extensions: [ListKeymap],
})
```

此扩展默认随 `ListKit` 扩展一起安装，因此无需单独安装。

```ts
import { Editor } from '@tiptap/core'
import { ListKit } from '@tiptap/extension-list'

new Editor({
  extensions: [ListKit],
})
```

## 设置

### listTypes

由列表项及其父级包装节点类型组成的数组。

```js
ListKeymap.configure({
  listTypes: [
    {
      itemName: 'taskItem',
      wrapperNames: ['customTaskList'],
    },
  ],
})
```

默认值：

```json
[
  {
    "itemName": "listItem",
    "wrapperNames": ["bulletList", "orderedList"]
  },
  {
    "itemName": "taskItem",
    "wrapperNames": ["taskList"]
  }
]
```
