Tracked Changes 扩展可为协作编辑工作流启用建议模式。启用后，所有编辑都会显示为可接受或拒绝的提议，类似文字处理软件中的修订跟踪。

<Callout title="了解详情" variant="hint">
  如需了解有关集成、安装和配置 Tiptap Tracked Changes 扩展的更多信息，请访问我们的[功能介绍页面](/tracked-changes/getting-started/overview)。
</Callout>

## 安装

```bash
npm install @tiptap-pro/extension-tracked-changes
```

## 基本设置

```js
import { Editor } from '@tiptap/core'
import { TrackedChanges } from '@tiptap-pro/extension-tracked-changes'

const editor = new Editor({
  extensions: [
    TrackedChanges.configure({
      enabled: true,
      userId: 'user-123',
      userMetadata: { name: 'John Doe' },
    }),
  ],
})
```

## 以编程方式创建建议

除了交互式审阅工作流外，此扩展还提供了一些命令，可直接通过应用逻辑创建修订建议。如果需要以建议的形式插入、删除或替换内容，而不希望在每次编辑器交互时都开启修订跟踪模式，可以使用这些命令。您还可以为以编程方式创建的建议附加 `reason`，该字段会随创建事件一同发出，供后续工作流使用。插入和替换命令接受完整的 Tiptap `Content`，因此不仅可以处理纯文本，也可以处理图像等 JSON 节点。修订标记命令支持简单的格式标记（如 `bold`），也支持带属性的标记（如 `link` 或 `highlight`）。

如果您也使用 [TrailingNode](/editor/extensions/functionality/trailing-node) 扩展，`addTrackedInsertion()` 和 `addTrackedReplacement()` 可以设置 `skipTrailingNode: true`，将该事务元数据传递到发出的修订跟踪事务中。

```js
editor.commands.addTrackedInsertion({
  from: 7,
  content: 'big ',
  reason: 'Applied assistant suggestion',
})

editor.commands.addTrackedDeletion({
  from: 7,
  to: 12,
  reason: 'Removed deprecated sentence',
})

editor.commands.addTrackedReplacement({
  from: 7,
  to: 12,
  content: 'earth',
  reason: 'Standardized terminology',
  skipTrailingNode: true,
})

editor.commands.addTrackedMark({
  from: 7,
  to: 12,
  markName: 'bold',
  reason: 'Emphasized approved terminology',
})

editor.commands.toggleTrackedMark({
  from: 7,
  to: 12,
  markName: 'link',
  markAttrs: {
    href: 'https://tiptap.dev',
    target: '_blank',
  },
  reason: 'Added canonical reference',
})
```

```js
editor.commands.addTrackedInsertion({
  from: 7,
  content: {
    type: 'image',
    attrs: {
      src: '/example.png',
      alt: 'Example image',
    },
  },
  reason: 'Inserted approved image asset',
})
```

完整 API 请参阅[命令参考](/tracked-changes/api-reference/commands)。
