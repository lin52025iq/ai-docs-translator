此扩展加载由 Marijn Haverbeke 开发的 [ProseMirror Dropcursor 插件](https://github.com/ProseMirror/prosemirror-dropcursor)。当内容被拖入编辑器时，该插件会在放置位置显示光标。

请注意，Tiptap 是无头的，但拖放光标需要 CSS 才能显示。你可以设置颜色和宽度，也可以添加自定义 CSS 类。

<CodeDemo path="/Extensions/Dropcursor" />

## 安装

```bash
npm install @tiptap/extensions
```

## 用法

```js
import { Editor } from '@tiptap/core'
import { Dropcursor } from '@tiptap/extensions'

new Editor({
  extensions: [Dropcursor],
})
```

## 设置

### color

拖放光标的颜色。

默认值：`'currentColor'`

```js
Dropcursor.configure({
  color: '#ff0000',
})
```

### width

拖放光标的宽度。

默认值：`1`

```js
Dropcursor.configure({
  width: 2,
})
```

### class

要应用于拖放光标的一个或多个 CSS 类。

```js
Dropcursor.configure({
  class: 'my-custom-class',
})
```
