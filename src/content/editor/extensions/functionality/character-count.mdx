`CharacterCount` 扩展可以将允许输入的字符数限制在指定长度，并返回字符数和单词数。就是这样，没别的了。

<CodeDemo path="/Extensions/CharacterCount" />

## 安装

```bash
npm install @tiptap/extensions
```

## 用法

```js
import { Editor } from '@tiptap/core'
import { CharacterCount } from '@tiptap/extensions'

new Editor({
  extensions: [CharacterCount],
})
```

## 设置

### limit

允许的最大字符数。

默认值：`null`

```js
CharacterCount.configure({
  limit: 240,
})
```

### autoTrim

设置通过编程方式设置的内容超过限制时，是否自动截断内容。如果设为 `false`，则不会自动截断内容，你可以手动处理超出的部分。

默认值：`true`

```js
CharacterCount.configure({
  limit: 240,
  autoTrim: false,
})
```

### mode

用于计算长度的模式。

默认值：`'textSize'`

```js
CharacterCount.configure({
  mode: 'nodeSize',
})
```

### autoTrim

控制初始内容超出配置的限制时是否自动截断。设为 `false` 时，会保留超出限制的初始内容。当文档仍超出限制时，会阻止增加内容大小的事务。

默认值：`true`

```js
CharacterCount.configure({
  limit: 280,
  autoTrim: false, // Preserve initial content over the limit
})
```

### textCounter

要使用的文本计数函数。默认情况下，只进行简单的字符计数。

默认值：`(text) => text.length`

```js
CharacterCount.configure({
  textCounter: (text) => [...new Intl.Segmenter().segment(text)].length,
})
```

### wordCounter

要使用的单词计数函数。默认情况下，只进行简单的单词计数。

默认值：`(text) => text.split(' ').filter((word) => word !== '').length`

```js
CharacterCount.configure({
  wordCounter: (text) => text.split(/\s+/).filter((word) => word !== '').length,
})
```

## 存储

### characters()

获取当前文档的字符数。

```js
editor.storage.characterCount.characters()

// Get the size of a specific node.
editor.storage.characterCount.characters({ node: someCustomNode })

// Overwrite the default `mode`.
editor.storage.characterCount.characters({ mode: 'nodeSize' })
```

### words()

获取当前文档的单词数。

```js
editor.storage.characterCount.words()

// Get the number of words for a specific node.
editor.storage.characterCount.words({ node: someCustomNode })
```
