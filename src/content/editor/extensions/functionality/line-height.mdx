此扩展可让你在编辑器中设置*行高*。它使用 [`TextStyle`](/editor/extensions/marks/text-style) 标记，该标记会渲染 `<span>` 标签（且只会渲染该标签）。行高随后会以内联样式应用，例如 `<span style="line-height: 1.5">`。

<CodeDemo path="/Extensions/LineHeight" />

## 安装

```bash
npm install @tiptap/extension-text-style
```

此扩展需要 [`TextStyle`](/editor/extensions/marks/text-style) 标记。

```ts
import { Editor } from '@tiptap/core'
import { TextStyle, LineHeight } from '@tiptap/extension-text-style'

new Editor({
  extensions: [TextStyle, LineHeight],
})
```

此扩展默认随 `TextStyleKit` 扩展一同安装，因此无需单独安装。

```ts
import { Editor } from '@tiptap/core'
import { TextStyleKit } from '@tiptap/extension-text-style'

new Editor({
  extensions: [TextStyleKit],
})
```

## 设置

### types

指定要应用 lineHeight 属性的标记列表。

默认值：`['textStyle']`

```js
LineHeight.configure({
  types: ['textStyle'],
})
```

## 命令

### setLineHeight()

以内联样式应用指定的行高。

```js
editor.commands.setLineHeight('1.1')
```

### unsetLineHeight()

移除所有行高设置。

```js
editor.commands.unsetLineHeight()
```
