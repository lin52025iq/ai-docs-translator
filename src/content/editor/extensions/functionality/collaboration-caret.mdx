此扩展会显示所有已连接用户的信息（例如姓名和指定颜色）、他们当前的光标位置以及文本选区（如果有）。

此扩展需要协同编辑器。请查看 [Tiptap 协作文档](/collaboration/getting-started/overview)，了解完全托管或本地部署的协作服务器解决方案。

## 安装

```bash
npm install @tiptap/extension-collaboration-caret
```

此扩展需要 [`Collaboration`](/collaboration/getting-started/overview) 扩展。

## 设置

### provider

Y.js 网络提供程序，例如 [Tiptap Collaboration](/collaboration/getting-started/overview) 实例。

默认值：`null`

### user

当前用户的属性，默认包含姓名和颜色，但也可以使用任意属性。这些值会与所有其他已连接的客户端同步。

`color` 值必须采用十六进制颜色格式（`#RRGGBB`）。

默认值：`{ user: null, color: null }`

### render

用于渲染光标的函数。示例请参阅[扩展源代码](https://github.com/ueberdosis/tiptap/blob/main/packages/extension-collaboration-caret/)。

### selectionRender

用于渲染选区的函数。示例请参阅[扩展源代码](https://github.com/ueberdosis/tiptap/blob/main/packages/extension-collaboration-caret/)。

## 样式

此扩展不包含默认样式。若不添加以下 CSS，光标将以未设置样式的行内元素形式显示。

将以下样式添加到项目中：

```css
/* Give a remote user a caret */
.tiptap .collaboration-carets__caret {
  border-left: 1px solid #0d0d0d;
  border-right: 1px solid #0d0d0d;
  margin-left: -1px;
  margin-right: -1px;
  pointer-events: none;
  position: relative;
  word-break: normal;
}

/* Render the username above the caret */
.tiptap .collaboration-carets__label {
  border-radius: 3px 3px 3px 0;
  color: #0d0d0d;
  font-size: 12px;
  font-style: normal;
  font-weight: 600;
  left: -1px;
  line-height: normal;
  padding: 0.1rem 0.3rem;
  position: absolute;
  top: -1.4em;
  user-select: none;
  white-space: nowrap;
}
```

## 命令

### updateUser()

传入一个包含当前用户更新后属性的对象。该对象需要包含 `name` 和 `color`，也可以添加其他字段。

```js
editor.commands.updateUser({
  name: 'John Doe',
  color: '#000000',
  avatar: 'https://unavatar.io/github/ueberdosis',
})
```
