此扩展提供占位符支持。通过简短提示，让用户了解应该输入什么内容。你还可以按需自定义多项设置。

<CodeDemo path="/Extensions/Placeholder" />

## 安装

```bash
npm install @tiptap/extensions
```

## 用法

```js
import { Editor } from '@tiptap/core'
import { Placeholder } from '@tiptap/extensions'

new Editor({
  extensions: [
    Placeholder.configure({
      placeholder: 'Write something …',
    }),
  ],
})
```

### 其他设置

占位符通过 CSS 显示。

**仅在空编辑器的第一行显示占位符。**

```
.tiptap p.is-editor-empty:first-child::before {
  color: #adb5bd;
  content: attr(data-placeholder);
  float: left;
  height: 0;
  pointer-events: none;
}
```

**在每个新行显示占位符。**

```
.tiptap p.is-empty::before {
  color: #adb5bd;
  content: attr(data-placeholder);
  float: left;
  height: 0;
  pointer-events: none;
}
```

## 设置

### emptyEditorClass

编辑器为空时添加的 CSS 类。

默认值：`'is-editor-empty'`

```js
Placeholder.configure({
  emptyEditorClass: 'is-editor-empty',
})
```

### emptyNodeClass

节点为空时添加的 CSS 类。

默认值：`'is-empty'`

```js
Placeholder.configure({
  emptyNodeClass: 'my-custom-is-empty-class',
})
```
也可以使用函数，根据节点确定类名：
```js
Placeholder.configure({
  emptyNodeClass: ({ node }) => {
    if (node.type.name === 'heading') {
      return 'my-custom-is-empty-heading-class'
    }
    return ''
  },
})
```

### dataAttribute

用于存储占位符文本的 data 属性。例如，将其设为 `'my-placeholder'` 时，占位符文本会存储在 `data-my-placeholder` 属性中。

默认值：`'placeholder'`

```js
Placeholder.configure({
  dataAttribute: 'my-placeholder'
})
```

### placeholder

作为 `data-placeholder` 属性添加的占位符文本。

默认值：`'Write something …'`

```js
Placeholder.configure({
  placeholder: 'My Custom Placeholder',
})
```

你还可以使用函数，根据节点添加占位符：

```js
Placeholder.configure({
  placeholder: ({ node }) => {
    if (node.type.name === 'heading') {
      return 'What’s the title?'
    }

    return 'Can you add some further context?'
  },
})
```

### showOnlyWhenEditable

仅当编辑器可编辑时显示装饰。

默认值：`true`

```js
Placeholder.configure({
  showOnlyWhenEditable: false,
})
```

### showOnlyCurrent

仅在当前选中的节点中显示装饰。

默认值：`true`

```js
Placeholder.configure({
  showOnlyCurrent: false,
})
```

### includeChildren

也为嵌套节点显示装饰。只有文本块节点（直接包含行内内容的节点，例如 `paragraph` 或 `heading`）会显示占位符；`bulletList` 或 `listItem` 这类包装节点会自动跳过。

默认值：`false`

```js
Placeholder.configure({
  includeChildren: true,
})
```
