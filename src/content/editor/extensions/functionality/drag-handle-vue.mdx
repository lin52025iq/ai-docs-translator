你是否希望在基于 Vue 的编辑器中拖动节点？我们也有同样的需求，因此推出了这个扩展。

`DragHandleVue` 组件让你可以轻松处理编辑器中的节点拖动。你可以定义自定义渲染函数、放置位置等。
它本质上是将 [DragHandle](/editor/extensions/functionality/drag-handle) 扩展封装在一个 Vue 组件中，并自动在编辑器中注册和注销该扩展。

<CodeDemo path="/Extensions/DragHandle?selectedTab=Vue" />

## 安装

```bash
npm install @tiptap/extension-drag-handle-vue-3 @tiptap/extension-drag-handle @tiptap/extension-node-range @tiptap/extension-collaboration @tiptap/y-tiptap yjs y-protocols
```

<Callout title="Vue 2 与 Vue 3" variant="info">
  DragHandle 扩展有两个版本。请确保安装与你的 Vue 版本相对应的版本：`@tiptap/extension-drag-handle-vue-2` 和
  `@tiptap/extension-drag-handle-vue-3`
</Callout>

## Props

所有 props 的结构都与 [DragHandle](/editor/extensions/functionality/drag-handle) 扩展相同。

### children

拖拽手柄内部要显示的内容。

```vue
<drag-handle>
  <div>拖动我！</div>
</drag-handle>
```

### computePositionConfig

使用 floating-ui/dom 包计算拖拽手柄位置时的配置。你可以传入 [floating-ui 文档](https://floating-ui.com/docs/computePosition)中提供的任意选项。

默认值：`{ placement: 'left-start', strategy: 'absolute' }`

```vue
<drag-handle :compute-position-config="{ placement: 'left', strategy: 'fixed' }">
  <div>拖动我！</div>
</drag-handle>
```

### onNodeChange

当鼠标悬停在某个节点上时，返回该节点或 null。你可以借此高亮当前悬停的节点。

默认值：`undefined`

```vue
<template>
  <drag-handle @nodeChange="handleNodeChange">
    <div>拖动我！</div>
  </drag-handle>
</template>

<script>
import { ref } from 'vue'
import { DragHandle } from '@tiptap/extension-drag-handle-vue-3'

export default {
  components: {
    DragHandle,
  },
  setup() {
    const selectedNode = ref(null)

    const handleNodeChange = ({ node, editor, pos }) => {
      selectedNode.value = node
      // 对该节点执行相应操作
    }

    return {
      selectedNode,
      handleNodeChange,
    }
  },
}
</script>
```

### onElementDragStart

元素开始被拖动时调用的函数。你可以在其中添加拖动开始时要执行的自定义逻辑。

签名：`(event: DragEvent) => void`

默认值：`undefined`

```vue
<template>
  <drag-handle @element-drag-start="handleElementDragStart">
    <div>拖动我！</div>
  </drag-handle>
</template>

<script>
import { DragHandle } from '@tiptap/extension-drag-handle-vue-3'

export default {
  components: {
    DragHandle,
  },
  setup() {
    const handleElementDragStart = (event) => {
      // 在拖动开始时执行相应操作
    }

    return {
      handleElementDragStart,
    }
  },
}
</script>
```

### onElementDragEnd

元素停止被拖动时调用的函数。你可以在其中添加拖动结束时要执行的自定义逻辑。

签名：`(event: DragEvent) => void`

默认值：`undefined`

```vue
<template>
  <drag-handle @element-drag-end="handleElementDragEnd">
    <div>拖动我！</div>
  </drag-handle>
</template>

<script>
import { DragHandle } from '@tiptap/extension-drag-handle-vue-3'

export default {
  components: {
    DragHandle,
  },
  setup() {
    const handleElementDragEnd = (event) => {
      // 在拖动结束时执行相应操作
    }

    return {
      handleElementDragEnd,
    }
  },
}
</script>
```

### getReferencedVirtualElement

返回拖拽手柄虚拟元素的函数。当菜单需要相对于特定 DOM 元素定位时，这个函数会很有用。

默认值：`undefined`

```vue
<template>
  <drag-handle :get-referenced-virtual-element="getVirtualElement">
    <div>拖动我！</div>
  </drag-handle>
</template>

<script>
export default {
  setup() {
    const getVirtualElement = () => {
      // 返回用于自定义定位的虚拟元素
      return null
    }

    return {
      getVirtualElement,
    }
  },
}
</script>
```

### locked

锁定拖拽手柄的位置和可见状态。如果拖拽手柄处于可见状态，它会一直保持可见，直到解除锁定；如果处于隐藏状态，它会一直保持隐藏，直到解除锁定。

默认值：`false`

```vue
<drag-handle :locked="true">
  <div>拖动我！</div>
</drag-handle>
```

### pluginKey

用于在编辑器中存储插件的键。如果同一个编辑器中有多个拖拽手柄，这个选项会很有用。

默认值：`undefined`

```vue
<drag-handle pluginKey="myCustomDragHandle">
  <div>拖动我！</div>
</drag-handle>
```

### nested

为列表项、引用块等嵌套结构启用拖拽手柄。

启用后，拖拽手柄会出现在嵌套块上，而不仅仅是顶层块。系统会根据光标位置和已配置的规则进行规则评分，确定要操作的节点。

默认值：`false`

<Callout title="避免重新渲染" variant="warning">
  将对象传给 `nested` prop 时，务必在组件外将其定义为常量。内联对象或在计算属性中创建的对象会导致插件在每次渲染周期中重新初始化，从而影响性能。
</Callout>

```vue
<template>
  <drag-handle :editor="editor" :nested="NESTED_CONFIG">
    <div>拖动我！</div>
  </drag-handle>
</template>

<script>
import { DragHandle } from '@tiptap/extension-drag-handle-vue-3'

// 在组件外将配置定义为常量
const NESTED_CONFIG = { edgeDetection: { threshold: -16 } }

export default {
  components: { DragHandle },
  data() {
    return {
      // 将常量提供给模板使用
      NESTED_CONFIG,
    }
  },
}
</script>
```

如果只需通过布尔值启用，而无需自定义配置：

```vue
<drag-handle :nested="true">
  <div>拖动我！</div>
</drag-handle>
```

#### 支持切换的完整示例

```vue
<template>
  <div v-if="editor">
    <button @click="nested = !nested">切换嵌套</button>
    <drag-handle :editor="editor" :nested="nestedOptions">
      <div class="drag-handle" />
    </drag-handle>
  </div>
  <editor-content :editor="editor" />
</template>

<script>
import { DragHandle } from '@tiptap/extension-drag-handle-vue-3'
import StarterKit from '@tiptap/starter-kit'
import { Editor, EditorContent } from '@tiptap/vue-3'

// 在组件外将配置定义为常量，避免重新渲染
const NESTED_CONFIG = { edgeDetection: { threshold: -16 } }

export default {
  components: {
    EditorContent,
    DragHandle,
  },
  data() {
    return {
      editor: null,
      nested: true,
    }
  },
  computed: {
    nestedOptions() {
      // 返回常量引用，而不是新对象
      return this.nested ? NESTED_CONFIG : false
    },
  },
  mounted() {
    this.editor = new Editor({
      extensions: [StarterKit],
      content: '<ul><li>项目 1</li><li>项目 2</li></ul>',
    })
  },
  beforeUnmount() {
    this.editor?.destroy()
  },
}
</script>
```

有关边缘检测、自定义规则和允许的容器等详细配置选项，请参阅 [DragHandle 嵌套文档](/editor/extensions/functionality/drag-handle#nested-drag-handle)。
