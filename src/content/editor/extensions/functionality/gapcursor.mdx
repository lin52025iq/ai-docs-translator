此扩展会加载 Marijn Haverbeke 编写的 [ProseMirror Gapcursor 插件](https://github.com/ProseMirror/prosemirror-gapcursor)，该插件可以在不允许常规选区的位置为光标创建一个间隙。例如，文档末尾的表格之后。

请注意，Tiptap 是无头的，但 Gapcursor 需要 CSS 来设置外观。[默认 CSS](https://github.com/ueberdosis/tiptap/tree/main/packages/core/src/style.ts) 会通过 Editor 类加载。

<CodeDemo path="/Extensions/Gapcursor" />

## 安装

```bash
npm install @tiptap/extensions
```

## 用法

```js
import { Editor } from '@tiptap/core'
import { Gapcursor } from '@tiptap/extensions'

new Editor({
  extensions: [Gapcursor],
})
```

```js
import { Editor } from '@tiptap/core'
import { Gapcursor } from '@tiptap/extensions/gapcursor'

new Editor({
  extensions: [Gapcursor],
})
```
