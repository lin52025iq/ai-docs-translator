`TableOfContents` 扩展可以从文档中获取锚点列表，并提供每个锚点的重要信息（例如深度、内容和每个标题的唯一 ID，以及每个锚点的激活状态和滚动状态）。你可以利用这些信息自行渲染目录。

<CodeDemo path="/Extensions/TableOfContents" />

## 安装

完成后，即可安装此扩展：

```bash
npm install @tiptap/extension-table-of-contents
```

## 配置

### anchorTypes

指定要用于目录的节点类型。默认值为 `["heading"]`。如果你创建了自定义的 Heading 扩展，或扩展了现有扩展并使用了不同的名称，可以在此处传入该名称。

默认值：`["heading"]`

```js
TableOfContents.configure({
  anchorTypes: ['heading', 'customAnchorType'],
})
```

### getIndex

此选项可用于自定义目录项索引的计算方式。默认情况下会使用内部函数，但你可以覆盖它，实现自定义逻辑。

```js
TableOfContents.configure({
  getIndex: (anchor, previousAnchors, level) => {
    // do some custom logic, but for this example we will just return 1
    return 1
  },
})
```

我们提供了两个可直接使用的函数：一个生成从 1 到 n 递增的线性索引，另一个生成分层索引，并在每个层级内从 1 到 n 计数。

```js
import { getLinearIndexes, getHierarchicalIndexes } from '@tiptap/extension-table-of-contents'

// generate linear indexes
TableOfContents.configure({
  getIndex: getLinearIndexes,
})

// generate hierarchical indexes
TableOfContents.configure({
  getIndex: getHierarchicalIndexes,
})
```

### getLevel

此选项可用于自定义目录项层级的生成方式。默认情况下，系统会检查标题元素的 level 属性来生成层级。如果你想自定义此行为，例如在标题生成过程中包含自定义锚点，可以使用此选项。

```js
TableOfContents.configure({
  getLevel: (anchor, previousAnchors) => {
    // do some custom logic, but for this example we will just return 1
    return 1
  },
})
```

### getId

用于为每个标题返回唯一 ID 的构造函数。参数中可以访问标题的文本内容（例如，你可以根据标题文本生成 ID）。

默认情况下，此函数会使用 [uuid](https://www.npmjs.com/package/uuid) 包生成唯一 ID。

默认值：`() => uuid()`

```js
// here we use an imaginary "slugify" function
// you should probably also add a unique identifier to the slug
TableOfContents.configure({
  getId: (content) => slugify(content),
})
```

### scrollParent

指定要附加到的滚动父级。此选项用于确定当前激活的标题，或已经滚动经过的标题。默认情况下，这是一个返回 window 的回调函数；你也可以传入一个返回任意 HTML 元素的回调函数。

默认值：`() => window`

```js
// For example the editors DOM element itself is the scrolling element
TableOfContents.configure({
  scrollParent: () => editor.view.dom,
})
```

### onUpdate

使用此扩展时必须设置的最重要选项。它是一个回调函数，每当目录更新时都会调用。你可以获取一个标题数据数组（见下文），并用它来渲染自己的目录。

你可以采用任意方式渲染目录。可以使用 Vue、React 或 Svelte 等框架，也可以使用 Handlebars 或 Pug 等简单模板引擎，还可以直接使用 `document.createElement` 来渲染目录。

你可以传入第二个参数，以了解当前是否是目录数据的初始创建阶段。

默认值：`undefined`

```js
// with vanilla JS
const tocElement = document.createElement('div')
document.body.appendChild(tocElement)

TableOfContents.configure({
  onUpdate: (anchors, isCreate) => {
    tocElement.innerHTML = ''

    if (isCreate) {
      console.log('This is the inital creation step for the ToC data')
    }

    anchors.forEach((anchor) => {
      const anchorElement = document.createElement('div')

      anchorElement.innerHTML = anchor.content
      anchorElement.dataset.id = anchor.id
      anchorElement.dataset.depth = anchor.depth
      anchorElement.dataset.active = anchor.active
      anchorElement.dataset.scrolled = anchor.scrolled

      tocElement.appendChild(anchorElement)
    })
  },
})
```

```js
// with react
const [anchors, setAnchors] = useState([])

// inside the useEditor hook you could then do something like that:
TableOfContents.configure({
  onUpdate: (anchors) => {
    setAnchors(anchors)
  },
})
```

```js
// with vue
const anchors = ref([])

TableOfContents.configure({
  onUpdate: (anchors) => {
    anchors.value = anchors
  },
})
```

## 存储

### content

当前文档的标题内容

```js
editor.storage.tableOfContents.content
```

### anchors

HTML 节点数组

```js
editor.storage.tableOfContents.anchors
```

### scrollHandler

滚动函数使用的 scrollHandler。请勿更改或编辑，但可以将此函数手动绑定到其他位置。

```js
editor.storage.tableOfContents.scrollHandler()
```

### scrollPosition

scrollParent 中的当前位置。

```js
editor.storage.tableOfContents.scrollPosition
```

## anchors 数组

存储或 `onUpdate` 函数返回的数组包含如下结构的对象：

```js
{
  dom: HTMLElement // the HTML element for this anchor
  editor: Editor // the editor
  id: string // the node id
  isActive: boolean // whether this anchor is currently active
  isScrolledOver: boolean // whether this anchor was already scrolled over
  itemIndex: number // the index of the item on its current level
  level: number // the current level of the item - this could be different from the actual anchor level and is used to render the hierarchy from high to low headlines
  node: Node // the ProseMirror node for this anchor
  originalLevel: number // the actual level
  pos: number // the position of the anchor node
  textContent: string // the text content of the anchor
}
```

这些信息应能让你灵活地渲染自己的目录。

## 服务端锚点 ID 工具函数

`generateTocIds` 函数可以在服务端为 Tiptap 文档分配锚点 ID（`id` 和 `data-toc-id`），而无需创建 `Editor` 实例。当你想要静态渲染文档（例如使用 `@tiptap/static-renderer`），同时又希望获得与实时编辑器中的 `TableOfContents` 插件生成的相同锚点属性时，这个函数就很有用。

### 参数

- **`doc`**（`JSONContent`）：要添加锚点 ID 的 Tiptap JSON 文档
- **`extensions`**（`Extensions`）：要使用的扩展。必须包含 `TableOfContents` 扩展。若要自定义 ID 的生成方式或指定哪些节点类型作为锚点，请向 `TableOfContents` 扩展传入 `getId` 或 `anchorTypes` 等选项。

### 返回类型

返回一个新的 Tiptap 文档（`JSONContent` 对象），并为缺少 ID 或存在重复 ID 的锚点类型节点分配 `id` 和 `data-toc-id` 属性。

### 示例

```js
import { generateTocIds, TableOfContents } from '@tiptap/extension-table-of-contents'
import { StarterKit } from '@tiptap/starter-kit'

const doc = {
  type: 'doc',
  content: [
    { type: 'heading', attrs: { level: 1 }, content: [{ type: 'text', text: 'Introduction' }] },
    { type: 'paragraph', content: [{ type: 'text', text: 'A paragraph.' }] },
    { type: 'heading', attrs: { level: 2 }, content: [{ type: 'text', text: 'Details' }] },
  ],
}

const newDoc = generateTocIds(doc, [StarterKit, TableOfContents])

// Result:
// {
//   type: 'doc',
//   content: [
//     { type: 'heading', attrs: { level: 1, id: 'd4590f81-52e8-45ec-b317-2e9a805b03e3', 'data-toc-id': 'd4590f81-52e8-45ec-b317-2e9a805b03e3' }, content: [...] },
//     { type: 'paragraph', content: [...] },
//     { type: 'heading', attrs: { level: 2, id: 'c88f9b5f-7b91-442f-b4d9-ee0d04104827', 'data-toc-id': 'c88f9b5f-7b91-442f-b4d9-ee0d04104827' }, content: [...] }
//   ]
// }
```

此函数会自动读取 `TableOfContents` 扩展的配置，包括 `anchorTypes` 和 `getId`。
