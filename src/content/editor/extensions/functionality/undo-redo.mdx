此扩展提供撤销和重做功能。文档中的所有更改都会被跟踪，并且可以使用 `undo` 撤销。已撤销的更改可以再次使用 `redo` 应用。

只有在不打算让编辑器支持协作时，才应集成此扩展。协作扩展有自己的撤销/重做功能，因为通常人们不希望撤销他人所做的更改。

## 安装

```bash
npm install @tiptap/extensions
```

## 用法

```js
import { Editor } from '@tiptap/core'
import { UndoRedo } from '@tiptap/extensions'

new Editor({
  extensions: [UndoRedo],
})
```

## 设置

### depth

保留的历史记录事件数量。超过此数量后，最早的事件将被丢弃。

默认值：`100`

```js
UndoRedo.configure({
  depth: 10,
})
```

### newGroupDelay

两次更改之间的延迟时间（毫秒）；超过此时间后会开始一个新分组。如果更改不连续，则始终会开始一个新分组。

默认值：`500`

```js
UndoRedo.configure({
  newGroupDelay: 1000,
})
```

## 命令

### undo()

撤销上一次更改。

```js
editor.commands.undo()
```

### redo()

重做上一次更改。

```js
editor.commands.redo()
```
