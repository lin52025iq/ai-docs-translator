使用 CodeBlockLowlight 扩展，可以在文档中添加围栏代码块。它会使用 `<pre>` 和 `<code>` HTML 标签包裹代码。

<Callout title="语法高亮依赖项" variant="warning">
  此扩展依赖 [lowlight](https://github.com/wooorm/lowlight) 库，为代码块中的内容应用
  语法高亮。
</Callout>

输入 <code>&grave;&grave;&grave; </code>（三个反引号和一个空格）或 <code>&Tilde;&Tilde;&Tilde; </code>（三个波浪号和一个空格），即可立即插入代码块。你还可以指定语言，试着输入 <code>&grave;&grave;&grave;css </code>。这样会为 `<code>` 标签添加 `language-css` 类。

## 安装

```bash
npm install lowlight @tiptap/extension-code-block-lowlight
```

## 设置

### lowlight

你需要向此扩展提供 `lowlight` 模块。将 `lowlight`
包与扩展解耦后，客户端应用便可以控制所使用的 lowlight 版本，以及需要加载的编程语言包。

```js
import { lowlight } from 'lowlight/lib/core'

CodeBlockLowlight.configure({
  lowlight,
})
```

### HTMLAttributes

要添加到渲染后 HTML 标签中的自定义 HTML 属性。

```js
CodeBlockLowlight.configure({
  HTMLAttributes: {
    class: 'my-custom-class',
  },
})
```

### enableTabIndentation

启用在代码块中使用 Tab 键缩进。

默认值：`false`

```js
CodeBlockLowlight.configure({
  enableTabIndentation: true,
})
```

### tabSize

Tab 缩进所使用的空格数。

默认值：`4`

```js
CodeBlockLowlight.configure({
  tabSize: 2,
})
```

### languageClassPrefix

为应用于代码标签的语言类添加前缀。

默认值：`'language-'`

```js
CodeBlockLowlight.configure({
  languageClassPrefix: 'language-',
})
```

### defaultLanguage

设置默认语言，而不是由 lowlight 自动检测语言。

默认值：`null`

```js
CodeBlockLowlight.configure({
  defaultLanguage: 'plaintext',
})
```

## 命令

### setCodeBlock()

将内容包裹在代码块中。

```js
editor.commands.setCodeBlock()
```

### toggleCodeBlock()

切换代码块。

```js
editor.commands.toggleCodeBlock()
```
