## 安装

```bash
npm install @tiptap/extension-paragraph
```

## 设置

### HTMLAttributes

要添加到渲染后 HTML 标签上的自定义 HTML 属性。

```js
Paragraph.configure({
  HTMLAttributes: {
    class: 'my-custom-class',
  },
})
```

## 命令

### setParagraph()

将所有选中的节点转换为段落。

```js
editor.commands.setParagraph()
```
