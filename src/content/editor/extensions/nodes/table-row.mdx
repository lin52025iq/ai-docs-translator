没有行的表格还算表格吗？添加此扩展，让表格真正可用。

<CodeDemo path="/Nodes/Table" />

## 安装

```bash
npm install @tiptap/extension-table
```

使用此扩展前，需要先安装 [`Table`](/editor/extensions/nodes/table) 扩展。

此扩展默认随 `TableKit` 扩展一起安装，因此无需单独安装。

```ts
import { Editor } from '@tiptap/core'
import { TableKit } from '@tiptap/extension-table'

new Editor({
  extensions: [TableKit],
})
```
