使用 CodeBlock 扩展可以在文档中添加围栏代码块。代码会被包裹在 `<pre>` 和 `<code>` HTML 标签中。

输入 <code>&grave;&grave;&grave; </code>（三个反引号和一个空格）或 <code>&Tilde;&Tilde;&Tilde; </code>（三个波浪号和一个空格），即可立即插入代码块。你还可以指定语言，例如输入 <code>&grave;&grave;&grave;css </code>。这会为 `<code>` 标签添加 `language-css` 类。

<Callout title="不提供语法高亮" variant="hint">
  CodeBlock 扩展不包含样式，也没有内置语法高亮。如果你需要带语法高亮的代码块，可以试试
  [CodeBlockLowlight](/editor/extensions/nodes/code-block-lowlight) 扩展。
</Callout>

## 安装

```bash
npm install @tiptap/extension-code-block
```

## 用法

```js
import CodeBlock from '@tiptap/extension-code-block'

const editor = new Editor({
  extensions: [CodeBlock],
})
```

## 设置

### languageClassPrefix

为应用于代码标签的语言类添加前缀。

默认值：`'language-'`

```js
CodeBlock.configure({
  languageClassPrefix: 'language-',
})
```

### exitOnTripleEnter

设置是否在连续按三次 Enter 键时退出此节点。

默认值：`true`

```js
CodeBlock.configure({
  exitOnTripleEnter: false,
})
```

### defaultLanguage

设置默认语言，而不是使用 lowlight 自动检测。

默认值：`null`

```js
CodeBlock.configure({
  defaultLanguage: 'plaintext',
})
```

### exitOnArrowDown

如果此节点后面没有其他节点，设置是否在按向下箭头键时退出此节点。

默认值：`true`

```js
CodeBlock.configure({
  exitOnArrowDown: false,
})
```

### exitOnArrowUp

如果此节点前面没有其他节点，设置是否在按向上箭头键时退出此节点。

默认值：`true`

```js
CodeBlock.configure({
  exitOnArrowUp: false,
})
```

### enableTabIndentation

设置是否使用 Tab 键进行缩进。

默认值：`false`

```js
CodeBlock.configure({
  enableTabIndentation: true,
})
```

### tabSize

设置缩进所使用的空格数。

默认值：`4`

```js
CodeBlock.configure({
  tabSize: 2,
})
```

### HTMLAttributes

要添加到渲染后 HTML 标签的自定义 HTML 属性。

```js
CodeBlock.configure({
  HTMLAttributes: {
    class: 'my-custom-class',
  },
})
```

### enableTabIndentation

启用 Tab 键在代码块中的缩进功能。

默认值：`false`

```js
CodeBlock.configure({
  enableTabIndentation: true,
})
```

### tabSize

Tab 缩进所使用的空格数。

默认值：`4`

```js
CodeBlock.configure({
  tabSize: 2,
})
```

## 命令

### setCodeBlock()

将内容包裹在代码块中。

```js
editor.commands.setCodeBlock()
```

### toggleCodeBlock()

切换代码块。

```js
editor.commands.toggleCodeBlock()
```
