使用此扩展渲染 `<img>` HTML 标签。默认情况下，图像是块级元素。如果要让图像与文本同行显示，请将 `inline` 选项设为 `true`。

<Callout title="不提供服务器功能" variant="info">
  此扩展仅负责显示图像，不会将图像上传到服务器。
  如需上传，可以集成 [FileHandler
  扩展](/editor/extensions/functionality/filehandler)
</Callout>

## 安装

```bash
npm install @tiptap/extension-image
```

## 设置

### inline

将图像节点以内联方式渲染，例如渲染在段落标签中：`<p><img src="spacer.gif"></p>`。默认情况下，图像与段落处于同一层级。

具体取决于你想要怎样的编辑体验，但如果你要从 Quill 迁移到 Tiptap 等场景，这种方式可能会很有用。

默认值：`false`

```js
Image.configure({
  inline: true,
})
```

### resize

可调整图像大小的选项。如果定义了此选项，节点将由[可调整大小的节点视图](/editor/api/resizable-nodeviews)包裹，从而可以通过调整大小控件来调整图像大小。

默认值：`undefined`

```js
Image.configure({
  resize: {
    enabled: true,
    directions: ['top', 'bottom', 'left', 'right'], // can be any direction or diagonal combination
    minWidth: 50,
    minHeight: 50,
    alwaysPreserveAspectRatio: true,
  }
})
```

### allowBase64

允许将图像解析为 base64 字符串，例如 `<img src="data:image/jpg;base64...">`。

默认值：`false`

```js
Image.configure({
  allowBase64: true,
})
```

### HTMLAttributes

要添加到渲染后 HTML 标签的自定义 HTML 属性。

```js
Image.configure({
  HTMLAttributes: {
    class: 'my-custom-class',
  },
})
```

## 命令

### setImage()

将当前节点设为图像。

```js
editor.commands.setImage({ src: 'https://example.com/foobar.png' })
editor.commands.setImage({
  src: 'https://example.com/foobar.png',
  alt: 'A boring example image',
  title: 'An example',
})
```
