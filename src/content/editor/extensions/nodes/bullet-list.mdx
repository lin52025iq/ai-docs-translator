此扩展可让你在编辑器中使用项目符号列表。列表会渲染为 `<ul>` HTML 标签。在新行开头输入 <code>\* </code>、<code>- </code> 或 <code>+ </code>，即可自动转换为项目符号列表。

<CodeDemo path="/Nodes/BulletList" />

<Callout title="修改退格键行为" variant="info">
  如果你想修改列表中退格键和删除键的默认行为，请参阅
  [ListKeymap](/editor/extensions/functionality/listkeymap) 扩展。
</Callout>

## 安装

```bash
npm install @tiptap/extension-list
```

此扩展需要 [`ListItem`](/editor/extensions/nodes/list-item) 节点。

## 用法

```js
import { Editor } from '@tiptap/core'
import { BulletList } from '@tiptap/extension-list'

new Editor({
  extensions: [BulletList],
})
```

此扩展默认随 `ListKit` 扩展一起安装，因此无需单独安装。

```ts
import { Editor } from '@tiptap/core'
import { ListKit } from '@tiptap/extension-list'

new Editor({
  extensions: [ListKit],
})
```

## 设置

### HTMLAttributes

要添加到渲染后 HTML 标签上的自定义 HTML 属性。

```js
BulletList.configure({
  HTMLAttributes: {
    class: 'my-custom-class',
  },
})
```

### itemTypeName

指定列表项名称。

默认值：`'listItem'`

```js
BulletList.configure({
  itemTypeName: 'listItem',
})
```

### keepMarks

决定通过 `inputRule` 或按钮切换列表后，是否保留上一行的标记。

默认值：`false`

```js
BulletList.configure({
  keepMarks: true,
})
```

### keepAttributes

决定通过 `inputRule` 或按钮切换列表后，是否保留上一行的属性。

默认值：`false`

```js
BulletList.configure({
  keepAttributes: true,
})
```

## 命令

### toggleBulletList()

切换项目符号列表。

```js
editor.commands.toggleBulletList()
```
