无论你用 Tiptap 构建什么，都需要 `Document` 扩展。它是所谓的“topNode”，也就是容纳所有其他节点的节点。可以把它想象成文档中的 `<body>` 标签。

不过，这个节点非常简单。它定义了节点名称（`doc`），将自身配置为顶级节点（`topNode: true`），并且可以包含多个其他节点（`block+`）。就这些。你可以亲自看看：

<CodeDemo path="/Nodes/Document" />

<Callout title="破坏性变更" variant="warning">
  Tiptap v1 曾试图把这个节点隐藏起来，但它一直都存在。从现在起，你必须显式导入它（或使用 [StarterKit](/editor/extensions/functionality/starterkit)）。
</Callout>

## 安装

```bash
npm install @tiptap/extension-document
```
