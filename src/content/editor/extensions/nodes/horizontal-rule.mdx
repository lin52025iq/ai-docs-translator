使用此扩展可渲染 `<hr>` HTML 标签。如果在编辑器的初始内容中传入 `<hr>`，它也会相应地渲染出来。

在新行开头输入三个连字符（<code>---</code>），或输入三个下划线并加一个空格（<code>\_\_\_ </code>），它们就会自动转换为水平分隔线。

<CodeDemo path="/Nodes/HorizontalRule" />

## 安装

```bash
npm install @tiptap/extension-horizontal-rule
```

## 设置

### HTMLAttributes

要添加到渲染后 HTML 标签上的自定义 HTML 属性。

```js
HorizontalRule.configure({
  HTMLAttributes: {
    class: 'my-custom-class',
  },
})
```

## 命令

### setHorizontalRule()

创建一条水平分隔线。

```js
editor.commands.setHorizontalRule()
```
