`Text` 扩展是必需的，至少当你想处理任何类型的文本时是这样，而你很可能会这么做。这个扩展有些特别，它甚至不会渲染 HTML。它就是纯文本，仅此而已。

<Callout title="重大变更" variant="info">
  Tiptap v1 曾试图向你隐藏这个节点，但它一直都存在。从现在起，你必须显式导入它（或使用 [StarterKit](/editor/extensions/functionality/starterkit)）。
</Callout>

<CodeDemo path="/Nodes/Text" />

## 安装

```bash
npm install @tiptap/extension-text
```
