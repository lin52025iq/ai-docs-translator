此扩展是 [`Table`](/editor/extensions/nodes/table) 扩展的补充，顾名思义，它为表格添加了表头。

<CodeDemo path="/Nodes/Table" />

## 安装

```bash
npm install @tiptap/extension-table
```

此扩展需要先安装 [`Table`](/editor/extensions/nodes/table) 扩展。

此扩展默认随 `TableKit` 扩展一同安装，因此无需单独安装。

```ts
import { Editor } from '@tiptap/core'
import { TableKit } from '@tiptap/extension-table'

new Editor({
  extensions: [TableKit],
})
```

## 用法

表头是可选的。不过，来吧，你肯定想要表头，对吧？如果不需要，可以像这样更新 [`TableRow`](/editor/extensions/nodes/table-row) 扩展的 `content` 属性：

```js
// Table rows without table headers
TableRow.extend({
  content: 'tableCell*',
})
```

以下是默认设置，允许使用表头：

```js
// Table rows with table headers (default)
TableRow.extend({
  content: '(tableCell | tableHeader)*',
})
```
