HardBreak 扩展支持 `<br>` HTML 标签，可用于强制换行。

<CodeDemo path="/Nodes/HardBreak" />

## 安装

```bash
npm install @tiptap/extension-hard-break
```

## 设置

### HTMLAttributes

要添加到渲染后 HTML 标签中的自定义 HTML 属性。

```js
HardBreak.configure({
  HTMLAttributes: {
    class: 'my-custom-class',
  },
})
```

### keepMarks

决定换行后是否保留标记。此选项基于标记的 `keepOnSplit` 选项。

默认值：`true`

```js
HardBreak.configure({
  keepMarks: false,
})
```

## 命令

### setHardBreak()

添加换行符。

```js
editor.commands.setHardBreak()
```
