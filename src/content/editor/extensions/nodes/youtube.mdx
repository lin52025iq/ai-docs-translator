此扩展会向编辑器添加一个新的 YouTube 嵌入节点。

<CodeDemo path="/Nodes/YouTube" />

## 安装

```bash
npm install @tiptap/extension-youtube
```

## 设置

### inline

控制节点应作为行内内容还是块级内容处理。

默认值：`false`

```js
Youtube.configure({
  inline: false,
})
```

### width

控制所添加视频的默认宽度

默认值：`640`

```js
Youtube.configure({
  width: 480,
})
```

### height

控制所添加视频的默认高度

默认值：`480`

```js
Youtube.configure({
  height: 320,
})
```

### controls

启用或禁用 YouTube 视频控件

默认值：`true`

```js
Youtube.configure({
  controls: false,
})
```

### nocookie

为 YouTube 嵌入内容启用 nocookie 模式

默认值：`false`

```js
Youtube.configure({
  nocookie: true,
})
```

### allowFullscreen

允许在 iframe 中全屏播放

默认值：`true`

```js
Youtube.configure({
  allowFullscreen: false,
})
```

### autoplay

允许播放器加载后自动开始播放

默认值：`false`

```js
Youtube.configure({
  autoplay: true,
})
```

### ccLanguage

指定播放器用于显示隐藏式字幕的默认语言。将此参数设为 ISO 639-1 双字母语言代码。例如，设为 `es` 会使字幕显示为西班牙语。

默认值：`undefined`

```js
Youtube.configure({
  ccLanguage: 'es',
})
```

### ccLoadPolicy

将此参数设为 `true` 后，即使用户已关闭字幕，默认也会显示隐藏式字幕。

默认值：`false`

```js
Youtube.configure({
  ccLoadPolicy: true,
})
```

### disableKBcontrols

禁用 iframe 播放器的键盘控制

默认值：`false`

```js
Youtube.configure({
  disableKBcontrols: true,
})
```

### enableIFrameApi

允许通过 IFrame Player API 调用控制播放器

默认值：`false`

```js
Youtube.configure({
  enableIFrameApi: true,
})
```

### origin

此参数为 IFrame API 提供额外的安全保障，且仅适用于 IFrame 嵌入。如果使用 IFrame API（即将 `enableIFrameApi` 参数设为 `true`），应始终将你的域名指定为 `origin` 参数值。

默认值：`''`

```js
Youtube.configure({
  origin: 'yourdomain.com',
})
```

### endTime

此参数指定播放器停止播放视频的时间，单位为秒，从视频开始处计时。
例如，将其设为 `15`，视频将在播放到第 15 秒时停止。

默认值：`0`

```js
Youtube.configure({
  endTime: '15',
})
```

### interfaceLanguage

设置播放器的界面语言。参数值为 ISO 639-1 双字母语言代码。例如，设为 `fr` 会使界面显示为法语。

默认值：`undefined`

```js
Youtube.configure({
  interfaceLanguage: 'fr',
})
```

### ivLoadPolicy

将此参数设为 1 会使视频注释默认显示；设为 3 则会使视频注释默认不显示。

默认值：`0`

```js
Youtube.configure({
  ivLoadPolicy: '3',
})
```

### loop

此参数在 IFrame 嵌入中的支持有限。若要循环播放单个视频，请将 `loop` 参数设为 `true`，并将 `playlist` 参数设为 Player API URL 中已指定的同一视频 ID。

默认值：`false`

```js
Youtube.configure({
  loop: true,
})
```

### playlist

此参数指定要播放的视频 ID 列表，多个 ID 以逗号分隔。

默认值：`''`

```js
Youtube.configure({
  playlist: 'VIDEO_ID_1,VIDEO_ID_2,VIDEO_ID_3,...,VIDEO_ID_N',
})
```

### modestBranding

禁用播放器控制栏上的 Youtube 标志。请注意，当用户的鼠标指针悬停在播放器上时，暂停的视频右上角仍会显示一小段 YouTube 文字标识。

默认值：`false`

```js
Youtube.configure({
  modestBranding: true,
})
```

### progressBarColor

此参数指定播放器视频进度条的颜色。请注意，将颜色参数设为 `white` 会禁用 `modestBranding` 参数。

默认值：`undefined`

```js
Youtube.configure({
  progressBarColor: 'white',
})
```

## 命令

### setYoutubeVideo(options)

在当前位置插入一个 YouTube iframe 嵌入内容。

```js
editor.commands.setYoutubeVideo({
  src: 'https://www.youtube.com/watch?v=dQw4w9WgXcQ',
  width: 640,
  height: 480,
})
```

#### 选项

| 选项 | 说明 | 可选 |
| ------ | -------------------------------------------------------------------- | -------- |
| src    | YouTube 视频的网址。可以是 YouTube 或 YouTube Music 链接 |  |
| width  | 嵌入内容的宽度（覆盖默认选项，可选） | ✅ |
| height | 嵌入内容的高度（覆盖默认选项，可选） | ✅ |
