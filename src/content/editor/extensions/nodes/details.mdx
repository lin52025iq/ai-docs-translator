Details 扩展支持在编辑器中使用 `<details>` HTML 标签，方便显示和隐藏内容。

<CodeDemo path="/Nodes/Details" />

## 安装

```bash
npm install @tiptap/extension-details
```

此扩展需要 [`DetailsSummary`](/editor/extensions/nodes/details-summary) 和 [`DetailsContent`](/editor/extensions/nodes/details-content) 节点。

## 设置

### persist

指定是否将打开状态保存到文档中。默认为 `false`。

```js
Details.configure({
  persist: true,
})
```

### openClassName

指定切换内容时设置的 CSS 类。默认为 `is-open`。

```js
Details.configure({
  openClassName: 'is-open',
})
```

### renderToggleButton

自定义用于切换 details 节点的按钮。回调会接收按钮 `element`、当前的 `isOpen` 状态，以及用于生成标签的 `node`。

当你想更改按钮的无障碍标签或直接更新按钮元素时，此选项会很有用。

```js
Details.configure({
  renderToggleButton: ({ element, isOpen, node }) => {
    element.setAttribute(
      'aria-label',
      isOpen
        ? `Collapse details: ${node.textContent || 'details'}`
        : `Expand details: ${node.textContent || 'details'}`,
    )
  },
})
```

### HTMLAttributes

要添加到渲染后的 HTML 标签中的自定义 HTML 属性。

```js
Details.configure({
  HTMLAttributes: {
    class: 'my-custom-class',
  },
})
```

## 命令

### setDetails()

将内容包裹在 details 节点中。

```js
editor.commands.setDetails()
```

### unsetDetails()

移除 details 节点的包裹。

```js
editor.commands.unsetDetails()
```
