ListItem 扩展添加了对 `<li>` HTML 标签的支持。该标签用于项目符号列表和有序列表，通常不能脱离它们单独使用。

<CodeDemo path="/Nodes/ListItem" />

<Callout title="修改退格键行为" variant="info">
  如果你想修改列表中退格键和删除键的标准行为，
  请阅读 [ListKeymap](/editor/extensions/functionality/listkeymap) 扩展的相关说明。
</Callout>

## 安装

```bash
npm install @tiptap/extension-list
```

此扩展需要 [`BulletList`](/editor/extensions/nodes/bullet-list) 或 [`OrderedList`](/editor/extensions/nodes/ordered-list) 节点。

## 用法

```js
import { Editor } from '@tiptap/core'
import { ListItem } from '@tiptap/extension-list'

new Editor({
  extensions: [ListItem],
})
```

此扩展默认随 `ListKit` 扩展一同安装，因此无需单独安装。

```ts
import { Editor } from '@tiptap/core'
import { ListKit } from '@tiptap/extension-list'

new Editor({
  extensions: [ListKit],
})
```

## 设置

### HTMLAttributes

要添加到渲染后 HTML 标签上的自定义 HTML 属性。

```js
ListItem.configure({
  HTMLAttributes: {
    class: 'my-custom-class',
  },
})
```
