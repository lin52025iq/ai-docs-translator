引用块扩展让你可以在编辑器中使用 `<blockquote>` HTML 标签。这很适合……在编辑器中展示引文，你懂的？

在新行开头输入 <code>&gt;&nbsp;</code>，它就会自动转换为引用块。

<CodeDemo path="/Nodes/Blockquote" />

## 安装

```bash
npm install @tiptap/extension-blockquote
```

## 设置

### HTMLAttributes

要添加到渲染后 HTML 标签中的自定义 HTML 属性。

```js
Blockquote.configure({
  HTMLAttributes: {
    class: 'my-custom-class',
  },
})
```

## 命令

### setBlockquote()

将内容包裹在引用块中。

```js
editor.commands.setBlockquote()
```

### toggleBlockquote()

包裹或取消包裹引用块。

```js
editor.commands.toggleBlockquote()
```

### unsetBlockquote()

取消包裹引用块。

```js
editor.commands.unsetBlockquote()
```
