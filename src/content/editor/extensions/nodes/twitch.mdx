此扩展支持在编辑器中嵌入 Twitch 视频、剪辑和直播频道。

## 支持的内容类型

- **视频**：Twitch 点播视频（VOD）的直接链接
- **剪辑**：Twitch 剪辑链接
- **频道**：Twitch 直播频道链接

## 安装

```bash
npm install @tiptap/extension-twitch
```

## 设置

### inline

控制节点是以内联方式还是块级方式处理。

默认值：`false`

```js
Twitch.configure({
  inline: false,
})
```

### width

控制所添加视频的默认宽度。

默认值：`640`

```js
Twitch.configure({
  width: 480,
})
```

### height

控制所添加视频的默认高度。

默认值：`480`

```js
Twitch.configure({
  height: 320,
})
```

### allowFullscreen

允许 iframe 进入全屏播放。

默认值：`true`

```js
Twitch.configure({
  allowFullscreen: false,
})
```

### autoplay

允许 iframe 在播放器加载后自动开始播放。

默认值：`false`

```js
Twitch.configure({
  autoplay: true,
})
```

### muted

指定视频的初始状态是否静音。启用自动播放时，此设置很有用，因为大多数浏览器要求视频静音才能自动播放。

默认值：`false`

```js
Twitch.configure({
  muted: true,
})
```

### time

视频开始播放的时间点。仅适用于视频嵌入，不适用于剪辑或频道。
格式：`1h2m3s`（小时、分钟、秒）。

默认值：`undefined`

```js
Twitch.configure({
  time: '1h2m3s',
})
```

### parent

指定嵌入 Twitch 播放器的域名。这是 Twitch 嵌入功能正常运行的必要设置，应将其设为你的域名。

默认值：`'localhost'`

```js
Twitch.configure({
  parent: 'example.com',
})
```

### addPasteHandler

控制是否添加用于处理 Twitch 视频 URL 的粘贴处理器。启用后，粘贴 Twitch 视频 URL 会自动创建嵌入内容。

默认值：`true`

```js
Twitch.configure({
  addPasteHandler: false,
})
```

### HTMLAttributes

向 iframe 元素传递自定义 HTML 属性。

默认值：`{}`

```js
Twitch.configure({
  HTMLAttributes: {
    class: 'custom-twitch-embed',
  },
})
```

## 命令

### setTwitchVideo(options)

在当前位置插入一个 Twitch 视频 iframe 嵌入内容。

```js
editor.commands.setTwitchVideo({
  src: 'https://www.twitch.tv/videos/1234567890',
  width: 640,
  height: 480,
})
```

#### 选项

- `src` - Twitch 视频的 URL（可选）
- `width` - 嵌入内容的宽度（覆盖默认选项）（可选）
- `height` - 嵌入内容的高度（覆盖默认选项）（可选）

## 使用示例

### 基本用法

```js
import { useEditor, EditorContent } from '@tiptap/react'
import { StarterKit } from '@tiptap/starter-kit'
import { Twitch } from '@tiptap/extension-twitch'

const editor = useEditor({
  extensions: [
    StarterKit,
    Twitch.configure({
      parent: 'example.com',
    }),
  ],
  content: '<p>Hello World!</p>',
})
```

### 自定义配置

```js
const editor = useEditor({
  extensions: [
    StarterKit,
    Twitch.configure({
      parent: 'example.com',
      width: 800,
      height: 600,
      allowFullscreen: true,
      autoplay: false,
      addPasteHandler: true,
    }),
  ],
})
```

### 以编程方式插入

```js
// 使用默认尺寸插入 Twitch 视频
editor.commands.setTwitchVideo({
  src: 'https://www.twitch.tv/videos/1234567890',
})

// 使用自定义尺寸插入
editor.commands.setTwitchVideo({
  src: 'https://www.twitch.tv/videos/1234567890',
  width: 960,
  height: 540,
})

// 使用自定义的自动播放和静音设置插入
editor.commands.setTwitchVideo({
  src: 'https://www.twitch.tv/videos/1234567890',
  autoplay: true,
  muted: true,
})

// 指定开始时间
editor.commands.setTwitchVideo({
  src: 'https://www.twitch.tv/videos/1234567890',
  time: '1h2m3s',
})
```

## 属性覆盖

插入视频时指定属性，即可覆盖单个嵌入内容的扩展选项。这样，你可以为不同的嵌入内容设置不同选项，同时将扩展选项用作默认值：

```js
// 扩展的默认配置为 autoplay=false
Twitch.configure({
  parent: 'example.com',
  autoplay: false,
})

// 但为这个特定视频启用自动播放
editor.commands.setTwitchVideo({
  src: 'https://www.twitch.tv/videos/1234567890',
  autoplay: true, // 覆盖扩展的 autoplay 选项
  muted: true, // 确保音频静音
})
```

## 支持的 URL 格式

此扩展支持以下 Twitch URL 格式：

### 视频

- `https://www.twitch.tv/videos/1234567890`
- `https://twitch.tv/videos/1234567890`

### 剪辑

- `https://www.twitch.tv/examplechannel/clip/ExampleClipName-ABC123`
- `https://twitch.tv/examplechannel/clip/ExampleClipName-ABC123`
- `https://clips.twitch.tv/ExampleClipName-ABC123`
- `https://www.clips.twitch.tv/ExampleClipName-ABC123`

### 频道

- `https://www.twitch.tv/examplechannel`
- `https://twitch.tv/examplechannel`

## 粘贴支持

启用 `addPasteHandler`（默认值）后，只需将 Twitch 视频 URL 粘贴到编辑器中，它就会自动转换为嵌入内容。

```
粘贴此 URL：https://www.twitch.tv/videos/1234567890
↓
自动创建 Twitch 嵌入节点
```

## 重要说明

- Twitch 嵌入内容要正常显示，必须配置 `parent` 域名。请务必将其设为你的实际域名。
- 出于安全原因，必须在 Twitch 端将父域名加入白名单，才能嵌入 Twitch 内容。
- 此扩展会在创建嵌入内容前验证 URL，以防止无效内容。
- 嵌入内容可以拖动，也可以在文档中重新定位。

## 键盘快捷键

- 选中 Twitch 嵌入内容后按 `Backspace` 或 `Delete` 可将其移除
- 可以使用键盘导航和方向键选中 Twitch 嵌入内容
