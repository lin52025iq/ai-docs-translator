`Emoji` 扩展会将表情符号渲染为行内节点。所有插入的表情符号（包括键入、粘贴等方式插入的）都会转换为此节点。这样做的好处是，可以使用备用图像渲染不受支持的表情符号。从编辑器中复制文本时，它们会立即转换回纯文本。

<CodeDemo path="/Nodes/Emoji" />

## 安装

```bash
npm install @tiptap/extension-emoji
```

## 设置

### HTMLAttributes

要添加到渲染后 HTML 标签的自定义 HTML 属性。

```js
Emoji.configure({
  HTMLAttributes: {
    class: 'my-custom-class',
  },
})
```

### emojis

定义一组表情符号。Tiptap 提供两组表情符号：

1. 默认的 `emojis` 列表，其中包含 Unicode 14.1 版的所有表情符号
2. 扩展的 `gitHubEmojis` 列表，其中还包含 :octocat: 等自定义表情符号

```js
import Emoji, { gitHubEmojis } from '@tiptap/extension-emoji'

Emoji.configure({
  emojis: gitHubEmojis,
})
```

<Callout title="肤色" variant="hint">

目前还不支持肤色 ✌🏽

</Callout>

### enableEmoticons

指定是否将文本转换为表情符号（例如，将 `<3` 转换为 ❤️）。默认为 `false`。

```js
Emoji.configure({
  enableEmoticons: true,
})
```

### forceFallbackImages

指定是否始终渲染备用图像。默认为 `false`。

```js
Emoji.configure({
  forceFallbackImages: true,
})
```

#### 添加自定义表情符号

添加自定义表情符号非常简单。

```js
import Emoji, { emojis } from '@tiptap/extension-emoji'

const customEmojis = [
  {
    // A unique name of the emoji which will be stored as attribute
    name: 'octocat',
    // A list of unique shortcodes that are used by input rules to find the emoji
    shortcodes: ['octocat'],
    // A list of tags that can help for searching emojis
    tags: ['cat', 'meow'],
    // A name that can help to group emojis
    group: 'My custom group of emojis',
    // The image to be rendered
    fallbackImage: 'https://github.githubassets.com/images/icons/emoji/octocat.png',
  },
]

Emoji.configure({
  emojis: [...emojis, ...customEmojis],
})
```
