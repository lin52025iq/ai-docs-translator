此扩展会将任务项渲染为列表元素，即带有 `data-type` 属性（值为 `taskItem`）的 `<li>` 标签。它还会在列表元素中渲染一个复选框，用于更新 `checked` 属性。

此扩展不依赖任何 JavaScript 框架，而是基于原生 JavaScript。

<CodeDemo path="/Nodes/TaskItem" />

## 安装

```bash
npm install @tiptap/extension-list
```

此扩展需要 [`TaskList`](/editor/extensions/nodes/task-list) 节点。

## 用法

```js
import { Editor } from '@tiptap/core'
import { TaskItem } from '@tiptap/extension-list'

new Editor({
  extensions: [TaskItem],
})
```

此扩展默认包含在 `ListKit` 扩展中，因此无需单独安装。

```ts
import { Editor } from '@tiptap/core'
import { ListKit } from '@tiptap/extension-list'

new Editor({
  extensions: [ListKit],
})
```

## 配置

### HTMLAttributes

要添加到渲染后的 HTML 标签中的自定义 HTML 属性。

```js
TaskItem.configure({
  HTMLAttributes: {
    class: 'my-custom-class',
  },
})
```

### nested

是否允许任务项相互嵌套。

```js
TaskItem.configure({
  nested: true,
})
```

### onReadOnlyChecked

当编辑器设置为 `readOnly` 时，任务项被选中或取消选中时调用的处理函数。
如果未提供此函数，编辑器处于 `readOnly` 状态时，任务项不可修改。
如果此函数返回 false，则会保留选中状态（`readOnly`）。

```js
TaskItem.configure({
  onReadOnlyChecked: (node, checked) => {
    // do something
  },
})
```

### taskListTypeName

此任务项所属任务列表的类型名称。用于确定父级任务列表类型。

```js
TaskItem.configure({
  taskListTypeName: 'taskList',
})
```

### a11y

任务项的无障碍设置，包含以下选项：

- **`checkboxLabel`**：根据任务项的选中状态返回复选框 `aria-label` 的函数。屏幕阅读器可以借此播报复选框状态。
  - **参数**：
    - `node`：任务项节点。
    - `checked`：布尔值，表示任务项是否已选中。
  - **返回值**：用作复选框 `aria-label` 的字符串。

```js
TaskItem.configure({
  a11y: {
    // the aria-label for the checkbox
    checkboxLabel: (node, checked) => {
      return checked ? 'Task completed' : 'Task not completed'
    },
  },
})
```
