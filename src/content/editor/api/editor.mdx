编辑器实例是 Tiptap 的核心组成部分。它负责完成创建可用的 [ProseMirror](https://ProseMirror.net/) 编辑器所需的大部分工作，例如创建 [`EditorView`](https://ProseMirror.net/docs/ref/#view.EditorView)、设置初始 [`EditorState`](https://ProseMirror.net/docs/ref/#state.Editor_State) 等。

## 设置

`Editor` 类接受多种设置。以下是所有可用设置的列表：

### element

`element` 用于指定编辑器所绑定的 HTML 元素。以下代码会将 Tiptap 集成到具有 `.element` 类的元素中：

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'

const editor = new Editor({
  element: document.querySelector('.element'),
  extensions: [StarterKit],
})
```

你甚至可以先初始化编辑器，再将它挂载到元素上。当 DOM 尚不可用或处于服务器端渲染环境时，这种方式很有用。只需先将 `null` 传给编辑器进行初始化，之后再挂载即可。

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'

const editor = new Editor({
  element: null,
  extensions: [StarterKit],
})

// Later in your code
editor.mount(document.querySelector('.element'))
```

### extensions

必须为 `extensions` 属性传入扩展列表，即使你只想启用段落也是如此。

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import Document from '@tiptap/extension-document'
import Paragraph from '@tiptap/extension-paragraph'
import Text from '@tiptap/extension-text'
import Highlight from '@tiptap/extension-highlight'

new Editor({
  // Use the default extensions
  extensions: [StarterKit],

  // … or use specific extensions
  extensions: [Document, Paragraph, Text],

  // … or both
  extensions: [StarterKit, Highlight],
})
```

### schemaSpec

可选的 `schemaSpec` 设置接受完整的 ProseMirror `SchemaSpec`。请从 `@tiptap/pm/model` 导入该类型。

它定义编辑器的文档结构，而本地扩展则提供解析、渲染、命令、节点视图和插件。如果省略此设置，Tiptap 会根据你的扩展构建 schema。

`schemaSpec` 中的每个节点和标记都必须有一个名称和类型相同的本地扩展。每个本地节点和标记也必须出现在该规范中。

创建编辑器时会应用此规范。通过 `setOptions()` 更改 `schemaSpec` 不会重建 schema。若要使用不同的规范，请创建新的编辑器。

有关示例、结构和属性规则，请参阅[使用外部 schema 规范](/editor/core-concepts/schema#use-an-external-schema-spec)。

### content

通过 `content` 属性，你可以为编辑器提供初始内容。内容可以是 HTML 或 JSON。

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'

new Editor({
  content: `<p>Example Text</p>`,
  extensions: [StarterKit],
})
```

### editable

`editable` 属性用于确定用户是否可以在编辑器中输入内容。

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'

new Editor({
  content: `<p>Example Text</p>`,
  extensions: [StarterKit],
  editable: false,
})
```

### coreExtensionOptions

`coreExtensionOptions` 属性用于配置 Tiptap 内置的核心扩展。

使用 `tabindex.value` 可设置编辑器元素的 `tabindex` 属性。当 `value` 未定义时，可编辑的编辑器默认使用 `tabindex="0"`，不可编辑的编辑器则不会添加 `tabindex` 属性。

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'

new Editor({
  content: `<p>Example Text</p>`,
  extensions: [StarterKit],
  editable: false,
  coreExtensionOptions: {
    tabindex: {
      value: '-1',
    },
  },
})
```

### textDirection

`textDirection` 属性用于设置编辑器中所有内容的文本方向。对于阿拉伯语和希伯来语等从右向左（RTL）书写的语言，或包含双向文本的内容，这项设置很有用。

| 值          | 说明                         |
| ----------- | ---------------------------- |
| `'ltr'`     | 将所有内容设为从左向右。     |
| `'rtl'`     | 将所有内容设为从右向左。     |
| `'auto'`    | 根据内容自动检测方向。       |
| `undefined` | 不添加方向属性（默认值）。   |

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'

new Editor({
  content: `<p>مرحبا بك في Tiptap</p>`,
  extensions: [StarterKit],
  textDirection: 'auto',
})
```

你也可以使用 `setTextDirection` 和 `unsetTextDirection` 命令覆盖特定节点的方向。更多详情请参阅[命令文档](/editor/api/commands)。

### autofocus

使用 `autofocus` 可以在初始化时让光标跳转到编辑器中。

| 值       | 说明                         |
| -------- | ---------------------------- |
| `start`  | 将焦点设在文档开头。         |
| `end`    | 将焦点设在文档末尾。         |
| `all`    | 选中整个文档。               |
| `Number` | 将焦点设在文档中的指定位置。 |
| `true`   | 启用自动聚焦。               |
| `false`  | 禁用自动聚焦。               |
| `null`   | 禁用自动聚焦。               |

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'

new Editor({
  extensions: [StarterKit],
  autofocus: false,
})
```

### enableInputRules

默认情况下，Tiptap 会启用所有[输入规则](/editor/api/input-rules)。你可以通过 `enableInputRules` 控制这一行为。

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'

new Editor({
  content: `<p>Example Text</p>`,
  extensions: [StarterKit],
  enableInputRules: false,
})
```

你也可以只允许特定的输入规则。

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import Link from '@tiptap/extension-link'

new Editor({
  content: `<p>Example Text</p>`,
  extensions: [StarterKit, Link],
  // pass an array of extensions or extension names
  // to allow only specific input rules
  enableInputRules: [Link, 'horizontalRule'],
})
```

### enablePasteRules

默认情况下，Tiptap 会启用所有[粘贴规则](/editor/api/paste-rules)。你可以通过 `enablePasteRules` 控制这一行为。

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'

new Editor({
  content: `<p>Example Text</p>`,
  extensions: [StarterKit],
  enablePasteRules: false,
})
```

你也可以只允许特定的粘贴规则。

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import Link from '@tiptap/extension-link'

new Editor({
  content: `<p>Example Text</p>`,
  extensions: [StarterKit, Link],
  // pass an array of extensions or extension names
  // to allow only specific paste rules
  enablePasteRules: [Link, 'horizontalRule'],
})
```

### injectCSS

默认情况下，Tiptap 会注入[少量 CSS](https://github.com/ueberdosis/tiptap/tree/main/packages/core/src/style.ts)。你可以通过 `injectCSS` 禁用此功能。

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'

new Editor({
  extensions: [StarterKit],
  injectCSS: false,
})
```

### injectNonce

如果你使用带有 `nonce` 的[内容安全策略（Content Security Policy）](https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/Content-Security-Policy)，可以指定要添加到动态创建元素中的 `nonce`。示例如下：

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'

new Editor({
  extensions: [StarterKit],
  injectCSS: true,
  injectNonce: 'your-nonce-here',
})
```

### enableExtensionDispatchTransaction

是否启用扩展级别的事务分发。如果设为 `false`，扩展将无法定义自己的 `dispatchTransaction` 钩子。

- **默认值**：`true`

```js
new Editor({
  enableExtensionDispatchTransaction: false,
})
```

### editorProps

对于高级用例，你可以传入 `editorProps`，由 [ProseMirror](https://prosemirror.net/docs/ref/#view.EditorProps) 处理。你可以用它覆盖各种编辑器事件，或更改编辑器 DOM 元素的属性，例如添加一些 Tailwind 类。示例如下：

```js
new Editor({
  // Learn more: https://prosemirror.net/docs/ref/#view.EditorProps
  editorProps: {
    attributes: {
      class: 'prose prose-sm sm:prose lg:prose-lg xl:prose-2xl mx-auto focus:outline-none',
    },
    transformPastedText(text) {
      return text.toUpperCase()
    },
  },
})
```

你也可以用它接入事件处理程序，例如传入自定义的粘贴处理程序。

将 `editorProps.attributes.spellcheck` 设为 `'true'` 可启用浏览器拼写检查。示例、语言设置和自定义拼写检查器请参阅[拼写检查指南](/guides/spellcheck)。

### parseOptions

传入的内容由 ProseMirror 解析。若要接入解析过程，可以传入 `parseOptions`，由 [ProseMirror](https://prosemirror.net/docs/ref/#model.ParseOptions) 处理。

```js
new Editor({
  // Learn more: https://prosemirror.net/docs/ref/#model.ParseOptions
  parseOptions: {
    preserveWhitespace: 'full',
  },
})
```

## 方法

编辑器实例会提供多种公共方法。方法是常规函数，可以返回任意内容，可用于操作编辑器。

不要将方法与[命令](/editor/api/commands)混淆。命令用于更改编辑器状态（内容、选区等），且只返回 `true` 或 `false`。

### can()

检查某个命令或命令链是否可以执行，而不实际执行它。这对于启用/禁用或显示/隐藏按钮非常有用。

```js
// Returns `true` if the undo command can be executed
editor.can().undo()
```

### chain()

创建命令链，以便一次调用多个命令。

```js
// Execute two commands at once
editor.chain().focus().toggleBold().run()
```

### destroy()

停止编辑器实例并解除所有事件绑定。

```js
// Hasta la vista, baby!
editor.destroy()
```

### getHTML()

以 HTML 格式返回当前编辑器文档。

```js
editor.getHTML()
```

### getJSON()

以 JSON 格式返回当前编辑器文档。

```js
editor.getJSON()
```

### getText()

以纯文本格式返回当前编辑器文档。

| 参数    | 类型                                                                       | 说明         |
| ------- | -------------------------------------------------------------------------- | ------------ |
| options | blockSeparator?: string, textSerializers?: Record;string, TextSerializer | 序列化选项。 |

```js
// Give me plain text!
editor.getText()
// Add two line breaks between nodes
editor.getText({ blockSeparator: '\n\n' })
```

### getAttributes()

获取当前选中节点或标记的属性。

| 参数       | 类型                           | 说明         |
| ---------- | ------------------------------ | ------------ |
| typeOrName | string \| NodeType \| MarkType | 节点或标记的名称 |

```js
editor.getAttributes('link').href
```

### isActive()

返回当前选中的节点或标记是否处于激活状态。

| 参数       | 类型                      | 说明             |
| ---------- | ------------------------- | ---------------- |
| name       | string \| null            | 节点或标记的名称 |
| attributes | Record&lt;string, any&gt; | 节点或标记的属性 |

```js
// Check if it’s a heading
editor.isActive('heading')
// Check if it’s a heading with a specific attribute value
editor.isActive('heading', { level: 2 })
// Check if it has a specific attribute value, doesn’t care what node/mark it is
editor.isActive({ textAlign: 'justify' })
```

### mount()

将编辑器挂载到某个元素上。当你想将编辑器挂载到尚未出现在 DOM 中的元素时，这种方式很有用。

```js
editor.mount(document.querySelector('.element'))
```

### unmount()

将编辑器从某个元素上卸载。当你想先卸载编辑器，之后再将它重新挂载到另一个元素上时，这种方式很有用。

```js
editor.unmount()
```

### registerPlugin()

注册 ProseMirror 插件。

| 参数            | 类型                                                 | 说明                               |
| --------------- | ---------------------------------------------------- | ---------------------------------- |
| plugin          | `Plugin`                                             | ProseMirror 插件                   |
| handlePlugins?  | `(newPlugin: Plugin, plugins: Plugin[]) => Plugin[]` | 控制如何将插件合并到现有插件中     |

### setOptions()

更新编辑器选项。

| 参数    | 类型                     | 说明       |
| ------- | ------------------------ | ---------- |
| options | `Partial<EditorOptions>` | 选项列表。 |

```js
// Add a class to an existing editor instance
editor.setOptions({
  editorProps: {
    attributes: {
      class: 'my-custom-class',
    },
  },
})
```

### setEditable()

更新编辑器的可编辑状态。

| 参数       | 类型      | 说明                                                   |
| ---------- | --------- | ------------------------------------------------------ |
| editable   | `boolean` | 如果用户应能在编辑器中输入内容，则为 `true`。         |
| emitUpdate | `boolean` | 默认为 `true`。用于确定是否触发 `onUpdate`。           |

```js
// Make the editor read-only
editor.setEditable(false)
```

### unregisterPlugin()

取消注册 ProseMirror 插件。

| 参数           | 类型                  | 说明       |
| -------------- | --------------------- | ---------- |
| nameOrPluginKey | `string \| PluginKey` | 插件名称   |

### $node()

请参阅 [NodePos 类](/editor/api/node-positions)。

## 属性

### isEditable

返回编辑器是否可编辑或处于只读状态。

```js
editor.isEditable
```

### isEmpty

检查是否有内容。

```js
editor.isEmpty
```

### isFocused

检查编辑器是否处于焦点状态。

```js
editor.isFocused
```

### isDestroyed

检查编辑器是否已销毁。

```js
editor.isDestroyed
```

### isCapturingTransaction

检查编辑器是否正在捕获事务。

```js
editor.isCapturingTransaction
```
