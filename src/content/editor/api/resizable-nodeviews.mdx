这是一个轻量、与框架无关的 NodeView，可包装任意 HTMLElement（图像、iframe、视频等）并添加可配置的调整大小控点。它负责处理用户交互、应用最小值和最大值限制、按需保持宽高比，并提供用于实时更新和提交的回调。

---

## 什么是可调整大小的节点视图？

ResizableNodeView 是兼容 ProseMirror/Tiptap 的 NodeView，能够：

- 将你的元素包裹在一个容器和一个包装器中
- 添加可配置的调整大小控点（角和边）
- 在拖动过程中持续触发 `onResize`
- 在用户完成调整大小后触发一次 `onCommit`（可用它持久化新属性）
- 支持最小值和最大值限制、宽高比锁定（配置项 / Shift 键）以及类名自定义
- 激活时添加 `data-resize-state` 属性和可选的 `resizing` CSS 类

---

## 选项

- `element: HTMLElement` — 要设置为可调整大小的元素（必填）
- `contentElement?: HTMLElement` — 可选的 HTML 节点，用作 contentElement（适用于 contenteditable 节点）
- `node: Node` — ProseMirror 节点（必填）
- `getPos: () => number | undefined` — 返回节点位置的函数（持久化时必需）
- `onResize?: (width: number, height: number) => void` — 可选，在拖动过程中持续调用
- `onCommit: (width: number, height: number) => void` — 在拖动结束时调用一次
- `onUpdate?: NodeView['update']` — 可选的节点更新处理函数
- `options?: object` — 可选配置（见下文）

### `options` 属性：

- `directions?: ResizableNodeViewDirection[]`
  默认值：`['bottom-left', 'bottom-right', 'top-left', 'top-right']`
  可选值：`'top' | 'right' | 'bottom' | 'left' | 'top-right' | 'top-left' | 'bottom-right' | 'bottom-left'`

- `min?: Partial<{ width: number; height: number; }>`
  默认值：`{ width: 8, height: 8 }`（像素）

- `max?: Partial<{ width: number; height: number; }>`
  默认值：`undefined`（无最大值限制）

- `preserveAspectRatio?: boolean`
  默认值：`false`
  为 `true` 时始终保持宽高比。为 `false` 时，拖动期间按住 `Shift` 可临时保持宽高比。

- `className?: { container?: string; wrapper?: string; handle?: string; resizing?: string }`
  可选的类名，分别应用于容器、包装器、每个控点，以及正在调整大小时添加的类名。

---

## 回调

- `onResize(width, height)`：拖动期间更新元素的视觉尺寸（`style.width/height`）。
- `onCommit(width, height)`：持久化最终尺寸（例如 `editor.commands.updateAttributes(...)`）。
- `onUpdate(node, decorations, innerDecorations)`：返回 `true` 接受更新，返回 `false` 则重新创建节点视图。

在 `onCommit` 中持久化尺寸的示例：

```ts
const pos = getPos()
if (pos !== undefined) {
  editor.commands.updateAttributes('image', { width, height })
}
```

## 使用示例

最简图像扩展节点视图：

```ts
// inside addNodeView()
return ({ node, getPos, HTMLAttributes }) => {
  const img = document.createElement('img')
  img.src = HTMLAttributes.src

  // copy non-size attributes to element
  Object.entries(HTMLAttributes).forEach(([key, value]) => {
    if (value == null) return
    if (key === 'width' || key === 'height') return
    img.setAttribute(key, String(value))
  })

  // instantiate ResizableNodeView
  return new ResizableNodeView({
    element: img,
    node,
    getPos,
    onResize: (w, h) => {
      img.style.width = `${w}px`
      img.style.height = `${h}px`
    },
    onCommit: (w, h) => {
      const pos = getPos()
      if (pos === undefined) return
      // persist new size to the node
      editor.commands.updateAttributes('image', { width: w, height: h })
    },
    onUpdate: (updatedNode) => {
      if (updatedNode.type !== node.type) return false
      return true
    },
    options: {
      directions: ['bottom-right', 'bottom-left', 'top-right', 'top-left'],
      min: { width: 50, height: 50 },
      preserveAspectRatio: false, // hold Shift to lock aspect ratio
      className: {
        container: 'my-resize-container',
        wrapper: 'my-resize-wrapper',
        handle: 'my-resize-handle',
        resizing: 'is-resizing',
      },
    },
  })
}
```

### 注意事项：

- 此类不会注入视觉样式；请为 `[data-resize-handle]`、`.is-resizing` 等提供 CSS（示例提供了最简样式）。
- 目前尚未完全支持 contentEditable 节点，调整大小时不会缩放其内容。

---

## 行为细节与边缘情况

- 宽高比与限制：保持宽高比时，若某个尺寸先达到最小值或最大值，则会将该尺寸限制在边界内，并按比例计算另一个尺寸，因此不会破坏宽高比。
- Shift 键：调整大小期间，按下 Shift 可切换临时的宽高比锁定（当 `preserveAspectRatio` 为 `false` 时）。
