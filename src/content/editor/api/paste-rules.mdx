粘贴规则是 Tiptap 的一项强大功能，可在内容粘贴到编辑器时自动转换内容。它们可用于创建格式快捷方式、插入内容，或根据粘贴文本中的特定模式触发命令。

## 什么是粘贴规则？

粘贴规则是基于模式的触发器，用于监视粘贴到编辑器中的特定文本或内容，并自动将其转换为其他内容。例如，粘贴 `**粗体**` 可以自动将文本转换为粗体格式，粘贴图片 URL 则可以创建图片节点。粘贴规则特别适合实现类似 Markdown 的快捷方式，并改善从外部来源粘贴内容时的用户体验。

## Tiptap 中的粘贴规则如何工作？

Tiptap 使用粘贴规则实现许多默认快捷方式和粘贴内容行为。粘贴规则通过正则表达式或自定义匹配器定义，用于匹配粘贴的文本。检测到符合模式的内容后，规则就会执行转换，例如应用标记、插入节点或运行命令。

粘贴规则通常使用 `addPasteRules()` 方法在扩展（节点、标记或通用扩展）中注册。Tiptap 提供了 `markPasteRule` 和 `nodePasteRule` 等辅助函数，以简化标记和节点粘贴规则的创建。

## 在扩展中创建粘贴规则

要添加自定义粘贴规则，请在扩展中定义 `addPasteRules()` 方法。此方法应返回一个粘贴规则数组。

### 示例：使用粘贴规则创建高亮标记

```ts
import { Mark, markPasteRule } from '@tiptap/core'

const HighlightMark = Mark.create({
  name: 'highlight',

  addPasteRules() {
    return [
      markPasteRule({
        find: /(?:==)((?:[^=]+))(?:==)/g, // Matches ==highlight==
        type: this.type,
      }),
    ]
  },
})
```

### 示例：使用粘贴规则创建自定义图形节点

```ts
import { Node, nodePasteRule } from '@tiptap/core'

const FigureNode = Node.create({
  name: 'figure',

  addPasteRules() {
    return [
      nodePasteRule({
        find: /!\[(.*?)\]\((.*?)(?:\s+"(.*?)")?\)/g, // Matches ![alt](src "title")
        type: this.type,
        getAttributes: match => {
          const [, alt, src, title] = match
          return { src, alt, title }
        },
      }),
    ]
  },
})
```

## 了解 `markPasteRule` 和 `nodePasteRule`

Tiptap 提供了两个辅助函数，以简化粘贴规则的创建：

- **`markPasteRule`**：根据粘贴内容中的模式应用标记（如粗体、斜体、高亮）。
- **`nodePasteRule`**：根据粘贴内容中的模式插入或转换节点（如图片、图形、自定义块）。

这两个函数都接受一个配置对象，其中至少包含以下属性：

- `find`：用于匹配粘贴内容模式的正则表达式或匹配器函数。
- `type`：要应用或插入的标记或节点类型。
- `getAttributes`（可选）：用于从正则表达式匹配结果中提取并返回属性的函数。
- `getContent`（仅适用于 `nodePasteRule`，可选）：用于提供节点内容的函数或值。

### 使用 `getAttributes` 提取信息

`getAttributes` 函数可以从匹配的输入中提取数据，并将其作为属性传递给节点或标记。这对于图片或图形等节点特别有用，因为你可能需要从粘贴的内容中提取 `src`、`alt` 或 `title` 等值。

#### 示例：在节点粘贴规则中使用 `getAttributes`

```ts
addPasteRules() {
  return [
    nodePasteRule({
      find: /!\[(.*?)\]\((.*?)(?:\s+"(.*?)")?\)/g, // Matches ![alt](src "title")
      type: this.type,
      getAttributes: match => {
        const [, alt, src, title] = match
        return { src, alt, title }
      },
    }),
  ]
},
```

在此示例中，当用户粘贴类似 `![替代文本](image.png "可选标题")` 的内容时，粘贴规则会从匹配结果中提取 `alt`、`src` 和 `title`，并将它们作为属性传递给节点。

#### 示例：在标记粘贴规则中使用 `getAttributes`

```ts
addPasteRules() {
  return [
    markPasteRule({
      find: /\*\*([^*]+)\*\*/g, // Matches **bold**
      type: this.type,
      getAttributes: match => {
        // You can extract custom attributes here if needed
        return {}
      },
    }),
  ]
},
```

### 提示

- `getAttributes` 中的 `match` 参数是正则表达式的匹配结果，因此可以通过解构获取捕获组。
- 你可以使用 `getAttributes` 设置节点或标记支持的任意属性，例如链接的 `href`、图片的 `src` 或自定义数据字段。
- 如果不需要提取属性，可以省略 `getAttributes`。
- 在正则表达式中使用 `g`（全局）标志，以匹配粘贴内容中的所有匹配项。
