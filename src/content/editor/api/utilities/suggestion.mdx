此工具可帮助你在编辑器中实现各种建议功能。请查看 [`Mention`](/editor/extensions/nodes/mention) 或 [`Emoji`](/editor/extensions/nodes/emoji) 节点，了解其实际效果。

## 设置

### char

触发自动补全弹出层的字符。

默认值：`'@'`

### pluginKey

一个 ProseMirror PluginKey。

默认值：`SuggestionPluginKey`

### allow

一个返回布尔值的函数，用于指示建议功能是否应处于激活状态。

默认值：`(props: { editor: Editor; state: EditorState; range: Range, isActive?: boolean }) => true`

### shouldShow

一个返回布尔值的函数，用于指示建议功能是否应处于激活状态。在协作环境中，这可用于防止远程用户触发建议。

```js
shouldShow: ({ editor, range, query, text, transaction }) => {
  return !isChangeOrigin(transaction)
}
```

默认值：`null`

### shouldResetDismissed

控制用户按 Escape 或调用 `exitSuggestion()` 关闭建议后，何时重新激活已关闭的建议。

默认情况下，只要用户仍处于同一触发上下文中，此工具就会保持建议关闭状态。设置 `allowSpaces: true` 后，该关闭状态的上下文可以跨越空格，直到光标离开为止。

如果需要自行决定何时清除该关闭状态上下文，请使用 `shouldResetDismissed`。

此回调不会针对每个 transaction 调用。只有在建议插件找到有效匹配项、匹配项通过 `allow` 和 `shouldShow` 检查，并且存在可能需要清除的已关闭建议状态时，才会进行计算。

```js
Suggestion({
  // ...
  shouldResetDismissed: ({ transaction, allowSpaces, range, match }) => {
    if (!allowSpaces) {
      return false
    }

    return transaction.doc.textBetween(range.from, match.range.to, '\n').includes('.')
  },
})
```

返回 `true` 可清除此 transaction 对应的关闭状态，并允许建议再次打开。

默认值：`null`

### allowSpaces

允许或禁止建议项中包含空格。此选项与 `allowToIncludeChar` 不兼容——如果 `allowToIncludeChar` 为 `true`，则此选项会被禁用。

默认值：`false`

### allowToIncludeChar

允许在建议查询中包含触发字符本身。此选项与 `allowSpaces` 不兼容。

默认值：`false`

### allowedPrefixes

允许触发建议的前缀字符。设为 `null` 可允许任意前缀字符。

默认值：`[' ']`

### startOfLine

仅在行首触发自动补全弹出层。

默认值：`false`

### minQueryLength

调用 `items()` 函数之前，用户在触发字符后必须输入的最少字符数。

从 API 获取建议时，此选项很有用：当查询过短、没有实际意义时，可避免不必要的网络请求。

默认值：`0`

```js
Suggestion({
  minQueryLength: 2,
  items: async ({ query, signal }) => {
    // Only called when query.length >= 2
    const response = await fetch(`/api/search?q=${query}`, { signal })
    return response.json()
  },
})
```

### debounce

用户停止输入后，调用 `items()` 前等待的毫秒数。这样可以避免每次按键都触发开销较大的操作（例如 API 请求）。

每次按键都会重置防抖计时器，因此只有用户暂停输入达到指定时长后，才会调用 `items()` 函数。

默认值：`0`（不防抖）

```js
Suggestion({
  debounce: 300,
  items: async ({ query }) => {
    // Called 300ms after the user stops typing
    return searchApi(query)
  },
})
```

### initialItems

建议弹出层打开时立即显示的项目数组，在异步 `items()` 调用完成之前展示。`items()` 执行完成后，其结果会替换初始项目。

在实际结果加载时显示最近使用或热门项目，此选项很有用。

```js
Suggestion({
  initialItems: ['Lea Thompson', 'Cyndi Lauper', 'Tom Cruise'],
  items: async ({ query }) => {
    // These replace the initial items once resolved
    return fetchSearchResults(query)
  },
})
```

默认值：`undefined`

### decorationTag

建议装饰使用的 HTML 标签。

默认值：`'span'`

### decorationClass

要添加到建议项的 CSS 类。

默认值：`'suggestion'`

### decorationContent

要在建议装饰中渲染的内容。

默认值：`''`

### decorationEmptyClass

建议项为空时要添加的 CSS 类。

默认值：`'is-empty'`

### placement

建议弹出层相对于光标或触发装饰的首选位置。使用 [Floating UI 的 placement 值](https://floating-ui.com/docs/computePosition#placement)。

解析后的 placement 会传递给 `SuggestionProps.floatingUi.placement`，你可以在渲染回调中读取它。

默认值：`'bottom-start'`

```js
Suggestion({
  placement: 'top-start',
})
```

### offset

将建议弹出层沿每个轴偏移指定像素，使其与锚点保持距离。这些值会传递给 Floating UI 的 [`offset` 中间件](https://floating-ui.com/docs/offset)。

默认值：`{ mainAxis: 4, crossAxis: 0 }`

```js
Suggestion({
  offset: { mainAxis: 8, crossAxis: 4 },
})
```

### flip

启用后，如果首选方向上的空间不足，弹出层会自动翻转到相反方向。此选项用于切换 Floating UI 的 [`flip` 中间件](https://floating-ui.com/docs/flip)。

默认值：`true`

```js
Suggestion({
  placement: 'top-start',
  flip: false,
})
```

### container

用于指定建议弹出层容器的 CSS 选择器字符串或 `HTMLElement`。设置此选项有助于控制滚动区域或 z-index 堆叠上下文。

默认值：`undefined`

```js
Suggestion({
  container: '#my-editor-container',
})
```

### floatingUi

当顶层选项无法满足需求时，可使用此选项进行高级 Floating UI 配置。插件负责管理锚点和位置——使用顶层 [`placement`](#placement) 选项设置方位；`floatingUi` 则用于切换定位 `strategy` 并添加额外的 `middleware`。

传入的任何中间件都会追加在插件根据顶层 `offset` 和 `flip` 选项创建的中间件之后，因此它们会组合使用，而不是相互替换。

```js
import { shift, size } from '@floating-ui/dom'

Suggestion({
  placement: 'top-start',
  floatingUi: {
    strategy: 'fixed',
    middleware: [shift({ padding: 8 }), size()],
  },
})
```

所有属性均为可选。完整类型如下：

```ts
type SuggestionFloatingUiOptions = {
  strategy?: 'absolute' | 'fixed'
  middleware?: Middleware[]
}
```

默认值：`undefined`

### dismissOnOutsideClick

设为 `true` 时，在弹出层和编辑器之外发生指针交互，会关闭当前激活的建议。此选项仅适用于使用[托管定位](#managed-positioning-with-propsmount)（`props.mount`）渲染弹出层的情况，因为插件需要知道哪个元素是弹出层，才能判断哪些位置属于“外部”。

默认值：`true`

### command

选中建议时执行的函数。

默认值：`() => {}`

### items

根据用户输入返回筛选后建议项的函数或异步函数。函数会接收一个 `AbortSignal`（`signal`）；当用户继续输入时（例如新按键使当前请求失效），该信号会中止。可用此信号取消正在进行的 fetch 请求。

```js
items: async ({ editor, query, signal }) => {
  const response = await fetch(`/api/search?q=${query}`, { signal })
  return response.json()
}
```

默认值：`({ editor, query, signal }) => []`

### render

用于渲染自动补全弹出层的函数。它会返回一个包含生命周期钩子（`onStart`、`onBeforeStart`、`onUpdate`、`onBeforeUpdate`、`onExit`、`onKeyDown`）的对象，这些钩子会接收一个 `SuggestionProps` 对象。

传递给每个钩子的 `SuggestionProps` 对象，除了现有的 `editor`、`range`、`query`、`text`、`items`、`command`、`decorationNode` 和 `clientRect` 属性外，还包含以下属性：

```ts
{
  /** Mounts your popup element and takes over positioning. The recommended,
   *  default way to render a suggestion popup — see "Positioning" below.
   *  Returns an `unmount` function to call in `onExit`. */
  mount: (element: HTMLElement, options?: SuggestionMountOptions) => () => void

  /** True while an async items() call is in progress, false otherwise.
   *  Only relevant when items() returns a Promise. */
  loading: boolean

  /** The resolved positioning options, passed through from the suggestion
   *  options so you can read them in your render callbacks. */
  placement: SuggestionPlacement
  offset: { mainAxis: number; crossAxis: number }
  flip: boolean
  container?: string | HTMLElement

  /** Resolved Floating UI config, ready to hand to `computePosition()`.
   *  This is the escape hatch for running your own positioning loop instead
   *  of using `mount()`. */
  floatingUi: {
    placement: SuggestionPlacement
    strategy: 'absolute' | 'fixed'
    middleware: Middleware[]
  }
}
```

默认值：`() => ({})`

### findSuggestionMatch

可选参数，用于替换内置的正则表达式匹配逻辑，以匹配编辑器内容中触发建议的文本。
详情请参阅[源代码](https://github.com/ueberdosis/tiptap/blob/main/packages/suggestion/src/findSuggestionMatch.ts#L18)。

默认值：`findSuggestionMatch(config: Trigger): SuggestionMatch`

## 异步行为

当你的 `items()` 函数返回 `Promise` 时，建议插件会自动处理异步生命周期：

1. **初始状态：** 弹出层打开，`loading` 为 `true`。如果提供了 `initialItems`，这些项目会立即显示。
2. **获取数据：** 使用 `AbortSignal` 调用 `items()` 函数。如果用户继续输入，先前请求的 signal 会中止，并在 `debounce` 延迟后启动新请求。
3. **解析完成：** Promise 解析后，返回的项目会替换当前项目，且 `loading` 变为 `false`。此时会使用新的 `SuggestionProps` 触发 `onUpdate` 回调。
4. **空状态：** 如果未提供 `items()` 函数，或该函数返回空数组，弹出层会显示空状态。除非正在获取数据，否则 `loading` 属性保持为 `false`。
5. **关闭：** 弹出层关闭时（例如用户按下 Escape），任何正在进行的请求都会自动中止。

下面是一个完整示例：

```js
Suggestion({
  minQueryLength: 2,
  debounce: 300,
  initialItems: ['Lea Thompson', 'Cyndi Lauper'],
  items: async ({ query, signal }) => {
    // Simulate an API call — this will be aborted if the query changes
    const response = await fetch(`/api/users?q=${query}`, { signal })
    const data = await response.json()
    return data.slice(0, 5)
  },
  render: () => {
    let component
    let unmount

    return {
      onStart(props) {
        component = new ReactRenderer(MyList, {
          props,
          editor: props.editor,
        })
        // Let the plugin mount and position the popup for you.
        unmount = props.mount(component.element)
      },
      onUpdate(props) {
        // `props.loading` is true while fetching, false otherwise
        // `props.items` contains the resolved data (or initialItems before resolution)
        component.updateProps(props)
      },
      onExit() {
        unmount?.()
        component.destroy()
      },
    }
  },
})
```

## 定位

Suggestion 工具集成了 [Floating UI](https://floating-ui.com/)，用于定位弹出层。定位弹出层有两种方式：

- **使用 `props.mount` 托管定位**——推荐的默认方式。插件会挂载元素，将其锚定到光标，并自动保持其位置。
- **手动定位**——供需要完全控制时使用。你需要自行挂载元素，并使用 `props.floatingUi` 和 `props.clientRect` 实现定位循环。

### 使用 `props.mount` 托管定位

在 `render` 回调中，使用渲染出的弹出层元素调用 `props.mount(element)`（例如 `ReactRenderer` 或 `VueRenderer` 的 `element`）。之后插件会：

- 将元素添加到配置的 [`container`](#container) 中（默认为 `document.body`）；
- 根据你的 [`placement`](#placement)、[`offset`](#offset)、[`flip`](#flip) 和 [`floatingUi`](#floatingui) 选项，将元素锚定到建议对应的光标矩形；
- 通过 Floating UI 的 [`autoUpdate`](https://floating-ui.com/docs/autoUpdate)，在滚动、调整大小和布局偏移时自动重新定位——无需手动添加监听器；
- 启用 [`dismissOnOutsideClick`](#dismissonoutsideclick) 时，在点击外部区域后关闭弹出层。

`mount()` 会返回一个 `unmount` 函数。**必须在 `onExit` 中调用它**，以清理自动更新循环和外部点击监听器（如果元素由插件添加，也会将其移除）。如果忘记调用，监听器会泄漏，DOM 中也会留下孤立的弹出层。

```js
import { ReactRenderer } from '@tiptap/react'
import DropdownList from './DropdownList.jsx'

Suggestion({
  placement: 'top-start',
  offset: { mainAxis: 8 },
  items: ({ query }) => fetchItems(query),
  render: () => {
    let component
    let unmount = null

    return {
      onStart(props) {
        component = new ReactRenderer(DropdownList, {
          props,
          editor: props.editor,
        })

        // The plugin mounts the element, positions it, and keeps it anchored.
        unmount = props.mount(component.element)
      },
      onUpdate(props) {
        component.updateProps(props)
        // No reposition call needed — autoUpdate keeps it anchored.
      },
      onKeyDown(props) {
        if (props.event.key === 'Escape') {
          component.destroy()
          return true
        }
        return component.ref?.onKeyDown(props)
      },
      onExit() {
        unmount?.()
        component.destroy()
      },
    }
  },
})
```

<Callout title="注意" variant="info">
  如果传入的元素已经挂载到 DOM，插件不会移动或移除它——只会对其进行定位。在这种情况下，你需要自行负责挂载和卸载元素。如果希望插件管理 DOM，请传入一个尚未挂载的元素。
</Callout>

### 配置 placement、offset 和 flip

使用顶层的 [`placement`](#placement)、[`offset`](#offset) 和 [`flip`](#flip) 选项，控制托管弹出层的显示位置：

```js
Suggestion({
  placement: 'top-start',
  offset: { mainAxis: 8, crossAxis: 0 },
  flip: true,
})
```

如果需要更改定位 `strategy` 或使用自定义中间件（例如 `shift` 或 `size`），请添加 [`floatingUi`](#floatingui) 选项。其中的 `middleware` 会追加在插件自身的 `offset` 和 `flip` 中间件之后：

```js
import { shift, size } from '@floating-ui/dom'

Suggestion({
  placement: 'bottom-end',
  floatingUi: {
    strategy: 'fixed',
    middleware: [
      shift({ padding: 16 }),
      size({
        apply({ availableWidth, availableHeight, elements }) {
          Object.assign(elements.floating.style, {
            maxWidth: `${availableWidth}px`,
            maxHeight: `${availableHeight}px`,
          })
        },
      }),
    ],
  },
})
```

### 自定义位置的应用方式

默认情况下，托管弹出层的位置通过将 `position`、`left` 和 `top` 写入元素的样式来应用（在首次测量完成前会隐藏元素，避免其短暂出现在错误的位置）。

如果需要使用不同方式应用位置——例如 CSS transform、动画，或写入框架 ref——请在挂载选项中传入 `onPosition` 回调。此时插件会停止自行写入样式，并将计算出的位置坐标交给你：

```js
onStart(props) {
  component = new ReactRenderer(DropdownList, { props, editor: props.editor })

  unmount = props.mount(component.element, {
    onPosition({ x, y, placement, strategy }) {
      Object.assign(component.element.style, {
        position: strategy,
        transform: `translate(${x}px, ${y}px)`,
      })
    },
  })
}
```

<Callout title="注意" variant="info">
  提供 `onPosition` 后，插件不会再于首次测量前隐藏元素，因此你需要自行设置初始位置，以避免元素短暂闪现。
</Callout>

### 跟随动画或变换后的锚点

`autoUpdate` 已能响应滚动、调整大小和布局偏移。对于持续移动的锚点（例如位于经过变换或动画处理的容器中），可传递 [`autoUpdate` 选项](https://floating-ui.com/docs/autoUpdate#options)，启用逐帧更新：

```js
unmount = props.mount(component.element, {
  autoUpdate: { animationFrame: true },
})
```

### 挂载到容器中

如果要在特定的堆叠或滚动上下文中渲染弹出层（例如模态框或对话框），请设置 [`container`](#container) 选项。托管弹出层会添加到指定容器，而非 `document.body`：

```js
Suggestion({
  container: '#my-dialog',
})
```

字符串会被视为 CSS 选择器；你也可以直接传入 `HTMLElement`。如果选择器没有匹配到元素（或选择器无效），插件会回退到 `document.body`。

### 手动定位（高级用法）

如果需要完全控制挂载和定位，请完全跳过 `props.mount`。自行挂载元素，然后结合解析后的 `props.floatingUi` 配置和 `props.clientRect`，运行自己的 Floating UI 定位循环。由于此时 DOM 由你管理，因此也需要自行在 `onUpdate` 中重新定位，并在 `onExit` 中进行清理：

```js
import { computePosition, shift } from '@floating-ui/dom'
import { ReactRenderer } from '@tiptap/react'

function reposition(props, element) {
  const reference = { getBoundingClientRect: () => props.clientRect() }

  computePosition(reference, element, props.floatingUi).then(({ x, y, strategy }) => {
    Object.assign(element.style, {
      position: strategy,
      left: `${x}px`,
      top: `${y}px`,
    })
  })
}

Suggestion({
  floatingUi: {
    strategy: 'fixed',
    middleware: [shift({ padding: 8 })],
  },
  render: () => {
    let component

    return {
      onStart(props) {
        component = new ReactRenderer(DropdownList, { props, editor: props.editor })

        if (!props.clientRect) {
          return
        }

        document.body.appendChild(component.element)
        reposition(props, component.element)
      },
      onUpdate(props) {
        component.updateProps(props)

        if (!props.clientRect) {
          return
        }

        reposition(props, component.element)
      },
      onExit() {
        component.element.remove()
        component.destroy()
      },
    }
  },
})
```

<Callout title="注意" variant="warning">
  使用手动定位时，只会在 `onUpdate` 时重新定位，因此除非你自行添加监听器（或使用 Floating UI 的 `autoUpdate`），弹出层不会跟随滚动、调整大小或布局偏移。`props.mount` 会为你处理这些情况，因此推荐使用该方式。
</Callout>

## 关闭已打开的建议

有时，你可能希望用户在不选择项目的情况下关闭已打开的建议。用户可以按 Escape 关闭建议。
如果要手动关闭建议，可以使用 `exitSuggestion` 工具函数，关闭当前视图中已打开的建议。

```js
import { exitSuggestion } from '@tiptap/suggestion'
import { PluginKey } from 'prosemirror-state' // optional, if you need to create a custom key

const MySuggestionPluginKey = new PluginKey('my-suggestions') // or use the default 'suggestion'

exitSuggestion(editor.view, MySuggestionPluginKey)

// Alternatively, use the default plugin key:
// exitSuggestion(editor.view, 'suggestion')
```

## 协作

在协作环境中使用 Tiptap 时，你可能会发现一位用户触发建议（例如提及）后，所有用户都会看到建议弹出。这是因为文档更改会同步到所有客户端，而每个客户端的建议插件都会对更改作出响应。

要避免这种情况，请将 `shouldShow` 选项与 `@tiptap/extension-collaboration` 中的 `isChangeOrigin` 辅助函数结合使用。

```js
import { isChangeOrigin } from '@tiptap/extension-collaboration'

Suggestion({
  // …
  shouldShow: ({ transaction }) => {
    return !isChangeOrigin(transaction)
  },
})
```

通过返回 `!isChangeOrigin(props.transaction)`，只有当前用户发起更改时才会激活建议。
