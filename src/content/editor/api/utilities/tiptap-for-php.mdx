这是一个用于处理 [Tiptap](https://tiptap.dev/) 内容的 PHP 包。你可以将 Tiptap 兼容的 JSON 转换为 HTML，也可以反向转换、净化内容，或直接修改内容。

## 安装

你可以通过 Composer 安装此包：

```bash
composer require ueberdosis/tiptap-php
```

## 使用 Tiptap PHP 工具

这个 PHP 包模拟了 JavaScript 包的大部分功能。如果你熟悉 Tiptap，PHP 语法也会让你感到熟悉。下面是一个简单示例：

```php
(new Tiptap\Editor)
    ->setContent('<p>Example Text</p>')
    ->getDocument();

// Returns:
// ['type' => 'doc', 'content' => …]
```
