创建自定义扩展时，通常需要定义其渲染为 HTML 的方式。一般来说，可以定义一个 `renderHTML` 函数，返回一个 ProseMirror 渲染数组，其中包含标签名称、属性和内容占位符。

使用 Tiptap JSX 渲染器，可以通过 JSX 定义扩展的渲染方式。

## 在扩展中使用 JSX

要在扩展中使用 JSX，需要使用能够处理 **JSX** 或 **TSX** 文件的打包工具，例如 Vite 或 Webpack。大多数框架（如 Next.js、Remix 或 Nuxt）应该都能直接处理这些文件。

默认情况下，除非另行配置，否则会使用 React 的 JSX 运行时。如果尝试在非 React 环境（例如 Tiptap 扩展）中使用 JSX，就会导致问题。

为了解决这个问题，可以在文件顶部添加注释，指定打包工具应使用哪个 JSX 运行时。Tiptap 在 `@tiptap/core` 中内置了自己的运行时。

```jsx
/** @jsxImportSource @tiptap/core */

// your code here
```

## 在 `renderHTML` 函数中编写 JSX

现在，打包工具应该能够为 Tiptap 处理 JSX 了，你可以在 `renderHTML` 函数中使用 JSX。

```jsx
/** @jsxImportSource @tiptap/core */

import { Node } from '@tiptap/core'

const MyNode = Node.create({
  // ... your node configuration

  renderHTML({ HTMLAttributes }) {
    return (
      <div {...HTMLAttributes}>
        <p>This is your custom node. And here is your content hole:</p>
        <slot />
      </div>
    )
  }
})
```

`<slot />` 标签用于通过 JSX 为 ProseMirror 定义内容占位符。这是可编辑内容将被渲染到的位置。

**注意：** 底层并未使用 React 或 Vue 等组件库，因此不支持钩子、状态或其他特定于这些库的功能。
