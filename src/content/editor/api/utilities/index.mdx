Tiptap 工具扩展了 Editor API，提供能够改进和扩展你与编辑器及内容交互方式的工具。

## 所有工具

| 工具名称                                                   | 描述                                                                                   |
| ---------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| [`HTML 工具`](/editor/api/utilities/html)                   | 在服务器端处理 JSON 和 HTML 转换。                                                     |
| [`JSX`](/editor/api/utilities/jsx)                         | 使用 JSX 控制扩展渲染为 HTML 的方式。                                                  |
| [`位置工具`](/editor/api/utilities/position)                | 随着文档变化，跟踪并更新编辑器中的位置。                                               |
| [`静态渲染器`](/editor/api/utilities/static-renderer)       | 无需编辑器实例，即可将 JSON 内容渲染为 HTML、Markdown 或 React 组件。                   |
| [`建议工具`](/editor/api/utilities/suggestion)              | 为编辑器添加可自定义的自动补全建议。                                                   |
| [`Tiptap for PHP`](/editor/api/utilities/tiptap-for-php)   | 将 Tiptap 功能集成到 PHP 项目中。                                                     |
