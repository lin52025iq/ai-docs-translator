输入规则是 Tiptap 中的一项强大功能，可在你输入时自动转换文本。你可以用它创建格式设置快捷方式、插入内容，或根据文本中的特定模式触发命令。

## 什么是输入规则？

输入规则是一种基于模式的触发器，会监视特定文本输入，并自动将其转换为其他内容。例如，输入 `**粗体**` 可以自动将文本设为粗体格式，或者在行首输入 `1.` 可以创建有序列表。输入规则特别适合实现类似 Markdown 的快捷方式，并改善用户体验。

## Tiptap 中的输入规则如何工作？

Tiptap 在底层使用输入规则来提供许多默认快捷方式（例如列表、引用块和标记）。输入规则以正则表达式的形式定义，用于匹配用户输入。检测到匹配模式后，规则便会执行转换，例如应用标记、插入节点或运行命令。

输入规则通常通过 `addInputRules()` 方法在扩展（节点、标记或通用扩展）中注册。Tiptap 提供了 `markInputRule` 和 `nodeInputRule` 等辅助函数，以简化标记和节点输入规则的创建。

## 了解 `markInputRule` 和 `nodeInputRule`

Tiptap 提供了两个辅助函数，以简化输入规则的创建：

- **`markInputRule`**：根据模式应用标记（如粗体、斜体、高亮）。
- **`nodeInputRule`**：根据模式插入或转换节点（如图像、图表、自定义块）。

这两个函数都接受一个配置对象，其中至少包含以下属性：

- `find`：用于匹配输入模式的正则表达式。
- `type`：要应用或插入的标记或节点类型。
- `getAttributes`（可选）：从正则表达式匹配结果中提取并返回属性的函数。
- `undoable`（可选）：输入规则是否可以撤销。默认为 `true`。

### 使用 `getAttributes` 提取信息

`getAttributes` 函数可以从匹配的输入中提取数据，并将其作为属性传递给节点或标记。这对于图像或图表等节点特别有用，因为你可能需要从用户输入中获取 `src`、`alt` 或 `title` 等值。

#### 示例：在节点输入规则中使用 `getAttributes`

```ts
addInputRules() {
  return [
    nodeInputRule({
      find: /!\[(.*?)\]\((.*?)(?:\s+"(.*?)")?\)$/, // Matches ![alt](src "title")
      type: this.type,
      getAttributes: match => {
        const [, alt, src, title] = match
        return { src, alt, title }
      },
    }),
  ]
},
```

在此示例中，当用户输入类似 `![替代文本](image.png "可选标题")` 的内容时，输入规则会从匹配结果中提取 `alt`、`src` 和 `title`，并将它们作为属性传递给节点。

#### 示例：在标记输入规则中使用 `getAttributes`

```ts
addInputRules() {
  return [
    markInputRule({
      find: /\*\*([^*]+)\*\*$/, // Matches **bold**
      type: this.type,
      getAttributes: match => {
        // You can extract custom attributes here if needed
        return {}
      },
    }),
  ]
},
```

### 提示

- `getAttributes` 中的 `match` 参数是正则表达式的匹配结果，你可以通过解构获取捕获组。
- 你可以使用 `getAttributes` 设置节点或标记支持的任意属性，例如链接的 `href`、图像的 `src` 或自定义数据字段。
- 如果不需要提取属性，可以省略 `getAttributes`。

更多详情请参阅 [ProseMirror 输入规则文档](https://prosemirror.net/docs/ref/#inputrules.InputRule)。
