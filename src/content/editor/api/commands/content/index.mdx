使用这些命令可在编辑器中动态插入、替换或删除内容。无论是初始化新文档、更新现有文档，还是管理用户选择，这些命令都能帮助你处理内容操作。

## 使用场景

- **初始化新文档：** 使用 [`setContent`](/editor/api/commands/content/set-content) 命令，创建空白文档或初始化预定义模板。
- **更新现有内容：** 使用 [`insertContent`](/editor/api/commands/content/insert-content) 或 [`insertContentAt`](/editor/api/commands/content/insert-content-at) 命令，根据用户交互添加新内容或更新特定部分。
- **清除内容：** 使用 [`clearContent`](/editor/api/commands/content/clear-content) 命令移除所有内容，同时保持文档结构有效。
- **管理用户选择：** 根据用户的选择，使用 [`insertContentAt`](/editor/api/commands/content/insert-content-at) 在特定位置或范围插入或替换内容。

## 内容命令列表

| 命令              | 描述                                      |
| ----------------- | ----------------------------------------- |
| `clearContent`    | 删除当前文档，同时遵循编辑器的 schema。   |
| `insertContent`   | 使用纯文本、HTML 或 JSON 向文档添加内容。 |
| `insertContentAt` | 在文档中的特定位置或范围插入内容。        |
| `setContent`      | 使用 JSON 或 HTML 替换整个文档。          |
