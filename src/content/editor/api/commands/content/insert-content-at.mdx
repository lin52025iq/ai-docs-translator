`insertContentAt` 会在指定位置或范围插入 HTML 字符串或节点。如果指定了范围，新内容将替换该范围内的内容。

## 参数

`position: number | Range`

要插入内容的位置或范围。

`value: Content`

要插入的内容。可以是纯文本、HTML 字符串或 JSON 节点。

`options: Record<string, any>`

- updateSelection：控制是否将选区移至新插入的内容。
- parseOptions：传入的内容由 ProseMirror 解析。若要介入解析过程，可以传入 `parseOptions`，它会由 [ProseMirror](https://prosemirror.net/docs/ref/#model.ParseOptions) 处理。

## 使用 insertContentAt 命令

```js
// Plain text
editor.commands.insertContentAt(12, 'Example Text')

// Plain text, replacing a range
editor.commands.insertContentAt({ from: 12, to: 16 }, 'Example Text')

// HTML
editor.commands.insertContentAt(12, '<h1>Example Text</h1>')

// HTML preserving whitespace
editor.commands.insertContentAt(12, '<p>Hello world</p>', {
  updateSelection: true,
  parseOptions: {
    preserveWhitespace: 'full',
  },
})

// JSON/Nodes
editor.commands.insertContentAt(12, {
  type: 'heading',
  attrs: {
    level: 1,
  },
  content: [
    {
      type: 'text',
      text: 'Example Text',
    },
  ],
})

// Multiple nodes at once
editor.commands.insertContentAt(12, [
  {
    type: 'paragraph',
    content: [
      {
        type: 'text',
        text: 'First paragraph',
      },
    ],
  },
  {
    type: 'paragraph',
    content: [
      {
        type: 'text',
        text: 'Second paragraph',
      },
    ],
  },
])
```
