`clearContent` 命令会删除当前文档。编辑器会保留满足其架构所需的内容，例如，使用默认设置的 StarterKit 时会保留一个空段落。

另请参阅：[setContent](/editor/api/commands/content/set-content)、[insertContent](/editor/api/commands/content/insert-content)

## 参数

`emitUpdate?: boolean (true)`
是否触发更新事件。默认为 `true`（注意：此默认值在 v2 中由 `false` 改为 `true`）。

## 示例

```js
// Clear content (emits update event by default)
editor.commands.clearContent()

// Clear content without emitting update
editor.commands.clearContent(false)
```
