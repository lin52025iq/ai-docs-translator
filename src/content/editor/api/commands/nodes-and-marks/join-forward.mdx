`joinForward` 命令会根据当前选区向前合并两个节点。如果选区为空且位于文本块末尾，`joinForward` 会尝试缩短该文本块与其后文本块之间的距离。[另请参阅](https://prosemirror.net/docs/ref/#commands.joinForward)

## 使用 joinForward 命令

```js
editor.commands.joinForward()
```
