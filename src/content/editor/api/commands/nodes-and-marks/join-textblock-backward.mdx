joinBackward 的一个受限版本：仅当光标位于文本块开头时，才尝试将当前文本块与前一个文本块合并。[另请参阅](https://prosemirror.net/docs/ref/#commands.joinTextblockBackward)

## 使用 joinTextblockBackward 命令

```js
editor.commands.joinTextblockBackward()
```
