`joinUp` 命令会将选中的块与其上方的同级块合并。如果选中的是文本，则会将包含该选区且可合并的最近祖先块与其上方的同级块合并。[另请参阅](https://prosemirror.net/docs/ref/#commands.joinUp)

## 使用 joinUp 命令

```js
editor.commands.joinUp()
```
