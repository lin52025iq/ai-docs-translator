`lift` 命令会将指定节点提升到其父节点中。**提升**是指将块移动到其当前所在块的父级。

## 参数

`typeOrName: String | NodeType`

要提升的节点。如果当前选区中未找到该节点，则忽略此命令。

`attributes: Record<string, any>`

要提升的节点必须具有的属性。此参数为**可选**。

## 使用 lift 命令

```js
// lift any headline
editor.commands.lift('headline')

// lift only h2
editor.commands.lift('headline', { level: 2 })
```
