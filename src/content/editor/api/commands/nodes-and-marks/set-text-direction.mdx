`setTextDirection` 命令可设置当前选区或指定位置处节点的文本方向。此命令适用于控制阿拉伯语和希伯来语等从右到左（RTL）语言的方向，或处理双向文本内容。

另请参阅：[unsetTextDirection](/editor/api/commands/nodes-and-marks/unset-text-direction)

## 参数

### direction

要设置的文本方向。可以是 `'ltr'`（从左到右）、`'rtl'`（从右到左）或 `'auto'`（根据内容自动检测）。

### position

可选。要应用方向的位置或范围。如果未提供，命令将使用当前选区。

可以是：
- 表示特定位置的数字
- 包含 `from` 和 `to` 属性、表示范围的对象

## 示例

```js
// 将当前选区设为 RTL 方向
editor.commands.setTextDirection('rtl')

// 将当前选区设为 LTR 方向
editor.commands.setTextDirection('ltr')

// 将当前选区设为自动方向
editor.commands.setTextDirection('auto')

// 为特定位置设置方向
editor.commands.setTextDirection('rtl', 5)

// 为特定范围设置方向
editor.commands.setTextDirection('ltr', { from: 0, to: 10 })

// 与其他命令串联使用
editor.chain().focus().setTextDirection('rtl').run()
```
