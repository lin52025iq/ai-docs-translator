Tiptap 提供了便捷的命令来操作节点和标记。

节点和标记是 Tiptap 编辑器的构成基础。节点表示段落、标题或图像等内容元素，而标记则提供粗体、斜体或链接等行内格式。

## 使用场景

- **创建新节点：** 使用 [`createParagraphNear`](/editor/api/commands/nodes-and-marks/create-paragraph-near) 或 [`splitBlock`](/editor/api/commands/nodes-and-marks/split-block)，在选区附近添加新节点。
- **管理节点结构：** 使用 [`setNode`](/editor/api/commands/nodes-and-marks/set-node)、[`lift`](/editor/api/commands/nodes-and-marks/lift) 或 [`toggleNode`](/editor/api/commands/nodes-and-marks/toggle-node) 等命令更新、替换或提升节点。
- **操作标记：** 使用 [`toggleMark`](/editor/api/commands/nodes-and-marks/toggle-mark)、[`setMark`](/editor/api/commands/nodes-and-marks/set-mark) 或 [`unsetMark`](/editor/api/commands/nodes-and-marks/unset-mark) 等命令切换、设置或取消设置标记。
- **清理内容：** 使用 [`clearNodes`](/editor/api/commands/nodes-and-marks/clear-nodes)、[`unsetAllMarks`](/editor/api/commands/nodes-and-marks/unset-all-marks) 或 [`resetAttributes`](/editor/api/commands/nodes-and-marks/reset-attributes) 移除不需要的标记或节点。

## 节点和标记命令列表

| 命令                  | 说明                                       |
| --------------------- | ------------------------------------------ |
| `clearNodes`          | 清除所有节点，同时遵循编辑器的 schema。     |
| `createParagraphNear` | 在当前选区附近创建一个新的段落节点。        |
| `deleteNode`          | 删除选中的节点。                           |
| `extendMarkRange`     | 扩展当前选区，使其包含指定标记。            |
| `exitCode`            | 退出当前代码块，并在新的默认块中继续编辑。  |
| `insertDefaultBlock`  | 在指定位置插入 schema 中的默认块类型。     |
| `joinBackward`        | 从当前选区向后合并两个节点。               |
| `joinForward`         | 从当前选区向前合并两个节点。               |
| `lift`                | 将节点提升至其父节点中。                   |
| `liftEmptyBlock`      | 提升当前选中的空文本块。                   |
| `newlineInCode`       | 在当前代码块中插入新行。                   |
| `resetAttributes`     | 将节点的指定属性重置为默认值。             |
| `setMark`             | 在当前选区添加新标记。                     |
| `setNode`             | 使用指定节点替换给定范围。                 |
| `splitBlock`          | 在当前选区处将当前节点拆分为两个节点。     |
| `toggleMark`          | 在当前选区切换指定标记的启用和禁用状态。   |
| `toggleNode`          | 将一个节点切换为另一个节点。               |
| `toggleWrap`          | 使用新节点包裹当前节点，或移除包裹节点。   |
| `undoInputRule`       | 撤销最近触发的输入规则。                   |
| `unsetAllMarks`       | 移除当前选区中的所有标记。                 |
| `unsetMark`           | 移除当前选区中的指定标记。                 |
| `updateAttributes`    | 将节点或标记的属性设为新值。               |
