`unsetAllMarks` 会移除当前选区中的所有标记。默认情况下，它会遵循每个标记的 [`clearable`](/editor/extensions/custom-extensions/create-new/mark#clearable) 选项——`clearable: false` 的标记不会被移除。

## 参数

`options?: Record<string, any>`

- `ignoreClearable?: boolean` - 如果为 `true`，则无论标记的 `clearable` 设置如何，都会移除所有标记。默认为 `false`

## 使用 unsetAllMarks 命令

```js
// removes all marks that have clearable: true (default behavior)
editor.commands.unsetAllMarks()

// removes all marks, ignoring the clearable option
editor.commands.unsetAllMarks({ ignoreClearable: true })
```
