`toggleWrap` 会用新节点包裹当前节点，或移除包裹节点。

## 参数

`typeOrName: string | NodeType`

用作包裹节点的节点类型。

`attributes?: Record<string, any>`

要应用于节点的属性。**这是可选项。**

## 使用 toggleWrap 命令

```js
// toggle wrap the current selection with a blockquote node
editor.commands.toggleWrap('blockquote')
```
