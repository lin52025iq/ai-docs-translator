joinTextblockForward 是 joinForward 的简化形式，仅当光标位于文本块末尾时，才会尝试将当前文本块与其后的文本块合并。[另请参阅](https://prosemirror.net/docs/ref/#commands.joinTextblockForward)

## 使用 joinTextblockForward 命令

```js
editor.commands.joinTextblockForward()
```
