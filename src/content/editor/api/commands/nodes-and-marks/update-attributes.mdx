`updateAttributes` 命令会将节点或标记的属性设为新值。未传入的属性不会受到影响。

另请参阅：[extendMarkRange](/editor/api/commands/nodes-and-marks/extend-mark-range)

## 参数

`typeOrName: string | NodeType | MarkType`

传入要更新的类型，例如 `'heading'`。

`attributes: Record<string, any>`

此参数需要一个包含待更新属性的对象，无需包含所有属性。

## 使用 updateAttributes 命令

```js
// 更新节点属性
editor.commands.updateAttributes('heading', { level: 1 })

// 更新标记属性
editor.commands.updateAttributes('highlight', { color: 'pink' })
```
