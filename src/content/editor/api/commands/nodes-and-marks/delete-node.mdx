`deleteNode` 命令会删除当前选区中的一个节点。它需要一个 `typeOrName` 参数，该参数可以是字符串或 `NodeType`，用于查找要删除的节点。删除节点后，视图会自动滚动到光标位置。

## 参数

`typeOrName: string | NodeType`

## 使用 deleteNode 命令

```js
// 删除段落节点
editor.commands.deleteNode('paragraph')

// 或

// 删除自定义节点
editor.commands.deleteNode(MyCustomNode)
```
