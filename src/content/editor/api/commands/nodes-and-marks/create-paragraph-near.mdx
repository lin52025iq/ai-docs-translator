如果当前选中了一个块节点，`createParagraphNear` 命令会在该块节点后创建一个空段落。如果选中的块节点是其父节点的第一个子节点，则会在当前选区前插入新段落。

## 使用 createParagraphNear 命令

```js
editor.commands.createParagraphNear()
```
