`clearNodes` 命令会将节点规范化为默认节点，默认情况下即段落节点。它甚至会规范化各种列表。在一些高级用例中，应用新的节点类型之前使用此命令会很有帮助。

如果你想了解如何定义默认节点：这取决于 [`Document`](/editor/extensions/nodes/document) 的 `content` 属性。默认值为 `block+`（至少包含一个块级节点），而 [`Paragraph`](/editor/extensions/nodes/paragraph) 节点的优先级最高，因此会最先加载，也就成为默认节点。

## 使用 clearNodes 命令

```js
editor.commands.clearNodes()
```
