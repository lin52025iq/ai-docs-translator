`joinBackward` 命令会从当前选区向后合并两个节点。如果选区为空且位于文本块的开头，`joinBackward` 会尝试缩短该文本块与前一个文本块之间的距离。[另请参阅](https://prosemirror.net/docs/ref/#commands.joinBackward)

## 使用 joinBackward 命令

```js
editor.commands.joinBackward()
```
