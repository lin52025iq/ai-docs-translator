`toggleNode` 可将一种节点切换为另一种节点。两个节点都必须是文本块节点。

## 参数

`typeOrName: string | NodeType`

要切换的节点类型。

`toggleTypeOrName: string | NodeType`

用于切换的节点类型。

`attributes?: Record<string, any>`

要应用于节点的属性。**此参数可选。**

## 使用 toggleNode 命令

```js
// toggle a paragraph with a heading node
editor.commands.toggleNode('heading', 'paragraph', { level: 1 })

// toggle a paragraph with a code block
editor.commands.toggleNode('codeBlock', 'paragraph')
```
