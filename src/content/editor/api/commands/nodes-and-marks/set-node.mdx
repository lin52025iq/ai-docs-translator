`setNode` 命令会将指定范围替换为指定节点。范围取决于当前选区。**重要提示**：目前 `setNode` 仅支持文本块节点。

## 参数

`typeOrName: string | NodeType`

用于替换该范围的节点类型。可以是字符串或 NodeType。

`attributes?: Record<string, any>`

要应用于节点的属性。**此参数可选。**

## 使用 setNode 命令

```js
editor.commands.setNode('paragraph', { id: 'paragraph-01' })
```
