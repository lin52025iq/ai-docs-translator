`joinDown` 命令会将选中的块与其下方的同级块合并。如果当前选中的是文本，则会将包含该选区且可合并的最近祖先块与其下方的同级块合并。[另请参阅](https://prosemirror.net/docs/ref/#commands.joinDown)

## 使用 joinDown 命令

```js
editor.commands.joinDown()
```
