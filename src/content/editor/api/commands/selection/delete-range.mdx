`deleteRange` 命令会删除指定范围内的所有内容。它需要一个 `Range` 类型的 `range` 属性。

## 参数

`range: Range`

## 使用 deleteRange 命令

```js
editor.commands.deleteRange({ from: 0, to: 12 })
```
