`setNodeSelection` 会在指定位置创建新的 NodeSelection。节点选择是一种指向单个节点的选择。[了解更多](https://prosemirror.net/docs/ref/#state.NodeSelection)

## 参数

`position: number`

创建 NodeSelection 的位置。

## 使用 setNodeSelection 命令

```js
editor.commands.setNodeSelection(10)
```
