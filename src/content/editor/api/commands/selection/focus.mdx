此命令会将焦点设回编辑器。

用户点击编辑器外部的按钮时，浏览器会将焦点设到该按钮上。在大多数情况下，你会希望随后再次将焦点设回编辑器。这就是为什么你几乎会在这里的每个演示中看到这个命令。

另请参阅：[setTextSelection](/editor/api/commands/selection/set-text-selection)、[blur](/editor/api/commands/selection/blur)

## 参数

`position: 'start' | 'end' | 'all' | number | boolean | null (null)`

当 `position` 为 `null`（默认值）时，会恢复光标位置和文本选区。传入一个位置可移动光标。传入 `false` 可跳过设置焦点。

`options: { scrollIntoView: boolean }`

定义设置焦点时是否滚动到光标位置。默认为 `true`。

## 使用 focus 命令

```js
// 将焦点设到编辑器
editor.commands.focus()

// 将光标设到第一个位置
editor.commands.focus('start')

// 将光标设到最后一个位置
editor.commands.focus('end')

// 选中整个文档
editor.commands.focus('all')

// 将光标设到位置 10
editor.commands.focus(10)
```
