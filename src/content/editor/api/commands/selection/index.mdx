Tiptap 编辑器提供了用于管理文档中选区和焦点的编辑器命令。下面概述了一些重要的选区命令，可帮助你管理光标移动、选区和焦点行为。

## 使用场景

- **管理焦点和失焦：** 使用 [`focus`](/editor/api/commands/selection/focus) 和 [`blur`](/editor/api/commands/selection/blur) 控制焦点行为。
- **删除和选择内容：** 使用 [`deleteSelection`](/editor/api/commands/selection/delete-selection) 和 [`selectAll`](/editor/api/commands/selection/select-all) 等命令，高效管理内容。
- **浏览文档：** 使用 [`scrollIntoView`](/editor/api/commands/selection/scroll-into-view) 滚动到指定位置或节点，并使用 [`selectNodeBackward`](/editor/api/commands/selection/select-node-backward)、[`selectNodeForward`](/editor/api/commands/selection/select-node-forward) 或 [`selectParentNode`](/editor/api/commands/selection/select-parent-node) 选择特定节点。

## 选区命令列表

| 命令                 | 说明                                                                                 |
| -------------------- | ------------------------------------------------------------------------------------------- |
| `blur`               | 移除编辑器的焦点。                                                              |
| `deleteRange`        | 删除指定范围内的所有内容。                                                              |
| `deleteSelection`    | 删除当前选区或光标位置处的内容。                                           |
| `enter`              | 模拟按下 Enter 键，创建新行。                                          |
| `focus`              | 重新聚焦编辑器，并将光标移至指定位置。                 |
| `keyboardShortcut`   | 触发具有指定名称的 ShortcutEvent。                                                 |
| `scrollIntoView`     | 将视图滚动到当前选区或光标位置。                               |
| `selectAll`          | 选中整个文档。                                                                |
| `selectNodeBackward` | 如果光标位于文本块开头，则选择当前文本块之前的节点。 |
| `selectNodeForward`  | 如果光标位于文本块末尾，则选择当前文本块之后的节点。    |
| `selectParentNode`   | 将选区移至当前所选节点的父节点。                      |
| `setNodeSelection`   | 在指定位置创建新的 NodeSelection。                                            |
| `setTextSelection`   | 通过将文本选区设为指定范围或位置来控制文本选区。                 |
