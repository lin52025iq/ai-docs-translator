列表是组织 Tiptap 编辑器内容的重要组成部分。Tiptap 提供了便捷的命令来操作列表结构。下面介绍一些可用于创建、更新和管理列表的核心命令。

## 使用场景

- **创建和切换列表：** 使用 [`toggleList`](/editor/api/commands/lists/toggle-list) 创建列表或切换列表类型。
- **嵌套和取消嵌套列表项：** 使用 [`liftListItem`](/editor/api/commands/lists/lift-list-item) 和 [`sinkListItem`](/editor/api/commands/lists/sink-list-item) 等命令提升或下沉列表项。
- **拆分和包装列表项：** 使用 [`splitListItem`](/editor/api/commands/lists/split-list-item) 和 [`wrapInList`](/editor/api/commands/lists/wrap-in-list) 高效地拆分或包装列表项。
- **优化列表的键盘操作：** 使用 [`List Keymap`](/editor/extensions/functionality/listkeymap) 扩展，通过额外的键位映射处理器改进列表行为。

## List Keymap 扩展

你也可以添加 [`List Keymap`](/editor/extensions/functionality/listkeymap) 扩展，它会增加额外的键位映射处理器，以更改列表默认的退格键和删除键行为。它会修改默认行为：在列表项开头按退格键时，将该项内容提升到上方的列表项中。

## 列表命令一览

| 命令            | 说明                                                       |
| --------------- | ---------------------------------------------------------- |
| `liftListItem`  | 尝试将当前选区所在的列表项提升到其外层父列表中。           |
| `sinkListItem`  | 尝试将当前选区所在的列表项下沉到其内层子列表中。           |
| `splitListItem` | 将一个列表项拆分为两个独立的列表项。                       |
| `toggleList`    | 在不同类型的列表之间切换。                                 |
| `wrapInList`    | 将当前选区中的节点包装在列表中。                           |
