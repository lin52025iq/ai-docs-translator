编辑器提供了大量命令，可通过编程方式添加或更改内容，也可以更改选区。如果你想构建自己的编辑器，一定要深入了解这些命令。

## 执行命令

所有可用命令都可以通过编辑器实例访问。假设你希望用户点击按钮时将文本加粗，可以这样做：

```js
editor.commands.setBold()
```

这样做完全没问题，也确实会将选中的文本加粗，但你可能还希望一次链式调用多个命令。下面来看看如何操作。

### 链式调用命令

大多数命令都可以合并为一次调用。在大多数情况下，这比单独调用多个函数更简洁。下面是将选中文本加粗的示例：

```js
editor.chain().focus().toggleBold().run()
```

`.chain()` 用于开始新的调用链，而 `.run()` 则用于实际执行其中的所有命令。

上面的示例会同时执行两个不同的命令。用户点击内容区域外的按钮时，编辑器就会失去焦点。因此，你可能希望在大多数命令中添加 `.focus()` 调用。它会让编辑器重新获得焦点，用户便可以继续输入。

链式调用中的所有命令会先加入队列，并合并为一个事务。这意味着内容只会更新一次，`update` 事件也只会触发一次。

例如，你可能希望将 **delete** 和 **insert** 命令链接在一起：

```js
addCommands() {
  return {
    delete: () => ({ tr }) => {
      tr.delete(tr.selection.from, tr.selection.to)

      return true
    },
    insert: (content: string) => ({ tr }) => {
      tr.insertText(content, tr.selection.from)

      return true
    },
  }
}
```

现在，你可以将这两个命令链接起来：

```js
editor.chain().delete().insert('foo').run()
```

#### 在自定义命令中链式调用

链式调用命令时，事务会暂缓提交。如果想在自定义命令中链式调用命令，需要使用该事务并将命令添加到其中。操作方法如下：

```js
addCommands() {
  return {
    customCommand: attributes => ({ chain }) => {
      // Doesn’t work:
      // return editor.chain() …

      // Does work:
      return chain()
        .insertContent('foo!')
        .insertContent('bar!')
        .run()
    },
  }
}
```

### 内联命令

在某些情况下，在命令中加入更多逻辑会很有用。因此，你可以在命令中执行命令。我知道，这听起来有点不可思议，不过我们来看一个示例：

```js
editor
  .chain()
  .focus()
  .command(({ tr }) => {
    // manipulate the transaction
    tr.insertText('hey, that’s cool!')

    return true
  })
  .run()
```

### 试运行命令

有时，你并不想实际运行命令，而只是想知道命令是否可以运行，例如据此显示或隐藏菜单中的按钮。为此，我们添加了 `.can()`。此方法之后的所有命令都会执行，但不会将更改应用到文档：

```js
editor.can().toggleBold()
```

你也可以将它与 `.chain()` 一起使用。下面的示例会检查是否可以应用所有命令：

```js
editor.can().chain().toggleBold().toggleItalic().run()
```

如果可以应用这些命令，这两种调用都会返回 `true`；否则返回 `false`。

要让自定义命令也能这样使用，别忘了返回 `true` 或 `false`。

对于某些自定义命令，你可能需要直接操作原始 [事务](/editor/core-concepts/introduction)。要让它们支持 `.can()`，应检查是否需要派发事务。下面是创建简单 `.insertText()` 命令的方法：

```js
export default (value) =>
  ({ tr, dispatch }) => {
    if (dispatch) {
      tr.insertText(value)
    }

    return true
  }
```

如果你只是封装另一个 Tiptap 命令，就不需要检查这一点，我们会替你处理。

```js
addCommands() {
  return {
    bold: () => ({ commands }) => {
      return commands.toggleMark('bold')
    },
  }
}
```

如果你只是封装一个普通的 ProseMirror 命令，则仍需传入 `dispatch`。这种情况下也无需再检查它：

```js
import { exitCode } from '@tiptap/pm/commands'

export default () =>
  ({ state, dispatch }) => {
    return exitCode(state, dispatch)
  }
```

### 尝试执行命令

如果你想运行一组命令，但只应用第一个成功的命令，可以使用 `.first()` 方法。此方法会依次运行命令，并在第一个返回 `true` 的命令处停止。

例如，退格键会先尝试撤销输入规则。如果成功，就会在此处停止。如果没有应用输入规则，因此也无法撤销，它就会运行下一个命令；若存在选区，则删除该选区。简化后的示例如下：

```js
editor.commands.first(({ commands }) => [
  () => commands.undoInputRule(),
  () => commands.deleteSelection(),
  // …
])
```

你也可以在命令内部执行相同操作：

```js
export default () =>
  ({ commands }) => {
    return commands.first([
      () => commands.undoInputRule(),
      () => commands.deleteSelection(),
      // …
    ])
  }
```

## 命令列表

请查看下方列出的所有核心命令，初步了解可以实现哪些功能。

### 内容

| 命令                | 描述                     |
| ------------------- | ------------------------ |
| `clearContent()`    | 清空整个文档。           |
| `insertContent()`   | 在当前位置插入节点或 HTML 字符串。 |
| `insertContentAt()` | 在指定位置插入节点或 HTML 字符串。 |
| `setContent()`      | 用新内容替换整个文档。   |

### 节点和标记

| 命令                    | 描述                                 |
| ----------------------- | ------------------------------------ |
| `clearNodes()`          | 将节点规范化为简单段落。             |
| `createParagraphNear()` | 在附近创建一个段落。                 |
| `deleteNode()`          | 删除节点。                           |
| `extendMarkRange()`     | 将文本选区扩展到当前标记范围。       |
| `exitCode()`            | 退出代码块。                         |
| `insertDefaultBlock()`  | 在指定位置插入默认块类型。           |
| `joinBackward()`        | 向后合并两个节点。                   |
| `joinForward()`         | 向前合并两个节点。                   |
| `lift()`                | 移除现有的包裹。                     |
| `liftEmptyBlock()`      | 如果块为空，则将其提升。             |
| `newlineInCode()`       | 在代码中添加换行符。                 |
| `resetAttributes()`     | 将部分节点或标记属性重置为默认值。   |
| `setMark()`             | 添加带有新属性的标记。               |
| `setNode()`             | 用节点替换指定范围。                 |
| `splitBlock()`          | 从现有节点拆分出一个新节点。         |
| `toggleMark()`          | 切换标记的启用和禁用状态。           |
| `toggleNode()`          | 在不同节点之间切换。                 |
| `toggleWrap()`          | 使用另一个节点包裹节点，或移除现有包裹。 |
| `undoInputRule()`       | 撤销输入规则。                       |
| `unsetAllMarks()`       | 移除当前选区中的所有标记。           |
| `unsetMark()`           | 移除当前选区中的标记。               |
| `updateAttributes()`    | 更新节点或标记的属性。               |

### 列表

| 命令              | 描述                     |
| ----------------- | ------------------------ |
| `liftListItem()`  | 将列表项提升到外层列表。 |
| `sinkListItem()`  | 将列表项下沉到内层列表。 |
| `splitListItem()` | 将一个列表项拆分为两个列表项。 |
| `toggleList()`    | 在不同列表类型之间切换。 |
| `wrapInList()`    | 使用列表包裹节点。       |

### 选区

| 命令                  | 描述                         |
| --------------------- | ---------------------------- |
| `blur()`              | 使编辑器失去焦点。           |
| `deleteRange()`       | 删除指定范围。               |
| `deleteSelection()`   | 如果存在选区，则将其删除。   |
| `enter()`             | 触发回车操作。               |
| `focus()`             | 将编辑器聚焦到指定位置。     |
| `keyboardShortcut()`  | 触发键盘快捷键。             |
| `scrollIntoView()`    | 将选区滚动到可视区域内。     |
| `selectAll()`         | 选中整个文档。               |
| `selectNodeBackward()` | 向后选择一个节点。          |
| `selectNodeForward()` | 向前选择一个节点。           |
| `selectParentNode()`  | 选择父节点。                 |
| `setNodeSelection()`  | 创建一个 NodeSelection。     |
| `setTextSelection()`  | 创建一个 TextSelection。     |
