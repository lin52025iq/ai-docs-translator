图像形状通过 URL 显示图像。用户可以将图像文件粘贴或拖放到白板上，由你的应用上传，白板会保存上传返回的 URL。这样，白板本身无需存储图像文件。

## 上传文件

通过 `WhiteboardKit` 的 `images` 选项，指定图像文件的上传位置。如果不配置此选项，用户就无法添加图像，但白板上已有的图像仍会显示。下面的示例会将每个文件发送到应用的一个端点，该端点会返回文件的 URL：

```js
import { Editor } from '@tiptap/core'
import { WhiteboardKit } from '@tiptap-pro/extension-whiteboard'

const upload = async ({ file, signal }) => {
  const body = new FormData()
  body.append('file', file)
  const response = await fetch('/api/uploads', { method: 'POST', body, signal })

  if (!response.ok) {
    throw new Error(`The upload failed with status ${response.status}`)
  }

  const { url } = await response.json()
  return url
}

const editor = new Editor({
  element: viewport,
  extensions: [
    WhiteboardKit.configure({
      images: {
        upload,
        onError: ({ file, reason }) => showMessage(`${file.name}: ${reason}`),
      },
    }),
  ],
})
```

在 React 中，请在组件外部创建一次配置好的 kit，或使用 `useMemo` 创建。请参阅[在 React 中设置白板](/editor/whiteboard/guides/react)。

`images` 对象包含以下成员：

- `upload({ file, signal })`：上传图像文件，并返回用于显示图像的 URL。如果在上传完成前白板编辑器被销毁，`signal` 会中止上传，因此请将它传给 `fetch`。
- `accept`（可选）：列出用户可以添加的图像类型。默认值：PNG、JPEG、GIF、WebP、AVIF 和 SVG。
- `maxSize`（可选）：用户可以添加的最大文件大小，以字节为单位。默认值：10 MB。
- `onError({ file, reason, error })`（可选）：在白板跳过某个文件时通知应用，例如用于显示提示。若 `accept` 中未列出文件类型或浏览器无法显示该文件，`reason` 为 `type`；若文件大于 `maxSize`，则为 `size`；若 `upload` 抛出错误或返回了无法显示的 URL，则为 `upload`。`error` 包含 `upload` 抛出或返回的内容。

### 图像 URL

白板会将 URL 存储在图像形状的 `src` 中。白板文件和白板的 Y.Doc 中也会保存该 URL，每位用户的浏览器都会从该 URL 加载图像。因此，请返回可长期使用的 URL，而不要使用很快就会过期的 URL，例如短时有效的签名 URL。

图像支持通过 `http` 和 `https` URL、相对于页面的 URL，以及 `data:image/` URL 显示。其他 URL 无法显示，例如 `blob:` URL；创建它的页面关闭后，这种 URL 就会失效。`data:` URL 会将整个文件存入白板文档，因此只适合较小的图像，或无需服务器的演示场景。

## 添加图像

挂载舞台后（请参阅[舞台和摄像机](/editor/whiteboard/guides/stage-and-camera#attach-the-stage)），用户粘贴的图像文件会出现在舞台中央，拖放的文件则会出现在放置位置。编辑文本时，粘贴内容会插入文本中，图像文件不会添加到白板。

如果要创建自定义按钮，请将文件输入框中的文件传给 `addImageFiles`。它会将图像添加到舞台中央，或添加到以白板单位表示的 `point` 附近：

```js
import { addImageFiles, focusBoard } from '@tiptap-pro/extension-whiteboard'

input.addEventListener('change', async () => {
  await addImageFiles({ stage, editor, files: input.files ?? [] })
  // 允许用户再次选择同一个文件，并将键盘焦点交还给白板
  input.value = ''
  focusBoard(editor.view)
})
```

为文件输入框设置与 `accept` 相同的文件类型，例如 `accept="image/png,image/jpeg"`，这样文件选择器就只会提供这些类型。

白板会先上传文件。所有文件上传完成后，白板会将图像作为一次操作添加到历史记录中，并选中这些图像。在此之前，白板不会显示任何内容；如果上传耗时较长，请在 `upload` 中自行显示进度。每张图像都会保留其自然尺寸，但最大不超过舞台的一半；同时添加的图像会并排排列。在只读白板上，不会添加任何内容。

在代码中，可以像添加其他形状一样添加图像，并指定 URL 和尺寸。`alt` 用于存放屏幕阅读器为图像朗读的文本：

```js
editor.commands.insertShape({
  type: 'boardImage',
  src: '/plan.png',
  width: 400,
  height: 300,
  alt: '楼层平面图',
})
```

用户粘贴或拖放的图像，其 `alt` 为空。之后可以像更新其他属性一样，通过 [`updateShape`](/editor/whiteboard/api-reference/commands#updateshape) 设置它。

## 调整图像大小

拖动角上的控制柄调整图像大小时，图像会保持原有比例。增长幅度较大的一边决定图像尺寸，因此指针会停留在图像边缘上。图像尺寸至少为 16 × 16 个白板单位。
