白板由三个元素组成。**舞台**是白板周围的元素。它接收指针和滚轮事件，并裁剪超出其范围的所有内容。舞台内部的**视口**包含编辑器。**相机**负责移动视口并缩放视口。

## 相机

相机是应用状态的一部分：

```ts
type Camera = {
  x: number
  y: number
  zoom: number
}
```

`x` 和 `y` 的单位是屏幕像素，`zoom` 为 1 时表示 100%。相机辅助函数会将缩放范围限制在 `minZoom`（10%）和 `maxZoom`（400%）之间。

使用相机显示白板：通过 `toCssTransform` 移动视口，并将 `--zoom` 设置为缩放值。控制柄会读取 `--zoom`，以便在任意缩放级别下保持大小不变。

```js
import { toCssTransform } from '@tiptap-pro/extension-whiteboard'

toCssTransform({ x: 100, y: 50, zoom: 2 }) // 'translate(100px, 50px) scale(2)'
```

视口需要设置 `transform-origin: 0 0`。有关舞台和视口的 CSS，请参阅[添加舞台 CSS](/editor/whiteboard/guides/react#add-the-stage-css)。

## 连接舞台

`attachStage` 会将编辑器的白板连接到舞台。它会返回一个用于解除连接并清理所有内容的函数：

```js
import { attachStage } from '@tiptap-pro/extension-whiteboard'

const detach = attachStage({ stage, editor, updateCamera: setCamera })
```

`updateCamera` 通过更新函数修改相机，例如 React 状态 setter。在 React 中，传入 `useState` 返回的 setter。如果不使用 React，则自行应用更新，请参阅[基本设置](/editor/whiteboard/getting-started/overview#basic-setup)。

连接后，用户便可以在舞台上操作白板。焦点位于舞台内时，白板会响应相应按键，因此页面其余部分以及页面上的其他白板仍可使用各自的按键：

- **平移**：按住空格键拖动、使用鼠标中键拖动，或使用 `hand` 工具拖动。滚动滚轮或触控板也可平移。在触摸屏上，启用 `select` 工具时，可用一根手指拖动空白画布；也可以移动两根手指。平移操作优先于绘制和选择。使用 `hand` 工具平移或单击，会让白板获得键盘焦点，效果与使用 `select` 工具单击相同，因此工具栏按钮切换工具后，白板按键即可立即生效。
- **缩放**：按住 <kbd>Control</kbd> 并滚动滚轮，在 macOS 上按住 <kbd>Cmd</kbd> 并滚动滚轮，或在触控板上捏合，即可围绕指针位置缩放。在触摸屏上，用两根手指捏合时，会围绕两指之间的中点缩放。第二根手指会中止并撤销第一根手指开始的操作，效果类似移动图形。
- **缩放快捷键**：按 <kbd>Control</kbd> + <kbd>=</kbd> 或 <kbd>+</kbd> 放大，按 <kbd>Control</kbd> + <kbd>-</kbd> 缩小，按 <kbd>Control</kbd> + <kbd>0</kbd> 则恢复到 100%，并以舞台中部为中心，而不是缩放整个页面。在 macOS 上，将 <kbd>Control</kbd> 替换为 <kbd>Cmd</kbd>。在输入框中按下的按键由输入框处理。
- **适配视图**：未编辑文本时，按 <kbd>Shift</kbd> + <kbd>1</kbd> 可将所有图形适配到视图中。
- **绘制**：使用图形工具时，在白板上拖动即可添加图形。单击会在指针位置居中添加便笺、文本、文档框、画框或几何图形；其大小由对应工具预先设定。画笔用于绘制线条，橡皮擦会擦除碰到的图形。如果从文档框上开始擦除，文档框会保留，因此用户可以擦除文档上的笔迹。也可以在其他图形上绘制。
- **选择**：使用 `select` 工具时，在空白画布上用鼠标或画笔拖动，框选区域触及的图形。只有当框选区域完整包含画框时，画框才会被选中；在画框内部拖动也会绘制框选区域。按住 <kbd>Shift</kbd> 可将图形添加到所选内容中。在空白画布上单击或轻触可清除选择。
- **图像**：使用白板的 [`images`](/editor/whiteboard/guides/images) 功能时，用户拖入的图像文件会放置在拖放位置，粘贴的图像则会放置在舞台中央。

拖动过程中按 <kbd>Escape</kbd> 可取消操作，平移除外。

### 为控件留出空间

按 <kbd>Shift</kbd> + <kbd>1</kbd> 时，舞台每条边缘都会保留 64 个屏幕像素的空白。如果面板浮在舞台上方，可通过 `fitInsets` 留出更多空间：

```js
import { attachStage } from '@tiptap-pro/extension-whiteboard'

attachStage({
  stage,
  editor,
  updateCamera: setCamera,
  // Keeps shapes out from under the toolbar when Shift + 1 fits them into view
  fitInsets: () => ({ top: 80, right: 24, bottom: 24, left: 24 }),
})
```

### 在 CSS 中显示工具和正在进行的平移

舞台会通过 `data-tool` 显示当前工具，并通过 `data-pan` 显示平移状态：按住空格键时为 `ready`，白板正在平移时为 `active`。可以使用这些属性设置光标：

```css
.stage:where([data-tool]:not([data-tool='select'], [data-tool='hand'])),
.stage:where([data-tool]:not([data-tool='select'], [data-tool='hand'])) * {
  cursor: crosshair;
}

.stage[data-tool='hand'],
.stage[data-tool='hand'] *,
.stage[data-pan='ready'],
.stage[data-pan='ready'] * {
  cursor: grab;
}

.stage[data-pan='active'],
.stage[data-pan='active'] * {
  cursor: grabbing;
}
```

拖动过程中，舞台会包含一个预览元素：`data-selection-box`、`data-shape-preview`、`data-arrow-preview` 或 `data-pen-preview`。请参阅[样式设置](/editor/whiteboard/api-reference/styling#stage)。

## 缩放按钮

`zoomAtStageCenter` 会围绕舞台中部调整缩放，因此白板在该位置保持不动。`stepZoom` 会按指定方向返回下一个缩放级别，范围为 10% 到 400%：

```js
import { stepZoom, zoomAtStageCenter } from '@tiptap-pro/extension-whiteboard'

// Zoom in one step
zoomAtStageCenter({
  stage,
  updateCamera: setCamera,
  nextZoom: (zoom) => stepZoom({ zoom, direction: 1 }),
})

// Back to 100%
zoomAtStageCenter({ stage, updateCamera: setCamera, nextZoom: () => 1 })
```

如果当前缩放值位于两个级别之间，函数会沿指定方向跳到下一个级别。例如，`stepZoom({ zoom: 0.8, direction: -1 })` 会返回 `0.75`。

## 将图形适配到视图中

`zoomToFitShapes` 会移动并缩放相机，使舞台中显示所有图形。它不会放大到超过 100%，也不会缩小到低于 `minZoom`；如果白板为空，则不执行任何操作：

```js
import { zoomToFitShapes } from '@tiptap-pro/extension-whiteboard'

zoomToFitShapes({ stage, editor, updateCamera: setCamera })
```

`scrollShapesIntoView` 会尽可能少地移动相机，让指定 ID 的图形显示在舞台中。只有图形无法全部显示时，它才会缩小：

```js
import { getSelectedShapeIds, scrollShapesIntoView } from '@tiptap-pro/extension-whiteboard'

scrollShapesIntoView({
  stage,
  editor,
  ids: getSelectedShapeIds(editor.state),
  updateCamera: setCamera,
})
```

这两个函数都会在每条边缘留出 64 个屏幕像素的空白。传入 `insets` 可调整留白：可以用一个数字应用于所有边缘，也可以分别为每条边缘指定数值。

如果要显示白板的一部分（例如白板打开时），`fitCameraToRect` 会返回一个相机设置，使矩形显示在舞台中央：

```js
import { fitCameraToRect } from '@tiptap-pro/extension-whiteboard'

const camera = fitCameraToRect({
  rect: { x: 0, y: 0, width: 1200, height: 800 },
  viewport: { width: stage.clientWidth, height: stage.clientHeight },
})
```

它会持续缩小，直到矩形适配视图，但不会低于 `minZoom`；默认情况下，放大倍数也不会超过 100%。设置 `largestZoom` 可允许更高的缩放值。

## 转换坐标

图形使用白板坐标单位。`clientToBoard` 会将窗口坐标中的点（例如指针事件的 `clientX` 和 `clientY`）转换为白板坐标单位。当白板尚未显示在页面上时（例如 `useEditor` 中的编辑器尚未挂载），或编辑器已销毁时，它会返回 `null`：

```js
import { clientToBoard } from '@tiptap-pro/extension-whiteboard'

stage.addEventListener('pointermove', (event) => {
  const point = clientToBoard({ editor, point: { x: event.clientX, y: event.clientY } })

  if (point) {
    console.log(`The pointer is at ${point.x}, ${point.y} on the board`)
  }
})
```

`visibleBoardRect` 会返回舞台当前显示的白板区域。可以用它在用户正在查看的位置添加图形：

```js
import { stickyNoteSize, visibleBoardRect } from '@tiptap-pro/extension-whiteboard'

const seen = visibleBoardRect({
  camera,
  viewport: { width: stage.clientWidth, height: stage.clientHeight },
})
const { width, height } = stickyNoteSize

// A new note in the middle of the stage
editor.commands.insertStickyNote({
  x: seen.x + (seen.width - width) / 2,
  y: seen.y + (seen.height - height) / 2,
})
```
