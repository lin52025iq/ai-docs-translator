本指南基于[基础设置](/editor/whiteboard/getting-started/overview#basic-setup)，介绍如何在 React 中设置白板并为其工具添加按钮。

## 安装

除了 Whiteboard 扩展，还需要安装 `@tiptap/react`：

```bash
npm install @tiptap/react
```

## 设置白板

白板需要三个元素：接收指针和滚轮事件的画布、位于画布内部并由摄像机移动的视口，以及视口内部的编辑器。此设置参照了[示例](/editor/whiteboard/examples/simple)：

```jsx
import { EditorContent, useEditor } from '@tiptap/react'
import {
  attachStage,
  boardContent,
  stickyNoteContent,
  toCssTransform,
  WhiteboardKit,
} from '@tiptap-pro/extension-whiteboard'
import { useEffect, useRef, useState } from 'react'

import { Toolbar } from './Toolbar'
import './whiteboard.css'

const content = boardContent([
  stickyNoteContent({ id: 'hello', x: 40, y: 40, text: 'Double-click to write here' }),
])

export default function Whiteboard() {
  const stageRef = useRef(null)
  const [camera, setCamera] = useState({ x: 0, y: 0, zoom: 1 })
  const editor = useEditor({ extensions: [WhiteboardKit], content, immediatelyRender: false })

  // Lets the user pan, zoom, draw and select in the stage
  useEffect(() => {
    if (!editor || !stageRef.current) {
      return undefined
    }

    return attachStage({ stage: stageRef.current, editor, updateCamera: setCamera })
  }, [editor])

  if (!editor) {
    return null
  }

  return (
    <div className="whiteboard">
      <Toolbar editor={editor} />
      <div className="stage" ref={stageRef}>
        <div
          className="viewport"
          style={{ transform: toCssTransform(camera), '--zoom': String(camera.zoom) }}
        >
          <EditorContent editor={editor} />
        </div>
      </div>
    </div>
  )
}
```

设置 `immediatelyRender: false` 后，`useEditor` 会在首次渲染之后创建编辑器，因此在此之前 `editor` 为 `null`。[Next.js](/editor/getting-started/install/nextjs#integrate-tiptap) 需要这样设置；如果白板仅在浏览器中通过 `next/dynamic` 加载，也同样需要。

`attachStage` 会返回一个用于清理所有绑定的函数，因此 effect 会自行清理。它的 `updateCamera` 选项接收一个函数，将旧摄像机状态转换为新状态，例如 React 状态 setter，因此可以传入 `setCamera`。

<Callout title="保持选项稳定" variant="warning">

每次渲染时都应保持 `useEditor` 的选项不变。配置好 kit（例如 `WhiteboardKit.configure({ docs })`），并在组件外或使用 `useMemo` 创建一次内容。选项发生变化时，`useEditor` 会重新应用这些选项，白板会变为只读。在组件内部配置的 kit 每次渲染都会变化，因此调用 `setEditable(true)` 后，白板又会变为只读。

</Callout>

### 添加工具

白板默认使用 `select` 工具。按钮通过 `setTool` 选择其他工具，而 `getActiveTool` 会告知当前激活的工具。`toolKeys` 保存了用于选择各工具的默认按键：

```jsx
import { useEditorState } from '@tiptap/react'
import { focusBoard, getActiveTool, toolKeys } from '@tiptap-pro/extension-whiteboard'

const tools = ['select', 'hand', 'note', 'text', 'rectangle', 'ellipse', 'arrow', 'pen', 'eraser']

export function Toolbar({ editor }) {
  const activeTool = useEditorState({
    editor,
    selector: ({ editor: currentEditor }) => getActiveTool(currentEditor.state),
  })

  return (
    <div role="group" aria-label="Tools">
      {tools.map((tool) => (
        <button
          key={tool}
          type="button"
          aria-pressed={activeTool === tool}
          title={`${tool} (${toolKeys[tool].toUpperCase()})`}
          onClick={() => {
            editor.commands.setTool(tool)
            // Focuses the board, so the tool keys keep working
            focusBoard(editor.view)
          }}
        >
          {tool}
        </button>
      ))}
    </div>
  )
}
```

`doc` 工具用于添加文档框，需要配置 `docs` 选项。请参阅[文档框](/editor/whiteboard/guides/doc-frames)。

### 添加画布 CSS

画布会裁剪白板内容，并拦截触摸事件。视口位于画布的左上角，并以此为基准缩放：

```css
.stage {
  height: 32rem;
  overflow: clip;
  position: relative;
  touch-action: none;
}

.viewport {
  left: 0;
  position: absolute;
  top: 0;
  transform-origin: 0 0;
}

/* The board's origin sits in the corner of the viewport, so the editor keeps no margin */
.viewport .tiptap {
  margin: 0;
}
```

### 设置形状样式

白板会添加其正常工作所需的 CSS，例如白板的尺寸和控制柄的位置。颜色、字体和光标由你的应用决定。以下几条规则可以为形状设置外观：

```css
[data-type='sticky-note'] {
  background: #fff59d;
  padding: 12px;
}

[data-shape-outline] path {
  fill: #fff;
  stroke: #1d1d1d;
  stroke-width: 2px;
  vector-effect: non-scaling-stroke;
}

/* Arrows and pen lines are drawn in the current color */
[data-type='arrow'],
[data-type='freehand'] {
  color: #1d1d1d;
}

/* Divided by the zoom, so outlines and handles keep their size */
[data-shape][data-selected],
[data-shape][data-editing] {
  outline: calc(2px / var(--zoom, 1)) solid #6a00f5;
}

[data-shape-handle='resize'],
[data-arrow-handle] {
  background: #fff;
  border: calc(1.5px / var(--zoom, 1)) solid #6a00f5;
}

[data-selection-box],
[data-shape-preview] {
  background: rgba(106, 0, 245, 0.1);
  border: 1px dashed #6a00f5;
}
```

形状会在 `data-color` 中保存颜色名称，例如 `data-color="blue"`，因此每种颜色的具体外观由你的 CSS 决定。请参阅[样式设置](/editor/whiteboard/api-reference/styling)，了解白板设置的所有属性。
