一个白板就是一个 Tiptap 文档，因此用户可以像协作编辑其他文档一样，通过 Yjs 一起编辑白板。白板还提供了白板所需的功能：`BoardCollaboration`，以及用于显示其他用户选择、拖动和指向内容的辅助工具。

## 安装

协作功能位于单独的入口 `@tiptap-pro/extension-whiteboard/collaboration` 中。只有这个入口需要 Yjs，因此不启用协作的白板不会加载 Yjs。请安装它的 peer dependencies，以及 `@tiptap/y-tiptap` 所需的 `y-protocols`：

```bash
npm install @tiptap/extension-collaboration @tiptap/y-tiptap yjs y-protocols
```

若要通过 Tiptap Collaboration 同步，还需要从私有 registry 安装 `@tiptap-pro/provider`。请参阅[安装 Collaboration](/collaboration/getting-started/install)。

## 设置编辑器

<Callout title="使用 BoardCollaboration，并关闭 kit 的撤销功能" variant="warning">
  当编辑器以 Yjs 中的内容启动时，普通的 `Collaboration` 会丢弃导致文档变空的第一项更改，例如删除最后一个
  形状。`BoardCollaboration` 也会同步这项更改。请在 kit 上设置
  `undoRedo: false`，这样 `undoBoard` 和 `redoBoard` 就会使用协作功能的撤销机制。
</Callout>

```js
import { Editor } from '@tiptap/core'
import { WhiteboardKit } from '@tiptap-pro/extension-whiteboard'
import { BoardCollaboration } from '@tiptap-pro/extension-whiteboard/collaboration'
import { TiptapCollabProvider } from '@tiptap-pro/provider'
import * as Y from 'yjs'

const ydoc = new Y.Doc()

const provider = new TiptapCollabProvider({
  name: 'board-1', // 白板文档的名称
  appId: 'your-app-id', // Cloud 控制面板中的文档服务器 ID
  token: 'your-jwt',
  document: ydoc,
})

const editor = new Editor({
  element: viewport,
  extensions: [
    // 协作功能负责撤销，因此 kit 不使用自身的撤销功能
    WhiteboardKit.configure({ undoRedo: false }),
    BoardCollaboration.configure({ document: ydoc }),
  ],
})
```

在 React 中，请在组件外部或使用 `useMemo` 创建一次配置好的扩展。请参阅[在 React 中设置白板](/editor/whiteboard/guides/react)。

`BoardCollaboration` 使用 [Collaboration](/editor/extensions/functionality/collaboration) 的选项。协作白板的内容来自 Yjs。若要为新白板添加初始形状，请参阅[正确初始化内容](/collaboration/getting-started/install#initialize-content-properly)。

## 显示其他用户的选择和拖动

Yjs 会同步文档，但不会同步用户的选择，也不会同步用户拖动形状时的状态。请通过 [awareness（感知）](/collaboration/core-concepts/awareness)共享这些信息：

- `getSelectedShapeIds` 返回当前用户选择的内容。`setRemoteSelections` 显示其他用户选择的内容。
- 白板编辑器会在拖动形状时发出 `shapesMove` 事件，拖动结束时 `delta: null`。`createRemoteMoves` 会显示其他用户的拖动操作，但不会更改文档。其他用户放下形状时才会更改文档。

```js
import { createRemoteMoves, getSelectedShapeIds } from '@tiptap-pro/extension-whiteboard'

provider.setAwarenessField('user', { name: 'Ada', color: '#be185d' })

// 选择内容发生变化时，分享当前用户的选择
let sharedIds = []

editor.on('transaction', () => {
  const ids = getSelectedShapeIds(editor.state)

  if (ids.length !== sharedIds.length || ids.some((id, index) => id !== sharedIds[index])) {
    sharedIds = ids
    provider.setAwarenessField('selection', ids)
  }
})

// 分享当前用户的拖动操作；拖动结束时发送 `null`
editor.on('shapesMove', ({ ids, delta }) => {
  provider.setAwarenessField('drag', delta ? { ids, delta } : null)
})

// 显示其他用户的选择和拖动
const moves = createRemoteMoves(editor)
let dragging = new Set()

provider.on('awarenessChange', ({ states }) => {
  const others = states.filter((state) => state.clientId !== ydoc.clientID)
  const stillDragging = new Set()

  editor.commands.setRemoteSelections(
    others.map((state) => ({ color: state.user?.color ?? '#6a00f5', ids: state.selection ?? [] })),
  )

  for (const { clientId, drag } of others) {
    if (drag) {
      moves.show({ owner: clientId, ids: drag.ids, delta: drag.delta })
      stillDragging.add(clientId)
    }
  }

  // 结束已停止的拖动，也包括已离开的用户
  for (const owner of dragging) {
    if (!stillDragging.has(owner)) {
      moves.end(owner)
    }
  }

  dragging = stillDragging
})
```

其他用户选中的形状会获得 `data-remote-selected` 属性，并通过 `--remote-selection` 使用该用户的颜色。多个用户同时选择一个形状时，只显示第一个有效颜色。由于颜色会写入元素样式，因此只接受 `#RRGGBB` 格式的颜色，例如 `#be185d`。如果选择状态使用其他颜色（如 `red` 或 `#abc`），则不会显示：

```css
[data-shape][data-remote-selected] {
  outline: calc(2px / var(--zoom, 1)) solid var(--remote-selection);
}
```

## 显示其他用户的光标

`createRemoteCursors` 会显示其他用户的指向位置及其名称。它也会让用户拖动的形状跟随其光标移动，可替代 `createRemoteMoves`。请分享指针下方的白板坐标、时间和拖动信息，每秒最多十次。指针事件来自白板外围的 `stage` 元素，详见[舞台与摄像机](/editor/whiteboard/guides/stage-and-camera)：

```js
import { clientToBoard, createRemoteCursors } from '@tiptap-pro/extension-whiteboard'

const stage = document.querySelector('.stage')
let point = null
let drag = null
let timer = null

// 分享当前用户的指向位置和拖动内容，每秒最多十次
const share = () => {
  timer ??= setTimeout(() => {
    timer = null
    provider.setAwarenessField('cursor', point && { point, time: Date.now(), drag })
  }, 100)
}

stage.addEventListener('pointermove', (event) => {
  point = clientToBoard({ editor, point: { x: event.clientX, y: event.clientY } })
  share()
})

stage.addEventListener('pointerleave', () => {
  point = null
  share()
})

editor.on('shapesMove', ({ ids, delta }) => {
  drag = delta && { ids, delta }
  share()
})

// 显示其他用户的光标
const cursors = createRemoteCursors(editor)

provider.on('awarenessChange', ({ states }) => {
  cursors.update(
    states
      .filter((state) => state.clientId !== ydoc.clientID && state.cursor)
      .map(({ clientId, user, cursor }) => ({
        owner: clientId,
        ...cursor,
        name: user?.name ?? '',
        color: user?.color ?? '',
      })),
  )
})
```

光标会稍有延迟地沿着用户分享的位置平滑移动，移动速度与分享频率一致。用户停止指向后，或一分钟没有移动后，光标会逐渐淡出。

光标显示在形状上方，并通过 `--zoom` 在不同缩放级别下保持大小不变。每个光标都通过 `--remote-cursor` 使用对应用户的颜色，颜色规则与选择状态相同，必须符合 `#RRGGBB` 格式。可以为光标箭头和名称设置样式：

```css
[data-remote-cursor-arrow] {
  fill: var(--remote-cursor);
  stroke: white;
  stroke-width: 2;
}

[data-remote-cursor-name] {
  padding: 2px 6px;
  color: white;
  font-size: 12px;
  background: var(--remote-cursor);
  border-radius: 4px;
}
```

## 文档框架

白板的 Y.Doc 保存框架，但不保存框架中的文档。由你的 `createEditor` 决定每个文档的存放位置及其同步方式。请参阅[文档框架](/editor/whiteboard/guides/doc-frames)。

`start` 只会在导致框架出现在白板上的更改所属的编辑器中运行。通过 Yjs 接收的框架会保留其自身编辑器启动的文档。通过 Yjs 执行撤销操作而恢复的框架也是如此。

## 文本高度

自由文本和文档框架会根据内容自动增高。每个编辑器都会使用自己的字体测量其所做更改的高度。其他用户所做的更改则会保留由其编辑器测量的高度。

## 同时更新所有编辑器

同一白板的所有编辑器都应使用相同版本的 Whiteboard 扩展，并同时更新。旧版编辑器无法读取仅由新版支持的内容，还可能会将其删除，导致所有人都受影响。例如，0.1.0 版编辑器无法读取带标签的箭头。
