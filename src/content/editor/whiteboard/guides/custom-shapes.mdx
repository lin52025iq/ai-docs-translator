自定义形状是白板上的自定义节点，其中包含应用组件，例如投票或图表。白板可以像处理自身的形状一样放置、选择、移动和调整它的大小，而组件负责绘制其中的内容。

## 创建节点

形状是 `shape` 组中的节点。`shapeAttributes` 会为形状添加所需的属性：ID、位置、大小和 z-index。`dataAttribute` 可添加自定义属性，例如投票的票数。`shapeNodeView` 会将组件的节点视图转换为形状。自定义形状不包含文本，因此应将其设为原子节点：

```js
import { mergeAttributes, Node } from '@tiptap/core'
import { ReactNodeViewRenderer } from '@tiptap/react'
import { dataAttribute, shapeAttributes, shapeNodeView } from '@tiptap-pro/extension-whiteboard'

import { VoteCardView } from './VoteCardView'

export const VoteCard = Node.create({
  name: 'voteCard',
  group: 'shape',
  atom: true,
  // The board selects shapes by their ids, never as a node selection
  selectable: false,

  addAttributes() {
    return {
      ...shapeAttributes({ width: 220, height: 150 }),
      votes: dataAttribute({ name: 'votes', default: 0 }),
    }
  },

  parseHTML() {
    return [{ tag: 'div[data-type="vote-card"]' }]
  },

  renderHTML({ HTMLAttributes }) {
    return ['div', mergeAttributes({ 'data-type': 'vote-card' }, HTMLAttributes)]
  },

  addNodeView() {
    return shapeNodeView({ dataType: 'vote-card', view: ReactNodeViewRenderer(VoteCardView) })
  },
})
```

将该节点与 `WhiteboardKit` 一起添加到编辑器中，例如：`extensions: [WhiteboardKit, VoteCard]`。

复制和粘贴通过 HTML 实现。`dataAttribute` 会将值保存在 HTML 数据属性中，例如 `data-votes`，从而保留该值。它支持字符串、数字、布尔值，以及以 JSON 格式保存的对象和数组。`shapeAttributes` 也会以相同方式保存位置和大小。

## 绘制组件

该组件是 Tiptap 的 [React 节点视图](/editor/extensions/custom-extensions/node-views/react)。用 `NodeViewWrapper` 包裹组件，使其填满形状，并从 `node.attrs` 读取形状的数据：

```jsx
import { NodeViewWrapper } from '@tiptap/react'
import { focusBoard } from '@tiptap-pro/extension-whiteboard'

export function VoteCardView({ node, editor }) {
  const { id, votes } = node.attrs

  const vote = () => {
    editor.commands.updateShape({ id, attributes: { votes: votes + 1 } })
    // Gives the keyboard back to the board, so undo keeps working
    focusBoard(editor.view)
  }

  return (
    <NodeViewWrapper className="vote-card">
      <p>{votes} votes</p>
      <button type="button" onClick={vote}>
        Vote
      </button>
    </NodeViewWrapper>
  )
}
```

应用中已有的组件也可以用相同方式处理。将它渲染在 `NodeViewWrapper` 中，并向其传入形状数据，例如 `<ProjectCard title={node.attrs.title} />`。组件会在 `EditorContent` 的 React 树中渲染，因此可以读取应用的上下文，例如主题。

组件通过 `updateShape` 修改形状，这也会更改自定义属性；撤销操作会逐一还原这些更改。形状每次发生变化后，组件都会再次收到节点，包括形状移动、调整大小或被其他用户修改的情况。

### Vue 和原生 JavaScript

在 Vue 中，可以使用 `@tiptap/vue-3` 提供的 `VueNodeViewRenderer` 和 `NodeViewWrapper`，方式相同。上方示例中的 Vue 选项卡展示了相同的卡片。请参阅 [Vue 节点视图](/editor/extensions/custom-extensions/node-views/vue)。

不使用框架时，可以传入自定义的[节点视图](/editor/extensions/custom-extensions/node-views/javascript)。它的 `update` 方法会绘制每次变化。没有 `update` 方法的节点视图会在每次变化后重新绘制：

```js
shapeNodeView({
  dataType: 'vote-card',
  view: ({ node }) => {
    const dom = document.createElement('div')
    dom.textContent = `${node.attrs.votes} votes`

    return {
      dom,
      update: (updated) => {
        dom.textContent = `${updated.attrs.votes} votes`
        return true
      },
    }
  },
})
```

节点视图的元素是 `[data-shape-component]`，其大小与形状相同。

## 按下操作

按下组件会选中形状，拖动组件会移动形状，与白板自带的形状一样。按下组件中的链接、按钮、字段和可编辑内容时，操作会传递给这些元素，因此它们仍可照常使用。对于图表图例等需要自行处理按下操作的其他部分，请添加 `data-shape-interactive` 标记：

```jsx
<div className="legend" data-shape-interactive>
  {legend}
</div>
```

`iframe` 会自行处理所有按下操作，白板无法接收到这些操作。为其设置 `pointer-events: none`，这样用户就可以在该区域选择和移动形状。

## 只读白板

在[只读白板](/editor/whiteboard/guides/shapes-and-tools#read-only-boards)上，用户可以选择形状，但不能移动或调整其大小。按下组件中的按钮和字段时，操作仍会传递给它们；`updateShape` 等命令也仍可修改只读白板。因此，应在组件中禁用会修改白板的操作。[`isBoardEditable`](/editor/whiteboard/api-reference/utilities#isboardeditable) 可用于判断白板是否可编辑。不要使用 `editor.isEditable`，因为只要白板获得键盘焦点，它的值就是 `false`。白板切换为只读或可编辑状态时，`useEditorState` 会重新绘制组件：

```jsx
import { NodeViewWrapper, useEditorState } from '@tiptap/react'
import { isBoardEditable } from '@tiptap-pro/extension-whiteboard'

export function VoteCardView({ editor }) {
  const isEditable = useEditorState({ editor, selector: (ctx) => isBoardEditable(ctx.editor) })

  return (
    <NodeViewWrapper className="vote-card">
      <button type="button" disabled={!isEditable}>
        Vote
      </button>
    </NodeViewWrapper>
  )
}
```

不使用 React 时，请在编辑器的 `update` 事件中再次检查 `isBoardEditable(editor)`；调用 `editor.setEditable()` 时会触发该事件。

## 添加形状

没有工具可以绘制自定义形状，因此可以使用 `insertShape` 添加，例如从应用的按钮触发：

```js
editor.commands.insertShape({ type: 'voteCard', x: 100, y: 100 })
```

除非另行传入 ID 和大小，否则形状会获得新的 ID，并使用 `shapeAttributes` 中定义的大小。之后，用户可以选择、移动、调整大小、复制、粘贴和删除该形状，也可以撤销每项更改。`updateShape`、`moveShapes` 和 `deleteShapes` 等命令也适用于自定义形状。

## 设置形状样式

形状的元素带有 `data-shape`、`shapeNodeView` 中指定的 `data-type`，并会在形状被选中时带有 `data-selected`。可以像设置白板自带形状的样式一样设置它：

```css
[data-type='vote-card'] {
  background: #fff;
  border: 1px solid rgba(61, 37, 20, 0.12);
  border-radius: 8px;
  padding: 14px;
}
```

有关形状各部分的信息，请参阅[样式设置](/editor/whiteboard/api-reference/styling#parts-of-shapes)。

## 限制

- 自定义形状不能包含用户在白板上编辑的文本。
