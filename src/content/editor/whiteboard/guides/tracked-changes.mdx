形状是节点，因此可以携带 [Tracked Changes](/tracked-changes/getting-started/overview) 的建议，例如 AI 代理建议添加的便笺。白板会在形状上显示这些建议，你可以使用 Tracked Changes 命令审核它们。

<Callout title="单独销售的产品" variant="info">
  [Tracked Changes](/tracked-changes/getting-started/overview) 是与 Whiteboard 不同的 Tiptap 产品，需单独购买。
</Callout>

## 设置编辑器

[安装 Tracked Changes](/tracked-changes/getting-started/install)，并将其添加到白板的编辑器中。将 Tracked Changes 中的 `getSuggestionHTMLAttributes` 作为 `WhiteboardKit` 的 `shapeElementAttributes` 选项传入：

```js
import { Editor } from '@tiptap/core'
import { getSuggestionHTMLAttributes, TrackedChanges } from '@tiptap-pro/extension-tracked-changes'
import { WhiteboardKit } from '@tiptap-pro/extension-whiteboard'

const editor = new Editor({
  element: viewport,
  extensions: [
    WhiteboardKit.configure({ shapeElementAttributes: getSuggestionHTMLAttributes }),
    TrackedChanges,
  ],
})
```

在 React 中，请在组件外部创建一次配置好的 kit，或使用 `useMemo` 创建。请参阅[在 React 中设置白板](/editor/whiteboard/guides/react)。

`shapeElementAttributes` 会根据形状节点，为每个形状的元素添加属性。使用 `getSuggestionHTMLAttributes` 后，被建议修改的形状元素会获得 `data-suggestion-*` 属性，例如 `data-suggestion-type` 和 `data-suggestion-user`。

Tracked Changes 默认以 `enabled: false` 启动。此时，白板上的编辑会直接生效，而白板仍会显示形状所携带的建议。

## 显示建议

使用形状元素上的属性为被建议修改的形状设置样式：

```css
/* A shape that a suggestion adds */
[data-shape][data-suggestion-type='add'] {
  outline: calc(2px / var(--zoom, 1)) dashed #2b9a66;
}

/* A shape that a suggestion deletes */
[data-shape][data-suggestion-type='delete'] {
  opacity: 0.5;
}

/* A shape that a suggestion moves or changes */
[data-shape][data-suggestion-type='attributeChange'] {
  outline: calc(2px / var(--zoom, 1)) dashed #0d74ce;
}
```

建议审核完成后，这些属性就会消失。形状文本中的建议与其他文档中的建议显示方式相同。有关所有属性，请参阅[样式设置](/tracked-changes/api-reference/styling)。

## 审核建议

使用 `findSuggestions` 查找建议，并通过 ID 接受或拒绝建议：

```js
import { findSuggestions } from '@tiptap-pro/extension-tracked-changes'

const [suggestion] = findSuggestions(editor)

if (suggestion) {
  editor.commands.acceptSuggestion({ id: suggestion.id })
}
```

添加形状的建议会在 `insertedNodes` 中列出这些形状，例如 `{ type: 'stickyNote' }`。如果一条建议添加了多个形状，例如某次 AI 工具调用添加的所有便笺，那么使用同一个 ID 即可接受或拒绝所有这些形状。

| 建议 | 接受 | 拒绝 |
| ---------------- | ------------------- | ------------------------ |
| 添加形状 | 保留该形状 | 移除该形状 |
| 删除形状 | 移除该形状 | 保留该形状 |
| 移动形状 | 保留新位置 | 将形状移回原位 |
| 修改形状文本 | 保留新文本 | 恢复旧文本 |

拒绝一条会移除形状的建议后，与该形状相连的箭头会保留一个悬空端点。协作白板也支持审核：所有用户都能看到建议，审核结果也会同步应用到所有人的白板上。
