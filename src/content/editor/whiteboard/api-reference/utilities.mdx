从 `@tiptap-pro/extension-whiteboard` 导入这些函数和常量。

- 白板上的位置和尺寸使用白板单位，舞台上的位置使用屏幕像素。
- `insertShapesInFront`、`removeShapes`、`restackShapes` 和 `keepShapeHeights` 适用于自行构建事务的代码，例如 AI 工具。

`Attribute`、`Attributes`、`Editor`、`JSONContent`、`NodeViewRenderer` 和 `NodeWithPos` 来自 `@tiptap/core`。`Node` 来自 `@tiptap/pm/model`，`EditorState` 和 `Transaction` 来自 `@tiptap/pm/state`，`EditorView` 来自 `@tiptap/pm/view`。

## `attachStage`

允许用户在 `stage` 中操作 `editor` 的白板：平移和缩放、使用缩放快捷键、通过形状工具绘图，以及使用选择框。按住 <kbd>Space</kbd>、使用鼠标中键或手形工具进行平移时，平移操作优先于绘图和选择。在触摸屏上，选择工具启用时，单指在空白白板上滑动可平移，双指可平移和缩放。使用白板的 [`images`](/editor/whiteboard/guides/images) 时，用户拖放的图像文件会放置在放下的位置，粘贴的图像则会放置在舞台中央。

```js
import { attachStage } from '@tiptap-pro/extension-whiteboard'

const detach = attachStage({ stage, editor, updateCamera: setCamera })
```

### 参数（`StageOptions`）

- `stage`（`HTMLElement`）：白板外围元素，用于接收指针和滚轮事件。
- `editor`（`Editor`）：白板的编辑器。
- `updateCamera`（`UpdateCamera`）：用户平移、缩放或使用缩放快捷键时移动摄像机。
- `fitInsets?`（`() => number | Insets`）：返回适应视图时，形状周围需要保留的空白区域（例如面板下方）。按 <kbd>Shift</kbd> + <kbd>1</kbd> 时会使用此设置。默认值：每条边保留 64 屏幕像素。

### 返回值（`() => void`）

用于解除所有绑定的函数。

舞台需要设置 `position: relative`、`overflow: clip` 和 `touch-action: none`。视口（容纳编辑器的元素）位于舞台左上角，并设置 `position: absolute`、`top: 0`、`left: 0` 和 `transform-origin: 0 0`。使用 [`toCssTransform(camera)`](#tocsstransform) 移动视口，并在其上将 `--zoom` 设置为缩放比例。

## `toCssTransform`

返回用于根据摄像机显示白板的 CSS 变换。被变换移动的视口需要设置 `transform-origin: 0 0`。

```js
import { toCssTransform } from '@tiptap-pro/extension-whiteboard'

toCssTransform({ x: 100, y: 50, zoom: 2 }) // 'translate(100px, 50px) scale(2)'
```

### 参数

- `camera`（`Camera`）：白板的摄像机。

### 返回值（`string`）

视口的 `transform` 值。

## `zoomAtStageCenter`

围绕舞台中心调整缩放，使白板在该位置保持不动。

```js
import { zoomAtStageCenter } from '@tiptap-pro/extension-whiteboard'

resetZoomButton.addEventListener('click', () => {
  zoomAtStageCenter({ stage, updateCamera: setCamera, nextZoom: () => 1 })
})
```

### 参数（`ZoomAtStageCenterOptions`）

- `stage`（`HTMLElement`）：白板外围元素。
- `updateCamera`（`UpdateCamera`）：移动摄像机。
- `nextZoom`（`(zoom: number) => number`）：根据当前缩放比例返回新的缩放比例。

## `stepZoom`

返回指定方向上的下一个缩放档位，适用于应用中的缩放按钮。当前缩放比例处于两个档位之间时，会切换到该方向上的下一个档位。缩放档位范围为 10% 到 400%。

```js
import { stepZoom } from '@tiptap-pro/extension-whiteboard'

stepZoom({ zoom: 1, direction: 1 }) // 1.25
stepZoom({ zoom: 0.8, direction: -1 }) // 0.75
```

### 参数（`StepZoomOptions`）

- `zoom`（`number`）：当前缩放比例，1 表示 100%。
- `direction`（`1 | -1`）：`1` 表示放大，`-1` 表示缩小。

### 返回值（`number`）

下一个缩放比例。

## `zoomToFitShapes`

移动并缩放摄像机，使所有形状都显示在舞台中。缩放比例不会超过 100%，也不会低于 [`minZoom`](#minzoom)；白板为空时不执行任何操作。

```js
import { zoomToFitShapes } from '@tiptap-pro/extension-whiteboard'

zoomToFitShapes({ stage, editor, updateCamera: setCamera })
```

### 参数（`ZoomToFitShapesOptions`）

- `stage`（`HTMLElement`）：白板外围元素。
- `editor`（`Editor`）：白板的编辑器。
- `updateCamera`（`UpdateCamera`）：移动摄像机。
- `insets?`（`number | Insets`）：边缘需要保留的空白区域，单位为屏幕像素；可以为所有边设置相同值，也可以分别设置各边的值。例如，可避免形状被浮动控件遮挡。默认值：`64`。

## `scrollShapesIntoView`

尽可能少地移动摄像机，使具有指定 id 的形状显示在舞台中。只有这些形状无法全部容纳时才会缩小；如果白板上不存在这些形状，则不执行任何操作。

```js
import { scrollShapesIntoView } from '@tiptap-pro/extension-whiteboard'

scrollShapesIntoView({ stage, editor, ids: ['note-1'], updateCamera: setCamera })
```

### 参数（`ScrollShapesIntoViewOptions`）

- `stage`（`HTMLElement`）：白板外围元素。
- `editor`（`Editor`）：白板的编辑器。
- `ids`（`readonly string[]`）：要显示的形状的 id。
- `updateCamera`（`UpdateCamera`）：移动摄像机。
- `insets?`（`number | Insets`）：边缘需要保留的空白区域，单位为屏幕像素；可以为所有边设置相同值，也可以分别设置各边的值。默认值：`64`。

## `fitCameraToRect`

返回一个摄像机设置，使白板的一部分显示在舞台中央，并位于 `insets` 留出的区域内。它会持续缩小，直到该区域能够完整显示，但放大不会超过 `largestZoom`，且缩放比例始终受 [`minZoom`](#minzoom) 和 [`maxZoom`](#maxzoom) 限制。因此，如果某个区域需要低于 `minZoom` 的缩放比例才能完整显示，就无法适配。

```js
import { fitCameraToRect } from '@tiptap-pro/extension-whiteboard'

const rect = { x: 0, y: 0, width: 1200, height: 800 }
const camera = fitCameraToRect({ rect, viewport: { width: 1000, height: 800 } })
```

### 参数（`FitCameraToRectOptions`）

- `rect`（`Rect`）：要显示的白板区域，单位为白板单位。
- `viewport`（`Size`）：舞台的尺寸，单位为屏幕像素。
- `insets?`（`number | Insets`）：边缘需要保留的空白区域，单位为屏幕像素；可以为所有边设置相同值，也可以分别设置各边的值。默认值：`64`。
- `largestZoom?`（`number`）：允许放大的最大比例。默认值：`1`，即 100%。

### 返回值（`Camera`）

用于显示该区域的摄像机设置。

## `visibleBoardRect`

返回舞台当前显示的白板区域。

```js
import { visibleBoardRect } from '@tiptap-pro/extension-whiteboard'

const seen = visibleBoardRect({ camera, viewport: { width: 1000, height: 800 } })
```

### 参数（`VisibleBoardRectOptions`）

- `camera`（`Camera`）：白板的摄像机。
- `viewport`（`Size`）：舞台的尺寸，单位为屏幕像素。

### 返回值（`Rect`）

白板上的可见区域，单位为白板单位。

## `clientToBoard`

根据白板当前显示的摄像机设置，将窗口坐标中的点转换为白板单位。

```js
import { clientToBoard } from '@tiptap-pro/extension-whiteboard'

stage.addEventListener('pointermove', (event) => {
  const point = clientToBoard({ editor, point: { x: event.clientX, y: event.clientY } })

  if (point) {
    console.log(`The pointer is at ${point.x}, ${point.y} on the board`)
  }
})
```

### 参数（`ClientToBoardOptions`）

- `editor`（`Editor`）：白板的编辑器。
- `point`（`Point`）：窗口坐标中的点，例如指针事件的 `clientX` 和 `clientY`。

### 返回值（`Point | null`）

白板单位中的点；如果白板尚未显示在页面上（例如 `useEditor` 的编辑器尚未挂载）或编辑器已销毁，则返回 `null`。

## `minZoom`

最小缩放比例，为 10%。摄像机辅助函数不会继续缩小。

值：`0.1`。

## `maxZoom`

最大缩放比例，为 400%。摄像机辅助函数不会继续放大。

值：`4`。

## `boardContent`

使用给定形状构建白板文档的 JSON，供编辑器作为内容使用。

```js
import { boardContent, stickyNoteContent } from '@tiptap-pro/extension-whiteboard'

editor.commands.setContent(boardContent([stickyNoteContent({ id: 'note', x: 0, y: 0 })]))
```

### 参数

- `shapes`（`JSONContent[]`）：形状的 JSON，例如 [`stickyNoteContent()`](#stickynotecontent) 返回的内容。

### 返回值（`JSONContent`）

文档的 JSON。

## `stickyNoteContent`

为白板内容构建便签的 JSON，其中包含一个文本段落。它接受 [`textShapeContent()`](#textshapecontent) 的选项，但不包括 `type` 和 `kind`。

```js
import { stickyNoteContent } from '@tiptap-pro/extension-whiteboard'

const note = stickyNoteContent({ id: 'note', x: 0, y: 0, text: 'Hello' })
```

### 参数（`StickyNoteContentOptions`）

- `id`（`string`）：便签的 id，在白板上必须唯一。
- `x`、`y`（`number`）：便签的位置，单位为白板单位。
- `width?`、`height?`（`number`）：便签的尺寸，单位为白板单位。默认值：[`stickyNoteSize`](#stickynotesize)。
- `zIndex?`（`string`）：堆叠顺序，使用分数索引。值较大的形状位于前方。
- `color?`（`ShapeColor`）：便签的颜色，例如 `blue`。参见 [`shapeColors`](#shapecolors)。
- `fontSize?`（`ShapeStyleValue<'fontSize'>`）：文本大小，例如 `s`、`m`、`l` 或 `xl`。
- `textAlign?`（`ShapeStyleValue<'textAlign'>`）：文本对齐方式：`start`、`center` 或 `end`。
- `font?`（`ShapeStyleValue<'font'>`）：文本字体，例如 `sans`、`serif` 或 `mono`。
- `text?`（`string`）：便签文本，放在一个段落中。

### 返回值（`JSONContent`）

便签的 JSON。

## `textShapeContent`

为白板内容构建带文本形状的 JSON。

```js
import { boardContent, textShapeContent } from '@tiptap-pro/extension-whiteboard'

const shape = textShapeContent({ type: 'geo', id: 'box', x: 0, y: 0, text: 'Hi' })

editor.commands.setContent(boardContent([shape]))
```

### 参数（`TextShapeContentOptions`）

- `type`（`string`）：形状的节点类型，例如 `stickyNote`、`geo` 或 `freeText`。
- `id`（`string`）：形状的 id，在白板上必须唯一。
- `x`、`y`（`number`）：形状的位置，单位为白板单位。
- `width?`、`height?`（`number`）：形状的尺寸，单位为白板单位。
- `zIndex?`（`string`）：堆叠顺序，使用分数索引。值较大的形状位于前方。
- `color?`（`ShapeColor`）：形状的颜色，例如 `blue`。参见 [`shapeColors`](#shapecolors)。
- `fontSize?`（`ShapeStyleValue<'fontSize'>`）：文本大小，例如 `s`、`m`、`l` 或 `xl`。
- `textAlign?`（`ShapeStyleValue<'textAlign'>`）：文本对齐方式：`start`、`center` 或 `end`。
- `font?`（`ShapeStyleValue<'font'>`）：文本字体，例如 `sans`、`serif` 或 `mono`。
- `kind?`（`GeoKind`）：几何形状的类型，取自 [`geoKinds`](#geokinds) 中的名称。
- `text?`（`string`）：形状文本，放在一个段落中。

### 返回值（`JSONContent`）

形状的 JSON。

## `freehandFromPoints`

将用白板单位绘制的线条转换为画笔线条的几何数据。边界框会为描边宽度留出空间，点的位置则相对于边界框的角点。

```js
import { freehandFromPoints } from '@tiptap-pro/extension-whiteboard'

const line = freehandFromPoints({
  points: [
    { x: 0, y: 0 },
    { x: 100, y: 40 },
  ],
  strokeWidth: 3,
})
const content = { type: 'freehand', attrs: { id: 'line', ...line, strokeWidth: 3 } }
```

### 参数（`FreehandFromPointsOptions`）

- `points`（`readonly Point[]`）：线条上的点，单位为白板单位。至少需要一个点。
- `strokeWidth`（`number`）：线条的宽度，单位为白板单位。

### 返回值（`FreehandShape`）

画笔线条的边界框和点。

## `createShapeId`

为形状 id 生成一个随机的版本 4 UUID。即使在不支持 `crypto.randomUUID` 的安全来源环境中也能使用。

```js
import { createShapeId, stickyNoteContent } from '@tiptap-pro/extension-whiteboard'

const note = stickyNoteContent({ id: createShapeId(), x: 0, y: 0 })
```

### 参数

无。

### 返回值（`string`）

新 id。

## `getSelectedShapeIds`

返回已选形状的 id。

```js
import { getSelectedShapeIds } from '@tiptap-pro/extension-whiteboard'

editor.commands.bringToFront(getSelectedShapeIds(editor.state))
```

### 参数

- `state`（`EditorState`）：白板编辑器的状态，例如 `editor.state`。

### 返回值（`readonly string[]`）

形状的 id，顺序与选择顺序一致。

## `isBoardEditable`

判断用户是否可以修改白板。调用 `editor.setEditable(false)` 会禁止修改。请使用此函数，而不要使用 `editor.isEditable`：只要白板拥有键盘焦点，后者就会返回 `false`。参见[自定义形状](/editor/whiteboard/guides/custom-shapes#read-only-boards)。

```js
import { isBoardEditable } from '@tiptap-pro/extension-whiteboard'

// 命令也可以修改只读白板，因此形状中的按钮执行命令前要先检查
if (isBoardEditable(editor)) {
  editor.commands.updateShape({ id, attributes: { votes: votes + 1 } })
}
```

### 参数

- `editor`（`Editor`）：白板的编辑器。

### 返回值（`boolean`）

用户是否可以修改白板。

## `isEditingText`

判断是否正在编辑形状文本；如果是，按键会输入到该文本中。否则，按键会作用于白板和已选形状。编辑文档框的文档时，此函数返回 `false`；参见 [`getEditedDocEditor()`](#getediteddoceditor)。

```js
import { isEditingText } from '@tiptap-pro/extension-whiteboard'

isEditingText(editor.state) // 按键作用于白板时返回 false
```

### 参数

- `state`（`EditorState`）：白板编辑器的状态，例如 `editor.state`。

### 返回值（`boolean`）

是否正在编辑形状文本。

## `getEditedShapeId`

返回正在编辑文本的形状的 id。对于文档框中的文档，请参见 [`getEditedDocEditor()`](#getediteddoceditor)。

```js
import { getEditedShapeId } from '@tiptap-pro/extension-whiteboard'

getEditedShapeId(editor.state) // 正在编辑便签文本时返回 'note'
```

### 参数

- `state`（`EditorState`）：白板编辑器的状态，例如 `editor.state`。

### 返回值（`string | null`）

形状的 id；如果按键作用于白板，或正在编辑文档框中的文档，则返回 `null`。

## `getActiveTool`

返回在白板上按下时会使用的工具。

```js
import { getActiveTool } from '@tiptap-pro/extension-whiteboard'

getActiveTool(editor.state) // 'select'
```

### 参数

- `state`（`EditorState`）：白板编辑器的状态，例如 `editor.state`。

### 返回值（`Tool`）

当前工具。如果未通过 [`setTool`](/editor/whiteboard/api-reference/commands#settool) 选择其他工具，则为 `select`。

## `getNextShapeStyles`

返回新形状将使用的样式。未设置的样式会使用各类形状的默认值。

```js
import { getNextShapeStyles } from '@tiptap-pro/extension-whiteboard'

getNextShapeStyles(editor.state).color // 在 `setShapeStyle` 选择颜色之前为 undefined
```

### 参数

- `state`（`EditorState`）：白板编辑器的状态，例如 `editor.state`。

### 返回值（`Partial<ShapeStyles>`）

由 [`setShapeStyle`](/editor/whiteboard/api-reference/commands#setshapestyle) 选择的样式。

## `getToolShapeType`

返回工具所添加形状的节点类型。

```js
import { getToolShapeType } from '@tiptap-pro/extension-whiteboard'

getToolShapeType('note') // 'stickyNote'
getToolShapeType('hand') // null
```

### 参数

- `tool`（`Tool`）：工具，例如 `note` 或 `hand`。

### 返回值（`string | null`）

节点类型；如果该工具不会添加形状，则返回 `null`。

## `isTypingTarget`

判断按键是否会在目标位置输入文本：例如输入框，或可编辑内容（如正在编辑的形状文本或文档框编辑器）。

```js
import { isTypingTarget } from '@tiptap-pro/extension-whiteboard'

// 在应用自身快捷键的 keydown 监听器中
if (event.key === '?' && !isTypingTarget(event.target)) showShortcuts()
```

### 参数

- `target`（`EventTarget | null`）：键盘事件的目标，例如 `event.target`。

### 返回值（`boolean`）

按键是否会在目标位置输入文本。

## `focusBoard`

立即聚焦白板；如果正在编辑文本，则聚焦文本。适用于命令链之外的代码，例如工具栏按钮的点击处理程序。与 ProseMirror 的 `focus` 不同，即使文本为只读，此函数也能正常工作。在命令链中，应改用 [`focusBoard()` 命令](/editor/whiteboard/api-reference/commands#focusboard)，它会在命令链的事务完成后聚焦。

```js
import { focusBoard } from '@tiptap-pro/extension-whiteboard'

// 在工具栏按钮的点击处理程序中
focusBoard(editor.view)
```

### 参数

- `view`（`EditorView`）：白板编辑器的视图，例如 `editor.view`。

## `findShapes`

查找具有指定 id 的形状。

```js
import { findShapes } from '@tiptap-pro/extension-whiteboard'

const [note] = findShapes({ doc: editor.state.doc, ids: ['note-1'] })
```

### 参数（`FindShapesOptions`）

- `doc`（`Node`）：白板文档，例如 `editor.state.doc`。
- `ids`（`readonly string[]`）：形状的 id。

### 返回值（`NodeWithPos[]`）

形状及其位置，按文档顺序排列。找不到的 id 会被跳过。

## `hasBoxGeometry`

判断形状是否具有由 `x`、`y`、`width` 和 `height` 定义的边界框。箭头没有边界框。

```js
import { findShapes, hasBoxGeometry } from '@tiptap-pro/extension-whiteboard'

const shapes = findShapes({ doc: editor.state.doc, ids })
const boxes = shapes.filter(({ node }) => hasBoxGeometry(node))
```

### 参数

- `shape`（`Node`）：形状的节点。

### 返回值（`boolean`）

形状是否具有边界框。

## `docIdOf`

根据文档框的节点或节点 JSON，返回该文档框所显示文档的 id。没有文档 id 的文档框会使用自身形状的 id，因此仍会拥有专属文档。

```js
import { docIdOf, findShapes } from '@tiptap-pro/extension-whiteboard'

const [frame] = findShapes({ doc: editor.state.doc, ids: ['frame'] })
const docId = frame && docIdOf(frame.node)
```

### 参数

- `frame`（`Node | JSONContent`）：文档框的节点或其 JSON。

### 返回值（`string`）

文档的 id。

## `shapeAttributes`

返回[自定义形状](/editor/whiteboard/guides/custom-shapes)所需的通用属性：id、位置、尺寸、z-index 和框架。这些属性会确保 HTML 中的数字仍以数字形式保存，即使用户复制并粘贴形状也一样。

```js
import { shapeAttributes } from '@tiptap-pro/extension-whiteboard'

// 在形状的节点中
addAttributes: () => ({
  ...shapeAttributes({ width: 320, height: 200 }),
  title: { default: '' },
}),
```

### 参数

- `size?`（`Size`）：新形状的尺寸，单位为白板单位。默认值：200 × 200。

### 返回值（`Attributes`）

供形状节点的 `addAttributes` 使用的属性。

## `dataAttribute`

返回[自定义形状](/editor/whiteboard/guides/custom-shapes)的属性，该属性会由 HTML 保存为 data 属性，因此用户复制并粘贴形状时也会保留。值缺失或无法解析时，会回退到默认值。

```js
import { dataAttribute, shapeAttributes } from '@tiptap-pro/extension-whiteboard'

// 在形状的节点中
addAttributes: () => ({
  ...shapeAttributes(),
  votes: dataAttribute({ name: 'votes', default: 0 }),
}),
```

### 参数（`DataAttributeOptions`）

- `name`（`string`）：属性名称，例如 `votes`。HTML 会将其保存为 `data-votes`，将 `chartData` 保存为 `data-chart-data`。
- `default`（`string | number | boolean | null | readonly unknown[] | Record<string, unknown>`）：新形状的属性值。其类型决定 HTML 如何保存该值：字符串、数字、布尔值，或用于 `null`、对象和数组的 JSON。

### 返回值（`Attribute`）

供形状节点的 `addAttributes` 使用的属性。

## `shapeNodeView`

将组件的节点视图（例如应用中的 React 组件）转换为不含文本的[自定义形状](/editor/whiteboard/guides/custom-shapes)。白板会像处理自身形状一样放置、选择、移动和调整该形状的大小，而节点视图负责绘制组件。用户点击组件中的链接、按钮、输入框和可编辑内容时，交互会传递给这些元素；点击带有 `data-shape-interactive` 的元素时也一样。只读白板上同样如此，因此组件在修改白板前应检查 [`isBoardEditable()`](#isboardeditable)。

```js
import { ReactNodeViewRenderer } from '@tiptap/react'
import { shapeNodeView } from '@tiptap-pro/extension-whiteboard'

// 在形状的节点中
addNodeView: () => shapeNodeView({ dataType: 'poll', view: ReactNodeViewRenderer(PollView) }),
```

### 参数（`ShapeNodeViewOptions`）

- `dataType`（`string`）：形状元素的 `data-type`，例如由节点的 `renderHTML` 设置的值。
- `view`（`NodeViewRenderer`）：形状中组件的节点视图，例如来自 `@tiptap/react` 的 `ReactNodeViewRenderer(Component)`。其元素会填满形状。

### 返回值（`NodeViewRenderer`）

供该节点的 `addNodeView` 使用的形状节点视图。

## `insertShapesInFront`

将形状添加到所有其他形状前方。除非 z-index 另有排序，否则 `shapes` 中的形状按从后到前的顺序排列。如果形状没有 id，或其 id 与白板上已有形状或列表中的其他形状重复，则会抛出 `RangeError`。

```js
import {
  createShapeId,
  insertShapesInFront,
  stickyNoteContent,
} from '@tiptap-pro/extension-whiteboard'

const { tr, schema } = editor.state
const note = stickyNoteContent({ id: createShapeId(), x: 0, y: 0, text: 'Idea' })

insertShapesInFront({ tr, shapes: [schema.nodeFromJSON(note)] })
editor.view.dispatch(tr)
```

### 参数（`InsertShapesInFrontOptions`）

- `tr`（`Transaction`）：用于添加形状的事务，例如 `editor.state.tr`。
- `shapes`（`readonly Node[]`）：要添加的形状节点。

### 返回值（`number | null`）

第一个形状的位置；如果没有添加任何形状，则返回 `null`。

事务的派发由你负责。使用 `UndoRedo` 时，该事务会成为单独的撤销步骤。协作时，Yjs 会将短时间内连续发生的更改合并为一个步骤。

## `removeShapes`

删除具有指定 id 的形状，以及这些形状中框架里的形状。连接到已删除形状的箭头会保留，其连接到该形状的一端会变为自由端。

```js
import { removeShapes } from '@tiptap-pro/extension-whiteboard'

const { tr } = editor.state
removeShapes({ tr, ids: ['note-1'] })
editor.view.dispatch(tr)
```

### 参数（`RemoveShapesOptions`）

- `tr`（`Transaction`）：用于删除形状的事务，例如 `editor.state.tr`。
- `ids`（`readonly string[]`）：形状的 id。

### 返回值（`boolean`）

白板上是否存在这些形状中的任意一个。

事务的派发由你负责。使用 `UndoRedo` 时，该事务会成为单独的撤销步骤。协作时，Yjs 会将短时间内连续发生的更改合并为一个步骤。

## `restackShapes`

将具有指定 id 的形状移到所有其他形状的前方或后方，同时保持它们彼此之间的顺序。通常只有移动的形状会获得新的 z-index；如果缺少或无效的 z-index 导致没有可用空间，则可能需要调整其他形状。

```js
import { restackShapes } from '@tiptap-pro/extension-whiteboard'

const { tr } = editor.state
restackShapes({ tr, ids: ['note-1'], place: 'back' })
editor.view.dispatch(tr)
```

### 参数（`RestackShapesOptions`）

- `tr`（`Transaction`）：用于移动形状的事务，例如 `editor.state.tr`。
- `ids`（`readonly string[]`）：形状的 id。
- `place`（`StackPlace`）：形状的目标位置：`front` 表示移到所有其他形状前方，`back` 表示移到它们后方。

### 返回值（`boolean`）

白板上是否存在这些形状中的任意一个。

事务的派发由你负责。使用 `UndoRedo` 时，该事务会成为单独的撤销步骤。协作时，Yjs 会将短时间内连续发生的更改合并为一个步骤。

## `keepShapeHeights`

保留事务为形状设置的高度，供稍后到达的内容使用，例如 AI 添加文档框后再写入其文档。不使用此函数时，白板会根据内容高度调整自由文本和文档框的高度。

```js
import { keepShapeHeights } from '@tiptap-pro/extension-whiteboard'

const { tr } = editor.state
// … 添加文档稍后才会到达的文档框
editor.view.dispatch(keepShapeHeights(tr))
```

### 参数

- `tr`（`Transaction`）：事务，例如 `editor.state.tr`。

### 返回值（`Transaction`）

同一个事务。

此函数只会为事务添加标记，不会创建撤销步骤。

## `getDocEditors`

返回白板上文档框所显示文档的编辑器。

```js
import { getDocEditors } from '@tiptap-pro/extension-whiteboard'

const documents = getDocEditors(editor).map((docEditor) => docEditor.getJSON())
```

### 参数

- `editor`（`Editor`）：白板的编辑器。

### 返回值（`Editor[]`）

文档的编辑器；白板编辑器销毁后，返回空数组。

## `getEditedDocEditor`

返回文档框当前正在编辑的文档的编辑器。

```js
import { getEditedDocEditor } from '@tiptap-pro/extension-whiteboard'

// 同样适用于文档的加粗按钮
const textEditor = getEditedDocEditor(editor) ?? editor
textEditor.commands.toggleBold()
```

### 参数

- `editor`（`Editor`）：白板的编辑器。

### 返回值（`Editor | null`）

文档的编辑器；如果当前没有正在编辑的文档（例如白板编辑器已销毁），则返回 `null`。

## `addImageFiles`

使用白板的 [`images`](/editor/whiteboard/api-reference/types#boardimages) 上传图像文件，然后为每个文件添加一个图像形状，将它们置于所有其他形状前方，并作为白板历史记录中的一个步骤，同时选中这些形状。图像会保持原有比例，缩放到舞台的一半范围内，并围绕 `point` 并排放置。`images` 不允许的文件，以及上传失败的文件，会传递给其 `onError`。只读白板上不执行任何操作。参见[图像](/editor/whiteboard/guides/images)。

```js
import { addImageFiles } from '@tiptap-pro/extension-whiteboard'

input.addEventListener('change', () => addImageFiles({ stage, editor, files: input.files ?? [] }))
```

### 参数（`AddImageFilesOptions`）

- `stage`（`HTMLElement`）：白板外围元素。
- `editor`（`Editor`）：白板的编辑器。
- `files`（`Iterable<File>`）：要添加的文件，例如文件输入框中的文件。
- `point?`（`Point`）：图像的中心位置，单位为白板单位。默认值：舞台中心。

### 返回值（`Promise<string[]>`）

已添加图像形状的 id。如果没有配置 `images`、白板为只读，或上传完成前编辑器已销毁，则返回空数组。

## `createRemoteCursors`

在 `editor` 的白板上显示其他用户的光标及其名称。每个光标都位于对应用户指向的位置，在任何缩放比例下都保持相同大小，并会略微延迟地平滑移动到用户共享的位置。用户拖动的形状会跟随其光标移动，但文档不会因此发生更改；只有其他用户放下形状时，文档才会更新。参见[显示其他用户的光标](/editor/whiteboard/guides/collaboration#show-the-cursors-of-others)。

```js
import { createRemoteCursors } from '@tiptap-pro/extension-whiteboard'

const cursors = createRemoteCursors(editor)
cursors.update([{ owner: clientId, point: { x: 120, y: 80 }, name: 'Ada', color: '#be185d' }])
```

### 参数

- `editor`（`Editor`）：白板的编辑器。

### 返回值（`RemoteCursors`）

光标对象，包含两个函数：

- `update(cursors)`：显示这些[光标](/editor/whiteboard/api-reference/types#remotecursor)及其拖动的形状，并淡出其他光标。如果光标没有有效位置，或者拖动信息没有形状 id 和位移，则会忽略该条目，因为其他用户共享的内容可能不可靠。
- `destroy()`：立即移除所有光标，并将拖动中的形状显示在文档记录的位置。销毁编辑器时也会执行此操作。

## `createRemoteMoves`

在 `editor` 的白板上显示其他用户的拖动操作。其形状和连接这些形状的箭头会一起移动，但文档不会因此发生更改；只有其他用户放下形状时，文档才会更新。

```js
import { createRemoteMoves } from '@tiptap-pro/extension-whiteboard'

const moves = createRemoteMoves(editor)
moves.show({ owner: clientId, ids: ['note'], delta: { x: 40, y: 0 } })
moves.end(clientId)
```

### 参数

- `editor`（`Editor`）：白板的编辑器。

### 返回值（`RemoteMoves`）

移动操作对象，包含两个函数：

- `show({ owner, ids, delta })`：显示 `owner` 正在拖动的形状，并按 `delta` 移动。`owner` 表示拖动者，例如其他用户的客户端 id；`delta` 表示从拖动开始到现在形状移动的距离，单位为白板单位。
- `end(owner)`：结束 `owner` 的拖动。其形状会显示在文档记录的位置。

## `exportBoard`

将白板保存为白板文件，其中包含白板 JSON 和文档框所显示的文档。参见[导出和导入](/editor/whiteboard/guides/export-and-import)。

```js
import { exportBoard } from '@tiptap-pro/extension-whiteboard'

const json = JSON.stringify(exportBoard({ editor }))
```

### 参数（`ExportBoardOptions`）

- `editor`（`Editor`）：白板的编辑器。

### 返回值（`BoardFile`）

白板文件，可使用 `JSON.stringify` 写入。参见 [`BoardFile`](/editor/whiteboard/api-reference/types#boardfile)。

## `importBoard`

打开由 `exportBoard` 导出的白板文件，并将此操作作为白板历史记录中的一个步骤。每个文档框都会显示一个新文档，文件中的内容由 [`BoardDocs.load`](/editor/whiteboard/api-reference/types#boarddocs) 填充，因此其他白板可以保留其文档。此函数也可以打开 Excalidraw 和 tldraw 保存的文件；参见[打开 Excalidraw 和 tldraw 文件](/editor/whiteboard/guides/export-and-import#open-excalidraw-and-tldraw-files)。如果 JSON 不属于上述文件类型，或由更新版本写入，则会抛出 [`BoardFileError`](/editor/whiteboard/api-reference/types#boardfileerror)。

```js
import { importBoard } from '@tiptap-pro/extension-whiteboard'

importBoard({ editor, file: JSON.parse(await file.text()) })
```

### 参数（`ImportBoardOptions`）

- `editor`（`Editor`）：白板的编辑器。
- `file`（`unknown`）：解析后的白板文件 JSON，例如 `exportBoard` 返回的内容，或 Excalidraw、tldraw 保存的文件。
- `mode?`（`'replace' | 'insert'`）：`replace` 会用文件中的白板替换当前白板；`insert` 会像粘贴一样，将文件中的形状副本添加到当前形状前方并选中它们。默认值：`'replace'`。

### 返回值（`ImportBoardResult`）

已添加形状的 id，以及编辑器无法显示的文件形状。参见 [`ImportBoardResult`](/editor/whiteboard/api-reference/types#importboardresult)。

## `exportBoardSvg`

将白板形状绘制为 SVG 图像，呈现效果与页面上的显示一致：使用应用的样式以及形状所用的字体和图像。选择框、控制柄和光标不会包含在图像中。文本会以 `foreignObject` 中的 HTML 形式保存，浏览器可以显示，但部分矢量编辑器无法显示。

```js
import { exportBoardSvg } from '@tiptap-pro/extension-whiteboard'

const image = await exportBoardSvg({ editor, background: '#fff' })
```

### 参数（`ExportBoardSvgOptions`）

- `editor`（`Editor`）：白板的编辑器。白板必须位于页面中，否则函数会抛出错误。
- `ids?`（`readonly string[]`）：要绘制的形状的 id。指定的形状中如果包含框架，也会绘制其内部形状。默认值：所有形状。
- `padding?`（`number`）：形状周围的留白，单位为白板单位。默认值：`16`。
- `background?`（`string`）：形状后方的 CSS 颜色。不设置时，图像背景为透明。

### 返回值（`Promise<BoardSvg | null>`）

SVG 及其尺寸；如果没有可绘制的形状，则返回 `null`。参见 [`BoardSvg`](/editor/whiteboard/api-reference/types#boardsvg)。

## `exportBoardImage`

将白板形状绘制为 PNG 或 JPEG 图像，绘制方式与 [`exportBoardSvg`](#exportboardsvg) 相同。JPEG 图像的背景默认为白色，除非通过 `background` 指定其他背景。在 Safari 中，图像不包含盒阴影。

```js
import { exportBoardImage } from '@tiptap-pro/extension-whiteboard'

const png = await exportBoardImage({ editor, background: '#fff' })
```

### 参数（`ExportBoardImageOptions`）

除 [`exportBoardSvg`](#exportboardsvg) 的选项外，还包括：

- `format?`（`'png' | 'jpeg'`）：文件类型。默认值：`'png'`。
- `pixelRatio?`（`number`）：每个白板单位对应的像素数。画布尺寸过大时，此值会降低。默认值：`2`。
- `quality?`（`number`）：JPEG 图像的质量，范围为 0 到 1。

### 返回值（`Promise<Blob | null>`）

图像文件；如果没有可绘制的形状，则返回 `null`。
