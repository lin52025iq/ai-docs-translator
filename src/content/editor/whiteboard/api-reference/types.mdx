从 `@tiptap-pro/extension-whiteboard` 导入用于相机、形状、工具、样式、文档框架、白板文件和图像的 TypeScript 类型。

`Editor` 来自 `@tiptap/core`，`UndoRedoOptions` 来自 `@tiptap/extensions`。`ProseMirrorNode` 是 `@tiptap/pm/model` 中的 `Node`。

## `Camera`

白板在舞台中的显示位置。

### 属性

- `x`（`number`）：以屏幕像素为单位。
- `y`（`number`）：以屏幕像素为单位。
- `zoom`（`number`）：缩放比例，1 表示 100%。

## `UpdateCamera`

类型：`(update: (camera: Camera) => Camera) => void`。通过更新函数更改相机，类似 React 状态设置函数。

## `Point`、`Rect` 和 `Size`

### `Point`

一个点，`x` 向右，`y` 向下。

- `x`（`number`）
- `y`（`number`）

### `Rect`

一个矩形，以左上角为起点。

- `x`（`number`）
- `y`（`number`）
- `width`（`number`）
- `height`（`number`）

### `Size`

宽度和高度。

- `width`（`number`）
- `height`（`number`）

## `Insets`

舞台每条边缘要留出的空白区域，以屏幕像素为单位。接收内边距的选项也会为每条边缘接收一个数值。

### 属性

- `top`（`number`）
- `right`（`number`）
- `bottom`（`number`）
- `left`（`number`）

## `ShapeAttributes`

形状的属性。位置和尺寸以白板单位为准。

### 属性

- `id`（`string | null`）：在白板上唯一。
- `x`（`number`）
- `y`（`number`）
- `width`（`number`）
- `height`（`number`）
- `zIndex`（`string | null`）：分数索引；值越大，形状越靠前。
- `frameId`（`string | null`）：形状所在的[框架](/editor/whiteboard/guides/frames)，或 `null`。形状移入或移出框架时，白板会保留此值。
- `color`（`string`）：白板颜色的名称，例如 `yellow`。
- `kind?`（`GeoKind`）：几何形状的种类，即 `geoKinds` 中的名称。

箭头没有边界框，而是有端点，参见 [`ArrowEndAttributes`](#arrowendattributes)；还有 `arrowheads`、`arrowheadKind`、`arrowKind` 和 `dash` 样式，以及用于标签的 `fontSize` 和 `font`。文档框架没有 `color`，但有 `docId`。框架没有 `color` 和 `frameId`，但有 `name`。图像没有 `color`，但有 `src`（图像 URL）和 `alt`（供屏幕阅读器使用的文本）。含文本的形状还具有 `fontSize`、`textAlign` 和 `font` 样式，参见 [`ShapeStyles`](#shapestyles)。画笔线条还具有 `points` 和 `strokeWidth`。

## `ShapeGeometry`

类型：`Pick<ShapeAttributes, 'x' | 'y' | 'width' | 'height'>`。形状的边界框，以白板单位为准。

## `ArrowEndAttributes`

箭头端点的位置。如果端点的 id 对应白板上的某个形状，它就会跟随该形状；否则端点是自由的，位于其指定点上。

### 属性

- `fromId`（`string | null`）
- `toId`（`string | null`）
- `fromX`（`number`）
- `fromY`（`number`）
- `toX`（`number`）
- `toY`（`number`）
- `fromAnchorX`、`fromAnchorY`、`toAnchorX` 和 `toAnchorY`（`number`）：连接端点在形状边界框中的目标位置，左侧或顶部为 0，右侧或底部为 1。线条会在形状轮廓处停止。曲线或折线会从离端点最近的一侧经过，除非端点在两个轴上都位于边界框的中间半区。默认值：`0.5`，即中间位置。

## `ShapeUpdate`

对单个形状属性的更改。更新可以更改形状的任意属性，但 `id` 除外。

### 属性

- `id`（`string`）
- `attributes`（`ShapeUpdateAttributes`）

### `ShapeUpdateAttributes`

类型：`Partial<Omit<ShapeAttributes, 'id'> & ArrowEndAttributes & ShapeStyles & { points: string; strokeWidth: number; docId: string }> & { [attribute: string]: unknown; id?: never }`。

`points` 和 `strokeWidth` 是画笔线条的属性，`docId` 是文档框架的文档 id。[自定义形状](/editor/whiteboard/guides/custom-shapes)可以有自己的属性，例如图表数据。

## `Tool`、`ShapeTool` 和 `ToolKeys`

### `Tool`

类型：`'select' | 'hand' | 'eraser' | ShapeTool`。在白板上按下鼠标时执行的操作：选择形状、平移白板、擦除形状或添加形状。

### `ShapeTool`

类型：`'note' | 'text' | 'doc' | 'rectangle' | 'ellipse' | 'diamond' | 'pen' | 'arrow' | 'frame'`。`ShapeTool` 会添加对应种类的形状。

### `ToolKeys`

类型：`Readonly<Partial<Record<Tool, string | null>>>`。用于选择各工具的按键。设为 `null` 时，工具不会绑定按键。参见 [`toolKeys`](/editor/whiteboard/api-reference/utilities#toolkeys)。

## `GeoKind` 和 `ShapeColor`

### `GeoKind`

类型：`(typeof geoKinds)[number]`，即 `'rectangle' | 'ellipse' | 'diamond' | 'triangle'`。`geoKinds` 中的几何形状种类。

### `ShapeColor`

类型：`(typeof shapeColors)[number] | (string & {})`。白板颜色的名称：可以是 `shapeColors` 中的值（如 `'black'` 或 `'red'`），也可以是自定义名称。参见[颜色](/editor/whiteboard/api-reference/styling#colors)。

## `ShapeStyles`

类型：`{ [Name in ShapeStyleName]: ShapeStyleValue<Name> }`。形状样式来自 `shapeStyles`。`ShapeStyles` 为每种样式提供一个值。

### `ShapeStyleName`

类型：`keyof typeof shapeStyles`，即 `'color' | 'fontSize' | 'textAlign' | 'font' | 'arrowheads' | 'arrowheadKind' | 'arrowKind' | 'dash'`。样式名称，例如 `color` 或 `fontSize`。

### `ShapeStyleValue`

对于 `color`、`fontSize` 和 `font`，类型为 `(typeof shapeStyles)[Name][number] | (string & {})`；对于其他样式，类型为 `(typeof shapeStyles)[Name][number]`，其中 `Name extends ShapeStyleName`。样式值的名称，例如 `color` 的 `blue`。颜色、字号和字体也可以使用自定义名称，因为只有你的 CSS 才能定义它们的外观。

## `ShapeElementAttributes`

类型：`(node: ProseMirrorNode) => Record<string, unknown>`。根据形状的节点，返回该形状元素的额外属性。值会转换为字符串，值为 `null` 或 `undefined` 时则不添加该属性。

## `WhiteboardKitOptions`

`WhiteboardKit` 的选项。参见[扩展](/editor/whiteboard/api-reference/extensions#whiteboardkit)。

### 属性

- `undoRedo`（`Partial<UndoRedoOptions> | false`）
- `shapeElementAttributes`（`ShapeElementAttributes | null`）
- `docs`（`BoardDocs | null`）
- `images`（`BoardImages | null`）
- `colors`（`readonly ShapeColor[]`）
- `toolKeys`（`ToolKeys | false`）

`BoardOptions` 是 `Board` 的选项，包含 `shapeElementAttributes`、`docs` 和 `images`。`BoardStorage` 是白板存储在 `editor.storage.board` 中的内容，参见[扩展](/editor/whiteboard/api-reference/extensions#storage-boardstorage)。

Kit 会将 `colors` 和 `toolKeys` 传递给其扩展。`BoardTextColorOptions` 是 `BoardTextColor` 的选项，包含 `colors`。`BoardHighlightOptions` 是 `BoardHighlight` 的选项，包含 `colors` 和 Tiptap Highlight 的 `HighlightOptions`。`ShapeSelectionOptions` 是 `ShapeSelection` 的选项，包含 `toolKeys`。

## `BoardDocs`

文档框架的文档存放位置，例如本地存储或 Tiptap Cloud。由应用提供，以便白板无需处理任何存储。参见[文档框架](/editor/whiteboard/guides/doc-frames)。

### 属性

- `createEditor`（`(options: CreateDocEditorOptions) => Editor`）：在 `element` 中创建文档的编辑器。`element` 是框架的内容元素 `[data-shape-content]`。销毁框架时，白板也会销毁该编辑器。
- `start?`（`(docId: string) => void`）：启动此编辑器中的更改带到白板上的每个框架所对应的文档，包括新建的框架、执行 `copy` 后的副本，以及通过 `setContent` 或 `UndoRedo` 撤销操作恢复的框架。此回调会在框架显示前运行，因此应保留框架已有的文档。通过 Yjs 从其他编辑器或其撤销操作带来的框架，不会在此处启动文档。
- `copy`（`(options: CopyDocOptions) => void`）：为框架副本复制文档。此回调会在副本显示前、`start` 运行前执行。
- `load?`（`(options: LoadDocOptions) => void`）：为通过 `importBoard` 从白板文件导入的新框架填充文档内容。此回调会在框架显示前、`start` 运行前执行。如果未提供，导入的框架将为空。

### `CreateDocEditorOptions`

- `element`（`HTMLElement`）
- `docId`（`string`）

### `CopyDocOptions`

- `fromDocId`（`string`）
- `toDocId`（`string`）

### `LoadDocOptions`

- `docId`（`string`）：新文档的 id，导入的框架会显示该文档。
- `content`（`JSONContent`）：白板文件中该文档的 JSON。

## `BoardImages`

图像形状的文件存放位置，例如应用的文件存储。由应用提供，以便白板无需处理任何存储。图像会从 `upload` 返回的 URL 加载。参见[图像](/editor/whiteboard/guides/images)。

### 属性

- `upload`（`(options: UploadImageOptions) => Promise<string>`）：上传图像文件，并返回图像形状用于加载图像的 URL。
- `accept?`（`readonly string[]`）：用户可以添加的图像类型。默认值：`['image/png', 'image/jpeg', 'image/gif', 'image/webp', 'image/avif', 'image/svg+xml']`。
- `maxSize?`（`number`）：用户可以添加的最大文件大小，以字节为单位。默认值：`10 * 1024 * 1024`，即 10 MB。
- `onError?`（`(options: ImageErrorOptions) => void`）：通知应用白板未能添加的文件，以便应用显示提示等信息。

### `UploadImageOptions`

- `file`（`File`）：用户粘贴、拖放或选择的图像文件。
- `signal`（`AbortSignal`）：如果上传结束前白板编辑器被销毁，则中止上传。

### `ImageErrorOptions`

- `file`（`File`）：白板未能添加的文件。
- `reason`（`'type' | 'size' | 'upload'`）：`type` 表示 `accept` 未列出该文件类型，或浏览器无法显示该文件；`size` 表示文件大小超过 `maxSize`；`upload` 表示 `upload` 抛出错误，或返回了无法显示的 URL。
- `error?`（`unknown`）：`upload` 抛出的内容；如果返回的 URL 无法显示，则为该 URL。

## `BoardFile`

由 `exportBoard` 保存为 JSON 的白板，其中包含文档框架显示的文档。可通过 `importBoard` 重新打开。参见[导出和导入](/editor/whiteboard/guides/export-and-import)。

### 属性

- `type`（`'tiptap-whiteboard'`）：将 JSON 标记为白板文件。
- `version`（`number`）：文件格式版本。`importBoard` 可以打开不高于 `exportBoard` 写入版本的文件。
- `content`（`JSONContent`）：白板文档，类似于 `editor.getJSON()` 返回的内容。
- `docs`（`Record<string, JSONContent>`）：文档框架显示的文档，按文档 id 索引。

## `BoardFileError`

一个扩展 `Error` 的类。当 JSON 不是可打开的文件，或使用了更新的白板或 tldraw 文件格式时，`importBoard` 会抛出此错误。

### 属性

- `code`（`BoardFileErrorCode`）：文件无法打开的原因。

### `BoardFileErrorCode`

类型：`'not-a-board-file' | 'version-too-new'`。`not-a-board-file` 表示 JSON 不属于 `importBoard` 可打开的文件；`version-too-new` 表示白板或 tldraw 文件格式较新。

## `ImportBoardResult`

`importBoard` 添加了哪些内容，以及跳过了哪些内容。

### 属性

- `ids`（`string[]`）：已添加形状的 id。
- `skipped`（`SkippedShape[]`）：编辑器无法显示的文件中的形状，例如类型不受支持或属性类型不正确的形状。对于 Excalidraw 或 tldraw 文件，还包括白板没有对应形状的内容（例如框架）以及其他页面中的形状。每项都会说明跳过原因、内容以及文件提供的位置。

### `SkippedShape`

- `id`（`string | null`）：形状在文件中的 id；如果没有，则为 `null`。
- `type`（`string`）：形状在文件中的节点类型，或保存文件的应用中的类型，例如 `frame`。
- `reason`（`SkippedReason`）：跳过原因。
- `detail`（`string`，可选）：用于标识形状的内容，例如框架名称、链接、页面名称或文本。
- `box`（[`Rect`](#point-rect-and-size)，可选）：文件提供的白板位置。如果文件只提供位置，则宽度和高度为 0。在 `insert` 模式下，该位置会随副本一起移动。

### `SkippedReason`

类型：`'unsupported' | 'other-page' | 'missing-image' | 'unreadable'`。白板没有对应的形状（例如框架），或编辑器缺少对应的节点类型；该形状位于 tldraw 文件的第一页之后；文件缺少形状所显示的图像；或形状数据已损坏。

## `BoardSvg`

`exportBoardSvg` 返回的白板形状 SVG 图像。

### 属性

- `svg`（`string`）：SVG 标记。
- `width`（`number`）：图像宽度，以白板单位为准。
- `height`（`number`）：图像高度，以白板单位为准。

## `RemoteSelection`

另一位用户选中的形状及其颜色，颜色格式为 `#RRGGBB`。如果选择颜色是其他格式（例如 `red` 或 `#abc`），则不会显示。

### 属性

- `color`（`string`）
- `ids`（`readonly string[]`）

## `RemoteCursor`

另一位用户在白板上指向的位置以及拖动的内容。

### 属性

- `owner`（`unknown`）：光标所属者，例如另一位用户的客户端 id。
- `point`（`Point`）：用户指向的位置，以白板单位为准。
- `time?`（`number`）：用户浏览器按自身时钟共享该位置的时间，以毫秒为单位。光标会按照位置共享的节奏移动。未提供时，使用位置到达的时间。
- `name`（`string`）：光标旁显示的名称。
- `color`（`string`）：用户的颜色，格式为 `#RRGGBB`，用于光标的 `--remote-cursor`。其他格式的颜色不会显示。
- `drag?`（`{ ids: readonly string[]; delta: Point } | null`）：用户正在拖动的形状，以及从拖动开始至用户指向 `point` 时移动的距离，以白板单位为准。

## `RemoteCursors`

白板上其他用户的光标。`createRemoteCursors` 会返回此对象。

### 属性

- `update`（`(cursors: readonly RemoteCursor[]) => void`）
- `destroy`（`() => void`）

## `RemoteMoves`

显示其他用户的拖动操作，直到他们放下形状。`createRemoteMoves` 会返回此对象。

### 属性

- `show`（`(options: ShowRemoteMoveOptions) => void`）
- `end`（`(owner: unknown) => void`）

### `ShowRemoteMoveOptions`

- `owner`（`unknown`）：拖动所属者，例如另一位用户的客户端 id。
- `ids`（`readonly string[]`）
- `delta`（`Point`）：从拖动开始至今，形状移动的距离，以白板单位为准。

## `FreehandShape`

类型：`ShapeGeometry & { points: string }`。`freehandFromPoints` 返回的画笔线条边界框和点。

## `StackPlace`

类型：`'front' | 'back'`。`restackShapes` 放置形状的位置：所有其他形状的前方或后方。
