白板的编辑器会触发以下事件。使用 `editor.on()` 监听，使用 `editor.off()` 停止监听。

## `docChange`

当文档框中文档的编辑器发生事务（包括仅移动光标的事务）、开始或停止编辑，以及编辑器创建或销毁时触发。可用它更新同时适用于文档的工具栏，但不要用它保存文档。

```js
import { getEditedDocEditor } from '@tiptap-pro/extension-whiteboard'

editor.on('docChange', ({ docId }) => {
  const isEditing = getEditedDocEditor(editor) !== null
  console.log(`The document ${docId} changed. A document is edited: ${isEditing}`)
})
```

### 负载

- `docId` (`string`)：发生变化的文档 ID。

## `shapesMove`

拖动形状时会触发此事件，`delta` 表示形状移动的距离，单位为白板单位。拖动结束后，`delta` 为 `null`。拖动结束时，放置操作会先更改文档，然后此事件才会报告拖动结束。

将此事件分享给其他用户，这样 [`createRemoteMoves`](/editor/whiteboard/api-reference/utilities#createremotemoves) 或 [`createRemoteCursors`](/editor/whiteboard/api-reference/utilities#createremotecursors) 就能在他们的白板上显示拖动：

```js
editor.on('shapesMove', ({ ids, delta }) => {
  provider.setAwarenessField('drag', delta ? { ids, delta } : null)
})
```

### 负载

- `ids` (`readonly string[]`)：被拖动形状的 ID。
- `delta` (`Point | null`)：从拖动开始到当前为止形状移动的距离；拖动结束后为 `null`。

参见[协作](/editor/whiteboard/guides/collaboration#show-what-others-select-and-drag)。
