白板扩展的所有编辑器命令。`WhiteboardKit` 会添加这些命令。

- 通过 ID 查找形状。
- 位置和尺寸的单位均为白板单位。

其他文本命令来自 kit 中的 Tiptap 扩展，例如 `toggleBold`、`setHighlight`、`setLink` 和 `toggleTaskList`。`setHighlight` 接受白板颜色，例如 `setHighlight({ color: 'blue' })`。

## `insertShape`

在所有其他形状前方添加一个形状，除非选项中指定了样式，否则使用 [`setShapeStyle()`](#setshapestyle) 设置的样式。如果形状包含文本，则将光标置于其中；否则选中该形状。

```js
editor.commands.insertShape({ type: 'geo', kind: 'ellipse', x: 100, y: 100 })
```

### 参数（`InsertShapeOptions`）

- `type`（`string`）：形状的节点类型，例如 `geo`、`freeText` 或 `arrow`。
- `id?`（`string`）：白板上尚未被任何形状使用的 ID。如果未提供，则自动生成。
- 其他属性（`unknown`）：形状的属性，例如 `x`、`y` 或 `color`。

### 返回值（`boolean`）

如果某个属性为 `NaN` 或无穷大、类型不是形状，或白板上已有形状使用该 ID，则返回 `false`，且不添加任何内容。

## `updateShape`

更改指定 ID 的形状属性。与 [`updateShapes()`](#updateshapes) 类似，不会处理没有变化的属性。

```js
editor.commands.updateShape({ id: 'note-1', attributes: { color: 'blue' } })
```

### 参数

- `update`（`ShapeUpdate`）：形状的 ID 和要更改的属性。

### 返回值（`boolean`）

如果没有任何变化，则返回 `false`。

## `updateShapes`

在一个步骤中更改多个形状的属性。会跳过不在白板上的 ID、会更改 ID 或包含 `NaN` 或无穷大数值的更新、形状不具备的属性，以及已具有相应属性的形状。

```js
editor.commands.updateShapes([
  { id: 'idea', attributes: { x: 0 } },
  { id: 'plan', attributes: { x: 300 } },
])
```

### 参数

- `updates`（`readonly ShapeUpdate[]`）：每个形状的 ID 及要更改的属性。

### 返回值（`boolean`）

如果没有任何变化，则返回 `false`。

## `moveShapes`

移动指定 ID 的形状。箭头会移动其自由端。

```js
editor.commands.moveShapes({ ids: ['note-1', 'note-2'], delta: { x: 40, y: 0 } })
```

### 参数（`MoveShapesOptions`）

- `ids`（`readonly string[]`）：形状的 ID。
- `delta`（`Point`）：移动距离，单位为白板单位。

### 返回值（`boolean`）

如果没有任何形状会移动，则返回 `false`。

## `duplicateShapes`

复制指定形状，为副本生成新的 ID，按 `offset` 偏移，将副本置于所有其他形状前方并选中。复制文档画框时，会从 `docs` 选项复制其文档。复制画框时，也会复制其中的形状。

```js
import { getSelectedShapeIds } from '@tiptap-pro/extension-whiteboard'

editor.commands.duplicateShapes({ ids: getSelectedShapeIds(editor.state) })
```

### 参数（`DuplicateShapesOptions`）

- `ids`（`readonly string[]`）：形状的 ID。
- `offset?`（`Point`）：副本相对于原形状的偏移距离，单位为白板单位。默认向右下方偏移 24。

### 返回值（`boolean`）

如果指定的形状均不在白板上，或偏移量为 `NaN` 或无穷大，则返回 `false`，且不添加任何内容。

## `deleteShapes`

在一个步骤中删除指定 ID 的形状，以及这些形状中的画框。连接到已删除形状的箭头会保留，其端点停留在原来与形状连接的位置。

```js
editor.commands.deleteShapes(['note-1'])
```

### 参数

- `ids`（`readonly string[]`）：形状的 ID。

### 返回值（`boolean`）

如果指定的形状均不在白板上，则返回 `false`。

## `frameShapes`

用一个新的[画框](/editor/whiteboard/guides/frames)围住指定形状，四周留出 32 个白板单位的空间，并选中该画框。其他画框中的形状会移入新画框。画框和箭头不会被放入其中。

```js
editor.commands.frameShapes({ ids: ['note-1', 'note-2'], name: 'Ideas' })
```

### 参数（`FrameShapesOptions`）

- `ids`（`readonly string[]`）：要放入画框的形状 ID。
- `id?`（`string`）：新画框的 ID。默认自动生成。
- `name?`（`string`）：新画框的名称。如果未提供，则显示“画框”。

### 返回值（`boolean`）

如果没有可放入画框的形状，或已有形状使用该 ID，则返回 `false`。

## `removeFrame`

移除画框，并将其中的形状保留在白板上。`deleteShapes` 会连同画框一起删除这些形状。

```js
editor.commands.removeFrame('frame-1')
```

### 参数

- `id`（`string`）：画框的 ID。

### 返回值（`boolean`）

如果白板上没有该 ID 的画框，则返回 `false`。

## `bringToFront`

将指定形状置于所有其他形状前方，同时保持它们之间的顺序。

```js
import { getSelectedShapeIds } from '@tiptap-pro/extension-whiteboard'

editor.commands.bringToFront(getSelectedShapeIds(editor.state))
```

### 参数

- `ids`（`readonly string[]`）：形状的 ID。

### 返回值（`boolean`）

如果指定的形状均不在白板上，则返回 `false`。

## `sendToBack`

将指定形状置于所有其他形状后方，同时保持它们之间的顺序。

```js
editor.commands.sendToBack(['note-1'])
```

### 参数

- `ids`（`readonly string[]`）：形状的 ID。

### 返回值（`boolean`）

如果指定的形状均不在白板上，则返回 `false`。

## `insertStickyNote`

在所有其他形状前方添加便签，并将光标置于便签内。便签默认为黄色，除非 [`setShapeStyle()`](#setshapestyle) 设置了其他颜色。

```js
editor.commands.insertStickyNote({ x: 100, y: 100 })
```

### 参数（`InsertStickyNoteOptions`）

- `x`（`number`）：便签左边缘的位置。
- `y`（`number`）：便签上边缘的位置。
- `width?`（`number`）：默认值为 `stickyNoteSize` 的宽度，即 220。
- `height?`（`number`）：默认值为 `stickyNoteSize` 的高度，即 160。
- `id?`（`string`）：白板上尚未被任何形状使用的 ID。如果未提供，则自动生成。

### 返回值（`boolean`）

如果某个选项为 `NaN` 或无穷大，或白板上已有形状使用该 ID，则返回 `false`，且不添加任何内容。

## `selectShapes`

选中指定 ID 的形状。忽略未知 ID。

```js
editor.commands.selectShapes(['idea', 'plan'])
```

### 参数

- `ids`（`readonly string[]`）：形状的 ID，按选中顺序排列。

### 返回值（`boolean`）

始终返回 `true`。

## `toggleShapeSelection`

将形状加入选区；如果它已经被选中，则将其从选区中移除。

```js
editor.commands.toggleShapeSelection('idea')
```

### 参数

- `id`（`string`）：形状的 ID。

### 返回值（`boolean`）

始终返回 `true`。

## `selectAllShapes`

选中白板上的所有形状。

```js
editor.commands.selectAllShapes()
```

### 参数

无。

### 返回值（`boolean`）

始终返回 `true`。

## `clearShapeSelection`

取消选中所有形状并结束文本编辑，使按键作用于白板。

```js
editor.commands.clearShapeSelection()
```

### 参数

无。

### 返回值（`boolean`）

始终返回 `true`。

## `editShapeText`

取消选中所有形状，并将光标置于指定形状的文本中：如果 `pos` 位于该文本范围内，则放在该位置；否则放在文本末尾。文档画框会改为开始编辑其中的文档。在[只读白板](/editor/whiteboard/guides/shapes-and-tools#read-only-boards)上则会选中该形状。

```js
editor.chain().focus().editShapeText({ id: 'note-1' }).run()
```

### 参数（`EditShapeTextOptions`）

- `id`（`string`）：形状的 ID。
- `pos?`（`number`）：光标在文档中的位置，即形状文本内的位置。默认位于文本末尾。

### 返回值（`boolean`）

如果没有形状使用该 ID、形状不包含文本（例如画笔线条），或白板未配置 `docs`，则对文档画框返回 `false`。

## `focusBoard`

在链式调用的事务完成后，将焦点置于白板，或正在编辑的文本中。与 `focus` 不同，即使文本为只读也能使用。对于链式调用外的代码（例如工具栏按钮的点击处理程序），请调用 [`focusBoard()` 函数](/editor/whiteboard/api-reference/utilities#focusboard)，它会立即设置焦点。

```js
editor.chain().selectShapes(['note-1']).focusBoard().run()
```

### 参数

无。

### 返回值（`boolean`）

始终返回 `true`。

## `selectShapeText`

选中当前承载选区的形状中的所有文本。

```js
editor.chain().editShapeText({ id: 'note' }).selectShapeText().run()
```

### 参数

无。

### 返回值（`boolean`）

如果没有形状承载选区，则返回 `false`。当键盘焦点位于白板上时，该命令会返回 `true`，但不会选中任何内容；因此请先开始编辑，例如调用 `editShapeText`。

## `setTextColor`

使用白板颜色为选中的文本着色。标记中存储的是颜色名称，因此具体显示效果由 CSS 决定。

```js
editor.commands.setTextColor('red')
```

### 参数

- `color`（`ShapeColor`）：白板颜色的名称，例如 `red`。

### 返回值（`boolean`）

如果选中的文本均无法应用该标记，则返回 `false`。

## `unsetTextColor`

将选中文本的颜色恢复为其所在形状的颜色。

```js
editor.commands.unsetTextColor()
```

### 参数

无。

### 返回值（`boolean`）

始终返回 `true`。

## `setTool`

设置在白板上按下鼠标时执行的操作，并结束文本编辑，使按键作用于白板。此命令不会移动焦点：点击工具栏按钮后，请调用 [`focusBoard()` 函数](/editor/whiteboard/api-reference/utilities#focusboard)。在[只读白板](/editor/whiteboard/guides/shapes-and-tools#read-only-boards)上，使用会更改白板的工具时会切换回 `select`。`doc` 工具需要 [`docs` 选项](/editor/whiteboard/guides/doc-frames)。

```js
editor.commands.setTool('pen')
```

### 参数

- `tool`（`Tool`）：工具，例如 `select`、`note` 或 `pen`。

### 返回值（`boolean`）

如果白板未配置 `docs`，使用 `doc` 工具时返回 `false`；使用其他工具时均返回 `true`。

## `setShapeStyle`

在一个步骤中为选中的形状或正在编辑文本的形状设置样式，之后添加的形状也会使用该样式。不支持该样式的形状保持不变。

```js
editor.commands.setShapeStyle({ name: 'color', value: 'blue' })
```

### 参数（`SetShapeStyleOptions<Name>`）

- `name`（`ShapeStyleName`）：样式名称，例如 `color` 或 `fontSize`。
- `value`（`ShapeStyleValue<Name>`）：样式值，例如 `blue` 或 `l`。

### 返回值（`boolean`）

始终返回 `true`。

## `undoBoard`

撤销上一次更改，并选中受影响的形状。如果撤销操作仅更改了文本，则会返回到该文本的编辑状态。支持 Tiptap 的 `UndoRedo` 和 Collaboration。

```js
editor.commands.undoBoard()
```

### 参数

无。

### 返回值（`boolean`）

如果没有可撤销的更改，或编辑器既未启用 `UndoRedo` 也未启用 Collaboration，则返回 `false`。

## `redoBoard`

重做上一次撤销的更改，并选中受影响的形状。如果重做操作仅更改了文本，则会返回到该文本的编辑状态。

```js
editor.commands.redoBoard()
```

### 参数

无。

### 返回值（`boolean`）

如果没有可重做的更改，或编辑器既未启用 `UndoRedo` 也未启用 Collaboration，则返回 `false`。

## `setRemoteSelections`

显示其他用户选中的形状，替换之前显示的选区。请参阅[协作](/editor/whiteboard/guides/collaboration#show-what-others-select-and-drag)。

```js
editor.commands.setRemoteSelections([{ color: '#be185d', ids: ['idea'] }])
```

### 参数

- `selections`（`readonly RemoteSelection[]`）：每位用户选中的形状，以及该用户的颜色。

### 返回值（`boolean`）

始终返回 `true`。

颜色必须采用 `#RRGGBB` 格式，其他格式的选区不会显示。多位用户选中同一形状时，会显示首个使用有效颜色的用户的选区。
