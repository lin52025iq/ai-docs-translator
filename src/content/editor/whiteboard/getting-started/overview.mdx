使用 **Whiteboard** 扩展，Tiptap 编辑器即可变成白板。用户可以在白板上添加便利贴、形状、文本、箭头、笔迹、画框、文档框和图片，并在白板上平移和缩放。该扩展采用无头模式：它负责绘制白板及其形状，而你的应用负责添加工具栏和白板周围的舞台。

## 安装

首先，[联系我们的团队](https://tiptap.dev/contact-sales?form=pilot-program)，加入 Tiptap Whiteboard 试点计划。

然后，按照[私有注册表指南](/guides/pro-extensions)配置包管理器。

接着，安装软件包：

```bash
npm install @tiptap/core @tiptap/pm @tiptap-pro/extension-whiteboard
```

<Callout title="所需的 Tiptap 版本" variant="warning" hasCalloutAfter>
  确保所有 `@tiptap/*` 软件包的版本均为 `3.22.5` 或更高，且版本一致；该软件包安装的文本扩展（例如 `@tiptap/extension-bold`）也要满足这一要求。
</Callout>

<Callout title="不要添加 Document 和 StarterKit" variant="warning" hasCalloutBefore>
  `WhiteboardKit` 自带文档、文本扩展和撤销功能，因此不要在白板编辑器中添加 `Document` 或
  `StarterKit`。
</Callout>

协作功能是可选的，位于 `@tiptap-pro/extension-whiteboard/collaboration` 中；只有这个入口需要 Yjs。请参阅[白板协作](/editor/whiteboard/guides/collaboration)。

## 基本设置

页面中需要两个元素来承载白板：接收指针和滚轮事件的舞台，以及舞台内部由摄像机移动的视口。在 `viewport` 中创建编辑器，并使用 `attachStage` 将其连接到 `stage`：

```js
import { Editor } from '@tiptap/core'
import { attachStage, toCssTransform, WhiteboardKit } from '@tiptap-pro/extension-whiteboard'

const editor = new Editor({ element: viewport, extensions: [WhiteboardKit] })
let camera = { x: 0, y: 0, zoom: 1 }

// Pan, zoom, draw and select in the stage, the element around the board
const detach = attachStage({
  stage,
  editor,
  updateCamera: (update) => {
    camera = update(camera)
    viewport.style.transform = toCssTransform(camera)
    viewport.style.setProperty('--zoom', String(camera.zoom))
  },
})
```

`attachStage` 会调用 `updateCamera`，并传入一个将旧摄像机状态转换为新状态的函数；它还会返回一个用于解除所有连接的函数。

舞台需要设置 `position: relative`、`overflow: clip` 和 `touch-action: none`。视口位于舞台左上角，并设置 `position: absolute`、`top: 0`、`left: 0` 和 `transform-origin: 0 0`：

```css
.stage {
  height: 32rem;
  overflow: clip;
  position: relative;
  touch-action: none;
}

.viewport {
  left: 0;
  position: absolute;
  top: 0;
  transform-origin: 0 0;
}

/* The board's origin sits in the corner of the viewport, so the editor keeps no margin */
.viewport .tiptap {
  margin: 0;
}
```

## 工作原理

### 整个白板是一个 Tiptap 文档

`WhiteboardKit` 自带顶层节点。文档包含一个 `board` 节点，而该节点包含各个形状。因此，白板的加载、保存和同步方式与其他 Tiptap 文档相同，例如可以保存为 JSON，或通过 Yjs 同步。

### 形状是节点

白板上的每个形状都是一个节点。其位置和尺寸以白板单位作为属性。便利贴、几何形状和自由文本可以包含段落和列表，用户可以像编辑其他内容一样编辑其中的文本。箭头会将段落作为标签。笔迹、画框、文档框和图片都是原子节点。画框会将 `frameId` 指向该画框的形状归为一组，详见[画框](/editor/whiteboard/guides/frames)。

每个形状都有一个 `id`，命令通过这些 ID 查找形状。白板通过 ID 单独记录选中的形状，与文本选区分开。当没有正在编辑文本时，按键会作用于白板：选择工具，并移动、删除或调整选中形状的堆叠顺序。

### 摄像机可以平移和缩放

舞台是白板外围的元素，其中的视口元素承载编辑器。`{ x, y, zoom }` 摄像机状态由你的应用管理。`attachStage` 会将舞台中的指针和滚轮事件及快捷键转换为摄像机状态变化，而你的应用则使用 `toCssTransform(camera)` 移动视口。请参阅[舞台和摄像机](/editor/whiteboard/guides/stage-and-camera)。

### 文档框可容纳独立文档

文档框是一种形状，可在自己的编辑器中显示富文本文档。白板会存储该画框及其文档 ID。你的应用负责保存这些文档并创建相应的编辑器。请参阅[文档框](/editor/whiteboard/guides/doc-frames)。
