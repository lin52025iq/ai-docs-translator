使用 React 和 Vue 创建带有自定义形状的白板：投票卡片由 React 或 Vue 组件绘制。用户可以通过每张卡片上的按钮投票，也可以像操作其他形状一样选择、移动和调整卡片大小。白板上方的按钮可以添加新卡片。请参阅[自定义形状](/editor/whiteboard/guides/custom-shapes)。
