这是一个使用 React 和 Vue 构建的白板，提供工具、撤销和重做、缩放以及将所有图形调整到视图范围内的按钮。颜色按钮可为选中的图形以及接下来添加的图形着色；箭头按钮可更改选中箭头以及接下来添加的箭头的线条、虚线样式和箭头端点。此示例在白板的颜色中添加了 `pink`。导出会将白板保存为 JSON 文件；导入会打开 JSON 文件，可替换白板内容，也可将内容添加到白板中。PNG 和 SVG 可将选中的图形或整个白板保存为图像；复制则会将其复制为 PNG。图像工具可添加图像文件，你也可以将图像粘贴或拖放到白板上。此示例没有服务器，因此图像会以数据 URL 的形式保存在白板中。白板初始包含便利贴、图形、箭头和一条画笔线。按下某个工具对应的按键（例如按 <kbd>N</kbd> 选择便利贴工具），即可选中该工具。
