导入包含分页符的 `.docx` 文件时，转换服务会在 Tiptap JSON 输出中生成 `pageBreak` 节点。若要在编辑器中渲染这些分页符并与之交互，请注册 `@tiptap-pro/extension-pagebreak` 扩展。

<CodeDemo isPro path="/Extensions/PageBreak" />

## 安装 PageBreak 扩展

```bash
npm install @tiptap-pro/extension-pagebreak
```

## 设置编辑器

将 PageBreak 扩展与 Import 扩展一同注册。导入时支持分页符无需额外配置。

```ts
import { Editor } from '@tiptap/core'
import { ConvertKit } from '@tiptap-pro/extension-convert-kit'
import { ImportDocx } from '@tiptap-pro/extension-import-docx'
import { PageBreak } from '@tiptap-pro/extension-pagebreak'

const editor = new Editor({
  extensions: [
    ConvertKit,
    PageBreak,
    ImportDocx.configure({
      token: 'your-jwt',
      imageUploadConfig: {
        url: 'https://your-image-upload-endpoint.com',
      },
    }),
  ],
})
```

导入 `.docx` 文件时，文档中的分页符都会在编辑器中保留为 `pageBreak` 节点。

```ts
editor.chain().focus().importDocx({ file }).run()
```

## 工作原理

1. 转换服务会检测 `.docx` 文件中的分页符元素（`<w:br w:type="page"/>`）。
2. 每个分页符都会在 Tiptap JSON 输出中生成为 `{ type: "pageBreak" }` 节点。
3. PageBreak 扩展会将这些节点渲染为可视的虚线分隔线，并在中央显示“分页符”标签。

<Callout title="未使用 PageBreak 扩展时">
  如果未注册 PageBreak 扩展，导入的 `pageBreak` 节点需要通过[自定义扩展](/editor/extensions/custom-extensions/extend-existing)才能渲染。否则，编辑器架构将无法识别该节点类型。有关应对方法，请参阅[无效架构指南](/guides/invalid-schema)。
</Callout>
