`@tiptap-pro/extension-import-docx` 扩展允许你定义导入 DOCX 文件时，如何将其中的自定义节点映射回 Tiptap schema。

## 从 .docx 导入自定义节点

<CodeDemo isPro path="/Extensions/ImportDocxCustomNode" />

导入 DOCX 文件时，你可以定义如何将自定义节点转换回 Tiptap 节点。具体做法是向 `import` 命令传入一个由自定义节点定义组成的数组。

```ts
import { ImportDocx } from '@tiptap-pro/extension-import-docx'

// ... inside your Editor or useEditor setup:
ImportDocx.configure({
  token: 'your-jwt',
  // ATTENTION: This is for demo purposes only
  endpoint: 'https://your-endpoint.com',
  imageUploadConfig: {
    url: 'https://your-endpoint.com/image-upload',
  },
  // ProseMirror custom node mapping
  prosemirrorNodes: {
    Hintbox: 'hintbox',
  },
}),
```

最新版的 `@tiptap-pro/extension-import-docx` 提供了 `prosemirrorNodes` 配置选项。此选项允许你将 DOCX 中的自定义节点映射到 Tiptap schema。在上面的示例中，我们将 DOCX 中的 `Hintbox` 自定义节点映射到 Tiptap schema 中的 `hintbox` 自定义节点。这样，导入时只要 DOCX 中包含 `Hintbox` 自定义节点，它就会在 Tiptap 中转换为 `hintbox` 节点。

<Callout title='DOCX、“prosemirrorNodes”和“prosemirrorMarks”' variant="info">
  请注意，只有在导入 `.docx` 文件时，`prosemirrorNodes` 和 `prosemirrorMarks` 选项才会生效。如果导入的是其他类型的文件，例如 `.odt` 文件，则会使用 `/import` 端点，而不是 `/import-docx` 端点。此时无法使用 `prosemirrorNodes` 和 `prosemirrorMarks` 选项，因此你需要使用这些端点的[自定义节点和标记映射 API](/conversion/import/docx/rest-api#custom-node-and-mark-mapping)。
</Callout>
