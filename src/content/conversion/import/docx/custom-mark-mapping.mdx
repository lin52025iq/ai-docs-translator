导入 DOCX 文件时，还可以定义如何将自定义标记转换回 Tiptap 节点。只需向 `import` 命令传入一个自定义标记定义数组即可。借助此功能，可以轻松地将 Word 中的自定义样式转换为 Tiptap 格式。

```ts
import { ImportDocx } from '@tiptap-pro/extension-import-docx'

const editor = new Editor({
  extensions: [
    // Other extensions ...
    ImportDocx.configure({
      token: 'your-jwt',
      // ATTENTION: This is for demo purposes only
      endpoint: 'https://your-endpoint.com',
      imageUploadConfig: {
        url: 'https://your-endpoint.com/image-upload',
      },
      // ProseMirror custom mark mapping
      prosemirrorMarks: {
        strong: 'bold',
        em: 'italic',
      }
    }),
    // Other extensions ...
  ],
  // Other editor settings ...
})
```

最新版本的 `@tiptap-pro/extension-import-docx` 提供了 `prosemirrorMarks` 配置选项。

此选项允许你将 DOCX 中的自定义节点映射到 Tiptap 架构。在上面的示例中，我们将 DOCX 中的 `strong` 和 `em` 节点映射到 Tiptap 架构中的 `bold` 和 `italic` 节点。

这样，导入时，DOCX 中的 `strong` 或 `em` 节点就会分别转换为 Tiptap 中的 `bold` 或 `italic` 节点。

<Callout title='DOCX、“prosemirrorNodes”和“prosemirrorMarks”' variant="info">
  请注意，`prosemirrorNodes` 和 `prosemirrorMarks` 选项仅在导入 `.docx` 文件时有效。如果导入的是其他类型的文件，例如 `.odt` 文件，则会使用 `/import` 端点而不是 `/import-docx` 端点，并且无法使用 `prosemirrorNodes` 和 `prosemirrorMarks` 选项。
</Callout>
