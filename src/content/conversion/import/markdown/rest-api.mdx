## 导入 Markdown

`POST /v2/convert/import/markdown`

`/v2/convert/import/markdown` 端点可将 Markdown 文件（`.md` 或 `.markdown`）转换为 Tiptap JSON 格式。请使用 `multipart/form-data` 上传文件。

### 示例（cURL）

```bash
curl -X POST "https://api.tiptap.dev/v2/convert/import/markdown" \
    -H "Authorization: Bearer YOUR_TOKEN" \
    -F "file=@/path/to/file.md"
```

<Callout title="需要订阅" variant="warning">
  此端点需要有效的 Tiptap 订阅。详情请查看我们的[定价页面](https://tiptap.dev/pricing)。
</Callout>

### 必需的请求头

| 名称            | 说明                                                                 |
| --------------- | --------------------------------------------------------------------------- |
| `Authorization` | 用于验证请求的 JWT 令牌。例如：`Bearer your-jwt-token` |

### 请求体

| 名称   | 类型   | 必需 | 说明                                         |
| ------ | ------ | -------- | --------------------------------------------------- |
| `file` | `File` | 是      | 要转换的 Markdown 文件（`.md` 或 `.markdown`） |

### 响应（200 OK）

```json
{
  "data": {
    "content": {
      "type": "doc",
      "content": [
        {
          "type": "paragraph",
          "content": [
            {
              "type": "text",
              "text": "Hello from Markdown!"
            }
          ]
        }
      ]
    }
  },
  "logs": {
    "info": [],
    "warn": [],
    "error": []
  }
}
```

### 错误响应

| 状态 | 代码                                        | 说明                        |
| ------ | ------------------------------------------- | ---------------------------------- |
| 400    | `NO_FILE_PROVIDED`                          | 未提供文件               |
| 400    | `INVALID_FILE_TYPE`                         | 文件不是 `.md` 或 `.markdown` 格式   |
| 422    | `FAILED_TO_GET_FILE_ARRAY_BUFFER`           | 无法读取文件缓冲区         |
| 500    | `FAILED_TO_CONVERT_MARKDOWN_TO_TIPTAP_JSON` | 无法将 Markdown 转换为 JSON |

## 支持情况与限制

Markdown 导入通过 v2 云 API 将 Markdown 文本解析为 Tiptap JSON。此端点支持标准 CommonMark 和 GFM 表格。导入服务不会解析 Tiptap 可选扩展（下划线、高亮、数学公式）使用的自定义语法，因此这些内容不会出现在返回的 JSON 中。

| **功能**               | **支持情况**                                                         |
| ------------------------- | ------------------------------------------------------------------- |
| **文本内容**          | ✓ 段落、标题（1–6 级）、硬换行                           |
| **行内格式**     | ✓ 粗体、斜体、删除线、行内代码                          |
| **块级元素**        | ✓ 引用块、代码块（带语言标记的围栏代码块）、水平线 |
| **列表**                 | ✓ 无序列表、有序列表、任务列表、嵌套列表             |
| **表格**                | ✓ 基本管道符语法表格（单个标题行，不支持合并单元格）     |
| **链接**                 | ✓ 包含文本和 URL 的超链接                                      |
| **图片**                | ✓ 带替代文本的图片引用                                    |
| **下划线**             | ✗ 服务器未注册自定义 `++text++` 语法             |
| **高亮**             | ✗ 服务器未注册自定义 `==text==` 语法             |
| **文本颜色 / 字体**     | ✗ Markdown 没有设置颜色、字体系列或字号的语法          |
| **文本对齐**        | ✗ Markdown 不提供相关语法                                                |
| **间距 / 缩进** | ✗ Markdown 不提供相关语法                                                |
| **合并单元格**          | ✗ Markdown 表格不支持 colspan 或 rowspan                  |
| **页眉和页脚**     | ✗ Markdown 中没有此概念                                            |
| **页面布局**           | ✗ 不支持分页符、分节或页面大小                            |
| **数学公式**                  | ✗ 服务器未注册 `$...$` 语法                       |
| **脚注和尾注**  | ✗ CommonMark 不支持                                       |

如需查看完整的 DOCX 功能对比，请参阅[支持的功能](/conversion/getting-started/feature-support-matrix)矩阵。
