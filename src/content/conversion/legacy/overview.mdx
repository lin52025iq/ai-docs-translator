Tiptap 最初提供的 `extension-import` 和 `extension-export` 软件包，可用于可靠地导入和导出 DOCX 文件。

这些扩展及其相关端点仍向所有 Tiptap 账户用户开放，但已弃用，不再积极开发。

它们已由新版 [Tiptap 转换](/conversion/getting-started/overview)扩展和服务取代。

<Callout title="从旧版扩展迁移" variant="hint">
  请参阅[迁移指南](/conversion/legacy/migration-guide)，了解如何逐步切换到特定格式的 Conversion 扩展和 `/v2/` REST 端点。
</Callout>

<Callout title="默认端点已不再托管" variant="warning">
  旧版 `extension-import` 和 `extension-export` 软件包的 `endpoint` 选项默认值为
  `/v1/convert`，而 Conversion 服务已不再托管此端点。现有集成必须显式传入
  `endpoint: 'https://api.tiptap.dev/v2/convert'`（并接受下文所述的响应结构差异），或迁移到特定格式的 Conversion 扩展。
</Callout>

以下指南主要介绍如何配置旧版扩展。

## 导入旧版扩展

<Callout title="旧版导入扩展（已弃用）" variant="warning">
  **extension-import** 软件包已弃用，不再添加新功能；在移除旧版端点前，我们会提前 90 天通知。请迁移到[较新的解决方案](/conversion/getting-started/overview)，以确保服务不中断。
</Callout>

```js
// 首先导入扩展
import { Import } from '@tiptap-pro/extension-import'

const editor = new Editor({
  // ...
  extensions: [
    // ...
    Import.configure({
      // 在 Convert 设置页面中获取 Convert App-ID：https://cloud.tiptap.dev/convert-settings
      appId: 'your-app-id',

      // 上一步生成的 JWT
      token: 'your-jwt',

      // 用于上传图片的 URL；如果未提供，文档中的图片将被移除
      imageUploadCallbackUrl: 'https://your-image-upload-url.com',

      // 启用实验性的 DOCX 导入，以便更好地保留内容样式
      experimentalDocxImport: true,
    }),
  ],
})
```

### 导入第一份文档

```js
// 导入文件的最简单方式
// 这会导入上传的文件、替换编辑器内容
// 并聚焦编辑器
editor.chain().focus().import({ file }).run()
```

#### 自定义导入行为

```js
// 你也可以使用 onImport 回调来自定义导入行为
editor
  .chain()
  .import({
    file,
    onImport(context) {
      const { setEditorContent, content, error } = context

      // 添加错误处理
      if (error) {
        showErrorToast({ message: error.message })
      }

      // 也可以在插入内容之前修改它
      content.doc.content.push({ type: 'paragraph', content: [{ type: 'text', text: 'Hello!' }] })

      // 例如，你可以更改应用的加载状态
      isLoading = false

      // 如果要执行扩展的默认插入行为，请确保调用 setEditorContent 函数
      // setEditorContent()
      // 但由于我们修改了内容，因此需要手动插入
      editor.commands.setContent(content)
    },
  })
  .focus()
  .run()
```

### 导入选项

| 名称                     | 类型       | 默认值      | 说明                                                                                                                                                                                     |
| ------------------------ | ---------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `appId`                  | `string`   | `undefined` | Convert 设置页面中的 Convert App ID：[https://cloud.tiptap.dev/convert-settings](https://cloud.tiptap.dev/convert-settings)                                                       |
| `token`                  | `string`   | `undefined` | 使用密钥从服务器生成的 JWT                                                                                                                                                   |
| `imageUploadCallbackUrl` | `string`   | `undefined` | 用于上传图片的 URL；如果未提供，文档中的图片将被移除                                                                                                         |
| `experimentalDocxImport` | `boolean ` | `false`     | 启用实验性的 DOCX 导入，以便更好地保留内容样式（此功能处于实验阶段，在 alpha 阶段 API 可能不完全稳定），仅适用于上传的 DOCX 文件 |

### 命令

| 名称     | 说明                   |
| -------- | ----------------------------- |
| `import` | 将文件导入编辑器 |

#### `import`

##### 参数

| 名称       | 类型       | 默认值      | 选项          | 说明                                                                                                                                                                   |
| ---------- | ---------- | ----------- | ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `file`     | `File`     | `undefined` | 任意文件      | 要导入的文件                                                                                                                                                            |
| `format`   | `string`   | `undefined` | `gfm`         | 当格式不明确时用于特殊情况，例如 Markdown GFM                                                                                             |
| `onImport` | `Function` | `undefined` | `fn(context)` | 用于自定义导入行为的回调。context 参数包含内容和错误的相关信息，以及用于修改内容的 `setEditorContent` 函数 |

### 支持的格式

- `docx` - Microsoft Word、Google Docs、OpenOffice、LibreOffice 等
- `odt` - OpenOffice、LibreOffice 等使用的 OpenDocument 文本文档格式
- `rtf` - Microsoft Word、Google Docs 等使用的富文本格式
- Commonmark `markdown` - 各种编辑器和平台使用的 Markdown 格式
- GFM `markdown` - GitHub 使用的 GitHub 风格 Markdown

### 注意事项和限制

- **图片上传** - 假定图片以内联方式包含在文档中，因此编辑器应配置为 `Image.configure({ inline: true })`，以便正确显示图片；否则，图片将从文档中移除
- **导入时不支持的 DOCX 元素** - 当前导入 DOCX 文件时不支持分页符、页眉和页脚、水平线或文本样式
- **通过建议模式添加的内容** - 通过建议模式添加的内容不会包含在导入的 ProseMirror 文档中
- **PDF 导入与导出** - 目前尚不支持导入和导出 PDF 文件
- **内联样式** - 当前不会解析内联样式，导入和导出时也无法使用

## 导出旧版扩展

<Callout title="旧版导出扩展（已弃用）" variant="warning">
  **extension-export** 软件包已弃用，不再添加新功能；在移除旧版端点前，我们会提前 90 天通知。我们强烈建议迁移到更新的[导出扩展](/conversion/getting-started/overview)，它提供了更灵活的自定义功能和持续支持。
</Callout>

```js
// 首先导入扩展
import { Export } from '@tiptap-pro/extension-export'

const editor = new Editor({
  // ...
  extensions: [
    // ...
    Export.configure({
      // 在 Convert 设置页面中获取 Convert App-ID：https://cloud.tiptap.dev/convert-settings
      appId: 'your-app-id',

      // 上一步生成的 JWT
      token: 'your-jwt',
    }),
  ],
})
```

### 导出文档

```js
// 简单地导出为 docx
// 支持的格式：docx、odt、md 和 gfm
editor.chain().focus().export({ format: 'docx' }).run()
```

### 自定义导出行为

```js
// 你也可以使用 onExport 回调来自定义导出行为
editor.chain().export({
  format: 'docx',
  onExport(context) {
    const { blob, error, download, filename } = context

    // 添加错误处理
    if (error) {
      showErrorToast({ message: error.message })
    }

    // 例如，你可以更改应用的加载状态
    isLoading = false

    // 你可以在这里修改文件名或以其他方式处理 blob
    // 但我们会保留它们不变

    // 调用 download 方法即可直接触发下载
    download()

    // 请注意，download 方法仅在浏览器中有效
    // 如果之前修改过 blob 或文件名，则必须手动处理
  },
})
```

| `token` | `string` | `undefined` | 使用密钥从服务器生成的 JWT                                                                                             |

### 支持的格式

### 注意事项和限制

- **PDF 导入与导出** - 目前尚不支持导出 PDF 文件
- **内联样式** - 请参阅新版 [Conversion](/conversion/getting-started/overview) 扩展和端点，了解如何集成内联样式。

### /import 端点

`/import` 端点可将 `docx`、`odt` 或 `markdown` 文件转换为 Tiptap JSON 格式。用户可以通过 POST 请求将文档发送到此端点，并使用各种参数自定义转换过程中对不同文档元素的处理方式。

- **方法**：`POST`

#### 必需的请求头

| 名称            | 说明                                                                                                                                     |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `Authorization` | 用于对请求进行身份验证的 JWT。示例：`Bearer your-jwt`                                                                                 |
| `X-App-Id`      | 在 Collaboration 设置页面中获取的 Convert App-ID：[https://cloud.tiptap.dev/convert-settings](https://cloud.tiptap.dev/convert-settings) |

#### 请求体

| 名称                     | 类型     | 说明                                                                               |
| ------------------------ | -------- | ----------------------------------------------------------------------------------------- |
| `file`                   | `File`   | 要转换的文件                                                                       |
| `imageUploadCallbackUrl` | `string` | 回调端点，用于上传在所上传文档中发现的图片 |

#### 查询参数

指定源文档元素如何映射到 ProseMirror 节点或标记，并调整转换方式，以符合特定的样式和结构偏好。

| 名称             | 默认值          | 说明                                                          |
| ---------------- | ---------------- | -------------------------------------------------------------------- |
| `paragraph`      | `paragraph`      | 指定段落转换使用的 ProseMirror 类型      |
| `heading`        | `heading`        | 指定标题转换使用的 ProseMirror 类型        |
| `blockquote`     | `blockquote`     | 指定引用块转换使用的 ProseMirror 类型     |
| `codeblock`      | `codeblock`      | 指定代码块转换使用的 ProseMirror 类型      |
| `bulletlist`     | `bulletlist`     | 指定项目符号列表转换使用的 ProseMirror 类型     |
| `orderedlist`    | `orderedlist`    | 指定有序列表转换使用的 ProseMirror 类型    |
| `listitem`       | `listitem`       | 指定列表项转换使用的 ProseMirror 类型       |
