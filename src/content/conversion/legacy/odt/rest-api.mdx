## 导入 API 端点
`POST /import`

`/import` 端点可将 `ODT` 文件转换为 Tiptap JSON 格式。用户可以向此端点 POST 文档。

### 示例（cURL）
 ```bash
 curl -X POST "https://api.tiptap.dev/v1/convert/import" \
   -H "Authorization: Bearer <your-jwt>" \
   -H "X-App-Id: <your-app-id>" \
   -F "file=@/path/to/document.odt"
 ```
在此示例中，请求会上传一个 ODT 文件。

### 必需的请求头

| 名称            | 描述                                                                                                                                     |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `Authorization` | 用于验证请求的 JWT。示例：`Bearer your-jwt`                                                                                 |
| `X-App-Id`      | 来自 Collaboration 设置页面的 Convert App-ID：[https://cloud.tiptap.dev/convert-settings](https://cloud.tiptap.dev/convert-settings) |

### 请求体

| 名称                     | 类型     | 描述                                                                                                                  |
| ------------------------ | -------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `file`                   | `File`   | 要转换的文件                                                                                                          |
| `imageUploadCallbackUrl` | `string` | 用于上传所上传文档中图片的回调端点 |

## 导出 API 端点
`POST /export`

`/export` 端点可将 Tiptap 文档转换回 `odt` 格式。

### 必需的请求头

| 名称            | 描述                                                                                                                                     |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `Authorization` | 用于验证请求的 JWT。示例：`Bearer your-jwt`                                                                                 |
| `X-App-Id`      | 来自 Collaboration 设置页面的 Convert App-ID：[https://cloud.tiptap.dev/convert-settings](https://cloud.tiptap.dev/convert-settings) |

### 请求体

| 名称              | 类型     | 描述                               |
|-------------------|----------|-------------------------------------------|
| `prosemirrorJson` | `Object` | Tiptap/ProseMirror JSON                   |
| `to`              | `string` | 要转换成的格式，应为 `odt` |
