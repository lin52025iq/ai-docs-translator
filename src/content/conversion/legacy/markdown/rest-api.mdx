## 导入 API 端点
`POST /import`

将 .md 文件（或 gfm 文件）转换为 Tiptap JSON。

```bash
curl -X POST "https://api.tiptap.dev/v1/convert/import?format=md" \
  -H "Authorization: Bearer <your-jwt>" \
  -H "X-App-Id: <your-app-id>" \
  -F "file=@/path/to/file.md"
```

### 导入 API 请求头
| Header          | Description                                                                                                |
|-----------------|------------------------------------------------------------------------------------------------------------|
| `Authorization` | `Bearer <your-jwt>`                                                                                        |
| `X-App-Id`      | Convert 应用 ID，获取地址：[https://cloud.tiptap.dev/convert-settings](https://cloud.tiptap.dev/convert-settings) |

### 导入 API 字段
| Field                    | Description                                                                        |
|--------------------------|------------------------------------------------------------------------------------|
| `file`                   | 要转换的 Markdown 文件                                                             |
| `imageUploadCallbackUrl` | 可选端点；如果 Markdown 文件引用了本地图片，可用于处理这些图片                      |

## 导出 API 端点
`POST /export`

将 Tiptap JSON 转换为 .md 或 .gfm。

```bash
curl -X POST "https://api.tiptap.dev/v1/convert/export" \
  -H "Authorization: Bearer <your-jwt>" \
  -H "X-App-Id: <your-app-id>" \
  -F 'prosemirrorJson={"type":"doc","content":[{"type":"paragraph","content":[{"type":"text","text":"Hello from Tiptap!"}]}]}' \
  -F 'to=md' \
  --output document.md
```

#### 导出 API 请求头
| Header          | Description                                                                                                |
|-----------------|------------------------------------------------------------------------------------------------------------|
| `Authorization` | `Bearer <your-jwt>`                                                                                        |
| `X-App-Id`      | Convert 应用 ID，获取地址：[https://cloud.tiptap.dev/convert-settings](https://cloud.tiptap.dev/convert-settings) |

#### 导出 API 字段
| Field             | Description                                               |
|-------------------|-----------------------------------------------------------|
| `prosemirrorJson` | Tiptap/ProseMirror JSON                                   |
| `to`              | 目标格式；`md` 或 `gfm`（GitHub 风格 Markdown）           |
