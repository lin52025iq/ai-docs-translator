导出为 `DOCX` 时，你可以定义应用于导出文档的自定义样式。如果你希望文档整体外观保持一致，这会很有用。

## 原生 DOCX 选项

导出的 `Docx` 命名空间和原始元素覆盖项使用原生 `docx` 9.12 选项。

### RTL 对齐

在原始段落选项中同时设置 `bidirectional: true` 和 `alignment`。对于需要显示在物理左侧的文本，请使用 `LEFT`；原生 docx 会处理左右方向的映射：

```ts
import { Docx, ExportDocx } from '@tiptap-pro/extension-export-docx'

ExportDocx.configure({
  paragraphOverrides: {
    bidirectional: true,
    alignment: Docx.AlignmentType.LEFT,
  },
})
```

这对静态覆盖项和回调函数都适用。段落节点中显式设置的 `textAlign` 优先于覆盖项。

### 表格宽度和默认样式

使用 `Docx.WidthType.PERCENTAGE` 时，数值 `size: 50` 表示 50%。若要保留更高精度，请使用百分比字符串，例如 `size: '33.33%'`；原生数值百分比会按 0.02% 的增量进行舍入。

原生文档包含 `Normal` 和 `TableNormal` 样式，并会推断未指定的网格宽度和单元格宽度。导出器还会提供段落和列表样式，你可以通过 `styleOverrides` 对其进行自定义。

## 使用函数设置各节点的覆盖项

除静态对象外，每种元素覆盖项——`paragraphOverrides`、`textRunOverrides`、`tableOverrides`、`tableRowOverrides`、`tableCellOverrides` 和 `imageOverrides`——也都接受函数。该函数会接收当前正在转换的节点，并返回该节点的覆盖项，因此你可以根据节点属性为不同节点设置不同的覆盖项。对象形式仍可照常使用；此功能可直接用于现有代码，无需其他更改。

```ts
ExportDocx.configure({
  onCompleteExport: (result) => {
    /* ... */
  },
  // `node` is the image node currently being converted, including its `attrs`.
  imageOverrides: (node) => ({
    // Carry the editor's alt text into Word's accessibility metadata.
    altText: { name: node.attrs?.alt, description: node.attrs?.alt },
    // Derive the rendered size from the dimensions set on the node.
    transformation: {
      width: Number(node.attrs?.width),
      height: Number(node.attrs?.height),
    },
  }),
  // The function receives the matching node for every override type.
  paragraphOverrides: (node) => ({
    keepNext: node.attrs?.keepWithNext === true,
  }),
})
```

函数返回的值与静态对象的应用方式完全相同，并遵循该覆盖项对象形式的相同优先级。返回空对象时，该节点的所有默认设置都会保留。

<Callout title="函数形式仅适用于 DOCX">
  DOCX 导出支持以函数形式设置元素覆盖项。其他导出格式仅接受静态对象形式。
</Callout>
