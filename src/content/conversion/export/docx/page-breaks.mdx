[PageBreak 扩展](/pages/core-concepts/page-break-node)允许用户在编辑器中插入明确的分页符。与 DOCX 导出扩展搭配使用时，这些分页符也会包含在导出的文档中。

## 工作原理

- 编辑器中的 `pageBreak` 节点会转换为 DOCX 输出中的 `<w:br w:type="page"/>`
- 这会生成标准的 Word 分页符，并从新页面开始
- 无需额外配置；只要注册了 PageBreak 扩展，导出就会自动生效

## 将 PageBreak 与 DOCX 导出搭配使用

除了 DOCX 导出扩展，还要注册 PageBreak 扩展。导出时，编辑器内容中的分页符会自动转换。

```ts
import { Editor } from '@tiptap/core'
import { ConvertKit } from '@tiptap-pro/extension-convert-kit'
import { ExportDocx } from '@tiptap-pro/extension-export-docx'
import { PageBreak } from '@tiptap-pro/extension-pagebreak'

const editor = new Editor({
  extensions: [
    ConvertKit,
    PageBreak,
    ExportDocx.configure({
      onCompleteExport: (result) => {
        const blob = new Blob([result], {
          type: 'application/vnd.openxmlformats-officedocument.wordprocessingml.document',
        })
        const url = URL.createObjectURL(blob)
        const a = document.createElement('a')
        a.href = url
        a.download = 'export.docx'
        a.click()
        URL.revokeObjectURL(url)
      },
    }),
  ],
})
```

## 单独使用

如果要构建自定义导出流程或在服务器端使用，可以直接使用 `convertPageBreak` 函数：

```js
import { convertPageBreak } from '@tiptap-pro/extension-export-docx'
```

此函数会将 `pageBreak` 节点转换为包含分页符元素的相应 DOCX 段落，可用于构建自定义节点转换流程。
