## 导出 Markdown

`POST /v2/convert/export/markdown`

`/v2/convert/export/markdown` 端点可将 Tiptap JSON 文档转换为 Markdown 格式。发送 `POST` 请求，并在 JSON 请求体中提供文档，即可接收可下载的 Markdown 文件。

### 示例（cURL）

```bash
curl --output document.md -X POST "https://api.tiptap.dev/v2/convert/export/markdown" \
    -H "Authorization: Bearer YOUR_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{
      "doc": "{\"type\":\"doc\",\"content\":[{\"type\":\"paragraph\",\"content\":[{\"type\":\"text\",\"text\":\"Hello from Tiptap!\"}]}]}"
    }'
```

<Callout title="需要订阅" variant="warning">
    此端点需要有效的 Tiptap 订阅。详情请查看我们的[定价页面](https://tiptap.dev/pricing)。
</Callout>

### 必需的请求头

| 名称            | 描述                                                                                                                               |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `Authorization` | 用于验证请求的 JWT 令牌。示例：`Bearer your-jwt-token`                                                               |
| `Content-Type`  | 必须为 `application/json`                                                                                                                |

### 请求体

| 名称  | 类型     | 描述                        | 必填 |
| ----- | -------- | ---------------------------------- | -------- |
| `doc` | `String` | 以字符串形式提供的 Tiptap JSON 文档   | 是      |

### 响应

成功时，API 会以文本下载的形式返回 Markdown 文件：

- **状态**：`200 OK`
- **Content-Type**：`text/markdown; charset=utf-8`
- **Content-Disposition**：`attachment; filename=export-{timestamp}.md`

### 错误响应

| 状态 | 代码                              | 描述                          |
| ------ | --------------------------------- | ------------------------------------ |
| 400    | `NO_DOCUMENT_PROVIDED`            | 请求体中未提供文档 |
| 422    | `FAILED_TO_PARSE_JSON_INPUT`     | 无法解析 JSON 输入          |
| 422    | `FAILED_TO_PARSE_MARKDOWN_FILE`  | Markdown 导出失败            |

## 支持范围与限制

REST API 使用与编辑器扩展相同的 Markdown 转换功能，因此支持的功能也完全相同。Markdown 导出会将 Tiptap 内容转换为兼容 CommonMark 的 Markdown。与 DOCX 不同，Markdown 不支持丰富的样式、页面布局或复杂的表格格式。

| **功能** | **支持情况** |
|---|---|
| **文本内容** | ✓ 段落、标题（1–6 级）、硬换行 |
| **行内格式** | ✓ 粗体、斜体、删除线、行内代码 |
| **块级元素** | ✓ 引用块、代码块（带语言标记的围栏形式）、水平分隔线 |
| **列表** | ✓ 项目符号列表、有序列表、任务列表、嵌套列表 |
| **表格** | ✓ 基础管道符语法表格（单个标题行，不支持合并单元格） |
| **链接** | ✓ 带文本和 URL 的超链接 |
| **图片** | ✓ 带替代文本的图片引用（不含尺寸） |
| **下划线** | ✓ 自定义语法（`++text++`，非标准） |
| **高亮** | ✓ 自定义语法（`==text==`，非标准） |
| **文本颜色 / 字体** | ✗ Markdown 没有设置颜色、字体系列或字号的语法 |
| **文本对齐** | ✗ Markdown 没有相应语法 |
| **间距 / 缩进** | ✗ Markdown 没有相应语法 |
| **合并单元格** | ✗ Markdown 表格不支持 colspan 或 rowspan |
| **页眉和页脚** | ✗ Markdown 中没有页眉和页脚的概念 |
| **页面布局** | ✗ 不支持分页符、分节或页面大小 |
| **数学公式** | ~ 取决于扩展（配置数学扩展后可使用 `$...$` 语法） |
| **脚注和尾注** | ✗ CommonMark 不支持 |

如需查看完整的 DOCX 功能对比，请参阅[支持的功能](/conversion/getting-started/feature-support-matrix)矩阵。
