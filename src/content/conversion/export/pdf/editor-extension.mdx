使用 Tiptap 的 `@tiptap-pro/extension-export-pdf` 将编辑器内容导出为 `.pdf` 文件。此扩展会将文档发送到 Tiptap 转换服务进行转换，从而在编辑器中集成 PDF 导出功能。

如果希望自行处理转换，也可以改用 [REST API](/conversion/export/pdf/rest-api)。

## 安装 PDF 导出扩展

Conversion 扩展发布在 Tiptap 的私有 npm 注册表中。请按照[私有注册表指南](/guides/pro-extensions)集成这些扩展。

完成后即可安装并导入 **Export PDF** 扩展包。

```bash
npm i @tiptap-pro/extension-export-pdf
```

```js
import { ExportPdf } from '@tiptap-pro/extension-export-pdf'
```

## 配置扩展

`ExportPdf` 扩展可通过 `configure` 方法接收 `ExportPdfOptions`（`object`）参数进行配置，其中包含以下属性：

```ts
import { ExportPdf } from '@tiptap-pro/extension-export-pdf'

const editor = new Editor({
  extensions: [
    // Other extensions ...
    ExportPdf.configure({
      region: 'eu', // 'eu' or 'us'
      token: 'YOUR_TOKEN',
      styleOverrides: {},
      headers: {},
      footers: {},
      pageSize: { width: '21cm', height: '29.7cm' },
      pageMargins: { top: '1cm', bottom: '1cm', left: '1cm', right: '1cm' },
      customNodes: [],
      onCompleteExport: (result) => {
        // Handle the exported Blob
      },
    }),
    // Other extensions ...
  ],
})
```

| 参数                 | 类型                     | 说明                                                                                                                                                                         | 默认值                         |
| -------------------- | ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------ |
| `endpoint`           | `string`                 | 用于转换的 Tiptap API 端点。设置后将覆盖 `region`                                                                                                                              | `undefined`                    |
| `region`             | `'eu' \| 'us'`           | 未设置 `endpoint` 时使用的 Tiptap Cloud 区域                                                                                                                                  | `'eu'`                         |
| `token`              | `string`                 | 用于身份验证的 Tiptap JWT，参见[身份验证](/authentication)                                                                                                                     | `''`                           |
| `styleOverrides`     | `Record<string, string>` | 应用于导出的样式覆盖项                                                                                                                                                       | `undefined`                    |
| `headers`            | `HeaderConfig`           | 导出文档的页眉配置                                                                                                                                                            | `undefined`                    |
| `footers`            | `FooterConfig`           | 导出文档的页脚配置                                                                                                                                                            | `undefined`                    |
| `pageSize`           | `PageSize`               | 页面尺寸配置                                                                                                                                                                 | `undefined`                    |
| `pageMargins`        | `PageMargins`            | 页边距配置                                                                                                                                                                   | `undefined`                    |
| `customNodes`        | `CustomNodeDefinition[]` | 基于 DOCX 转换的自定义节点定义（需要安装 `@tiptap-pro/extension-export-docx`）                                                                                                 | `undefined`                    |
| `customFonts`        | `CustomFont[]`           | 为 PDF 导出提供的自定义字体文件（仅限本地部署）                                                                                                                               | `undefined`                    |
| `onCompleteExport`   | `(result: Blob) => void` | 接收导出文件 Blob 的回调                                                                                                                                                     | 未提供时抛出错误               |
| `onExportError`      | `(error: Error) => void` | 可选回调，在导出流程失败时调用（动态导入失败、DOCX 转换失败、网络错误、响应状态非 OK）。省略时，错误会通过 `console.error` 记录。                                               | `undefined`                    |

### 页眉和页脚插槽值

每个页眉和页脚插槽（`default`、`first`、`even`）都接受五种形式中的任意一种；请根据数据选择合适的形式。前面三种仅需使用 `@tiptap-pro/extension-export-pdf`；后面两种还需要安装 `@tiptap-pro/extension-export-docx`（它们采用 DOCX 优先的导出路径，并按需延迟加载，因此不会影响仅使用 PDF 的用户）。

| 形式                                         | 示例                                       | 说明                                                                                     |
| -------------------------------------------- | ------------------------------------------ | ---------------------------------------------------------------------------------------- |
| 纯文本                                       | `'Company name, 2026'`                     | 不带样式的页眉/页脚。                                                                     |
| 序列化为字符串的 Tiptap JSONContent          | `JSON.stringify(myHeaderDoc)`              | 预先序列化的 Tiptap 节点。保留富文本格式。                                                 |
| Tiptap JSONContent 对象                      | `{ type: 'doc', content: [/* … */] }`      | 直接传入的富文本 Tiptap 节点。无需序列化为字符串。                                        |
| `docx` 的 `Header` / `Footer` 实例           | `new Docx.Header({ children: [/* … */] })` | 可完全控制 DOCX 级别的内容。需要 DOCX 扩展。                                              |
| 返回 `Header` / `Footer` 的异步工厂函数      | `() => convertHeader({ node })`            | 导出时按需创建。典型用法：`convertHeader` / `convertFooter`。需要 DOCX 扩展。              |

Tiptap JSONContent 对象**必须**包含 `type` 字段。扩展会在运行时通过此字段判断对象是 Tiptap 节点还是 `docx` 实例。没有 `type` 字段、且不是 `Header` / `Footer` 实例的对象会被丢弃，并通过 `console.warn` 指出有问题的值，而不会转发给 DOCX 序列化器。

在 TypeScript 中，这些形式归并为两个类型别名（`type` 要求已在 `TiptapNodeContent` 中声明）：

```ts
import type { JSONContent } from '@tiptap/core'
import type { Footer, Header } from 'docx'

type TiptapNodeContent = JSONContent & { type: string }

type HeaderSlotValue = string | TiptapNodeContent | Header | (() => Promise<Header>)
type FooterSlotValue = string | TiptapNodeContent | Footer | (() => Promise<Footer>)
```

### HeaderConfig

| 属性                  | 类型              | 说明                                                                                  |
| --------------------- | ----------------- | ------------------------------------------------------------------------------------- |
| `evenAndOddHeaders`   | `boolean`         | 是否为奇数页和偶数页使用不同的页眉。                                                  |
| `differentFirstPage`  | `boolean`         | 是否为首页使用不同的页眉。设为 `true` 时，首页使用 `first` 值，而不是 `default`。       |
| `default`             | `HeaderSlotValue` | 每页使用的默认页眉；启用 `evenAndOddHeaders` 时，则作为奇数页的页眉。                   |
| `first`               | `HeaderSlotValue` | 首页页眉。仅当 `differentFirstPage` 为 `true` 时使用。                                 |
| `even`                | `HeaderSlotValue` | 偶数页页眉。仅当 `evenAndOddHeaders` 为 `true` 时使用。                                |

| `differentFirstPage`  | `boolean`         | 是否为首页使用不同的页脚。设为 `true` 时，首页使用 `first` 值，而不是 `default`。       |

## 导出 PDF 文件

安装扩展后，可以使用 `exportPdf` 命令将编辑器内容导出为 `.pdf`。

```ts
/**
 * Export the current document as a PDF file via the Tiptap convert service.
 *
 * @param options - All extension-level options can be overridden per-invocation
 * @example editor.commands.exportPdf({ onCompleteExport: (result) => {} })
 */
exportPdf: (options?: ExportPdfCommandOptions) => ReturnType
```

`ExportPdfCommandOptions` 接口扩展了 `ExportPdfOptions`，因此可以在每次调用命令时覆盖所有配置选项：

| 属性                 | 类型                     | 说明                                    |
| -------------------- | ------------------------ | --------------------------------------- |
| `endpoint`           | `string`                 | 为本次导出覆盖 API 端点                 |
| `region`             | `'eu' \| 'us'`           | 为本次导出覆盖区域                      |
| `token`              | `string`                 | 为本次导出覆盖 JWT 令牌                 |
| `styleOverrides`     | `Record<string, string>` | 为本次导出覆盖样式                      |
| `headers`            | `HeaderConfig`           | 为本次导出覆盖页眉配置                  |
| `footers`            | `FooterConfig`           | 为本次导出覆盖页脚配置                  |
| `pageSize`           | `PageSize`               | 为本次导出覆盖页面尺寸                  |
| `pageMargins`        | `PageMargins`            | 为本次导出覆盖页边距                    |
| `customNodes`        | `CustomNodeDefinition[]` | 为本次导出覆盖自定义节点定义            |
| `customFonts`        | `CustomFont[]`           | 为本次导出覆盖自定义字体（仅限本地部署） |
| `onCompleteExport`   | `(result: Blob) => void` | 为本次导出覆盖回调                      |
| `onExportError`      | `(error: Error) => void` | 为本次导出覆盖错误处理程序              |

```js
import { ExportPdf } from '@tiptap-pro/extension-export-pdf'

const editor = new Editor({
  extensions: [
    // Other extensions ...
    ExportPdf.configure({
      token: 'YOUR_TOKEN',
      onCompleteExport(result) {
        // Download the PDF file
        const url = URL.createObjectURL(result)
        const a = document.createElement('a')

        a.href = url
        a.download = 'document.pdf'
        a.click()

        URL.revokeObjectURL(url)
      },
    }),
    // Other extensions ...
  ],
})

// Use the extension-level callback
editor.chain().exportPdf().run()

// Or override options for a specific export
editor
  .chain()
  .exportPdf({
    pageSize: { width: '8.5in', height: '11in' },
    onCompleteExport(result) {
      // Custom handling for this specific export
      const url = URL.createObjectURL(result)
      window.open(url)
    },
  })
  .run()
```

### 工作原理

调用 `exportPdf` 时，扩展会将编辑器文档序列化为 JSON，并连同已配置的选项（样式覆盖、页面布局、页眉、页脚、自定义字体）一起发送到 Tiptap 转换服务。该服务会将文档转换为 PDF，并以二进制 Blob 的形式返回。`onCompleteExport` 回调会直接接收此 Blob，您可以按需下载或处理。发生错误时会抛出异常，而不会通过回调传递。

## 自定义字体

<Callout title="仅限本地部署" variant="warning">
  自定义字体仅适用于本地部署。如果您希望在 Tiptap 云服务中使用自定义字体，请[联系我们了解 Enterprise
  计划](https://tiptap.dev/pricing)。
</Callout>

PDF 导出支持在本地部署中使用自定义字体。您可以提供字体 URL 数组来配置自定义字体；转换服务会下载这些字体，并在生成 PDF 时使用。

字体文件必须为 `.ttf` 或 `.woff2` 格式，并可通过 HTTPS 访问。`fontFamily` 必须与文档文本样式中使用的字体系列名称一致。

```ts
ExportPdf.configure({
  token: 'YOUR_TOKEN',
  customFonts: [
    {
      url: 'https://your-cdn.com/fonts/CustomFont-Regular.ttf',
      fontFamily: 'Custom Font',
    },
    {
      url: 'https://your-cdn.com/fonts/CustomFont-Bold.ttf',
      fontFamily: 'Custom Font',
    },
  ],
  onCompleteExport(result) {
    // Handle the exported PDF
  },
})
```

您也可以在每次调用命令时覆盖自定义字体：

```ts
editor
  .chain()
  .exportPdf({
    customFonts: [
      {
        url: 'https://your-cdn.com/fonts/SpecialFont.woff2',
        fontFamily: 'Special Font',
      },
    ],
  })
  .run()
```

## 预期行为

- **需要身份验证。** 导出会将文档发送到 Convert 服务，该服务要求提供带有 `aud: "Convert"` 的签名令牌（`token`）。请在服务器上签署令牌，切勿在浏览器中暴露签名密钥。请参阅[身份验证](/authentication)。
- **可能需要处理的 HTTP 响应：** `401`（缺少或无效的 JWT）、`403`（此操作不允许用于您的应用，通常是因为计划不包含所需格式，或在云计划中使用了 `customFonts`）、`5xx`（暂时性服务器错误；请采用退避策略重试）。
- **自定义字体是 Enterprise / 本地部署功能。** 在云计划中，包含 `customFonts` 的请求会返回 `403`。如需启用，请联系我们了解 [Enterprise 计划](https://tiptap.dev/pricing)，或运行本地部署。
- **每个请求都会在响应前完成整个处理流程。** 处理非常大的文档可能需要更长时间；请据此设置请求超时时间。

## 不支持的预期

- **无法确保 DOCX → PDF 往返转换后完全一致。** PDF 是固定版式格式；Word 和 Convert 服务使用不同的排版引擎，因此视觉效果可能与 Word 打印出的 PDF 存在细微差异。
- **复杂布局无法保证与 Word 像素级一致**，尤其是多栏分节、RTL 文本，或依赖 Word 特有排版行为的内容。
- **无法编辑生成的 PDF。** PDF 导出是单向的。如需保留可编辑性，也请导出为 DOCX。
