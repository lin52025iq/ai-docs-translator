`@tiptap-pro/extension-export-pdf` 扩展内置了自定义导出文档页眉和页脚的支持。你可以为首页、奇数页和偶数页分别配置不同的页眉和页脚。

## 页眉和页脚插槽值

每个页眉和页脚插槽（`default`、`first`、`even`）都接受以下任一种格式。你可以在不同插槽中自由组合，选择最适合你数据的格式。

| 格式                             | 示例                                             | 说明                                                                                                     |
| -------------------------------- | ------------------------------------------------ | --------------------------------------------------------------------------------------------------------- |
| 纯文本                           | `'Company name, 2026'`                           | 以无样式的页眉或页脚形式呈现。                                                                            |
| 字符串化的 Tiptap JSONContent    | `JSON.stringify(myHeaderDoc)`                    | 预先序列化的 Tiptap 节点。呈现时会保留粗体、斜体、链接等富文本格式。                                       |
| Tiptap JSONContent 对象          | `{ type: 'doc', content: [/* … */] }`            | 直接传入的 Tiptap 节点。效果与字符串化的 JSONContent 相同，但无需调用 `JSON.stringify`。                  |
| `docx` `Header` / `Footer`       | `new Docx.Header({ children: [/* … */] })`       | 对 DOCX 级别的段落和文本运行进行完全控制。需要安装 `@tiptap-pro/extension-export-docx`。                  |
| 返回 `Header` / `Footer` 的异步工厂 | `() => convertHeader({ node })`       | 在执行导出时按需创建。常见用法是使用 DOCX 扩展中的 `convertHeader` / `convertFooter`。                    |

Tiptap JSONContent 对象**必须**包含 `type` 字段。扩展会在运行时使用该字段，区分 Tiptap 节点和 `docx` 实例。没有 `type` 字段且不是 `Header` / `Footer` 实例的对象会被丢弃，并通过 `console.warn` 指明有问题的值；这些对象不会传递给 DOCX 序列化器。

在 TypeScript 中，这些格式可归为两个类型别名（`type` 要求已编码在 `TiptapNodeContent` 中）：

```ts
import type { JSONContent } from '@tiptap/core'
import type { Footer, Header } from 'docx'

type TiptapNodeContent = JSONContent & { type: string }

type HeaderSlotValue = string | TiptapNodeContent | Header | (() => Promise<Header>)
type FooterSlotValue = string | TiptapNodeContent | Footer | (() => Promise<Footer>)
```

前三种格式可单独与 `@tiptap-pro/extension-export-pdf` 配合使用。`Header` / `Footer` 实例和异步工厂格式需要安装 `@tiptap-pro/extension-export-docx`；它们会采用 DOCX 优先的导出路径，该路径按需加载，因此不会影响仅使用 PDF 的用户。

## 页眉配置

`headers` 对象用于配置页眉。每个插槽都接受一个[页眉插槽值](#页眉和页脚插槽值)。

| 属性                 | 类型              | 说明                                                                                                    |
| -------------------- | ----------------- | ---------------------------------------------------------------------------------------------------- |
| `evenAndOddHeaders`  | `boolean`         | 是否为奇数页和偶数页使用不同的页眉。                                                                     |
| `differentFirstPage` | `boolean`         | 是否为首页使用不同的页眉。设为 `true` 时，第一页使用 `first` 值，而不是 `default`。                     |
| `default`            | `HeaderSlotValue` | 每页使用的默认页眉；或者在启用 `evenAndOddHeaders` 时，用作奇数页页眉。                                  |
| `first`              | `HeaderSlotValue` | 首页的页眉。仅当 `differentFirstPage` 为 `true` 时使用。                                                 |
| `even`               | `HeaderSlotValue` | 偶数页的页眉。仅当 `evenAndOddHeaders` 为 `true` 时使用。                                                |

## 页脚配置

`footers` 对象与 `headers` 类似。每个插槽都接受一个[页脚插槽值](#页眉和页脚插槽值)。

| 属性                 | 类型              | 说明                                                                                                    |
| -------------------- | ----------------- | ---------------------------------------------------------------------------------------------------- |
| `evenAndOddFooters`  | `boolean`         | 是否为奇数页和偶数页使用不同的页脚。                                                                     |
| `differentFirstPage` | `boolean`         | 是否为首页使用不同的页脚。设为 `true` 时，第一页使用 `first` 值，而不是 `default`。                     |
| `default`            | `FooterSlotValue` | 每页使用的默认页脚；或者在启用 `evenAndOddFooters` 时，用作奇数页页脚。                                  |
| `first`              | `FooterSlotValue` | 首页的页脚。仅当 `differentFirstPage` 为 `true` 时使用。                                                 |
| `even`               | `FooterSlotValue` | 偶数页的页脚。仅当 `evenAndOddFooters` 为 `true` 时使用。                                                |

## 完整示例

```js
import { ExportPdf } from '@tiptap-pro/extension-export-pdf'

const editor = new Editor({
  extensions: [
    // Other extensions...
    ExportPdf.configure({
      token: 'YOUR_TOKEN',
      headers: {
        evenAndOddHeaders: true,
        default: 'My Document - Confidential',
        first: 'Welcome to My Document',
        even: 'My Document - Even Page',
      },
      footers: {
        evenAndOddFooters: true,
        default: 'Company Name - All Rights Reserved',
        first: 'Draft Version 1.0',
        even: 'Company Name - Even Page Footer',
      },
    }),
    // Other extensions...
  ],
})

// Export with headers and footers
editor
  .chain()
  .exportPdf({
    onCompleteExport(result) {
      const url = URL.createObjectURL(result)
      const a = document.createElement('a')

      a.href = url
      a.download = 'document-with-headers.pdf'
      a.click()

      URL.revokeObjectURL(url)
    },
  })
  .run()
```

## 简单页眉和页脚

如果不需要为奇数页和偶数页设置不同的页眉，可以只提供 `default` 值：

```js
ExportPdf.configure({
  token: 'YOUR_TOKEN',
  headers: {
    default: 'My Document Title',
  },
  footers: {
    default: 'Page Footer - Company Name',
  },
})
```

## 通过 Tiptap JSONContent 设置富文本页眉

可以在任意插槽中直接传入 Tiptap JSONContent 节点。如果节点已在内存中，且你不想手动创建 `Docx.Header`，这种方式就很实用：

```js
ExportPdf.configure({
  token: 'YOUR_TOKEN',
  headers: {
    default: {
      type: 'doc',
      content: [
        {
          type: 'paragraph',
          content: [
            { type: 'text', marks: [{ type: 'bold' }], text: 'My Document' },
            { type: 'text', text: ' · Confidential' },
          ],
        },
      ],
    },
  },
})
```

## Docx Header / Footer 实例

如需完全控制段落属性、对齐方式和文本运行样式，可以传入 `docx` 的 `Header` / `Footer` 实例（或返回此类实例的异步工厂）。这要求在 PDF 扩展之外安装 `@tiptap-pro/extension-export-docx`：

```ts
import { Docx, convertHeader } from '@tiptap-pro/extension-export-docx'

ExportPdf.configure({
  token: 'YOUR_TOKEN',
  headers: {
    // Direct Docx.Header instance
    default: new Docx.Header({
      children: [
        new Docx.Paragraph({
          children: [new Docx.TextRun({ text: 'My Document' })],
        }),
      ],
    }),
    // Async factory: convert a Tiptap node to a Docx.Header on demand
    first: () =>
      convertHeader({
        node: {
          type: 'doc',
          content: [
            { type: 'paragraph', content: [{ type: 'text', text: 'Welcome' }] },
          ],
        },
      }),
  },
})
```
