## 导出 PDF

`POST /v2/convert/export/pdf`

`/v2/convert/export/pdf` 端点可将 Tiptap JSON 文档转换为 PDF 格式。发送 `POST` 请求，并在 JSON 请求体中提供文档，即可获得可下载的 PDF 文件。

### 示例（cURL）

```bash
curl --output document.pdf -X POST "https://api.tiptap.dev/v2/convert/export/pdf" \
    -H "Authorization: Bearer YOUR_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{
      "doc": "{\"type\":\"doc\",\"content\":[{\"type\":\"paragraph\",\"content\":[{\"type\":\"text\",\"text\":\"Hello World\"}]}]}"
    }'
```

<Callout title="需要订阅" variant="warning">
    使用此端点需要有效的 Tiptap 订阅。详情请查看我们的[定价页面](https://tiptap.dev/pricing)。
</Callout>

### 必需的请求头

| 名称            | 说明                                                                                                                               |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `Authorization` | 用于对请求进行身份验证的 JWT 令牌。示例：`Bearer your-jwt-token`                                                               |
| `Content-Type`  | 必须为 `application/json`                                                                                                                |

### 请求体

| 名称                 | 类型     | 说明                                                            | 默认值     |
| -------------------- | -------- | ---------------------------------------------------------------------- | ----------- |
| `doc`                | `String` | 字符串形式的 Tiptap JSON 文档                                       | `N/A`       |
| `exportType`         | `string` | 预期的导出类型                                               | `blob`      |
| `styleOverrides`     | `Object` | 样式覆盖                                                        | `{}`        |
| `pageSize`           | `Object` | 页面尺寸配置                                                | `undefined` |
| `pageMargins`        | `Object` | 页边距配置                                             | `undefined` |
| `headers`            | `Object` | 页眉配置                                              | `undefined` |
| `footers`            | `Object` | 页脚配置                                              | `undefined` |
| `customFonts`        | `Array`  | 要提供的自定义字体文件（仅限本地部署）                      | `undefined` |
| `tableOverrides`     | `Object` | 传递给 DOCX 步骤的表格级渲染覆盖             | `undefined` |
| `paragraphOverrides` | `Object` | 传递给 DOCX 步骤的段落级渲染覆盖         | `undefined` |
| `textRunOverrides`   | `Object` | 传递给 DOCX 步骤的文本运行级渲染覆盖                | `undefined` |
| `tableCellOverrides` | `Object` | 传递给 DOCX 步骤的表格单元格渲染覆盖              | `undefined` |
| `imageOverrides`     | `Object` | 传递给 DOCX 步骤的图像渲染覆盖                   | `undefined` |
| `headerFooterOverrides` | `Object` | 仅作用于页眉/页脚内容的逐字段覆盖（与元素覆盖使用相同的五个键）。请参阅[元素覆盖](#element-overrides)。 | `undefined` |
| `placeholders`       | `Object \| false` | 页眉/页脚中页码标记的重命名映射（`{ page?, total? }`），与 `Pages.configure({ placeholders })` 相对应。支持所有栏位形式：纯文本、字符串化的 Tiptap JSON 或 Tiptap JSON 对象。传入 `false` 可禁用替换。请参阅[自定义标记名称](/conversion/export/docx/rest-api#custom-token-names-placeholders)。 | `undefined` |
| `customNodeDsl` | `Object` | 用于将自定义 Tiptap 节点渲染到导出文件中的[自定义节点 DSL](/conversion/export/docx/custom-nodes-dsl) 规则。 | `undefined` |

#### 页面尺寸配置

`pageSize` 对象可用于自定义导出 PDF 文档的尺寸：

| 属性 | 类型     | 说明                                                                                         | 默认值    |
| -------- | -------- | --------------------------------------------------------------------------------------------------- | ---------- |
| `width`  | `string` | 页面宽度。必须为正数，后跟有效单位（cm、in、pt、pc、mm、px）。 | `"21.0cm"` |
| `height` | `string` | 页面高度。必须为正数，后跟有效单位（cm、in、pt、pc、mm、px）。| `"29.7cm"` |

#### 页边距配置

`pageMargins` 对象可用于自定义导出 PDF 文档的页边距：

| 属性 | 类型     | 说明                                                                                                       | 默认值  |
| -------- | -------- | ----------------------------------------------------------------------------------------------------------------- | -------- |
| `top`    | `string` | 页面上边距。可以为负数。必须为数字，后跟有效单位（cm、in、pt、pc、mm、px）。  | `"1.0cm"`|
| `bottom` | `string` | 页面下边距。可以为负数。必须为数字，后跟有效单位（cm、in、pt、pc、mm、px）。| `"1.0cm"`|
| `left`   | `string` | 页面左边距。必须为正数，后跟有效单位（cm、in、pt、pc、mm、px）。         | `"1.0cm"`|
| `right`  | `string` | 页面右边距。必须为正数，后跟有效单位（cm、in、pt、pc、mm、px）。        | `"1.0cm"`|

#### 页眉配置

`headers` 对象可用于自定义导出 PDF 文档的页眉。每个栏位（`default`、`first`、`even`）均可接受以下任一形式：纯文本字符串、字符串化的 Tiptap JSONContent，或直接放在 JSON 请求体中的 Tiptap JSONContent 对象。

| 属性            | 类型                  | 说明                                                                                                          |
| ------------------- | --------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `evenAndOddHeaders` | `boolean`             | 是否为奇数页和偶数页使用不同的页眉                                                              |
| `differentFirstPage` | `boolean`             | 是否为首页使用不同的页眉。设为 `true` 时，第一页使用 `first` 的值，而不是 `default`。 |
| `default`           | `string \| Object`    | 每页使用的默认页眉；启用 `evenAndOddHeaders` 时，则为奇数页页眉。接受纯文本、字符串化的 Tiptap JSONContent 或 Tiptap JSONContent 对象。 |
| `first`             | `string \| Object`    | 首页页眉。仅当 `differentFirstPage` 设为 `true` 时使用。接受纯文本、字符串化的 Tiptap JSONContent 或 Tiptap JSONContent 对象。 |
| `even`              | `string \| Object`    | 启用 `evenAndOddHeaders` 选项时用于偶数页的页眉。接受纯文本、字符串化的 Tiptap JSONContent 或 Tiptap JSONContent 对象。 |

<Callout title="支持的栏位值" >
    每个页眉值可采用以下三种形式之一：
    - **纯文本字符串。**生成无样式的简单页眉。
    - **字符串化的 Tiptap JSONContent。**支持加粗、斜体、链接等富文本格式。可使用 `JSON.stringify(yourHeaderDoc)` 生成。
    - **Tiptap JSONContent 对象。**同样支持富文本内容，可将其作为嵌套 JSON 对象直接放入请求体（无需转换为字符串）。

    对象会在栏位级别进行验证，并且必须包含 `type` 字段。无效的形式会返回 `400 Bad Request`。
</Callout>

#### 页脚配置

`footers` 对象可用于自定义导出 PDF 文档的页脚。栏位支持与页眉相同的三种形式。

| 属性            | 类型                  | 说明                                                                                                          |
| ------------------- | --------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `evenAndOddFooters` | `boolean`             | 是否为奇数页和偶数页使用不同的页脚                                                              |
| `differentFirstPage` | `boolean`             | 是否为首页使用不同的页脚。设为 `true` 时，第一页使用 `first` 的值，而不是 `default`。 |
| `default`           | `string \| Object`    | 每页使用的默认页脚；启用 `evenAndOddFooters` 时，则为奇数页页脚。接受纯文本、字符串化的 Tiptap JSONContent 或 Tiptap JSONContent 对象。 |
| `first`             | `string \| Object`    | 首页页脚。仅当 `differentFirstPage` 设为 `true` 时使用。接受纯文本、字符串化的 Tiptap JSONContent 或 Tiptap JSONContent 对象。 |
| `even`              | `string \| Object`    | 启用 `evenAndOddFooters` 选项时用于偶数页的页脚。接受纯文本、字符串化的 Tiptap JSONContent 或 Tiptap JSONContent 对象。 |

### 页眉和页脚示例

```bash
curl --output document.pdf -X POST "https://api.tiptap.dev/v2/convert/export/pdf" \
    -H "Authorization: Bearer YOUR_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{
      "doc": "{\"type\":\"doc\",\"content\":[{\"type\":\"paragraph\",\"content\":[{\"type\":\"text\",\"text\":\"Hello World\"}]}]}",
      "headers": {
        "default": {
          "type": "doc",
          "content": [
            {
              "type": "paragraph",
              "content": [{ "type": "text", "text": "My Header" }]
            }
          ]
        }
      },
      "footers": {
        "default": "Company name, 2026"
      }
    }'
```

#### 自定义字体配置

<Callout title="仅限本地部署" variant="warning">
    自定义字体仅适用于本地部署。如果你想在 Tiptap 云服务中使用自定义字体，请[联系我们了解 Enterprise 计划](https://tiptap.dev/pricing)。
</Callout>

`customFonts` 数组可用于提供生成 PDF 所需的自定义字体文件。每个条目指定字体文件 URL 及其字体族名称：

| 属性     | 类型     | 说明                                                    |
| ------------ | -------- | -------------------------------------------------------------- |
| `url`        | `string` | 直接指向 `.ttf` 或 `.woff2` 字体文件的 HTTPS URL |
| `fontFamily` | `string` | 文档中使用的字体族名称                       |

### 自定义字体示例（本地部署）

```bash
curl --output document.pdf -X POST "https://api.tiptap.dev/v2/convert/export/pdf" \
    -H "Authorization: Bearer YOUR_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{
      "doc": "{\"type\":\"doc\",\"content\":[{\"type\":\"paragraph\",\"content\":[{\"type\":\"text\",\"text\":\"Hello World\"}]}]}",
      "customFonts": [
        {
          "url": "https://your-cdn.com/fonts/CustomFont-Regular.ttf",
          "fontFamily": "Custom Font"
        }
      ]
    }'
```

### 元素覆盖

PDF 生成会经过 DOCX 处理流程，因此，在发送 Tiptap JSON 时，`/export/docx` 支持的同一组五种元素覆盖也适用于此处。
通过 `docxFile` 上传预先生成的 DOCX 时，这些覆盖**不会生效**。

<ElementOverridesRestApi />

#### 组合使用多个元素覆盖的 cURL 示例

```bash
curl --output document.pdf -X POST "https://api.tiptap.dev/v2/convert/export/pdf" \
    -H "Authorization: Bearer YOUR_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{
      "doc": "{\"type\":\"doc\",\"content\":[{\"type\":\"paragraph\",\"content\":[{\"type\":\"text\",\"text\":\"PDF with element-level overrides\"}]}]}",
      "paragraphOverrides": {
        "spacing": { "before": 200, "after": 200 }
      },
      "textRunOverrides": {
        "font": "Arial",
        "size": 24
      }
    }'
```

### 自定义页面布局示例

```bash
curl --output document.pdf -X POST "https://api.tiptap.dev/v2/convert/export/pdf" \
    -H "Authorization: Bearer YOUR_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{
      "doc": "{\"type\":\"doc\",\"content\":[{\"type\":\"paragraph\",\"content\":[{\"type\":\"text\",\"text\":\"Hello World\"}]}]}",
      "pageSize": {
        "width": "210mm",
        "height": "297mm"
      },
      "pageMargins": {
        "top": "20mm",
        "bottom": "20mm",
        "left": "15mm",
        "right": "15mm"
      }
    }'
```

### 响应

请求成功时，API 会以二进制下载的形式返回 PDF 文件：

- **状态**：`200 OK`
- **Content-Type**：`application/pdf`
- **Content-Disposition**：`attachment; filename=export-{timestamp}.pdf`

### 错误响应

| 状态 | 代码                            | 说明                          |
| ------ | ------------------------------- | ------------------------------------ |
| 400    | `NO_DOCUMENT_PROVIDED`          | 请求体中未提供文档 |
| 400    | _(validation)_                  | `headers` / `footers` 栏位包含未设置 `type` 字段的对象，或存在其他架构级问题。响应体会包含 ZodError，指出验证失败的字段。 |
| 422    | `FAILED_TO_PARSE_DOCX_FILE`    | 无法解析 JSON 输入          |
| 422    | `FAILED_TO_EXPORT_PDF_FILE`    | 无法导出中间格式 |
| 403    | `CUSTOM_FONTS_NOT_AVAILABLE`   | 自定义字体仅适用于本地部署 |
| 422    | `FAILED_TO_CONVERT_DOCX_TO_PDF`| 无法转换为 PDF             |
