PDF Export 扩展支持自定义页面尺寸和页边距，让你能够创建布局精准、符合需求的文档。无论你需要 A5 页面、自定义纸张尺寸，还是特定的页边距配置，都可以直接在扩展中进行设置。

## 页面尺寸配置

使用 `pageSize` 选项为导出的 PDF 文件设置自定义页面尺寸。页面尺寸配置接受不同计量单位的宽度和高度值。

### 支持的单位

页面尺寸和页边距均支持以下单位：

| 单位 | 描述       |
| ---- | ---------- |
| `cm` | 厘米（默认） |
| `in` | 英寸       |
| `pt` | 点         |
| `pc` | 派卡       |
| `mm` | 毫米       |
| `px` | 像素       |

### 配置选项

| 属性     | 类型     | 描述                                                              | 默认值   |
| -------- | -------- | ----------------------------------------------------------------- | -------- |
| `width`  | `string` | 页面宽度。必须是一个正数，后接有效单位（cm、in、pt、pc、mm、px）。  | `"21cm"`   |
| `height` | `string` | 页面高度。必须是一个正数，后接有效单位（cm、in、pt、pc、mm、px）。 | `"29.7cm"` |

```js
import { ExportPdf } from '@tiptap-pro/extension-export-pdf'

ExportPdf.configure({
  token: 'YOUR_TOKEN',
  pageSize: {
    width: '14.8cm', // A5 width
    height: '21cm', // A5 height
  },
})
```

## 页边距配置

`pageMargins` 选项可用于设置文档页面四边的自定义页边距。与页面尺寸不同，顶部和底部页边距可以是负值。

### 配置选项

| 属性     | 类型     | 描述                                                                                                      | 默认值     |
| -------- | -------- | --------------------------------------------------------------------------------------------------------- | ---------- |
| `top`    | `string` | 页面顶部页边距。可以为负值。必须是一个数字，后接有效单位（cm、in、pt、pc、mm、px）。                       | `"1cm"`    |
| `bottom` | `string` | 页面底部页边距。可以为负值。必须是一个数字，后接有效单位（cm、in、pt、pc、mm、px）。                       | `"1cm"`    |
| `left`   | `string` | 页面左侧页边距。必须是一个正数，后接有效单位（cm、in、pt、pc、mm、px）。                                   | `"1cm"`    |
| `right`  | `string` | 页面右侧页边距。必须是一个正数，后接有效单位（cm、in、pt、pc、mm、px）。                                   | `"1cm"`    |
| `header` | `string` | 页面上边缘到页眉顶部的距离。应小于 `top`。必须是带单位的正数。                                             | `"1.25cm"` |
| `footer` | `string` | 页面下边缘到页脚底部的距离。应小于 `bottom`。必须是带单位的正数。                                          | `"1.25cm"` |

```js
import { ExportPdf } from '@tiptap-pro/extension-export-pdf'

ExportPdf.configure({
  token: 'YOUR_TOKEN',
  pageMargins: {
    top: '2cm',
    bottom: '2cm',
    left: '1.5cm',
    right: '1.5cm',
    // Distance from the page edge to the header/footer
    header: '1cm',
    footer: '1cm',
  },
})
```

<Callout title="自动从 Pages 扩展派生" variant="hint">
  将 [Pages 扩展](/editor/extensions/functionality/pages) 与 `ExportPdf` 一起配置时，`header` 和 `footer` 偏移量会自动从 Pages 的存储值 `headerTopMargin` 和 `footerBottomMargin` 中派生。你传入 `pageMargins` 的值始终优先。
</Callout>

<Callout title="转换服务要求" variant="info">
  要端到端支持 `pageMargins.header` 和 `pageMargins.footer`，Tiptap 转换服务必须使用支持这些字段的版本，并搭载更新后的 `@tiptap-pro/extension-export-docx`。在较旧版本的转换服务中，这些值会被忽略，并使用 Word 的默认值。
</Callout>

## 页面背景颜色

使用 `pageColor` 选项为导出 PDF 的每一页设置背景颜色。

### 支持的格式

| 格式          | 示例                                                      |
| ------------- | --------------------------------------------------------- |
| 十六进制（6 位） | `"#ff0000"`                                               |
| 十六进制（3 位） | `"#f00"`                                                  |
| `rgb()`        | `"rgb(255, 0, 0)"`                                        |
| `rgba()`       | `"rgba(255, 0, 0, 0.5)"`                                  |
| 颜色名称       | 常见的 CSS 颜色名称（`"red"`、`"blue"`、`"green"` 等） |

传入 `"transparent"` 或将 `pageColor` 留空，即可不设置页面颜色。

```js
ExportPdf.configure({
  token: 'YOUR_TOKEN',
  pageColor: '#fff8dc',
})
```

## 完整示例

以下示例展示了如何使用 PDF Export 扩展配置自定义页面布局：

```js
import { ExportPdf } from '@tiptap-pro/extension-export-pdf'

const editor = new Editor({
  extensions: [
    // Other extensions...
    ExportPdf.configure({
      token: 'YOUR_TOKEN',
      // A5 page size
      pageSize: {
        width: '14.8cm',
        height: '21cm',
      },
      // Custom margins
      pageMargins: {
        top: '2cm',
        bottom: '2cm',
        left: '2cm',
        right: '2cm',
      },
      // Page background color
      pageColor: '#fff8dc',
    }),
    // Other extensions...
  ],
})

// Export with custom layout
editor
  .chain()
  .exportPdf({
    onCompleteExport(result) {
      const url = URL.createObjectURL(result)
      const a = document.createElement('a')

      a.href = url
      a.download = 'custom-layout.pdf'
      a.click()

      URL.revokeObjectURL(url)
    },
  })
  .run()
```

## 常见页面尺寸

以下是一些常见页面尺寸，可供参考：

| 格式       | 宽度     | 高度     |
| ---------- | -------- | -------- |
| **A4**     | `21cm`   | `29.7cm` |
| **A5**     | `14.8cm` | `21cm`   |
| **Letter** | `8.5in`  | `11in`   |
| **Legal**  | `8.5in`  | `14in`   |
| **Tabloid**| `11in`   | `17in`   |

## 使用不同的计量单位

你可以根据偏好混合使用不同单位：

```js
ExportPdf.configure({
  token: 'YOUR_TOKEN',
  // US Letter size in inches
  pageSize: {
    width: '8.5in',
    height: '11in',
  },
  // Margins in different units
  pageMargins: {
    top: '0.75in', // Inches
    bottom: '72pt', // Points (1 inch = 72 points)
    left: '2cm', // Centimeters
    right: '20mm', // Millimeters
  },
})
```

<Callout title="单位一致性" variant="hint">
  虽然可以混合使用不同单位，但通常建议在整个配置中统一使用同一种单位，以便于维护和理解。
</Callout>
