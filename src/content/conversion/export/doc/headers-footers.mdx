`@tiptap-pro/extension-export-doc` 扩展内置了自定义导出文档页眉和页脚的支持。你可以为首页、奇数页和偶数页分别配置不同的页眉和页脚。

## 配置页眉

`headers` 对象允许你自定义导出 DOC 文档的页眉：

| 属性 | 类型 | 说明 |
| ------------------- | --------- | ---------------------------------------------------------------------------------------------------- |
| `evenAndOddHeaders` | `boolean` | 是否为奇数页和偶数页使用不同的页眉 |
| `differentFirstPage` | `boolean` | 是否为首页使用不同的页眉。设为 `true` 时，首页使用 `first` 的值，而不是 `default`。 |
| `default`           | `string`  | 每页使用的标准默认页眉；启用 `evenAndOddHeaders` 时，则用于奇数页。可接受纯文本字符串，或用于实现丰富格式的序列化 Tiptap JSONContent。 |
| `first`             | `string`  | 首页页眉。仅当 `differentFirstPage` 设为 `true` 时使用。可接受纯文本字符串，或用于实现丰富格式的序列化 Tiptap JSONContent。 |
| `even`              | `string`  | 启用 `evenAndOddHeaders` 选项时，偶数页使用的页眉。可接受纯文本字符串，或用于实现丰富格式的序列化 Tiptap JSONContent。 |

使用纯文本时，会生成简单的无样式页眉。使用序列化的 Tiptap JSONContent（通过 `JSON.stringify()`）时，则会保留粗体、斜体和链接等丰富格式。

## 配置页脚

`footers` 对象允许你自定义导出 DOC 文档的页脚：

| 属性 | 类型 | 说明 |
| ------------------- | --------- | ---------------------------------------------------------------------------------------------------- |
| `evenAndOddFooters` | `boolean` | 是否为奇数页和偶数页使用不同的页脚 |
| `differentFirstPage` | `boolean` | 是否为首页使用不同的页脚。设为 `true` 时，首页使用 `first` 的值，而不是 `default`。 |
| `default`           | `string`  | 每页使用的标准默认页脚；启用 `evenAndOddFooters` 时，则用于奇数页。可接受纯文本字符串，或用于实现丰富格式的序列化 Tiptap JSONContent。 |
| `first`             | `string`  | 首页页脚。仅当 `differentFirstPage` 设为 `true` 时使用。可接受纯文本字符串，或用于实现丰富格式的序列化 Tiptap JSONContent。 |
| `even`              | `string`  | 启用 `evenAndOddFooters` 选项时，偶数页使用的页脚。可接受纯文本字符串，或用于实现丰富格式的序列化 Tiptap JSONContent。 |

使用纯文本时，会生成简单的无样式页脚。使用序列化的 Tiptap JSONContent（通过 `JSON.stringify()`）时，则会保留粗体、斜体和链接等丰富格式。

## 完整示例

```js
import { ExportDoc } from '@tiptap-pro/extension-export-doc'

const editor = new Editor({
  extensions: [
    // Other extensions...
    ExportDoc.configure({
      token: 'YOUR_TOKEN',
      headers: {
        evenAndOddHeaders: true,
        default: 'My Document - Confidential',
        first: 'Welcome to My Document',
        even: 'My Document - Even Page',
      },
      footers: {
        evenAndOddFooters: true,
        default: 'Company Name - All Rights Reserved',
        first: 'Draft Version 1.0',
        even: 'Company Name - Even Page Footer',
      },
    }),
    // Other extensions...
  ],
})

// Export with headers and footers
editor
  .chain()
  .exportDoc({
    onCompleteExport(result) {
      const url = URL.createObjectURL(result)
      const a = document.createElement('a')

      a.href = url
      a.download = 'document-with-headers.doc'
      a.click()

      URL.revokeObjectURL(url)
    },
  })
  .run()
```

## 简单页眉和页脚

如果不需要为奇数页和偶数页设置不同的页眉，只需提供 `default` 值即可：

```js
ExportDoc.configure({
  token: 'YOUR_TOKEN',
  headers: {
    default: 'My Document Title',
  },
  footers: {
    default: 'Page Footer - Company Name',
  },
})
```
