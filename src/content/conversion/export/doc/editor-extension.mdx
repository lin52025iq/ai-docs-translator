使用 Tiptap 的 `@tiptap-pro/extension-export-doc`，可将编辑器内容导出为 `.doc` 文件。此扩展会将文档发送到 Tiptap 转换服务进行转换，从而将 DOC 导出功能集成到编辑器中。

如果希望自行处理转换，也可以改用 [REST API](/conversion/export/doc/rest-api)。

## 安装 DOC 导出扩展

Conversion 扩展发布在 Tiptap 的私有 npm 仓库中。请按照[私有仓库指南](/guides/pro-extensions)集成这些扩展。

完成后，即可安装并导入 **Export DOC** 扩展包。

```bash
npm i @tiptap-pro/extension-export-doc
```

```js
import { ExportDoc } from '@tiptap-pro/extension-export-doc'
```

## 配置扩展

`ExportDoc` 扩展可通过 `configure` 方法接收 `ExportDocOptions`（`object`）作为参数，并使用以下属性进行配置：

```ts
import { ExportDoc } from '@tiptap-pro/extension-export-doc'

const editor = new Editor({
  extensions: [
    // Other extensions ...
    ExportDoc.configure({
      region: 'eu', // 'eu' or 'us'
      token: 'YOUR_TOKEN',
      styleOverrides: {},
      headers: {},
      footers: {},
      pageSize: { width: '21cm', height: '29.7cm' },
      pageMargins: { top: '1cm', bottom: '1cm', left: '1cm', right: '1cm' },
      customNodes: [],
      onCompleteExport: (result) => {
        // Handle the exported Blob
      },
    }),
    // Other extensions ...
  ],
})
```

| 参数                 | 类型                     | 说明                                                                                          | 默认值                     |
| -------------------- | ------------------------ | --------------------------------------------------------------------------------------------- | -------------------------- |
| `endpoint`           | `string`                 | 用于转换的 Tiptap API 端点。设置后会覆盖 `region`                                              | `undefined`                |
| `region`             | `'eu' \| 'us'`           | 未设置 `endpoint` 时使用的 Tiptap Cloud 区域                                                   | `'eu'`                     |
| `token`              | `string`                 | 用于身份验证的 Tiptap JWT，参见[身份验证](/authentication)                                   | `''`                       |
| `styleOverrides`     | `Record<string, string>` | 应用于导出的样式覆盖                                                                          | `undefined`                |
| `headers`            | `HeaderConfig`           | 导出文档的页眉配置                                                                            | `undefined`                |
| `footers`            | `FooterConfig`           | 导出文档的页脚配置                                                                            | `undefined`                |
| `pageSize`           | `PageSize`               | 页面大小配置                                                                                  | `undefined`                |
| `pageMargins`        | `PageMargins`            | 页边距配置                                                                                    | `undefined`                |
| `customNodes`        | `CustomNodeDefinition[]` | 用于基于 DOCX 的转换的自定义节点定义（需要 `@tiptap-pro/extension-export-docx`）               | `undefined`                |
| `onCompleteExport`   | `(result: Blob) => void` | 接收导出文件 Blob 的回调                                                                      | 未提供时抛出错误           |

## 导出 DOC 文件

安装扩展后，可以使用 `exportDoc` 命令将编辑器内容导出为 `.doc` 文件。

```ts
/**
 * Export the current document as a DOC file via the Tiptap convert service.
 *
 * @param options - All extension-level options can be overridden per-invocation
 * @example editor.commands.exportDoc({ onCompleteExport: (result) => {} })
 */
exportDoc: (options?: ExportDocCommandOptions) => ReturnType
```

`ExportDocCommandOptions` 接口扩展了 `ExportDocOptions`，因此可以在每次调用命令时覆盖所有配置选项：

| 属性                 | 类型                     | 说明                                  |
| -------------------- | ------------------------ | ------------------------------------- |
| `endpoint`           | `string`                 | 覆盖本次导出的 API 端点               |
| `region`             | `'eu' \| 'us'`           | 覆盖本次导出的区域                    |
| `token`              | `string`                 | 覆盖本次导出的 JWT 令牌               |
| `styleOverrides`     | `Record<string, string>` | 覆盖本次导出的样式覆盖                |
| `headers`            | `HeaderConfig`           | 覆盖本次导出的页眉配置                |
| `footers`            | `FooterConfig`           | 覆盖本次导出的页脚配置                |
| `pageSize`           | `PageSize`               | 覆盖本次导出的页面大小                |
| `pageMargins`        | `PageMargins`            | 覆盖本次导出的页边距                  |
| `customNodes`        | `CustomNodeDefinition[]` | 覆盖本次导出的自定义节点定义          |
| `onCompleteExport`   | `(result: Blob) => void` | 覆盖本次导出的回调                    |

```js
import { ExportDoc } from '@tiptap-pro/extension-export-doc'

const editor = new Editor({
  extensions: [
    // Other extensions ...
    ExportDoc.configure({
      token: 'YOUR_TOKEN',
      onCompleteExport(result) {
        // Download the DOC file
        const url = URL.createObjectURL(result)
        const a = document.createElement('a')

        a.href = url
        a.download = 'document.doc'
        a.click()

        URL.revokeObjectURL(url)
      },
    }),
    // Other extensions ...
  ],
})

// Use the extension-level callback
editor.chain().exportDoc().run()

// Or override options for a specific export
editor
  .chain()
  .exportDoc({
    pageSize: { width: '8.5in', height: '11in' },
    onCompleteExport(result) {
      // Custom handling for this specific export
      const url = URL.createObjectURL(result)
      window.open(url)
    },
  })
  .run()
```

### 工作原理

调用 `exportDoc` 时，扩展会将编辑器文档及配置的选项（样式覆盖、页面布局、页眉、页脚）发送到 Convert 服务。服务会返回生成的 `.doc` 文件（二进制 Blob）。`onCompleteExport` 回调会直接接收此 Blob。发生错误时会抛出异常，而不会通过回调传递。

## 预期情况

- **需要身份验证**（`token` JWT）。请在服务器端生成 JWT。参见[转换安装指南](/conversion/getting-started/install)。
- **需要处理的 HTTP 响应：** `401`（缺少或无效的 JWT）、`403`（应用无权执行此操作，通常是因为套餐不包含该格式）、`5xx`（临时服务器错误；请采用退避策略重试）。
- **每个请求都会在响应前完成端到端处理。** 处理较大的文档时，请预留较长的往返时间。

## 不支持的情况

- **往返转换后完全一致。** DOC 是 1997–2003 年间使用的二进制格式，本身存在渲染差异；我们力求忠实还原，但不保证逐字节一致。
- **现代 Word 功能。** DOC 早于许多 Word 功能；高级布局、批注、修订和带样式的元数据可能会被简化或舍弃。若目标是现代 Word 版本，请使用 [DOCX](/conversion/export/docx/editor-extension)。
