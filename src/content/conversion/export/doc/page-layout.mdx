DOC 导出扩展支持自定义页面尺寸和边距，让你可以创建布局精准、符合需求的文档。无论你需要 A5 页面、自定义纸张尺寸，还是特定的边距设置，都可以直接在扩展中进行配置。

<Callout title="建议改用 DOCX" variant="info">
  DOC 是 Microsoft Word 97-2003 使用的旧版格式。对于现代用途，我们建议改为导出为 [DOCX](/conversion/export/docx/page-layout)。只有在需要兼容旧系统时才使用 DOC。
</Callout>

## 页面尺寸配置

使用 `pageSize` 选项为导出的 DOC 文件定义自定义页面尺寸。页面尺寸配置接受采用各种度量单位的宽度和高度值。

### 支持的单位

所有页面尺寸和边距的测量值均支持以下单位：

| 单位 | 说明         |
| ---- | ------------ |
| `cm` | 厘米（默认） |
| `in` | 英寸         |
| `pt` | 磅           |
| `pc` | 派卡         |
| `mm` | 毫米         |
| `px` | 像素         |

### 配置选项

| 属性     | 类型     | 说明                                                                                 | 默认值     |
| -------- | -------- | ------------------------------------------------------------------------------------ | ---------- |
| `width`  | `string` | 页面宽度。必须是一个正数，后接有效单位（cm、in、pt、pc、mm、px）。                    | `"21cm"`   |
| `height` | `string` | 页面高度。必须是一个正数，后接有效单位（cm、in、pt、pc、mm、px）。                    | `"29.7cm"` |

```js
import { ExportDoc } from '@tiptap-pro/extension-export-doc'

ExportDoc.configure({
  token: 'YOUR_TOKEN',
  pageSize: {
    width: '14.8cm', // A5 宽度
    height: '21cm', // A5 高度
  },
})
```

## 页面边距配置

`pageMargins` 选项允许你为文档页面的各个方向设置自定义边距。与页面尺寸不同，上边距和下边距可以使用负值。

### 配置选项

| 属性     | 类型     | 说明                                                                                                       | 默认值     |
| -------- | -------- | ---------------------------------------------------------------------------------------------------------- | ---------- |
| `top`    | `string` | 页面上边距。可以为负值。必须是一个数字，后接有效单位（cm、in、pt、pc、mm、px）。                           | `"1cm"`    |
| `bottom` | `string` | 页面下边距。可以为负值。必须是一个数字，后接有效单位（cm、in、pt、pc、mm、px）。                           | `"1cm"`    |
| `left`   | `string` | 页面左边距。必须是一个正数，后接有效单位（cm、in、pt、pc、mm、px）。                                       | `"1cm"`    |
| `right`  | `string` | 页面右边距。必须是一个正数，后接有效单位（cm、in、pt、pc、mm、px）。                                       | `"1cm"`    |
| `header` | `string` | 页面顶边到页眉顶部的距离。应小于 `top`。必须是带单位的正数。                                               | `"1.25cm"` |
| `footer` | `string` | 页面底边到页脚底部的距离。应小于 `bottom`。必须是带单位的正数。                                            | `"1.25cm"` |

```js
import { ExportDoc } from '@tiptap-pro/extension-export-doc'

ExportDoc.configure({
  token: 'YOUR_TOKEN',
  pageMargins: {
    top: '2cm',
    bottom: '2cm',
    left: '1.5cm',
    right: '1.5cm',
    // 页面边缘到页眉/页脚的距离
    header: '1cm',
    footer: '1cm',
  },
})
```

<Callout title="自动从 Pages 扩展派生" variant="hint">
  将 [Pages 扩展](/editor/extensions/functionality/pages)与 `ExportDoc` 一起配置时，`header` 和 `footer` 偏移量会自动从 Pages 存储值 `headerTopMargin` 和 `footerBottomMargin` 中派生。你传入 `pageMargins` 的值始终优先。
</Callout>

<Callout title="转换服务要求" variant="info">
  要端到端支持 `pageMargins.header` 和 `pageMargins.footer`，Tiptap 转换服务必须使用能够接受这些字段并附带更新版 `@tiptap-pro/extension-export-docx` 的版本。在较旧版本的转换服务中，这些值会被忽略，并使用 Word 的默认设置。
</Callout>

## 页面背景颜色

使用 `pageColor` 选项为导出 DOC 的每一页设置背景颜色。

### 接受的格式

| 格式         | 示例                                                      |
| ------------ | --------------------------------------------------------- |
| 十六进制（6 位） | `"#ff0000"`                                               |
| 十六进制（3 位） | `"#f00"`                                                  |
| `rgb()`      | `"rgb(255, 0, 0)"`                                        |
| `rgba()`     | `"rgba(255, 0, 0, 0.5)"`                                  |
| 命名颜色     | 常见的 CSS 命名颜色（`"red"`、`"blue"`、`"green"` 等） |

传入 `"transparent"` 或不设置 `pageColor`，即可不指定页面颜色。

```js
ExportDoc.configure({
  token: 'YOUR_TOKEN',
  pageColor: '#fff8dc',
})
```

<Callout title="Word 默认不会打印页面背景" variant="hint">
  在 Microsoft Word 中，页面背景会显示在屏幕上，但**不会**包含在打印内容或导出的 PDF 中。若要让背景显示在打印输出或导出的 PDF 中，读者必须在 Word 中启用**文件 → 选项 → 显示 → 打印背景色和图像**。
</Callout>

## 完整示例

以下是一个完整示例，展示如何使用 DOC 导出扩展配置自定义页面布局：

```js
import { ExportDoc } from '@tiptap-pro/extension-export-doc'

const editor = new Editor({
  extensions: [
    // 其他扩展...
    ExportDoc.configure({
      token: 'YOUR_TOKEN',
      // A5 页面尺寸
      pageSize: {
        width: '14.8cm',
        height: '21cm',
      },
      // 自定义边距
      pageMargins: {
        top: '2cm',
        bottom: '2cm',
        left: '2cm',
        right: '2cm',
      },
      // 页面背景颜色
      pageColor: '#fff8dc',
    }),
    // 其他扩展...
  ],
})

// 使用自定义布局导出
editor
  .chain()
  .exportDoc({
    onCompleteExport(result) {
      const url = URL.createObjectURL(result)
      const a = document.createElement('a')

      a.href = url
      a.download = 'custom-layout.doc'
      a.click()

      URL.revokeObjectURL(url)
    },
  })
  .run()
```

## 常见页面尺寸

以下是一些常见页面尺寸，可供参考：

| 格式        | 宽度     | 高度     |
| ----------- | -------- | -------- |
| **A4**      | `21cm`   | `29.7cm` |
| **A5**      | `14.8cm` | `21cm`   |
| **Letter**  | `8.5in`  | `11in`   |
| **Legal**   | `8.5in`  | `14in`   |
| **Tabloid** | `11in`   | `17in`   |

## 使用不同的度量单位

你可以根据偏好混合使用不同的单位：

```js
ExportDoc.configure({
  token: 'YOUR_TOKEN',
  // 以英寸为单位的 US Letter 尺寸
  pageSize: {
    width: '8.5in',
    height: '11in',
  },
  // 使用不同单位的边距
  pageMargins: {
    top: '0.75in', // 英寸
    bottom: '72pt', // 磅（1 英寸 = 72 磅）
    left: '2cm', // 厘米
    right: '20mm', // 毫米
  },
})
```

<Callout title="单位一致性" variant="hint">
  虽然可以混用不同单位，但通常建议在整个配置中使用统一的单位，以便于维护和理解。
</Callout>
