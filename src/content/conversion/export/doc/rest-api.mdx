## 导出 DOC

`POST /v2/convert/export/doc`

`/v2/convert/export/doc` 端点可将 Tiptap JSON 文档转换为 DOC 格式。发送 `POST` 请求，并在 JSON 请求体中提供文档，即可接收可下载的 DOC 文件。

### 示例（cURL）

```bash
curl --output document.doc -X POST "https://api.tiptap.dev/v2/convert/export/doc" \
    -H "Authorization: Bearer YOUR_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{
      "doc": "{\"type\":\"doc\",\"content\":[{\"type\":\"paragraph\",\"content\":[{\"type\":\"text\",\"text\":\"Hello World\"}]}]}"
    }'
```

<Callout title="需要订阅" variant="warning">
    此端点需要有效的 Tiptap 订阅。详情请查看我们的[定价页面](https://tiptap.dev/pricing)。
</Callout>

### 必需的请求头

| 名称            | 说明                                                                                                                               |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `Authorization` | 用于验证请求的 JWT 令牌。例如：`Bearer your-jwt-token`                                                               |
| `Content-Type`  | 必须为 `application/json`                                                                                                                |

### 请求体

| 名称                 | 类型     | 说明                                                            | 默认值     |
| -------------------- | -------- | ---------------------------------------------------------------------- | ----------- |
| `doc`                | `String` | 以字符串形式提供的 Tiptap JSON 文档                                       | `N/A`       |
| `exportType`         | `string` | 预期的导出类型                                               | `blob`      |
| `styleOverrides`     | `Object` | 样式覆盖                                                        | `{}`        |
| `pageSize`           | `Object` | 页面尺寸配置                                                | `undefined` |
| `pageMargins`        | `Object` | 页边距配置                                             | `undefined` |
| `headers`            | `Object` | 页眉配置                                              | `undefined` |
| `footers`            | `Object` | 页脚配置                                              | `undefined` |
| `tableOverrides`     | `Object` | 表格级渲染覆盖，传递至 DOCX 处理步骤             | `undefined` |
| `paragraphOverrides` | `Object` | 段落级渲染覆盖，传递至 DOCX 处理步骤         | `undefined` |
| `textRunOverrides`   | `Object` | 文本运行渲染覆盖，传递至 DOCX 处理步骤                | `undefined` |
| `tableCellOverrides` | `Object` | 表格单元格渲染覆盖，传递至 DOCX 处理步骤              | `undefined` |
| `imageOverrides`     | `Object` | 图像渲染覆盖，传递至 DOCX 处理步骤                   | `undefined` |
| `headerFooterOverrides` | `Object` | 应用于页眉/页脚内容的字段级覆盖（与元素覆盖相同的五个键）。请参阅[元素覆盖](#元素覆盖)。 | `undefined` |
| `placeholders`       | `Object \| false` | 用于重命名页眉/页脚中页码标记的映射（`{ page?, total? }`），与 `Pages.configure({ placeholders })` 对应。适用于所有槽位形式：纯文本、字符串化的 Tiptap JSON 或 Tiptap JSON 对象。传入 `false` 可禁用替换。请参阅[自定义标记名称](/conversion/export/docx/rest-api#custom-token-names-placeholders)。 | `undefined` |
| `customNodeDsl` | `Object` | 用于将自定义 Tiptap 节点渲染到导出文件中的[自定义节点 DSL](/conversion/export/docx/custom-nodes-dsl) 规则。 | `undefined` |

#### 页面尺寸配置

`pageSize` 对象可用于自定义导出 DOC 文档的页面尺寸：

| 属性 | 类型     | 说明                                                                                         | 默认值    |
| -------- | -------- | --------------------------------------------------------------------------------------------------- | ---------- |
| `width`  | `string` | 页面宽度。必须是后跟有效单位（cm、in、pt、pc、mm、px）的正数。 | `"21.0cm"` |
| `height` | `string` | 页面高度。必须是后跟有效单位（cm、in、pt、pc、mm、px）的正数。| `"29.7cm"` |

#### 页边距配置

`pageMargins` 对象可用于自定义导出 DOC 文档的页边距：

| 属性 | 类型     | 说明                                                                                                       | 默认值  |
| -------- | -------- | ----------------------------------------------------------------------------------------------------------------- | -------- |
| `top`    | `string` | 页面上边距。可以为负数。必须是后跟有效单位（cm、in、pt、pc、mm、px）的数字。  | `"1.0cm"`|
| `bottom` | `string` | 页面下边距。可以为负数。必须是后跟有效单位（cm、in、pt、pc、mm、px）的数字。| `"1.0cm"`|
| `left`   | `string` | 页面左边距。必须是后跟有效单位（cm、in、pt、pc、mm、px）的正数。         | `"1.0cm"`|
| `right`  | `string` | 页面右边距。必须是后跟有效单位（cm、in、pt、pc、mm、px）的正数。        | `"1.0cm"`|

#### 页眉配置

`headers` 对象可用于自定义导出 DOC 文档的页眉：

| 属性            | 类型      | 说明                                                                                                          |
| ------------------- | --------- | -------------------------------------------------------------------------------------------------------------------- |
| `evenAndOddHeaders` | `boolean` | 是否为奇数页和偶数页使用不同的页眉                                                              |
| `differentFirstPage` | `boolean` | 是否为首页使用不同的页眉。设为 `true` 时，首页使用 `first` 值，而非 `default`。 |
| `default`           | `string \| Object` | 每页使用的默认页眉；启用 `evenAndOddHeaders` 时，也可作为奇数页页眉。接受纯文本、字符串化的 Tiptap JSONContent 或 Tiptap JSONContent 对象。 |
| `first`             | `string \| Object` | 首页页眉。仅当 `differentFirstPage` 设为 `true` 时使用。接受纯文本、字符串化的 Tiptap JSONContent 或 Tiptap JSONContent 对象。 |
| `even`              | `string \| Object` | 启用 `evenAndOddHeaders` 选项时用于偶数页的页眉。接受纯文本、字符串化的 Tiptap JSONContent 或 Tiptap JSONContent 对象。 |

<Callout title="可接受的槽位值">
  每个页眉值可以采用以下三种形式之一：

- **纯文本字符串。**生成简单、无样式的页眉。
- **字符串化的 Tiptap JSONContent。**支持粗体、斜体和链接等丰富格式。使用 `JSON.stringify(yourHeaderDoc)` 生成。
- **Tiptap JSONContent 对象。**同样支持丰富内容，可作为请求体中的嵌套 JSON 对象发送，无需将其字符串化。

在 JSON 请求体中，对象必须包含 `type` 字段；如果格式无效，则会返回 `400 Bad Request`。

</Callout>

#### 页脚配置

`footers` 对象可用于自定义导出 DOC 文档的页脚：

| 属性            | 类型      | 说明                                                                                                          |
| ------------------- | --------- | -------------------------------------------------------------------------------------------------------------------- |
| `evenAndOddFooters` | `boolean` | 是否为奇数页和偶数页使用不同的页脚                                                              |
| `differentFirstPage` | `boolean` | 是否为首页使用不同的页脚。设为 `true` 时，首页使用 `first` 值，而非 `default`。 |
| `default`           | `string \| Object` | 每页使用的默认页脚；启用 `evenAndOddFooters` 时，也可作为奇数页页脚。接受纯文本、字符串化的 Tiptap JSONContent 或 Tiptap JSONContent 对象。 |
| `first`             | `string \| Object` | 首页页脚。仅当 `differentFirstPage` 设为 `true` 时使用。接受纯文本、字符串化的 Tiptap JSONContent 或 Tiptap JSONContent 对象。 |
| `even`              | `string \| Object` | 启用 `evenAndOddFooters` 选项时用于偶数页的页脚。接受纯文本、字符串化的 Tiptap JSONContent 或 Tiptap JSONContent 对象。 |

<Callout title="可接受的槽位值">
  每个页脚值可以采用与页眉值相同的三种形式之一：纯文本字符串、字符串化的 Tiptap JSONContent，或 Tiptap JSONContent 对象。在 JSON 请求体中，对象必须包含 `type` 字段；如果格式无效，则会返回 `400 Bad Request`。
</Callout>

### 元素覆盖

DOC 生成流程会经过 DOCX 处理管线，因此发送 Tiptap JSON 时，也适用 `/export/docx` 支持的相同五种元素覆盖。
通过 `docxFile` 上传预先生成的 DOCX 时，这些覆盖**不会生效**。

<ElementOverridesRestApi />

#### 组合使用多种元素覆盖的 cURL 示例

```bash
curl --output document.doc -X POST "https://api.tiptap.dev/v2/convert/export/doc" \
    -H "Authorization: Bearer YOUR_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{
      "doc": "{\"type\":\"doc\",\"content\":[{\"type\":\"paragraph\",\"content\":[{\"type\":\"text\",\"text\":\"DOC with element-level overrides\"}]}]}",
      "paragraphOverrides": {
        "spacing": { "before": 200, "after": 200 }
      },
      "textRunOverrides": {
        "font": "Arial",
        "size": 24
      }
    }'
```

### 自定义页面布局示例

```bash
curl --output document.doc -X POST "https://api.tiptap.dev/v2/convert/export/doc" \
    -H "Authorization: Bearer YOUR_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{
      "doc": "{\"type\":\"doc\",\"content\":[{\"type\":\"paragraph\",\"content\":[{\"type\":\"text\",\"text\":\"Hello World\"}]}]}",
      "pageSize": {
        "width": "210mm",
        "height": "297mm"
      },
      "pageMargins": {
        "top": "20mm",
        "bottom": "20mm",
        "left": "15mm",
        "right": "15mm"
      }
    }'
```

### 响应

成功时，API 会以二进制下载的形式返回 DOC 文件：

- **状态**：`200 OK`
- **Content-Type**：`application/msword`
- **Content-Disposition**：`attachment; filename=export-{timestamp}.doc`

### 错误响应

| 状态 | 代码                            | 说明                          |
| ------ | ------------------------------- | ------------------------------------ |
| 400    | `NO_DOCUMENT_PROVIDED`          | 请求体中未提供文档 |
| 422    | `FAILED_TO_PARSE_DOCX_FILE`    | 无法解析 JSON 输入          |
| 422    | `FAILED_TO_EXPORT_DOC_FILE`    | 无法导出中间格式 |
| 422    | `FAILED_TO_CONVERT_DOCX_TO_DOC`| 无法转换为 DOC             |
