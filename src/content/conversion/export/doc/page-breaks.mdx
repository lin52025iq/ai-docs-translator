[PageBreak 扩展](/pages/core-concepts/page-break-node)允许用户在编辑器中插入显式分页符。与 DOC 导出扩展结合使用时，这些分页符也会包含在导出的文档中。

## 工作原理

DOC 导出完全支持分页符。DOC 导出在底层使用 DOCX 转换，其中 `pageBreak` 节点会转换为 `<w:br w:type="page"/>`，从而在生成的 DOC 文件中创建标准分页符。

## 将 PageBreak 与 DOC 导出搭配使用

将 PageBreak 扩展与 DOC 导出扩展一同注册。导出时，编辑器内容中的分页符会自动转换。

```ts
import { Editor } from '@tiptap/core'
import { ConvertKit } from '@tiptap-pro/extension-convert-kit'
import { ExportDoc } from '@tiptap-pro/extension-export-doc'
import { PageBreak } from '@tiptap-pro/extension-pagebreak'

const editor = new Editor({
  extensions: [
    ConvertKit,
    PageBreak,
    ExportDoc.configure({
      token: 'your-jwt',
      onCompleteExport: (result) => {
        const blob = new Blob([result], { type: 'application/msword' })
        const url = URL.createObjectURL(blob)
        const a = document.createElement('a')
        a.href = url
        a.download = 'export.doc'
        a.click()
        URL.revokeObjectURL(url)
      },
    }),
  ],
})
```
