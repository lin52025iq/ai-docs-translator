你也可以为其他元素创建自定义样式，例如 `Heading 2`、`Heading 3`、`List Bullet`、`List Number` 等。`paragraphStyles` 数组接受由以下属性组成的对象数组：

### 段落样式对象

`paragraphStyle` 对象接受以下属性：

| 属性          | 类型      | 描述                                               |
| ------------- | --------- | -------------------------------------------------- |
| `id`          | `string`  | 样式的唯一标识符。                                 |
| `name`        | `string`  | 样式的显示名称。                                   |
| `basedOn`     | `string`  | 此样式所基于的基本样式（例如 `Normal`）。          |
| `next`        | `string`  | 应用于后续段落的样式。                             |
| `quickFormat` | `boolean` | 如果为 `true`，该样式会显示在快速样式菜单中。      |
| `run`         | `object`  | 定义文本格式（字体、字号、颜色、粗体等）。         |
| `paragraph`   | `object`  | 定义段落格式（间距、对齐方式、边框等）。           |

### 文本运行样式属性

`paragraphStyle` 对象中的 `run` 对象接受以下属性：

| 属性                  | 类型            | 描述                                                                                              |
| --------------------- | --------------- | ------------------------------------------------------------------------------------------------- |
| `font`                | `string`        | 文本字体。                                                                                        |
| `size`                | `number`        | 以半磅为单位的字号（例如，16 磅 = 32）。                                                           |

| `effect`              |                 | 可应用的特殊文本效果。                                                                            |
| `emphasisMark`        | `string`        | 显示在文本上方或下方的着重号（例如 `dot`）。                                                       |
| `smallCaps`           | `boolean`       | 设为 `true` 可将文本显示为小型大写字母。                                                          |
| `allCaps`             | `boolean`       | 设为 `true` 可将文本全部显示为大写。                                                               |

| `highlight`           |                 | 高亮颜色（预定义值）。                                                                            |

如需了解更高级的样式选项和详细用法，请参考包中导出的 `IParagraphStylePropertiesOptions` 类型，或查阅 [docx 文档](https://docx.js.org/#/usage/styling-with-js)。

## 元素覆盖

元素覆盖与 `styleOverrides` 相互独立。`styleOverrides` 定义的是 Word 通过其样式系统应用的**命名段落样式**（Heading 1、Normal 等）；而**元素覆盖**则会在转换过程中，将基础默认值直接应用于每个段落、文本运行、表格、表格行、表格单元格或图像。

这样无需定义命名样式，也能精细控制每个元素的原始 docx 属性。

> **浅层展开**：所有覆盖对象都采用浅层展开，而非深度合并。覆盖 `spacing` 或 `transformation` 等嵌套属性时，请提供完整的嵌套对象，以避免字段未定义。

### `paragraphOverrides`

接受除 `children` 以外的任何 `IParagraphOptions` 属性。这些值会**首先**展开为基础默认值；按节点计算的值（`alignment`、列表编号、标题级别）会覆盖这些默认值。

应用于：普通段落、标题、引用块、项目符号列表、编号列表和列表项。

```ts
ExportDocx.configure({
  onCompleteExport: (result) => {
    /* ... */
  },
  paragraphOverrides: {
    spacing: { after: 200, before: 100 },
    alignment: AlignmentType.LEFT,
  },
})
```

> **`spacing` 是部分覆盖**：`paragraphOverrides` 中的 `spacing.before` 和 `spacing.after` 会保留在每个段落上，但 `spacing.line` 始终会根据各段落的 `lineHeight` 重新计算，并替换你在此处传入的值。`IParagraphOptions` 中的其他嵌套对象仍会被整体替换（不会深度合并）。

### `textRunOverrides`

接受除 `text` 以外的任何 `IRunOptions` 属性。这些值会**首先**展开为基础默认值；各标记的格式（粗体、斜体、下划线、字体系列、字号、颜色、高亮等）会覆盖这些默认值。

适用于为整个导出文档设置默认字体或字号。

```ts
ExportDocx.configure({
  onCompleteExport: (result) => {
    /* ... */
  },
  textRunOverrides: {
    font: 'Arial',
    size: 24, // 12pt in half-points
  },
})
```

### `tableOverrides`

接受除 `rows` 以外的任何 `ITableOptions` 属性。这些值会**最后**展开，因此用户提供的表格级属性（边框、边距、布局）会优先于计算得出的默认值。

```ts
ExportDocx.configure({
  onCompleteExport: (result) => {
    /* ... */
  },
  tableOverrides: {
    width: { size: 100, type: WidthType.PERCENTAGE },
    layout: TableLayoutType.FIXED,
  },
})
```

### `tableRowOverrides`

接受除 `children` 以外的任何 `ITableRowOptions` 属性。这些值会在添加各行单元格之前，**首先**展开为基础默认值。适用于没有对应逐样式设置的行级布局，例如在分页符处保持整行不拆分（`cantSplit`）、在每页重复显示表头行（`tableHeader`），或固定行高（`height`）。

```ts
ExportDocx.configure({
  onCompleteExport: (result) => {
    /* ... */
  },
  tableRowOverrides: {
    cantSplit: true,
  },
})
```

例如，若要重复显示表格的表头行（包括 DOCX 导入创建的表头行），请启用 `repeatTableHeaderRows`，而不要自行设置 `tableHeader`。请参阅[表格](/conversion/content-types/structures-and-media/tables#export)。

### `tableCellOverrides`

接受除 `children` 以外的任何 `ITableCellOptions` 属性。这些值会**首先**展开为基础默认值；按单元格计算的值（宽度、colspan、宽度类型）会覆盖它们。

适用于为所有表格单元格统一设置底纹、垂直对齐方式或边框样式。

```ts
ExportDocx.configure({
  onCompleteExport: (result) => {
    /* ... */
  },
  tableCellOverrides: {
    shading: { fill: 'F0F0F0', type: ShadingType.SOLID },
    verticalAlign: VerticalAlign.CENTER,
  },
})
```

### `imageOverrides`

接受除 `data`、`type` 和 `fallback` 以外的任何 `IImageOptions` 属性。这些值会**最后**展开，因此用户提供的值（例如自定义的 `transformation` 尺寸）会优先于从图像缓冲区检测到的固有尺寸。无论覆盖值如何设置，SVG 回退数据都会始终保留。

```ts
ExportDocx.configure({
  onCompleteExport: (result) => {
    /* ... */
  },
  imageOverrides: {
    transformation: { width: 400, height: 300 },
    floating: {
      horizontalPosition: { offset: 0 },
      verticalPosition: { offset: 0 },
    },
  },
})
```

### 组合使用示例

你可以在同一配置中组合使用所有元素覆盖：

```ts
editor.commands.exportDocx({
  onCompleteExport: (result) => {
    /* ... */
  },
  exportType: 'blob',
  paragraphOverrides: {
    spacing: { after: 200, before: 100 },
  },
  textRunOverrides: {
    font: 'Arial',
    size: 24, // 12pt in half-points
  },
  tableCellOverrides: {
    shading: { fill: 'F0F0F0', type: ShadingType.SOLID },
  },
  imageOverrides: {
    transformation: { width: 400, height: 300 },
  },
})
```

### `headerFooterOverrides`

元素覆盖同样适用于页眉和页脚内容以及正文：在顶层设置的 `paragraphOverrides`、`textRunOverrides`、`tableOverrides`、`tableRowOverrides`、`tableCellOverrides` 或 `imageOverrides` 值也会应用于运行中的页眉和页脚。

如果你希望页眉/页脚内容的样式与正文**不同**，请使用 `headerFooterOverrides`。它接受相同的六个字段，并仅在页眉/页脚内容范围内替换对应的全局正文覆盖。每个字段都是完整替换，而非深度合并：未定义的字段会回退到同名的全局正文覆盖。

```ts
import { Docx, ExportDocx } from '@tiptap-pro/extension-export-docx'

ExportDocx.configure({
  onCompleteExport: (result) => {
    /* ... */
  },
  // Body tables get a 1pt grid border
  tableOverrides: {
    borders: {
      top: { style: Docx.BorderStyle.SINGLE, size: 4, color: '000000' },
      bottom: { style: Docx.BorderStyle.SINGLE, size: 4, color: '000000' },
      left: { style: Docx.BorderStyle.SINGLE, size: 4, color: '000000' },
      right: { style: Docx.BorderStyle.SINGLE, size: 4, color: '000000' },
      insideHorizontal: { style: Docx.BorderStyle.SINGLE, size: 4, color: '000000' },
      insideVertical: { style: Docx.BorderStyle.SINGLE, size: 4, color: '000000' },
    },
  },
  // Header/footer tables (e.g. a layout table inside a page header) are
  // borderless. Other body overrides still apply unless overridden here.
  headerFooterOverrides: {
    tableOverrides: {
      borders: {
        top: { style: Docx.BorderStyle.NONE },
        bottom: { style: Docx.BorderStyle.NONE },
        left: { style: Docx.BorderStyle.NONE },
        right: { style: Docx.BorderStyle.NONE },
        insideHorizontal: { style: Docx.BorderStyle.NONE },
        insideVertical: { style: Docx.BorderStyle.NONE },
      },
    },
  },
})
```

> **适用范围**：`headerFooterOverrides` 仅适用于从 [Pages 扩展](/pages/getting-started/overview)自动提取的页眉/页脚内容。如果你使用 `Docx.Header` / `Docx.Footer` 实例手动构建页眉/页脚，或使用传递给 `headers` / `footers` 选项的自定义工厂构建，则这些构造不会应用 `headerFooterOverrides`，因此请在工厂内部自行应用覆盖。
