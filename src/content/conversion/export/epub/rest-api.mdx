## 导出 EPUB

`POST /v2/convert/export/epub`

`/v2/convert/export/epub` 端点可将 Tiptap JSON 文档转换为 EPUB 格式。发送 `POST` 请求，并将文档作为 JSON 请求体，即可接收可下载的 EPUB 文件。

### 示例（cURL）

```bash
curl --output document.epub -X POST "https://api.tiptap.dev/v2/convert/export/epub" \
    -H "Authorization: Bearer YOUR_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{
      "doc": "{\"type\":\"doc\",\"content\":[{\"type\":\"paragraph\",\"content\":[{\"type\":\"text\",\"text\":\"Hello World\"}]}]}"
    }'
```

<Callout title="需要订阅" variant="warning">
    此端点需要有效的 Tiptap 订阅。详情请查看我们的[定价页面](https://tiptap.dev/pricing)。
</Callout>

### 必需的请求头

| 名称            | 说明                                                                                                                               |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `Authorization` | 用于对请求进行身份验证的 JWT 令牌。示例：`Bearer your-jwt-token`                                                               |
| `Content-Type`  | 必须为 `application/json`                                                                                                                |

### 请求体

| 名称                 | 类型     | 说明                                                            | 默认值     |
| -------------------- | -------- | ---------------------------------------------------------------------- | ----------- |
| `doc`                | `String` | 字符串形式的 Tiptap JSON 文档                                       | `N/A`       |
| `exportType`         | `string` | 预期的导出类型                                               | `blob`      |
| `styleOverrides`     | `Object` | 样式覆盖                                                        | `{}`        |
| `pageSize`           | `Object` | 页面尺寸配置                                                | `undefined` |
| `pageMargins`        | `Object` | 页边距配置                                             | `undefined` |
| `headers`            | `Object` | 页眉配置                                              | `undefined` |
| `footers`            | `Object` | 页脚配置                                              | `undefined` |
| `tableOverrides`     | `Object` | 转交给 DOCX 步骤的表格级渲染覆盖项             | `undefined` |
| `paragraphOverrides` | `Object` | 转交给 DOCX 步骤的段落级渲染覆盖项         | `undefined` |
| `textRunOverrides`   | `Object` | 转交给 DOCX 步骤的文本运行渲染覆盖项                | `undefined` |
| `tableCellOverrides` | `Object` | 转交给 DOCX 步骤的表格单元格渲染覆盖项              | `undefined` |
| `imageOverrides`     | `Object` | 转交给 DOCX 步骤的图像渲染覆盖项                   | `undefined` |
| `headerFooterOverrides` | `Object` | 仅作用于页眉/页脚内容的逐字段覆盖项（与元素覆盖项使用相同的五个键）。请参阅[元素覆盖项](#element-overrides)。 | `undefined` |
| `placeholders`       | `Object \| false` | 页眉/页脚中页码标记的重命名映射（`{ page?, total? }`），对应于 `Pages.configure({ placeholders })`。适用于所有插槽形式：纯文本、字符串化的 Tiptap JSON 或 Tiptap JSON 对象。传入 `false` 可禁用替换。请参阅[自定义标记名称](/conversion/export/docx/rest-api#custom-token-names-placeholders)。 | `undefined` |
| `customNodeDsl` | `Object` | 用于将自定义 Tiptap 节点渲染到导出文件中的[自定义节点 DSL](/conversion/export/docx/custom-nodes-dsl)规则。 | `undefined` |

#### 页面尺寸配置

`pageSize` 对象可用于自定义导出 EPUB 文档的页面尺寸：

| 属性 | 类型     | 说明                                                                                         | 默认值    |
| -------- | -------- | --------------------------------------------------------------------------------------------------- | ---------- |
| `width`  | `string` | 页面宽度。必须是正数，后跟有效单位（cm、in、pt、pc、mm、px）。 | `"21.0cm"` |
| `height` | `string` | 页面高度。必须是正数，后跟有效单位（cm、in、pt、pc、mm、px）。| `"29.7cm"` |

#### 页边距配置

`pageMargins` 对象可用于自定义导出 EPUB 文档的页边距：

| 属性 | 类型     | 说明                                                                                                       | 默认值  |
| -------- | -------- | ----------------------------------------------------------------------------------------------------------------- | -------- |
| `top`    | `string` | 页面上边距。可以为负数。必须是数字，后跟有效单位（cm、in、pt、pc、mm、px）。  | `"1.0cm"`|
| `bottom` | `string` | 页面下边距。可以为负数。必须是数字，后跟有效单位（cm、in、pt、pc、mm、px）。| `"1.0cm"`|
| `left`   | `string` | 页面左边距。必须是正数，后跟有效单位（cm、in、pt、pc、mm、px）。         | `"1.0cm"`|
| `right`  | `string` | 页面右边距。必须是正数，后跟有效单位（cm、in、pt、pc、mm、px）。        | `"1.0cm"`|

#### 页眉配置

`headers` 对象可用于自定义导出 EPUB 文档的页眉：

| 属性            | 类型      | 说明                                                                                                          |
| ------------------- | --------- | -------------------------------------------------------------------------------------------------------------------- |
| `evenAndOddHeaders` | `boolean` | 是否为奇数页和偶数页使用不同的页眉                                                              |
| `differentFirstPage` | `boolean` | 是否为首页使用不同的页眉。设为 `true` 时，首页使用 `first` 的值，而非 `default`。 |
| `default`           | `string \| Object` | 每页的标准默认页眉；启用 `evenAndOddHeaders` 时，则用于奇数页。接受纯文本、字符串化的 Tiptap JSONContent，或 Tiptap JSONContent 对象。 |
| `first`             | `string \| Object` | 首页的页眉。仅当 `differentFirstPage` 设为 `true` 时使用。接受纯文本、字符串化的 Tiptap JSONContent，或 Tiptap JSONContent 对象。 |
| `even`              | `string \| Object` | 启用 `evenAndOddHeaders` 选项时偶数页的页眉。接受纯文本、字符串化的 Tiptap JSONContent，或 Tiptap JSONContent 对象。 |

<Callout title="支持的插槽值">
  每个页眉值都可以采用以下三种形式之一：

- **纯文本字符串。**生成简单的无样式页眉。
- **字符串化的 Tiptap JSONContent。**支持粗体、斜体和链接等富文本格式。可通过 `JSON.stringify(yourHeaderDoc)` 生成。
- **Tiptap JSONContent 对象。**内容与上述富文本相同，但以嵌套 JSON 对象的形式直接放入请求体，无需字符串化。

在 JSON 请求体中，对象必须包含 `type` 字段；如果格式无效，则会返回 `400 Bad Request`。

</Callout>

#### 页脚配置

`footers` 对象可用于自定义导出 EPUB 文档的页脚：

| 属性            | 类型      | 说明                                                                                                          |
| ------------------- | --------- | -------------------------------------------------------------------------------------------------------------------- |
| `evenAndOddFooters` | `boolean` | 是否为奇数页和偶数页使用不同的页脚                                                              |
| `differentFirstPage` | `boolean` | 是否为首页使用不同的页脚。设为 `true` 时，首页使用 `first` 的值，而非 `default`。 |
| `default`           | `string \| Object` | 每页的标准默认页脚；启用 `evenAndOddFooters` 时，则用于奇数页。接受纯文本、字符串化的 Tiptap JSONContent，或 Tiptap JSONContent 对象。 |
| `first`             | `string \| Object` | 首页的页脚。仅当 `differentFirstPage` 设为 `true` 时使用。接受纯文本、字符串化的 Tiptap JSONContent，或 Tiptap JSONContent 对象。 |
| `even`              | `string \| Object` | 启用 `evenAndOddFooters` 选项时偶数页的页脚。接受纯文本、字符串化的 Tiptap JSONContent，或 Tiptap JSONContent 对象。 |

<Callout title="支持的插槽值">
  每个页脚值都可以采用与页眉相同的三种形式之一：纯文本字符串、字符串化的 Tiptap JSONContent，或 Tiptap JSONContent 对象。在 JSON 请求体中，对象必须包含 `type` 字段；如果格式无效，则会返回 `400 Bad Request`。
</Callout>

### 元素覆盖项

EPUB 生成过程会经过 DOCX 流水线，因此发送 Tiptap JSON 时，`/export/docx` 接受的同样五种元素覆盖项在此也适用。
通过 `docxFile` 上传预先生成的 DOCX 时，这些覆盖项**不会生效**。

<ElementOverridesRestApi />

#### 组合多个元素覆盖项的 cURL 示例

```bash
curl --output document.epub -X POST "https://api.tiptap.dev/v2/convert/export/epub" \
    -H "Authorization: Bearer YOUR_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{
      "doc": "{\"type\":\"doc\",\"content\":[{\"type\":\"paragraph\",\"content\":[{\"type\":\"text\",\"text\":\"EPUB with element-level overrides\"}]}]}",
      "paragraphOverrides": {
        "spacing": { "before": 200, "after": 200 }
      },
      "textRunOverrides": {
        "font": "Arial",
        "size": 24
      }
    }'
```

### 自定义页面布局示例

```bash
curl --output document.epub -X POST "https://api.tiptap.dev/v2/convert/export/epub" \
    -H "Authorization: Bearer YOUR_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{
      "doc": "{\"type\":\"doc\",\"content\":[{\"type\":\"paragraph\",\"content\":[{\"type\":\"text\",\"text\":\"Hello World\"}]}]}",
      "pageSize": {
        "width": "210mm",
        "height": "297mm"
      },
      "pageMargins": {
        "top": "20mm",
        "bottom": "20mm",
        "left": "15mm",
        "right": "15mm"
      }
    }'
```

### 响应

成功时，API 会以二进制下载的形式返回 EPUB 文件：

- **状态**：`200 OK`
- **Content-Type**：`application/epub+zip`
- **Content-Disposition**：`attachment; filename=export-{timestamp}.epub`

### 错误响应

| 状态 | 代码                             | 说明                          |
| ------ | -------------------------------- | ------------------------------------ |
| 400    | `NO_DOCUMENT_PROVIDED`           | 请求体中未提供文档 |
| 422    | `FAILED_TO_PARSE_DOCX_FILE`     | 解析 JSON 输入失败          |
| 422    | `FAILED_TO_EXPORT_EPUB_FILE`    | 导出中间格式失败 |
| 422    | `FAILED_TO_CONVERT_DOCX_TO_EPUB`| 转换为 EPUB 失败            |
