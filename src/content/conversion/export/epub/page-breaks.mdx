[PageBreak 扩展](/pages/core-concepts/page-break-node)允许用户在编辑器中插入明确的分页符。与 EPUB 导出扩展结合使用时，这些分页符会包含在导出的文档中。

## 工作原理

EPUB 导出完全支持分页符。EPUB 导出功能在底层使用 DOCX 转换，会将 `pageBreak` 节点转换为 `<w:br w:type="page"/>`，从而在生成的 EPUB 文件中创建标准分页符。

## 在 EPUB 导出中配置 PageBreak

将 PageBreak 扩展与 EPUB 导出扩展一起注册。导出时，编辑器内容中的分页符会自动转换。

```ts
import { Editor } from '@tiptap/core'
import { ConvertKit } from '@tiptap-pro/extension-convert-kit'
import { ExportEpub } from '@tiptap-pro/extension-export-epub'
import { PageBreak } from '@tiptap-pro/extension-pagebreak'

const editor = new Editor({
  extensions: [
    ConvertKit,
    PageBreak,
    ExportEpub.configure({
      token: 'your-jwt',
      onCompleteExport: (result) => {
        const blob = new Blob([result], { type: 'application/epub+zip' })
        const url = URL.createObjectURL(blob)
        const a = document.createElement('a')
        a.href = url
        a.download = 'export.epub'
        a.click()
        URL.revokeObjectURL(url)
      },
    }),
  ],
})
```
