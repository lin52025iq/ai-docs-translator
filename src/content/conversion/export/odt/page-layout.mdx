ODT Export 扩展支持自定义页面尺寸和页边距，让你能够创建符合需求、布局精准的文档。无论你需要 A5 页面、自定义纸张尺寸，还是特定的页边距设置，都可以直接在扩展中进行配置。

## 页面尺寸配置

使用 `pageSize` 选项定义导出 ODT 文件的自定义页面尺寸。页面尺寸配置接受使用各种度量单位的宽度和高度值。

### 支持的单位

所有页面尺寸和页边距测量值均支持以下单位：

| 单位 | 说明             |
| ---- | ---------------- |
| `cm` | 厘米（默认）     |
| `in` | 英寸             |
| `pt` | 磅               |
| `pc` | 派卡             |
| `mm` | 毫米             |
| `px` | 像素             |

### 配置选项

| 属性     | 类型     | 说明                                                                                  | 默认值     |
| -------- | -------- | ------------------------------------------------------------------------------------- | ---------- |
| `width`  | `string` | 页面宽度。必须是一个正数，后接有效单位（cm、in、pt、pc、mm、px）。                    | `"21cm"`   |
| `height` | `string` | 页面高度。必须是一个正数，后接有效单位（cm、in、pt、pc、mm、px）。                    | `"29.7cm"` |

```js
import { ExportOdt } from '@tiptap-pro/extension-export-odt'

ExportOdt.configure({
  token: 'YOUR_TOKEN',
  pageSize: {
    width: '14.8cm', // A5 width
    height: '21cm', // A5 height
  },
})
```

## 页面页边距配置

`pageMargins` 选项允许你为文档页面的各边设置自定义页边距。与页面尺寸不同，上下页边距可以使用负值。

### 配置选项

| 属性     | 类型     | 说明                                                                                                                     | 默认值     |
| -------- | -------- | ------------------------------------------------------------------------------------------------------------------------ | ---------- |
| `top`    | `string` | 页面上边距。可以为负值。必须是一个数字，后接有效单位（cm、in、pt、pc、mm、px）。                                         | `"1cm"`    |
| `bottom` | `string` | 页面下边距。可以为负值。必须是一个数字，后接有效单位（cm、in、pt、pc、mm、px）。                                         | `"1cm"`    |
| `left`   | `string` | 页面左边距。必须是一个正数，后接有效单位（cm、in、pt、pc、mm、px）。                                                     | `"1cm"`    |
| `right`  | `string` | 页面右边距。必须是一个正数，后接有效单位（cm、in、pt、pc、mm、px）。                                                     | `"1cm"`    |
| `header` | `string` | 页面顶边到页眉顶部的距离。应小于 `top`。必须是带单位的正数。                                                              | `"1.25cm"` |
| `footer` | `string` | 页面底边到页脚底部的距离。应小于 `bottom`。必须是带单位的正数。                                                          | `"1.25cm"` |

```js
import { ExportOdt } from '@tiptap-pro/extension-export-odt'

ExportOdt.configure({
  token: 'YOUR_TOKEN',
  pageMargins: {
    top: '2cm',
    bottom: '2cm',
    left: '1.5cm',
    right: '1.5cm',
    // Distance from the page edge to the header/footer
    header: '1cm',
    footer: '1cm',
  },
})
```

<Callout title="从 Pages 扩展自动派生" variant="hint">
  如果同时配置了 [Pages 扩展](/editor/extensions/functionality/pages)和
  `ExportOdt`，`header` 和 `footer` 偏移量会自动根据 Pages 存储中的
  `headerTopMargin` 和 `footerBottomMargin` 值计算。你传入 `pageMargins` 的值始终优先。
</Callout>

<Callout title="Convert 服务要求" variant="info">
  要端到端支持 `pageMargins.header` 和 `pageMargins.footer`，Tiptap convert
  服务必须使用能够接受这些字段并包含更新版
  `@tiptap-pro/extension-export-docx` 的版本。在较旧版本的 convert 服务中，这些值会被忽略，并使用 Word 的默认值。
</Callout>

## 页面背景色

使用 `pageColor` 选项为导出的 ODT 文件中的每一页设置背景色。

### 接受的格式

| 格式       | 示例                                                      |
| ---------- | --------------------------------------------------------- |
| 十六进制（6 位） | `"#ff0000"`                                        |
| 十六进制（3 位） | `"#f00"`                                           |
| `rgb()`    | `"rgb(255, 0, 0)"`                                        |
| `rgba()`   | `"rgba(255, 0, 0, 0.5)"`                                  |
| 命名颜色   | 常见的 CSS 命名颜色（`"red"`、`"blue"`、`"green"` 等） |

传入 `"transparent"` 或将 `pageColor` 留空，即可不设置页面颜色。

```js
ExportOdt.configure({
  token: 'YOUR_TOKEN',
  pageColor: '#fff8dc',
})
```

## 完整示例

以下是一个完整示例，展示如何使用 ODT Export 扩展配置自定义页面布局：

```js
import { ExportOdt } from '@tiptap-pro/extension-export-odt'

const editor = new Editor({
  extensions: [
    // Other extensions...
    ExportOdt.configure({
      token: 'YOUR_TOKEN',
      // A5 page size
      pageSize: {
        width: '14.8cm',
        height: '21cm',
      },
      // Custom margins
      pageMargins: {
        top: '2cm',
        bottom: '2cm',
        left: '2cm',
        right: '2cm',
      },
      // Page background color
      pageColor: '#fff8dc',
    }),
    // Other extensions...
  ],
})

// Export with custom layout
editor
  .chain()
  .exportOdt({
    onCompleteExport(result) {
      const url = URL.createObjectURL(result)
      const a = document.createElement('a')

      a.href = url
      a.download = 'custom-layout.odt'
      a.click()

      URL.revokeObjectURL(url)
    },
  })
  .run()
```

## 常见页面尺寸

以下是一些可供参考的常见页面尺寸：

| 格式        | 宽度     | 高度     |
| ----------- | -------- | -------- |
| **A4**      | `21cm`   | `29.7cm` |
| **A5**      | `14.8cm` | `21cm`   |
| **信纸**    | `8.5in`  | `11in`   |
| **法律纸**  | `8.5in`  | `14in`   |
| **Tabloid** | `11in`   | `17in`   |

## 使用不同的度量单位

你可以根据偏好混合使用不同单位：

```js
ExportOdt.configure({
  token: 'YOUR_TOKEN',
  // US Letter size in inches
  pageSize: {
    width: '8.5in',
    height: '11in',
  },
  // Margins in different units
  pageMargins: {
    top: '0.75in', // Inches
    bottom: '72pt', // Points (1 inch = 72 points)
    left: '2cm', // Centimeters
    right: '20mm', // Millimeters
  },
})
```

<Callout title="单位一致性" variant="hint">
  虽然你可以混合使用不同单位，但通常建议在整个配置中保持单位一致，以便于维护和理解。
</Callout>
