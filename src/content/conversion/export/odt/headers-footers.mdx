`@tiptap-pro/extension-export-odt` 扩展内置了自定义导出文档页眉和页脚的功能。你可以为首页、奇数页和偶数页分别配置不同的页眉和页脚。

## 页眉配置

`headers` 对象用于自定义导出 ODT 文档的页眉：

| 属性 | 类型 | 说明 |
| ------------------- | --------- | ---------------------------------------------------------------------------------------------------- |
| `evenAndOddHeaders` | `boolean` | 是否为奇数页和偶数页使用不同的页眉 |
| `differentFirstPage` | `boolean` | 是否为首页使用不同的页眉。设为 `true` 时，首页使用 `first` 的值，而不是 `default`。 |
| `default` | `string` | 每页使用的默认页眉；启用 `evenAndOddHeaders` 时，也用于奇数页。可接受纯文本字符串，或序列化为字符串的 Tiptap JSONContent，以实现富文本格式。 |
| `first` | `string` | 首页页眉。仅当 `differentFirstPage` 设为 `true` 时使用。可接受纯文本字符串，或序列化为字符串的 Tiptap JSONContent，以实现富文本格式。 |
| `even` | `string` | 启用 `evenAndOddHeaders` 选项时，偶数页使用的页眉。可接受纯文本字符串，或序列化为字符串的 Tiptap JSONContent，以实现富文本格式。 |

使用纯文本时，将生成不带样式的简单页眉。使用序列化为字符串的 Tiptap JSONContent（通过 `JSON.stringify()`）时，则会保留粗体、斜体和链接等富文本格式。

## 页脚配置

`footers` 对象用于自定义导出 ODT 文档的页脚：

| 属性 | 类型 | 说明 |
| ------------------- | --------- | ---------------------------------------------------------------------------------------------------- |
| `evenAndOddFooters` | `boolean` | 是否为奇数页和偶数页使用不同的页脚 |
| `differentFirstPage` | `boolean` | 是否为首页使用不同的页脚。设为 `true` 时，首页使用 `first` 的值，而不是 `default`。 |
| `default` | `string` | 每页使用的默认页脚；启用 `evenAndOddFooters` 时，也用于奇数页。可接受纯文本字符串，或序列化为字符串的 Tiptap JSONContent，以实现富文本格式。 |
| `first` | `string` | 首页页脚。仅当 `differentFirstPage` 设为 `true` 时使用。可接受纯文本字符串，或序列化为字符串的 Tiptap JSONContent，以实现富文本格式。 |
| `even` | `string` | 启用 `evenAndOddFooters` 选项时，偶数页使用的页脚。可接受纯文本字符串，或序列化为字符串的 Tiptap JSONContent，以实现富文本格式。 |

使用纯文本时，将生成不带样式的简单页脚。使用序列化为字符串的 Tiptap JSONContent（通过 `JSON.stringify()`）时，则会保留粗体、斜体和链接等富文本格式。

## 完整示例

```js
import { ExportOdt } from '@tiptap-pro/extension-export-odt'

const editor = new Editor({
  extensions: [
    // Other extensions...
    ExportOdt.configure({
      token: 'YOUR_TOKEN',
      headers: {
        evenAndOddHeaders: true,
        default: 'My Document - Confidential',
        first: 'Welcome to My Document',
        even: 'My Document - Even Page',
      },
      footers: {
        evenAndOddFooters: true,
        default: 'Company Name - All Rights Reserved',
        first: 'Draft Version 1.0',
        even: 'Company Name - Even Page Footer',
      },
    }),
    // Other extensions...
  ],
})

// Export with headers and footers
editor
  .chain()
  .exportOdt({
    onCompleteExport(result) {
      const url = URL.createObjectURL(result)
      const a = document.createElement('a')

      a.href = url
      a.download = 'document-with-headers.odt'
      a.click()

      URL.revokeObjectURL(url)
    },
  })
  .run()
```

## 简单页眉和页脚

如果无需为奇数页和偶数页设置不同的页眉，可以只提供 `default` 值：

```js
ExportOdt.configure({
  token: 'YOUR_TOKEN',
  headers: {
    default: 'My Document Title',
  },
  footers: {
    default: 'Page Footer - Company Name',
  },
})
```
