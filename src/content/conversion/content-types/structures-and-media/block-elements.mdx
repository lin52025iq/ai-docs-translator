块级元素定义了文档的结构布局，包括引用段落、预格式化代码、视觉分隔线和换行。它们都包含在 StarterKit 中，但在转换流程中的支持情况各不相同。

## 所需内容

- **扩展：** `StarterKit`（包含 `Blockquote`、`CodeBlock`、`HorizontalRule` 和 `HardBreak`）
- **配置：** 无需配置。分页符需要单独的扩展，详见[分页符](/conversion/content-types/page-layout/page-breaks)页面。
- **集成方式：** 通过[编辑器扩展](/conversion/import/docx/editor-extension)和 [REST API](/conversion/import/docx/rest-api) 导入和导出的效果相同。

## 支持概览

| | 导入 | 编辑器 | 导出 |
| --- | --- | --- | --- |
| 引用块 | 支持 | 支持（StarterKit） | 支持 |
| 代码块 | 不支持 | 支持（StarterKit） | 不支持（会被丢弃） |
| 水平线 | 支持 | 支持（StarterKit） | 支持 |
| 硬换行 | 支持 | 支持（StarterKit） | 支持 |
| 分页符 | 参见[分页符](/conversion/content-types/page-layout/page-breaks) | | |

## 引用块

在 Word 中，引用块是应用了“Quote”样式的段落（匹配时不区分大小写）。

导入时会生成一个 `blockquote` 节点，其中包含一个或多个 `paragraph` 子节点。引用内容中的行内格式会予以保留。

导出时，会将应用了“Quote”样式的段落写回 DOCX。引用块可以正确地往返转换。

**扩展：** [`Blockquote`](/editor/extensions/nodes/blockquote)（StarterKit） | **快捷键：** Cmd+Shift+B

## 代码块

导入 DOCX 时，不会将任何 Word 样式映射到 `codeBlock` 节点。编辑器通过 StarterKit 提供代码块，但转换流程不支持导入或导出代码块。

<Callout variant="warning" title="代码块不支持 DOCX 转换">
  代码块既不会从 DOCX 导入，也不会导出到 DOCX。导出时，`codeBlock` 节点不会被转换。如果你的工作流程需要往返转换代码块，请在导入和导出扩展中都注册自定义节点处理程序。
</Callout>

**扩展：** [`CodeBlock`](/editor/extensions/nodes/code-block)（StarterKit） | **快捷键：** Cmd+Alt+C

## 水平线

Word 中的水平线通常是 VML 图形（带有 `o:hr` 属性的 `v:rect`，以及 `v:line` 元素）。导入时会检测这些图形并创建 `horizontalRule` 节点。

导出时会使用 VML 图形生成有效的 Word 水平线。水平线可以正确地往返转换。

**扩展：** [`HorizontalRule`](/editor/extensions/nodes/horizontal-rule)（StarterKit） | **输入规则：** `---`、`___`、`***`

## 硬换行

硬换行（Shift+Enter）会在同一段落中另起一行。在 Word 中，它对应 `<w:br/>` 元素。硬换行可以正确地往返转换。

**扩展：** [`HardBreak`](/editor/extensions/nodes/hard-break)（StarterKit） | **快捷键：** Shift+Enter

## 分页符

分页符内容已移至“页面布局”下的[分页符](/conversion/content-types/page-layout/page-breaks)页面。

## 导出

| 元素 | DOCX 输出 |
| --- | --- |
| 引用块 | 应用了“Quote”样式的段落 |
| 代码块 | 不导出 |
| 水平线 | VML 水平线图形 |
| 硬换行 | 文本运行中的 `<w:br/>` |
| 分页符 | 参见[分页符](/conversion/content-types/page-layout/page-breaks) |
