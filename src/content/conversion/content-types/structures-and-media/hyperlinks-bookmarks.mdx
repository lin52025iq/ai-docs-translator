DOCX 与 Tiptap 之间的超链接会转换为带有 `href` 属性的 `link` 标记。外部 URL 和电子邮件链接可以顺利往返转换。指向同一文档中其他位置的链接也可以往返转换，其指向的书签目标也会一并保留。

## 所需条件

- **扩展：**[ConvertKit](/conversion/import/docx/convertkit)，它会注册用于超链接的 `Link` 标记，以及用于锚点目标的 `Bookmark` 节点。
- **配置：**无需配置。

## 支持概览

| | 导入 | 编辑器 | 导出 |
| --- | --- | --- | --- |
| 外部超链接 (http/https) | 支持 | 支持 | 支持 |
| 电子邮件链接 (mailto:) | 支持 | 支持 | 支持 |
| 内部锚点链接 | 支持 | 支持 | 支持 |
| 书签目标 | 支持 | 支持 | 支持 |
| 链接中的行内格式 | 支持 | 支持 | 支持 |

## 导入

使用[编辑器扩展](/conversion/import/docx/editor-extension)或 [REST API](/conversion/import/docx/rest-api) 导入超链接。两者生成的输出完全相同。

转换服务会检测 `<w:hyperlink>` 元素，并生成带有 `link` 标记的文本节点。外部链接通过文档的关系文件解析。

```json
{
  "type": "text",
  "text": "Visit the Tiptap website",
  "marks": [
    { "type": "link", "attrs": { "href": "https://tiptap.dev" } }
  ]
}
```

### 文档内链接

跳转到同一文档中其他位置的链接（例如目录条目或“返回顶部”链接）会转换为 `link` 标记，其 `href` 为片段标识符：

```json
{
  "type": "text",
  "text": "Go to introduction",
  "marks": [
    { "type": "link", "attrs": { "href": "#intro" } }
  ]
}
```

Word 以多种方式存储这类链接，且都会导入：

- 超链接元素本身的锚点，Word 将其写作 `w:anchor`。
- 带有 `\l` 开关的 `HYPERLINK` 域，包括简单形式和复杂形式。

如果链接同时包含网址和锚点，两者会合并到同一个 href 中，例如 `https://example.com#intro`。

### 书签目标

链接跳转到的位置由 Word 书签指定。每个书签都会作为一个零宽度的 `bookmark` 节点导入，并将书签名称存储在其 `id` 中：

```json
{ "type": "bookmark", "attrs": { "id": "intro" } }
```

该节点位于书签的起始位置，因此锚点会保留在文档中的原有位置。链接通过在相同的 id 前加上 `#` 来指向该节点。位于段落之间而非段落内部的书签，会附加到后续段落的开头。

<Callout variant="info" title="Word 自带的书签也会导入">
  Word 会添加自带书签，例如用于标记上次编辑位置的 `_GoBack`，以及目录项背后的 `_Toc`。这些书签会像其他书签一样导入，因此你可能会看到 id 并非由你创建的 `bookmark` 节点。它们是零宽度的，不会渲染任何内容，并能确保自动生成的目录在往返转换后继续正常工作。
</Callout>

<Callout variant="info" title="超链接中的行内格式会在导入时保留">
  当 DOCX 超链接包含多个格式不同的文本片段（例如，先是一个粗体单词，后跟一个常规字体的单词）时，导入器会分别遍历每个 `w:r`。每个片段的格式（如粗体和斜体）都会与链接标记一并保留。
</Callout>

## 在编辑器中渲染

ConvertKit 会注册 [`Link`](/editor/extensions/marks/link) 扩展，因此无需单独安装。

它会将链接标记渲染为带有 `href` 属性的 `<a>` 标签。

该扩展会自动添加 `target`（默认值为 `_blank`）和 `rel`（默认值为 `noopener noreferrer nofollow`）属性。这些属性不会从 DOCX 导入，也不会包含在 DOCX 导出中。

书签目标需要使用 `Bookmark` 节点，该节点由 ConvertKit 默认注册。如果没有该节点，导入的内容加载到编辑器时锚点会被丢弃，指向这些锚点的链接也就无法解析。该节点是一个行内原子节点，会渲染为空的 `<span data-bookmark-id="...">`，因此不占空间，也不会与链接自身的 `<a>` 元素冲突。向 ConvertKit 传入 `bookmark: false` 可将其禁用。

## 导出

使用[编辑器扩展](/conversion/export/docx/editor-extension)或 [REST API](/conversion/export/docx/rest-api) 导出超链接。两者对链接的处理方式完全相同。

指向网址的链接（包括 `mailto:` 地址）会被包装为 DOCX 外部超链接，并应用 Hyperlink 样式；其 href 会成为 DOCX 包中的外部关系。

href 以 `#` 开头的链接会导出为指向匹配书签的 Word 内部超链接，因此它在文档中的跳转方式与在编辑器中相同。`bookmark` 节点会重新导出为 Word 书签，供这些链接指向。

单独的 `#` 没有可指向的目标，因此对应文本会以无链接的形式导出。仅包含片段标识符的网址（例如 `https://example.com#intro`）仍然是外部链接。

### 往返转换时的保留内容

带有纯文本链接文字的外部超链接可以完整经历导入、编辑和导出流程。href 和可见文本都会保留。导出的链接使用 DOCX 的 Hyperlink 样式（通常显示为蓝色带下划线的文本）。

文档内导航也能完整经历这一流程：链接仍指向相同目标，目标也保留在原有位置。

变化之处：编辑器添加的 `target` 和 `rel` 属性不会保留到 DOCX 中。
