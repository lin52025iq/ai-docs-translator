下标和上标标记可以在 DOCX 与 Tiptap 之间双向转换。例如，H₂O 等内容导入后会在编辑器中渲染，并在导出回 DOCX 时保留格式。

## 所需内容

- **扩展：**[ConvertKit](/conversion/import/docx/convertkit) 内置 `Subscript` 和 `Superscript`，两者默认均已启用。
- **配置：**注册 ConvertKit 即可，无需其他配置。

## 支持概览

| | 导入 | 编辑器 | 导出 |
| --- | --- | --- | --- |
| 下标 | 支持 | 通过 ConvertKit 支持 | 支持 |
| 上标 | 支持 | 通过 ConvertKit 支持 | 支持 |

## 导入

可使用[编辑器扩展](/conversion/import/docx/editor-extension)或 [REST API](/conversion/import/docx/rest-api) 导入下标和上标。两者会生成相同的输出。

转换服务会读取 `<w:vertAlign>` 行属性，并生成相应的标记：

| Word 元素 | Tiptap 标记 |
| --- | --- |
| `<w:vertAlign val="subscript">` | `subscript` |
| `<w:vertAlign val="superscript">` | `superscript` |

化学式（H₂O、CO₂）、数学符号（x²、E=mc²）和脚注引用均可正确导入。

## 在编辑器中渲染

[ConvertKit](/conversion/import/docx/convertkit) 内置 [`Subscript`](/editor/extensions/marks/subscript) 和 [`Superscript`](/editor/extensions/marks/superscript)，且默认启用，因此无需单独安装。

```ts
import { ConvertKit } from '@tiptap-pro/extension-convert-kit'

const editor = new Editor({
  extensions: [ConvertKit],
})
```

下标会渲染为 `<sub>`，上标会渲染为 `<sup>`。键盘快捷键：Cmd+, 用于下标，Cmd+. 用于上标。

如果不需要其中一种，可以通过 ConvertKit 的配置将其禁用：

```ts
ConvertKit.configure({
  subscript: false,   // disable subscript
  superscript: false, // disable superscript
})
```

<Callout title="禁用其中一种会丢弃导入的标记" variant="info">
  将 `subscript: false` 或 `superscript: false` 设为禁用后，编辑器架构将无法识别从 DOCX 导入的相应类型标记。有关如何处理无法识别的标记，请参阅
  [无效架构指南](/guides/invalid-schema)。
</Callout>

## 导出

[编辑器扩展](/conversion/export/docx/editor-extension)和 [REST API](/conversion/export/docx/rest-api) 都可以将下标和上标标记导出为 DOCX 行属性：

| Tiptap 标记 | Word 元素 |
| --- | --- |
| `subscript` | `<w:vertAlign val="subscript">` |
| `superscript` | `<w:vertAlign val="superscript">` |

化学式（H₂O、CO₂）、数学符号（x²、E=mc²）和脚注引用均可无损地完成双向转换。

数学或 LaTeX 表达式中的下标和上标使用单独的处理路径（采用 OOXML 数学元素 `m:sSub` 和 `m:sSup`）。
