文本颜色和高亮会在 Word 的颜色模型与 Tiptap 的 `textStyle` 和 `highlight` 标记之间相互转换。安装了正确的扩展后，两者都支持往返转换。

## 所需内容

- **扩展：**[`ConvertKit`](/conversion/import/docx/convertkit)。其内置的 `TextStyleKit` 提供 `Color`（和 `BackgroundColor`），而 ConvertKit 注册 `Highlight` 时已预先配置 `multicolor: true`。
- **配置：**无需配置。

```ts
import { ConvertKit } from '@tiptap-pro/extension-convert-kit'

new Editor({ extensions: [ConvertKit] })
```

<Callout title="multicolor: true 很重要" variant="warning">
  如果 `Highlight` 未设置 `multicolor: true`，则只支持单一的通用高亮，所有导入的高亮都会变为默认的黄色。ConvertKit 会自动应用此配置；如果覆盖 `highlight` 插槽，请保留此标志。
</Callout>

## 支持概览

|                     | 导入                          | 编辑器                            | 导出                        |
| ------------------- | ----------------------------- | --------------------------------- | ----------------------------- |
| 文本颜色            | 支持（`textStyle` 标记）       | 支持（TextStyle + Color）         | 支持（规范化为十六进制）      |
| 高亮                | 支持（`highlight` 标记）       | 支持（Highlight，支持多色）       | 支持（命名颜色或十六进制）    |
| 底纹（`<w:shd>`）   | 支持（映射为 `highlight`）     | 支持                              | 支持（纯色底纹）              |
| 主题颜色            | 不支持（不会转换）             | 不适用                            | 不适用                        |

## 导入

使用[编辑器扩展](/conversion/import/docx/editor-extension)或 [REST API](/conversion/import/docx/rest-api) 导入文本颜色和高亮。两者生成的输出完全相同。

转换服务会将 Word 颜色元素映射为 Tiptap 标记：

| Word 元素                           | Tiptap 标记 | 属性                   |
| ----------------------------------- | ----------- | ---------------------- |
| `<w:color val="FF0000">`            | `textStyle` | `{ color: "#FF0000" }` |
| `<w:highlight val="yellow">`        | `highlight` | `{ color: "yellow" }`  |
| `<w:shd val="clear" fill="00FFFF">` | `highlight` | `{ color: "#00FFFF" }` |

`<w:highlight>` 和 `<w:shd>` 都会生成相同的 `highlight` 标记。开发者无需区分两者。

<Callout title="不会导入主题颜色" variant="warning">
  Word 主题颜色（例如 `<w:color>` 上的 `accent1`、`accent2` 或 `themeColor` 属性）在导入时不会转换。如果文本片段仅使用主题颜色且 `val="auto"`，输出中将不包含该颜色。只会保留 `<w:color val="...">` 中明确指定的十六进制颜色值。
</Callout>

## 编辑器渲染

[`Color`](/editor/extensions/functionality/color) 扩展为 [`TextStyle`](/editor/extensions/marks/text-style) 添加颜色支持，而 [`Highlight`](/editor/extensions/marks/highlight) 扩展则处理背景颜色。ConvertKit 内置了这两个扩展：`TextStyleKit` 包含 `TextStyle` + `Color` + `BackgroundColor`，并且注册 `Highlight` 时已预先配置 `multicolor: true`。

文本颜色会在 `<span>` 元素上渲染为内联 `style="color: ..."`。高亮会渲染为带有 `background-color` 样式的 `<mark>` 元素。

如果禁用 `ConvertKit.configure({ textStyleKit: false })`，模式将无法识别导入的文本颜色属性。`highlight: false` 也会有同样的问题。有关如何处理无法识别的标记和属性，请参阅[无效模式指南](/guides/invalid-schema)。

## 导出

使用[编辑器扩展](/conversion/export/docx/editor-extension)或 [REST API](/conversion/export/docx/rest-api) 导出文本颜色和高亮。两者对颜色和高亮的处理方式完全相同。

导出时，颜色值会规范化为 6 位十六进制格式。支持以下输入格式：

- 带井号的十六进制：`#FF0000`、`#F00`、`#FF0000AA`
- RGB/RGBA：`rgb(255, 0, 0)`、`rgba(255, 0, 0, 0.5)`
- CSS 命名颜色：`red`、`blue`、`green`、`yellow`、`cyan`、`purple` 等另外 14 种颜色

高亮会导出为 Word 命名高亮颜色（颜色与 `yellow` 或 `cyan` 等 Word 枚举值匹配时），或者导出为填充了十六进制颜色值的纯色字符底纹。没有颜色属性的 `highlight` 标记默认使用黄色。
