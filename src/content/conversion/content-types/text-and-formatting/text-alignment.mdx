文本对齐是段落级属性，可在 DOCX 与编辑器之间往返转换。配置 TextAlign 扩展后，导入、编辑和导出时都会保留对齐方式。

## 所需内容

- **扩展：**[`ConvertKit`](/conversion/import/docx/convertkit) 内置 `TextAlign`，并预先将其配置为 `types: ['paragraph', 'heading']`。
- **配置：**无需配置。
- **就是这么简单。**使用标准的 ConvertKit 设置即可实现端到端的对齐处理。

## 支持情况概览

|         | 导入    | 编辑器    | 导出    |
| ------- | --------- | --------- | --------- |
| 左对齐    | 支持 | 支持 | 支持 |
| 居中  | 支持 | 支持 | 支持 |
| 右对齐   | 支持 | 支持 | 支持 |
| 两端对齐 | 支持 | 支持 | 支持 |

## 导入

使用[编辑器扩展](/conversion/import/docx/editor-extension)或 [REST API](/conversion/import/docx/rest-api)导入文本对齐。两者生成的输出完全相同。

转换服务会读取每个 DOCX 段落中的 `<w:jc>` 元素，并将其映射为对应 Tiptap 节点上的 `textAlign` 属性。

| Word `<w:jc>` 值 | Tiptap `textAlign`                                           |
| ------------------- | ------------------------------------------------------------ |
| `left`              | `left`                                                       |
| `center`            | `center`                                                     |
| `right`             | `right`                                                      |
| `both`              | `justify`                                                    |
| `start`             | `start`（原样传递，TextAlign 可能无法识别） |
| `end`               | `end`（原样传递，TextAlign 可能无法识别）   |

`textAlign` 属性会同时设置在 `paragraph` 和 `heading` 节点上。

<Callout title="不支持从右向左的文本方向" variant="warning">
  导入器不会解析 DOCX 段落方向（`<w:bidi>`）和文本运行方向（`<w:rtl>`）。无论源文档的编写方式如何，阿拉伯语、希伯来语、波斯语、乌尔都语或其他 RTL 语言的文档都会按照 Tiptap 的 CSS 方向渲染（默认为 LTR）。导出器也不会写入方向信息，因此以 LTR 方向编辑的文档导出时仍为 LTR。若要处理 RTL 内容，目前可在 CSS 中为编辑器根元素设置 `dir="rtl"`，也可以在应用层检测语言并自行设置方向。
</Callout>

## 编辑器渲染

[`TextAlign`](/editor/extensions/functionality/textalign) 扩展会在指定的节点类型上添加全局属性 `textAlign`。该属性会以行内样式 `style="text-align: ..."` 的形式渲染到 HTML 元素上。ConvertKit 将其注册为 `types: ['paragraph', 'heading']`，因此导入的对齐方式开箱即用：

```ts
import { ConvertKit } from '@tiptap-pro/extension-convert-kit'

new Editor({ extensions: [ConvertKit] })
```

如果需要用于其他类型（例如表格单元格），可以覆盖配置项：

```ts
ConvertKit.configure({
  textAlign: { types: ['paragraph', 'heading', 'tableCell'] },
})
```

<Callout title="禁用 textAlign 会丢弃该属性" variant="warning">
  如果设置 `ConvertKit.configure({ textAlign: false })`，导入的 `textAlign` 属性将无法被 schema 识别，也不会生效。此时不会抛出错误。有关此行为的更多信息，请参阅[无效 schema 指南](/guides/invalid-schema)。
</Callout>

## 导出

使用[编辑器扩展](/conversion/export/docx/editor-extension)或 [REST API](/conversion/export/docx/rest-api)导出文本对齐。两者对文本对齐的处理方式完全相同。

导出器会读取每个段落和标题中的 `node.attrs.textAlign`，并将其映射回 DOCX 对齐类型。无需额外配置。如果导入和编辑器配置正确，导出会自动完成。
