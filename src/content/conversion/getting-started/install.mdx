为项目设置凭据并安装转换扩展。

## 前提条件

1. [开始免费试用或选择订阅方案](https://cloud.tiptap.dev/v2/billing)。
2. 设置对 [Tiptap 私有 npm registry](/guides/pro-extensions) 的访问权限。

## 身份验证

大多数转换扩展和 REST API 端点都需要经过签名的 JWT。DOCX 导出扩展是个例外，无需凭据即可使用。

将 `aud` 声明设为 `"Convert"`，并授予集成所用的格式和方向对应的操作权限。若要创建密钥对并签署令牌，请参阅[身份验证](/authentication)。

### 操作权限

每个转换方向都有各自的操作权限，因此令牌只需限定为功能所需的操作；新增转换方向时，权限范围也不会在不知情的情况下扩大：

| 操作权限 | 授予的权限 |
| --- | --- |
| `Convert:Import:Docx` | 导入 DOCX |
| `Convert:Export:Docx` | 导出 DOCX |
| `Convert:Import:Markdown` | 导入 Markdown |
| `Convert:Export:Markdown` | 导出 Markdown |
| `Convert:Export:Doc` | 导出旧版 DOC |
| `Convert:Export:Odt` | 导出 ODT |
| `Convert:Export:Epub` | 导出 EPUB |
| `Convert:Export:Pdf` | 导出 PDF |
| `Convert:Fonts` | 管理字体缓存（`/fonts/*`），仅限本地部署 |

未指定格式的旧版路由（`POST /v2/import`、`POST /v2/export`）分别检查 `Convert:Import:Docx` 和 `Convert:Export:Docx`。

### 令牌示例

```json
{
  "iss": "env_abc123",
  "aud": "Convert",
  "exp": 1777033105,
  "permissions": [
    { "action": "Convert:Import:Docx", "resource": "*" },
    { "action": "Convert:Export:Docx", "resource": "*" },
    { "action": "Convert:Export:Pdf", "resource": "*" }
  ]
}
```

使用此令牌调用 `POST /v2/export/pdf` 会成功。调用 `POST /v2/export/odt` 则会被拒绝，并返回指出缺少相应操作权限的 `permission_denied` 错误。

对于 REST 请求，请将令牌放在 `Authorization: Bearer <jwt>` 标头中；对于编辑器扩展，请通过 `token` 选项传入令牌。请求只需提供令牌即可。

<Callout title="导入批注" variant="hint">
  导入包含批注的文档时，批注会写入 Document Server。请在 `Convert:Import:*` 操作权限之外，同时授予 `Documents:Write`，以便导入过程保存批注。请参阅[跨服务操作权限](/authentication#cross-service-actions)。
</Callout>

### 错误响应

令牌缺少所需权限时，服务会返回 `403 Forbidden`，响应内容如下：

```json
{
  "message": "Token is missing permission Convert:Export:Pdf.",
  "code": "permission_denied"
}
```

如果环境的订阅完全不包含 Convert，响应会返回 `403`，且 `code` 为 `feature_not_available`。上游云服务错误会原样映射：`429 rate_limited`、`503 service_unavailable`，以及 `401 token_expired` / `signature_invalid`，以便客户端区分无效令牌和暂时性的云服务问题。

<Callout title="正在维护现有集成？" variant="info">
  以前的 App ID 和密钥认证流程记录在[旧版身份验证](/authentication/legacy)中，并且仍可使用。
</Callout>

## 安装软件包

安装所需的扩展，以支持相应格式。

**导入：**

```bash
# DOCX import (editor extension)
npm install @tiptap-pro/extension-import-docx
```

**导出：**

```bash
# DOCX export (editor extension, no auth required)
npm install @tiptap-pro/extension-export-docx

# PDF export
npm install @tiptap-pro/extension-export-pdf

# ODT export
npm install @tiptap-pro/extension-export-odt

# EPUB export
npm install @tiptap-pro/extension-export-epub

# Markdown export
npm install @tiptap-pro/extension-export-markdown
```

<Callout title="导出 DOCX 无需身份验证" variant="info">
  `@tiptap-pro/extension-export-docx` 软件包完全在客户端处理转换，无需令牌或服务器调用。
</Callout>
