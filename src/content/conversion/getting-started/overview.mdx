Tiptap Conversion 可在文档格式与编辑器的文档模型之间进行转换。它支持导入 DOCX 和 Markdown，并导出为 DOCX、PDF、ODT、EPUB 和 Markdown。它**不是**文档渲染器，**不是**实时协作编辑器（这是 Tiptap 的另一款产品），**不是** OCR 或扫描版 PDF 处理工具，也**不是**异步任务队列。每个端点都会同步处理，并在响应中返回结果。它是一个桥梁。编辑器中实际渲染的内容取决于你安装了哪些扩展。

## 转换流程

转换是一个多步骤流程，而非单一操作。转换服务负责在文件格式与 Tiptap 的 JSON 文档模型之间进行转换，编辑器则负责渲染。

1. **导入：**转换服务解析源文档并生成 Tiptap JSON。这是一种结构化表示，包含文档的内容、格式和布局。
2. **编辑器渲染：**Tiptap 编辑器接收 JSON。JSON 中的每种节点类型（标题、表格、图像等）都需要在编辑器中安装对应的扩展才能渲染。对于没有匹配扩展的内容，需要妥善处理。有关处理策略，请参阅[无效架构指南](/guides/invalid-schema)。
3. **导出：**导出扩展会将编辑器中的内容转换回文档格式。它导出的是编辑器当前包含的内容，而不是原始源文档中的内容。

请参阅[支持的功能](/conversion/getting-started/feature-support-matrix)页面，全面了解各个阶段支持的功能；也可以浏览[内容类型](/conversion/content-types/text-and-formatting/paragraphs)页面，查看各项功能的详细文档。

在[在线演示](/conversion/getting-started/demo)中亲自试用。

## 渲染转换后内容所需的组件

你需要在编辑器中还原多少文档体验，取决于你要构建什么。

### ConvertKit

无论采用哪种 Conversion 工作流，都应注册来自 `@tiptap-pro/extension-convert-kit` 的 [ConvertKit](/conversion/import/docx/convertkit) 扩展。ConvertKit 是 Conversion 的标准编辑器套件：它包含兼容 DOCX 的架构（段落、标题、列表、图像和标记），以及转换服务生成的格式属性。请使用它替代 `StarterKit`；即使你目前不导入 DOCX，ConvertKit 也能让你为将来做好准备。

如果你要构建一个可接收文档上传的**内容编辑器**或 **CMS**，使用 ConvertKit 就足够了。文本内容可以在连续滚动的编辑器中正确渲染。对于 Markdown 导入，ConvertKit 也是合适的选择，因为它支持相同的一组功能。

[支持的功能](/conversion/getting-started/feature-support-matrix)页面介绍了 ConvertKit 对各项功能的处理方式，以及可能需要额外扩展的情况。

### 用于文档布局的 Pages 扩展

对于需要支持页眉、页脚、分页符、页码、页面大小和页边距的分页文档，你还需要 [Pages 扩展](/pages/getting-started/overview)和 [PagesTableKit](/pages/guides/pages-tablekit)。Pages 提供分页编辑体验，内容会流经各个可视页面，页眉和页脚也有专门的编辑区域；PagesTableKit 则提供支持分页的表格（ConvertKit 内置的表格不支持分页）。

只有安装 Pages 后，带有分页信息的导入内容（页眉、页脚和分页符）才能在编辑器中渲染。没有 Pages 时，导入的页眉和页脚无处渲染，分页符会被忽略，编辑器也不会识别页面边界。

| 你要构建的内容 | 所需组件 |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| 支持文档上传的内容编辑器或 CMS | `ConvertKit` |
| 支持页面布局的文档编辑器 | `ConvertKit` + `TableKit`（`@tiptap-pro/extension-pages-tablekit`）+ `Pages`（使用 `ConvertKit.configure({ table: false })`） |
| 无头处理流程（无编辑器） | 仅需 REST API，无需扩展 |

## 支持的格式

你可以通过编辑器扩展（Tiptap 编辑器中的命令）或 REST API（用于服务端或非编辑器场景的 HTTP 端点）集成转换功能。

| 格式 | 导入 | 导出 | 备注 |
| ---------------- | --------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- | ----- |
| **DOCX**（Word） | [扩展](/conversion/import/docx/editor-extension)、[REST API](/conversion/import/docx/rest-api) | [扩展](/conversion/export/docx/editor-extension)、[REST API](/conversion/export/docx/rest-api) | |
| **Markdown** | [REST API](/conversion/import/markdown/rest-api) | [扩展](/conversion/export/markdown/editor-extension)、[REST API](/conversion/export/markdown/rest-api) | |
| **PDF** | | [扩展](/conversion/export/pdf/editor-extension)、[REST API](/conversion/export/pdf/rest-api) | |
| **ODT** | | [扩展](/conversion/export/odt/editor-extension)、[REST API](/conversion/export/odt/rest-api) | |
| **EPUB** | | [扩展](/conversion/export/epub/editor-extension)、[REST API](/conversion/export/epub/rest-api) | |
| **DOC**（旧版） | | [扩展](/conversion/export/doc/editor-extension)、[REST API](/conversion/export/doc/rest-api) | |

Markdown 也可作为[编辑器核心功能](/editor/markdown)使用，内置解析和序列化能力，独立于转换服务。
