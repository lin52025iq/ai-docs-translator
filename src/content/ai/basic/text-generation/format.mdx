使用 `format: 'rich-text'` 选项，可以生成带有格式的 AI 响应。当你想生成包含粗体、斜体、链接等富文本格式的内容时，这尤其有用。

```ts
// Steams the response as rich text into the editor
editor
  .chain()
  .aiTextPrompt({
    text: 'Write a list of popular programming languages',
    stream: true,
    format: 'rich-text',
  })
  .run()
```
