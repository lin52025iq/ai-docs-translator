AI 扩展会将当前状态存储在扩展存储中的 `editor.storage.ai` 下。它会跟踪 AI 响应的当前状态以及所有历史响应。

<CodeDemo isPro path="/Extensions/AiStorage" />

| key            | type                                                                                    | definition                                                                                                                                                                                                                                                                                                               |
| -------------- | --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| state          | `'loading' \| 'error' \| 'idle'`                                                        | AI 正在生成响应时，状态为 `loading`。响应生成后，状态变为 `idle`。发生错误时，状态为 `error`                                                                                                                                                                                                                              |
| response       | `string \| undefined`                                                                   | AI 最近生成的消息。状态为 `idle` 时，如果这是字符串，则表示之前生成的消息；如果是 `undefined`，则表示尚未生成任何消息。状态为 `loading` 时，这是 AI 目前已生成的 HTML 或文本（如果响应正在流式传输）。状态为 `error` 时，此值为 `undefined`                                      |
| error          | `Error \| undefined`                                                                    | 生成的错误，仅在错误状态下设置                                                                                                                                                                                                                                                                                           |
| generatedWith  | `{ action: TextAction; options: TextOptions; range: undefined \| Range; } \| undefined` | 描述上次生成响应时所用选项的对象。只有将内容插入编辑器时，才会设置 range                                                                                                                                                                                                                                                 |
| pastResponses  | `string[]`                                                                              | 存储之前成功生成的响应，最新的排在最前面。响应被接受或拒绝时会清空                                                                                                                                                                                                                                                       |
| initialContent | `Slice \| null`                                                                         | 插入 AI 响应之前编辑器中的内容。用于通过 `aiReject` 命令撤销 AI 响应                                                                                                                                                                                                                                                     |

## 访问 AI 存储

你可以使用扩展存储来访问 AI 生成的当前状态。

```ts
const aiStorage = editor.storage.ai

if (aiStorage.response.state === 'error') {
  // The error that occurred
  aiStorage.response.error
}

if (aiStorage.response.state === 'loading') {
  // The response of the AI model as it is being generated
  aiStorage.response
}

if (aiStorage.response.state === 'idle') {
  if (aiStorage.response) {
    // The successful response
    aiStorage.response
  } else {
    // No response has been requested yet
  }
}
```

## 审核 AI 生成的内容

AI 扩展提供了一些命令，可在 AI 生成的内容插入编辑器后对其进行审核。

### `aiAccept`

将 AI 响应标记为已接受。这会清空 `pastResponses` 数组，并将 `initialContent` 设为 `null`。

```ts
editor.commands.aiAccept()
```

### `aiReject`

将编辑器内容恢复为之前的值。

```ts
editor.commands.aiReject()
```

<Callout title="多次请求 AI 后恢复到初始值" variant="info">
  如果连续调用多个 AI 命令，`initialContent` 属性会设为紧邻的上一个命令执行前的内容。因此，调用 `aiReject` 时，编辑器内容会恢复到上一个 AI 命令执行前的状态。若要将编辑器内容恢复到所有 AI 命令执行前的状态，可以调用带有 `regenerate` 选项且将其设为 `true` 的命令。
  例如：`editor.commands.aiSummarize({ regenerate: true })`。
</Callout>

### `aiRegenerate`

使用与上一次请求相同的参数重新生成 AI 响应。

```ts
editor.commands.aiRegenerate()
```

## 插入前预览 AI 响应

想在将 AI 响应插入编辑器前先预览吗？你可以在任意 AI [TextOption](/ai/basic/text-generation/built-in-commands#text-command-options) 中使用 `insert: false`。结果会存储在扩展存储中，但不会插入编辑器内容。

```ts
editor.commands.aiTextPrompt({
  text: 'Re-write this text to make it more formal',
  stream: true,
  insert: false,
  format: 'rich-text',
})
```

之后，你可以使用 `aiAccept`、`aiReject` 和 `aiRegenerate` 命令。

### `aiAccept`

此命令用于用户接受 AI 响应时调用。默认情况下，它会将响应插入编辑器；具体行为会根据提供的选项而变化。

| key      | type                                     | definition                                                                                                                                                                                                               |
| -------- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| insertAt | `number \| { from: number, to: number }` | 如果值为 `number`，则接受响应并将其插入编辑器开头。如果值为 `{ from: number, to: number }`，则接受响应，并用 AI 响应替换从 from 位置到 to 位置的内容 |
| append   | `boolean`                                | 如果为 `true`，则不替换当前选区，而是将响应追加到选区内容后                                                                                                                                                              |

未提供任何选项时，默认会接受响应并将其插入编辑器，替换当前选区。

```ts
// Accept the response and insert it into the editor
editor.commands.aiAccept()

// Accept the response and insert it into the editor at the start
editor.commands.aiAccept({ insertAt: 0 })

// Accept the response and insert it into the editor at the end
editor.commands.aiAccept({ insertAt: editor.state.doc.content.size })

// Accept the response and append it to the current selection
editor.commands.aiAccept({ append: true })
```

### `aiRegenerate`

当用户想要重新生成 AI 响应时，可以调用此命令。它会使用上一次 AI 文本操作的所有相同选项，并将响应添加到 `editor.storage.ai.pastResponses` 数组中。

| key      | type                                     | definition                                                                                                                                                                                                                                                                                                                   |
| -------- | ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| insert   | `boolean`                                | 是否将重新生成的响应插入编辑器                                                                                                                                                                                                                                                                                               |
| insertAt | `number \| { from: number, to: number }` | 如果未指定，重新生成的响应会插入到上一个响应所在的位置。如果值为 `number`，则重新生成响应并将其插入编辑器开头。如果值为 `{ from: number, to: number }`，则重新生成响应，并用 AI 响应替换从 from 位置到 to 位置的内容 |

未提供任何选项时，默认会重新生成响应并将其插入编辑器，替换当前选区。

```ts
// Regenerate the response and insert it into the editor
editor.commands.aiRegenerate()

// Regenerate the response and insert it into the editor at the start
editor.commands.aiRegenerate({ insertAt: 0 })

// Regenerate the response and insert it into the editor at the end
editor.commands.aiRegenerate({ insertAt: editor.state.doc.content.size })

// Regenerate the response and append it to the current selection
editor.commands.aiRegenerate({ append: true })
```

### `aiReject`

当用户拒绝 AI 响应时，可以调用此命令。它会将扩展状态重置为初始的空闲状态，并清空所有 `editor.storage.ai.pastResponses`。

| key  | type               | definition                                                                                          |
| ---- | ------------------ | --------------------------------------------------------------------------------------------------- |
| type | 'reset' \| 'pause' | 是否将 AI 重置为空闲状态，或仅暂停当前响应。默认为 `'reset'` |

```ts
editor.commands.aiReject()

// Will not clear out editor.storage.ai, useful for keeping current response in the editor storage
editor.commands.aiReject({ type: 'pause' })
```

## 高级示例（预览 AI 响应）

扩展存储的一种用途是渲染 AI 生成内容的预览。`tryParseToTiptapHTML` 函数会利用编辑器的 schema 生成 AI 响应的 HTML 预览。

```tsx
// Display the response as HTML
import { tryParseToTiptapHTML } from '@tiptap-pro/extension-ai'

// try to parse the current message as HTML, and null if it could not be parsed
tryParseToTiptapHTML(editor.storage.ai.response, editor)

// try to parse a previous response as HTML, and null if it could not be parsed
tryParseToTiptapHTML(editor.storage.ai.pastResponses[0], editor)

// For example in React
function PreviewComponent({ editor }) {
  const htmlResponse = tryParseToTiptapHTML(editor.storage.ai.response, editor)
  /* This is safe since we've parsed the content with prose-mirror first */
  return <div dangerouslySetInnerHTML={{ __html: htmlResponse }}></div>
}
```

## 与协作功能搭配使用

将 Basic AI Generation 与 [Tiptap Collaboration](/collaboration/getting-started/overview) 搭配使用时，通过 `insert: false` 存储的响应仅对发起请求的用户可见。其他用户在使用 `aiAccept()` 接受响应之前看不到这些内容，因此你可以先预览和审核 AI 内容，再与团队共享。
