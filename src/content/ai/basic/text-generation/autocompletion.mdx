启用自动补全后，系统会使用你已输入文本中的一部分来生成建议。

输入时只需按 `Tab` 键即可触发自动补全。再次按 `Tab` 键即可接受补全建议。

想要查看实际效果？在此演示中的任意一行文本后按下 `Tab` 键即可。

## 配置自动补全

集成 Basic AI Generation 扩展时，你可以指定是否启用自动补全、自动补全功能的行为，以及需要参考的上下文。

| 设置                    | 类型      | 默认值                                                                                       | 说明                                                                                                                                                                                                                                                   |
| ----------------------- | --------- | --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `autocompletion`        | `boolean` | `false`                                                                                       | 启用自动补全功能。输入文本时，按 **Tab** 键触发自动补全，再按一次 **Tab** 键接受补全内容。系统会使用你已输入文本中的一部分来构建 OpenAI 提示词。                         |
| `autocompletionOptions` | `object`  | `{ trigger: 'Tab', accept: 'Tab', debounce: 0, inputLength: 4000, modelName: 'gpt-4o-mini' }` | 定义用于生成自动补全建议的触发方式和文本长度。如果未显式设置，接受补全的按键默认为触发按键。触发后，可设置请求的防抖时间（毫秒）。你还可以选择用于自动补全任务的 OpenAI 模型。 |

如需查看 Basic AI Generation 扩展的其他配置选项，请参阅[安装](/ai/basic/install#configure-the-extension)页面。

## 启用自动补全

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import Ai from '@tiptap-pro/extension-ai'

const editor = new Editor({
  extensions: [
    StarterKit,
    Ai.configure({
      token: 'TOKEN_HERE',
      autocompletion: true,
      // … other options (see above)
    }),
    // … more extensions
  ],
})
```

## 与协作功能配合使用

将自动补全与 [Tiptap Collaboration](/collaboration/getting-started/overview) 配合使用时，建议内容对每位用户都是私有的，只有在接受建议后，其他用户才能看到这些内容。
