Tiptap Editor 的基础 AI 生成扩展包含一组预配置命令，可集成到富文本编辑器中。这些命令可以调整文本语气、续写文本、生成图像等，从而增强编辑器的功能。

如需了解如何使用这些命令，请查看[概览](/ai/basic/overview)页面中的示例。

| 命令                                                                                                                         | 说明                                                                                                                          |
| ------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| [`aiAdjustTone(tone: Tone, options: TextOptions)`](#aiadjusttone)                                                               | 将所选文本的语气调整为指定的[语气](#aiadjusttone)。                                                     |
| [`aiBloggify(options: TextOptions)`](#most-text-commands)                                                                       | 将文本改写为博客形式                                                                                                  |
| [`aiComplete(options: TextOptions)`](#most-text-commands)                                                                       | 补全所选文本                                                                                                          |
| [`aiDeEmojify(options: TextOptions)`](#most-text-commands)                                                                      | 移除所选文本中的表情符号                                                                                                |
| [`aiEmojify(options: TextOptions)`](#most-text-commands)                                                                        | 为文本添加表情符号 ✨                                                                                                          |
| [`aiExtend(options: TextOptions)`](#most-text-commands)                                                                         | 扩展文本                                                                                                                    |
| [`aiFixSpellingAndGrammar(options: TextOptions)`](#most-text-commands)                                                          | 修正拼写和语法                                                                                                             |
| [`aiKeypoints(options: TextOptions)`](#most-text-commands)                                                                      | 将文本概括为要点列表                                                                                         |
| [`aiRephrase(options: TextOptions)`](#most-text-commands)                                                                       | 改写所选文本                                                                                                          |
| [`aiRestructure(options: TextOptions)`](#most-text-commands)                                                                    | 重新组织所选文本，并使用富文本格式                                                                           |
| [`aiShorten(options: TextOptions)`](#most-text-commands)                                                                        | 缩短所选文本                                                                                                           |
| [`aiSimplify(options: TextOptions)`](#most-text-commands)                                                                       | 使用简明的措辞改写文本                                                                                              |
| [`aiSummarize(options: TextOptions)`](#most-text-commands)                                                                      | 总结文本                                                                                                                 |
| [`aiTextPrompt(options: TextOptions)`](#most-text-commands)                                                                     | 执行自定义提示词                                                                                                              |
| [`aiTldr(options: TextOptions)`](#most-text-commands)                                                                           | 创建文本的“太长不看”版本                                                                                       |
| [`aiTranslate(language: Language, options: TextOptions)`](#aitranslate)                                                         | 将所选文本翻译为指定语言                                                                             |
| **实用工具**                                                                                                                     |
| [`aiAccept(options: AcceptOptions)`](/ai/basic/text-generation/manage-responses#aiaccept)             | [接受生成的响应](/ai/basic/text-generation/manage-responses)，并将其插入编辑器 |
| [`aiReject(options: RejectOptions)`](/ai/basic/text-generation/manage-responses#aireject)             | [拒绝生成的响应](/ai/basic/text-generation/manage-responses)，并重置 ai.storage 状态    |
| [`aiRegenerate(options: RegenerateOptions)`](/ai/basic/text-generation/manage-responses#airegenerate) | 使用相同参数[重新生成响应](/ai/basic/text-generation/manage-responses)              |

### 大多数文本命令

大多数文本命令接受相同的选项，用法也类似。以下示例展示了如何使用 `aiBloggify` 命令：

```js
editor.chain().focus().aiBloggify(options: TextOptions)
```

### aiAdjustTone

```js
// Tone: 'default' | 'academic' | 'business' | 'casual' | 'childfriendly' | 'confident' | 'conversational' | 'creative' | 'emotional' | 'excited' | 'formal' | 'friendly' | 'funny' | 'humorous' | 'informative' | 'inspirational' | 'memeify' | 'narrative' | 'objective' | 'persuasive' | 'poetic' | string
editor.chain().focus().aiAdjustTone(tone: Tone, options: TextOptions).run()
```

### aiTranslate

将所选文本内容翻译为指定的目标语言。

该命令接受 ISO 639-1 双字母语言代码。

```js
// Language: 'en' | 'de' | 'nl' | ...
editor.chain().focus().aiTranslate(language: Language, options: TextOptions).run()
```

## 文本命令选项

对于支持 `TextOptions` 的命令，可以指定以下选项：

| 设置          | 类型                                                                   | 默认值                                       | 定义                                                                                                                                                                                                                 |
| ---------------- | ---------------------------------------------------------------------- | --------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `modelName`      | 参见[支持的文本模型](#supported-text-models)                    | `gpt-6-luna`（AI Server 4.3.0+） | OpenAI 使用的模型                                                                                                                                                                                                   |
| `format`         | `'rich-text' \| 'plain-text'`                                          | `plain-text`                                  | 决定模型响应的[格式](/ai/basic/text-generation/format)                                        |
| `stream`         | `boolean`                                                              | `false`                                       | 是否将生成的字符流式输出到编辑器？类似于 ChatGPT 的**打字机**效果。**此功能需要使用最新版本的扩展！**                                                                      |
| `insertAt`       | `undefined \| number \| {from: number; to: number}`                    | `undefined`                                   | 在编辑器中的插入位置。如果为 `undefined`，响应将插入当前选区；如果为数字，则插入该位置；如果为对象，则替换对应范围。 |
| `language`       | `string`（例如 `en`、`de`）                                             | `null`                                        | 虽然我们会尽力提示 OpenAI 使用输入内容的语言作答，但有时最好自行指定。                                                                                         |
| `tone`           | `string`                                                               | `null`                                        | 响应应调整为的[语气](#aiadjusttone)                                                                                                                                                   |
| `textLength`     | `number`                                                               | `undefined`                                   | AI 响应应包含的 `textLengthUnit` 数量（例如“3 个段落”中的 `3`）                                                                                                                                |
| `textLengthUnit` | `'paragraphs' \| 'words' \| 'characters'`                              | `undefined`                                   | AI 响应长度所用的单位（例如“3 个段落”中的 `paragraphs`）                                                                                                                             |
| `collapseToEnd`  | `boolean`                                                              | `true`                                        | 操作完成后是否将光标移至末尾，还是选中插入的内容。                                                      |
| `context`        | `Array<{ type: 'text', text: string} \| { type: 'url', url: string }>` | `[]`                                          | 为模型生成响应提供的[上下文](/ai/basic/text-generation/provide-context)。                                                                                             |
| `text`           | `string`                                                               | `undefined`                                   | 可选消息，供模型据此作答                                                                                                                                                                           |
| `insert`         | `boolean`                                                              | `true`                                        | 可用于禁用直接向编辑器插入内容                                                                                                                                                                |
| `append`         | `boolean`                                                              | `true`                                        | 如果为 `true`，响应将追加到当前选区末尾；如果为 `false`，则替换当前选区。                                                                                 |
| `regenerate`     | `boolean`                                                              | `false`                                       | 命令是否重新生成先前生成的响应。如果设为 `true`，则不会更新 `initialContent` 属性。                                                                             |

_遗憾的是，**语气**和**语言**组合使用时，有时会导致响应未使用期望的语言。_

## 选择合适的模型

配置 Tiptap AI 扩展时，请考虑应用的具体需求：

- **注重成本效益：**如果主要考虑预算，且任务不需要最先进的能力，请选择 GPT-5 mini。
- **有更高要求：**如果应用需要出色的语言理解能力或图像生成质量，且预算限制较少，请选择 GPT-5。

Tiptap AI 扩展支持灵活配置，可根据具体需求和预算调整 AI 集成方案。
