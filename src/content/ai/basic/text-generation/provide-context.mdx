使用 `context` 选项，你可以向 AI 模型提供更多信息，帮助它生成更相关的内容。如果你希望生成的内容更贴合对话上下文，这会很有用。

<CodeDemo isPro path="/Extensions/AiContext" />

## Context 选项

可以通过 `text` 和 `url` 两种格式提供上下文。`text` 格式用于向 AI 模型提供额外的文本上下文，`url` 格式则用于提供 URL 上下文。

<Callout title="URL 要求" variant="warning">
    提供的 URL 必须有效，并且 Tiptap Basic AI Generation 能够访问。如果你希望向 AI 模型提供来自第三方来源的额外上下文，这种方式会很有用。
</Callout>

```ts
// Steams the response as rich text into the editor
editor
  .chain()
  .aiTextPrompt({
    text: 'What does Alice do for a living?',
    stream: true,
    format: 'rich-text',
    context: [
      { type: 'text', text: 'John & Alice are a software engineers.' },
      { type: 'url', url: 'https://company.example.com/team' },
    ],
  })
  .run()
```
