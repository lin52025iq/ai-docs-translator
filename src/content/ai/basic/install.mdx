## 启动基础 AI 生成应用
1. **激活方案：** 开始[免费试用或选择订阅方案](https://cloud.tiptap.dev/v2/billing)。
2. **配置 AI 应用。** 将 OpenAI API 密钥添加到[你的应用](https://cloud.tiptap.dev/v2/cloud/ai)中。
3. **设置身份验证：** 使用 `aud: "AI"` 和 `AI:Generation` 权限对令牌进行签名，然后将其传递给扩展。有关令牌签名方法，请参阅[身份验证](/authentication)。

## 访问私有注册表
基础 AI 生成扩展发布在 Tiptap 的私有 npm 注册表中。请按照[私有注册表指南](/guides/pro-extensions)集成此扩展。如果你已完成 Tiptap 账户身份验证，可以直接跳转到 [#安装](#install)。

## 安装

```bash
npm install @tiptap-pro/extension-ai
```

将扩展集成到编辑器实例中的方式与其他 Tiptap 扩展相同。示例如下：

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import Ai from '@tiptap-pro/extension-ai'

const editor = new Editor({
  extensions: [
    StarterKit,
    Ai.configure({
      // This needs to be your signed token and MUST NOT be the OpenAI API key!
      token: 'TOKEN_HERE',
      autocompletion: true,
      // … other options (see below)
    }),
    // … more extensions
  ],
})
```

现在，你可以在 Tiptap 编辑器中使用 OpenAI 了。请查看[配置选项](/ai/basic/configure)，根据需要自定义使用体验。

之前使用 App ID 和密钥（HS256）的流程仍然有效，相关说明请参阅[旧版身份验证](/authentication/legacy)。
