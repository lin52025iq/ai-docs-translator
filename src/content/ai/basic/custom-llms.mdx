如果你想使用自己的后端来访问自定义 LLM，可以在扩展配置中覆盖下文定义的解析器函数。

请确保返回正确类型的响应，并正确处理错误。

<Callout title="请注意！" variant="hint">
  我们强烈建议不要在前端直接调用 OpenAI，否则可能导致 API 令牌泄露！你应该在后端使用代理来保护 API 令牌。
</Callout>

## 访问私有仓库

高级 AI 扩展发布在 Tiptap 的私有 npm 仓库中。请按照[私有仓库指南](/guides/pro-extensions)集成此扩展。如果你已经登录 Tiptap 账户，可以直接跳转到 [#Install](#install)。

<Callout title="专业版扩展" variant="warning">

    此扩展要求你订阅符合条件的有效套餐，并[有权访问我们的私有仓库](/guides/pro-extensions)。请先完成设置。

</Callout>

```bash
npm install @tiptap-pro/extension-ai
```

### 同时使用自定义 LLM 和 Tiptap AI Cloud

如果你希望在某些情况下使用我们的云服务，请确保已[按照此处的说明设置团队](/ai/basic/install#start-your-basic-ai-generation-app)。

## 解析器函数

你可以在扩展选项中定义自定义解析器函数。请注意，这些函数必须返回以下类型的值。

| 类型 | 方法名 | 返回类型 |
| ---------- | ---------------------- | --------------------------------------------- |
| 补全 | `aiCompletionResolver` | `Promise<string \| null>` |
| 流式 | `aiStreamResolver` | `Promise<ReadableStream<Uint8Array> \| null>` |
| 图像 | `aiImageResolver` | `Promise<string \| null>` |

使用 `aiCompletionResolver` 以非流式方式向编辑器添加文本。

使用 `aiStreamResolver` 将内容直接流式传输到编辑器，从而实现打字机效果。

请确保流返回 HTML，以便 Tiptap 能够将内容直接渲染为富文本。这种方式无需使用 Markdown 解析器，也能让前端保持轻量。

## 示例

### 在补全模式下覆盖特定命令的解析

在此示例中，当调用 `rephrase` 操作/命令时，我们希望调用自定义后端。
其他所有操作都由 Tiptap Cloud 中的默认后端处理。

```js
// ...
import Ai from '@tiptap-pro/extension-ai'
// ...

Ai.configure({
  token: 'TOKEN_HERE',
  // ...
  onError(error, context) {
    // handle error
  },
  // Define the resolver function for completions (attention: streaming and image have to be defined separately!)
  aiCompletionResolver: async ({
    editor,
    action,
    text,
    textOptions,
    extensionOptions,
    defaultResolver,
  }) => {
    // Check against action, text, whatever you like
    // Decide to use custom endpoint
    if (action === 'rephrase') {
      const response = await fetch('https://dummyjson.com/quotes/random')
      const json = await response.json()

      if (!response.ok) {
        throw new Error(`${response.status} ${json?.message}`)
      }

      return json?.quote
    }

    // Everything else is routed to the Tiptap AI service
    return defaultResolver({
      editor,
      action,
      text,
      textOptions,
      extensionOptions,
      defaultResolver,
    })
  },
})
```

### 注册新的 AI 命令并调用自定义后端操作

在此示例中，我们注册一个名为 `aiCustomTextCommand` 的新编辑器命令，使用 Tiptap 的 `runAiTextCommand` 函数处理其余逻辑，并添加自定义命令解析逻辑，以便在补全模式下调用自定义后端。

```js
// …
import { Ai, runAiTextCommand } from '@tiptap-pro/extension-ai'
// …

// Declare typings if TypeScript is used:
//
// declare module '@tiptap/core' {
//   interface Commands<ReturnType> {
//     ai: {
//       aiCustomTextCommand: () => ReturnType,
//     }
//   }
// }

const AiExtended = Ai.extend({
  addCommands() {
    return {
      ...this.parent?.(),

      aiCustomTextCommand:
        (options = {}) =>
        (props) => {
          // Do whatever you want; e.g. get the selected text and pass it to the specific command resolution
          return runAiTextCommand(props, 'customCommand', options)
        },
    }
  },
})

// … this is where you initialize your Tiptap editor instance and register the extended extension

const editor = new Editor({
  extensions: [
    /* … add other extension */
    AiExtended.configure({
      /* … add configuration here (token etc.) */
      onError(error, context) {
        // handle error
      },
      aiCompletionResolver: async ({
        action,
        text,
        textOptions,
        extensionOptions,
        defaultResolver,
        editor,
      }) => {
        if (action === 'customCommand') {
          const response = await fetch('https://dummyjson.com/quotes/random')
          const json = await response.json()

          if (!response.ok) {
            throw new Error(`${response.status} ${json?.message}`)
          }

          return json?.quote
        }

        return defaultResolver({
          editor,
          action,
          text,
          textOptions,
          extensionOptions,
          defaultResolver,
        })
      },
    }),
  ],
  content: '',
})

// … use this to run your new command:
// editor.chain().focus().aiCustomTextCommand().run()
```

### 在流式模式下使用自定义后端

此示例完全依赖自定义后端。

请确保 `aiStreamResolver` 函数返回 `ReadableStream<Uint8Array>`。

还要记住：如果你想同时使用流式模式和传统的补全模式（非流式），还需要定义 `aiCompletionResolver`！

```js
// ...
import Ai from '@tiptap-pro/extension-ai'
// ...

Ai.configure({
  token: 'TOKEN_HERE',
  // ...
  onError(error, context) {
    // handle error
  },
  // Define the resolver function for streams
  aiStreamResolver: async ({ action, text, textOptions }) => {
    const fetchOptions = {
      method: 'POST',
      headers: {
        accept: 'application/json',
        'content-type': 'application/json',
      },
      body: JSON.stringify({
        ...textOptions,
        text,
      }),
    }

    const response = await fetch(`<YOUR_STREAMED_BACKEND_ENDPOINT>`, fetchOptions)

    if (!response.ok) {
      const json = await response.json()
      throw new Error(`${json?.error} ${json?.message}`)
    }

    return response.body
  },
})
```
