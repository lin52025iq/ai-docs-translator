使用 AI 生成图像并将其插入文档。

## 安装 Image 扩展

将 [`@tiptap/extension-image`](/editor/extensions/nodes/image) 扩展添加到编辑器中。

```js
import Image from '@tiptap/extension-image'
import { Editor } from '@tiptap/core'

const editor = new Editor({
  extensions: [Image],
})
```

## 在服务器上生成图像

通过服务器端路由调用 OpenAI API，以免 API 密钥暴露给浏览器。使用图像生成模型，例如 `gpt-image-2`。

然后，将生成的图像存储到应用使用的存储服务中，例如 S3、R2、Supabase Storage 或自有媒体服务。将存储后的图像 URL 返回给客户端。

<Callout title="避免将图像存储为 base64" variant="warning">
  不建议将生成的图像以 base64 格式存储在文档中，尤其是在协作文档中。Base64 图像会显著增大文档体积、拖慢同步速度，还会增加处理协作更新的成本。
</Callout>

```js
import OpenAI from 'openai'

const openai = new OpenAI()

export async function POST(request) {
  const { prompt } = await request.json()

  const result = await openai.images.generate({
    model: 'gpt-image-2',
    prompt,
    size: '1024x1024',
  })

  const imageBuffer = Buffer.from(result.data[0].b64_json, 'base64')
  const imageSrc = await uploadImageToStorage(imageBuffer, {
    contentType: 'image/png',
    fileName: `generated-${Date.now()}.png`,
  })

  return Response.json({
    imageSrc,
  })
}
```

`uploadImageToStorage` 函数的实现取决于你的应用。它应将图像数据上传到存储服务，并返回一个可供编辑器显示的 URL。

## 插入生成的图像

从客户端调用服务器路由，并将返回的图像源传递给 `setImage`。

```js
async function generateAndInsertImage(prompt) {
  const response = await fetch('/api/generate-image', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({ prompt }),
  })

  const { imageSrc } = await response.json()

  editor.commands.setImage({ src: imageSrc })
}
```

插入图像时，你还可以添加其他属性。请参阅[所有可用选项列表](/editor/extensions/nodes/image)。

```js
editor.commands.setImage({
  src: imageSrc,
  alt: prompt,
  title: prompt,
})
```
