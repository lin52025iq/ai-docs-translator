AI Changes 扩展在设计时充分考虑了灵活性。作为一个无头库，它让你可以完全控制更改在编辑器中的显示方式。

## 默认样式

默认情况下，AI Changes 扩展会应用 CSS 类来突出显示已修改的内容：

- `tiptap-ai-changes--old` 用于已删除的文本
- `tiptap-ai-changes--new` 用于已插入的文本

该扩展不包含任何内置样式，因此你需要自行定义 CSS。下面是一个用于突出显示更改的基础样式完整示例：

```css
:root {
  --color-green-100: oklch(0.962 0.044 156.743);
  --color-green-700: oklch(0.527 0.154 150.069);
  --color-red-100: oklch(0.936 0.032 17.717);
  --color-red-700: oklch(0.505 0.213 27.518);
}

.tiptap-ai-changes--old,
.tiptap-ai-changes--old > * {
  color: var(--color-red-700);
  background-color: var(--color-red-100);
}

.tiptap-ai-changes--new,
.tiptap-ai-changes--new > * {
  color: var(--color-green-700);
  background-color: var(--color-green-100);
}
```

这会为已删除的文本添加红色背景，为已插入的文本添加绿色背景。

如需使用更高级的样式，请使用 `getCustomDecorations` [配置选项](/ai/deprecated/changes/configure#custom-styles)。

## 选中的更改

当选区光标位于某项更改上时，该更改即被视为“选中”。

你可以通过扩展的存储对象获取选中的更改：

```ts
const storage = editor.extensionStorage.aiChanges
const selectedChange = storage.getSelectedChange()
```

如需通过编程方式选中某项更改，请使用 `selectAiChange` 命令。

```ts
editor.commands.selectAiChange(changeId)
```

此命令会将光标移至更改的开头，使其被视为“选中”。

你可以在 `getCustomDecorations` 函数中引用选中更改的文本，并为其应用自定义样式。

## 自定义更改的外观

`getCustomDecorations` 选项可用于控制更改的外观，并为用户提供视觉提示。

它会接收以下参数：

- `change`：包含更改信息的更改对象。
- `changes`：所有受跟踪更改的列表。
- `isSelected`：一个布尔值，表示该更改是否已选中。光标位于更改上时，该更改即被选中。
- `getDefaultDecorations`：返回该更改默认装饰的函数。如果未提供 `getCustomDecorations` 函数，则会使用默认装饰。
- `editor`：Tiptap Editor 实例。
- `previousDoc`：AI 做出更改之前的文档。通过将当前文档与此文档进行比较来获取更改。
- `currentDoc`：AI 做出更改之后的文档。

```ts
AiChanges.configure({
  getCustomDecorations({ change, isSelected, getDefaultDecorations }) {
    // You can combine the default decorations of the AI Changes extension with your custom ones
    const decorations = getDefaultDecorations()

    // Add a custom element after the inserted text of the change
    decorations.push(
      Decoration.widget(change.newRange.to, () => {
        const element = document.createElement('span')

        element.textContent = '✅'
        return element
      }),
    )
    return decorations
  },
})
```

自定义样式和元素通过 [Prosemirror Decorations API](https://prosemirror.net/docs/ref/#view.Decorations) 实现。

要了解如何在选中更改时显示弹出框，请参阅[本指南](/ai/deprecated/changes/features/display-changes#show-a-popover-when-a-change-is-selected)。

## 选中更改时显示弹出框

在大多数用户审核工作流中，你需要在选中的更改上方显示弹出框或工具提示，并提供接受或拒绝更改的操作。

要在选中更改时显示弹出框，请使用 `getCustomDecorations` 选项。它允许你向更改添加自定义元素，包括弹出框。

下面是一个使用 React 的简化示例：

```tsx
// First, define a hook to store the HTML element where the popover will be rendered
const [popoverElement, setPopoverElement] = useState<HTMLElement | null>(null)

AiChanges.configure({
  getCustomDecorations({ change, isSelected, getDefaultDecorations }) {
    const decorations = getDefaultDecorations()

    // Then, create a Prosemirror decoration that contains the HTML element
    // Add a custom element after the inserted text when the change is selected
    if (isSelected) {
      decorations.push(
        Decoration.widget(change.newRange.to, () => {
          const element = document.createElement('span')

          setPopoverElement(element)
          return element
        }),
      )
    }
    return decorations
  },
})

const selectedChange = editor.extensionStorage.aiChanges.getSelectedChange()
if (popoverElement && selectedChange) {
  // Then, add the HTML content to the custom element. In this example, we use React Portals to render the popover.
  ReactDOM.createPortal(<Popover change={selectedChange} />, popoverElement)
}
```

我们建议使用 [Floating UI](https://floating-ui.com/) 库来显示弹出框。你可以在[演示](/ai/deprecated/changes/overview)中查看示例。

## 在编辑器外部的侧边栏中显示更改

你可以通过扩展的[存储对象](/ai/deprecated/changes/api-reference#extension-storage)访问更改数据：

```ts
const storage = editor.extensionStorage.aiChanges
const changes = storage.getChanges()
```

然后，使用这些数据来渲染自定义 UI 组件。下面是一个使用 React 的示例：

```tsx
// Get the changes from the Editor state.
const storage = editor.extensionStorage.aichange
const changes = storage.getchanges()

// Render the changes in the UI
return (
  <div>
    {changes.map((change) => (
      <div key={change.id}>
        <button onClick={() => editor.commands.acceptAiChange(change.id)}>Accept</button>
        <button onClick={() => editor.commands.rejectAiChange(change.id)}>Reject</button>
      </div>
    ))}
  </div>
)
```

## 隐藏和显示更改

在某些情况下，你可能希望继续跟踪更改，但在 UI 中将其隐藏。例如，在流式传输 AI 生成的内容时。你可以使用 `setShowAiChanges` 命令，通过编程方式隐藏或显示更改。

```ts
// Hide changes
editor.commands.setShowAiChanges(false)

// Show changes
editor.commands.setShowAiChanges(true)
```

这只会影响更改的视觉显示——跟踪机制仍会在后台运行，并且仍可通过扩展的存储方法访问所有更改。
