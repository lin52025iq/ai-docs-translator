借助 AI Changes 扩展，您可以为 AI 生成的内容引入审阅工作流，让用户校正并批准 AI 所做的更改。

## 开始跟踪更改

要开始跟踪更改，请使用 `startTrackingAiChanges` 命令。

```ts
editor.commands.startTrackingAiChanges()
```

该命令会在执行时为编辑器内容创建快照。从此之后，文档中的所有新更改都会与此快照进行比较，并显示在编辑器中。

最常见的做法是在生成 AI 内容之前立即调用 `startTrackingAiChanges`。这样可以捕获所有 AI 生成的更改以供审阅。例如，您可以将它与 [Basic AI Generation 扩展命令](/ai/basic/text-generation/built-in-commands) 链式调用：

```ts
editor
  .chain()
  .startTrackingAiChanges()
  .aiTextPrompt({ text: 'Write a blog post about Tiptap' })
  .run()
```

您可以通过扩展存储对象的 `getPreviousDoc` 方法访问先前文档的快照：

```ts
const storage = editor.extensionStorage.aiChanges
const previousDoc = storage.getPreviousDoc()
```

此方法会返回一个表示先前文档的 [ProseMirror Node 对象](https://prosemirror.net/docs/ref/#model.Node)。

调用 `startTrackingAiChanges` 命令时，可以选择传入一个先前文档。如果您想将新更改与不同于编辑器当前文档的文档进行比较，这会很有用。

```ts
editor.commands.startTrackingAiChanges(previousDoc)
```

## 访问更改数据

AI Changes 扩展提供了多种扩展存储方法，用于获取跟踪中的更改：

- `getChanges`：返回自上次调用 `startTrackingAiChanges` 以来对文档所做的所有更改。
- `getSelectedChange`：返回当前选中的更改。当光标位于某项更改上时，该更改即为选中状态。
- `getIsTrackingAiChanges`：返回一个布尔值，指示编辑器当前是否正在跟踪 AI 更改。
- `getIsShowingAiChanges`：返回一个布尔值，指示编辑器当前是否正在显示 AI 更改。您可以使用 `setShowAiChanges` 命令[临时隐藏 AI 更改](/ai/deprecated/changes/features/display-changes#hide-and-show-changes)。
- `getPreviousDoc`：返回 AI 进行更改之前的文档。如果扩展当前未跟踪更改，则返回 `null`。

如需了解如何使用这些方法在编辑器中显示更改，请参阅[显示 AI 更改](/ai/deprecated/changes/features/display-changes)指南。

## 接受和拒绝更改

AI Changes 扩展提供了多个用于审阅更改的命令。

要接受某项更改，请调用 `acceptAiChange` 命令。该命令会修改先前文档的快照，将这项更改纳入其中。

```ts
editor.commands.acceptAiChange(changeId)
```

要拒绝某项更改，请调用 `rejectAiChange` 命令。该命令会修改当前编辑器内容，使该更改范围内的内容与先前文档一致。

```ts
editor.commands.rejectAiChange(changeId)
```

要接受所有 AI 更改，请使用 `acceptAllAiChanges` 命令。

```ts
editor.commands.acceptAllAiChanges()
```

要拒绝所有 AI 更改，请使用 `rejectAllAiChanges` 命令。

```ts
editor.commands.rejectAllAiChanges()
```

## 停止跟踪更改

最后，要停止跟踪 AI 更改，请运行 `stopTrackingAiChanges` 命令。该命令会移除先前文档的快照并停止跟踪更改。

```ts
editor.commands.stopTrackingAiChanges()
```

先前文档的快照将被设为 `null`，编辑器也不再显示 AI 所做的更改。

如需进一步了解 AI Changes 扩展命令，请参阅 [API 参考](/ai/deprecated/changes/api-reference)。
