AI Changes 扩展通过我们的私有注册表以 npm 包的形式提供。按照以下步骤在项目中进行设置。

## 安装扩展

AI Changes 扩展发布在 Tiptap 的私有 npm 注册表中。请按照[私有注册表指南](/guides/pro-extensions)集成此扩展。

## 初始化扩展

像集成其他 Tiptap 扩展一样，将 AI Changes 集成到编辑器实例中。以下是一个实现示例：

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import AiChanges from '@tiptap-pro/extension-ai-changes'

const editor = new Editor({
  extensions: [
    StarterKit,
    AiChanges,
    // … more extensions
  ],
})
```

你还需要设置 CSS 样式，以便在编辑器中显示更改。

```css
:root {
  --color-green-100: oklch(0.962 0.044 156.743);
  --color-green-700: oklch(0.527 0.154 150.069);
  --color-red-100: oklch(0.936 0.032 17.717);
  --color-red-700: oklch(0.505 0.213 27.518);
}

.tiptap-ai-changes--old,
.tiptap-ai-changes--old > * {
  color: var(--color-red-700);
  background-color: var(--color-red-100);
}

.tiptap-ai-changes--new,
.tiptap-ai-changes--new > * {
  color: var(--color-green-700);
  background-color: var(--color-green-100);
}
```

## 开始跟踪更改

要开始跟踪更改，请调用 `startTrackingAiChanges` 命令。该命令会创建当前编辑器内容的快照，并将其与 AI 生成的新内容进行比较。

```ts
editor.commands.startTrackingAiChanges()
```

调用此命令后，对编辑器内容所做的任何修改（无论是手动进行，还是通过 [Basic AI Generation](/ai/basic/overview) 扩展进行）都会被跟踪，并作为更改显示。

## 接受或拒绝更改

此扩展提供了多个用于审核更改的命令：

```ts
// Accept a specific change
editor.commands.acceptAiChange(changeId)

// Reject a specific change
editor.commands.rejectAiChange(changeId)

// Accept all changes
editor.commands.acceptAllAiChanges()

// Reject all changes
editor.commands.rejectAllAiChanges()
```

## 停止跟踪更改

完成更改审核后，调用 `stopTrackingAiChanges` 命令以结束跟踪会话：

```ts
editor.commands.stopTrackingAiChanges()
```

此命令会移除先前文档的快照，并停止显示更改高亮。

有关审核、接受和拒绝更改的详细信息，请参阅[内容审核指南](/ai/deprecated/changes/features/review-changes)。
