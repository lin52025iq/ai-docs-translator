Tiptap 的 AI Changes 扩展提供了多种配置选项，可自定义其外观和行为。

## 自定义样式

`getCustomDecorations` 函数可用于控制更改文本的外观。你可以为文本应用自定义 CSS 类，并在文本前后添加自定义元素。这适用于显示弹出框、工具提示或图标。

该函数接收以下参数：

- `change`：当前更改对象，包含已修改内容的信息
- `changes`：文档中检测到的所有更改列表
- `isSelected`：布尔值，表示当前更改是否处于选中状态（光标位于其中）
- `getDefaultDecorations`：返回当前更改默认装饰的函数。如果未提供 `getCustomDecorations` 函数，则使用默认装饰。
- `editor`：Tiptap Editor 实例
- `previousDoc`：AI 更改之前的文档快照
- `currentDoc`：AI 更改后的当前文档

```ts
AiChanges.configure({
  getCustomDecorations({ change, isSelected, getDefaultDecorations }) {
    // 你可以将 AI Changes 扩展的默认装饰与自定义装饰结合使用
    const decorations = getDefaultDecorations()

    // 选中更改时，在插入的文本后添加自定义元素
    if (isSelected) {
      decorations.push(
        Decoration.widget(change.newRange.to, () => {
          const element = document.createElement('span')
          element.textContent = '✅'
          return element
        }),
      )
    }
    return decorations
  },
})
```

自定义样式和元素通过 [Prosemirror Decorations API](https://prosemirror.net/docs/ref/#view.Decorations) 实现。

若要在选中更改时显示弹出框，请参阅[本指南](/ai/deprecated/changes/features/display-changes#show-a-popover-when-a-change-is-selected)。
