使用 Tiptap Cloud 是开始使用 AI Agent 扩展的最快方式。它提供托管式、开箱即用的 AI 代理。

## 启动 Content AI 应用

1. **激活套餐：** 开始[免费试用或选择订阅套餐](https://cloud.tiptap.dev/v2/billing)。
2. **配置 AI 应用：** 将 OpenAI API 密钥添加到你的 [Content AI 应用](https://cloud.tiptap.dev/v2/cloud/ai)中。
3. **设置身份验证：** 使用 `aud: "AI"` 和 `AI:Generation` 权限对令牌进行签名，然后将其传递给扩展。请参阅[身份验证](/authentication)。

## 将身份验证凭据添加到扩展

使用 `AiAgentProvider` 类连接到 Tiptap Cloud。它负责与 Tiptap Cloud 通信，并管理 AI 代理的状态。

```tsx
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import AiAgent, { AiAgentProvider } from '@tiptap-pro/extension-ai-agent'

const provider = new AiAgentProvider({
  // Your generated JWT. It MUST NOT be the OpenAI API key!
  token: 'TOKEN_HERE',
  // ... Other options
})
```

使用 `AiAgentProvider` 向 AI 代理发送消息时，系统会调用 Tiptap Cloud API 获取 AI 代理的响应。随后，AI 代理会生成聊天消息并编辑文档，以完成用户的任务。

## 自定义 OpenAI 模型

你可以通过设置 `modelName` 选项，自定义 Tiptap Cloud 使用的 OpenAI 模型。AI Agent 扩展搭配 `gpt-4.1` 模型的效果最佳，因为它在复杂文档编辑任务中性能最优。请注意，模型必须支持[函数调用](https://platform.openai.com/docs/guides/function-calling)。

```tsx
const provider = new AiAgentProvider({
  modelName: 'gpt-4.1',
})
```
