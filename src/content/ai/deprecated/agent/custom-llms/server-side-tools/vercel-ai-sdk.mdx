本指南介绍如何使用 [Vercel AI SDK](https://ai-sdk.dev) 调用服务端工具，并演示一个可返回指定位置天气信息的工具。

首先，按照 [Vercel AI SDK 工具格式](https://ai-sdk.dev/docs/ai-sdk-core/tools-and-tool-calling)定义工具：

```ts
import { z } from 'zod'
import { tool } from 'ai'

const weatherTool = tool({
  description: 'Get the weather in a location',
  parameters: z.object({
    location: z.string().describe('The location to get the weather for'),
  }),
  execute: async (args) => {
    // Get weather from an external API
    const result = await getWeather(args)
    return result
  },
})
```

然后，调用 Vercel AI SDK 时，将该工具包含在 `tools` 对象中。

请务必将 `maxSteps` 设置为大于 1 的值，以启用[多步工具调用](https://ai-sdk.dev/docs/ai-sdk-core/tools-and-tool-calling#multi-step-calls-using-maxsteps)。此参数允许 AI 按顺序调用多个工具。例如，它可以先调用工具获取天气报告，再调用另一个工具将相关信息写入文档。

<Callout title="与 Vercel AI SDK v4 搭配使用" variant="info">
  若要使用 Vercel AI SDK v4 而非 v5，请导入 `vercelAiSdkV4Adapter`，而不是
  `vercelAiSdkAdapter`。
</Callout>

```ts
import {
  AiAgentToolkit,
  vercelAiSdkAdapter,
  ChatMessagesFormatter,
} from '@tiptap-pro/extension-ai-agent-server'
import { generateText } from 'ai'
import { openai } from '@ai-sdk/openai'

const { chatMessages, schemaAwarenessData } = request

const toolkit = new AiAgentToolkit({
  adapter: vercelAiSdkAdapter,
  schemaAwarenessData,
})

const formatter = new ChatMessagesFormatter({
  // Get the chat messages from the request body
  initialMessages: chatMessages,
  adapter: vercelAiSdkAdapter,
})

// Call the Vercel AI SDK
const response = await generateText({
  model: openai('gpt-4.1'),
  messages: [
    {
      role: 'system',
      content: `
<Your system prompt>
${toolkit.getSystemPrompt()}
`,
    },
    ...formatter.format(),
  ],
  // Include the weather tool in the tools object, beside
  // the other tools provided by AiAgentToolkit
  tools: {
    ...toolkit.format(),
    get_weather: weatherTool,
  },
  // Enable multi-step tool calls
  maxSteps: 5,
})
```

然后，将响应添加到格式化器中，使其包含在对话中。

```ts
formatter.addAiResponse(response)
```

最后，使用 `formatter` 将响应转换为 AI Agent 扩展所需的格式。

```ts
const response = formatter.getResolverResponse()
```

`formatter.getResolverResponse()` 返回的值应作为 API 端点的响应，也是 resolver 函数的返回值。
