工具是构建 AI 代理的基础。它们定义了 AI 模型可以采取哪些操作来与其环境交互。

Tiptap AI Agent 扩展提供了一组内置工具，让 AI 代理能够读取和编辑富文本文档。

虽然 AI Agent 扩展提供了一组内置工具，但你也可以[定义自定义工具](#custom-tools)，扩展 AI 代理的功能。

## 内置工具

### `read_first_chunk`

从头开始读取当前文档。

### `read_next_chunk`

读取文档的下一个区块。

### `read_previous_chunk`

读取文档的上一个区块。

### `apply_diff`

这是 AI 代理用于修改文档的主要工具。它会将一组差异应用到文档中。每项差异包含：

- 更改前的内容，用于定位需要编辑的位置。
- 要删除的内容
- 要插入的内容

### `replace_document`

用新内容替换整个文档。

### `plan`

规划要完成的工作，并以 Markdown 格式生成步骤列表。

### `ask_user`

向用户提问。

### `finish_with_summary`

将任务标记为已完成，并以 Markdown 格式提供摘要。

## 自定义内置工具

你可以通过配置 `AiAgentToolkit` 实例来移除或替换内置工具。

```ts
import {
  AiAgentToolkit,
  planTool,
  askUserTool,
  readFirstChunkTool,
  readNextChunkTool,
  readPreviousChunkTool,
  replaceDocumentTool,
  finishWithSummaryTool,
  applyDiffTool,
} from '@tiptap-pro/extension-ai-agent-server'

const toolkit = new AiAgentToolkit({
  tools: [
    // These are all the built-in tools. Remove or replace them as needed.
    planTool(),
    askUserTool(),
    readFirstChunkTool(),
    readNextChunkTool(),
    readPreviousChunkTool(),
    replaceDocumentTool(),
    finishWithSummaryTool(),
    applyDiffTool(),
  ],
})
```

## 自定义工具

除了内置工具，你还可以定义其他工具。自定义工具分为两种：

- [**客户端工具**](/ai/deprecated/agent/custom-llms/client-side-tools)在客户端运行，可与编辑器内容交互。例如，统计文档字数或设置文档格式的工具。所有内置工具都是客户端工具。
- [**服务器端工具**](/ai/deprecated/agent/custom-llms/server-side-tools)在服务器上运行，可与外部数据源交互。例如，搜索网页或查询数据库的工具。
