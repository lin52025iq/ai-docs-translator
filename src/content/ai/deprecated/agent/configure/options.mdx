Tiptap 的 AI Agent 扩展支持多种配置选项。创建 `AiAgentProvider` 新实例时，可以传入这些设置。

## 身份验证

要使用 AI Agent 扩展，您需要提供 Tiptap Cloud 的身份验证凭据。

```ts
const provider = new AiAgentProvider({
  // Your generated JWT
  token: 'YOUR_TOKEN',
})
```

## 模型选择

设置 `modelName` 选项，即可配置 Tiptap Cloud 使用的 OpenAI 模型。AI Agent 扩展使用 `gpt-4.1` 模型时效果最佳，因为它在复杂的文档编辑任务中表现出色。请注意，模型必须支持[函数调用](https://platform.openai.com/docs/guides/function-calling)。

```ts
const provider = new AiAgentProvider({
  modelName: 'gpt-4.1',
  // ... Other options
})
```

## 系统提示词

在 Tiptap Cloud 中使用 AI agent 时，您可以[定义自定义系统提示词](/ai/deprecated/agent/configure/system-prompt)。

```ts
const provider = new AiAgentProvider({
  systemPrompt: 'You are an AI agent that edits rich text documents...',
  // ... Other options
})
```

## 初始聊天消息

您可以提供初始聊天消息，以便在首次加载扩展时填充对话内容。

```ts
const provider = new AiAgentProvider({
  initialChatMessages: [
    {
      type: 'ai',
      text: 'Hello! I am your AI assistant. How can I help you today?',
    },
  ],
  // ... Other options
})
```

## 自动保存检查点

`autoSaveCheckpoints` 选项允许您在用户发送消息时自动保存检查点。

```ts
const provider = new AiAgentProvider({
  autoSaveCheckpoints: true,
  // ... Other options
})
```

启用 `autoSaveCheckpoints` 选项后，系统会在发送用户消息之前以及调用工具之前保存检查点。如果您想自定义保存检查点的方式和时机，可以禁用此选项，并手动使用 `setCheckpoint()` 方法。请参阅[检查点指南](/ai/deprecated/agent/features/checkpoints)，了解有关检查点的更多信息。

## 文档分块

`chunkSize` 选项用于控制读取文档时每个文档块的最大大小（以字符数计）。`chunkHtml` 选项允许您自定义文档的分块方式。

```ts
const provider = new AiAgentProvider({
  chunkSize: 2000,
  chunkHtml: ({ html, chunkSize }) => {
    // Custom logic to split HTML into chunks
    // Must return an array of HTML strings
    return customSplitFunction(html, chunkSize)
  },
  // ... Other options
})
```

## 审核 AI 生成的更改

`reviewOptions` 选项允许您定义审核、接受和拒绝 AI 生成更改的工作流。请参阅[审核 AI 生成的更改](/ai/deprecated/agent/review)指南，了解更多信息。

```ts
const provider = new AiAgentProvider({
  reviewOptions: {
    // Set extension to "aiChanges" to use the AI Changes extension for review
    extension: 'aiChanges',
    // Set autoAccept to "never" to always require review
    autoAccept: 'never',
  },
  // ... Other options
})
```

## 事件处理程序

`AiAgentProvider` 支持多个事件处理程序，帮助您响应不同的状态和操作：

### 状态变更处理程序

每当 AI Agent 扩展的状态发生变化时，都会调用 `onStateChange` 处理程序。

```ts
const provider = new AiAgentProvider({
  onStateChange: (newState, previousState, context) => {
    console.log('State changed:', newState)
    updateUI(newState)
  },
  // ... Other options
})
```

### 加载错误处理程序

加载 AI Agent 扩展时发生错误，会调用 `onLoadingError` 处理程序。

```ts
const provider = new AiAgentProvider({
  onLoadingError: (error, context) => {
    console.error('Loading error:', error)
    showErrorNotification(error.message)
  },
  // ... Other options
})
```

### 工具调用处理程序

执行工具调用前后，分别会调用 `onBeforeToolCall` 和 `onAfterToolCall` 处理程序。

```ts
const provider = new AiAgentProvider({
  onBeforeToolCall: (toolCall, context) => {
    console.log('Before tool call:', toolCall)
    showLoadingIndicator()
  },
  onAfterToolCall: (toolCall, context) => {
    console.log('After tool call:', toolCall)
    hideLoadingIndicator()
  },
  // ... Other options
})
```

### 停止运行处理程序

AI Agent 扩展停止运行且其[生命周期](/ai/deprecated/agent/features/lifecycle)结束时，会调用 `onStopRunning` 处理程序。

```ts
const provider = new AiAgentProvider({
  onStopRunning: (context) => {
    console.log('The AI Agent extension finished running')
    playCompletionSound()
  },
  // ... Other options
})
```

## 自定义 API 端点

设置 `baseUrl` 选项，即可为 AI Agent 扩展指定自定义 API 端点。如果您运行自己的 Tiptap Content AI 服务实例，这会很有用。

```ts
const provider = new AiAgentProvider({
  baseUrl: 'https://your-custom-api-endpoint.com',
  // ... Other options
})
```

## 自定义 AI agent 集成选项

这些配置选项可让您将 AI Agent 扩展与自己的 AI agent 集成，而不是使用 Tiptap Cloud 托管的 AI agent。详情请参阅[自定义 AI agent 集成指南](/ai/deprecated/agent/custom-llms/overview)。

### 自定义 resolver

`resolver` 选项允许您将 AI Agent 扩展与自己的后端服务集成。此函数负责向 LLM 发送聊天消息并返回响应。

```ts
const provider = new AiAgentProvider({
  resolver: async (options) => {
    // Your custom logic to send the chat messages to the LLM
    // and return the response
    const response = await yourCustomBackend.sendChatMessages(options)
    return response
  },
  // ... Other options
})
```

默认情况下，AI Agent 扩展使用 `defaultAiAgentResolver`，将聊天消息发送到 Tiptap Cloud。

### 自定义工具

`toolHandlers` 选项允许您定义 AI agent 可以调用的自定义客户端工具。此选项仅适用于将 AI Agent 扩展与自己的后端搭配使用的情况。要了解如何设置自定义工具，请参阅[自定义 AI agent 集成指南](/ai/deprecated/agent/custom-llms/overview)。

```ts
import { toolHandlersStarterKit } from '@tiptap-pro/extension-ai-agent'

const provider = new AiAgentProvider({
  toolHandlers: [
    toolHandlersStarterKit(),
    // ... custom tool handlers
  ],
  // ... Other options
})
```

## 自定义节点

配置 AI Agent 扩展，使其能够[生成和理解自定义节点](/ai/deprecated/agent/configure/custom-nodes)。

```ts
const provider = new AiAgentProvider({
  schemaAwarenessCustomElements: [
    /* Custom node configuration */
  ],
})
```

## 主要配置选项

| 选项                            | 类型                       | 默认值                     | 描述                                                   |
| ------------------------------- | -------------------------- | -------------------------- | ------------------------------------------------------ |
| `token`                         | `string`                   | `""`                       | 用于身份验证的 JWT                                     |
| `baseUrl`                       | `string`                   | `""`                       | AI 服务 API 的基础 URL                                 |
| `modelName`                     | `AiAgentModelName`         | `"gpt-4.1"`                | 要使用的 OpenAI 模型（推荐 gpt-4.1 和 gpt-4o）         |
| `autoSaveCheckpoints`           | `boolean`                  | `false`                    | 用户发送消息时自动保存检查点                           |
| `chunkSize`                     | `number`                   | `1000`                     | 读取文档时每个文档块的大小（以字符数计）                |
| `chunkHtml`                     | `Function`                 | `defaultChunkHtmlFunction` | 自定义文档分块方式                                     |
| `initialChatMessages`           | `ChatMessage[]`            | `[]`                       | 用于填充对话的初始聊天消息                             |
| `resolver`                      | `Function`                 | `defaultAiAgentResolver`   | 使用自定义后端处理请求的函数                           |
| `toolHandlers`                  | `AiAgentToolCallHandler[]` | `toolHandlersStarterKit()` | 自定义工具的处理程序                                   |
| `onStateChange`                 | `Function`                 | `undefined`                | AI Agent 扩展状态发生变化时调用                        |
| `onLoadingError`                | `Function`                 | `undefined`                | 加载 AI Agent 扩展时发生错误时调用                     |
| `onBeforeToolCall`              | `Function`                 | `undefined`                | 执行工具调用前调用                                     |
| `onAfterToolCall`               | `Function`                 | `undefined`                | 执行工具调用后调用                                     |
| `onStopRunning`                 | `Function`                 | `undefined`                | AI Agent 扩展停止运行时调用                            |
| `systemPrompt`                  | `string`                   | `undefined`                | 在 Tiptap Cloud 中使用 AI Agent 扩展时的自定义系统提示词 |
| `schemaAwarenessCustomElements` | `SchemaAwarenessItem[]`    | `[]`                       | 向 AI 模型提供文档可包含的自定义节点信息               |
