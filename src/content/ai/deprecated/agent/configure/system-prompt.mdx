想要自定义 AI 代理的行为、写作方式和用户交互方式吗？定义自定义系统提示词即可。

## 在 Tiptap Cloud 中使用

在 Tiptap Cloud 中使用 AI Agent 扩展时，可以通过 `systemPrompt` 选项为 AI 代理设置自定义系统提示词。

```ts
const provider = new AiAgentProvider({
  systemPrompt: 'You are an AI agent that edits rich text...',
  // ... Other options
})
```

这会**替换** Tiptap Cloud 中使用的默认系统提示词。

## 与自定义 AI 代理搭配使用

如果 AI Agent 扩展使用的是运行在后端的自定义 AI 代理，自定义系统提示词的方式取决于你使用的 AI 模型提供商。了解详情，请参阅[自定义 AI 代理集成指南](/ai/deprecated/agent/custom-llms/overview)。

## 支持多种 AI 代理类型

借助系统提示词，应用可以支持多种 AI 代理类型，每种类型都有自己的规则和个性。你可以随时调用 `setSystemPrompt` 方法来更改系统提示词。

```ts
provider.setSystemPrompt('You are an AI agent that edits rich text...')
```

## 编写优质的系统提示词

要编写出合适的系统提示词并非易事。`@tiptap-pro/extension-ai-agent-server` 包提供了一个开箱即用的默认系统提示词。你可以以此为基础，构建自己的自定义系统提示词。

```ts
import { getDefaultSystemPrompt } from '@tiptap-pro/extension-ai-agent-server'

// Log the default system prompt to read it and adjust it to your needs.
console.log(getDefaultSystemPrompt())
```
