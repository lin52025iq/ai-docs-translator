将 AI Agent 扩展与 AI Changes 扩展集成，为 AI 生成的更改提供审查工作流。用户可以在更改应用到文档后进行审查。

## 设置 AI Changes 集成

本指南将介绍如何设置 AI Changes 扩展，以便审查、接受和拒绝更改。

<Callout title="注意" variant="info">
  我们在[介绍页面](/ai/deprecated/agent/overview)中提供了集成 AI Changes 扩展的代码示例。
</Callout>

### 第 1 步：安装两个扩展

```bash
npm install @tiptap-pro/extension-ai-agent @tiptap-pro/extension-ai-changes
```

### 第 2 步：在编辑器中配置两个扩展

```tsx
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import AiAgent from '@tiptap-pro/extension-ai-agent'
import AiChanges from '@tiptap-pro/extension-ai-changes'

const provider = new AiAgentProvider({
  token: 'YOUR_JWT_TOKEN',
  reviewOptions: {
    // Set extension to "aiChanges" to use AI Changes for review
    extension: 'aiChanges',
    // Optional: Set autoAccept to "never" to always require review
    autoAccept: 'never',
  },
  // ... other options
})

const editor = new Editor({
  extensions: [
    StarterKit,
    AiAgent.configure({
      provider,
    }),
    AiChanges.configure({
      // Optional: Customize the appearance of AI changes to display a popover when a change is selected
      getCustomDecorations({ change, isSelected, getDefaultDecorations }) {
        const decorations = getDefaultDecorations()
        // Add custom decorations if needed
        return decorations
      },
    }),
  ],
})
```

### 第 3 步：配置样式

自定义建议在编辑器中的显示方式。

```css
.tiptap-ai-changes--old {
  color: var(--color-red-700);
  background-color: var(--color-red-100);
}

.tiptap-ai-changes--old * {
  background-color: var(--color-red-100);
}

.tiptap-ai-changes--new {
  color: var(--color-green-700);
  background-color: var(--color-green-100);
}
```

## 审查工作流的运作方式

1. AI agent 更改文档时，AI Changes 扩展会跟踪这些更改
2. 如果 `autoAccept` 设置为 `never`，或对于会修改内容的更改设置为 `onlyRead`，这些更改会显示为待处理状态
3. provider 的状态会变为 `reviewingToolCall`
4. 用户可以审查更改，并决定接受或拒绝
5. 接受或拒绝后，对话会继续

## 接受和拒绝更改

可以调用以下方法来接受或拒绝更改：

```tsx
// Accept all pending changes
provider.acceptToolCall()

// Reject all pending changes
provider.rejectToolCall()
```

<Callout title="注意" variant="warning">
  如果工具调用被拒绝，AI agent provider 会尝试借助 AI Changes 扩展，将文档重置为执行工具调用之前的状态。不过，如果未导入 AI Changes 扩展，或 `extension` 参数设为 `null`，AI agent 将无法自动重置文档状态。因此，你需要自行实现逻辑，以处理被拒绝的工具调用并将文档恢复到之前的状态。
</Callout>

如果不使用 AI Changes 扩展，要处理被拒绝的工具调用，可以在应用工具调用之前（触发 `beforeToolCall` 事件时）保存文档状态，并在工具调用被拒绝时恢复该状态。

<Callout title="注意" variant="info">
  AI Changes 扩展允许用户在更改应用到文档后进行审查。若要在应用更改之前进行审查，请集成 [AI Suggestion](/ai/deprecated/agent/review/ai-suggestion) 扩展。
</Callout>
