配置审查工作流，让用户更好地控制 AI 生成的内容。AI Agent 扩展与 [AI Changes](/ai/deprecated/changes/overview) 和 [AI Suggestion](/ai/deprecated/suggestion/overview) 扩展集成，帮助用户批准、拒绝和修改 AI 生成的内容。

处理 AI 生成的更改有两种方式：

- [**应用后审查**](/ai/deprecated/agent/review/ai-changes)：先将更改应用到文档，再使用 **AI Changes** 扩展进行审查。随后，用户可以接受或拒绝这些更改。拒绝某项更改会将文档还原为之前的内容。请按照[本指南](/ai/deprecated/agent/review/ai-changes)进行配置。
- [**应用前预览**](/ai/deprecated/agent/review/ai-suggestion)：将更改发送到 **AI Suggestion** 扩展，用户可以在更改应用到文档之前进行审查并批准或拒绝。请按照[本指南](/ai/deprecated/agent/review/ai-suggestion)进行配置。

## 自动接受配置

AI 代理调用工具时，你可能希望它暂停并等待用户审查，也可能希望它在没有用户交互的情况下继续运行。

你可以通过 `autoAccept` 选项配置此行为。此选项用于控制 AI 代理是否自动接受所有工具调用并继续运行，还是暂停并等待用户审查。

- `"always"`：自动应用所有工具调用，无需审查。AI 代理会持续运行，直到完成任务。
- `"never"`：所有工具调用都需要用户审查并明确接受。
- `"onlyRead"`：只有会修改编辑器内容的工具调用需要审查；读取操作会自动接受。

```tsx
// Configure auto-accept behavior
const provider = new AiAgentProvider({
  reviewOptions: {
    autoAccept: 'onlyRead',
  },
  // ... other options
})

// Change auto-accept behavior at runtime
provider.setAutoAccept('never')
```
