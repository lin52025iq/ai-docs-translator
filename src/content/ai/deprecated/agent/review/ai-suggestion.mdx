## 设置 AI Suggestion 集成

本指南将介绍如何设置 AI Suggestion 扩展，以预览、接受和拒绝更改。

### 第 1 步：安装这两个扩展

```bash
npm install @tiptap-pro/extension-ai-agent @tiptap-pro/extension-ai-suggestion
```

### 第 2 步：在编辑器中配置这两个扩展

```tsx
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import AiAgent from '@tiptap-pro/extension-ai-agent'
import AiSuggestion from '@tiptap-pro/extension-ai-suggestion'

const provider = new AiAgentProvider({
  token: 'YOUR_JWT_TOKEN',
  reviewOptions: {
    // 将 extension 设置为 "aiSuggestion"，以使用 AI Suggestion 预览更改
    extension: 'aiSuggestion',
    // 可选：将 autoAccept 设置为 "never"，始终要求用户在应用更改前进行审核
    autoAccept: 'never',
  },
  // ... 其他选项
})

const editor = new Editor({
  extensions: [
    StarterKit,
    AiAgent.configure({
      provider,
    }),
    AiSuggestion.configure({
      loadOnStart: false,
      reloadOnUpdate: false,
      // 可选：自定义建议的外观。
      // 例如，选中建议时显示弹出框。
      getCustomDecorations({ change, isSelected, getDefaultDecorations }) {
        const decorations = getDefaultDecorations()
        // 如有需要，可添加自定义装饰（示例请参见上方演示）
        return decorations
      },
    }),
  ],
})
```

### 第 3 步：配置样式

自定义建议在编辑器中的显示方式。

```css
:root {
  --color-green-100: oklch(0.962 0.044 156.743);
  --color-green-700: oklch(0.527 0.154 150.069);
  --color-red-100: oklch(0.936 0.032 17.717);
  --color-red-700: oklch(0.505 0.213 27.518);
}

.tiptap-ai-diff-suggestion--old {
  color: var(--color-red-700);
  background-color: var(--color-red-100);
}

.tiptap-ai-diff-suggestion--new {
  color: var(--color-green-700);
  background-color: var(--color-green-100);
}

.tiptap-ai-diff-suggestion--new * {
  background-color: var(--color-green-100);
}
```

## 审核流程的工作方式

1. AI Agent 更改文档时，如果 `autoAccept` 设置为 `never` 或 `onlyRead`，更改会发送到 AI Suggestion 扩展，而不是直接应用到文档。
2. AI Suggestion 扩展会将更改显示为建议。
3. 用户可以审核这些建议，并决定接受或拒绝。
4. 接受或拒绝后，更改会应用到文档，并继续对话。

## 接受和拒绝更改

你可以调用以下方法接受或拒绝更改：

```tsx
// 接受所有待处理的更改
provider.acceptToolCall()

// 拒绝所有待处理的更改
provider.rejectToolCall()
```
