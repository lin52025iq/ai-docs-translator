在 AI 智能体中，上下文是补充用户请求的数据。有时，它对于完成任务至关重要。

例如，在多文档 AI 智能体中，如果用户提到了某个文档，也应将该文档的 ID 作为上下文发送。

创建用户消息时，可以使用 `context` 选项提供上下文。

```ts
provider.addUserMessage('Summarize the selected document', {
  context: 'The selected document ID is: 12345',
})
```

## 使用提及插入上下文

在许多 AI 聊天机器人中，用户可以通过提及来引用文件和其他用户，例如：`@John`、`#file-123` 等。你可以将提示词输入框定义为 Tiptap 文本编辑器，并安装 [Mention 扩展](/editor/extensions/nodes/mention)，以便在 Tiptap 中实现此功能。

## 将文件和 URL 添加到上下文

`context` 选项只接受字符串，不接受文件对象。要将文件作为上下文添加，请按以下步骤操作：

1. 将文件上传到服务器，并获取其标识符。
2. 将文件标识符添加到 `context` 选项中。
3. 在[后端](/ai/deprecated/agent/custom-llms/overview)定义一个[自定义服务器端工具](/ai/deprecated/agent/custom-llms/server-side-tools)，让 AI 智能体能够读取文件内容。

URL 也是如此。如果用户提供了 URL，你可以将其作为字符串添加到 `context` 选项中，并定义一个[自定义工具](/ai/deprecated/agent/custom-llms/server-side-tools)，用于搜索网络并获取该 URL 的内容。

## 将编辑器中的选区添加到上下文

要让 AI 智能体了解编辑器中选中的内容，请启用[选区感知](/ai/deprecated/agent/features/selection-awareness)。
