选区感知功能可让 AI 代理了解编辑器中选中的内容，帮助它理解用户的请求，并仅对选区进行精准编辑。

要启用选区感知功能，请将 `addSelection` 选项设为 `true`。这样会将选中的内容作为[上下文](/ai/deprecated/agent/features/context)发送给 AI 代理。

```ts
provider.addUserMessage('Summarize the selected document', {
  addSelection: true, // Defaults to false
})
```
