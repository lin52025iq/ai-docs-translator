调用 `provider.run()` 时，AI 智能体的生命周期开始；当 AI 智能体完成任务、需要用户审核或遇到错误时，生命周期结束。

## 生命周期步骤

1. **初始化**：添加用户消息后，调用 `provider.run()`，生命周期随之开始。
2. **处理**：AI 智能体调用 AI 模型。AI 会返回一条消息和一个工具调用。
3. **工具执行**：AI 智能体调用工具来读取或修改文档。
4. **循环**：AI 智能体再次调用 AI 并执行下一个工具，直到满足终止条件。
5. **完成**：当 AI 智能体完成任务、需要用户审核或遇到错误时，生命周期结束。

## 控制生命周期

你可以使用以下方法控制 AI 智能体的生命周期：

```tsx
// Start the lifecycle
provider.run()

// Stop the current lifecycle
provider.stop()
```

默认情况下，添加用户消息后，AI 智能体不会自动运行。你需要显式调用 `run()`：

```tsx
// Add a message and run the AI agent
provider.addUserMessage('Format this document with proper headings')
provider.run()
```

## 处理完成状态

监听 `stopRunning` 事件，以便在生命周期结束、AI 智能体停止运行时收到通知。

```tsx
// Subscribe to the stopRunning event
provider.on('stopRunning', (context) => {
  console.log('AI agent lifecycle completed')
  showCompletionNotification('The AI agent has completed the task')
})
```

## 状态

在生命周期内，AI 智能体会在不同的[状态](/ai/deprecated/agent/features/state#status)之间切换：

1. `idle` → `loading`：调用 `run()` 时
2. `loading` → `reviewingToolCall`：工具调用需要用户审核时
3. `loading` → `loadingError`：发生错误时
4. `loading` → `idle`：满足以下任一条件时：
   - 执行了最终工具调用。最终工具调用是指工具调用处理程序对象中 `isFinal` 属性设为 `true` 的工具调用。
   - LLM 未返回工具调用。
   - 调用了 `provider.stop()`。
   - 当前生命周期尚未结束时，通过 `provider.run()` 启动了另一个生命周期。

## 并发运行 AI 智能体

在当前版本中，AI Agent 扩展不支持在同一编辑器中运行多个 AI Agent。如果调用 `provider.run()` 时已有生命周期正在进行，当前生命周期会先中断，然后才启动新的生命周期。

如需同时运行多个 AI Agent，请实例化多个编辑器和 AI 智能体提供程序。
