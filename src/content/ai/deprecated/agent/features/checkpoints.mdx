检查点是编辑器内容和对话状态在某个时间点的快照。它们可以保存文档和对话的当前状态，并在需要时稍后恢复。

## 设置检查点

要创建检查点，请使用 `setCheckpoint` 方法：

```tsx
const checkpointMessage = provider.setCheckpoint()
```

此方法会返回一条检查点消息，其中包含当前的聊天消息和编辑器内容。

## 恢复检查点

要恢复之前保存的检查点，请使用 `restoreCheckpoint` 方法：

```tsx
provider.restoreCheckpoint(checkpointMessage.checkpoint)
```

这会将编辑器内容和对话消息恢复到创建检查点时的状态。

## 自动检查点

你可以将 provider 配置为在用户发送消息时自动保存检查点：

```tsx
const provider = new AiAgentProvider({
  // ...other options
  autoSaveCheckpoints: true,
})
```

启用 `autoSaveCheckpoints` 后，系统会在发送用户消息前以及调用工具前保存检查点。若要在其他时间保存检查点，可以手动调用 `setCheckpoint`。
