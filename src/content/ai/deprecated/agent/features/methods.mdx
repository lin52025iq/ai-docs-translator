AI 代理提供程序提供了多种方法。

## 核心方法

| 方法                            | 说明                                                                  | 参数                             |
| ------------------------------- | --------------------------------------------------------------------- | -------------------------------- |
| `run()`                         | 启动新的 AI 代理[生命周期](/ai/deprecated/agent/features/lifecycle) | 无                               |
| `stop()`                        | 停止当前 AI 代理生命周期                                              | 无                               |
| `reset(chatMessages?)`          | 将 AI 代理提供程序重置为初始状态                                      | `chatMessages?`: `ChatMessage[]` |
| `setSystemPrompt(systemPrompt)` | 设置[系统提示词](/ai/deprecated/agent/configure/system-prompt)       | `systemPrompt`: `string \| null` |

## 对话管理

| 方法                                | 说明                                                                                                      | 参数                                                    |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| `addUserMessage(message, options?)` | 向对话中添加用户消息                                                                                      | `message`: `string`，`options?`: `AddUserMessageOptions` |
| `addChatMessages(messages)`         | 向对话中添加多条聊天消息                                                                                  | `messages`: `ChatMessage[]`                             |
| `setChatMessages(messages)`         | 替换对话中的所有消息                                                                                      | `messages`: `ChatMessage[]`                             |
| `setAutoAccept(autoAccept)`         | 更改[自动接受](/ai/deprecated/agent/review#auto-accept-configuration)设置                               | `autoAccept`: `"always" \| "never" \| "onlyRead"` |
| `setCheckpoint()`                   | 将当前状态保存为[检查点](/ai/deprecated/agent/features/checkpoints)                                     | 无                                                      |
| `restoreCheckpoint(checkpoint)`     | 恢复先前保存的检查点                                                                                      | `checkpoint`: `Checkpoint`                              |

## 工具调用审核

| 方法               | 说明             | 参数 |
| ------------------ | ---------------- | ---- |
| `acceptToolCall()` | 接受待处理的工具调用 | 无   |
| `rejectToolCall()` | 拒绝待处理的工具调用 | 无   |
