## 主要功能

- 快速、高效地编辑大型文档。
- 理解文档结构，包括自定义元素。
- 集成外部数据源和 RAG 流程。
- 感知编辑器中当前选中的内容。
- 让用户检查并接受或拒绝 AI 生成的更改。

## 使用 Tiptap 的 AI Agent，或构建自己的 Agent

使用 AI Agent 扩展有两种方式：

- [与 Tiptap Cloud 搭配使用](/ai/deprecated/agent/use-with-content-ai-cloud)，使用托管的现成 AI Agent。
- [将其添加到现有 AI Agent 中](/ai/deprecated/agent/custom-llms/overview)，该 Agent 托管在你的后端。

AI Agent 扩展为常见的 AI 服务提供商库提供工具定义：

- [Vercel 的 AI SDK](/ai/ai-toolkit/client/agents/tools/ai-sdk)
- [LangChain.js](/ai/ai-toolkit/client/agents/tools/langchain-js)
- [OpenAI](/ai/ai-toolkit/client/agents/tools/openai)

## 什么是 AI Agent？

AI Agent 是一种能够通过自主决策完成复杂任务的系统。与简单的聊天机器人助手不同，AI Agent 不仅能用文本回复，还能调用与环境交互的“工具”。

Tiptap AI Agent 扩展为 AI Agent 提供了执行以下操作的工具：

- 读取文档
- 重写文档内容
- 制定计划、与用户交互，并总结所做的更改。

这些内置工具针对富文本编辑进行了优化，并遵循 LLM 最佳实践，让你能够专注于应用的核心逻辑。你还可以将它们与用于检索数据的自定义工具结合使用。

使用这些工具调用 LLM 时，LLM 会选择一个工具执行。随后，Tiptap AI Agent 扩展会在编辑器中执行该工具，以高效地修改文档或读取其内容。典型实现中，LLM 在服务器端调用，而文档编辑则在浏览器中进行。

可以把 LLM 看作 AI Agent 的“大脑”，负责决定调用哪些工具。Tiptap AI Agent 扩展则充当它的“双手”和“眼睛”，让 Agent 能够读取文档并与之交互。

将 AI Agent 扩展与 Tiptap Cloud 搭配使用时，无需操心服务器——我们已为你搭建好。不过，如果你想自定义 LLM 及 AI Agent 可用的工具（例如，让它执行搜索外部数据源等操作），可以将 AI Agent 扩展集成到自己的后端。
