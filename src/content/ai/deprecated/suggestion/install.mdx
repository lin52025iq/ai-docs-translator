本设置指南将帮助你从头开始将 AI Suggestion 扩展集成到应用中。

## 安装

AI Suggestion 扩展发布在 Tiptap 的私有 npm 注册表中。请按照[私有注册表指南](/guides/pro-extensions)集成此扩展。

## 在编辑器中导入扩展

将 `AiSuggestion` 添加到扩展列表中。

```ts
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import AiSuggestion from '@tiptap-pro/extension-ai-suggestion'

// Initialize the editor
const editor = new Editor({
  extensions: [
    StarterKit,
    AiSuggestion.configure({
      // Define suggestion rules
      rules: [
        {
          id: '1',
          title: 'Spell Check',
          prompt: 'Identify and correct any spelling mistakes',
          color: '#DC143C',
          backgroundColor: 'FFE6E6',
        },
      ],
      // Configure Content AI Cloud (see next section)
      token: 'TOKEN_HERE',
      // … other options
    }),
    // … more extensions
  ],
  // Recommended: disable spellcheck to avoid conflicts
  editorProps: {
    attributes: {
      spellcheck: false,
    },
  },
})
```

## 决定如何生成建议

下一步是配置生成建议的方式，以便在编辑器中显示这些建议。

使用 Tiptap Content AI Cloud 是开始使用 AI Suggestion 扩展的最简单方式。我们的 API 会根据你的规则和内容生成建议。请参阅此设置指南：[使用 Tiptap Content AI Cloud](/ai/deprecated/suggestion/use-with-content-ai-cloud)。

你也可以使用自己的后端和 LLM 来生成校对建议。请参阅此指南：[集成自己的后端和 LLM](/ai/deprecated/suggestion/custom-llms)。

## 自定义用户界面

最后，你需要配置编辑器样式，以便在 UI 中显示建议。

默认情况下，AI Suggestions 带有 CSS 类和颜色属性，方便你设置样式。使用以下 CSS 样式可在建议下方显示彩色下划线。

```css
.tiptap-ai-suggestion {
  border-bottom: 2px solid var(--tiptap-ai-suggestion-color);
  margin-bottom: -2px;
}

.tiptap-ai-suggestion--selected {
  background-color: var(--tiptap-ai-suggestion-background-color);
  transition: background-color 0.5s;
}
```

你还可以通过提供自定义装饰来进一步自定义建议的外观。若要在选中建议时显示工具提示或弹出框，请[参阅此指南](/ai/deprecated/suggestion/features/display-suggestions#show-a-popover-when-you-select-a-suggestion)。
