Tiptap 的 AI Suggestion 扩展提供多种设置，用于配置扩展和命令的全局行为。

## 规则

校对时要应用的规则数组。每条规则包含：

- 唯一的 `id`
- `prompt` 属性：AI 模型会读取此文本并据此生成建议
- 决定规则在 UI 中显示方式的参数，例如 `title`、`color` 和 `backgroundColor`

你可以随时使用 `setAiSuggestionRules` 命令更改规则，无需重新加载编辑器。

```ts
AiSuggestion.configure({
  rules: [
    {
      id: '1',
      title: 'Spell Check',
      prompt: 'Identify and correct any spelling mistakes',
      color: '#DC143C',
      backgroundColor: 'FFE6E6',
    },
  ],
})
```

如需了解更多规则相关信息，请参阅本指南：[定义规则](/ai/deprecated/suggestion/features/define-rules)

## 初始建议

在开始校对前要显示的初始建议数组。此功能可用于优化性能，避免等待生成第一批建议。

```ts
export const suggestions: Suggestion[] = [
  {
    id: '1',
    deleteRange: { from: 1, to: 5 },
    deleteText: 'Mistaek',
    replacementOptions: [
      {
        id: '1',
        addText: 'Mistake',
      },
    ],
    rule: {
      id: '1',
      title: 'Spell Check',
      prompt: 'Identify and correct any spelling mistakes',
      color: '#DC143C',
      backgroundColor: 'FFE6E6',
    },
    isRejected: false,
  },
]

AiSuggestion.configure({
  initialSuggestions: suggestions,
})
```

如需了解建议对象应包含哪些数据，请参阅 [API 参考](/ai/deprecated/suggestion/api-reference#proofreading-suggestions)。

## 自定义建议样式

`getCustomSuggestionDecoration` 函数可用于控制建议的外观，并向用户提供视觉提示。你可以为建议添加自定义 CSS 类，也可以在建议前后添加自定义元素。此功能适用于为建议添加弹出框、工具提示或图标。

自定义样式和元素通过 [Prosemirror Decorations API](https://prosemirror.net/docs/ref/#view.Decorations) 实现。

如需了解如何在选中建议时显示弹出框，请参阅[本指南](/ai/deprecated/suggestion/features/display-suggestions#show-a-popover-when-you-select-a-suggestion)。

```ts
AiSuggestion.configure({
  getCustomSuggestionDecoration({ suggestion, isSelected, getDefaultDecorations }) {
    // You can combine the default decorations of the AI Suggestion extension with your custom ones
    const decorations = getDefaultDecorations()

    // Add a custom element before the suggestion text
    Decoration.widget(suggestion.deleteRange.from, () => {
      const element = document.createElement('span')
      element.textContent = '⚠️'
      return element
    })
    return decorations
  },
})
```

## 自定义建议的加载时机

默认情况下，AI Suggestion 扩展会在编辑器就绪时自动加载建议。你可以通过 `loadOnStart` 选项禁用此行为。

```ts
AiSuggestion.configure({
  loadOnStart: false,
})
```

默认情况下，编辑器内容发生变化时，AI Suggestion 扩展会重新加载建议。你可以通过 `reloadOnUpdate` 选项禁用此行为。

```ts
AiSuggestion.configure({
  reloadOnUpdate: false,
})
```

如需了解如何配置建议的加载时机，请参阅[本指南](/ai/deprecated/suggestion/features/configure-when-to-load-suggestions)。

## 自定义防抖超时时间

默认情况下，用户停止输入 800ms 后，AI Suggestion 扩展会重新加载建议，以避免过于频繁地调用 API。你可以通过 `debounceTimeout` 选项配置此超时时间。

```ts
AiSuggestion.configure({
  debounceTimeout: 1000,
})
```

## 处理加载建议时的错误

你可以提供一个回调函数来处理加载建议时发生的错误。发生错误时，你可以借此记录错误、向用户显示错误消息，或执行其他操作。

如需了解如何在 UI 中处理加载和错误状态，请参阅完整指南：

```ts
AiSuggestion.configure({
  onLoadSuggestionsError(error) {
    console.error('An error occurred while loading suggestions', error)
  },
})
```

## Tiptap Content AI 云选项

如果你没有[提供自己的后端](/ai/deprecated/suggestion/custom-llms)，AI Suggestion 扩展将使用 Tiptap Content AI 云生成建议。

你可以通过 `model` 选项配置用于生成建议的 OpenAI 模型。默认模型为 `gpt-4o-mini`。我们建议大多数使用场景选用此模型，因为它在速度、成本和准确性之间取得了良好的平衡。

```ts
AiSuggestion.configure({
  // This needs to be your generated JWT and MUST NOT be the OpenAI API key!
  token: 'YOUR_TOKEN',
  // The model to use for generating suggestions. Defaults to "gpt-4o-mini"
  model: 'gpt-4o',
})
```

- `gpt-6.1-terra`
- `gpt-5.1`
- `gpt-5.1-2025-11-13`
- `gpt-5.6-luna`
- `gpt-5.6-terra`
- `gpt-5`
- `gpt-5-2025-08-07`
- `gpt-5-mini`
- `gpt-5-mini-2025-08-07`
- `gpt-5-nano`
- `gpt-5-nano-2025-08-07`

## 集成你自己的后端和 LLM

如果你想使用自己的后端和 LLM 生成建议，可以提供自定义的 `resolver` 函数。该函数应根据编辑器内容和规则返回建议数组。

如需更全面地了解如何集成自己的后端和 LLM，请参阅[本指南](/ai/deprecated/suggestion/custom-llms)。

```ts
AiSuggestion.configure({
  resolver: async ({ content, rules }) => {
    // Your custom logic to generate suggestions
    return suggestions
  },
})
```

## 为 LLM 提供额外上下文

如果你想为 LLM 提供额外信息，可以使用 `context` 选项。你可以通过此选项传递其他数据，以提升建议的质量。

`context` 选项是一个字符串，会作为提示词的一部分传递给 LLM，并应用于所有规则。

```ts
AiSuggestion.configure({
  context: 'The tone should be formal and professional.',
})
```

如需了解如何提供上下文，请参阅[本指南](/ai/deprecated/suggestion/features/provide-llm-context)。

## 配置缓存

AI Suggestion 扩展会缓存建议，以尽量减少 API 调用。它会将编辑器内容拆分为多个块，并为每个块存储生成的建议。重新加载建议时，只会重新获取已修改块的建议。此行为默认启用，但你可以自定义配置。

将 `enableCache` 设为 `false` 可禁用缓存。这样一来，编辑器内容发生变化时，AI Suggestion 扩展会为所有块调用 API。

```ts
AiSuggestion.configure({
  // Disable caching
  enableCache: false,
})
```

你可以通过 `chunkSize` 选项配置块大小。此选项控制每个块包含的文档顶层节点数。默认值为 `2`，也就是说，对于包含 10 个段落的文档，AI Suggestion 会将其拆分为 5 个块，每块包含 2 个段落。

```ts
AiSuggestion.configure({
  // Each chunk will contain 3 top-level HTML nodes
  chunkSize: 3,
})
```

你可以通过覆盖 `chunkHtml` 函数自定义分块方式。此函数接收编辑器内容，并应返回一个 HTML 字符串数组，每个字符串代表一个块。这样你就可以精细控制内容的拆分方式。

```ts
AiSuggestion.configure({
  chunkHtml: customChunkHtmlFunction,
})
```
