开始使用 AI Suggestion 扩展的最快方式，是通过 Tiptap Content AI Cloud API 生成建议。该功能开箱即用，你只需向扩展提供身份验证凭据。

本安装指南使用 [Tiptap Content AI 后端服务](https://cloud.tiptap.dev/v2/cloud/ai)。如果你想使用自己的自定义 LLM 进行配置，请改为参阅[本指南](/ai/deprecated/suggestion/custom-llms)。

## 启动 Content AI 应用
1. **激活方案：** 开始[免费试用或选择订阅方案](https://cloud.tiptap.dev/v2/billing)。
2. **配置 AI 应用。** 将 OpenAI API 密钥添加到你的 [Content AI 应用](https://cloud.tiptap.dev/v2/cloud/ai)。
3. **设置身份验证：** 使用 `aud: "AI"` 和 `AI:Generation` 权限对令牌进行签名，然后将其传递给扩展。请参阅[身份验证](/authentication)。

## 将身份验证凭据添加到扩展

导入扩展，并使用已签名的令牌进行配置。

```tsx
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import AiSuggestion from '@tiptap-pro/extension-ai-suggestion'

// 初始化编辑器
const editor = new Editor({
  extensions: [
    StarterKit,
    AiSuggestion.configure({
      // 这里必须填写生成的 JWT，绝不能使用 OpenAI API 密钥！
      token: 'TOKEN_HERE',
      // 其他配置选项……
    }),
  ],
})
```

现在，编辑器加载时会从 Tiptap Content AI API 获取建议。

## 隐私与数据处理

请参阅我们的[隐私文档](/ai/basic/privacy)，了解 Tiptap 如何处理 AI 请求以及如何处理你的内容数据。文档涵盖了使用 Content AI 功能时的数据保留、安全实践和合规信息。
