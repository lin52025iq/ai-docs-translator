你可以自定义 AI Suggestion 扩展调用 LLM 生成建议的时机。这样可以控制何时加载新建议，以及重新加载的频率。

## 启动时加载建议

默认情况下，AI Suggestion 扩展会在编辑器就绪时自动加载建议。你可以通过 `loadOnStart` 选项禁用此行为。

```ts
AiSuggestion.configure({
  // Disable automatic loading of suggestions
  loadOnStart: false,
})
```

## 内容更新时重新加载建议

默认情况下，编辑器内容发生变化时，AI Suggestion 扩展会重新加载建议。你可以通过 `reloadOnUpdate` 选项禁用此行为。

```ts
AiSuggestion.configure({
  // Disable automatic loading of suggestions
  reloadOnUpdate: false,
})
```

## 防抖时间

默认情况下，用户停止输入 800 毫秒后，AI Suggestion 扩展会重新加载建议。这样可以避免过于频繁地调用 API。你可以通过 `debounceTimeout` 选项配置此时间。

```ts
AiSuggestion.configure({
  debounceTimeout: 1000,
})
```

不过，有时你可能需要强制重新加载建议。例如，你可能希望在用户点击“刷新”按钮时重新加载建议。

要手动重新加载建议，请使用 `loadAiSuggestions` 命令。

```ts
editor.commands.loadAiSuggestions()
```

要延迟加载建议，请使用 `loadAiSuggestionsDebounced` 命令。延迟时间由 `debounceTimeout` 选项决定。

此命令在内部用于编辑器内容发生变化后重新加载建议（例如，用户在编辑器中输入内容时）。此函数经过防抖处理，因此，如果在防抖时间内多次调用，只会执行最后一次调用。

```ts
editor.commands.loadAiSuggestionsDebounced()
```

## 以编程方式设置建议

如果你想将建议设置为特定值，而不是通过已配置的 API 加载，可以使用 `setAiSuggestions` 命令。以下场景适合使用此命令：

- 你有一组想要立即显示的建议。
- 你想清除建议。
- 你想显示来自其他来源的建议，而不是扩展选项中配置的 API。

```ts
editor.commands.setAiSuggestions(suggestions)
```

要了解建议对象应包含哪些数据，请参阅 [API 参考](/ai/deprecated/suggestion/api-reference#proofreading-suggestions)。
