AI Suggestion 扩展必须配置规则列表，以帮助大语言模型分析编辑器中的内容并生成建议。

```ts
AiSuggestion.configure({
  rules: [
    {
      id: '1',
      title: 'Spell Check',
      prompt: 'Identify and correct any spelling mistakes',
      color: '#DC143C',
      backgroundColor: 'FFE6E6',
    },
  ],
})
```

每条建议都与一条规则相关联。如果未提供规则，AI Suggestion 扩展将不会生成任何建议。

每条规则都必须具有唯一的字符串 id，以便将每条建议与相应的规则关联起来。

prompt 属性是用于描述规则的字符串。它会提供给 AI 模型，帮助其生成建议。

只有 id 和 prompt 会发送给 AI 模型。title、color 和 backgroundColor 属性用于设置建议的样式并在编辑器中显示建议。

## 规则会存储在 Tiptap Cloud 中吗？

如果使用 Tiptap Content AI Cloud 为内容生成建议，规则不会存储在云端，而是会随每次请求发送。

由于我们不会存储你的规则，你可以随时更改规则，并根据应用自身的逻辑启用规则。例如，你可以设置适用于所有文档的规则、特定文档的规则、适用于某些用户的规则，甚至允许用户自行定义规则。

如果你希望规则在多个会话之间保留，应将其存储在自己的数据库中。

## 编辑器加载后如何更改规则

无需重新加载编辑器，你可以随时更改规则。使用 `setAiSuggestionRules` 命令更新规则。

```ts
const newRules = [
  {
    id: '2',
    title: 'Grammar Check',
    prompt: 'Identify and correct any grammar mistakes',
    color: '#FFA500',
    backgroundColor: 'FFF5E6',
  },
]

editor.commmands.setAiSuggestionRules(newRules)
```

警告：`setAiSuggestionRules` 命令不会自动重新加载建议。你需要调用 `loadAiSuggestions` 命令，根据新规则更新建议。常见做法是将这两个命令串联起来。

```ts
editor.chain().setAiSuggestionRules(newRules).loadAiSuggestions().run()
```
