使用 [Tiptap Content AI 云端服务生成建议](/ai/deprecated/suggestion/use-with-content-ai-cloud) 时，以下信息会发送给 LLM：

- 编辑器内容。
- 扩展的[规则](/ai/deprecated/suggestion/features/define-rules)。
- `context` 选项（如果已提供）。

`context` 选项是一个可选的字符串属性，可用于向 LLM 提供额外信息。这些信息会添加到提示词中。该选项是全局的，因此会应用于所有规则。

## 配置上下文的初始值

你可以在扩展的配置中设置上下文的初始值。

```ts
AiSuggestion.configure({
  context: 'The tone should be formal and professional.',
})
```

## 更新上下文

你可以随时使用 `setAiSuggestionContext` 命令更新上下文值。如果你想根据用户输入或其他特定于应用程序的逻辑更改上下文，这会很有用。

```ts
const newContext = 'The tone should be informal and friendly.'
editor.commands.setAiSuggestionContext(newContext)
```

此命令不会自动重新加载建议。你需要调用 `loadAiSuggestions` 命令，根据新的上下文更新建议。常见做法是将这两个命令串联起来。

```ts
editor.chain().setAiSuggestionContext(newContext).loadAiSuggestions().run()
```

要清除上下文，请将其设为 `null`。

```ts
editor.commands.setAiSuggestionContext(null)
```

## 读取当前上下文

你可以通过 `context` 存储属性访问当前上下文值。

```ts
const currentContext = editor.extensionStorage.aiSuggestion.context
```
