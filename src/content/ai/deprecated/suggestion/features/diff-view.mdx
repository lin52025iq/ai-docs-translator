使用 AI Suggestion 扩展，在将更改应用到文档之前预览这些更改。以差异视图显示更改，并允许用户接受或拒绝单项更改。

<Callout title="注意" variant="info">
  如需在更改应用到文档**之后**进行审阅，请参阅 [AI
  Changes](/ai/deprecated/changes/overview) 扩展。
</Callout>

## 设置指南

### 第 1 步：配置 AI Suggestion 扩展

使用 AI Suggestion 扩展初始化 Editor 实例。禁用自动加载建议。

```ts
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import AiSuggestion from '@tiptap-pro/extension-ai-suggestion'

const editor = new Editor({
  content: '<p>This is the initial content of the document</p>',
  extensions: [
    StarterKit,
    AiSuggestion.configure({
      // 禁用自动加载建议
      loadOnStart: false,
      reloadOnUpdate: false,
    }),
  ],
})
```

### 第 2 步：定义用于归组差异建议的规则

每条建议都必须关联一条规则。在本例中，我们希望将差异显示为一组属于 `'diff'` 规则的建议。

```ts
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import AiSuggestion from '@tiptap-pro/extension-ai-suggestion'

const editor = new Editor({
  content: '<p>This is the initial content of the document</p>',
  extensions: [
    StarterKit,
    AiSuggestion.configure({
      // 禁用自动加载建议
      loadOnStart: false,
      reloadOnUpdate: false,
      rules: [
        {
          id: 'diff',
          // 差异视图不会使用标题、提示词和颜色
          title: '',
          prompt: '',
          color: '#000',
          backgroundColor: '#fff',
          // 不将此规则发送给 AI 模型来生成建议
          ignoreInTiptapCloud: true,
          // 以差异格式显示建议
          displayAsDiff: true,
        },
      ],
    }),
  ],
})
```

### 第 3 步：配置样式

自定义建议在编辑器中的显示方式。

```css
:root {
  --color-green-100: oklch(0.962 0.044 156.743);
  --color-green-700: oklch(0.527 0.154 150.069);
  --color-red-100: oklch(0.936 0.032 17.717);
  --color-red-700: oklch(0.505 0.213 27.518);
}

.tiptap-ai-diff-suggestion--old {
  color: var(--color-red-700);
  background-color: var(--color-red-100);
}

.tiptap-ai-diff-suggestion--new {
  color: var(--color-green-700);
  background-color: var(--color-green-100);
}

.tiptap-ai-diff-suggestion--new * {
  background-color: var(--color-green-100);
}
```

了解如何为建议添加高级样式，请参阅[样式指南](/ai/deprecated/suggestion/features/display-suggestions)。

### 第 4 步：生成建议

将文档的新内容（HTML 格式）传递给 resolver 函数以生成建议。AI Suggestion 扩展会将新内容与当前内容进行比较，并生成一组属于前面定义的 `'diff'` 规则的建议。

```ts
editor.commands.loadAiSuggestions({
  resolver: async (options) => {
    const newSuggestions = await options.defaultResolver({
      ...options,
      apiResolver: async () => {
        return {
          format: 'fullHtml',
          content: {
            items: [
              {
                ruleId: 'diff',
                fullHtml: '<p>This is the new content of the document</p>',
              },
            ],
          },
        }
      },
    })

    return newSuggestions
  },
})
```

### 第 5 步：审阅建议

审阅基于差异的建议与审阅常规建议的方式相同。更多信息请参阅[应用建议](/ai/deprecated/suggestion/features/apply-suggestions)指南。
