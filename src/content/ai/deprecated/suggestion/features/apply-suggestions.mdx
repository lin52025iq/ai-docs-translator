AI Suggestion 扩展提供了将建议应用到编辑器内容的命令。借助这些命令，您可以接受或拒绝建议，并将建议应用到编辑器内容中。

## 应用单条建议

如需将一条建议应用到编辑器内容中，请使用 `applyAiSuggestion` 命令。

一条建议可以包含多个替换选项。如需应用特定的替换选项，请提供 `replacementOptionId` 属性。如果不提供此属性，则会应用第一个替换选项。

注意：如果使用 Tiptap Content AI Cloud API 生成建议，每条建议只会有一个替换选项。不过，如果您使用自己的后端和 LLM，则可以提供多个替换选项。

您可以通过提供 `format` 属性来自定义替换文本的格式。默认格式为 "plain-text"。如果希望将替换文本设置为富文本格式，请使用 "rich-text" 格式。当建议会修改样式（例如加粗或斜体）时，这种格式很有用。

```ts
editor.commands.applyAiSuggestion({
  suggestionId: '1',
  replacementOptionId: '1',
  format: 'plain-text',
})
```

## 应用所有建议

如需一次性应用所有建议，请使用 `applyAllAiSuggestions` 命令。

```ts
editor.commands.applyAllAiSuggestions()
```

这会将每条建议的第一个替换选项应用到编辑器内容中。

如果某些建议彼此重叠，AI Suggestion 扩展会自动解决冲突，忽略后应用的重叠建议。通常这不会造成问题，因为每次更改后都会重新加载建议，AI Suggestion 扩展也会根据更新后的内容生成新建议。

## 拒绝建议

您可以使用 `rejectAiSuggestion` 命令拒绝建议。

```ts
editor.commands.rejectAiSuggestion('suggestionId')
```

拒绝建议后，该建议将不再显示在编辑器中。不过，它仍会存储在扩展的 storage 对象中，您可以调用 `storage.getSuggestions()` 获取。读取 `isRejected` 属性即可检查建议是否已被拒绝。

您可以调用 `storage.getRejections()` 获取已拒绝建议的列表。

## 应用建议后高亮显示被替换的文本

如需高亮显示建议替换的文本或为其添加标记，可以将 `applyAiSuggestion` 命令与一个用于为建议范围设置标记的命令串联起来。

```ts
editor
  .chain()
  // 应用建议
  .applyAiSuggestion({
    suggestionId: suggestion.id,
    replacementOptionId: option.id,
  })
  // 选中已更改的文本
  .command(({ tr, commands }) => {
    // 需要映射更改文本的位置，因为应用建议时这些位置可能会发生变化
    return commands.setTextSelection({
      from: tr.mapping.map(suggestion.deleteRange.from),
      to: tr.mapping.map(suggestion.deleteRange.to),
    })
  })
  // 为已更改的文本应用样式，例如加粗
  .setBold()
  // 将光标置于已更改文本的末尾
  .command(({ tr, commands }) => {
    return commands.setTextSelection(tr.mapping.map(suggestion.deleteRange.to))
  })
  .focus()
  .run()
```

## 与协作功能搭配使用

将 AI Suggestion 与 Tiptap Collaboration 搭配使用时，建议对每位用户都是私有的。这样便可以根据用户偏好或上下文显示不同的建议。建议一经接受，所有已连接的用户都可以看到（[了解更多](/ai/deprecated/resources/collaboration)）。
