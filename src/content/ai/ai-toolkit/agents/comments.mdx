## 启用评论工具

要启用评论工具，请在从 Server AI Toolkit API 获取工具定义时传入 `getThreads` 和 `editThreads` 选项。

```ts
import { getAuthHeaders } from '@/lib/server-ai-toolkit/get-auth-headers'

const response = await fetch(`${apiBaseUrl}/v4/ai/toolkit/fetch-tools`, {
  method: 'POST',
  headers: await getAuthHeaders(),
  body: JSON.stringify({
    editorContext,
    tools: {
      // Disable tiptap edit tool so that the AI can not edit the document,
      // only add comments
      tiptapEdit: false,
      // Enable comment tools
      getThreads: true,
      editThreads: true,
    },
  }),
})
```

## 执行评论工具

评论工具需要 **Tiptap Cloud 文档**，因为评论串和评论都存储在 Tiptap Document Server 上。传入 `document: { type: 'cloud', id }`，这样 AI Server 就能自动从 Document Server 获取文档。

### 请求正文

在请求正文中加入云端文档引用：

- `document.id`（`string`，必填）：文档 ID。
- `user`（`string`，可选）：创建评论的用户 ID。若省略，创建的评论不会关联用户。

```ts
const result = await fetch(`${apiBaseUrl}/v4/ai/toolkit/execute-tool`, {
  method: 'POST',
  headers: await getAuthHeaders('your-document-id'),
  body: JSON.stringify({
    editorContext,
    // Reference the Tiptap Cloud document
    document: {
      type: 'cloud',
      id: 'your-document-id',
    },
    user: 'ai-assistant',
    tool: {
      name: 'editThreads',
      input: {
        operations: [
          {
            type: 'createComment',
            threadId: 'your-thread-id',
            content: 'Consider clarifying this point.',
          },
        ],
      },
    },
  }),
})
```
