## 可用工具

Server AI Toolkit 提供了[工具定义](/ai/ai-toolkit/api-reference/rest-api)，供 AI 代理调用，以便与服务器上的文档交互。这些工具可以高效地读取内容并进行编辑。

调用 Server AI Toolkit API 端点时，AI 模型可以生成工具调用，然后通过 `/v4/ai/toolkit/execute-tool` 端点执行。这样，AI 就可以根据用户请求读取、编辑和操作文档。
