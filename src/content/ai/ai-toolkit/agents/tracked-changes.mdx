## 工作原理

1. AI 在 `trackedChanges` 模式下使用 `tiptapRead` 读取文档。
2. AI 在 `trackedChanges` 模式下使用 `tiptapEdit` 编辑文档。
3. Server AI Toolkit 通过修订扩展写入修订标记，而不是直接修改文档。
4. 客户端使用修订扩展显示修订，并允许用户接受或拒绝修订。

## 显示修订

要将服务器端 AI 编辑显示为修订，请在 `POST /v4/ai/toolkit/execute-tool` 端点配置 `reviewOptions` 参数。调用 `tiptapRead` 和 `tiptapEdit` 工具时，将审核模式设为 `{ mode: 'trackedChanges' }`。有关所有可用设置，请参阅[审核选项参考](/ai/ai-toolkit/api-reference/review-options)。

### 使用修订执行工具

调用 `execute-tool` 时传入 `reviewOptions`：

`getAuthHeaders` 辅助函数会对 JWT 签名，因此向 `fetch` 传递请求头时请保留 `await`。

```ts
import { getAuthHeaders } from '@/lib/server-ai-toolkit/get-auth-headers'

const result = await fetch(`${apiBaseUrl}/v4/ai/toolkit/execute-tool`, {
  method: 'POST',
  headers: await getAuthHeaders('your-document-id'),
  body: JSON.stringify({
    editorContext,
    document: {
      type: 'cloud',
      id: 'your-document-id',
    },
    user: 'ai-assistant',
    tool: {
      name: 'tiptapEdit',
      input: toolCallInput,
    },
    reviewOptions: {
      mode: 'trackedChanges',
      trackedChangesOptions: {
        userId: 'ai-assistant',
        userMetadata: {
          name: 'AI Assistant',
        },
      },
    },
  }),
})
```

有关完整的 `reviewOptions` 结构，包括 `trackedChangesOptions` 和 `diffUtilityOptions`，请参阅[审核选项参考](/ai/ai-toolkit/api-reference/review-options)。

### 客户端设置

在客户端安装并添加 `ServerAiToolkit` 和 `TrackedChanges` 扩展。

```tsx
import { useChat } from '@ai-sdk/react'
import { Collaboration } from '@tiptap/extension-collaboration'
import { EditorContent, useEditor } from '@tiptap/react'
import StarterKit from '@tiptap/starter-kit'
import { TrackedChanges, findSuggestions } from '@tiptap-pro/extension-tracked-changes'
import { TiptapCollabProvider } from '@tiptap-pro/provider'
import { ServerAiToolkit, getEditorContext } from '@tiptap/ai-toolkit'

export default function Page() {
  const editor = useEditor({
    immediatelyRender: false,
    extensions: [
      StarterKit.configure({ undoRedo: false }),
      Collaboration.configure({ document: doc }),
      TrackedChanges.configure({ enabled: false }),
      ServerAiToolkit,
    ],
  })

  // ... render editor and chat UI
}
```

AI 编辑文档后，所做更改会显示为修订。用户可以使用修订扩展提供的 `acceptSuggestion`、`rejectSuggestion`、`acceptAllSuggestions` 和 `rejectAllSuggestions` 命令来接受或拒绝修订。

你可以让 AI 为每项更改提供理由。借助 [评论](/comments/getting-started/overview) 扩展，每条理由都会成为与相应修订关联的评论讨论串。

### API 端点

获取工具定义时，配置 `tiptapEdit` 工具，使其能够在操作中包含 `meta` 字段。`meta` 值是针对每项编辑操作添加到工具架构中的指令。AI 创建编辑时会填写该字段，Server AI Toolkit 则会将每个非空的 `meta` 值用作该修订的理由评论。

```ts
const response = await fetch(`${apiBaseUrl}/v4/ai/toolkit/fetch-tools`, {
  method: 'POST',
  headers: await getAuthHeaders(),
  body: JSON.stringify({
    editorContext,
    tools: {
      tiptapEdit: {
        meta: 'Brief justification explaining why this change improves the document.',
      },
    },
  }),
})
```

### 执行工具并添加评论

调用 `execute-tool` 时传入 `reviewOptions`：

```ts
const result = await fetch(`${apiBaseUrl}/v4/ai/toolkit/execute-tool`, {
  method: 'POST',
  headers: await getAuthHeaders('your-document-id'),
  body: JSON.stringify({
    editorContext,
    document: {
      type: 'cloud',
      id: 'your-document-id',
    },
    user: 'ai-assistant',
    tool: {
      name: 'tiptapEdit',
      input: toolCallInput,
    },
    reviewOptions: {
      mode: 'trackedChanges',
      trackedChangesOptions: {
        userId: 'ai-assistant',
        userMetadata: {
          name: 'AI Assistant',
        },
      },
    },
  }),
})
```

编辑操作中每个非空的 `meta` 字段都会成为与相应修订关联的评论讨论串。理由会存储为讨论串的首条评论内容，并作为 `suggestionReason` 存储在讨论串数据中。

### 客户端设置

在客户端添加 `CommentsKit` 扩展，并配置 `TiptapCollabProvider`：

```tsx
import { CommentsKit } from '@tiptap-pro/extension-comments'
import { TrackedChanges } from '@tiptap-pro/extension-tracked-changes'
import { ServerAiToolkit } from '@tiptap/ai-toolkit'

const editor = useEditor({
  extensions: [
    StarterKit.configure({ undoRedo: false }),
    Collaboration.configure({ document: doc }),
    TrackedChanges.configure({ enabled: false }),
    ServerAiToolkit,
    CommentsKit.configure({
      provider, // Your TiptapCollabProvider instance
    }),
  ],
})
```

用户可以查看修订，并在评论侧边栏中阅读 AI 给出的理由。
