使用 Server AI Toolkit API 之前，需要先从 Tiptap 编辑器获取编辑器上下文数据。

`getEditorContext` 函数会从 Tiptap 编辑器中提取架构信息，并将其转换为适用于 Server AI Toolkit API 的格式。这些数据描述了文档结构，可帮助 AI 理解哪些内容有效。

## `getEditorContext`

返回描述文档结构的编辑器上下文数据，供 Server AI Toolkit API 使用。

此函数会收集扩展中的架构信息，并将其转换为适合 AI 模型处理的格式。Server AI Toolkit API 会使用返回的数据来理解文档中哪些内容有效。

<Callout title="已弃用的别名" variant="warning">
  `getSchemaAwarenessData` 仍可用于向后兼容，但已弃用。对于新的集成，请使用
  `getEditorContext`。
</Callout>

<Callout title="存储编辑器上下文数据" variant="info">
  `getEditorContext` 返回的编辑器上下文数据是可序列化为 JSON 的对象，可以存储在数据库中。
  无需每次都重新生成——只需在 Editor 扩展或架构发生变化时更新即可。
</Callout>

<Callout title="何处调用 getEditorContext" variant="info">
  `getEditorContext` 需要一个已配置的 Tiptap 编辑器实例。请在客户端编辑器设置过程中，或在其他能够实例化相同编辑器扩展的环境中生成该数据，然后在服务器端 API 调用中重用已存储的 JSON。
</Callout>

请参阅[自定义节点指南](/ai/ai-toolkit/advanced-guides/custom-nodes)中的使用示例。

### 参数

#### `editor` (`Editor`)

用于提取编辑器上下文数据的 Tiptap 编辑器实例。

#### `options?` (`GetEditorContextOptions`)

编辑器上下文的配置选项：

- `customNodes?` (`JsonItem[]`)：除默认项之外要包含的自定义编辑器上下文项。可通过此选项添加自定义节点类型，或修改现有节点定义，从而扩展供 AI 模型使用的架构信息。默认值：`[]`。

每个 `JsonItem` 对象包含以下属性：

- `extensionName` (`string`)：提供此元素的扩展名称
- `name` (`string`)：元素的英文可读名称
- `description?` (`string`)：对元素及其显示方式的说明
- `isMark?` (`boolean`)：此项是否为标记（而非节点）
- `attributes?` (`Record<string, unknown>`)：元素可能具有的属性，以 Zod 架构定义，并将转换为 JSON 架构

### 返回值

`EditorContext`：描述文档结构的编辑器上下文数据。此数据会传递给 Server AI Toolkit API 端点。

### 示例

```ts
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import { getEditorContext, ServerAiToolkit } from '@tiptap/ai-toolkit'

const editor = new Editor({
  extensions: [StarterKit, ServerAiToolkit],
})

// Get editor context data
const editorContext = getEditorContext(editor)

// Use with Server AI Toolkit API
const response = await fetch('https://api.tiptap.dev/v4/ai/toolkit/fetch-tools', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    Authorization: `Bearer ${API_TOKEN}`,
  },
  body: JSON.stringify({
    editorContext,
  }),
})
```
