`AiCaret` 扩展会在 AI 当前插入内容的位置显示光标装饰。它能在流式操作期间提供实时视觉反馈，类似于 [Collaboration Caret 扩展](/editor/extensions/functionality/collaboration-caret)。

## 用法

从 `@tiptap-pro/client-ai-toolkit` 导入 `AiCaret` 扩展，并将其添加到编辑器扩展中。

```tsx
import { AiCaret, AiToolkit } from '@tiptap-pro/client-ai-toolkit'

const editor = useEditor({
  extensions: [StarterKit, AiToolkit, AiCaret],
})
```

在 `streamHtml`、`streamTool` 和 `tiptapEditWorkflow` 等流式操作期间，光标会自动显示。流式处理结束后，光标会消失。

## 配置

你可以配置光标的超时时间、用户标签和渲染方式。

```tsx
AiCaret.configure({
  // 最后一次更新后光标继续显示的时长（毫秒）
  timeout: 2000,
  // 光标标签的用户信息
  user: {
    name: 'AI',
    color: '#a5b4fc',
  },
})
```

### 选项

| 选项      | 类型                                 | 默认值                              | 说明                                      |
| --------- | ------------------------------------ | ---------------------------------- | ----------------------------------------- |
| `timeout` | `number`                             | `2000`                             | 最后一次更新后光标继续显示的时长（毫秒）。 |
| `user`    | `{ name: string, color: string }`    | `{ name: 'AI', color: '#a5b4fc' }` | 光标标签上显示的名称和颜色。               |
| `render`  | `(user: AiCaretUser) => HTMLElement` | 内置渲染函数                       | 用于渲染光标 DOM 元素的自定义函数。        |

## CSS 样式

默认渲染函数会创建一个带有 `tiptap-ai-caret` 类的 DOM 元素，以及一个带有 `tiptap-ai-caret__label` 类的标签。添加以下 CSS 来设置光标样式：

```css
.tiptap .tiptap-ai-caret {
  border-left: 1px solid #0d0d0d;
  border-right: 1px solid #0d0d0d;
  margin-left: -1px;
  margin-right: -1px;
  pointer-events: none;
  position: relative;
  word-break: normal;
}

.tiptap .tiptap-ai-caret__label {
  border-radius: 3px 3px 3px 0;
  color: #0d0d0d;
  font-size: 12px;
  font-style: normal;
  font-weight: 600;
  left: -1px;
  line-height: normal;
  padding: 0.1rem 0.3rem;
  position: absolute;
  top: -1.4em;
  user-select: none;
  white-space: nowrap;
}
```

光标和标签的 `border-color` 与 `background-color` 会根据 `user.color` 选项以内联样式设置。

## 自定义渲染

你可以提供自定义 `render` 函数，完全控制光标 DOM 元素。

```tsx
AiCaret.configure({
  render: (user) => {
    const el = document.createElement('span')
    el.className = 'my-custom-ai-caret'
    el.style.borderColor = user.color
    el.textContent = user.name
    return el
  },
})
```

## 事件

`AiCaret` 扩展通过 Tiptap 事件 API 触发事件。你可以订阅这些事件，以便在光标移动时作出响应，例如通过自定义 UI 行为跟随 AI 的写入位置。

### 可用事件

| 事件                     | 说明                                                    | 负载                   |
| ------------------------ | ------------------------------------------------------- | ---------------------- |
| `aiCaret:positionChanged` | AI 光标在流式或编辑操作期间更新位置时触发。             | `{ position: number }` |

`position` 值是一个 ProseMirror 文档位置，指向 AI 光标当前所在的位置。

### 订阅事件

使用 `editor.on` 监听事件；不再需要时，使用 `editor.off` 取消订阅。

```tsx
editor.on('aiCaret:positionChanged', ({ position }) => {
  console.log('AI caret moved to position', position)
})
```

流式处理期间，`aiCaret:positionChanged` 事件可能会频繁触发——每个流式数据块触发一次。如果处理程序执行开销较大的操作，可以考虑使用 `requestAnimationFrame` 或 `lodash.throttle` 等工具进行节流。
