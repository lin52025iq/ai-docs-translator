Tiptap Edit 钩子可让你在操作应用到文档之前拦截这些操作。你可以根据自定义逻辑接受或拒绝每项操作，也可以在接受操作时选择修改内容或操作类型。

<Callout title="实验性功能" variant="info">
  Tiptap Edit 钩子目前仍是实验性功能，其 API 未来可能会发生变化。
</Callout>

## 使用场景

- **内容审核**：在 AI 生成的内容写入文档前对其进行筛选或清理
- **自定义验证**：确保操作符合业务要求
- **日志记录与分析**：跟踪 AI 所做的更改
- **访问控制**：防止修改文档的特定部分

## `beforeOperation` 钩子

每次应用 Tiptap Edit 操作之前，都会调用 `beforeOperation` 钩子。该钩子会接收操作上下文，并返回要执行的动作。

### 钩子上下文

该钩子会接收一个 `BeforeOperationContext` 对象，其中包含以下属性：

| 属性             | 类型                           | 描述                                                                                                       |
| ---------------- | ------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| `operation`      | `TiptapEditOperation`          | 正在执行的操作，包含 `type`、`target` 和 `content`                                                                  |
| `operationIndex` | `number`                       | 此操作在批次中的索引（从 0 开始）                                                                    |
| `doc`            | `Node`                         | 事务当前阶段的文档                                                              |
| `deleteContent`  | `Fragment \| null`             | 将被删除的内容（对于 `insertBefore`/`insertAfter`，值为 `null`）                                        |
| `insertContent`  | `Fragment`                     | 将要插入的内容（作为 [ProseMirror Fragment](https://prosemirror.net/docs/ref/#model.Fragment)） |
| `range`          | `{ from: number; to: number }` | 将应用操作的位置范围                                                            |

若要在钩子中访问编辑器实例，请在定义钩子时通过闭包捕获该实例。

### 钩子返回值

钩子必须返回以下某个动作：

```ts
// Accept the operation unchanged
{ action: 'accept' }

// Accept with a modified fragment (overrides the content to insert)
{ action: 'accept', fragment: modifiedFragment }

// Accept with a modified operation type
{ action: 'accept', operationType: 'insertAfter' }

// Accept with both modifications
{ action: 'accept', fragment: modifiedFragment, operationType: 'replace' }

// Skip this operation and record an error
{ action: 'reject', error: 'Reason for rejection' }
```

`fragment` 属性可用于替换将要插入的 [ProseMirror Fragment](https://prosemirror.net/docs/ref/#model.Fragment)。`operationType` 属性可用于更改操作类型（`'replace'`、`'insertBefore'` 或 `'insertAfter'`）。

拒绝某项操作后，批次中的其余操作仍会继续执行。

## 用法

### 与 `executeTool` 搭配使用

```ts
import { getAiToolkit } from '@tiptap-pro/client-ai-toolkit'
import { log } from './lib/logger'

const toolkit = getAiToolkit(editor)

const result = toolkit.executeTool({
  toolName: 'tiptapEdit',
  input: {
    operations: [['replace', 'abc123', '<p>New content</p>']],
  },
  tiptapEditHooks: {
    beforeOperation: (context) => {
      // Log every operation
      log(`Operation type: ${context.operation.type}`)

      // Example: reject operations that delete too much content
      if (context.deleteContent && context.deleteContent.size > 1000) {
        return {
          action: 'reject',
          error: 'Content to delete is too large',
        }
      }

      return { action: 'accept' }
    },
  },
})
```

### 与 `streamTool` 搭配使用

```ts
const result = toolkit.streamTool({
  toolCallId: 'call_123',
  toolName: 'tiptapEdit',
  hasFinished: true,
  input,
  tiptapEditHooks: {
    beforeOperation: (context) => {
      // Change all replacements to insertAfter operations
      if (context.operation.type === 'replace') {
        return {
          action: 'accept',
          operationType: 'insertAfter',
        }
      }

      return { action: 'accept' }
    },
  },
})
```

### 与 `tiptapEditWorkflow` 搭配使用

```ts
const { content } = toolkit.tiptapRead()

const operations = await callApiEndpoint({ content, task: 'Improve the writing' })

const result = toolkit.tiptapEditWorkflow({
  operations,
  workflowId: 'edit-123',
  tiptapEditHooks: {
    beforeOperation: (context) => {
      // Only allow replacements, not insertions
      if (context.operation.type !== 'replace') {
        return {
          action: 'reject',
          error: 'Only replace operations are allowed',
        }
      }

      return { action: 'accept' }
    },
  },
})
```
