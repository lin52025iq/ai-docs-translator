了解有助于使用 AI Toolkit 的基本概念。

## 位置

AI Toolkit 的方法允许你在文档的特定位置[读取](/ai/ai-toolkit/client/api-reference/read-the-document)和[编辑](/ai/ai-toolkit/client/api-reference/edit-the-document)文档。

位置用于定位文档中的元素，以整数表示。

文档中的第一个位置是 0。最后一个位置等于文档内容的大小。

```ts
const position = 0
const lastPosition = editor.state.doc.content.size
```

可以通过编辑器状态的 `selection` 属性获取光标位置。

```ts
const position = editor.state.selection.head
```

## 范围

范围由一对位置组成，表示文档中一段连续的内容。

```ts
import { Range } from '@tiptap/core'

const range: Range = { from: 0, to: 100 }
```

整个文档的范围是：

```ts
const range = { from: 0, to: editor.doc.content.size }
```

可以通过编辑器状态的 `selection` 属性获取选区范围。

```ts
const range = { from: editor.state.selection.from, to: editor.state.selection.to }
```

你可以在特定位置或范围插入或读取内容。

```ts
const range: Range = { from: 0, to: 100 }

// Read the document
editor.commands.tiptapRead({ range })

editor.commands.insertHtml(
  '<p>AI-generated content</p>',
  {
    position: range,
  }
)
```

范围用于确定[建议](#suggestion)的位置。

## 建议

建议表示对文档的一项拟议更改。当 AI 修改文档时，你可以将更改显示为建议，让用户查看并接受或拒绝。详细了解[审阅界面指南](/ai/ai-toolkit/client/agents/review-changes)。

## 节点范围

节点范围是文档中顶层节点组成的范围。

顶层节点是 `doc` 节点的直接子节点。

节点范围是一个包含两个属性的对象：

- `from`（数字）：范围内第一个节点的索引（包含）
- `to`（数字）：最后一个节点之后的索引（不包含上界）

```ts
// Range from the first to the 100th node
const nodeRange: NodeRange = { from: 0, to: 100 }
```

整个文档的节点范围是：

```ts
const nodeRange = { from: 0, to: editor.state.doc.childCount }
```

## Tiptap Read 和 Tiptap Edit

Tiptap Edit 是 Tiptap 开发的一种格式，可帮助 AI 高效、准确地编辑文档。借助它，AI 无需替换整个文档，就能快速进行细小而精准的编辑。它最多可减少 95% 的 token 用量。

AI 代理可以将 Tiptap Edit 作为[工具](/ai/ai-toolkit/client/agents/tools)使用，也可以将其作为[工作流](/ai/ai-toolkit/client/workflows/tiptap-edit)使用。

要使用 Tiptap Edit，必须先通过 Tiptap Read 读取文档。AI 代理可以将 Tiptap Read 作为[工具](/ai/ai-toolkit/client/agents/tools)使用，也可以将其作为[工作流](/ai/ai-toolkit/client/workflows/tiptap-edit)使用。

```ts
const { content } = toolkit.tiptapRead()
toolkit.tiptapEdit({ content })
```
