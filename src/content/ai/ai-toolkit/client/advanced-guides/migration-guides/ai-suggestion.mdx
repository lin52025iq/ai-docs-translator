AI Suggestion 扩展可以使用 AI 审阅文档，并显示用户可以接受或拒绝的建议。

按照[校对工具指南](/ai/ai-toolkit/client/workflows/proofreader)操作，即可通过 AI Toolkit 实现相同的功能。

## 审阅文档

在[校对工具指南](/ai/ai-toolkit/client/workflows/proofreader)中，`proofreaderWorkflow` 方法会根据 AI 模型生成的 HTML 内容，显示一系列用户可以接受或拒绝的建议。

建议查看 `proofreaderWorkflow` 方法的 [API 参考](/ai/ai-toolkit/client/api-reference/workflows)，详细了解其参数和自定义选项。

## 接受和拒绝建议

如需了解建议的存储和管理方式，请参阅[建议指南](/ai/ai-toolkit/client/agents/review-changes)。

具体来说，可以使用 `acceptSuggestion` 方法接受建议。

## 自定义建议的外观

通过 AI Toolkit 的选项，可以完全自定义建议的外观。请参阅[自定义建议样式指南](/ai/ai-toolkit/client/agents/review-changes/style-suggestions)。

你还可以使用 `renderDecorations` 选项，在建议中[渲染 React 和 Vue 组件](/ai/ai-toolkit/client/agents/review-changes/style-suggestions#render-react-components-inside-a-suggestion)。[查看 API 参考](/ai/ai-toolkit/client/api-reference/suggestions)。配置此选项后，选中建议时可以显示弹出框或工具提示。

## 提升速度和性能

AI Toolkit 的建议工具比 AI Suggestion 扩展快得多，因为它支持流式输出建议（示例请参阅[校对工具指南](/ai/ai-toolkit/client/workflows/proofreader)）。这比 AI Suggestion 扩展有了很大改进：该扩展会一次性加载所有建议，当建议数量较多时可能导致性能问题。

AI Toolkit 还支持将文档拆分为多个块，然后分别发送给 AI 进行处理。并行处理这些块可以显著降低延迟。

```ts
import { proofreaderApi } from './api'

// Get the AI Toolkit
const toolkit = getAiToolkit(editor)

// Split the document into chunks of the default size
const chunks = toolkit.getHtmlChunks()

// Iterate over each chunk.
for (const chunk of chunks) {
  // Read the content of the chunk.
  const { content } = toolkit.tiptapRead({ range: chunk.range })
  // Call the AI to generate the operations that should be applied
  // to that chunk.
  const operations = await proofreaderApi({ content })
  // Apply the operations using the `proofreaderWorkflow` method,
  // only on the range of that chunk.
  toolkit.proofreaderWorkflow({
    range: chunk.range,
    operations,
  })
}
```
