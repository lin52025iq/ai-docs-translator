AI Assistant 扩展可帮助你集成 AI 聊天机器人，让它根据用户定义的任务编辑文档。

按照 [AI 代理聊天机器人指南](/ai/ai-toolkit/client/agents/ai-agent-chatbot)，即可使用 AI Toolkit 实现相同的功能。

如需查看 AI 聊天机器人所做的更改，请参阅[查看更改指南](/ai/ai-toolkit/client/agents/review-changes)。AI Toolkit 内置了显示建议的系统，用户可以接受或拒绝这些建议，因此无需将其与 AI Changes 或 AI Suggestion 扩展结合使用来实现此功能。

## 实现检查点

AI Assistant 扩展具有检查点系统，可用于保存文档和对话的状态，并将其恢复到之前的某个时间点。

使用 Tiptap 的编辑器命令，你也可以在特定时间点保存文档内容的快照，并在之后恢复。

```ts
// 对文档进行快照
const document = editor.getJSON()

// 稍后恢复该快照
editor.setContent(document)
```

此系统让你可以灵活地在任何时间点保存和恢复文档。与 AI Assistant 扩展相比，这是一个改进；后者仅会在聊天对话的少数几个事件中创建检查点。
