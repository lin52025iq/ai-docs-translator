AI Toolkit 可搭配任何后端语言使用。`@tiptap-pro/client-ai-toolkit-tool-definitions` 包含一个 CLI，可将工具定义和工作流配置输出为 JSON，因此你可以在 Python、Go、Ruby 或任何其他语言中使用它们。

## 设置

为 Tiptap 的私有 npm 注册表配置身份验证。请按照[私有注册表指南](/guides/pro-extensions)设置 `.npmrc` 文件并添加访问令牌。

<Callout title="需要 Node.js" variant="hint">
  CLI 需要 Node.js 18 或更高版本。你只需使用 Node.js 运行 CLI 并生成 JSON 文件，后端可以使用任何语言。
</Callout>

## 生成工具定义

运行 CLI，生成包含所有默认工具的 `tool-definitions.json` 文件：

```bash
npx @tiptap-pro/client-ai-toolkit-tool-definitions@latest tool-definitions > tool-definitions.json
```

输出是一个 JSON 数组。每个条目包含：

- `name`：工具的唯一标识符
- `description`：提供给 AI 模型的指令
- `inputSchema`：[JSON Schema](https://json-schema.org/)，用于描述工具的输入参数

### 在后端中使用

在后端加载 JSON 文件，并将工具定义转换为 AI 服务提供商所需的格式。例如，使用 OpenAI SDK 的 Python 示例：

```python
import json

with open("tool-definitions.json") as f:
    tool_definitions = json.load(f)

# Convert to OpenAI tool format
tools = [
    {
        "type": "function",
        "function": {
            "name": tool["name"],
            "description": tool["description"],
            "parameters": tool["inputSchema"],
        },
    }
    for tool in tool_definitions
]
```

## 生成工作流配置

每个工作流命令都会输出一个 JSON 对象，其中包含 `systemPrompt`（以及可选的 `jsonOutputSchema`），供你传递给 AI 服务提供商。

### 插入内容工作流

```bash
npx @tiptap-pro/client-ai-toolkit-tool-definitions@latest insert-content-workflow > insert-content-workflow.json
```

输出：
- `systemPrompt`：提供给 AI 模型的指令

### 校对工作流

```bash
npx @tiptap-pro/client-ai-toolkit-tool-definitions@latest proofreader-workflow > proofreader-workflow.json
```

输出：
- `systemPrompt`：提供给 AI 模型的指令
- `jsonOutputSchema`：[JSON Schema](https://json-schema.org/)，用于验证 AI 输出

### Tiptap 编辑工作流

```bash
npx @tiptap-pro/client-ai-toolkit-tool-definitions@latest tiptap-edit-workflow > tiptap-edit-workflow.json
```

输出：
- `systemPrompt`：提供给 AI 模型的指令
- `jsonOutputSchema`：[JSON Schema](https://json-schema.org/)，用于验证 AI 输出

### 评论工作流

```bash
npx @tiptap-pro/client-ai-toolkit-tool-definitions@latest edit-threads-workflow > edit-threads-workflow.json
```

输出：
- `systemPrompt`：提供给 AI 模型的指令
- `jsonOutputSchema`：[JSON Schema](https://json-schema.org/)，用于验证 AI 输出

### 模板工作流

模板工作流需要 HTML 模板作为输入：

```bash
npx @tiptap-pro/client-ai-toolkit-tool-definitions@latest template-workflow --html-template '<p _templateslot="title">Title</p><p _templateslot="body">Body</p>' > template-workflow.json
```

输出：
- `systemPrompt`：提供给 AI 模型的指令（包含模板）
- `jsonOutputSchema`：[JSON Schema](https://json-schema.org/)，用于验证 AI 输出

### 在后端中使用工作流

加载 JSON 文件，并将系统提示词和 Schema 传递给 AI 服务提供商。以下是使用 OpenAI SDK 的 Python 示例：

```python
import json

with open("proofreader-workflow.json") as f:
    workflow = json.load(f)

response = client.chat.completions.create(
    model="gpt-5.6-luna",
    messages=[
        {"role": "system", "content": workflow["systemPrompt"]},
        {"role": "user", "content": json.dumps({
            "content": "<p _hash='abc123'>Document content here</p>",
            "task": "Correct all grammar and spelling mistakes",
        })},
    ],
    response_format={
        "type": "json_schema",
        "json_schema": {
            "name": "proofreader_output",
            "schema": workflow["jsonOutputSchema"],
        },
    },
)
```

## CLI 参考

### `tool-definitions`

以 JSON 格式生成工具定义。

```bash
npx @tiptap-pro/client-ai-toolkit-tool-definitions@latest tool-definitions [options]
```

| 选项 | 说明 |
| --- | --- |
| `--tools <names...>` | 要启用的工具名称列表，以空格分隔。省略时使用默认工具集。有效名称：`tiptapRead`、`tiptapEdit`、`tiptapReadSelection`、`getThreads`、`editThreads`。 |
| `--operation-meta <description>` | 编辑操作中 `meta` 字段的说明。 |

### `tiptap-edit-workflow`

以 JSON 格式生成 Tiptap 编辑工作流配置。

```bash
npx @tiptap-pro/client-ai-toolkit-tool-definitions@latest tiptap-edit-workflow [options]
```

| 选项 | 说明 |
| --- | --- |
| `--operation-meta <description>` | 编辑操作中 `meta` 字段的说明。 |

### `proofreader-workflow`

以 JSON 格式生成校对工作流配置。

```bash
npx @tiptap-pro/client-ai-toolkit-tool-definitions@latest proofreader-workflow [options]
```

| 选项 | 说明 |
| --- | --- |
| `--operation-meta <description>` | 操作中 `meta` 字段的说明。 |

### `template-workflow`

以 JSON 格式生成模板工作流配置。

```bash
npx @tiptap-pro/client-ai-toolkit-tool-definitions@latest template-workflow --html-template <html>
```

| 选项 | 说明 |
| --- | --- |
| `--html-template <html>` | **（必填）** HTML 模板字符串。 |

### `edit-threads-workflow`

以 JSON 格式生成评论工作流配置。

```bash
npx @tiptap-pro/client-ai-toolkit-tool-definitions@latest edit-threads-workflow
```

无选项。

### `insert-content-workflow`

以 JSON 格式生成插入内容工作流配置。

```bash
npx @tiptap-pro/client-ai-toolkit-tool-definitions@latest insert-content-workflow
```

无选项。
