首先，<a href="https://tiptap.dev/contact-sales?form=ai-toolkit">联系我们的团队</a>，购买付费版
AI Toolkit 附加组件。

获得访问权限后，请按照[私有注册表指南](/guides/pro-extensions)配置包管理器。

然后，安装软件包：

```bash
npm install @tiptap-pro/client-ai-toolkit
```

将扩展添加到编辑器中。

```tsx
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import { AiToolkit, getAiToolkit } from '@tiptap-pro/client-ai-toolkit'

const editor = new Editor({
  // Add the AI Toolkit extension
  extensions: [AiToolkit],
})

// Get the AI Toolkit instance
const toolkit = getAiToolkit(editor)
```

恭喜！你已完成 AI Toolkit 的设置。现在可以开始构建 AI 集成了。

<Callout title="所需的 Tiptap 版本" variant="warning">
  请确保所有 `@tiptap/*` 软件包的版本均为 `3.12.0` 或更高。
</Callout>
