Tiptap [Schema](/editor/core-concepts/schema) 描述了文档可以（或不可以）包含哪些元素。Tiptap 的 **Schema 感知**功能可以帮助 AI 模型更好地理解文档。

<Callout title="为什么需要 Schema 感知？" variant="default">
  如果没有 Schema 感知，AI 模型可能会生成 Tiptap 编辑器不支持的内容。例如，它可能会在不支持表格的文档中生成表格。启用
  Schema 感知后，AI 模型会知道不支持表格节点，并拒绝生成表格。
</Callout>

如需了解如何逐步集成 Schema 感知，请参阅 [Schema 感知指南](/ai/ai-toolkit/client/agents/schema-awareness)。

## API 参考

## `getHtmlSchemaAwareness`

返回一个描述文档 Schema 的字符串。此字符串应添加到发送给 AI 模型的系统提示末尾。

目前，`getHtmlSchemaAwareness` 方法仅支持生成 HTML 内容的 AI 模型。我们计划在未来支持其他格式。

### 参数（`GetHtmlSchemaAwarenessOptions`）

- `customNodes?`（`HtmlItem[]`）：除默认项目外，还要包含的自定义 Schema 感知项目。此选项中定义的值会覆盖自定义扩展 `addHtmlSchemaAwareness` 配置项中定义的 Schema 感知数据，也会覆盖 Tiptap 官方扩展的 Schema 感知数据。默认值：`[]`。

每个 `HtmlItem` 对象都包含以下属性：

- `extensionName`（`string`）：提供此元素的[扩展名称](/editor/extensions/custom-extensions/create-new/extension#name)
- `tag`（`string`）：此元素对应的 HTML 标签名
- `name`（`string`）：此元素易于理解的英文名称
- `description?`（`string | null`）：对该元素是什么以及它如何显示的说明
- `attributes?`（`HtmlAttribute[]`）：HTML 标签可能包含的属性。如果为 `undefined`，则表示没有属性。每个 `HtmlAttribute` 对象都包含以下属性：
  - `attr`（`string`）：HTML 代码中的属性名称
  - `value?`（`string`）：如果 `value` 不是 `undefined`，则该元素的此属性始终具有该值。此项用于值固定的属性
  - `description?`（`string | null`）：用英文编写的属性说明，帮助 AI 模型理解

### 返回值

`string`：适用于系统提示的易读 Schema 感知文本

### 示例

```ts
// 获取 Schema 感知字符串
const schemaAwareness = toolkit.getHtmlSchemaAwareness()
```

## `addHtmlSchemaAwareness`（扩展配置项）

添加有关自定义 Node 或 Mark 的 Schema 感知信息。此选项用于配置自定义节点和标记，让 AI 模型了解它们。

此配置项适用于[自定义 Node 和 Mark 扩展](/editor/extensions/custom-extensions/create-new/node)。

### 参数（`HtmlItem`）

- `tag`（`string`）：此元素对应的 HTML 标签名
- `name`（`string`）：此元素易于理解的英文名称
- `description?`（`string | null`）：对该元素是什么以及它如何显示的说明
- `attributes?`（`HtmlAttribute[]`）：HTML 标签可能包含的属性。如果为 `undefined`，则表示没有属性。每个 `HtmlAttribute` 对象都包含以下属性：
  - `attr`（`string`）：HTML 代码中的属性名称
  - `value?`（`string`）：如果 `value` 不是 `undefined`，则该元素的此属性始终具有该值。此项用于值固定的属性
  - `description?`（`string | null`）：用英文编写的属性说明，帮助 AI 模型理解
