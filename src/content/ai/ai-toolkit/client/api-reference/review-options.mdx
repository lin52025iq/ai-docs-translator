所有[编辑文档](/ai/ai-toolkit/client/api-reference/edit-the-document)的 AI Toolkit 方法都包含 `reviewOptions` 属性。配置此属性后，文档编辑完成后即可显示审阅界面。

```ts
const result = toolkit.executeTool({
  toolName: 'tiptapEdit',
  input,
  // Display a UI that allows the user to review
  // the changes after they are applied.
  reviewOptions: { mode: 'review' },
})
```

编辑文档后，将显示一组[建议](/ai/ai-toolkit/client/agents/review-changes)。

`reviewOptions` 属性接受一个 `ReviewOptions` 配置对象。

## `ReviewOptions`

- `mode?`（`'disabled' | 'review' | 'preview' | 'trackedChanges'`）：在应用更改之前还是之后审阅更改。默认值：`'disabled'`
  - `'disabled'`：不显示审阅界面。
  - `'review'`：先应用更改，然后显示审阅界面，供用户撤销更改。
  - `'preview'`：应用更改之前显示预览界面，供用户接受或拒绝更改。
  - `'trackedChanges'`：使用 [Tracked Changes](/tracked-changes/getting-started/overview) 扩展将 AI 生成的更改编码为修订记录，用户可以逐项接受或拒绝更改。
- `displayOptions?`（`DisplayOptions`）：自定义建议在编辑器界面中的显示方式。此选项会设置 [`Suggestion`](/ai/ai-toolkit/client/api-reference/suggestions#the-suggestion-object) 类型的 `displayOptions` 属性。[查看可用选项](/ai/ai-toolkit/client/api-reference/suggestions#the-suggestion-object)。
- `metadata?`（`Record<string, any>`）：建议的额外元数据，可用于存储相关信息（例如来源或类别）。扩展内部不会使用此属性，但开发者可借此自定义建议在界面中的显示方式。
- `trackedChangesOptions?`（`{ userId: string, userMetadata?: Record<string, unknown> | null }`）：`trackedChanges` 模式的配置。`userId` 用于标识修订记录的作者。`userMetadata` 用于存储有关作者的其他信息。
- `commentsOptions?`（`{ threadData?: Record<string, unknown>, commentData?: Record<string, unknown> }`）：与 `trackedChanges` 模式一起提供时，操作元数据（编辑操作中的 `meta` 字段）会成为与每条修订记录关联的评论线程。此选项需要 [Comments](/comments/getting-started/overview) 扩展。
- `useDiffUtility?`（`boolean`）：是否使用[差异工具](/ai/ai-toolkit/client/api-reference/diff-utility)比较更改前后的文档，并以丰富的差异视图显示删除和新增的内容。如果为 `false`，删除和新增的内容会作为单个更改显示在一个整体区块中。默认值：`true`
- `diffUtilityOptions?`（[`ExternalDiffUtilityOptions`](/ai/ai-toolkit/client/api-reference/diff-utility#parameters-diffutilityoptions)）：使用差异工具比较文档时的选项。[查看可用选项](/ai/ai-toolkit/client/api-reference/diff-utility#parameters-diffutilityoptions)。
