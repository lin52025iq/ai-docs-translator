## `diffUtility`

比较两个文档，并返回它们之间的更改列表。

### 支持的格式

Diff Utility 可用于比较整个文档或文档的一部分。

若要比较整个文档，可以使用 [Tiptap JSON 格式](/editor/core-concepts/introduction#content)或 [ProseMirror Node](https://prosemirror.net/docs/ref/#model.Node) 提供文档。

若要比较文档的一部分，可以将其作为 Tiptap JSON 片段（Tiptap JSON 节点列表）或 [ProseMirror Fragment](https://prosemirror.net/docs/ref/#model.Fragment) 提供。

### 参数（`DiffUtilityOptions`）

- `schema`（`Schema`）：编辑器中使用的 ProseMirror schema。可从编辑器实例获取：`editor.schema`
- `docA`（`Node | Fragment | JSONContent | JSONContent[]`）：原始文档。可以是 ProseMirror Node/Fragment 或 Tiptap JSON
- `docB`（`Node | Fragment | JSONContent | JSONContent[]`）：修改后的文档。可以是 ProseMirror Node/Fragment 或 Tiptap JSON
- `simplifyChanges?`（`boolean`）：是否简化更改：如果同一个词中有多个更改，则将它们合并为一项更改。`mode` 为 `'block'` 时不适用。默认值：`true`
- `ignoreAttributes?`（`string[]`）：要忽略的属性。默认值：`['id', 'data-thread-id']`
- `ignoreMarks?`（`string[]`）：要忽略的标记。默认值：`['inlineThread']`
- `nodeComparators?`（`Record<string, (nodeA: Node, nodeB: Node) => boolean | undefined>`）：*实验性功能。仅在确有必要时使用。建议对文档进行建模，使相同内容具有相同的标记。* 按节点类型指定的属性比较器，支持所有差异比较模式，包括嵌套节点。回调接收应用 `ignoreAttributes` 和 `ignoreMarks` 后的 ProseMirror 节点；仅当类型和标记相同而属性不同时才会运行。返回 `true` 表示允许属性差异；返回 `false` 或 `undefined` 则保留该差异。类型、标记、文本和子节点仍按常规方式比较。回调必须同步且具有确定性。这只会更改比较方式，不会影响应用替换时的元数据保留。
- `changeMergeDistance?`（`number | null`）：将未更改范围视为重要内容的最小长度。短于此值的未更改范围会并入相邻更改，合并为一项更改。设为 `null` 或 `undefined` 时使用自动计算的默认值。`mode` 为 `'block'` 时不适用。默认值：`10`
- `groupInlineChanges?`（`number`）：控制在 `smart` 模式下，何时将内联编辑合并为一项块级更改。使用 `1`（默认值）仅在所有内联内容都已更改时合并；使用 `0` 始终合并；使用 `2` 则从不合并。
- `mode?`（`'smart' | 'inline' | 'block'`）：要使用的差异比较模式。
  - `'smart'`（默认值）平衡块级和内联级输出，以便清晰地查看建议。
  - `'inline'` 执行字符级差异比较，精确识别文本中的更改。
  - `'block'` 执行块级差异比较，将每个顶层节点视为一个整体。在块模式下，`simplifyChanges` 和 `changeMergeDistance` 不起作用。

### 返回值（`Change[]`）

返回更改列表。每个 `Change` 项包含：

- `rangeA`（`Range`）：原始文档中发生更改的范围
- `rangeB`（`Range`）：修改后文档中发生更改的范围

### 示例

```ts
import { diffUtility } from '@tiptap-pro/client-ai-toolkit'

// Compute changes between two documents (uses 'smart' mode by default)
const changes = diffUtility({
  schema: editor.schema,
  docA,
  docB,
})

// Use block-level diffing
const blockChanges = diffUtility({
  schema: editor.schema,
  docA,
  docB,
  mode: 'block',
})

// Use inline (character-level) diffing
const inlineChanges = diffUtility({
  schema: editor.schema,
  docA,
  docB,
  mode: 'inline',
})
```

# 实时比较文档

实时比较两个文档，并在编辑器中显示差异。

<Callout title="适用于非 AI 场景">
  此功能无需 AI 即可使用。它可以比较任意两个文档，无论文档是否由 AI 生成。
</Callout>

如需逐步了解如何比较文档，请参阅[比较文档指南](/ai/ai-toolkit/client/advanced-guides/compare-documents)。

## `startComparingDocuments`

开始与另一个文档进行实时比较。差异会以建议的形式显示在内联差异视图中，编辑器会同时展示旧内容和新内容。

### 参数（`StartComparingDocumentsOptions`）

- `otherDoc?`（`Node`）：要与之比较的文档，是一个 [ProseMirror Node 对象](https://prosemirror.net/docs/ref/#model.Node)。如果省略，则默认为当前文档的快照
- `displayOptions?`（`DisplayOptions`）：控制如何将差异渲染为建议。[查看可用选项](/ai/ai-toolkit/client/api-reference/suggestions#the-suggestion-object)。
- `debounceTimeout?`（`number`）：重新计算差异前等待的毫秒数。值较低会让应用看起来响应更快，但可能导致大型文档出现性能问题。默认值：`500`
- `diffUtilityOptions?`（[`ExternalDiffUtilityOptions`](/ai/ai-toolkit/client/api-reference/diff-utility#parameters-diffutilityoptions)）：使用差异比较工具比较文档时的选项。[查看可用选项](/ai/ai-toolkit/client/api-reference/diff-utility#parameters-diffutilityoptions)。

### 返回值

`void`

### 示例

```ts
// Start comparing changes with another document
toolkit.startComparingDocuments({
  otherDoc,
})
```

## `stopComparingDocuments`

停止实时比较并清除所有建议，使差异视图不再显示。

### 返回值

`void`

### 示例

```ts
// Stop comparison and clear decorations
toolkit.stopComparingDocuments()
```

## 接受和拒绝更改

比较文档时，更改会以建议的形式显示。若要接受或拒绝单项更改，或一次性接受或拒绝所有更改，请使用建议相关方法：

- [`acceptSuggestion`](/ai/ai-toolkit/client/api-reference/suggestions#acceptsuggestion)：接受指定更改
- [`rejectSuggestion`](/ai/ai-toolkit/client/api-reference/suggestions#rejectsuggestion)：拒绝指定更改
- [`acceptAllSuggestions`](/ai/ai-toolkit/client/api-reference/suggestions#acceptallsuggestions)：接受所有更改
- [`rejectAllSuggestions`](/ai/ai-toolkit/client/api-reference/suggestions#rejectallsuggestions)：拒绝所有更改

如需查看使用示例，请参阅[比较文档指南](/ai/ai-toolkit/client/advanced-guides/compare-documents)。
