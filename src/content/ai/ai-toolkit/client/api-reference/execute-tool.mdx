使用 `executeTool` 将 AI 代理发出的工具调用应用到编辑器。

将[工具定义](/ai/ai-toolkit/client/agents/tools)添加到 AI 代理后，AI 代理便会生成工具调用。使用 `executeTool` 方法将这些工具调用应用到编辑器。

## `executeTool`

根据名称和输入执行受支持的工具。

### 参数（`ExecuteToolOptions`）

- `toolName`（`string`）：要执行的工具。可选值包括[可用工具](/ai/ai-toolkit/client/agents/tools)。
- `input`（`unknown`）：与工具参数输入架构相符的 JSON 对象。如果该工具不需要参数，请传入空对象（`{}`）。
- `chunkSize?`（`number`）：可作为输入传递给 AI 模型的字符串最大长度。此参数可防止 AI 一次读取过多内容，从而避免超出 AI 模型的上下文窗口。默认值：`32000`。读取类工具会使用此参数控制文档的分块方式。
- `reviewOptions?`（[`ReviewOptions`](/ai/ai-toolkit/client/api-reference/review-options)）：控制预览和审阅行为。[查看可用选项](/ai/ai-toolkit/client/api-reference/review-options)。
- `commentsOptions?`（`CommentsOptions`）：评论和讨论串操作的选项。可用于向评论和讨论串的创建或更新操作传递自定义数据。`data` 属性用于讨论串数据，`commentData` 用于评论数据。
  - `threadData?`（`Record<string, any>`）：使用 `editThreads` 工具创建的 AI 生成讨论串的额外元数据
  - `commentData?`（`Record<string, any>`）：使用 `editThreads` 工具创建的 AI 生成评论的额外元数据
- `tiptapEditHooks?`（`TiptapEditHooks`）：用于拦截和修改 Tiptap Edit 操作的钩子。详情请参阅 [Tiptap Edit 钩子指南](/ai/ai-toolkit/client/advanced-guides/tiptap-edit-hooks)。
  - `beforeOperation?`（`(context: BeforeOperationContext) => BeforeOperationResult`）：在应用每项操作之前调用。返回 `{ action: 'accept' }` 以应用操作（可选通过 `fragment` 或 `operationType` 覆盖相应值），或返回 `{ action: 'reject', error }` 以跳过操作。

### 返回值（`ExecuteToolResult`）

- `output`（`object`）：工具执行的响应对象，供 AI 代理读取。对象结构因执行的工具而异。
- `hasError`（`boolean`）：执行过程中是否发生错误
- `unknownTool`（`boolean`）：AI Toolkit 是否无法识别 `toolName`
- `docChanged`（`boolean`）：工具调用是否修改了文档。

### 示例

```ts
// Handle the tiptapRead tool call
const result = toolkit.executeTool({
  toolName: 'tiptapRead',
  input: {
    from: 0,
  },
})
```

如需完整的实践教程，请参阅 [AI 代理聊天机器人指南](/ai/ai-toolkit/client/agents/ai-agent-chatbot)。

## `streamTool`

在工具调用流式传输期间实时更新文档。

此方法与调用 `executeTool` 方法的效果相同，但会在工具调用流式传输期间逐步编辑文档，而不是等到流式传输完成后一次性编辑文档。

### 参数（`StreamToolOptions`）

- `toolCallId`（`unknown`）：工具调用的 ID
- `toolName`（`string`）：要执行的工具。可选值包括[可用工具](/ai/ai-toolkit/client/agents/tools)。
- `input`（`unknown`）：与工具参数输入架构相符的 JSON 对象。如果该工具不需要参数，请传入空对象（`{}`）。如果工具尚未完成流式传输，此参数应为仅包含部分参数的对象，但仍须是有效的 JSON 对象。
- `hasFinished?`（`boolean`）：工具是否已完成流式传输。默认值：`false`
- `chunkSize?`（`number`）：可作为输入传递给 AI 模型的字符串最大长度。此参数可防止 AI 一次读取过多内容，从而避免超出 AI 模型的上下文窗口。默认值：`32000`。读取类工具会使用此参数控制文档的分块方式。
- `reviewOptions?`（[`ReviewOptions`](/ai/ai-toolkit/client/api-reference/review-options)）：控制预览和审阅行为。[查看可用选项](/ai/ai-toolkit/client/api-reference/review-options)。
- `commentsOptions?`（`CommentsOptions`）：评论和讨论串操作的选项。可用于向评论和讨论串的创建或更新操作传递自定义数据。`data` 属性用于讨论串数据，`commentData` 用于评论数据。
  - `threadData?`（`Record<string, any>`）：使用 `editThreads` 工具创建的 AI 生成讨论串的额外元数据
  - `commentData?`（`Record<string, any>`）：使用 `editThreads` 工具创建的 AI 生成评论的额外元数据
- `tiptapEditHooks?`（`TiptapEditHooks`）：用于拦截和修改 Tiptap Edit 操作的钩子。详情请参阅 [Tiptap Edit 钩子指南](/ai/ai-toolkit/client/advanced-guides/tiptap-edit-hooks)。
  - `beforeOperation?`（`(context: BeforeOperationContext) => BeforeOperationResult`）：在应用每项操作之前调用。返回 `{ action: 'accept' }` 以应用操作（可选通过 `fragment` 或 `operationType` 覆盖相应值），或返回 `{ action: 'reject', error }` 以跳过操作。

### 返回值（`StreamToolResult`）

- `output`（`object`）：工具执行的响应对象，供 AI 代理读取。对象结构因执行的工具而异。
- `hasError`（`boolean`）：执行过程中是否发生错误
- `unknownTool`（`boolean`）：AI Toolkit 是否无法识别 `toolName`
- `docChanged`（`boolean`）：工具调用是否修改了文档。

### 示例

工具调用处于流式传输期间，会反复调用 `streamTool` 方法。工具调用完成流式传输后，再次调用 `streamTool` 并设置 `hasFinished: true`，以表明工具调用已完成流式传输。

```ts
// Stream a tool call while it's being generated.
// Call `streamTool` again every time a new streaming part is received.
const result = toolkit.streamTool({
  // Tool is still streaming, so tool streaming has not finished yet
  hasFinished: false,
  toolCallId: 'call_123',
  toolName: 'tiptapEdit',
  // Content is still streaming, so we pass a partial object.
  input,
})

// When the tool call is complete, call it again with hasFinished: true
const finalResult = toolkit.streamTool({
  // Tool streaming has finished
  hasFinished: true,
  toolCallId: 'call_123',
  toolName: 'tiptapEdit',
  // Streaming is complete, so we can pass the full object
  input,
})
```

如需完整的流式传输实践教程，请参阅[流式传输指南](/ai/ai-toolkit/client/agents/streaming)。

## `getActiveSelection`

返回 `activeSelection` 变量的值。

活动选区是由 AI Toolkit 设置的范围。设置后，在 `tiptapReadSelection` 等操作中会使用此范围，而不是编辑器当前的选区。随着文档发生变化，该范围会自动映射到事务中，以保持位置正确。

### 返回值

- `Range | null`：活动选区范围，包含 `from` 和 `to` 属性；如果未设置活动选区，则为 `null`。

### 示例

```ts
const toolkit = getAiToolkit(editor)
const activeSelection = toolkit.getActiveSelection()
```

## `setActiveSelection`

设置 `activeSelection` 变量。在使用 `executeTool` 或 `streamTool` 方法执行工具调用时，此变量用于确定 AI 在 `tiptapReadSelection` 等操作中应使用的范围，以替代编辑器当前的选区。

活动选区是 AI 应使用的范围，用于替代编辑器当前的选区。随着文档发生变化，该范围会自动映射到事务中，以保持位置正确。

### 参数

- `selection`（`Range | null`）：要设置的范围，其中 `from` 和 `to` 属性分别表示起始和结束位置；传入 `null` 可清除活动选区。

### 示例

```ts
const toolkit = getAiToolkit(editor)
// Set the active selection to the current selection
toolkit.setActiveSelection(editor.state.selection)

// Set the active selection to a specific range
toolkit.setActiveSelection({ from: 10, to: 50 })

// Clear the active selection
toolkit.setActiveSelection(null)
```
