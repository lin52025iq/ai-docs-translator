AI Toolkit 提供了多种方法，可用于以不同格式编辑文档。

## `insertText`

向编辑器中插入纯文本。

### 参数

- `content` (`string`)：要插入的文本
- `options?` (`InsertTextOptions`)：`insertText` 方法的选项
  - `position?` (`Range | number`)：插入位置。`Range`（`{ from, to }`）会替换对应范围；`number` 会在指定位置插入。默认值：整个文档范围。
  - `reviewOptions?` ([`ReviewOptions`](/ai/ai-toolkit/client/api-reference/review-options))：控制预览和审阅行为。[查看可用选项](/ai/ai-toolkit/client/api-reference/review-options)。

### 返回值

`void`

### 示例

```ts
// Replace the entire document and show review markers
toolkit.insertText('AI content', { reviewOptions: { mode: 'review' } })
```

## `insertHtml`

向编辑器中插入 HTML。

### 参数

- `content` (`string`)：要插入的 HTML
- `options?` (`InsertHtmlOptions`)：`insertHtml` 方法的选项
  - `position?` (`Range | number`)：插入位置。`Range`（`{ from, to }`）会替换对应范围；`number` 会在指定位置插入。默认值：整个文档范围。
  - `reviewOptions?` ([`ReviewOptions`](/ai/ai-toolkit/client/api-reference/review-options))：控制预览和审阅行为。[查看可用选项](/ai/ai-toolkit/client/api-reference/review-options)。

### 返回值

`void`

### 示例

```ts
// Insert a paragraph at the end of the document
toolkit.insertHtml('<p>AI paragraph</p>', { position: editor.state.doc.content.size })
```

## `insertJson`

向编辑器中插入 ProseMirror JSON。

### 参数

- `content` (`any`)：ProseMirror JSON 节点或切片
- `options?` (`InsertJsonOptions`)：`insertJson` 方法的选项
  - `position?` (`Range | number`)：插入位置。`Range`（`{ from, to }`）会替换对应范围；`number` 会在指定位置插入。默认值：整个文档范围。
  - `reviewOptions?` ([`ReviewOptions`](/ai/ai-toolkit/client/api-reference/review-options))：控制预览和审阅行为。[查看可用选项](/ai/ai-toolkit/client/api-reference/review-options)。

### 返回值

`void`

### 示例

```ts
// Replace the entire document with a paragraph node
toolkit.insertJson({ type: 'paragraph', content: [{ type: 'text', text: 'AI' }] })
```

## `streamText`

实时向编辑器中流式传输纯文本内容。

### 参数

- `stream` (`AsyncIterable<string | Uint8Array>`)：文本内容流。它可以是任何实现了 [Async Iterable 协议](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Iteration_protocols#the_async_iterator_and_async_iterable_protocols) 的对象，例如 [生成器](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Iterators_and_generators)。
- `options?` (`StreamTextOptions`)：`streamText` 方法的选项
  - `position?` (`Range | number`)：插入位置。`Range`（`{ from, to }`）会替换对应范围；`number` 会在指定位置插入。默认值：整个文档范围。
  - `reviewOptions?` ([`ReviewOptions`](/ai/ai-toolkit/client/api-reference/review-options))：控制预览和审阅行为。[查看可用选项](/ai/ai-toolkit/client/api-reference/review-options)。
  - `checkChunkForError?` (`(status: { chunk: string; content: string; range: Range }) => boolean`)：检查数据块是否包含错误的函数。若数据块有错误，则返回 `true`；否则返回 `false`。如果返回 `true`，流式传输将停止，并抛出 `StreamingChunkCheckFailedError`。
  - `onError?` (`(event: { error: unknown; chunk: string; content: string; range: Range }) => void`)：用于处理流式传输期间发生的错误的函数。
  - `onChunkInserted?` (`(event: { chunk: string; content: string; range: Range }) => void`)：用于处理数据块流入的函数。在数据块插入编辑器后调用。

### 返回值

`Promise<void>`：流传输完成时兑现的 Promise。

### 示例

```ts
const response = await fetch('/api/generate-text')
// The API endpoint returns a stream of text content
const stream = response.body

toolkit.streamText(stream)
```

## `streamHtml`

实时向编辑器中流式传输 HTML 内容。

### 参数

- `stream` (`AsyncIterable<string | Uint8Array> | ReadableStream<string | Uint8Array>`)：HTML 内容流。它可以是任何实现了 [Async Iterable 协议](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Iteration_protocols#the_async_iterator_and_async_iterable_protocols) 的对象，例如 [ReadableStream](https://developer.mozilla.org/en-US/docs/Web/API/ReadableStream) 或[生成器](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Iterators_and_generators)。
- `options?` (`StreamHtmlOptions`)：`streamHtml` 方法的选项
  - `position?` (`Range | number`)：插入位置。`Range`（`{ from, to }`）会替换对应范围；`number` 会在指定位置插入。默认值：整个文档范围。
  - `reviewOptions?` ([`ReviewOptions`](/ai/ai-toolkit/client/api-reference/review-options))：控制预览和审阅行为。[查看可用选项](/ai/ai-toolkit/client/api-reference/review-options)。
  - `checkChunkForError?` (`(status: { chunk: string; content: string; range: Range }) => boolean`)：检查数据块是否包含错误的函数。若数据块有错误，则返回 `true`；否则返回 `false`。如果返回 `true`，流式传输将停止，并抛出 `StreamingChunkCheckFailedError`。
  - `onError?` (`(event: { error: unknown; chunk: string; content: string; range: Range }) => void`)：用于处理流式传输期间发生的错误的函数。
  - `onChunkInserted?` (`(event: { chunk: string; content: string; range: Range }) => void`)：用于处理数据块流入的函数。在数据块插入编辑器后调用。

### 返回值

`Promise<void>`：流传输完成时兑现的 Promise。

### 示例
