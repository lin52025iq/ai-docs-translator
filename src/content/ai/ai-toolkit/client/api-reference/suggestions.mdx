建议用于显示 AI 代理对文档所做的更改。

如果你刚开始使用建议，建议先阅读以下指南：

- [建议指南](/ai/ai-toolkit/client/agents/review-changes)
- [样式建议](/ai/ai-toolkit/client/agents/review-changes/style-suggestions)

本页介绍 AI Toolkit 中所有与建议相关的方法。

## `Suggestion` 对象

`Suggestion` 表示对编辑器中某段内容的拟议更改，通常由 AI 代理生成。它支持预览、审阅和应用更改，也可以包含多个替换选项。

### 属性

- `id` (`string`)：建议的唯一标识符。
- `range` (`Range`)：建议所针对的编辑器内容范围。
- `rangeInOtherDoc?` (`Range`)：如果此 `Suggestion` 是通过比较当前文档与另一文档创建的，该属性包含另一文档中 `Change` 的范围。
- `replacementOptions` (`ReplacementOption[]`)：所选范围的一个或多个可能替换项。用户可以选择要应用的选项。每个 `ReplacementOption` 都具有以下属性：
  - `id` (`string`)：此替换选项的唯一标识符。
  - `content` (`string | Slice`)：替换内容。结构化内容（含格式）可以使用 ProseMirror `Slice`，纯文本替换则可以使用普通 `string`。
  - `metadata?` (`Record<string, any>`)：此替换选项的可选附加元数据（例如来源、类别）。
- `displayOptions?` (`DisplayOptions`)：可选的显示选项，用于控制建议在编辑器 UI 中的呈现方式。
  - `showReplacement?` (`boolean`)：是否以差异形式显示替换内容。默认值：`true`
  - `hideCurrentContent?` (`boolean`)：是否在差异小组件中隐藏当前内容。默认值：`false`
  - `showSubChanges?` (`boolean`)：显示行内分组时是否显示子更改。默认值：`true`
  - `attributes?` (`Record<string, any>`)：要添加到建议的额外 HTML 属性
  - `replacementAttributes?` (`Record<string, any>`)：替换装饰的额外 HTML 属性
  - `subChangeAttributes?` (`Record<string, any>`)：行内子更改高亮的额外 HTML 属性
  - `replacementSubChangeAttributes?` (`Record<string, any>`)：替换内容中子更改高亮的额外 HTML 属性
  - `renderDecorations?` (`RenderDecorations`)：将建议渲染为 ProseMirror 装饰的函数
- `reviewMode?` (`'preview' | 'review'`)：建议的审阅模式。`'preview'` 表示在应用更改前预览建议（默认值）。`'review'` 表示审阅已完成的更改，用户可以通过应用建议来撤销更改。创建建议时，此字段会根据 `reviewOptions.mode` 自动设置。
- `isInlineGroup?` (`boolean`)：此建议是否表示一组行内更改。
- `metadata?` (`Record<string, any>`)：建议的可选附加元数据。可用于存储来源、类别或任何自定义数据等信息。扩展内部不会使用此属性，但它有助于自定义 UI 呈现方式。

## `getSuggestions`

返回所有当前建议。

### 返回值（`Suggestion[]`）

- `Suggestion[]`：当前生效建议的列表。

### 示例

```ts
// Get all active suggestions
const suggestions = toolkit.getSuggestions()
```

## `getSelectedSuggestion`

返回当前选中的建议。

当光标（`editor.state.selection.head`）位于某条建议上时，该建议即视为“已选中”。

### 返回值（`Suggestion | null`）

- `Suggestion | null`：当前选中的建议；如果没有选中任何建议，则为 `null`。

### 示例

```ts
// Get the currently selected suggestion
const selectedSuggestion = toolkit.getSelectedSuggestion()
```

## `setSuggestions` / `addSuggestions`

替换或追加建议。

`setSuggestions` 会替换所有当前建议。`addSuggestions` 会将新建议追加到现有列表中。

### 参数

- `suggestions` (`Suggestion[]`)：要显示的建议列表。

如果两条建议的范围重叠，则只显示列表中的第一条建议，第二条会被忽略。由于 ProseMirror 装饰渲染引擎的限制，建议的范围不能重叠。

### 返回值

`void`

### 示例

```ts
// Set suggestions
toolkit.setSuggestions([
  {
    id: 'suggestion-1',
    range: { from: 0, to: 5 },
    replacementOptions: [{ id: '1', content: 'Improved text' }],
  },
])

// Clear all suggestions
toolkit.setSuggestions([])
```

## `setSuggestionsFromDiff`

通过比较当前编辑器文档与另一文档来设置建议。两份文档之间的差异会自动转换为建议。

### 参数

- `options` (`SetSuggestionsFromDiffOptions`)：文档比较的配置
  - `doc` (`Node`)：用于与当前编辑器文档进行比较的文档
  - `reviewOptions?` ([`ReviewOptions`](/ai/ai-toolkit/client/api-reference/review-options))：控制如何审阅和显示建议的选项。[查看可用选项](/ai/ai-toolkit/client/api-reference/review-options)。

<Callout title="Schema 问题" variant="warning">
  `doc` 参数必须与当前文档使用相同的 schema。如果 `doc` 来自另一个编辑器，请将其转换为目标编辑器的 schema：`doc: Node.fromJSON(editor.state.schema,
  otherEditor.getJSON())`
</Callout>

### 返回值

`void`

### 示例

```ts
// Compare documents and show differences as suggestions
toolkit.setSuggestionsFromDiff({
  doc: otherDocument,
  reviewOptions: { mode: 'review' },
})
```

## `acceptSuggestion`

接受指定建议。

### 参数

- `suggestionId` (`string`)：要接受的建议
- `options?` (`AcceptSuggestionOptions`)：`acceptSuggestion` 方法的选项
  - `replacementOptionId?` (`string`)：要应用的替换选项 ID。如果未提供，则应用第一个替换选项

### 返回值

`AcceptSuggestionResult`

返回一个包含以下内容的对象：

- `aiFeedback` (`{ events: SuggestionFeedbackEvent[] }`)：包含已接受建议相关事件的 AI 反馈。每个事件包含：
  - `delete` (`string`)：已删除（或将被删除）的 HTML 内容
  - `insert` (`string`)：已插入（或将被插入）的 HTML 内容或文本
  - `accepted` (`boolean`)：用户是否接受了建议（`true`）或拒绝了建议（`false`）
- `range` (`Range | null`)：文档中插入内容的范围。如果无法应用建议，则为 `null`。

此反馈可用于告知 AI 用户接受或拒绝了哪些更改。

### 示例

```ts
// Accept a suggestion by id and get feedback
const result = toolkit.acceptSuggestion('suggestion-1')
result.aiFeedback.events
```

## `acceptAllSuggestions`

一次性接受所有生效的建议。

此方法会将每条建议范围内的内容替换为第一个替换选项，从而接受所有建议。你也可以筛选要接受的建议。

### 参数

- `options?` (`AcceptAllSuggestionsOptions`)：`acceptAllSuggestions` 方法的选项
  - `filter?` (`(suggestion: Suggestion) => boolean`)：用于确定要接受哪些建议的谓词

### 返回值

`AcceptAllSuggestionsResult`

返回一个包含以下内容的对象：

- `aiFeedback` (`{ events: SuggestionFeedbackEvent[] }`)：包含所有已接受建议相关事件的 AI 反馈。每个事件包含：
  - `delete` (`string`)：已删除（或将被删除）的 HTML 内容
  - `insert` (`string`)：已插入（或将被插入）的 HTML 内容或文本
  - `accepted` (`boolean`)：用户是否接受了建议（`true`）或拒绝了建议（`false`）
- `range` (`Range | null`)：文档中最后一条建议插入内容的范围。

此反馈可用于告知 AI 用户接受了哪些更改。

### 示例

```ts
// Accept all suggestions at once and get feedback
const result = toolkit.acceptAllSuggestions()
result.aiFeedback.events
```

## `acceptSuggestions`

按 ID 接受多条建议。

这是对 `acceptAllSuggestions` 的便捷封装，用于接受指定的一组生效建议。

### 参数

- `ids` (`string[]`)：要接受的建议 ID

### 返回值

`AcceptSuggestionsResult`

返回与 `acceptAllSuggestions` 相同的结果，包括 `aiFeedback` 和最后一条已接受建议的范围。

### 示例

```ts
// Accept a specific set of suggestions
const result = toolkit.acceptSuggestions(['suggestion-1', 'suggestion-2'])
```

## `rejectSuggestion`

拒绝指定建议，但不应用该建议。

此方法会从生效建议列表中移除建议，但不会将其应用到文档中。它会返回有关被拒绝内容的反馈。

### 参数

- `suggestionId` (`string`)：要拒绝的建议

### 返回值

`RejectSuggestionResult`

返回一个包含以下内容的对象：

- `aiFeedback` (`{ events: SuggestionFeedbackEvent[] }`)：包含被拒绝建议相关事件的 AI 反馈。每个事件包含：
  - `delete` (`string`)：已删除（或将被删除）的 HTML 内容
  - `insert` (`string`)：已插入（或将被插入）的 HTML 内容或文本
  - `accepted` (`boolean`)：用户是否接受了建议（`true`）或拒绝了建议（`false`）

此反馈可用于告知 AI 用户拒绝了哪些更改。

### 示例

```ts
// Reject a suggestion by id and get feedback
const result = toolkit.rejectSuggestion('suggestion-1')
result.aiFeedback.events
```

## `rejectAllSuggestions`

拒绝所有生效建议，但不应用这些建议。

默认情况下，此方法会从建议列表中移除所有生效建议，但不会将其应用到文档中。你也可以筛选要拒绝的建议。不符合筛选条件的建议仍保持生效。此方法会返回有关被拒绝内容的反馈。

### 参数

- `options?` (`RejectAllSuggestionsOptions`)：`rejectAllSuggestions` 方法的选项
  - `filter?` (`(suggestion: Suggestion) => boolean`)：用于确定要拒绝哪些建议的谓词

### 返回值

`RejectAllSuggestionsResult`

返回一个包含以下内容的对象：

- `aiFeedback` (`{ events: SuggestionFeedbackEvent[] }`)：包含所有被拒绝建议相关事件的 AI 反馈。每个事件包含：
  - `delete` (`string`)：已删除（或将被删除）的 HTML 内容
  - `insert` (`string`)：已插入（或将被插入）的 HTML 内容或文本
  - `accepted` (`boolean`)：用户是否接受了建议（`true`）或拒绝了建议（`false`）

此反馈可用于告知 AI 用户拒绝了哪些更改。

### 示例

```ts
// Reject all suggestions and get feedback
const result = toolkit.rejectAllSuggestions()
result.aiFeedback.events
```

## `setMarkdownSuggestions`

通过比较修正后的 Markdown 与当前文档内容，加载 AI 生成的建议。

<Callout title="需要 Markdown 扩展" variant="warning">
  此方法需要安装并配置 [Tiptap Markdown 扩展](https://tiptap.dev/docs/editor/markdown/api/editor)。
</Callout>

此方法支持两种输入格式：

1. **完整文档格式**：提供修正后的 Markdown，由 toolkit 自动计算差异
2. **更改列表格式**：提供具体文本替换项数组（删除/插入对）

此方法使用基于差异的方式识别更改，并在文档中的相应位置创建建议。

### 参数

- `options` (`SetMarkdownSuggestionsOptions`)：配置选项
  - `content?` (`string`)：AI 服务提供商返回的修正后 Markdown 内容。完整文档格式请使用此参数。不能与 `changes` 同时使用。
  - `changes?` (`TextChange[]`)：文本更改数组，格式为 `{ delete: string, insert: string }`。每项更改指定要删除的文本及其替换内容。不能与 `content` 同时使用。
  - `range?` (`Range`)：可选范围，用于将建议限制在文档的特定部分。`from` 值**包含在范围内**，`to` 值**不包含在范围内**（`[from, to)`）。这些值表示**文档中的绝对位置**（从文档开头的 0 开始），使用**字符偏移量**（而非节点位置）。如果未提供，则处理整个文档。
  - `reviewOptions?` ([`ReviewOptions`](/ai/ai-toolkit/client/api-reference/review-options))：控制预览/审阅行为。[查看可用选项](/ai/ai-toolkit/client/api-reference/review-options)。

<Callout title="更改列表格式的行为" variant="info">
  使用 `changes` 格式时，在指定范围内，每个 `delete` 文本的**所有**出现位置都会被对应的 `insert` 文本替换。如果需要针对特定位置进行替换，请改用完整文档格式。
</Callout>

### 返回值

`SetMarkdownSuggestionsResult`

返回一个包含以下内容的对象：

- `suggestions` (`Suggestion[]`)：生成的建议数组

### 示例

#### 与 API 集成的完整文档格式

```ts
const toolkit = getAiToolkit(editor)

// Get corrected Markdown from your AI API
const response = await fetch('/api/grammar-check', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ markdown: editor.getMarkdown() }),
})
const { correctedMarkdown } = await response.json()

// Set suggestions using the corrected Markdown
const result = toolkit.setMarkdownSuggestions({
  content: correctedMarkdown,
})

console.log(`Generated ${result.suggestions.length} suggestions`)
```

#### 带范围参数的完整文档格式

```ts
const toolkit = getAiToolkit(editor)

// Only process a specific range of the document
toolkit.setMarkdownSuggestions({
  content: '# Corrected heading\n\nCorrected paragraph content',
  range: { from: 0, to: 100 },
})
```

#### 单项更改的更改列表格式

```ts
const toolkit = getAiToolkit(editor)

// Capitalize all occurrences of 'api' to 'API'
toolkit.setMarkdownSuggestions({
  changes: [{ delete: 'api', insert: 'API' }],
})
```

#### 多项更改的更改列表格式

```ts
const toolkit = getAiToolkit(editor)

// Apply multiple text corrections at once
toolkit.setMarkdownSuggestions({
  changes: [
    { delete: 'javascript', insert: 'JavaScript' },
    { delete: 'typescript', insert: 'TypeScript' },
    { delete: 'api', insert: 'API' },
  ],
  range: { from: 0, to: 500 },
})
```

## `invertSuggestions`

将所有当前建议应用到文档副本，并返回生成的文档以及可撤销这些更改的反向建议。这是一次试运行操作，不会修改编辑器文档。

对于每条原始建议，都会应用其替换内容以生成新文档，并创建一条反向建议。在新文档上接受反向建议即可撤销更改。预览模式的建议在反向结果中会变为审阅模式，反之亦然。每条反向建议都会保留原建议的 ID、元数据和显示选项。

### 参数

- `options?` (`InvertSuggestionsOptions`)：可选配置
  - `schema?` (`Schema`)：目标 ProseMirror schema。如果提供此参数，返回的文档及所有建议替换切片都会转换为该 schema。当反向结果将用于 schema 与当前编辑器不同的编辑器时，此参数很有用。

### 返回值

`InvertSuggestionsResult`

返回一个包含以下内容的对象：

- `doc` (`Node`)：应用所有建议后的文档。此文档不会应用到编辑器。
- `suggestions` (`Suggestion[]`)：反向建议；将其设置到返回的文档上即可撤销已应用的更改。

### 示例

```ts
const toolkit = getAiToolkit(editor)

// Get the inverted result without modifying the editor
const { doc, suggestions } = toolkit.invertSuggestions()

// Translate the result to a different editor's schema
const { doc, suggestions } = toolkit.invertSuggestions({ schema: otherEditor.schema })
```
