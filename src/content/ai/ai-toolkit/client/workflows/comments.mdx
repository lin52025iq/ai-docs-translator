## 项目概览

此演示使用 AI Toolkit 的 Comments 工作流来管理文档中的评论串和评论。AI 可以创建新的评论串、添加评论、更新评论、删除评论以及管理评论串状态。

## 安装

创建一个 [Next.js](https://nextjs.org/) 项目：

```bash
npx create-next-app@latest comments-workflow
```

安装 Tiptap 核心软件包，以及用于 Anthropic 的 [Vercel AI SDK](https://ai-sdk.dev/)：

```bash
npm install @tiptap/react @tiptap/starter-kit ai @ai-sdk/react @ai-sdk/anthropic zod uuid
```

## 服务端设置

创建一个 API 端点，使用 [Vercel AI SDK](https://ai-sdk.dev/) 调用 Anthropic 模型。

如果你的后端使用 TypeScript 以外的编程语言，请参阅[此指南](/ai/ai-toolkit/client/advanced-guides/non-typescript-backends)。

在 API 端点中，使用 `createEditThreadsWorkflow` 函数创建并配置 Comments 工作流。该工作流包含一段可直接使用的系统提示词，用于指示 AI 模型如何管理评论。

用户消息应包含：

- `content`：文档内容（通过 `tiptapRead` 获取）
- `threads`：文档中现有的评论串（通过 `getThreads` 获取）
- `task`：要由 AI 执行的任务。例如：`添加一条评论，建议如何改进引言。`

```ts
// app/api/comments-workflow/route.ts
import { openai } from '@ai-sdk/openai'
import { createEditThreadsWorkflow } from '@tiptap-pro/client-ai-toolkit-tool-definitions'
import { createTextStreamResponse, Output, streamText, toTextStream } from 'ai'

export async function POST(req: Request) {
  const { content, threads, task } = await req.json()

  // 创建并配置 Comments 工作流（使用默认设置）。
  // 其中包含可直接使用的系统提示词和输出架构。
  const workflow = createEditThreadsWorkflow()

  const result = streamText({
    model: openai('gpt-5.6-luna'),
    // 系统提示词
    instructions: workflow.systemPrompt,
    // 用户消息
    prompt: JSON.stringify({
      content,
      threads,
      task,
    }),
    output: Output.object({ schema: workflow.zodOutputSchema }),
  })

  return createTextStreamResponse({ stream: toTextStream({ stream: result.stream }) })
}
```

## 客户端设置

创建一个 React 组件，使用 Comments 扩展渲染编辑器并应用评论操作。

此工作流支持流式传输，也就是说，随着 AI 模型生成操作，这些操作会逐步应用，为用户提供实时反馈。

工作流启动时，首先调用 `tiptapRead` 方法获取文档内容，并调用 `getThreads` 方法获取现有评论串。

然后，调用 API 端点启动工作流。使用 `editThreadsWorkflow` 方法应用评论操作。`isStreaming` 参数可确保随着操作流入而逐步应用。

```tsx
// app/comments-workflow/page.tsx
'use client'

import { useObject } from '@ai-sdk/react'
import { EditorContent, useEditor } from '@tiptap/react'
import StarterKit from '@tiptap/starter-kit'
import {
  AiToolkit,
  getAiToolkit,
  editThreadsWorkflowOutputSchema,
} from '@tiptap-pro/client-ai-toolkit'
import { Comments } from '@tiptap-pro/extension-comments'
import { useEffect, useState } from 'react'
import { v4 as uuid } from 'uuid'

// 创建一个简单的评论提供程序
const commentsProvider = {
  threads: [],
  getThreads: () => commentsProvider.threads,
  createThread: (thread) => {
    commentsProvider.threads.push(thread)
    return thread
  },
  updateThread: (id, data) => {
    const index = commentsProvider.threads.findIndex((t) => t.id === id)
    if (index !== -1) {
      commentsProvider.threads[index] = { ...commentsProvider.threads[index], ...data }
    }
  },
  deleteThread: (id) => {
    commentsProvider.threads = commentsProvider.threads.filter((t) => t.id !== id)
  },
}

export default function Page() {
  const editor = useEditor({
    immediatelyRender: false,
    extensions: [
      StarterKit,
      AiToolkit,
      Comments.configure({
        provider: commentsProvider,
      }),
    ],
    content: `<h1>带评论的文档</h1><p>这是一个示例文档，AI 可以在其中添加和管理评论。</p>`,
  })

  const [workflowId, setWorkflowId] = useState('')
  const [task, setTask] = useState('添加一条评论，为改进本文档提出建议')

  const { submit, isLoading, object } = useObject({
    api: '/api/comments-workflow',
    schema: editThreadsWorkflowOutputSchema,
  })

  // 随着操作流入而应用
  useEffect(() => {
    if (!editor || !object?.operations) return

    const toolkit = getAiToolkit(editor)
    toolkit.editThreadsWorkflow({
      operations: object.operations,
      workflowId,
      isStreaming: isLoading,
    })
  }, [editor, object, workflowId, isLoading])

  if (!editor) return null

  const manageComments = () => {
    setWorkflowId(uuid())

    const toolkit = getAiToolkit(editor)

    // 获取文档内容和现有评论串
    const { content } = toolkit.tiptapRead()
    const { threads } = toolkit.getThreads()

    // 调用 API 端点启动工作流
    submit({ content, threads, task })
  }

  return (
    <div>
      <EditorContent editor={editor} />

      <input
        type="text"
        value={task}
        onChange={(e) => setTask(e.target.value)}
        placeholder="输入评论任务……"
      />

      <button onClick={manageComments} disabled={isLoading}>
        {isLoading ? '处理中……' : '使用 AI 管理评论'}
      </button>
    </div>
  )
}
```

## 可用操作

Comments 工作流支持以下操作：

| 操作     | 说明             |
| -------- | ---------------- |
| 创建评论串 | 在指定位置创建新的评论串 |
| 创建评论   | 向现有评论串添加评论     |
| 更新评论   | 更新现有评论           |
| 删除评论   | 从评论串中删除一条评论   |
| 删除评论串 | 删除整个评论串         |
| 解决评论串 | 将评论串标记为已解决    |
| 取消解决评论串 | 将评论串标记为未解决 |

## 针对文档部分内容添加评论

若只想针对文档的某个子部分添加评论，请在 `tiptapRead` 上设置 `range` 选项。此参数接收一个 [Range](/ai/ai-toolkit/client/advanced-guides/concepts#range)，用于指定要读取的区域。

例如，只针对选中的内容添加评论：

```ts
const range = editor.state.selection

// 仅读取文档中选中的部分
const { content } = toolkit.tiptapRead({ range })
const { threads } = toolkit.getThreads()

const operations = callApi(content, threads)

// 应用评论操作
toolkit.editThreadsWorkflow({ operations, workflowId })
```

对于较大的文档，可以使用 [`tiptapReadChunks`](/ai/ai-toolkit/client/api-reference/read-the-document#tiptapreadchunks) 方法将文档拆分成多个块并并行处理。每个块都包含一个 [Range](/ai/ai-toolkit/client/advanced-guides/concepts#range)，用于指定该块对应的区域。
