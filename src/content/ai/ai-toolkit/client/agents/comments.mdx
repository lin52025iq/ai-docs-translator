## 初始设置

首先，按照[评论指南](/comments/getting-started/overview)创建一个带有评论功能的 Tiptap 编辑器。

## API 端点

创建一个调用 AI 模型的 API 端点。在本例中，我们使用 [Next.js 框架](https://nextjs.org/)构建 API 端点，并使用 [Vercel AI SDK](https://ai-sdk.dev/)调用 AI 模型。

如果你的后端使用的编程语言不是 TypeScript，请参阅[本指南](/ai/ai-toolkit/client/advanced-guides/non-typescript-backends)。

为 Tiptap AI Toolkit 提供[工具定义](/ai/ai-toolkit/client/agents/tools/ai-sdk)。启用 `getThreads` 和 `editThreads` 工具，让 AI 代理能够读取和编辑文档中的评论。

你也可以禁用 `tiptapEdit` 工具，以防止 AI 修改文档。

```ts
// app/api/chat/route.ts
import { openai } from '@ai-sdk/openai'
import { toolDefinitions } from '@tiptap-pro/client-ai-toolkit-ai-sdk'
import { createAgentUIStreamResponse, ToolLoopAgent, UIMessage } from 'ai'

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json()

  const agent = new ToolLoopAgent({
    model: openai('gpt-5.6-luna'),
    instructions: 'You are an assistant that can add comments to a rich text document.',
    tools: toolDefinitions({
      tools: {
        // 启用用于读取和编辑评论的工具
        getThreads: true,
        editThreads: true,
        // （可选）阻止 AI 修改文档
        tiptapEdit: false,
      },
    }),
  })

  return createAgentUIStreamResponse({
    agent,
    uiMessages: messages,
  })
}
```

## 客户端设置

在前端创建一个用于呈现聊天机器人界面的 React 组件。该组件使用 Vercel AI SDK 的 [useChat hook](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat) 调用 API 端点并管理聊天对话。

当 AI 模型输出工具调用时，它会使用 Tiptap AI Toolkit 来执行工具：

- 如果调用的是 `getThreads` 工具，它会读取文档中的评论。
- 如果调用的是 `editThreads` 工具，它会编辑文档中的评论。

以下示例展示了如何实现：

```tsx
import { useChat } from '@ai-sdk/react'
import { getAiToolkit } from '@tiptap-pro/client-ai-toolkit'
import { DefaultChatTransport, lastAssistantMessageIsCompleteWithToolCalls } from 'ai'
import { useState } from 'react'

export function CommentsAiChatbot({ editor }) {
  const [input, setInput] = useState(
    "Add a comment to the first sentence of the last paragraph, that says 'well done'",
  )

  const { messages, sendMessage, addtoolOutput } = useChat({
    transport: new DefaultChatTransport({ api: '/api/comments' }),
    sendAutomaticallyWhen: lastAssistantMessageIsCompleteWithToolCalls,
    async onToolCall({ toolCall }) {
      if (!editor) return

      const { toolName, input, toolCallId } = toolCall

      // 使用 AI Toolkit 执行工具
      const toolkit = getAiToolkit(editor)
      const result = toolkit.executeTool({
        toolName,
        input,
      })

      addtoolOutput({ tool: toolName, toolCallId, output: result.output })
    },
  })

  return (
    <div>
      <EditorContent editor={editor} />
      {messages?.map((message) => (
        <div key={message.id} style={{ whiteSpace: 'pre-wrap' }}>
          <strong>{message.role}</strong>
          <br />
          {message.parts
            .filter((p) => p.type === 'text')
            .map((p) => p.text)
            .join('\n')}
        </div>
      ))}
      <form
        onSubmit={(e) => {
          e.preventDefault()
          sendMessage({ text: input })
          setInput('')
        }}
      >
        <input value={input} onChange={(e) => setInput(e.target.value)} />
      </form>
    </div>
  )
}
```

## 自定义 AI 代理的行为

你可以通过提供自定义系统提示词来影响 AI 代理撰写评论的方式。例如，可以指示 AI 按特定风格或格式添加评论。

```
You are an assistant that can add comments to a rich text document. The content of the comments should always be in Markdown format.
```

你也可以指示 AI 执行特定操作。借助[工具定义](/ai/ai-toolkit/client/agents/tools)，AI 能够理解线程、评论、已解决的线程和回复等概念。

```
Never resolve threads, even if the user asks you to. Only users can resolve threads by clicking on the resolve button.
```

如需了解有关提示词工程的更多信息，请参阅 [AI 工程指南](/ai/ai-toolkit/client/advanced-guides/ai-engineering)。
