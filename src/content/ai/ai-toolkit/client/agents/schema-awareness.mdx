Tiptap [Schema](/editor/core-concepts/schema) 描述了文档可以（以及不可以）包含哪些元素。Tiptap 的 **Schema 感知**功能可帮助 AI 模型更好地理解文档。

<Callout title="为什么需要 Schema 感知？" variant="default">
  如果没有 Schema 感知，AI 模型可能会生成 Tiptap 编辑器不支持的内容。例如，它可能会在不支持表格的文档中生成表格。启用
  Schema 感知后，AI 模型会知道不支持表格节点，因此不会生成表格。
</Callout>

## 指南：让 AI 模型具备 Schema 感知能力

将 Schema 感知功能集成到 AI 代理中，例如 [AI 代理聊天机器人指南](/ai/ai-toolkit/client/agents/ai-agent-chatbot)中构建的代理。

### 第 1 步：获取 Schema 感知字符串

从 AI Toolkit 获取 Schema 感知字符串。该字符串包含一条描述文档 Schema 的消息，并针对 AI 模型进行了优化。

```ts
const toolkit = getAiToolkit(editor)
// Retrieve the schema awareness string
const schemaAwareness = toolkit.getHtmlSchemaAwareness()
```

### 第 2 步（可选）：配置自定义节点

如果文档中包含[自定义节点和标记](/editor/extensions/custom-extensions)，请在扩展配置中添加 `addHtmlSchemaAwareness` 选项。这样，AI 模型就能准确地生成这些自定义节点或标记。例如，如果有一个名为 `'alert'` 的自定义节点，可以按如下方式配置，让 AI 模型能够生成它：

```ts
import { Node } from '@tiptap/core'

const CustomExtension = Node.configure({
  name: 'alert',

  addHtmlSchemaAwareness() {
    return {
      tag: 'div',
      name: 'Alert Box',
      description: `A highlighted box used to display important information, warnings, or tips to the user.
It can have inline content inside like text and formatting tags.`,
      attributes: [
        {
          attr: 'data-alert',
          value: '',
          description: 'Indicates that this is an alert box',
        },
        {
          attr: 'data-type',
          description:
            'The type of alert. Can be one of these 4 values: info, warning, error, or success',
        },
      ],
    }
  },

  // ... Other extension configuration options
})
```

或者，也可以配置 `getHtmlSchemaAwareness` 方法的 `customNodes` 选项。有关配置选项的详细信息，请参阅 [API 参考](/ai/ai-toolkit/client/api-reference/schema-awareness#gethtmlschemaawareness)。

<Callout title="官方 Tiptap 扩展呢？" variant="info">
  AI Toolkit 会自动支持官方 Tiptap 扩展的 Schema 感知功能，无需进行配置。你也可以扩展官方 Tiptap 扩展并添加
  `addHtmlSchemaAwareness` 选项，以覆盖其默认的 Schema 感知信息。
</Callout>

### 第 3 步：将 Schema 感知字符串添加到系统提示词

调用 AI 模型时，将 Schema 感知字符串作为参数发送给返回 AI 模型响应的 API 端点。

下面的代码展示了一个使用 Next.js 和 Vercel AI SDK 构建的 API 端点，与 [AI 代理聊天机器人指南](/ai/ai-toolkit/client/agents/ai-agent-chatbot)中的端点类似。

```ts
// app/page.tsx
import { useEditor } from '@tiptap/react'
import { getAiToolkit } from '@tiptap-pro/client-ai-toolkit'
import { useChat } from '@ai-sdk/react'
import { DefaultChatTransport } from 'ai'

// Inside the React component

const editor = useEditor()
const toolkit = getAiToolkit(editor)

// Get the schema awareness string
const schemaAwareness = toolkit.getHtmlSchemaAwareness()

const { messages } = useChat({
  transport: new DefaultChatTransport({
    api: '/api/chat',
    // Send the schema awareness string as a parameter to the API endpoint
    body: { schemaAwareness },
  }),
  // ...
})
```

然后，在 API 端点处理程序中，将 Schema 感知字符串添加到系统提示词末尾。

```ts
// app/api/chat/route.ts
import { openai } from '@ai-sdk/openai'
import { toolDefinitions } from '@tiptap-pro/client-ai-toolkit-ai-sdk'
import { createAgentUIStreamResponse, ToolLoopAgent, UIMessage } from 'ai'

export async function POST(req: Request) {
  // Get the schema awareness string from the request body
  const { messages, schemaAwareness }: { messages: UIMessage[]; schemaAwareness: string } =
    await req.json()

  const agent = new ToolLoopAgent({
    model: openai('gpt-5.6-luna'),
    // Add the schema awareness string to end of the system prompt
    instructions: `You are an assistant that can edit rich text documents.
${schemaAwareness}`,
    tools: toolDefinitions(),
  })

  return createAgentUIStreamResponse({
    agent,
    uiMessages: messages,
  })
}
```

现在，你已经为 AI 模型配置好了 Schema 感知功能。
