## 主要改动

要为我们在[上一份指南](/ai/ai-toolkit/client/agents/ai-agent-chatbot)中构建的 AI 智能体聊天机器人添加流式传输，需要将 `executeTool` 方法替换为 `streamTool` 方法。

首先，在工具调用进行流式传输时，每收到一个新的流式片段，都可以重复调用 `streamTool`。这样会逐步更新文档。

```tsx
const aiToolkit = getAiToolkit(editor)

const result = aiToolkit.streamTool({
  toolCallId: 'call_123',
  toolName,
  // 内容仍在流式传输，因此传入部分 JSON 对象。
  input,
  // 此参数表示工具流式传输尚未完成
  hasFinished: false,
})
```

然后，工具调用完成后，再次调用 `streamTool` 方法并设置 `hasFinished: true`，以表示工具调用的流式传输已经完成。这样会使用最终内容更新文档。

```tsx
const result = aiToolkit.streamTool({
  toolCallId: 'call_123',
  toolName,
  // 流式传输已完成，因此可以传入完整的 JSON 对象
  input,
  // 此参数表示工具流式传输已经完成
  hasFinished: true,
})
```

要在我们于[上一份指南](/ai/ai-toolkit/client/agents/ai-agent-chatbot)中构建的 AI 智能体聊天机器人里实现此流程，请按以下步骤操作：

### 1. 处理流式更新

添加一个 `useEffect` hook，在工具调用进行过程中处理流式更新。在这个 hook 中，每收到一个新的流式片段，我们都会重复调用 `streamTool`。

```tsx
// 工具流式传输进行中时，需要随着工具输入的变化更新文档
useEffect(() => {
  if (!editor) return

  // 查找最后一条消息
  const lastMessage = messages[messages.length - 1]
  if (!lastMessage) return

  // 查找 AI 刚刚调用的最后一个工具
  const toolCallParts = lastMessage.parts.filter((p) => p.type.startsWith('tool-')) ?? []
  const lastToolCall = toolCallParts[toolCallParts.length - 1]
  if (!lastToolCall) return

  // 获取工具调用数据
  interface ToolStreamingPart {
    input: unknown
    state: string
    toolCallId: string
    type: string
  }
  const part = lastToolCall as ToolStreamingPart
  if (!(part.state === 'input-streaming')) return
  const toolName = part.type.replace('tool-', '')

  // 在工具流式传输期间，将工具调用应用到文档
  const toolkit = getAiToolkit(editor)
  toolkit.streamTool({
    toolCallId: part.toolCallId,
    toolName,
    input: part.input,
    // 此参数表示工具流式传输尚未完成
    hasFinished: false,
  })
}, [addtoolOutput, editor, messages])
```

### 2. 处理流式传输完成

在我们的演示中，我们使用 [Vercel 的 AI SDK](https://ai-sdk.vercel.app/) 中的 `useChat` hook 来实现 AI 智能体聊天机器人。这个 hook 包含一个 `onToolCall` 事件处理程序，会在工具调用完成流式传输时运行。

在此处理程序中，我们调用 `streamTool` 并设置 `hasFinished: true`，以表示工具调用的流式传输已经完成。

```tsx
const { messages, sendMessage, addtoolOutput } = useChat({
  transport: new DefaultChatTransport({ api: '/api/chat' }),
  sendAutomaticallyWhen: lastAssistantMessageIsCompleteWithToolCalls,
  async onToolCall({ toolCall }) {
    if (!editor) return

    const { toolName, input, toolCallId } = toolCall

    // 使用 AI Toolkit 对工具进行流式传输
    const toolkit = getAiToolkit(editor)
    const result = toolkit.streamTool({
      toolCallId,
      toolName,
      input,
      // 此参数表示工具流式传输已经完成
      hasFinished: true,
    })

    addtoolOutput({ tool: toolName, toolCallId, output: result.output })
  },
})
```

<Callout title="在所有 streamTool 调用中传入相同的属性" variant="warning">
  所有 `streamTool` 调用都应传入相同的属性值。例如，在第一次调用 `streamTool` 方法时，如果向 `reviewOptions` 参数传入 `{mode: 'preview'}`，那么之后的所有 `streamTool` 调用也都应传入相同的值（`{mode: 'preview'}`）。
</Callout>

## 完整实现

下面是包含工具流式传输的完整更新组件：

```tsx
'use client'

import { DefaultChatTransport, lastAssistantMessageIsCompleteWithToolCalls } from 'ai'
import { useChat } from '@ai-sdk/react'
import { EditorContent, useEditor } from '@tiptap/react'
import StarterKit from '@tiptap/starter-kit'
import { useEffect, useState } from 'react'
import { AiToolkit, getAiToolkit } from '@tiptap-pro/client-ai-toolkit'

export default function Page() {
  const editor = useEditor({
    immediatelyRender: false,
    extensions: [StarterKit, AiToolkit],
    content: `<h1>AI Agent Demo</h1><p>Ask the AI to improve this.</p>`,
  })

  const { messages, sendMessage, addtoolOutput } = useChat({
    transport: new DefaultChatTransport({ api: '/api/chat' }),
    sendAutomaticallyWhen: lastAssistantMessageIsCompleteWithToolCalls,
    async onToolCall({ toolCall }) {
      if (!editor) return

      const { toolName, input, toolCallId } = toolCall

      // 工具流式传输完成后，需要将工具调用应用到文档
      // 使用 AI Toolkit 执行工具
      const toolkit = getAiToolkit(editor)
      const result = toolkit.streamTool({
        toolCallId,
        toolName,
        input,
        // 此参数表示工具流式传输已经完成
        hasFinished: true,
      })

      addtoolOutput({ tool: toolName, toolCallId, output: result.output })
    },
  })

  const [input, setInput] = useState(
    'Insert, at the end of the document, a long story with 10 paragraphs about Tiptap',
  )

  // 工具流式传输进行中时，需要随着工具输入的变化更新文档
  useEffect(() => {
    if (!editor) return

    // 查找最后一条消息
    const lastMessage = messages[messages.length - 1]
    if (!lastMessage) return

    // 查找 AI 刚刚调用的最后一个工具
    const toolCallParts = lastMessage.parts.filter((p) => p.type.startsWith('tool-')) ?? []
    const lastToolCall = toolCallParts[toolCallParts.length - 1]
    if (!lastToolCall) return

    // 获取工具调用数据
    interface ToolStreamingPart {
      input: unknown
      state: string
      toolCallId: string
      type: string
    }
    const part = lastToolCall as ToolStreamingPart
    if (!(part.state === 'input-streaming')) return
    const toolName = part.type.replace('tool-', '')

    // 在工具流式传输期间，将工具调用应用到文档
    const toolkit = getAiToolkit(editor)
    toolkit.streamTool({
      toolCallId: part.toolCallId,
      toolName,
      input: part.input,
      // 此参数表示工具流式传输尚未完成
      hasFinished: false,
    })
  }, [addtoolOutput, editor, messages])

  if (!editor) return null

  return (
    <div>
      <EditorContent editor={editor} />
      {messages?.map((message) => (
        <div key={message.id} style={{ whiteSpace: 'pre-wrap' }}>
          <strong>{message.role}</strong>
          <br />
          {message.parts
            .filter((p) => p.type === 'text')
            .map((p) => p.text)
            .join('\n')}
        </div>
      ))}
      <form
        onSubmit={(e) => {
          e.preventDefault()
          sendMessage({ text: input })
          setInput('')
        }}
      >
        <input value={input} onChange={(e) => setInput(e.target.value)} />
      </form>
    </div>
  )
}
```

import { AiCaret, AiToolkit, getAiToolkit } from '@tiptap-pro/client-ai-toolkit'

const editor = useEditor({

})

## 显示审阅界面

在审阅界面中显示更改，让用户可以接受或拒绝这些更改。

有两种方式：

- 使用 [**Tracked Changes**](/tracked-changes/getting-started/overview) 扩展呈现审阅界面。更改会作为文档的一部分持久保存，并对其他用户可见。
- **AI Toolkit 建议**：基于装饰的临时界面，仅对当前文档用户可见。

通过设置 `reviewOptions` 参数来配置审阅界面。每次调用 `streamTool` 方法时，此参数都应使用相同的值。

```ts
toolkit.streamTool({
  // ... other options

  // 使用 Tracked Changes 显示审阅界面
  reviewOptions: { mode: 'trackedChanges' },

  // 使用 AI Toolkit 建议显示审阅界面
  reviewOptions: { mode: 'review' },
})
```

如需详细了解审阅界面，请参阅[审阅更改指南](/ai/ai-toolkit/client/agents/review-changes)。

有关如何将 AI Toolkit 流式传输与审阅界面结合使用的示例，请参阅 [AI Toolkit 演示](https://github.com/ueberdosis/ai-toolkit-demos)。
