AI Toolkit 可在审阅界面中显示 AI 生成的更改，让用户接受或拒绝这些更改。

有两种方式：

- 使用 [**Tracked Changes**](/tracked-changes/getting-started/overview) 扩展（单独销售的产品）来呈现审阅界面。更改会作为文档的一部分保留，并对其他用户可见。
- **AI Toolkit 建议**：基于装饰的临时界面，仅对当前文档用户可见。

## AI Toolkit 建议

AI Toolkit 建议是一种基于装饰的审阅界面，属于临时内容，仅对当前文档用户可见。

如果希望审阅界面仅对当前文档用户可见，而不让协作文档中的其他用户看到，可以使用这种方式替代 Tracked Changes 审阅界面。

### 什么是建议？

建议是对文档所做更改的提议。每个 `Suggestion` 对象都具有以下属性：

- `id` (`string`)：建议的唯一标识符。
- `range` (`Range`)：建议所在的位置。它具有 `from` 属性（建议的起始位置）和 `to` 属性（建议的结束位置）。如需了解有关范围的更多信息，请参阅[概念指南](/ai/ai-toolkit/client/advanced-guides/concepts)。
- AI 建议插入该 `range` 的内容。此内容存储在 `replacementOptions` 属性中。

请参阅 [API 参考](/ai/ai-toolkit/client/api-reference/suggestions)，了解 `Suggestion` 对象的所有属性。

### 两种建议类型

建议分为两种：

- **预览模式**：应用更改前先预览。用户接受建议后，文档才会修改。
- **审阅模式**：应用更改后再审阅。文档已被修改，用户可以通过应用建议撤销更改。

### 如何生成建议？

调用 AI Toolkit 中[编辑文档](/ai/ai-toolkit/client/api-reference/edit-the-document)的方法时，就会生成建议。

这些方法可以通过三种不同的方式配置：

#### 选项 1：不显示建议

AI Toolkit 方法默认会直接编辑文档，而不生成任何建议。

```ts
toolkit.executeTool({
  toolName: 'tiptapEdit',
  input: {},
  // No reviewOptions property
  // or:
  // reviewOptions: { mode: 'disabled' }
})
```

#### 选项 2：编辑文档前生成建议

这种方式不会修改文档，而是以**预览模式**生成建议。

只有用户接受建议后，文档才会被编辑。

```ts
toolkit.executeTool({
  toolName: 'tiptapEdit',
  input: {},
  reviewOptions: { mode: 'preview' },
})
```

#### 选项 3：编辑文档后生成建议

这种方式会直接修改文档，并以**审阅模式**生成建议。用户可以应用建议来撤销更改。

```ts
toolkit.executeTool({
  toolName: 'tiptapEdit',
  input: {},
  reviewOptions: { mode: 'review' },
})
```

差异工具还有其他选项，详情请参阅 [API 参考](/ai/ai-toolkit/client/api-reference/diff-utility)。

### 接受和拒绝建议

你可以调用 `acceptSuggestion` 和 `rejectSuggestion` 方法来接受或拒绝建议。

```ts
toolkit.acceptSuggestion('suggestion-1')
toolkit.rejectSuggestion('suggestion-1')
```

这些方法会返回 AI 反馈，你可以收集这些反馈并发送给 AI，以改进后续建议。

```ts
const result = toolkit.acceptSuggestion('suggestion-1')
// result.aiFeedback.events
```

你还可以调用 `acceptAllSuggestions` 和 `rejectAllSuggestions` 方法，一次性接受或拒绝所有建议。

你可以通过编程方式读取和更新建议。请参阅 [API 参考](/ai/ai-toolkit/client/api-reference/suggestions)，了解所有可用方法。
