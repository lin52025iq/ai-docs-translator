Tiptap AI Toolkit 提供了一套全面的工具，可用于与 Tiptap 文档交互。这些工具支持读取内容、进行编辑，并高效浏览长文档。

工具定义提供了多种常用 AI 提供商库的格式：

- [Vercel AI SDK](/ai/ai-toolkit/client/agents/tools/ai-sdk)
- [LangChain.js](/ai/ai-toolkit/client/agents/tools/langchain-js)
- [OpenAI](/ai/ai-toolkit/client/agents/tools/openai)
- [Anthropic](/ai/ai-toolkit/client/agents/tools/anthropic)
- [Mastra](/ai/ai-toolkit/client/agents/tools/mastra)
- [其他提供商](/ai/ai-toolkit/client/agents/tools/other-providers)

将工具定义添加到 AI 提供商库后，AI 代理便会生成工具调用。然后，您可以使用 [`executeTool` 方法](/ai/ai-toolkit/client/api-reference/execute-tool)执行这些工具调用。

```ts
// Read the document from the beginning
await agent.executeTool({
  toolName: 'tiptapRead',
  // Pass here the AI-generated tool input
  input: { from: 0 },
})
```

## `tiptapRead`

从指定位置读取文档。

### 参数

- `from`（`number`）：读取的起始位置。

### 结果

从指定位置开始的文档内容。我们为客户提供有关此工具格式的更详细信息。

## `tiptapEdit`

在指定位置编辑文档。

### 参数

- `operations`（`array`）：要对文档执行的操作列表。我们为客户提供有关此工具格式的更详细信息。

### 结果

包含编辑操作结果的成功或错误消息。

## `tiptapReadSelection`

读取文档中的选区。

### 参数

无需参数。

### 结果

选区的内容和位置。我们为客户提供有关此工具格式的更详细信息。

## `getThreads`

获取文档中的所有讨论串和评论。此工具会提供文档中现有讨论和反馈的详细信息。

### 参数

- `from`（`number`）：要读取的讨论串起始索引。

### 结果

文档中所有讨论串和评论的数据，包括其内容和位置。

### 要求

此工具要求在编辑器中配置 Comments 扩展和 CommentsProvider。此工具默认处于停用状态，需要显式启用。

## `editThreads`

对文档中的讨论串和评论执行操作。此工具支持全面管理讨论串和评论，包括创建、更新和删除。

### 参数

- `operations`（`array`）：要执行的操作数组。

### 结果

操作成功时返回成功消息，否则返回错误消息。

### 要求

此工具要求在编辑器中配置 Comments 扩展和 CommentsProvider。此工具默认处于停用状态，需要显式启用。
