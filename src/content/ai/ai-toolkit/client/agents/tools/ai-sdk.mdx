`@tiptap-pro/client-ai-toolkit-ai-sdk` 包提供了一组工具定义，可将其添加到使用 [Vercel AI SDK](https://ai-sdk.dev/) 构建的 AI 智能体中。

随后，可以使用 [`executeTool` 方法](/ai/ai-toolkit/client/api-reference/execute-tool)执行模型生成的工具调用。

## 使用示例

安装此包。

```bash
npm install @tiptap-pro/client-ai-toolkit-ai-sdk
```

将工具定义传递给 `ToolLoopAgent` 类的 `tools` 参数。

```ts
import { openai } from '@ai-sdk/openai'
import { createAgentUIStreamResponse, ToolLoopAgent, UIMessage } from 'ai'
import { toolDefinitions } from '@tiptap-pro/client-ai-toolkit-ai-sdk'

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json()

  const agent = new ToolLoopAgent({
    model: openai('gpt-5.6-luna'),
    tools: toolDefinitions(),
  })

  return createAgentUIStreamResponse({
    agent,
    uiMessages: messages,
  })
}
```

将这些工具定义与自定义工具组合使用。

```ts
import { openai } from '@ai-sdk/openai'
import { createAgentUIStreamResponse, ToolLoopAgent, tool, UIMessage } from 'ai'
import { toolDefinitions } from '@tiptap-pro/client-ai-toolkit-ai-sdk'
import { z } from 'zod'

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json()

  const agent = new ToolLoopAgent({
    model: openai('gpt-5.6-luna'),
    tools: {
      // Tool definitions from the AI Toolkit
      ...toolDefinitions(),
      // Custom weather tool
      weather: tool({
        description: 'Get the weather in a location',
        inputSchema: z.object({
          location: z.string(),
        }),
        execute: async () => ({
          temperature: 72,
        }),
      }),
    },
  })

  return createAgentUIStreamResponse({
    agent,
    uiMessages: messages,
  })
}
```

<Callout title="Zod 3 中的类型错误" variant="warning">
  如果应用使用 [Zod 验证库](https://zod.dev/)的 3.x 版本，将工具定义传递给 `ToolLoopAgent` 类的 `tools` 参数时，可能会遇到类型错误。可以升级到 Zod 4，或将工具定义强制转换为 AI SDK 的 `ToolSet` 类型来解决此问题。
</Callout>

## API 参考

### `toolDefinitions`

创建与 [Vercel AI SDK](https://ai-sdk.dev/) 兼容、供 Tiptap AI 工具包使用的工具定义。

#### 参数（`ToolDefinitionsOptions`）

- `tools?`: `EnabledTools` - 通过将值设为 `true`（启用）或 `false`（禁用），启用或禁用特定工具。
  - `tiptapRead?`: `boolean` - 启用或禁用 `tiptapRead` 工具（默认值：`true`）
  - `tiptapEdit?`: `boolean` - 启用或禁用 `tiptapEdit` 工具（默认值：`true`）
  - `tiptapReadSelection?`: `boolean` - 启用或禁用 `tiptapReadSelection` 工具（默认值：`true`）
  - `getThreads?`: `boolean` - 启用或禁用 `getThreads` 工具（默认值：`false`）
  - `editThreads?`: `boolean` - 启用或禁用 `editThreads` 工具（默认值：`false`）

#### 返回值

返回一个对象，其中包含已启用的工具定义，可用于 [Vercel AI SDK](https://ai-sdk.dev/) 的工具调用系统。有关完整的工具列表，请参阅[可用工具](/ai/ai-toolkit/client/agents/tools)页面。
