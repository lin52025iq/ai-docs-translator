`@tiptap-pro/client-ai-toolkit-ai-sdk` 包提供了工具定义，可将其添加到使用 [Mastra](https://mastra.ai/) AI Agent 框架构建的 AI 代理中。

之后，可以使用 [`executeTool` 方法](/ai/ai-toolkit/client/api-reference/execute-tool)执行模型生成的工具调用。

## 使用示例

安装此软件包。

```bash
npm install @tiptap-pro/client-ai-toolkit-ai-sdk
```

将工具定义传递给 Mastra Agent 的 `tools` 参数。

```ts
import { Agent } from '@mastra/core/agent'
import { openai } from '@ai-sdk/openai'
import { toolDefinitions } from '@tiptap-pro/client-ai-toolkit-ai-sdk'

const agent = new Agent({
  name: 'Tiptap AI Agent',
  instructions: 'You are an AI assistant that can read and edit Tiptap documents.',
  model: openai('gpt-5.6-luna'),
  tools: toolDefinitions(),
})

const result = await agent.generate('Read the document and summarize it')
```

将工具定义与自定义工具结合使用。

```ts
import { Agent } from '@mastra/core/agent'
import { openai } from '@ai-sdk/openai'
import { createTool } from '@mastra/core/tools'
import { toolDefinitions } from '@tiptap-pro/client-ai-toolkit-ai-sdk'
import { z } from 'zod'

// Custom weather tool using Mastra's createTool
const weatherTool = createTool({
  id: 'Get Weather Information',
  description: 'Get the weather in a location',
  inputSchema: z.object({
    location: z.string().describe('The location to get weather for'),
  }),
  outputSchema: z.object({
    temperature: z.number(),
  }),
  execute: async ({ context: { location } }) => ({
    temperature: 72,
  }),
})

const agent = new Agent({
  name: 'Tiptap AI Agent with Weather',
  instructions:
    'You are an AI assistant that can read and edit Tiptap documents and get weather information.',
  model: openai('gpt-5.6-luna'),
  tools: {
    // Tool definitions from the AI Toolkit
    ...toolDefinitions(),
    // Custom weather tool
    weather: weatherTool,
  },
})

const result = await agent.generate('Read the document and get the weather in New York')
```

## API 参考

### `toolDefinitions`

创建与 [Mastra](https://mastra.ai/) 兼容的 Tiptap AI 工具包工具定义。

#### 参数（`ToolDefinitionsOptions`）

- `tools?`：`EnabledTools` - 通过将值设为 `true`（启用）或 `false`（禁用）来启用或禁用特定工具。
  - `tiptapRead?`：`boolean` - 启用或禁用 `tiptapRead` 工具（默认值：`true`）
  - `tiptapEdit?`：`boolean` - 启用或禁用 `tiptapEdit` 工具（默认值：`true`）
  - `tiptapReadSelection?`：`boolean` - 启用或禁用 `tiptapReadSelection` 工具（默认值：`true`）
  - `getThreads?`：`boolean` - 启用或禁用 `getThreads` 工具（默认值：`false`）
  - `editThreads?`：`boolean` - 启用或禁用 `editThreads` 工具（默认值：`false`）

#### 返回值

返回一个对象，其中包含可用于 [Mastra](https://mastra.ai/) 工具调用系统的已启用工具定义。完整工具列表请参阅[可用工具](/ai/ai-toolkit/client/agents/tools)页面。
