`@tiptap-pro/client-ai-toolkit-openai` 包提供了工具定义，你可以将其添加到使用 [OpenAI JavaScript SDK](https://github.com/openai/openai-node) 构建的 AI 代理中。

之后，模型生成的工具调用便可在客户端使用 [`executeTool` 方法](/ai/ai-toolkit/client/api-reference/execute-tool)执行。

## 使用示例

安装此软件包。

```bash
npm install @tiptap-pro/client-ai-toolkit-openai
```

将工具定义传递给 OpenAI 模型。

```ts
import OpenAI from 'openai'
import { toolDefinitions } from '@tiptap-pro/client-ai-toolkit-openai'

const openai = new OpenAI()

const response = await openai.responses.create({
  model: 'gpt-5.6-luna',
  input: [{ role: 'user', content: 'Help me edit this document' }],
  tools: toolDefinitions(),
})
```

将工具定义与自定义工具组合使用。

```ts
import OpenAI from 'openai'
import { toolDefinitions } from '@tiptap-pro/client-ai-toolkit-openai'

const openai = new OpenAI()

const customTools = [
  {
    type: 'function',
    name: 'get_weather',
    description: 'Get the weather in a location',
    parameters: {
      type: 'object',
      properties: {
        location: {
          type: 'string',
          description: 'The city and state, e.g. San Francisco, CA',
        },
      },
      required: ['location'],
    },
  },
]

const response = await openai.responses.create({
  model: 'gpt-5.6-luna',
  input: [{ role: 'user', content: 'What is the weather like and help me edit this document' }],
  tools: [...toolDefinitions(), ...customTools],
})
```

## API 参考

### `toolDefinitions`

创建与 [OpenAI Responses API](https://platform.openai.com/docs/api-reference/responses) 兼容的 Tiptap AI 工具包工具定义。

#### 参数（`ToolDefinitionsOptions`）

- `tools?`：`EnabledTools` - 将值设为 `true`（启用）或 `false`（禁用），以启用或禁用特定工具。
  - `tiptapRead?`：`boolean` - 启用或禁用 `tiptapRead` 工具（默认值：`true`）
  - `tiptapEdit?`：`boolean` - 启用或禁用 `tiptapEdit` 工具（默认值：`true`）
  - `tiptapReadSelection?`：`boolean` - 启用或禁用 `tiptapReadSelection` 工具（默认值：`true`）
  - `getThreads?`：`boolean` - 启用或禁用 `getThreads` 工具（默认值：`false`）
  - `editThreads?`：`boolean` - 启用或禁用 `editThreads` 工具（默认值：`false`）

#### 返回值

返回一个数组，其中包含可用于 [OpenAI Responses API](https://platform.openai.com/docs/api-reference/responses) 的已启用工具定义。完整工具列表请参阅[可用工具](/ai/ai-toolkit/client/agents/tools)页面。

### `completionsApiToolDefinitions`

创建与 [OpenAI Completions API](https://platform.openai.com/docs/api-reference/completions) 兼容的 Tiptap AI 工具包工具定义。

#### 参数（`ToolDefinitionsOptions`）

- `tools?`：`EnabledTools` - 将值设为 `true`（启用）或 `false`（禁用），以启用或禁用特定工具。
  - `tiptapRead?`：`boolean` - 启用或禁用 `tiptapRead` 工具（默认值：`true`）
  - `tiptapEdit?`：`boolean` - 启用或禁用 `tiptapEdit` 工具（默认值：`true`）
  - `tiptapReadSelection?`：`boolean` - 启用或禁用 `tiptapReadSelection` 工具（默认值：`true`）
  - `getThreads?`：`boolean` - 启用或禁用 `getThreads` 工具（默认值：`false`）
  - `editThreads?`：`boolean` - 启用或禁用 `editThreads` 工具（默认值：`false`）

#### 返回值

返回一个数组，其中包含可用于 [OpenAI Completions API](https://platform.openai.com/docs/api-reference/completions) 的已启用工具定义。完整工具列表请参阅[可用工具](/ai/ai-toolkit/client/agents/tools)页面。
