`@tiptap-pro/client-ai-toolkit-anthropic` 包提供了一组工具定义，可添加到使用 [Anthropic 的 JavaScript SDK](https://github.com/anthropics/anthropic-sdk-typescript) 构建的 AI 代理中。

随后，可在客户端使用 [`executeTool` 方法](/ai/ai-toolkit/client/api-reference/execute-tool)执行模型生成的工具调用。

## 使用示例

安装此包。

```bash
npm install @tiptap-pro/client-ai-toolkit-anthropic
```

将工具定义提供给 Anthropic 模型。

```ts
import Anthropic from '@anthropic-ai/sdk'
import { toolDefinitions } from '@tiptap-pro/client-ai-toolkit-anthropic'

const anthropic = new Anthropic()

const response = await anthropic.messages.create({
  model: 'claude-sonnet-4-5',
  max_tokens: 2048,
  system: 'You are a helpful assistant that can edit rich text documents.',
  messages: [{ role: 'user', content: 'Help me edit this document' }],
  tools: toolDefinitions(),
})
```

将工具定义与自定义工具结合使用。

```ts
import Anthropic from '@anthropic-ai/sdk'
import { toolDefinitions } from '@tiptap-pro/client-ai-toolkit-anthropic'

const anthropic = new Anthropic()

const customTools = [
  {
    name: 'get_weather',
    description: 'Get the weather in a location',
    input_schema: {
      type: 'object',
      properties: {
        location: {
          type: 'string',
          description: 'The city and state, e.g. San Francisco, CA',
        },
      },
      required: ['location'],
    },
  },
]

const response = await anthropic.messages.create({
  model: 'claude-sonnet-4-5',
  max_tokens: 1024,
  messages: [{ role: 'user', content: 'What is the weather like and help me edit this document' }],
  tools: [...toolDefinitions(), ...customTools],
})
```

## API 参考

### `toolDefinitions`

创建与 [Anthropic 的 Messages API](https://docs.claude.com/en/docs/get-started#typescript) 兼容的 Tiptap AI Toolkit 工具定义。

#### 参数（`ToolDefinitionsOptions`）

- `tools?`：`EnabledTools` - 通过将值设为 `true`（启用）或 `false`（禁用）来启用或禁用特定工具。
  - `tiptapRead?`：`boolean` - 启用或禁用 `tiptapRead` 工具（默认：`true`）
  - `tiptapEdit?`：`boolean` - 启用或禁用 `tiptapEdit` 工具（默认：`true`）
  - `tiptapReadSelection?`：`boolean` - 启用或禁用 `tiptapReadSelection` 工具（默认：`true`）
  - `getThreads?`：`boolean` - 启用或禁用 `getThreads` 工具（默认：`false`）
  - `editThreads?`：`boolean` - 启用或禁用 `editThreads` 工具（默认：`false`）

#### 返回值

返回一个数组，其中包含可与 [Anthropic 的 Messages API](https://docs.claude.com/en/docs/get-started#typescript) 配合使用的已启用工具定义。完整工具列表请参阅[可用工具](/ai/ai-toolkit/client/agents/tools)页面。
