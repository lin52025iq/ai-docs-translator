Tiptap AI Toolkit 为最常用的 AI 提供商库（例如 [Vercel 的 AI SDK](https://ai-sdk.dev/)）提供工具定义。如果你的 AI 提供商尚未获得支持，请[联系 Tiptap 团队](mailto:humans@tiptap.dev)提出需求。

你也可以获取所有工具定义组成的通用 JSON 对象，并将其转换为你的 AI 提供商所需的格式。

## 获取工具定义

使用 `@tiptap-pro/client-ai-toolkit-tool-definitions` 包中的 `toolDefinitions()` 函数，以通用格式获取工具定义：

```ts
import { toolDefinitions } from '@tiptap-pro/client-ai-toolkit-tool-definitions'

const tools = toolDefinitions()
```

每个工具定义都是一个包含以下属性的对象：

- `name`：工具名称，是工具的唯一标识符。
- `description`：工具描述，供 AI 模型读取。
- `inputSchema`：[JSON Schema](https://json-schema.org/)，用于描述工具的输入参数。

使用这些数据，按照你的 AI 提供商所需的格式构建工具定义。

### 非 TypeScript 后端

如果你的后端使用 TypeScript 以外的编程语言，可以使用 CLI 生成包含工具定义的 JSON 文件。请参阅[本指南](/ai/ai-toolkit/client/advanced-guides/non-typescript-backends)。

## API 参考

### `toolDefinitions`

以通用格式创建 Tiptap AI Toolkit 的工具定义，可将其转换为任何 AI 提供商所需的格式。

#### 参数（`ToolDefinitionsOptions`）

- `tools?`：`EnabledTools` — 通过将值设为 `true`（启用）或 `false`（禁用）来启用或禁用特定工具。
  - `tiptapRead?`：`boolean` — 启用或禁用 `tiptapRead` 工具（默认值：`true`）
  - `tiptapEdit?`：`boolean` — 启用或禁用 `tiptapEdit` 工具（默认值：`true`）
  - `tiptapReadSelection?`：`boolean` — 启用或禁用 `tiptapReadSelection` 工具（默认值：`true`）
  - `getThreads?`：`boolean` — 启用或禁用 `getThreads` 工具（默认值：`false`）
  - `editThreads?`：`boolean` — 启用或禁用 `editThreads` 工具（默认值：`false`）

#### 返回值

包含已启用工具定义的数组，格式为通用格式。每个工具定义都是包含 `name`、`description` 和 `inputSchema` 属性的对象。如需查看完整工具列表，请参阅[可用工具](/ai/ai-toolkit/client/agents/tools)页面。
