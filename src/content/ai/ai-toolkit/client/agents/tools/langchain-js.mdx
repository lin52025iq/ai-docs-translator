`@tiptap-pro/client-ai-toolkit-langchain` 包提供了一组工具定义，可添加到使用 [LangChain.js](https://js.langchain.com/) 构建的 AI 代理中。

模型生成的工具调用随后可以通过 [`executeTool` 方法](/ai/ai-toolkit/client/api-reference/execute-tool)在客户端执行。

## 使用示例

安装此软件包。

```bash
npm install @tiptap-pro/client-ai-toolkit-langchain
```

向 LangChain.js 模型提供工具定义。

```ts
import { ChatOpenAI } from '@langchain/openai'
import { toolDefinitions } from '@tiptap-pro/client-ai-toolkit-langchain'

const llm = new ChatOpenAI({ model: 'gpt-5.6-luna' })
const llmWithTools = llm.bindTools(toolDefinitions())
```

将工具定义与自定义工具组合使用。

```ts
import { ChatOpenAI } from '@langchain/openai'
import { toolDefinitions } from '@tiptap-pro/client-ai-toolkit-langchain'
import { DynamicStructuredTool } from '@langchain/core/tools'
import { z } from 'zod'

const llm = new ChatOpenAI({ model: 'gpt-5.6-luna' })

const customTools = [
  new DynamicStructuredTool({
    name: 'weather',
    description: 'Get the weather in a location',
    schema: z.object({
      location: z.string(),
    }),
    func: async ({ location }) => {
      return `The weather in ${location} is sunny with 72°F`
    },
  }),
]

const llmWithTools = llm.bindTools([...toolDefinitions(), ...customTools])
```

## API 参考

### `toolDefinitions`

创建与 [LangChain.js](https://js.langchain.com/) 兼容的 Tiptap AI Toolkit 工具定义。

#### 参数（`ToolDefinitionsOptions`）

- `tools?`：`EnabledTools` - 通过将值设为 `true`（启用）或 `false`（禁用），启用或禁用特定工具。
  - `tiptapRead?`：`boolean` - 启用或禁用 `tiptapRead` 工具（默认值：`true`）
  - `tiptapEdit?`：`boolean` - 启用或禁用 `tiptapEdit` 工具（默认值：`true`）
  - `tiptapReadSelection?`：`boolean` - 启用或禁用 `tiptapReadSelection` 工具（默认值：`true`）
  - `getThreads?`：`boolean` - 启用或禁用 `getThreads` 工具（默认值：`false`）
  - `editThreads?`：`boolean` - 启用或禁用 `editThreads` 工具（默认值：`false`）

#### 返回值

返回一个数组，其中包含已启用的工具定义，可用于 [LangChain.js](https://js.langchain.com/) 的工具调用系统。完整工具列表请参阅[可用工具](/ai/ai-toolkit/client/agents/tools)页面。
