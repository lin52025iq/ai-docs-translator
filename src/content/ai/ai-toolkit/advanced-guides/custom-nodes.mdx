如果文档包含自定义节点或标记，请配置编辑器上下文，以便 Server AI Toolkit 能向 AI 模型准确描述这些元素。

<Callout title="为什么要配置自定义节点？" variant="default">
  如果没有编辑器上下文，AI 模型可能会生成编辑器不支持的内容，或完全遗漏自定义元素。添加自定义节点元数据可以为模型提供充足的上下文，帮助它可靠地生成这些元素。
</Callout>

## 获取编辑器上下文数据

首先，从编辑器生成编辑器上下文数据。Server AI Toolkit 会使用这些数据向 AI 模型描述文档结构。

```ts
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import { getEditorContext, ServerAiToolkit } from '@tiptap/ai-toolkit'

const editor = new Editor({
  extensions: [StarterKit, ServerAiToolkit],
})

// Retrieve the editor context data
const editorContext = getEditorContext(editor)
```

<Callout title="存储编辑器上下文数据" variant="info">
  `getEditorContext` 返回的编辑器上下文数据是可序列化为 JSON 的对象，可以存储在数据库中。无需每次都重新生成。编辑器扩展或架构发生变化时，再更新这些数据即可。
</Callout>

## 配置自定义节点

如果文档包含[自定义节点和标记](/editor/extensions/custom-extensions)，请在扩展配置中添加 `addJsonSchemaAwareness` 选项。这样，AI 模型就能理解并准确生成相应的自定义节点或标记。

例如，如果你有一个名为 `'alert'` 的自定义节点，可以这样配置：

```ts
import { Node } from '@tiptap/core'
import { z } from 'zod'

const CustomExtension = Node.create({
  name: 'alert',

  addAttributes() {
    return {
      type: {
        default: 'info',
        parseHTML: (element) => element.getAttribute('data-type'),
        renderHTML: (attributes) => {
          if (!attributes.type) {
            return {}
          }

          return {
            'data-type': attributes.type,
          }
        },
      },
    }
  },

  addJsonSchemaAwareness() {
    return {
      name: 'Alert Box',
      description: `A highlighted box used to display important information, warnings, or tips to the user.
It can contain inline content like text and formatting marks.`,
      attributes: {
        type: z
          .enum(['info', 'warning', 'error', 'success'])
          .describe(
            'The type of alert. Can be one of these 4 values: info, warning, error, or success',
          ),
      },
    }
  },

  parseHTML() {
    return [
      {
        tag: 'div[data-alert]',
      },
    ]
  },

  renderHTML({ HTMLAttributes }) {
    return ['div', { ...HTMLAttributes, 'data-alert': '' }, 0]
  },
})
```

`addJsonSchemaAwareness` 函数应返回一个包含以下属性的对象：

- `name`（`string`）：元素易于理解的英文名称
- `description?`（`string`）：面向 AI 模型、用英文编写的元素说明
- `attributes?`（`Record<string, z.ZodTypeAny>`）：元素可能具有的属性，以 Zod 架构定义，并将转换为 JSON 架构

<Callout title="官方 Tiptap 扩展怎么办？" variant="info">
  Server AI Toolkit 会自动支持官方 Tiptap 扩展的编辑器上下文，无需进行配置。你仍然可以通过扩展官方扩展并添加 `addJsonSchemaAwareness` 选项，覆盖其默认的编辑器上下文信息。
</Callout>
