Tiptap Shorthand 是一种用于表示 Tiptap 文档的高效 token 格式。与 Tiptap JSON 相比，它最多可降低 50% 的 AI token 成本，同时不牺牲准确性。

Tiptap Shorthand 目前处于测试阶段。如果您想了解 Tiptap Shorthand 带来的优势，请[联系我们](https://tiptap.dev/contact-sales)。

</Callout>

## 设置 Tiptap Shorthand

通过设置 JSON 请求体中的 `format` 参数，定义 AI 读取和编辑文档时使用的格式。所有 Server AI Toolkit 端点都支持此参数。

`format` 的默认值为 `"json"`。若要启用 Tiptap Shorthand，请在**所有** API 请求中传入 `format: "shorthandV2"` 参数。在支持 `shorthand` 格式的所有场景中，都可以使用 `shorthandV2` 格式。

例如，获取工具定义：

```bash
curl -X POST https://api.tiptap.dev/v4/ai/toolkit/fetch-tools \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -d '{
    "format": "shorthandV2",
    "editorContext": {}
  }'
```

无需进行其他更改。

<Callout title="格式一致性" variant="warning">
  在一次对话中的所有 API 调用中使用相同的 `format` 值。请勿在一次 AI 交互中混用 `json`、
  `shorthand` 和 `shorthandV2` 格式。
</Callout>

## Tiptap Shorthand 的工作原理

`/v4/ai/toolkit/fetch-tools` 端点会返回一段提示词，向 AI 说明文档的结构以及生成文档时应使用的格式。其中包括对 AI 生成文档内容时所用格式的说明。该提示词会向 AI 模型介绍相应的语言规则和语法。

Tiptap Shorthand 内容以文本字符串编码。与 Tiptap JSON 相比，它占用的空间要少得多，无论是字符数还是 token 数都是如此。因此，无需更改 AI 模型，即可提升速度并降低成本。
