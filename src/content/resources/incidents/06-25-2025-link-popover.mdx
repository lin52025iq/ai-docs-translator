[链接弹出框 UI 组件](/ui-components/components/link-popover)接受恶意 URL，可能导致 XSS 攻击。

**受影响的组件**
- [链接弹出框组件](/ui-components/components/link-popover)，截至 Jun 25, 2025, 9:39 PM GMT+2
- [简单编辑器模板](/ui-components/templates/simple-editor)，截至 Jun 25, 2025, 9:39 PM GMT+2

**不受影响**

- 其他 UI 组件或模板
- Link 扩展本身
- Jun 25, 2025, 9:39 PM GMT+2 之后下载的组件或模板

### 漏洞成因
为了在缺少 Link 扩展时仍能正常工作，该组件绕过了 `editor.commands.setLink()`。这个命令通常会拒绝 `javascript:` 等协议。由于采用了这种捷径，整个过程中都没有进行任何验证：无论是插入链接时，还是用户点击“在新窗口中打开”按钮时。

<Callout title="注意" variant="info">
Link 扩展本身包含适当的 URL 验证（参见 [isAllowedUri](/editor/extensions/marks/link#isalloweduri)）。
</Callout>

## 修复方案
现在，每次插入链接时都会调用 `editor.commands.setLink()`；此外，每当用户点击“在新窗口中打开”按钮时，都会单独检查 URL。

## 如何更新

要更新现有项目中的代码，请在终端运行以下命令：

```bash
npx @tiptap/cli@latest add link-popover
```

此命令会下载最新版本的链接弹出框 UI 组件。
