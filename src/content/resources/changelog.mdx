Tiptap 由 50 多个独立的软件包组成。要查看各软件包的更新，请使用侧边栏中自动生成的软件包页面；要全面了解更新内容，请先查看根目录的更新日志页面。

以下是跟踪变更的所有方法：

1. 查看 [GitHub 发布页面](https://github.com/ueberdosis/tiptap/releases)，了解最全面的概况。
2. 如需了解更多详情，请查看 GitHub 上的 [Tiptap 更新日志](https://github.com/ueberdosis/tiptap/blob/main/CHANGELOG.md)。
3. 此外，这里还提供基于上游 `CHANGELOG.md` 文件自动生成的各软件包更新日志页面。
4. 关注 [GitHub 上已合并的拉取请求](https://github.com/ueberdosis/tiptap/pulls?q=is%3Apr+is%3Aclosed)也很有帮助。

对于较大的变更，我们会在[博客](https://tiptap.dev/blog)中发布文章，并在此处将其记录到更新日志中。
