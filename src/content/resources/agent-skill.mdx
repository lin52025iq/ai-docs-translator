这是一项预先构建的 [智能体技能](https://agentskills.io/)，用于帮助 AI 编程智能体学习如何集成和使用 Tiptap。

这项技能为智能体提供：

- 搜索 Tiptap 源代码和文档的策略。
- 使用 Tiptap 3 的最佳实践。
- 特定框架的使用指南（例如 React）。

## 安装

使用 [skills CLI](https://skills.sh/) 安装这项技能：

```bash
npx skills add ueberdosis/tiptap
```

或者[直接从 GitHub 下载 SKILL.md](https://github.com/ueberdosis/tiptap/blob/main/.agents/skills/tiptap/SKILL.md)。
