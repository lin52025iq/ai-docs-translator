## 安装

你需要拥有有效订阅或正在试用的 Tiptap 账户。请前往 [cloud.tiptap.dev/register](https://cloud.tiptap.dev/register) 创建账户。

### 用于现有项目

```bash
npx @tiptap/cli@latest add notion-like-editor
```

### 用于新项目

```bash
npx @tiptap/cli@latest init notion-like-editor
```

此模板需要进行样式和配置设置。

### 样式

我们不限定你使用哪种样式框架，因此你需要将其集成到自己的项目配置中。请按照[样式设置指南](/ui-components/getting-started/style)操作，确保编辑器正确显示。

### 配置

运行应用前，请在 `tiptap-collab-utils.ts` 中配置所需常量，以启用 AI 或协作等功能。

### 环境变量

请为以下环境变量设置值：

- `TIPTAP_COLLAB_DOC_PREFIX` - 用于标识协作文档的前缀
- `TIPTAP_COLLAB_APP_ID` - 你的文档服务器 ID
- `TIPTAP_COLLAB_TOKEN` - 用于访问 Collaboration 服务的 JWT
- `TIPTAP_AI_TOKEN` - 用于访问 AI 服务的 JWT

上述环境变量需要在客户端可用。根据你使用的框架，添加以下前缀以便在客户端访问这些变量：

- [Next.js](/ui-components/install/next)：`NEXT_PUBLIC_`。例如：`NEXT_PUBLIC_TIPTAP_COLLAB_DOC_PREFIX`。
- [Vite + React](/ui-components/install/vite)：`VITE_`。例如：`VITE_TIPTAP_COLLAB_DOC_PREFIX`。
- 其他框架：遵循相应框架的具体规则，并在 `tiptap-collab-utils.ts` 文件中定义变量。

### JWT 身份验证

协作和 AI 功能需要将有效的服务器生成 JWT 传递给编辑器。`tiptap-collab-utils.ts` 中的 `fetchCollabToken` 函数提供了示例。

> 请参阅 [JWT 身份验证](https://tiptap.dev/docs/guides/authentication)完整指南。

<Callout title="生成 JWT" variant="info">
  如需快速上手，可以使用 Tiptap Cloud 账户中的示例 JWT，并将其存储在 `TIPTAP_COLLAB_TOKEN` 和 `TIPTAP_AI_TOKEN` 环境变量中。不过，示例 JWT 的有效期很短，不应在生产环境中使用。在生产环境中，请实现一个在服务器端生成 JWT 的 API 端点。
</Callout>

### `room` 属性

使用 `room` 属性区分协作文档。每个会话都应使用唯一的 room ID。

### 图片上传

图片上传需要服务器端支持，而这不包含在我们的 UI 组件中。下面提供了一个示例服务器：它接收图片、将图片上传到 S3，然后返回图片的永久 URL。请注意，在生产环境中使用时，你可能需要实施其他检查以防止滥用。

服务器端（使用 `node --experimental-strip-types` 运行）
```typescript
import {
  GetObjectCommand,
  PutObjectCommand,
  S3Client,
} from "@aws-sdk/client-s3";
import { Hono } from 'hono'
import { serve } from '@hono/node-server'
import { cors } from 'hono/cors'
import { v4 } from 'uuid'

const S3_REGION = 'xxx'
const S3_BUCKET = 'xxx'
const S3_ACCESS_KEY= 'xxx'
const S3_ACCESS_SECRET_KEY='xxx'

const PORT = 1234
const BASE_URL = `http://127.0.0.1:${PORT}`

const app = new Hono()
const client = new S3Client({
  region: S3_REGION,
  credentials: {
    accessKeyId: S3_ACCESS_KEY,
    secretAccessKey: S3_ACCESS_SECRET_KEY,
  }
});

// in production, make sure to set up restrictive cors rules
app.use('/upload', cors())

// in prod, you should add sensitive rate limits for both endpoints
// you probably want to add content-type and/or filename and filesize validation
app.post('/upload', async (c) => {
  const body = await c.req.arrayBuffer()
  const remoteFileKey = `upload-${v4()}`

  const command = new PutObjectCommand({
    Bucket: S3_BUCKET,
    Key: remoteFileKey,
    Body: body,
    ContentType: c.req.header('content-type') ?? ''
  });

  try{
    await client.send(command)
  } catch(e) {
    console.error(e)
    c.status(500)
    return c.text('')
  }

  return c.text(`${BASE_URL}/files/${remoteFileKey}`)
})

app.get('/files/:name', async (c) => {
  const { name } = c.req.param()
  const remoteFileKey = `${name}`

  // you may want to implement caching when using this in production
  // or, maybe you want to use pre-signed URLs to the client can directly fetch
  // the document from S3.
  const command = new GetObjectCommand({
    Bucket: S3_BUCKET,
    Key: remoteFileKey,
  })

  try{
    const r = await client.send(command)
    return c.body(r.Body, 200, {
      'content-type': r.ContentType ?? ''
    })
  } catch(e) {
    console.error(e)
    c.status(500)
    return c.text('')
  }

})

serve({...app, port: PORT})
```

要使用此端点，请调整 `tiptap-utils.ts` 中的 `handleImageUpload`。删除验证之后的所有代码，并替换为类似下面的内容：

```typescript
const response = await fetch('http://YOUR_URL/upload', {
    body: file,
    method: 'post',
    headers: {
        'content-type': file.type,
    }
})

if( response.ok ) {
    return response.text()
}

throw new Error('upload failed')
```

## 用法

在 React 应用中导入并渲染 `NotionEditor` 组件：

```tsx
import { NotionEditor } from '@/components/tiptap-templates/notion-like/components/notion-like-editor'

export default function App() {
  return <NotionEditor room="my-document-room" placeholder="Start writing..." />
}
```

## 功能

此模板包含现代 Notion 风格编辑器所需的全部核心功能：

- **实时协作**：实时光标和用户状态
- **AI 辅助**：用于撰写和编辑的内联 AI 工具
- **响应式设计**：适配移动设备的 UI 和自适应工具栏
- **深色/浅色模式**：开箱即用的完整主题支持
- **斜杠命令**：使用 `/` 菜单快速设置格式
- **浮动工具栏**：根据上下文提供格式选项
- **拖放**：在块级别重新排序
- **表情符号支持**：GitHub 风格的表情符号选择器
- **提及**：`@user` 自动补全
- **丰富的格式设置**：

  - 粗体、斜体、下划线、删除线
  - 突出显示和颜色
  - 上标/下标
  - 语法高亮代码块

- **块类型**：

  - 标题、列表、引用块、分隔线、数学公式

- **媒体支持**：拖放上传图片
- **链接管理**：支持内联预览
- **文本对齐**：左对齐、居中、右对齐、两端对齐
- **撤销/重做**：完整的编辑历史记录
- **上下文菜单**：右键增强功能

## 协作

要使用协作功能：

1. 为 `NotionEditor` 传入唯一的 `room` ID
2. 为每个用户会话启用 JWT 身份验证
3. 自动处理用户状态和光标
4. 使用操作转换处理并发编辑
5. 开箱即用地管理同步和保存

```tsx
<NotionEditor room="team-notes" placeholder="Share your ideas..." />
```
