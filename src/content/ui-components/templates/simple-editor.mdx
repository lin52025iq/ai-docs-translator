## 安装

### 用于现有项目

```bash
npx @tiptap/cli@latest add simple-editor
```

### 用于新项目

```bash
npx @tiptap/cli@latest init simple-editor
```

## 样式

此模板需要配置样式。我们不限定样式框架，因此你需要将其集成到自己的项目配置中。请参阅[样式配置指南](/ui-components/getting-started/style)，确保编辑器能够正确显示。

## 用法

安装后，可在 React 或 Next.js 项目中使用 SimpleEditor 组件：

```jsx
import { SimpleEditor } from '@/components/tiptap-templates/simple/components/simple-editor'

export default function App() {
  return <SimpleEditor />
}
```

## 功能

这是一款完全响应式的富文本编辑器，内置支持常见的格式和布局工具。所有组件均为开源，且易于扩展。

- **响应式设计**：默认适配移动设备
- **深色和浅色模式**：开箱即用
- **文本格式**：粗体、斜体、下划线
- **列表**：项目符号列表、有序列表、复选框
- **文本对齐**：左对齐、居中、右对齐、两端对齐
- **标题**：通过下拉菜单选择多个级别
- **图片上传**
- **链接编辑**：用于添加和编辑链接的界面
- **查找和替换**：查找文本、选择匹配项并替换，由[查找和替换扩展](/editor/extensions/functionality/find-and-replace)提供支持
- **撤销/重做**：历史记录管理
