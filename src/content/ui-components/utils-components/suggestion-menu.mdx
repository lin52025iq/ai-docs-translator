功能强大且灵活的 Tiptap 编辑器建议菜单系统。通过可配置字符触发浮动下拉菜单，并支持完整的键盘导航、筛选和自定义渲染。

<CodeDemo isScrollable src="https://template.tiptap.dev/preview/tiptap-ui-utils/suggestion-menu" />

## 安装

通过 Tiptap CLI 添加此组件：

```bash
npx @tiptap/cli@latest add suggestion-menu
```

## 组件

### `<SuggestionMenu />`

核心建议菜单组件，提供浮动下拉界面，可通过输入特定字符触发。

#### 用法

```tsx
<SuggestionMenu
  editor={editor}
  char="@"
  pluginKey="myMentionMenu"
  items={async ({ query, editor }) => [
    {
      title: 'John Doe',
      subtext: 'Software Engineer',
      onSelect: ({ editor, range }) => {
        editor.chain().focus().insertContentAt(range, '@john').run()
      },
    },
  ]}
>
  {({ items, selectedIndex, onSelect }) => (
    <MenuList items={items} selectedIndex={selectedIndex} onSelect={onSelect} />
  )}
</SuggestionMenu>
```

#### 属性

| 名称                 | 类型                                   | 默认值                     | 说明                                                                                  |
| -------------------- | -------------------------------------- | -------------------------- | -------------------------------------------------------------------------------------------- |
| `editor`             | `Editor \| null`                       | `undefined`                | Tiptap 编辑器实例                                                                   |
| `char`               | `string`                               | `"@"`                      | 触发建议菜单的字符                                                  |
| `items`              | `(props) => Item[] \| Promise<Item[]>` | `() => []`                 | 返回建议条目的函数                                                          |
| `children`           | `(props) => ReactNode`                 | `undefined`                | 菜单内容的渲染函数                                                             |
| `floatingOptions`    | `Partial<UseFloatingOptions>`          | `undefined`                | 浮动 UI 的其他定位选项                                                   |
| `selector`           | `string`                               | `"tiptap-suggestion-menu"` | 菜单容器的 CSS 选择器                                                          |
| `pluginKey`          | `string \| PluginKey`                  | `SuggestionPluginKey`      | 建议插件的唯一标识符                                                  |
| `maxHeight`          | `number`                               | `384`                      | 建议菜单的最大高度（像素）。内容超出此高度时，菜单可滚动 |
| `allowSpaces`        | `boolean`                              | `false`                    | 是否允许建议查询中包含空格                                                           |
| `allowToIncludeChar` | `boolean`                              | `false`                    | 是否在查询中包含触发字符                                                           |
| `allowedPrefixes`    | `string[] \| null`                     | `[" "]`                    | 触发字符前允许出现的字符                                                      |
| `startOfLine`        | `boolean`                              | `false`                    | 是否仅在行首触发                                                                   |
| `decorationTag`      | `string`                               | `"span"`                   | 装饰元素的 HTML 标签                                                              |
| `decorationClass`    | `string`                               | `"suggestion"`             | 装饰样式的 CSS 类                                                             |
| `decorationContent`  | `string`                               | `""`                       | 装饰中的占位文本                                                               |

## 类型

### `SuggestionItem<T>`

定义建议条目结构的接口。

```tsx
interface SuggestionItem<T = any> {
  title: string // Main display text
  subtext?: string // Secondary context text
  badge?: React.MemoExoticComponent<IconComponent> | React.FC<IconProps> | string // Icon or badge component
  group?: string // Group identifier for organization
  keywords?: string[] // Additional search keywords
  context?: T // Custom data passed to onSelect
  onSelect: (props: {
    // Selection handler
    editor: Editor
    range: Range
    context?: T
  }) => void
}
```

### `SuggestionMenuRenderProps<T>`

传递给 children 渲染函数的属性。

```tsx
type SuggestionMenuRenderProps<T = any> = {
  items: SuggestionItem<T>[] // Filtered suggestion items
  selectedIndex?: number // Currently selected item index
  onSelect: (item: SuggestionItem<T>) => void // Item selection handler
}
```

## 实用工具

### `filterSuggestionItems(items, query)`

根据搜索查询筛选并排列建议条目。

```tsx
import { filterSuggestionItems } from '@/components/tiptap-ui-utils/suggestion-menu'

const filteredItems = filterSuggestionItems(allItems, 'john')
```

#### 参数

| 名称    | 类型               | 说明                         |
| ------- | ------------------ | ----------------------------------- |
| `items` | `SuggestionItem[]` | 要筛选的建议条目数组 |
| `query` | `string`           | 搜索查询字符串                 |

#### 筛选逻辑

- 匹配 `title`、`subtext` 和 `keywords` 属性
- 匹配时不区分大小写
- 优先显示完全匹配和以查询内容开头的匹配项
- 查询为空时返回所有条目

### `calculateStartPosition(cursorPosition, previousNode, triggerChar)`

计算文本中建议命令的起始位置。

```tsx
import { calculateStartPosition } from '@/components/tiptap-ui-utils/suggestion-menu'

const startPos = calculateStartPosition(100, textNode, '@')
```

#### 参数

| 名称             | 类型           | 说明                          |
| ---------------- | -------------- | ------------------------------------ |
| `cursorPosition` | `number`       | 光标在文档中的当前位置  |
| `previousNode`   | `Node \| null` | 光标前的文本节点              |
| `triggerChar`    | `string`       | 触发建议的字符            |

## 高级用法

### 自定义建议菜单

创建自定义建议菜单，全面控制条目和渲染方式：

```tsx
function CustomMentionMenu() {
  const getSuggestionItems = async ({ query, editor }) => {
    const users = await fetchUsers(query)

    return users.map((user) => ({
      title: user.name,
      subtext: user.email,
      context: user,
      badge: UserIcon,
      keywords: [user.department, user.role],
      onSelect: ({ editor, range, context }) => {
        editor
          .chain()
          .focus()
          .insertContentAt(range, {
            type: 'mention',
            attrs: { id: context.id, label: context.name },
          })
          .run()
      },
    }))
  }

  return (
    <SuggestionMenu
      char="@"
      pluginKey="customMention"
      items={getSuggestionItems}
      allowSpaces={false}
      decorationClass="my-mention-decoration"
    >
      {({ items, selectedIndex, onSelect }) => (
        <Card>
          <CardBody>
            {items.map((item, index) => (
              <MentionItem
                key={item.title}
                item={item}
                isSelected={index === selectedIndex}
                onSelect={() => onSelect(item)}
              />
            ))}
          </CardBody>
        </Card>
      )}
    </SuggestionMenu>
  )
}
```

### 使用分组条目

将建议按组整理，方便浏览：

```tsx
function GroupedSuggestionMenu() {
  const getSuggestionItems = async ({ query, editor }) => {
    return [
      {
        title: 'Add Heading',
        group: 'Formatting',
        badge: HeadingIcon,
        onSelect: ({ editor, range }) => {
          editor.chain().focus().deleteRange(range).toggleHeading({ level: 1 }).run()
        },
      },
      {
        title: 'Add Table',
        group: 'Insert',
        badge: TableIcon,
        onSelect: ({ editor, range }) => {
          editor.chain().focus().deleteRange(range).insertTable().run()
        },
      },
    ]
  }

  return (
    <SuggestionMenu char="/" items={getSuggestionItems}>
      {({ items, selectedIndex, onSelect }) => (
        <Card>
          <CardBody>
            {Object.entries(groupBy(items, 'group')).map(([groupName, groupItems]) => (
              <div key={groupName}>
                <CardGroupLabel>{groupName}</CardGroupLabel>
                <CardItemGroup>
                  {groupItems.map((item, index) => (
                    <SuggestionItem
                      key={item.title}
                      item={item}
                      isSelected={index === selectedIndex}
                      onSelect={() => onSelect(item)}
                    />
                  ))}
                </CardItemGroup>
              </div>
            ))}
          </CardBody>
        </Card>
      )}
    </SuggestionMenu>
  )
}
```

## 样式

建议菜单会设置一个 CSS 自定义属性，可用于样式设置：

### CSS 自定义属性

| 属性                           | 说明                                        | 默认值 |
| ------------------------------ | -------------------------------------------------- | ------------- |
| `--suggestion-menu-max-height` | 菜单的最大高度，动态计算 | `384px`       |

菜单容器使用 `tiptap-suggestion-menu` 类，并包含一个 `data-selector` 属性，便于针对性设置样式。

### 样式示例

```css
.tiptap-suggestion-menu {
  max-height: var(--suggestion-menu-max-height);
  overflow-y: auto;
  background: white;
  border-radius: 8px;
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.15);
}
```

## 无障碍

该组件内置了以下无障碍功能：

- 使用 `role="listbox"`，为屏幕阅读器提供适当支持
- 使用 `aria-label="Suggestions"` 说明菜单用途
- 支持使用方向键浏览，并按 Enter 进行选择
- 按 Escape 键关闭菜单
- 阻止默认指针事件，以保持编辑器焦点
