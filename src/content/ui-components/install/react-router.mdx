使用以下命令创建一个新的 TypeScript React 项目，然后添加 React Router。

```bash
npx create-react-router@latest my-app
```

## 添加 Tiptap 组件

使用 CLI 安装 Tiptap UI 组件。例如，添加 `HeadingButton` 组件：

```bash
npx @tiptap/cli@latest add heading-button
```

上述命令会安装 `HeadingButton` 组件及其依赖。然后，你就可以在 **Tiptap** 项目中导入并使用它：

```tsx
import React from 'react'
import { HeadingButton } from '@/components/ui/heading-button'

export default function EditorPage() {
  // Tiptap setup...

  return (
    <div className="editor-page">
      <div className="toolbar">
        <HeadingButton level={1}>Heading 1</HeadingButton>
        <HeadingButton level={2}>Heading 2</HeadingButton>
        <HeadingButton level={3}>Heading 3</HeadingButton>
      </div>
      {/* Your editor component */}
    </div>
  )
}
```

## 添加样式

<Callout title="样式会自动添加" variant="info">
  安装第一个 Tiptap UI 组件时，CLI 会自动将所需的{' '}
  <code>.scss</code> 导入语句添加到主样式表中。大多数情况下，**无需手动配置**。
</Callout>

继续之前，请确保项目中包含 CSS reset。
如果你使用 Tailwind CSS，则项目中已经包含了 CSS reset。

#### 样式导入位置

CLI 会自动将样式导入语句注入全局样式表，例如：

- `src/index.css`（具体取决于你的项目）

如果你自定义了入口文件，请确保其中包含以下内容：

**文件：** `src/index.css`（具体取决于你的项目）

```css
@import '<path-to-styles>/_variables.scss';
@import '<path-to-styles>/_keyframe-animations.scss';
```

如需了解如何配置样式，请参阅[样式设置指南](/ui-components/getting-started/style)。
