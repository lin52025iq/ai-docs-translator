使用以下命令搭建新的 Vite 项目。出现提示时，选择 `React + TypeScript`。

```bash
npm create vite@latest
```

## 配置 TypeScript 路径

Vite 将 TypeScript 配置拆分到多个文件中。你需要同时更新 `tsconfig.json` 和 `tsconfig.app.json`。

在 `tsconfig.json` 的 `compilerOptions` 中添加以下内容：

```json
{
  // ...
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

在 `tsconfig.app.json` 中更新以下 `compilerOptions`：

```json
{
  "compilerOptions": {
    // ...
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
  // ...
}
```

## 更新 Vite 配置

若要启用路径别名并避免 `__dirname` 类型错误：

安装 Node 类型：

```bash
npm install -D @types/node
```

然后编辑 `vite.config.ts`：

```ts
import path from 'path'

export default defineConfig({
  // ...
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './src'),
    },
  },
})
```

## 渲染编辑器

<Callout title="新项目仍会显示 Vite 默认页面" variant="warning">
  搭建项目会创建标准的 Vite + React 应用。添加组件时，组件源代码会复制到
  `src/components/`，但在你自行于 `src/App.tsx` 中渲染 Tiptap 组件之前，该文件仍会渲染 Vite 的默认起始页面。这是预期行为，并不代表安装失败。
</Callout>

将你安装的模板或组件替换到 `src/App.tsx` 中。例如，**Simple Editor** 模板：

```tsx
import { SimpleEditor } from '@/components/tiptap-templates/simple/components/simple-editor'

export default function App() {
  return <SimpleEditor />
}
```

启动开发服务器以查看编辑器：

```bash
npm run dev
```

## 添加 Tiptap 组件

使用 CLI 安装 Tiptap UI 组件。例如，添加 `HeadingButton` 组件：

```bash
npx @tiptap/cli@latest add heading-button
```

上述命令会安装 `HeadingButton` 组件及其依赖项。然后，你就可以在 **Tiptap** 项目中导入并使用它：

```tsx
import { HeadingButton } from '@/components/ui/heading-button'

export default function App() {
  // Tiptap ...

  return (
    <>
      <HeadingButton level={1}>Heading 1</HeadingButton>
      <HeadingButton level={2}>Heading 2</HeadingButton>
      <HeadingButton level={3}>Heading 3</HeadingButton>
    </>
  )
}
```

## 添加样式

<Callout title="样式会自动添加" variant="info">
  安装第一个 Tiptap UI Component 时，CLI 会自动将所需的{' '}
  <code>.scss</code> 导入语句添加到主样式表中。大多数情况下，**无需手动设置**。
</Callout>

继续之前，请确保项目中包含 CSS 重置样式。
如果你使用 Tailwind CSS，则已经包含了重置样式。

#### 样式导入位置

CLI 会自动将样式导入语句注入全局样式表，例如：

- `src/index.css`（取决于你的项目）

如果你自定义了入口文件，请确保其中包含以下内容：

**文件：** `src/index.css`（取决于你的项目）

```css
@import '<path-to-styles>/_variables.scss';
@import '<path-to-styles>/_keyframe-animations.scss';
```

有关样式配置的更多信息，请参阅[样式设置指南](/ui-components/getting-started/style)。
