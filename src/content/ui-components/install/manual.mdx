## 配置路径别名

在 `tsconfig.json` 文件中配置路径别名。

```json
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./*"]
    }
  }
}
```

`@` 别名只是一个建议。你也可以根据需要使用其他别名。

## 配置样式

请按照[样式设置指南](/ui-components/getting-started/style)操作，确保编辑器和组件能够正确渲染。

### 就这样！

现在，你无需进行其他设置，即可在项目中使用 Tiptap UI Components。只需导入所需组件，就可以开始构建编辑器了。
