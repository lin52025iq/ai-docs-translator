这是一款完全无障碍、由 AI 驱动的 Tiptap 编辑器按钮。它支持键盘快捷键和灵活的自定义选项，可对选中的文本触发智能内容生成和编辑。

<Callout title="集成" variant="info">
  AI 提问按钮需要在 Tiptap 编辑器中安装 `ai-menu` 和 `ui-state-extension`。查看演示，请前往 [AI 菜单](/ui-components/components/ai-menu)。
</Callout>

## 安装

通过 Tiptap CLI 添加此组件：

```bash
npx @tiptap/cli@latest add ai-ask-button
```

## 组件

### `<AiAskButton />`

一个预构建的 React 组件，可为选中的内容触发 AI 辅助。

#### 用法

```tsx
import { EditorContent, EditorContext, useEditor } from '@tiptap/react'
import { StarterKit } from '@tiptap/starter-kit'
import { Ai } from '@tiptap-pro/extension-ai'
import { AiAskButton } from '@/components/tiptap-ui/ai-ask-button'
import { UiState } from '@/components/tiptap-extension/ui-state-extension'

import '@/components/tiptap-node/paragraph-node/paragraph-node.scss'

export default function MyEditor() {
  const editor = useEditor({
    immediatelyRender: false,
    extensions: [
      StarterKit,
      UiState,
      Ai.configure({
        token: 'your-ai-token',
        autocompletion: false,
        showDecorations: true,
        onLoading: (context) => {
          context.editor.commands.aiGenerationSetIsLoading(true)
          context.editor.commands.aiGenerationHasMessage(false)
        },
        onSuccess: (context) => {
          context.editor.commands.aiGenerationSetIsLoading(false)
          context.editor.commands.aiGenerationHasMessage(!!context.response)
        },
      }),
    ],
    content: `
      <p>Select some text and click the AI button to get intelligent suggestions and improvements.</p>
      <p>The AI can help improve writing, fix grammar, translate, and much more!</p>
    `,
  })

  return (
    <EditorContext.Provider value={{ editor }}>
      <AiAskButton
        editor={editor}
        text="Ask AI"
        hideWhenUnavailable={true}
        showShortcut={true}
        onAiAsked={() => console.log('AI assistance triggered!')}
      />

      <EditorContent editor={editor} role="presentation" />
    </EditorContext.Provider>
  )
}
```

#### 属性

| 名称                  | 类型             | 默认值      | 说明                                         |
| --------------------- | ---------------- | ----------- | -------------------------------------------- |
| `editor`              | `Editor \| null` | `undefined` | Tiptap 编辑器实例                            |
| `text`                | `string`         | `undefined` | 按钮的可选文本标签                           |
| `hideWhenUnavailable` | `boolean`        | `false`     | AI 功能不可用时隐藏按钮                      |
| `onAiAsked`           | `() => void`     | `undefined` | 触发 AI 辅助后调用的回调                     |
| `showShortcut`        | `boolean`        | `false`     | 显示键盘快捷键徽标（Cmd/Ctrl + J）            |

## Hooks

### `useAiAsk()`

一个自定义 Hook，可完全掌控渲染方式和行为，自行构建 AI 提问按钮。

#### 用法

```tsx
import { useAiAsk } from '@/components/tiptap-ui/ai-ask-button'

function MyAiAskButton() {
  const { isVisible, canAiAsk, handleAiAsk, label, shortcutKeys, Icon } = useAiAsk({
    editor: myEditor,
    hideWhenUnavailable: true,
    onAiAsked: () => console.log('AI assistance requested!'),
  })

  if (!isVisible) return null

  return (
    <button
      onClick={handleAiAsk}
      disabled={!canAiAsk}
      aria-label={label}
      title={`${label} (${shortcutKeys})`}
    >
      <Icon />
      {label}
    </button>
  )
}
```

#### 属性

| 名称                  | 类型             | 默认值      | 说明                                          |
| --------------------- | ---------------- | ----------- | --------------------------------------------- |
| `editor`              | `Editor \| null` | `undefined` | Tiptap 编辑器实例                             |
| `hideWhenUnavailable` | `boolean`        | `false`     | AI 功能不可用时隐藏按钮                       |
| `onAiAsked`           | `() => void`     | `undefined` | 触发 AI 辅助后调用的回调                      |

#### 返回值

| 名称           | 类型            | 说明                                  |
| -------------- | --------------- | ------------------------------------- |
| `isVisible`    | `boolean`       | 是否应渲染此按钮                      |
| `canAiAsk`     | `boolean`       | 当前是否可以触发 AI 辅助              |
| `handleAiAsk`  | `() => boolean` | 触发 AI 辅助的函数                    |
| `label`        | `string`        | 按钮的无障碍标签文本                  |
| `shortcutKeys` | `string`        | 键盘快捷键（Cmd/Ctrl + J）            |
| `Icon`         | `React.FC`      | AI 提问按钮的图标组件                 |

## 工具函数

### `canPerformAiAsk(editor)`

检查当前编辑器状态下是否可以触发 AI 辅助。

```tsx
import { canPerformAiAsk } from '@/components/tiptap-ui/ai-ask-button'

const canTriggerAi = canPerformAiAsk(editor)
if (canTriggerAi) {
  console.log('AI assistance is available for the current selection')
}
```

#### 参数

| 名称     | 类型             | 说明             |
| -------- | ---------------- | ---------------- |
| `editor` | `Editor \| null` | Tiptap 编辑器实例 |

#### 返回值

`boolean` - 是否可以对当前选区执行 AI 辅助。

### `shouldShowButton(props)`

根据编辑器状态和配置，判断是否应显示 AI 提问按钮。

```tsx
import { shouldShowButton } from '@/components/tiptap-ui/ai-ask-button'

const isVisible = shouldShowButton({
  editor: myEditor,
  hideWhenUnavailable: true,
})
```

#### 参数

| 名称                        | 类型             | 说明                       |
| --------------------------- | ---------------- | -------------------------- |
| `props.editor`              | `Editor \| null` | Tiptap 编辑器实例          |
| `props.hideWhenUnavailable` | `boolean`        | AI 功能不可用时是否隐藏按钮 |

#### 返回值

`boolean` - 是否应显示此按钮。

## 行为和限制

### 选区要求

AI 提问按钮适用于文本选区，并有以下要求：

- **必须选择文本**：仅当选中了文本时，按钮才会启用
- **支持的内容**：适用于段落、标题、列表以及大多数文本内容
- **不支持的内容类型**：
  - 图片和图片上传内容
  - 代码块
  - 水平分隔线
  - 空选区

## 键盘快捷键

AI 提问按钮支持以下键盘快捷键：

- **Cmd/Ctrl + J**：为选中的内容触发 AI 辅助

使用 `<AiAskButton />` 组件或 `useAiAsk()` Hook 时，都会自动注册此快捷键。仅在以下条件全部满足时，快捷键才会生效：

- 按钮可见
- 可以对当前选区执行 AI 辅助
- 编辑器处于聚焦且可编辑状态

- `@tiptap/react` - Tiptap React 核心集成

- `ui-state-extension` - 管理 AI 操作的 UI 状态（推荐）
- 以下二者之一：`@tiptap-pro/extension-ai` 或自定义 `aiGeneration` 扩展

- `use-tiptap-editor`（Hook）
- `button`（基础组件）
- `badge`（基础组件）
- `tiptap-utils`（库）
