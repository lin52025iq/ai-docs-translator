适用于 Tiptap 编辑器的无障碍搜索与替换面板。它提供实时结果高亮、从 1 开始计数的结果计数器、循环导航、区分大小写和整词匹配选项、正则表达式搜索，以及替换或全部替换操作。

该组件负责管理搜索状态和编辑器命令，但不会管理自身的位置或打开状态。你可以将它停靠在角落、放入弹出层，或作为行内内容渲染。

</Callout>

## 安装

通过 Tiptap CLI 添加此组件：

```bash
npx @tiptap/cli@latest add search-and-replace
```

## 设置

在编辑器中注册 [Find and Replace 扩展](/editor/extensions/functionality/find-and-replace)。该 UI 组件包含 `.find-and-replace-result` 和 `.find-and-replace-result-current` 的样式，因此使用随附的 SCSS 时，请禁用扩展注入的高亮 CSS。

```tsx
import { FindAndReplace } from '@tiptap/extension-find-and-replace'
import { StarterKit } from '@tiptap/starter-kit'

const editor = useEditor({
  immediatelyRender: false,
  extensions: [
    StarterKit,
    FindAndReplace.configure({
      injectCSS: false,
    }),
  ],
})
```

搜索输入的变化会直接传递给扩展。扩展的 `searchDebounceMs` 选项控制结果何时更新；UI 不会再额外添加一层防抖。

## 组件

### `<SearchAndReplace />`

完整的搜索与替换面板。如果希望内置的 `Mod+F` 快捷键能够重新打开已关闭的面板，请让该组件保持挂载，并通过 `open` 控制其状态。

#### 用法

```tsx
'use client'

import { useState } from 'react'
import { EditorContent, EditorContext, useEditor } from '@tiptap/react'
import { FindAndReplace } from '@tiptap/extension-find-and-replace'
import { StarterKit } from '@tiptap/starter-kit'

import { SearchAndReplace, SearchAndReplaceButton } from '@/components/tiptap-ui/search-and-replace'

export default function MyEditor() {
  const [isSearchOpen, setIsSearchOpen] = useState(false)
  const editor = useEditor({
    immediatelyRender: false,
    extensions: [
      StarterKit,
      FindAndReplace.configure({
        injectCSS: false,
      }),
    ],
    content: '<p>Search this document for Tiptap.</p>',
  })

  return (
    <EditorContext.Provider value={{ editor }}>
      <SearchAndReplaceButton
        tabIndex={0}
        aria-expanded={isSearchOpen}
        data-active-state={isSearchOpen ? 'on' : 'off'}
        onClick={() => setIsSearchOpen((current) => !current)}
      />

      <div style={{ position: 'relative' }}>
        <SearchAndReplace
          open={isSearchOpen}
          onOpen={() => setIsSearchOpen(true)}
          onClose={() => setIsSearchOpen(false)}
          style={{
            position: 'absolute',
            top: '0.5rem',
            right: '0.5rem',
            zIndex: 10,
          }}
        />

        <EditorContent editor={editor} />
      </div>
    </EditorContext.Provider>
  )
}
```

已打开的 `SearchAndReplace` 面板切换为 `open={false}` 时，组件仍保持挂载，关闭的面板不再显示，结果高亮会被清除，已输入的搜索词和替换词则会保留。再次打开面板时，会重新应用已保存的搜索。卸载组件会彻底清除搜索和待处理操作。

用户点击面板外部时，面板不会自动关闭。如果你的布局需要点击外部关闭，请在负责管理 `open` 的组件中处理此行为。

浏览结果时只会移动高亮。编辑器选区会保留在用户原先的位置，因此工具栏状态、浮动菜单以及链接弹出层等弹出窗口不会响应当前匹配项。

#### 属性

面板由两个独立状态控制：`open` 决定已挂载的面板是显示还是关闭，`hideWhenUnavailable` 则决定组件是否渲染。

此外，该组件会将 `HTMLAttributes<HTMLDivElement>`（`children` 除外）转发给根面板。

| 名称                    | 类型                    | 默认值                                    | 说明                                                                                                                          |
| ----------------------- | ----------------------- | ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `editor`                | `Editor \| null`        | 来自 `EditorContext` 的编辑器             | Tiptap 编辑器实例。                                                                                                          |
| `hideWhenUnavailable`   | `boolean`               | `false`                                   | Find and Replace 扩展不可用时不渲染任何内容。否则面板仍会渲染，但控件处于禁用状态。       |
| `scrollIntoViewOptions` | `ScrollIntoViewOptions` | `{ block: 'nearest', inline: 'nearest' }` | 将当前结果滚动到视野内时使用的选项。用户偏好减少动态效果时，平滑滚动会变为即时滚动。 |
| `open`                  | `boolean`               | `true`                                    | 已挂载的面板是否打开。关闭面板会保留已输入的值，但暂停结果高亮。                                |
| `onClose`               | `() => void`            | `undefined`                               | 点击关闭按钮或按下 `Escape` 时调用。此回调必须更新受控的 `open` 状态。                                        |
| `onOpen`                | `() => void`            | `undefined`                               | 面板关闭时按下 `Mod+F` 会调用此回调。若希望快捷键重新打开面板，请提供此回调。                      |
| `enableShortcut`        | `boolean`               | `true`                                    | 组件已挂载且扩展可用时，为整个页面绑定 `Mod+F`，包括面板关闭期间。 |
| `autoFocusSearch`       | `boolean`               | `true`                                    | 面板打开且编辑器就绪时，聚焦并选中搜索输入框。                                                   |
| `className`             | `string`                | `undefined`                               | 为根面板添加类名，同时保留 `tiptap-search-replace`。                                                             |

### `<SearchAndReplaceContent />`

`SearchAndReplace` 的完全别名。当面板作为行内内容嵌入时（例如放在折叠的移动端工具栏中），可以使用此名称。它接受相同的 `SearchAndReplaceProps`。

```tsx
<SearchAndReplaceContent
  editor={editor}
  open={isSearchOpen}
  onOpen={() => setIsSearchOpen(true)}
  onClose={() => setIsSearchOpen(false)}
/>
```

### `<SearchAndReplaceButton />`

基于共享 `Button` 基元构建的展示型触发按钮。它会渲染搜索图标、工具提示和 `Mod+F` 快捷键提示，但不会管理面板状态或执行编辑器命令。

```tsx
<SearchAndReplaceButton
  tabIndex={0}
  aria-expanded={isSearchOpen}
  data-active-state={isSearchOpen ? 'on' : 'off'}
  onClick={() => setIsSearchOpen((current) => !current)}
/>
```

此按钮接受共享的 `ButtonProps`。其默认 `tabIndex` 为 `-1`，因为工具栏基元通过循环焦点停靠点管理焦点。在受管理的工具栏之外将其作为独立按钮渲染时，请设置 `tabIndex={0}`。

## 正则表达式模式

启用 **使用正则表达式** 后，搜索词会被视为正则表达式源。扩展使用兼容 RE2 的引擎编译这些模式，因此不支持环视和反向引用。正则表达式模式启用时，区分大小写和整词匹配选项仍可使用；面板还会提供可将示例模式填入输入框的按钮。

无效模式以及被引擎判定为不安全的模式会返回零个结果，不会抛出错误。正则表达式只影响匹配：替换文本会按字面插入，因此 `$1` 等捕获组引用不会展开。

有关扩展级选项和匹配规则（包括各选项在正则表达式模式下的行为），请参阅 [Find and Replace 扩展文档](/editor/extensions/functionality/find-and-replace)。

## Hooks

### `useSearchAndReplace()`

一个无头 hook，可公开预构建面板使用的相同响应式编辑器状态和操作。

#### 用法

```tsx
import { useSearchAndReplace } from '@/components/tiptap-ui/search-and-replace'

function CustomSearchPanel({ editor }) {
  const {
    isVisible,
    canSearch,
    searchTerm,
    replaceTerm,
    resultCountLabel,
    caseSensitive,
    canNavigate,
    canReplace,
    setSearchTerm,
    setReplaceTerm,
    toggleCaseSensitive,
    goToNext,
    replaceCurrent,
  } = useSearchAndReplace({
    editor,
    hideWhenUnavailable: true,
  })

  if (!isVisible) return null

  return (
    <div role="search">
      <input
        aria-label="Search"
        value={searchTerm}
        disabled={!canSearch}
        onChange={(event) => setSearchTerm(event.target.value)}
      />
      <input
        aria-label="Replace"
        value={replaceTerm}
        disabled={!canSearch}
        onChange={(event) => setReplaceTerm(event.target.value)}
      />
      <span>{resultCountLabel}</span>
      <button
        type="button"
        aria-pressed={caseSensitive}
        disabled={!canSearch}
        onClick={toggleCaseSensitive}
      >
        Match case
      </button>
      <button type="button" disabled={!canNavigate} onClick={goToNext}>
        Next
      </button>
      <button type="button" disabled={!canReplace} onClick={replaceCurrent}>
        Replace
      </button>
    </div>
  )
}
```

#### 配置

| 名称                    | 类型                    | 默认值                             | 说明                                                                                     |
| ----------------------- | ----------------------- | ---------------------------------- | ----------------------------------------------------------------------------------------------- |
| `editor`                | `Editor \| null`        | 来自 `EditorContext` 的编辑器      | Tiptap 编辑器实例。                                                                     |
| `hideWhenUnavailable`   | `boolean`               | `false`                            | Find and Replace 扩展不可用时，hook 是否报告 `isVisible: false`。 |
| `scrollIntoViewOptions` | `ScrollIntoViewOptions` | `DEFAULT_SCROLL_INTO_VIEW_OPTIONS` | 在不移动焦点的情况下显示当前结果时使用的选项。                                 |

#### 返回值

| 名称                  | 类型                      | 说明                                                                                                      |
| --------------------- | ------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `editor`              | `Editor \| null`          | 解析得到的编辑器实例。                                                                                    |
| `isVisible`           | `boolean`                 | 搜索 UI 是否应当渲染。                                                                             |
| `canSearch`           | `boolean`                 | 编辑器是否具有 Find and Replace 扩展。                                                           |
| `searchTerm`          | `string`                  | 当前搜索输入值。                                                                                |
| `replaceTerm`         | `string`                  | 当前替换输入值。                                                                           |
| `appliedSearchTerm`   | `string`                  | 防抖后当前由扩展应用的搜索词。                                           |
| `total`               | `number`                  | 当前结果数。                                                                                       |
| `currentIndex`        | `number \| null`          | 当前结果的从 0 开始的索引；未选中结果时为 `null`。                                           |
| `resultCountLabel`    | `string`                  | 从 1 开始的计数标签，例如 `1 / 8`；无结果时为 `0 / 0`。                                                     |
| `caseSensitive`       | `boolean`                 | 扩展存储中的当前区分大小写状态。                                                                 |
| `wholeWord`           | `boolean`                 | 扩展存储中的当前整词匹配状态。                                                                 |
| `useRegex`            | `boolean`                 | 扩展存储中的当前正则表达式状态。                                                         |
| `canNavigate`         | `boolean`                 | 是否至少有一个结果可供选中。                                                                     |
| `canReplace`          | `boolean`                 | 编辑器是否可编辑、是否存在当前结果，以及替换文本是否非空。                      |
| `canReplaceAll`       | `boolean`                 | 编辑器是否可编辑、是否存在结果，以及替换文本是否非空。                                |
| `setSearchTerm`       | `(value: string) => void` | 立即更新输入，并将非空值传递给扩展。空文本会立即清除结果。 |
| `setReplaceTerm`      | `(value: string) => void` | 更新 hook 和扩展中的替换值。                                                         |
| `toggleCaseSensitive` | `() => void`              | 切换区分大小写匹配。                                                                                 |
| `toggleWholeWord`     | `() => void`              | 切换整词匹配。                                                                                     |
| `toggleUseRegex`      | `() => void`              | 切换正则表达式匹配。                                                                             |
| `goToNext`            | `() => boolean`           | 选择下一个结果，并在到达末尾时循环到开头。                                                                    |
| `goToPrevious`        | `() => boolean`           | 选择上一个结果，并在到达开头时循环到末尾。                                                          |
| `replaceCurrent`      | `() => boolean`           | 替换当前结果，并在可能时前进到下一个结果。                                                          |
| `replaceAll`          | `() => boolean`           | 替换当前结果集中的所有结果。                                                                 |
| `applySearch`         | `() => void`              | 重新应用已保存的搜索和替换值，例如重新打开已挂载的面板时。                  |
| `suspendSearch`       | `() => void`              | 清除高亮和待处理操作，同时保留 hook 的输入值。                                     |
| `clearSearch`         | `() => void`              | 清除输入值、待处理操作和高亮。                                                               |
| `label`               | `string`                  | 无障碍标签：`Search and replace`。                                                                          |
| `shortcutKeys`        | `string`                  | 主快捷键：`mod+f`。                                                                                      |
| `Icon`                | `React.ComponentType`     | 搜索图标组件。                                                                                           |

导出的 `UseSearchAndReplaceReturn` 类型是根据此 hook 推断出的返回类型。

## 工具函数

### 可用性和存储辅助函数

```tsx
import {
  getFindAndReplaceStorage,
  isFindAndReplaceAvailable,
  shouldShowSearchAndReplace,
} from '@/components/tiptap-ui/search-and-replace'

const available = isFindAndReplaceAvailable(editor)
const storage = getFindAndReplaceStorage(editor)
const visible = shouldShowSearchAndReplace({
  editor,
  hideWhenUnavailable: true,
})
```

- `isFindAndReplaceAvailable(editor)` 检查是否已注册 `findAndReplace` 扩展。
- `getFindAndReplaceStorage(editor)` 返回其响应式存储对象；如果不存在，则返回 `null`。
- `shouldShowSearchAndReplace({ editor, hideWhenUnavailable })` 应用组件的可见性规则。

### 结果格式化和滚动

```tsx
import {
  DEFAULT_SCROLL_INTO_VIEW_OPTIONS,
  formatResultCount,
  scrollCurrentResultIntoView,
} from '@/components/tiptap-ui/search-and-replace'

formatResultCount(null, 0) // "0 / 0"
formatResultCount(0, 8) // "1 / 8"

scrollCurrentResultIntoView(editor, {
  block: 'center',
  inline: 'nearest',
})
```

`scrollCurrentResultIntoView()` 会根据文档位置解析当前匹配项，并滚动到该位置而不移动焦点。焦点位于编辑器内时，它不会执行操作；同时会遵循 `prefers-reduced-motion` 设置。

### 导出的常量

| 常量                               | 值                                        | 用途                                                   |
| ---------------------------------- | ----------------------------------------- | ------------------------------------------------------ |
| `SEARCH_AND_REPLACE_SHORTCUT_KEY`  | `mod+f`                                   | 打开搜索或重新聚焦搜索。                                |
| `NEXT_RESULT_SHORTCUT_KEY`         | `mod+shift+f`                             | 在面板内选择下一个结果。          |
| `PREVIOUS_RESULT_SHORTCUT_KEY`     | `mod+shift+d`                             | 在面板内选择上一个结果。      |
| `SEARCH_RESULT_CLASS`              | `find-and-replace-result`                 | 扩展为每个匹配项渲染的类。       |
| `SEARCH_RESULT_CURRENT_CLASS`      | `find-and-replace-result-current`         | 扩展为当前匹配项渲染的类。 |
| `DEFAULT_SCROLL_INTO_VIEW_OPTIONS` | `{ block: 'nearest', inline: 'nearest' }` | 当前结果滚动对齐方式的默认值。               |

该模块还导出 `SearchAndReplaceProps`、`SearchAndReplaceContentProps`、`UseSearchAndReplaceConfig`、`UseSearchAndReplaceReturn` 和 `SearchAndReplaceEditorState`。

## 键盘快捷键

| 按键               | 行为                                                                                                                                        |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `Mod+F`            | 面板打开时聚焦并选中搜索输入框。面板关闭时，如果提供了 `onOpen`，则调用该回调；否则仍可使用浏览器原生搜索。 |
| `ArrowDown`        | 搜索打开且存在结果时选择下一个结果。                                                                                 |
| `ArrowUp`          | 搜索打开且存在结果时选择上一个结果。                                                                             |
| 搜索框中的 `Enter`  | 选择下一个结果。                                                                                                                        |
| 替换框中的 `Enter` | 启用替换功能时替换当前结果。                                                                                        |
| `Mod+Shift+F`      | 焦点位于面板内时选择下一个结果。                                                                                        |
| `Mod+Shift+D`      | 焦点位于面板内时选择上一个结果。                                                                                    |
| `Escape`           | 焦点位于面板内时调用 `onClose`。                                                                                                |

在面板外使用普通方向键导航时，不会接管编辑器内容、表单字段或其他文本输入框。

只要组件已挂载且扩展可用，无论面板打开还是关闭，`Mod+F` 都会在整个页面被捕获，包括其他输入框和 contenteditable 区域，因此浏览器的页内搜索不会与组件自身的搜索冲突。如果布局需要将 `Mod+F` 留给浏览器，请将 `enableShortcut` 设为 `false`。

## 样式和公共选择器

面板默认不定位，宽度为 `19rem`，并设有 `max-width: 100%`。视口宽度不超过 `480px` 时，面板可扩展至可用宽度。可通过 `className`、`style` 或外层布局组件添加定位。

以下类可公开用于样式设置和查询：

- `tiptap-search-replace`
- `tiptap-search-replace-header`
- `tiptap-search-replace-count`
- `tiptap-search-replace-nav-group`
- `tiptap-search-replace-inputs`
- `tiptap-search-replace-options`
- `tiptap-search-replace-actions`
- `button-group`

该组件还提供：

- 根面板上的 `role="dialog"` 和 `aria-label="Search and replace"`，结果计数器会通过 `aria-live="polite"` 播报。
- 根面板上的 `data-open="true|false"`。
- 操作按钮和正则表达式文档链接上的 `data-search-replace-action="prev|next|close|replace|replace-all|regex-docs"`。
- 输入框上的 `data-field="search-query|replace-query"`。
- 匹配控件上的 `data-option="match-case|whole-words|use-regex"`。
- 每个可将正则表达式示例填入输入框的按钮上的 `data-regex-example="<pattern>"`。

结果高亮选择器为 `.find-and-replace-result` 和 `.find-and-replace-result-current`。如果要覆盖这些样式，请在扩展上保留 `injectCSS: false`，确保只有一个高亮样式表控制结果。

## 要求

### 依赖项

- `@tiptap/react` - Tiptap React 核心集成
- `@tiptap/extension-find-and-replace` - 搜索状态、匹配、导航和替换命令
- `@tiptap/starter-kit` - 已安装示例使用的基础编辑器扩展
- `react-hotkeys-hook` - 键盘快捷键处理

### 可选依赖项

- `sass` - SCSS 样式支持
- `sass-embedded` - 选择嵌入式实现的项目所用的 Sass 编译器

### 引用的组件

- `use-tiptap-editor` 和 `use-composed-ref` hooks
- `tiptap-utils`
- `button`、`button-group`、`card`、`input-group`、`separator` 和 `switch` 基元
- `search-icon`、`arrow-right-icon`、`external-link-icon`、`chevron-up-icon`、`chevron-down-icon`、`close-icon`、`case-sensitive-icon` 和 `whole-word-icon`
- `styles` 共享样式基础

`button` 基元还会安装其 `check` 变体所用的 `check-icon`。

有关与框架无关的命令和存储示例，请参阅[自定义 Find and Replace UI 指南](/guides/find-and-replace)。
