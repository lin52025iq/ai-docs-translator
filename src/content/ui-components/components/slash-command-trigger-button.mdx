一款完全支持无障碍访问的 Tiptap 编辑器斜杠命令触发按钮。轻松插入斜杠命令触发符，以打开块级命令菜单，并支持键盘快捷键和灵活的自定义选项。

## 安装

通过 Tiptap CLI 添加此组件：

```bash
npx @tiptap/cli@latest add slash-command-trigger-button
```

## 组件

### `<SlashCommandTriggerButton />`

一个预构建的 React 组件，可在编辑器中插入斜杠命令触发符。

#### 用法

```tsx
<SlashCommandTriggerButton
  editor={editor}
  text="Insert Block"
  trigger="/"
  hideWhenUnavailable={true}
  showShortcut={true}
  onTriggered={(trigger) => console.log('Inserted:', trigger)}
/>
```

#### 属性

| 名称                  | 类型                        | 默认值      | 说明                                              |
| --------------------- | --------------------------- | ----------- | ------------------------------------------------- |
| `editor`              | `Editor \| null`            | `undefined` | Tiptap 编辑器实例                                 |
| `node`                | `Node \| null`              | `undefined` | 要应用触发符的节点                                |
| `nodePos`             | `number \| null`            | `undefined` | 节点在文档中的位置                                |
| `text`                | `string`                    | `undefined` | 按钮的可选文本标签                                |
| `trigger`             | `string`                    | `"/"`       | 要插入的触发符文本                                |
| `hideWhenUnavailable` | `boolean`                   | `false`     | 无法插入触发符时隐藏按钮                          |
| `onTriggered`         | `(trigger: string) => void` | `undefined` | 成功插入触发符后调用的回调                        |
| `showShortcut`        | `boolean`                   | `false`     | 显示键盘快捷键标记（如果有）                      |

## Hooks

### `useSlashCommandTrigger()`

自定义 Hook，可让你完全控制渲染和行为，从而构建自己的斜杠命令触发按钮。

#### 用法

```tsx
function MySlashCommandButton() {
  const { isVisible, canInsert, handleSlashCommand, label, shortcutKeys, trigger, Icon } =
    useSlashCommandTrigger({
      editor: myEditor,
      trigger: '/',
      hideWhenUnavailable: true,
      onTriggered: (trigger) => console.log('Inserted:', trigger),
    })

  if (!isVisible) return null

  return (
    <button onClick={handleSlashCommand} disabled={!canInsert} aria-label={label}>
      <Icon />
      {label}
      {shortcutKeys && <Badge>{parseShortcutKeys({ shortcutKeys })}</Badge>}
    </button>
  )
}
```

#### 属性

| 名称                  | 类型                        | 默认值      | 说明                                              |
| --------------------- | --------------------------- | ----------- | ------------------------------------------------- |
| `editor`              | `Editor \| null`            | `undefined` | Tiptap 编辑器实例                                 |
| `node`                | `Node \| null`              | `undefined` | 要应用触发符的节点                                |
| `nodePos`             | `number \| null`            | `undefined` | 节点在文档中的位置                                |
| `trigger`             | `string`                    | `"/"`       | 要插入的触发符文本                                |
| `hideWhenUnavailable` | `boolean`                   | `false`     | 无法插入触发符时隐藏按钮                          |
| `onTriggered`         | `(trigger: string) => void` | `undefined` | 成功插入触发符后调用的回调                        |

#### 返回值

| 名称                 | 类型            | 说明                                      |
| -------------------- | --------------- | ----------------------------------------- |
| `isVisible`          | `boolean`       | 按钮是否应当渲染                            |
| `canInsert`          | `boolean`       | 当前是否允许插入触发符                      |
| `handleSlashCommand` | `() => boolean` | 插入斜杠命令触发符的函数                    |
| `label`              | `string`        | 按钮的无障碍标签文本                        |
| `shortcutKeys`       | `string`        | 键盘快捷键（Cmd/Ctrl + /）                 |
| `trigger`            | `string`        | 将要插入的触发符文本                        |
| `Icon`               | `React.FC`      | 斜杠命令按钮的图标组件                      |

## 实用工具

### `canInsertSlashCommand(editor, node?, nodePos?)`

检查当前编辑器状态或指定位置是否可以插入斜杠命令触发符。

```tsx
import { canInsertSlashCommand } from '@/components/tiptap-ui/slash-command-trigger-button'

const canInsert = canInsertSlashCommand(editor) // Check current position
const canInsertAtNode = canInsertSlashCommand(editor, node, nodePos) // Check specific position
```

### `insertSlashCommand(editor, trigger?, node?, nodePos?)`

以编程方式在编辑器中插入斜杠命令触发符。

```tsx
import { insertSlashCommand } from '@/components/tiptap-ui/slash-command-trigger-button'

// Insert at current position
const success = insertSlashCommand(editor, '/')

// Insert at specific node/position
const success2 = insertSlashCommand(editor, '+', node, nodePos)

// Insert with custom trigger
const success3 = insertSlashCommand(editor, '\\')

if (success) {
  console.log('Slash command trigger inserted successfully!')
}
```

## 键盘快捷键

斜杠命令触发按钮支持以下键盘快捷键：

- **Cmd/Ctrl + /**：插入斜杠命令触发符

使用 `<SlashCommandTriggerButton />` 组件或 `useSlashCommandTrigger()` Hook 时，系统会自动注册此快捷键。
