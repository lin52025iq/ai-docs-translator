为 Tiptap 编辑器提供完全无障碍支持的标题按钮。可在不同标题级别和段落文本之间切换，并支持键盘快捷键、各级别专属图标和工具提示集成。

<CodeDemo isScrollable src="https://template.tiptap.dev/preview/tiptap-ui/heading-button" />

## 安装

通过 Tiptap CLI 添加此组件：

```bash
npx @tiptap/cli@latest add heading-button
```

## 组件

### `<HeadingButton />`

预构建的 React 组件，可在编辑器中切换标题级别，并提供完整的无障碍支持。

#### 用法

```tsx
import { HeadingButton } from '@/components/tiptap-ui/heading-button'
import { EditorContent, EditorContext, useEditor } from '@tiptap/react'
import { StarterKit } from '@tiptap/starter-kit'

import '@/components/tiptap-node/paragraph-node/paragraph-node.scss'

export default function MyEditor() {
  const editor = useEditor({
    immediatelyRender: false,
    extensions: [StarterKit],
    content: `
          <h1>Heading 1</h1>
          <h2>Heading 2</h2>
        `,
  })

  return (
    <EditorContext.Provider value={{ editor }}>
      <HeadingButton
        editor={editor}
        level={1}
        text="Heading 1"
        hideWhenUnavailable={true}
        showShortcut={true}
        onToggled={() => console.log(`Heading ${level} toggled!`)}
      />
      <HeadingButton
        editor={editor}
        level={2}
        text="Heading 2"
        hideWhenUnavailable={true}
        showShortcut={true}
        onToggled={() => console.log(`Heading ${level} toggled!`)}
      />

      <EditorContent editor={editor} role="presentation" />
    </EditorContext.Provider>
  )
}
```

#### 属性

| 名称                  | 类型             | 默认值      | 说明                               |
| --------------------- | ---------------- | ----------- | ---------------------------------- |
| `editor`              | `Editor \| null` | `undefined` | Tiptap 编辑器实例                  |
| `level`               | `Level` (1-6)    | `required`  | 标题级别（1、2、3、4、5 或 6）     |
| `text`                | `string`         | `undefined` | 可选的按钮文本标签                 |
| `hideWhenUnavailable` | `boolean`        | `false`     | 标题不适用时隐藏按钮               |
| `onToggled`           | `() => void`     | `undefined` | 成功切换标题后触发的回调           |
| `showShortcut`        | `boolean`        | `false`     | 显示键盘快捷键徽标                 |

## Hook

### `useHeading()`

自定义 Hook，可完全掌控渲染和行为，用于构建自己的标题按钮。

#### 用法

```tsx
function MyHeadingButton() {
  const { isVisible, isActive, canToggle, handleToggle, label, shortcutKeys, Icon } = useHeading({
    editor: myEditor,
    level: 3,
    hideWhenUnavailable: true,
    onToggled: () => console.log('Heading 3 toggled!'),
  })

  if (!isVisible) return null

  return (
    <button onClick={handleToggle} disabled={!canToggle} aria-label={label} aria-pressed={isActive}>
      <Icon />
      {label}
      {shortcutKeys && <HeadingShortcutBadge level={3} shortcutKeys={shortcutKeys} />}
    </button>
  )
}
```

#### 属性

| 名称                  | 类型             | 默认值      | 说明                             |
| --------------------- | ---------------- | ----------- | -------------------------------- |
| `editor`              | `Editor \| null` | `undefined` | Tiptap 编辑器实例                |
| `level`               | `Level` (1-6)    | `required`  | 标题级别                         |
| `hideWhenUnavailable` | `boolean`        | `false`     | 标题无法应用时隐藏按钮           |
| `onToggled`           | `() => void`     | `undefined` | 切换标题后触发的回调             |

#### 返回值

| 名称           | 类型            | 说明                             |
| -------------- | --------------- | -------------------------------- |
| `isVisible`    | `boolean`       | 是否应渲染按钮                   |
| `isActive`     | `boolean`       | 当前标题级别是否处于激活状态     |
| `canToggle`    | `boolean`       | 是否可以切换标题                 |
| `handleToggle` | `() => boolean` | 切换标题格式的函数               |
| `label`        | `string`        | 按钮的无障碍标签文本             |
| `shortcutKeys` | `string`        | 对应级别的键盘快捷键             |
| `Icon`         | `React.FC`      | 对应标题级别的图标组件           |

## 工具函数

### `canToggle(editor, level?, turnInto?)`

检查当前编辑器状态下是否可以切换标题。

```tsx
import { canToggle } from '@/components/tiptap-ui/heading-button'

const canToggleH2 = canToggle(editor, 2) // Check if can toggle to Heading 2
const canTurnInto = canToggle(editor, 1, true) // Check if can turn into Heading 1
```

### `isHeadingActive(editor, level?)`

检查指定标题级别当前是否处于激活状态。

```tsx
import { isHeadingActive } from '@/components/tiptap-ui/heading-button'

const isH1Active = isHeadingActive(editor, 1) // Check if Heading 1 is active
const isAnyHeadingActive = isHeadingActive(editor) // Check if any heading is active
```

### `toggleHeading(editor, level)`

以编程方式切换当前选区的标题格式。

```tsx
import { toggleHeading } from '@/components/tiptap-ui/heading-button'

const success = toggleHeading(editor, 3) // Toggle Heading 3
if (success) {
  console.log('Heading toggled successfully!')
}
```

## 键盘快捷键

标题按钮支持按级别区分且会自动注册的键盘快捷键：

- **Ctrl + Alt + 1**：切换标题 1
- **Ctrl + Alt + 2**：切换标题 2
- **Ctrl + Alt + 3**：切换标题 3
- **Ctrl + Alt + 4**：切换标题 4
- **Ctrl + Alt + 5**：切换标题 5
- **Ctrl + Alt + 6**：切换标题 6

使用 `<HeadingButton />` 组件或 `useHeading()` Hook 时，都会自动注册这些快捷键。每个标题级别都有各自专属的快捷键。

- `badge`（基础组件）
- `tiptap-utils`（库）
