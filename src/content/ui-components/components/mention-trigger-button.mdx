适用于 Tiptap 编辑器的完全无障碍提及触发按钮。轻松插入 `"@"` 等提及触发字符，以启用提及功能，并支持键盘快捷键和灵活的自定义选项。

<CodeDemo isScrollable src="https://template.tiptap.dev/preview/tiptap-ui/mention-trigger-button" />

## 安装

通过 Tiptap CLI 添加组件：

```bash
npx @tiptap/cli@latest add mention-trigger-button
```

## 组件

### `<MentionTriggerButton />`

一个预构建的 React 组件，可在编辑器中插入提及触发字符。

#### 用法

```tsx
function MyMentionTriggerButton() {
  return (
    <MentionTriggerButton
      editor={editor}
      text="Mention"
      trigger="@"
      hideWhenUnavailable={true}
      showShortcut={true}
      onTriggered={(trigger) => console.log('Inserted:', trigger)}
    />
  )
}
```

#### 属性

| 名称                  | 类型                        | 默认值      | 说明                                             |
| --------------------- | --------------------------- | ----------- | ------------------------------------------------ |
| `editor`              | `Editor \| null`            | `undefined` | Tiptap 编辑器实例                                |
| `node`                | `Node \| null`              | `undefined` | 要应用触发字符的节点                             |
| `nodePos`             | `number \| null`            | `undefined` | 节点在文档中的位置                               |
| `text`                | `string`                    | `undefined` | 按钮的可选文本标签                               |
| `trigger`             | `string`                    | `"@"`       | 要插入的触发文本                                 |
| `hideWhenUnavailable` | `boolean`                   | `false`     | 无法插入触发字符时隐藏按钮                       |
| `onTriggered`         | `(trigger: string) => void` | `undefined` | 成功插入触发字符后调用的回调                     |
| `showShortcut`        | `boolean`                   | `false`     | 显示键盘快捷键标记（如果有）                     |

## Hook

### `useMentionTrigger()`

自定义 Hook，可完全控制渲染和行为，帮助你构建自己的提及触发按钮。

#### 用法

```tsx
function MyMentionTriggerButton() {
  const { isVisible, canInsert, handleMention, label, shortcutKeys, trigger, Icon } =
    useMentionTrigger({
      editor: myEditor,
      trigger: '@',
      hideWhenUnavailable: true,
      onTriggered: (trigger) => console.log('Inserted:', trigger),
    })

  if (!isVisible) return null

  return (
    <button onClick={handleMention} disabled={!canInsert} aria-label={label}>
      <Icon />
      {label}
      {shortcutKeys && <Badge>{parseShortcutKeys({ shortcutKeys })}</Badge>}
    </button>
  )
}
```

#### 属性

| 名称                  | 类型                        | 默认值      | 说明                                             |
| --------------------- | --------------------------- | ----------- | ------------------------------------------------ |
| `editor`              | `Editor \| null`            | `undefined` | Tiptap 编辑器实例                                |
| `node`                | `Node \| null`              | `undefined` | 要应用触发字符的节点                             |
| `nodePos`             | `number \| null`            | `undefined` | 节点在文档中的位置                               |
| `trigger`             | `string`                    | `"@"`       | 要插入的触发文本                                 |
| `hideWhenUnavailable` | `boolean`                   | `false`     | 无法插入触发字符时隐藏按钮                       |
| `onTriggered`         | `(trigger: string) => void` | `undefined` | 成功插入触发字符后调用的回调                     |

#### 返回值

| 名称            | 类型            | 说明                                 |
| --------------- | --------------- | ------------------------------------ |
| `isVisible`     | `boolean`       | 按钮是否应渲染                       |
| `canInsert`     | `boolean`       | 当前是否允许插入触发字符             |
| `handleMention` | `() => boolean` | 插入提及触发字符的函数               |
| `label`         | `string`        | 按钮的无障碍标签文本                 |
| `shortcutKeys`  | `string`        | 键盘快捷键（Cmd/Ctrl + Shift + 2）   |
| `trigger`       | `string`        | 将要插入的触发文本                   |
| `Icon`          | `React.FC`      | 提及触发按钮的图标组件               |

## 工具函数

### `canInsertMention(editor, node?, nodePos?)`

检查当前编辑器状态或指定位置是否可以插入提及触发字符。

```tsx
import { canInsertMention } from '@/components/tiptap-ui/mention-trigger-button'

const canInsert = canInsertMention(editor) // Check current position
const canInsertAtNode = canInsertMention(editor, node, nodePos) // Check specific position
```

### `addMentionTrigger(editor, trigger?, node?, nodePos?)`

以编程方式在编辑器中插入提及触发字符。

```tsx
import { addMentionTrigger } from '@/components/tiptap-ui/mention-trigger-button'

// Insert at current position
const success = addMentionTrigger(editor, '@')

// Insert at specific node/position
const success2 = addMentionTrigger(editor, '#', node, nodePos)

// Insert with custom trigger
const success3 = addMentionTrigger(editor, '/')

if (success) {
  console.log('Mention trigger inserted successfully!')
}
```

## 键盘快捷键

提及触发按钮支持以下键盘快捷键：

- **Cmd/Ctrl + Shift + 2**：插入提及触发字符

使用 `<MentionTriggerButton />` 组件或 `useMentionTrigger()` Hook 时，系统会自动注册此快捷键。
