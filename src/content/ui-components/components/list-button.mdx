适用于 Tiptap 编辑器的无障碍列表按钮。轻松在项目符号列表、有序列表和任务列表之间切换，并支持键盘快捷键和灵活的自定义选项。

<CodeDemo isScrollable src="https://template.tiptap.dev/preview/tiptap-ui/list-button" />

## 安装

通过 Tiptap CLI 添加此组件：

```bash
npx @tiptap/cli@latest add list-button
```

## 组件

### `<ListButton />`

预构建的 React 组件，可切换指定类型的列表格式。

#### 用法

```tsx
export default function MyEditor() {
  return (
    <ListButton
      editor={editor}
      type="bulletList"
      text="Bullet List"
      hideWhenUnavailable={true}
      showShortcut={true}
      onToggled={() => console.log('List toggled!')}
    />
  )
}
```

#### 属性

| 名称                  | 类型             | 默认值      | 说明                                                           |
| --------------------- | ---------------- | ----------- | -------------------------------------------------------------- |
| `editor`              | `Editor \| null` | `undefined` | Tiptap 编辑器实例                                              |
| `type`                | `ListType`       | `required`  | 列表类型（`"bulletList"`、`"orderedList"`、`"taskList"`）   |
| `text`                | `string`         | `undefined` | 按钮的可选文本标签                                             |
| `hideWhenUnavailable` | `boolean`        | `false`     | 无法切换列表时隐藏按钮                                         |
| `onToggled`           | `() => void`     | `undefined` | 成功切换列表后触发的回调                                       |
| `showShortcut`        | `boolean`        | `false`     | 显示键盘快捷键徽标（如果有）                                   |

## Hooks

### `useList()`

自定义 Hook，可完全掌控渲染方式和行为，从而构建自己的列表按钮。

#### 用法

```tsx
function MyListButton() {
  const { isVisible, isActive, canToggle, handleToggle, label, shortcutKeys, Icon } = useList({
    editor: myEditor,
    type: 'bulletList',
    hideWhenUnavailable: true,
    onToggled: () => console.log('List toggled!'),
  })

  if (!isVisible) return null

  return (
    <button onClick={handleToggle} disabled={!canToggle} aria-label={label} aria-pressed={isActive}>
      <Icon />
      {label}
      {shortcutKeys && <Badge>{parseShortcutKeys({ shortcutKeys })}</Badge>}
    </button>
  )
}
```

#### 属性

| 名称                  | 类型             | 默认值      | 说明                                           |
| --------------------- | ---------------- | ----------- | ---------------------------------------------- |
| `editor`              | `Editor \| null` | `undefined` | Tiptap 编辑器实例                              |
| `type`                | `ListType`       | `required`  | 要切换的列表类型                               |
| `hideWhenUnavailable` | `boolean`        | `false`     | 无法切换列表时隐藏按钮                         |
| `onToggled`           | `() => void`     | `undefined` | 成功切换列表后触发的回调                       |

#### 返回值

| 名称           | 类型            | 说明                                           |
| -------------- | --------------- | ---------------------------------------------- |
| `isVisible`    | `boolean`       | 是否应渲染该按钮                               |
| `isActive`     | `boolean`       | 指定类型的列表当前是否处于激活状态             |
| `canToggle`    | `boolean`       | 当前是否允许切换列表                           |
| `handleToggle` | `() => boolean` | 用于切换列表格式的函数                         |
| `label`        | `string`        | 按钮的无障碍标签文本                           |
| `shortcutKeys` | `string`        | 指定列表类型对应的键盘快捷键                   |
| `Icon`         | `React.FC`      | 列表按钮的图标组件                             |

## 实用工具

### `canToggleList(editor, type, turnInto?)`

检查当前编辑器状态下是否可以切换为指定类型的列表。

```tsx
import { canToggleList } from '@/components/tiptap-ui/list-button'

const canToggle = canToggleList(editor, 'bulletList') // Check if can toggle
const canTurnInto = canToggleList(editor, 'bulletList', true) // Check if can turn into bullet list
```

### `toggleList(editor, type)`

以编程方式切换为指定类型的列表格式。

```tsx
import { toggleList } from '@/components/tiptap-ui/list-button'

const success = toggleList(editor, 'orderedList')
if (success) {
  console.log('Ordered list toggled successfully!')
}
```

### `isListActive(editor, type)`

检查指定类型的列表当前是否处于激活状态。

```tsx
import { isListActive } from '@/components/tiptap-ui/list-button'

const active = isListActive(editor, 'taskList')
```

### `listLabels`、`listIcons` 和 `LIST_SHORTCUT_KEYS`

按列表类型提供的查找映射，可用于构建自定义列表控件。每个映射都以 `ListType` 为键。

```tsx
import { LIST_SHORTCUT_KEYS, listIcons, listLabels } from '@/components/tiptap-ui/list-button'

const Icon = listIcons.bulletList // ListIcon
const label = listLabels.bulletList // "Bullet List"
const shortcut = LIST_SHORTCUT_KEYS.bulletList // "mod+shift+8"
```

## 键盘快捷键

每种列表类型都有自己的键盘快捷键：

- **Cmd/Ctrl + Shift + 8**：切换项目符号列表
- **Cmd/Ctrl + Shift + 7**：切换有序列表
- **Cmd/Ctrl + Shift + 9**：切换任务列表

使用 `<ListButton />` 组件或 `useList()` Hook 时，快捷键会自动注册。
