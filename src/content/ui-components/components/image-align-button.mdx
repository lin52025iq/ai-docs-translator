这是一款完全支持无障碍功能的 Tiptap 编辑器图片对齐按钮。可通过左对齐、居中和右对齐选项控制图片位置，并支持键盘快捷键和智能图片检测。

<CodeDemo isScrollable src="https://template.tiptap.dev/preview/tiptap-ui/image-align-button" />

## 安装

通过 Tiptap CLI 添加此组件：

```bash
npx @tiptap/cli@latest add image-align-button
```

## 组件

### `<ImageAlignButton />`

一个预构建的 React 组件，用于控制编辑器中的图片对齐方式。

#### 用法

```tsx
export default function MyEditor() {
  return (
    <div>
      <ImageAlignButton
        editor={editor}
        align="left"
        text="Align Left"
        hideWhenUnavailable={true}
        showShortcut={true}
        onAligned={() => console.log('Image aligned!')}
      />
      <ImageAlignButton
        editor={editor}
        align="center"
        text="Align Center"
        hideWhenUnavailable={true}
        showShortcut={true}
      />
      <ImageAlignButton
        editor={editor}
        align="right"
        text="Align Right"
        hideWhenUnavailable={true}
        showShortcut={true}
      />
    </div>
  )
}
```

#### 属性

| 名称                  | 类型                            | 默认值         | 说明                                         |
| --------------------- | ------------------------------- | -------------- | -------------------------------------------- |
| `editor`              | `Editor \| null`                | `undefined`    | Tiptap 编辑器实例                            |
| `align`               | `'left' \| 'center' \| 'right'` | `undefined`    | 要应用的对齐方向                             |
| `text`                | `string`                        | `undefined`    | 按钮的可选文本标签                           |
| `extensionName`       | `string`                        | `'image'`      | 要定位的图片扩展名称                         |
| `attributeName`       | `string`                        | `'data-align'` | 用于对齐的属性名称                           |
| `hideWhenUnavailable` | `boolean`                       | `false`        | 无法进行对齐时隐藏按钮                       |
| `onAligned`           | `() => void`                    | `undefined`    | 对齐成功后触发的回调                         |
| `showShortcut`        | `boolean`                       | `false`        | 显示键盘快捷键标记                           |

## Hooks

### `useImageAlign()`

一个自定义 Hook，可让你完全控制渲染方式和行为，从而构建自己的图片对齐按钮。

#### 用法

```tsx
function MyImageAlignButton({ align }: { align: 'left' | 'center' | 'right' }) {
  const { isVisible, handleImageAlign, canAlign, isActive, label, shortcutKeys, Icon } =
    useImageAlign({
      editor: myEditor,
      align,
      hideWhenUnavailable: true,
      onAligned: () => console.log(`Image aligned to ${align}!`),
    })

  if (!isVisible) return null

  return (
    <button
      onClick={handleImageAlign}
      disabled={!canAlign}
      data-active={isActive}
      aria-label={label}
      aria-pressed={isActive}
    >
      <Icon />
      {label}
      {shortcutKeys && <Badge>{parseShortcutKeys({ shortcutKeys })}</Badge>}
    </button>
  )
}
```

#### 属性

| 名称                  | 类型                            | 默认值         | 说明                                         |
| --------------------- | ------------------------------- | -------------- | -------------------------------------------- |
| `editor`              | `Editor \| null`                | `undefined`    | Tiptap 编辑器实例                            |
| `align`               | `'left' \| 'center' \| 'right'` | `undefined`    | 要应用的对齐方向                             |
| `extensionName`       | `string`                        | `'image'`      | 要定位的图片扩展名称                         |
| `attributeName`       | `string`                        | `'data-align'` | 用于对齐的属性名称                           |
| `hideWhenUnavailable` | `boolean`                       | `false`        | 无法进行对齐时隐藏按钮                       |
| `onAligned`           | `() => void`                    | `undefined`    | 对齐成功后触发的回调                         |

#### 返回值

| 名称               | 类型            | 说明                                                   |
| ------------------ | --------------- | ------------------------------------------------------ |
| `isVisible`        | `boolean`       | 是否应渲染该按钮                                       |
| `canAlign`         | `boolean`       | 是否可以对当前节点应用图片对齐                         |
| `isActive`         | `boolean`       | 当前对齐方式是否处于激活状态                           |
| `handleImageAlign` | `() => boolean` | 应用图片对齐方式的函数                                 |
| `label`            | `string`        | 按钮的无障碍标签文本                                   |
| `shortcutKeys`     | `string`        | 此对齐方式对应的键盘快捷键                             |
| `Icon`             | `React.FC`      | 对齐按钮的图标组件                                     |

## 工具函数

### `canSetImageAlign(editor, align, extensionName, attributeName)`

检查当前编辑器状态下是否可以进行图片对齐。

```tsx
import { canSetImageAlign } from '@/components/tiptap-ui/image-align-button'

const canAlign = canSetImageAlign(editor, 'center', 'image', 'data-align')
```

### `isImageAlignActive(editor, align, extensionName, attributeName)`

检查指定的图片对齐方式当前是否处于激活状态。

```tsx
import { isImageAlignActive } from '@/components/tiptap-ui/image-align-button'

const isActive = isImageAlignActive(editor, 'left', 'image', 'data-align')
```

### `setImageAlign(editor, align, extensionName, attributeName)`

以编程方式设置编辑器中的图片对齐方式。

```tsx
import { setImageAlign } from '@/components/tiptap-ui/image-align-button'

const success = setImageAlign(editor, 'right', 'image', 'data-align')
if (success) {
  console.log('Image alignment applied successfully!')
}
```

### `shouldShowButton(props)`

根据编辑器状态和配置，判断是否应显示图片对齐按钮。

```tsx
import { shouldShowButton } from '@/components/tiptap-ui/image-align-button'

const shouldShow = shouldShowButton({
  editor,
  align: 'center',
  hideWhenUnavailable: true,
  extensionName: 'image',
  attributeName: 'data-align',
})
```

### `<ImageAlignShortcutBadge />`

一个辅助组件，可在自定义按钮中显示键盘快捷键。

```tsx
import { ImageAlignShortcutBadge } from '@/components/tiptap-ui/image-align-button'
;<ImageAlignShortcutBadge align="center" />
```

## 键盘快捷键

图片对齐按钮支持以下键盘快捷键：

- **Alt + Shift + L**：将图片左对齐
- **Alt + Shift + E**：将图片居中对齐
- **Alt + Shift + R**：将图片右对齐

使用 `<ImageAlignButton />` 组件或 `useImageAlign()` Hook 时，都会自动注册这些快捷键。选中编辑器中的图片节点后即可使用快捷键。

## 对齐选项

### 左对齐

将图片对齐到内容区域的左侧。

```tsx
<ImageAlignButton editor={editor} align="left" />
```

### 居中对齐

将图片在内容区域内水平居中。

```tsx
<ImageAlignButton editor={editor} align="center" />
```

### 右对齐

将图片对齐到内容区域的右侧。

```tsx
<ImageAlignButton editor={editor} align="right" />
```

## 工作原理

图片对齐功能的工作方式如下：

1. **节点检测**：自动检测编辑器中是否选中了图片节点
2. **属性管理**：更新图片节点上的指定属性（默认为 `data-align`）
3. **状态跟踪**：监控当前对齐状态并更新按钮的激活状态
4. **无障碍支持**：为每种对齐选项提供恰当的 ARIA 标签和键盘快捷键
5. **扩展集成**：适用于所有支持自定义属性的 Tiptap 图片扩展

对齐操作通过更新图片节点的属性来实现，之后可使用 CSS 设置样式：

```css
img[data-align='left'] {
  text-align: left;
}

img[data-align='center'] {
  text-align: center;
}

img[data-align='right'] {
  text-align: right;
}
```

## 自定义扩展支持

此组件支持自定义图片扩展，你可以指定扩展名称：

```tsx
<ImageAlignButton
  editor={editor}
  align="center"
  extensionName="myCustomImage"
  attributeName="alignment"
/>
```

这种灵活性使你可以将对齐按钮用于：

- 自定义图片扩展
- 具备额外功能的扩展图片节点
- 使用不同属性命名约定的扩展

## 要求

### 依赖项

- `@tiptap/react` - Tiptap React 核心集成
- `react-hotkeys-hook` - 键盘快捷键管理

### 引用的组件

- `use-tiptap-editor`（Hook）
- `use-mobile`（Hook）
- `button`（基础组件）
- `badge`（基础组件）
- `tiptap-utils`（库）
- `align-center-vertical-icon`（图标）
- `align-start-vertical-icon`（图标）
- `align-end-vertical-icon`（图标）

### 所需扩展

此组件适用于所有支持自定义属性的 Tiptap 图片扩展。最常见的配置使用：

- `@tiptap/extension-image` - Tiptap 标准图片扩展
- 支持属性的自定义图片扩展

扩展应配置为接受对齐属性：

```tsx
import { Image } from '@tiptap/extension-image'

const editor = useEditor({
  extensions: [
    Image.configure({
      HTMLAttributes: {
        class: 'editor-image',
      },
    }),
  ],
})
```
