这是一款完全支持无障碍访问的 Tiptap 编辑器文本颜色按钮。可为选中的文本应用前景色，并支持键盘快捷键和灵活的自定义选项。

## 安装

通过 Tiptap CLI 添加此组件：

```bash
npx @tiptap/cli@latest add color-text-button
```

## 组件

### `<ColorTextButton />`

一个预构建的 React 组件，可为选中的文本应用文本颜色。

#### 用法

```tsx
export default function MyEditor() {
  return (
    <ColorTextButton
      editor={editor}
      textColor="var(--tt-color-text-blue)"
      text="Blue Text"
      hideWhenUnavailable={true}
      showShortcut={true}
      onApplied={({ color, label }) => console.log(`Applied ${label} text color: ${color}`)}
    />
  )
}
```

#### 属性

| 名称                  | 类型                         | 默认值      | 说明                                             |
| --------------------- | ---------------------------- | ----------- | ------------------------------------------------ |
| `editor`              | `Editor \| null`             | `undefined` | Tiptap 编辑器实例                                |
| `textColor`           | `string`                     | `required`  | 要应用的文本颜色（CSS 颜色值）                   |
| `text`                | `string`                     | `undefined` | 按钮的可选文本标签                               |
| `hideWhenUnavailable` | `boolean`                    | `false`     | 不适用文本颜色时隐藏按钮                         |
| `onApplied`           | `({ color, label }) => void` | `undefined` | 应用文本颜色后触发的回调                         |
| `showShortcut`        | `boolean`                    | `false`     | 显示键盘快捷键徽标（如果有）                     |

## Hooks

### `useColorText(config)`

自定义 Hook，可用于构建自己的文本颜色按钮，并完全掌控其渲染方式和行为。

#### 用法

```tsx
function MyColorTextButton() {
  const { isVisible, isActive, canColorText, handleColorText, label, shortcutKeys, Icon } =
    useColorText({
      editor: myEditor,
      textColor: 'var(--tt-color-text-red)',
      label: 'Red Text',
      hideWhenUnavailable: true,
      onApplied: ({ color, label }) => console.log(`Applied: ${label}`),
    })

  if (!isVisible) return null

  return (
    <button
      onClick={handleColorText}
      disabled={!canColorText}
      aria-label={label}
      aria-pressed={isActive}
      style={{ color: isActive ? textColor : 'inherit' }}
    >
      <Icon />
      {label}
      {shortcutKeys && <Badge>{parseShortcutKeys({ shortcutKeys })}</Badge>}
    </button>
  )
}
```

#### 属性

| 名称                  | 类型                         | 默认值      | 说明                                           |
| --------------------- | ---------------------------- | ----------- | ---------------------------------------------- |
| `editor`              | `Editor \| null`             | `undefined` | Tiptap 编辑器实例                              |
| `textColor`           | `string`                     | `required`  | 要应用的文本颜色                               |
| `label`               | `string`                     | `required`  | 按钮的无障碍标签                               |
| `hideWhenUnavailable` | `boolean`                    | `false`     | 无法应用文本颜色时隐藏按钮                     |
| `onApplied`           | `({ color, label }) => void` | `undefined` | 应用文本颜色后触发的回调                       |

#### 返回值

| 名称              | 类型            | 说明                               |
| ----------------- | --------------- | ---------------------------------- |
| `isVisible`       | `boolean`       | 是否应渲染按钮                     |
| `isActive`        | `boolean`       | 当前文本颜色是否处于激活状态       |
| `canColorText`    | `boolean`       | 是否可以应用文本颜色               |
| `handleColorText` | `() => boolean` | 应用文本颜色的函数                 |
| `label`           | `string`        | 按钮的无障碍标签文本               |
| `shortcutKeys`    | `string`        | 键盘快捷键（Cmd/Ctrl + Shift + T） |
| `Icon`            | `React.FC`      | 文本颜色按钮的图标组件             |

## 实用工具

### `canColorText(editor)`

检查当前编辑器状态下是否可以应用文本颜色。

```tsx
import { canColorText } from '@/components/tiptap-ui/color-text-button'

const canApply = canColorText(editor)
```

### `isColorTextActive(editor, color)`

检查选区中是否已启用指定的文本颜色。

```tsx
import { isColorTextActive } from '@/components/tiptap-ui/color-text-button'

const isRedActive = isColorTextActive(editor, 'red')
const isBlueActive = isColorTextActive(editor, 'var(--tt-color-text-blue)')
```

## 键盘快捷键

文本颜色按钮支持以下键盘快捷键：

- **Cmd/Ctrl + Shift + T**：应用文本颜色

使用 `<ColorTextButton />` 组件或 `useColorText()` Hook 时，都会自动注册此快捷键。它会将配置的文本颜色应用到当前选区。
