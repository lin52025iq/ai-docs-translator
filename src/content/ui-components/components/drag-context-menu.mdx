DragContextMenu 提供拖拽手柄和丰富的上下文菜单，可执行块级操作。当你将鼠标悬停在编辑器中的任意块上时，左侧会出现一个拖拽手柄。点击该手柄会打开上下文菜单，其中包含以下选项：

- 将块转换为不同类型（标题、列表、引用块等）
- 应用颜色和高亮
- 复制、创建副本或删除块
- 重置格式
- 使用 AI 助手（如果已启用）
- 下载图片（适用于图片节点）

## 安装

### 第 1 步：设置项目

> 如果你的项目已经使用 Tiptap CLI 完成设置，请跳到[第 2 步：配置路径别名](#step-2-configure-path-aliases)。

如果尚未设置，请运行以下命令初始化新项目：

```bash
npx @tiptap/cli@latest init
```

设置过程中，选择你偏好的框架，并等待安装完成。
当系统询问 **“Would you like to add a template or UI components to your project?”** 时，请选择 **No** ——我们会在接下来的步骤中添加 **DragContextMenu** 组件。

### 第 3 步：安装组件

使用 Tiptap CLI 安装 **DragContextMenu** 组件及其所有依赖项：

```bash
npx @tiptap/cli@latest add drag-context-menu
```

此命令将会：

- 将所有组件文件下载到已配置的组件目录
- 安装 npm 依赖项（`@floating-ui/react`、`@tiptap/extension-drag-handle-react`）
- 安装约 60 个注册表依赖项（钩子、UI 基础组件、图标、按钮等）
- 创建所需的目录结构

**已安装的目录：**

- `{components}/tiptap-ui/drag-context-menu/` — 主组件文件
- `{components}/hooks/` — 自定义钩子（`use-tiptap-editor`、`use-mobile` 等）
- `{components}/tiptap-ui-primitive/` — UI 基础组件（`button`、`menu`、`combobox` 等）
- `{components}/tiptap-icons/` — 图标组件
- `{components}/tiptap-ui/` — 操作按钮组件（`duplicate`、`copy`、`delete` 等）
- `{components}/tiptap-extension/` — 自定义 Tiptap 扩展（`UiState` 等）
- `{components}/lib/` — 工具函数

### 第 6 步：配置编辑器扩展

首先，使用以下最简扩展集即可让 DragContextMenu 正常工作：

```tsx
import { EditorContent, EditorContext, useEditor } from '@tiptap/react'
import { StarterKit } from '@tiptap/starter-kit'
import { Highlight } from '@tiptap/extension-highlight'
import { TextStyle } from '@tiptap/extension-text-style'
import { Color } from '@tiptap/extension-color'

// Custom extensions
import { UiState } from '@/components/tiptap-extension/ui-state-extension'
import { NodeBackground } from '@/components/tiptap-extension/node-background-extension'

// UI components
import { DragContextMenu } from '@/components/tiptap-ui/drag-context-menu'

// Editor styles
import '@/components/tiptap-node/paragraph-node/paragraph-node.scss'
import '@/components/tiptap-node/blockquote-node/blockquote-node.scss'
import '@/components/tiptap-node/code-block-node/code-block-node.scss'
import '@/components/tiptap-node/heading-node/heading-node.scss'
import '@/components/tiptap-node/horizontal-rule-node/horizontal-rule-node.scss'
import '@/components/tiptap-node/list-node/list-node.scss'

// Global styles
import '@/styles/_keyframe-animations.scss'
import '@/styles/_variables.scss'

export default function TiptapEditor() {
  const editor = useEditor({
    immediatelyRender: false,
    extensions: [
      // Base extensions
      StarterKit,

      // Text styling extensions which handle the "Colors" menu
      TextStyle,
      Highlight,
      Color,
      NodeBackground,

      // UI state management (REQUIRED for drag context menu)
      // This was installed automatically by the CLI
      UiState,
    ],
    content: `
      <h1>Welcome to Tiptap</h1>
      <p>Hover over any block to see the drag handle appear on the left.</p>
      <blockquote>
        <p>Click the drag handle to access the context menu.</p>
      </blockquote>
    `,
  })

  return (
    <EditorContext.Provider value={{ editor }}>
      <EditorContent editor={editor} />

      <DragContextMenu />
    </EditorContext.Provider>
  )
}
```

将鼠标悬停在块上时，你应该能看到拖拽手柄；点击手柄即可打开上下文菜单。

### 扩展说明

| 扩展                  | 用途                                                   | 是否必需 |
| --------------------- | ------------------------------------------------------ | -------- |
| `StarterKit`          | 提供基本编辑功能（段落、标题、列表等）                 | 是       |
| `Highlight`           | 启用带颜色的文本高亮                                   | 可选     |
| `TextStyle` + `Color` | 启用文本颜色更改                                       | 可选     |
| `NodeBackground`      | 启用块的背景颜色更改                                   | 可选     |
| `UiState`             | 管理拖拽操作的 UI 状态                                 | 是       |

这些扩展是可选的，但能启用上下文菜单中的特定功能。若未安装相应扩展，这些功能会自动隐藏。

#### Props 参考

| 属性                      | 类型             | 默认值                                  | 说明                                                    |
| ------------------------- | ---------------- | --------------------------------------- | ------------------------------------------------------- |
| `editor`                  | `Editor \| null` | 必填（除非使用 EditorContext）          | 你的 Tiptap 编辑器实例                                  |
| `withSlashCommandTrigger` | `boolean`        | `true`                                  | 在拖拽手柄旁显示斜杠命令按钮                            |
| `mobileBreakpoint`        | `number`         | `768`                                   | 低于该屏幕宽度（像素）时隐藏拖拽手柄                    |

> **注意：** 除非你使用 `EditorContext`（或类似的上下文提供器）来提供编辑器实例，否则必须传入 `editor` 属性。如果上下文可用，则可以省略 `editor` 属性。

## 高级自定义

### 禁用斜杠命令触发按钮

如果你不需要斜杠命令按钮：

```tsx
<DragContextMenu editor={editor} withSlashCommandTrigger={false} />
```

### 自定义移动端断点

调整拖拽手柄在较小屏幕上隐藏的临界宽度：

```tsx
<DragContextMenu
  editor={editor}
  mobileBreakpoint={1024} // Hide on tablets too
/>
```

### 以编程方式控制

你可以通过编辑器命令以编程方式控制拖拽手柄的行为：

```tsx
// Lock drag handle (prevent hiding)
editor.commands.setLockDragHandle(true)
// Hide drag handle
editor.commands.setMeta('hideDragHandle', true)
// Set dragging state
editor.commands.setIsDragging(true)
```

## 功能参考

### 可用的上下文菜单操作

上下文菜单会根据以下因素动态显示操作：

- 当前节点类型
- 可用的扩展
- 编辑器选区
- 内容状态

#### 颜色操作

- **文本颜色**：更改文本颜色（需要 `TextStyle` + `Color` 扩展）
- **高亮**：应用背景高亮（需要 `Highlight` 扩展）

#### 转换操作

将当前块转换为：

- 段落
- 标题 1、2、3
- 项目符号列表
- 编号列表
- 任务列表（需要 `TaskList` + `TaskItem` 扩展）
- 引用块
- 代码块

#### 核心操作

- **复制**：将块内容复制到剪贴板
- **创建副本**：复制当前块
- **复制锚点链接**：复制指向当前块的链接（需要 ID 支持）

#### 格式操作

- **重置格式**：移除所有格式标记

#### 图片操作（适用于图片节点）

- **下载**：下载图片（需要 `Image` 扩展）

#### 删除操作

- **删除**：移除当前块

### 键盘快捷键

上下文菜单支持 Tiptap 的标准键盘快捷键：

- Command/Ctrl + D：创建块的副本
- Command/Ctrl + Shift + C：复制到剪贴板
- Command/Ctrl + Delete/Backspace：删除块
