适用于分页式或画布式编辑器的受控缩放控件。它将缩小/放大步进按钮与百分比触发按钮组合在一起；触发按钮的弹出层提供数字输入框、预设缩放级别，以及可选的“适合页面”操作。

该组件完全**无头且仅负责呈现**——它不保存自身的缩放状态，也**不依赖 Tiptap 编辑器**。缩放值由你管理，并通过 `currentZoom` / `onZoomChange` 传入，因此可以配合任何缩放实现使用。所有控件逻辑都封装在 `useZoomDropdownMenu` Hook 中，内置 UI 只是其中一种渲染方式。

## 安装

使用 Tiptap CLI 添加此组件：

```bash
npx @tiptap/cli@latest add zoom-dropdown-menu
```

## 组件

### `<ZoomDropdownMenu />`

预构建的 React 组件，可渲染步进按钮、百分比触发按钮，以及包含输入框、预设和适合页面选项的弹出层。

#### 用法

```tsx
import { useState } from 'react'
import { ZoomDropdownMenu, type ZoomLevel } from '@/components/tiptap-ui/zoom-dropdown-menu'

export default function MyToolbar() {
  const [zoom, setZoom] = useState<ZoomLevel>(100)

  return (
    <ZoomDropdownMenu currentZoom={zoom} onZoomChange={setZoom} onFitToPage={() => setZoom(100)} />
  )
}
```

#### 属性

组件还会将额外的 `Button` 属性（`type` 除外）转发给百分比触发按钮。

| 名称           | 类型                     | 默认值         | 说明                                                                 |
| -------------- | ------------------------ | -------------- | ------------------------------------------------------------------- |
| `currentZoom`  | `number`                 | `100`          | 当前缩放级别（百分比）。由你控制。                                   |
| `onZoomChange` | `(zoom: number) => void` | `undefined`    | 用户更改缩放级别时，会使用新的缩放级别调用此回调。                   |
| `onFitToPage`  | `() => void`             | `undefined`    | 触发“适合页面”时调用。省略此属性即可隐藏该操作。                     |
| `min`          | `number`                 | `40`           | 可选的最小缩放级别。                                                 |
| `max`          | `number`                 | `200`          | 可选的最大缩放级别。                                                 |
| `presets`      | `readonly number[]`      | `ZOOM_PRESETS` | 选择器中提供的预设级别，也用于增大或减小缩放时的步进。               |

## Hooks

### `useZoomDropdownMenu()`

无头 Hook，可计算缩放 UI 所需的所有内容。当前值由使用者管理（`currentZoom` / `onZoomChange`）；Hook 会计算限制范围后的值、最小值/最大值标记、支持解析并提交的文本字段状态、键盘操作、预设步进，以及适合页面回调。

#### 用法

```tsx
function MyZoomControl(props) {
  const { zoom, zoomIn, zoomOut, isMinZoom, isMaxZoom } = useZoomDropdownMenu(props)

  return (
    <div>
      <button onClick={zoomOut} disabled={isMinZoom}>
        -
      </button>
      <span>{zoom}%</span>
      <button onClick={zoomIn} disabled={isMaxZoom}>
        +
      </button>
    </div>
  )
}
```

#### 属性

| 名称           | 类型                     | 默认值         | 说明                                             |
| -------------- | ------------------------ | -------------- | ----------------------------------------------- |
| `currentZoom`  | `number`                 | `100`          | 当前缩放级别（百分比）。由你控制。               |
| `onZoomChange` | `(zoom: number) => void` | `undefined`    | 缩放级别更改时，会使用新的缩放级别调用此回调。   |
| `onFitToPage`  | `() => void`             | `undefined`    | 触发适合页面操作时调用。省略此属性即可隐藏该操作。|
| `min`          | `number`                 | `40`           | 可选的最小缩放级别。                             |
| `max`          | `number`                 | `200`          | 可选的最大缩放级别。                             |
| `presets`      | `readonly number[]`      | `ZOOM_PRESETS` | 提供的预设级别，也用于步进。                     |

#### 返回值

| 名称                 | 类型                                                 | 说明                                                                    |
| -------------------- | ---------------------------------------------------- | ---------------------------------------------------------------------- |
| `zoom`               | `number`                                             | 限制在有效范围内的当前缩放级别。                                        |
| `min`                | `number`                                             | 实际的最小缩放级别。                                                    |
| `max`                | `number`                                             | 实际的最大缩放级别。                                                    |
| `presets`            | `readonly number[]`                                  | 预设缩放级别。                                                         |
| `isMinZoom`          | `boolean`                                            | 当前缩放级别是否达到或低于 `min`。                                      |
| `isMaxZoom`          | `boolean`                                            | 当前缩放级别是否达到或高于 `max`。                                      |
| `canFitToPage`       | `boolean`                                            | 是否提供适合页面操作（即是否传入 `onFitToPage`）。                      |
| `zoomIn`             | `() => void`                                         | 增大到高于当前缩放级别的下一个预设值。                                  |
| `zoomOut`            | `() => void`                                         | 减小到低于当前缩放级别的下一个预设值。                                  |
| `setZoom`            | `(zoom: number) => void`                             | 设置任意缩放级别（限制在 `min` / `max` 范围内）。                      |
| `inputValue`         | `string`                                             | 百分比文本字段的受控值。                                                |
| `setInputValue`      | `(value: string) => void`                            | 设置文本字段的值。                                                     |
| `commitInput`        | `() => void`                                         | 解析并应用文本字段内容（无效时恢复原值）。绑定到 `onBlur`。              |
| `handleInputKeyDown` | `(e: React.KeyboardEvent<HTMLInputElement>) => void` | 处理文本字段中的 Enter/Escape 按键。绑定到 `onKeyDown`。                |
| `fitToPage`          | `() => void`                                         | 调用使用者提供的适合页面处理函数。                                      |

## 工具函数

组件模块还导出了几个纯辅助函数和常量，可用于构建自定义缩放逻辑。

### `clampZoom(value, min?, max?)`

将缩放值限制在支持的范围内，并四舍五入到最接近的整数。

```tsx
import { clampZoom } from '@/components/tiptap-ui/zoom-dropdown-menu'

clampZoom(87.6) // 88
clampZoom(999) // 200
```

### `parsePercent(input)`

将百分比字符串（例如 `"100%"` 或 `"100"`）解析为数字；输入无效时返回 `null`。

```tsx
import { parsePercent } from '@/components/tiptap-ui/zoom-dropdown-menu'

parsePercent('125%') // 125
parsePercent('abc') // null
```

### `getNextPresetZoom(currentZoom, direction, presets?, min?, max?)`

返回当前缩放级别上方或下方的下一个预设级别。

```tsx
import { getNextPresetZoom } from '@/components/tiptap-ui/zoom-dropdown-menu'

getNextPresetZoom(100, 'up') // 125
getNextPresetZoom(100, 'down') // 90
```

### 常量

- `ZOOM_MIN` (`40`)、`ZOOM_MAX` (`200`)、`ZOOM_DEFAULT` (`100`)
- `ZOOM_PRESETS` — `[40, 50, 75, 90, 100, 125, 150, 175, 200]`
- `ZoomLevel` — 在整个 API 中使用的导出 `number` 类型别名
