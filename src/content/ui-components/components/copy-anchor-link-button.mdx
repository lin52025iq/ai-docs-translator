## 安装

通过 Tiptap CLI 添加此组件：

```bash
npx @tiptap/cli@latest add copy-anchor-link-button
```

## 组件

### `<CopyAnchorLinkButton />`

一个预构建的 React 组件，可复制指向编辑器中节点的锚点链接。

#### 用法

```tsx
export default function MyEditor() {
  return (
    <CopyAnchorLinkButton
      editor={editor}
      text="Copy Link"
      hideWhenUnavailable={true}
      showShortcut={true}
      onCopied={() => console.log('Link copied!')}
      onNodeIdNotFound={(found) => console.log(`Node ID found: ${found}`)}
      onExtractedNodeId={(nodeId) => console.log(`Extracted ID: ${nodeId}`)}
    />
  )
}
```

#### 属性

| 名称                  | 类型                               | 默认值      | 描述                                           |
| --------------------- | ---------------------------------- | ----------- | ---------------------------------------------- |
| `editor`              | `Editor \| null`                   | `undefined` | Tiptap 编辑器实例                              |
| `text`                | `string`                           | `undefined` | 按钮的可选文本标签                             |
| `hideWhenUnavailable` | `boolean`                          | `false`     | 没有可用的节点 ID 时隐藏按钮                   |
| `onCopied`            | `() => void`                       | `undefined` | 成功复制后触发的回调                           |
| `onNodeIdNotFound`    | `(found: boolean) => void`         | `undefined` | 复制操作结束时调用，并传入是否找到节点 ID 的状态 |
| `onExtractedNodeId`   | `(nodeId: string \| null) => void` | `undefined` | 提取节点 ID 后调用                             |
| `showShortcut`        | `boolean`                          | `false`     | 显示键盘快捷键徽标                             |

## Hooks

### `useCopyAnchorLink()`

自定义 Hook，可用于构建自己的锚点链接复制按钮，并全面控制其渲染和行为。

#### 用法

```tsx
function MyCopyAnchorLinkButton() {
  const { isVisible, handleCopyAnchorLink, canCopyAnchorLink, label, shortcutKeys, Icon } =
    useCopyAnchorLink({
      editor: myEditor,
      hideWhenUnavailable: true,
      onCopied: () => console.log('Link copied!'),
      onNodeIdNotFound: (found) => console.log(`Node ID found: ${found}`),
      onExtractedNodeId: (nodeId) => console.log(`Extracted ID: ${nodeId}`),
    })

  if (!isVisible) return null

  return (
    <button onClick={handleCopyAnchorLink} disabled={!canCopyAnchorLink} aria-label={label}>
      <Icon />
      {label}
      {shortcutKeys && <Badge>{parseShortcutKeys({ shortcutKeys })}</Badge>}
    </button>
  )
}
```

#### 属性

| 名称                  | 类型                               | 默认值      | 描述                                           |
| --------------------- | ---------------------------------- | ----------- | ---------------------------------------------- |
| `editor`              | `Editor \| null`                   | `undefined` | Tiptap 编辑器实例                              |
| `hideWhenUnavailable` | `boolean`                          | `false`     | 没有可用的节点 ID 时隐藏按钮                   |
| `onCopied`            | `() => void`                       | `undefined` | 成功复制后触发的回调                           |
| `onNodeIdNotFound`    | `(found: boolean) => void`         | `undefined` | 复制操作结束时调用，并传入是否找到节点 ID 的状态 |
| `onExtractedNodeId`   | `(nodeId: string \| null) => void` | `undefined` | 提取节点 ID 后调用                             |

#### 返回值

| 名称                   | 类型            | 描述                                           |
| ---------------------- | --------------- | ---------------------------------------------- |
| `isVisible`            | `boolean`       | 是否应渲染此按钮                               |
| `canCopyAnchorLink`    | `boolean`       | 是否可以复制当前节点的锚点链接                 |
| `handleCopyAnchorLink` | `() => boolean` | 复制所选节点锚点链接的函数                     |
| `label`                | `string`        | 按钮的无障碍标签文本                           |
| `shortcutKeys`         | `string`        | 复制锚点链接的键盘快捷键                       |
| `Icon`                 | `React.FC`      | 复制按钮的图标组件（LinkIcon）                 |

## 工具函数

### `canCopyAnchorLink(editor)`

检查当前编辑器状态下，节点是否具有可复制的 data-id。

```tsx
import { canCopyAnchorLink } from '@/components/tiptap-ui/copy-anchor-link-button'

const canCopy = canCopyAnchorLink(editor)
```

### `copyNodeId(editor, onExtractedNodeId, onNodeIdNotFound)`

以编程方式提取节点 ID，并将其与完整 URL 一并复制到剪贴板。

```tsx
import { copyNodeId } from '@/components/tiptap-ui/copy-anchor-link-button'

const success = await copyNodeId(
  editor,
  (nodeId) => console.log(`Extracted: ${nodeId}`),
  (found) => console.log(`Found: ${found}`),
)
if (success) {
  console.log('Anchor link copied successfully!')
}
```

### `extractNodeId(node, attributeName)`

从指定节点提取 data-id。

```tsx
import { extractNodeId } from '@/components/tiptap-ui/copy-anchor-link-button'

const nodeId = extractNodeId(node, 'data-id')
```

### `shouldShowButton(props)`

根据编辑器状态和配置，判断是否应显示锚点链接复制按钮的工具函数。

```tsx
import { shouldShowButton } from '@/components/tiptap-ui/copy-anchor-link-button'

const shouldShow = shouldShowButton({
  editor,
  hideWhenUnavailable: true,
})
```

## 键盘快捷键

锚点链接复制按钮支持以下键盘快捷键：

- **Cmd/Ctrl + Ctrl + L**：复制当前节点的锚点链接

使用 `<CopyAnchorLinkButton />` 组件或 `useCopyAnchorLink()` Hook 时，都会自动注册此快捷键。此快捷键适用于任何具有唯一 ID 的块级节点，包括段落、标题、引用块和代码块。

## 工作原理

锚点链接复制功能的工作方式如下：

1. **节点 ID 检测**：自动检测具有唯一 ID 的节点（通常使用 `data-id` 属性）
2. **URL 生成**：将当前页面 URL 与指向节点 ID 的哈希片段组合，生成完整 URL
3. **剪贴板集成**：使用原生剪贴板 API 复制生成的 URL
4. **来源跟踪**：添加 `source=copy_link` 查询参数以用于分析

生成的 URL 格式为：`https://example.com/page?source=copy_link#node-id`

## 要求

### 依赖项

- `@tiptap/react` - Tiptap React 核心集成
- `@tiptap/pm` - ProseMirror 核心功能
- `react-hotkeys-hook` - 键盘快捷键管理

### 引用的组件

- `use-tiptap-editor`（Hook）
- `use-mobile`（Hook）
- `button`（基础组件）
- `badge`（基础组件）
- `tiptap-utils`（库）
- `tiptap-advanced-utils`（库）
- `link-icon`（图标）

### 所需扩展

此组件与 UniqueID 扩展搭配使用效果最佳。该扩展会自动为节点分配唯一标识符，并可配置自定义属性名称（默认为 `data-id`）。
