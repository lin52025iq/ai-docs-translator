用于有序列表的编号样式选择器。它会显示一个用于切换有序列表的 `ListButton`，以及一个编号样式下拉菜单，其中包含十进制、带括号、嵌套十进制、大写/小写字母、大写/小写罗马数字和补零格式；每种格式都以小型嵌套列表预览呈现。

当前格式通过 **`orderedListNumbering` 扩展**（属于 `@tiptap-pro/extension-convert-kit`）读取和应用，因此屏幕上显示的标记始终与已注册的格式一致。所有编辑器逻辑都由 `useNumberingFormatDropdownMenu` hook 提供，你可以基于它构建完全自定义的 UI。

## 安装

通过 Tiptap CLI 添加此组件：

```bash
npx @tiptap/cli@latest add numbering-format-dropdown-menu
```

## 设置

此组件只会在列表上存储格式 **id**；实际标记的呈现由扩展负责。请通过 ConvertKit 配置 `orderedListNumbering`，为你希望提供的每个格式 id 定义一个级别；也可以将相同的定义传递给 `ExportDocx`，以确保往返转换时格式准确保留。

```tsx
import { ConvertKit } from '@tiptap-pro/extension-convert-kit'

const NUMBERING_FORMATS = [
  {
    id: 'decimal',
    levels: Array.from({ length: 9 }, (_v, depth) => ({
      baseStyle: ['decimal', 'lowerLetter', 'lowerRoman'][depth % 3],
      textTemplate: `%${depth + 1}.`,
    })),
  },
  // …one entry per id you offer (see NUMBERING_FORMAT_IDS)
]

const editor = useEditor({
  extensions: [
    ConvertKit.configure({
      orderedListNumbering: {
        formats: NUMBERING_FORMATS,
        defaultFormat: 'decimal',
      },
    }),
    // …
  ],
})
```

## 组件

### `<NumberingFormatDropdownMenu />`

预构建组件，将有序列表切换按钮与编号样式下拉菜单组合在一起。

#### 用法

```tsx
export default function MyEditor() {
  return (
    <NumberingFormatDropdownMenu
      editor={editor}
      hideWhenUnavailable={true}
      modal={false}
      onOpenChange={(isOpen) => console.log('Dropdown', isOpen ? 'opened' : 'closed')}
    />
  )
}
```

#### 属性

此组件还会将所有额外的 `Button` 属性（`type` 除外）传递给下拉菜单触发器。

| 名称                  | 类型                | 默认值            | 描述                                                   |
| --------------------- | ------------------- | ----------------- | ------------------------------------------------------ |
| `editor`              | `Editor \| null`    | `undefined`       | Tiptap 编辑器实例。                                    |
| `formats`             | `NumberingFormat[]` | `DEFAULT_FORMATS` | 下拉菜单中提供的编号格式 id。                          |
| `hideWhenUnavailable` | `boolean`           | `false`           | 没有可用的有序列表时隐藏下拉菜单。                     |
| `modal`               | `boolean`           | `true`            | 下拉菜单是否以模态框形式锁定焦点。                     |
| `onOpenChange`        | `(boolean) => void` | `undefined`       | 下拉菜单打开或关闭时调用的回调函数。                   |

### `<NumberingFormatButton />`

单个格式选项，以小型嵌套列表预览呈现。可用于构建下拉网格，也可单独使用。

#### 属性

| 名称                  | 类型              | 默认值      | 描述                                                    |
| --------------------- | ----------------- | ----------- | ------------------------------------------------------- |
| `editor`              | `Editor \| null`  | `undefined` | Tiptap 编辑器实例。                                     |
| `format`              | `NumberingFormat` | —           | 此按钮应用的编号格式。**必填。**                       |
| `hideWhenUnavailable` | `boolean`         | `false`     | 没有可用的有序列表时隐藏此按钮。                        |
| `onFormatSet`         | `() => void`      | `undefined` | 成功应用格式后调用。                                    |

## Hooks

### `useNumberingFormatDropdownMenu()`

无界面 hook，提供构建自定义编号下拉菜单所需的完整状态和操作。

#### 用法

```tsx
function MyNumberingDropdown() {
  const {
    isVisible,
    currentFormat,
    canToggle,
    formats,
    setFormat,
    isFormatActive,
    getFormatLabel,
  } = useNumberingFormatDropdownMenu({ editor, hideWhenUnavailable: true })

  if (!isVisible) return null

  return (
    <DropdownMenu>
      <DropdownMenuTrigger disabled={!canToggle}>Numbering</DropdownMenuTrigger>
      <DropdownMenuContent>
        {formats.map((format) => (
          <DropdownMenuItem
            key={format}
            data-active-state={isFormatActive(format) ? 'on' : 'off'}
            onClick={() => setFormat(format)}
          >
            {getFormatLabel(format)}
          </DropdownMenuItem>
        ))}
      </DropdownMenuContent>
    </DropdownMenu>
  )
}
```

#### 属性

| 名称                  | 类型                | 默认值            | 描述                                           |
| --------------------- | ------------------- | ----------------- | ---------------------------------------------- |
| `editor`              | `Editor \| null`    | `undefined`       | Tiptap 编辑器实例。                            |
| `formats`             | `NumberingFormat[]` | `DEFAULT_FORMATS` | 提供的编号格式 id。                            |
| `hideWhenUnavailable` | `boolean`           | `false`           | 没有可用的有序列表时隐藏下拉菜单。             |

#### 返回值

| 名称             | 类型                                   | 描述                                                        |
| ---------------- | -------------------------------------- | ----------------------------------------------------------- |
| `isVisible`      | `boolean`                              | 是否应渲染下拉菜单。                                        |
| `currentFormat`  | `string`                               | 当前应用的格式 id（未设置时为 `"decimal"`）。              |
| `isActive`       | `boolean`                              | 当前是否有任一提供的格式处于启用状态。                      |
| `canToggle`      | `boolean`                              | 当前状态下是否可以设置编号格式。                            |
| `formats`        | `NumberingFormat[]`                    | 提供的格式 id。                                             |
| `setFormat`      | `(format: NumberingFormat) => boolean` | 应用格式；成功时返回 `true`。                               |
| `isFormatActive` | `(format: NumberingFormat) => boolean` | 指定格式是否为当前启用的格式（用于显示启用状态标记）。      |
| `getFormatLabel` | `(format: NumberingFormat) => string`  | 格式的易读预览标签，例如 `"1. 2. 3."`。                    |

### `useNumberingFormatButton()`

单个格式选项的状态和处理函数。

#### 属性

| 名称                  | 类型              | 默认值      | 描述                                       |
| --------------------- | ----------------- | ----------- | ------------------------------------------ |
| `editor`              | `Editor \| null`  | `undefined` | Tiptap 编辑器实例。                        |
| `format`              | `NumberingFormat` | —           | 此按钮应用的格式。**必填。**               |
| `hideWhenUnavailable` | `boolean`         | `false`     | 不可用时隐藏此按钮。                       |
| `onFormatSet`         | `() => void`      | `undefined` | 设置格式后调用。                           |

#### 返回值

| 名称              | 类型            | 描述                                             |
| ----------------- | --------------- | ------------------------------------------------ |
| `isVisible`       | `boolean`       | 是否应渲染此按钮。                               |
| `isActive`        | `boolean`       | 此格式当前是否处于启用状态。                     |
| `handleSetFormat` | `() => boolean` | 应用格式；成功时返回 `true`。                    |
| `canSet`          | `boolean`       | 当前状态下是否可以设置此格式。                   |
| `label`           | `string`        | 格式的预览标签，例如 `"1. 2. 3."`。             |

## 实用工具

### 格式 id 和标签

```tsx
import {
  NUMBERING_FORMAT_IDS,
  NUMBERING_FORMAT_LABELS,
  DEFAULT_FORMATS,
} from '@/components/tiptap-ui/numbering-format-dropdown-menu'
```

`NumberingFormat` 可以是以下值之一：`decimal`、`decimal-paren`、`decimal-nested`、`upper-alpha`、`lower-alpha`、`upper-roman`、`lower-roman`、`decimal-zero`。`NUMBERING_FORMAT_IDS` 按下拉菜单中的顺序列出这些值；`DEFAULT_FORMATS` 是默认提供的格式集合；`NUMBERING_FORMAT_LABELS` 将每个 id 映射到对应的预览字符串（例如 `"A. B. C."`）。

### 编辑器辅助函数

```tsx
import {
  setNumberingFormat,
  isNumberingFormatActive,
  getCurrentNumberingFormat,
  canSetNumberingFormat,
  getFormatLabel,
} from '@/components/tiptap-ui/numbering-format-dropdown-menu'

setNumberingFormat(editor, 'upper-roman') // applies the format, returns boolean
getCurrentNumberingFormat(editor) // active format id, or null when not in a list
isNumberingFormatActive(editor, 'decimal') // boolean
canSetNumberingFormat(editor) // boolean
getFormatLabel('lower-alpha') // "a. b. c."
```
