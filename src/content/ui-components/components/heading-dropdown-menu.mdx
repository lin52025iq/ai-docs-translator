这是一款适用于 Tiptap 编辑器、无障碍支持完善的标题下拉菜单。通过简洁的下拉界面和灵活的自定义选项，轻松选择并应用标题级别（H1-H6）。

<CodeDemo isScrollable src="https://template.tiptap.dev/preview/tiptap-ui/heading-dropdown-menu" />

## 安装

通过 Tiptap CLI 添加此组件：

```bash
npx @tiptap/cli@latest add heading-dropdown-menu
```

## 组件

### `<HeadingDropdownMenu />`

预构建的 React 组件，提供用于选择标题级别的下拉菜单。

#### 用法

```tsx
export default function MyEditor() {
  return (
    <HeadingDropdownMenu
      editor={editor}
      levels={[1, 2, 3, 4, 5, 6]}
      hideWhenUnavailable={true}
      portal={false}
      onOpenChange={(isOpen) => console.log('Dropdown', isOpen ? 'opened' : 'closed')}
    />
  )
}
```

#### 属性

| 名称                  | 类型                | 默认值          | 描述                                             |
| --------------------- | ------------------- | --------------- | ------------------------------------------------ |
| `editor`              | `Editor \| null`    | `undefined`     | Tiptap 编辑器实例                                |
| `levels`              | `Level[]`           | `[1,2,3,4,5,6]` | 下拉菜单中显示的可用标题级别                     |
| `hideWhenUnavailable` | `boolean`           | `false`         | 标题不可用时隐藏下拉菜单                         |
| `portal`              | `boolean`           | `false`         | 是否通过 portal 渲染下拉菜单                     |
| `onOpenChange`        | `(boolean) => void` | `undefined`     | 下拉菜单打开或关闭时调用的回调                   |

## Hooks

### `useHeadingDropdownMenu()`

自定义 hook，可用于构建自己的标题下拉菜单，并完全控制其渲染和行为。

#### 用法

```tsx
function MyHeadingDropdown() {
  const { isVisible, activeLevel, isActive, canToggle, levels, label, Icon } =
    useHeadingDropdownMenu({
      editor: myEditor,
      levels: [1, 2, 3],
      hideWhenUnavailable: true,
    })

  if (!isVisible) return null

  return (
    <DropdownMenu>
      <DropdownMenuTrigger asChild>
        <button disabled={!canToggle} aria-label={label} aria-pressed={isActive}>
          <Icon />
          {label}
          <ChevronDownIcon />
        </button>
      </DropdownMenuTrigger>
      <DropdownMenuContent>
        {levels.map((level) => (
          <DropdownMenuItem key={level}>
            <HeadingButton editor={editor} level={level} text={`Heading ${level}`} />
          </DropdownMenuItem>
        ))}
      </DropdownMenuContent>
    </DropdownMenu>
  )
}
```

#### 属性

| 名称                  | 类型             | 默认值          | 描述                                          |
| --------------------- | ---------------- | --------------- | --------------------------------------------- |
| `editor`              | `Editor \| null` | `undefined`     | Tiptap 编辑器实例                             |
| `levels`              | `Level[]`        | `[1,2,3,4,5,6]` | 下拉菜单中显示的可用标题级别                  |
| `hideWhenUnavailable` | `boolean`        | `false`         | 标题无法应用时隐藏下拉菜单                    |

#### 返回值

| 名称          | 类型                 | 描述                                      |
| ------------- | -------------------- | ----------------------------------------- |
| `isVisible`   | `boolean`            | 是否应渲染下拉菜单                        |
| `activeLevel` | `Level \| undefined` | 当前激活的标题级别（1-6）                 |
| `isActive`    | `boolean`            | 当前是否有任何标题处于激活状态            |
| `canToggle`   | `boolean`            | 当前是否允许切换标题格式                  |
| `levels`      | `Level[]`            | 可用标题级别的数组                        |
| `label`       | `string`             | 下拉菜单的无障碍标签文本                  |
| `Icon`        | `React.FC`           | 表示当前标题状态的图标组件                |

## 工具函数

### `getActiveHeadingLevel(editor, levels?)`

从可用级别中获取当前激活的标题级别。

```tsx
import { getActiveHeadingLevel } from '@/components/tiptap-ui/heading-dropdown-menu'

const activeLevel = getActiveHeadingLevel(editor, [1, 2, 3]) // 返回激活的级别；若无则返回 undefined
```

### 单独的标题函数

标题下拉菜单使用标题按钮组件中的函数：

#### `isHeadingActive(editor, level?)`

检查指定的标题级别是否处于激活状态，或检查是否有任意标题处于激活状态。

```tsx
import { isHeadingActive } from '@/components/tiptap-ui/heading-button'

const isH1Active = isHeadingActive(editor, 1) // 检查 H1 是否激活
const isAnyHeadingActive = isHeadingActive(editor) // 检查是否有任意标题处于激活状态
```

#### `canToggle(editor)`

检查当前编辑器状态下是否可以切换标题格式。

```tsx
import { canToggle } from '@/components/tiptap-ui/heading-button'

const canApplyHeading = canToggle(editor)
```

## 键盘快捷键

使用 `HeadingButton` 组件时，各标题级别支持以下键盘快捷键：

- **Cmd/Ctrl + Alt + 1**：切换 H1
- **Cmd/Ctrl + Alt + 2**：切换 H2
- **Cmd/Ctrl + Alt + 3**：切换 H3
- **Cmd/Ctrl + Alt + 4**：切换 H4
- **Cmd/Ctrl + Alt + 5**：切换 H5
- **Cmd/Ctrl + Alt + 6**：切换 H6

下拉菜单本身不会注册快捷键，但可在一个界面中访问所有标题选项。
