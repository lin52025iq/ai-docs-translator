适用于 Tiptap 编辑器的无障碍链接弹出框。通过易用的弹出框界面，轻松添加、编辑和移除链接，并支持键盘快捷键和灵活的自定义选项。

<CodeDemo isScrollable isSmall src="https://template.tiptap.dev/preview/tiptap-ui/link-popover" />

## 安装

通过 Tiptap CLI 添加此组件：

```bash
npx @tiptap/cli@latest add link-popover
```

## 组件

### `<LinkPopover />`

预构建的 React 组件，可在弹出框中提供完整的链接编辑界面。

#### 用法

```tsx
import { EditorContent, EditorContext, useEditor } from '@tiptap/react'
import { StarterKit } from '@tiptap/starter-kit'
import { LinkPopover } from '@/components/tiptap-ui/link-popover'

import '@/components/tiptap-node/paragraph-node/paragraph-node.scss'

export default function MyEditor() {
  const editor = useEditor({
    immediatelyRender: false,
    extensions: [
      StarterKit.configure({
        link: { openOnClick: false, enableClickSelection: true },
      }),
    ],
    content: `
        <p>Click the button to open the link popover.</p>
        <p><a href="https://www.tiptap.dev">Tiptap</a></p>
        `,
  })

  return (
    <EditorContext.Provider value={{ editor }}>
      <LinkPopover
        editor={editor}
        hideWhenUnavailable={true}
        autoOpenOnLinkActive={true}
        onSetLink={() => console.log('Link set!')}
        onOpenChange={(isOpen) => console.log('Popover opened:', isOpen)}
      />

      <EditorContent editor={editor} role="presentation" />
    </EditorContext.Provider>
  )
}
```

#### 属性

| 名称                   | 类型                        | 默认值      | 描述                                               |
| ---------------------- | --------------------------- | ----------- | --------------------------------------------------------- |
| `editor`               | `Editor \| null`            | `undefined` | Tiptap 编辑器实例                                |
| `hideWhenUnavailable`  | `boolean`                   | `false`     | 链接功能不可用时隐藏按钮 |
| `onSetLink`            | `() => void`                | `undefined` | 成功设置链接后触发的回调           |
| `onOpenChange`         | `(isOpen: boolean) => void` | `undefined` | 弹出框打开或关闭时触发的回调           |
| `autoOpenOnLinkActive` | `boolean`                   | `true`      | 链接处于活动状态时是否自动打开弹出框       |

### `<LinkButton />`

独立的链接按钮组件，用于触发链接功能。

#### 用法

```tsx
<LinkButton onClick={handleClick} aria-label="Add link">
  Custom Link Content
</LinkButton>
```

### `<LinkContent />`

独立组件，可在不使用弹出框容器的情况下呈现链接编辑界面。

#### 用法

```tsx
<LinkContent editor={editor} />
```

## Hooks

### `useLinkPopover()`

自定义 hook，可用于构建自己的链接界面，并完全掌控其呈现方式和行为。

#### 用法

```tsx
function MyLinkButton() {
  const { isVisible, canSet, isActive, url, setUrl, setLink, removeLink, label, Icon } =
    useLinkPopover({
      editor: myEditor,
      hideWhenUnavailable: true,
      onSetLink: () => console.log('Link set!'),
    })

  if (!isVisible) return null

  return (
    <div>
      <button onClick={setLink} disabled={!canSet} aria-label={label} aria-pressed={isActive}>
        <Icon />
        {label}
      </button>
      <input
        type="url"
        value={url}
        onChange={(e) => setUrl(e.target.value)}
        placeholder="Enter URL..."
      />
      <button onClick={removeLink}>Remove</button>
    </div>
  )
}
```

#### 属性

| 名称                  | 类型             | 默认值      | 描述                                   |
| --------------------- | ---------------- | ----------- | --------------------------------------------- |
| `editor`              | `Editor \| null` | `undefined` | Tiptap 编辑器实例                    |
| `hideWhenUnavailable` | `boolean`        | `false`     | 无法应用链接时隐藏此功能 |
| `onSetLink`           | `() => void`     | `undefined` | 设置链接后触发的回调           |

#### 返回值

| 名称         | 类型                                                   | 描述                                       |
| ------------ | ------------------------------------------------------ | ------------------------------------------------- |
| `isVisible`  | `boolean`                                              | 是否应呈现链接功能 |
| `canSet`     | `boolean`                                              | 当前上下文中是否可以设置链接       |
| `isActive`   | `boolean`                                              | 链接当前是否处于活动或选中状态            |
| `url`        | `string`                                               | 当前链接的 URL 值                    |
| `setUrl`     | `React.Dispatch<React.SetStateAction<string \| null>>` | 用于更新 URL 状态的函数                  |
| `setLink`    | `() => void`                                           | 用于在编辑器中应用链接的函数          |
| `removeLink` | `() => void`                                           | 用于从编辑器中移除链接的函数       |
| `label`      | `string`                                               | 按钮的无障碍标签文本              |
| `Icon`       | `React.FC`                                             | 链接按钮的图标组件                |

### `useLinkHandler()`

专用于处理链接操作的 hook，不管理 UI 状态。

#### 用法

```tsx
function MyCustomLinkInterface() {
  const { url, setUrl, setLink, removeLink } = useLinkHandler({
    editor: myEditor,
    onSetLink: () => console.log('Link applied!'),
  })

  return (
    <div>
      <input
        value={url}
        onChange={(e) => setUrl(e.target.value)}
        onKeyDown={(e) => e.key === 'Enter' && setLink()}
      />
      <button onClick={setLink}>Apply</button>
      <button onClick={removeLink}>Remove</button>
    </div>
  )
}
```

#### 属性

| 名称        | 类型             | 默认值      | 描述                         |
| ----------- | ---------------- | ----------- | ----------------------------------- |
| `editor`    | `Editor \| null` | `undefined` | Tiptap 编辑器实例          |
| `onSetLink` | `() => void`     | `undefined` | 设置链接后触发的回调 |

#### 返回值

| 名称         | 类型                                                   | 描述                                 |
| ------------ | ------------------------------------------------------ | ------------------------------------------- |
| `url`        | `string`                                               | 当前链接的 URL 值              |
| `setUrl`     | `React.Dispatch<React.SetStateAction<string \| null>>` | 用于更新 URL 状态的函数            |
| `setLink`    | `() => void`                                           | 用于在编辑器中应用链接的函数    |
| `removeLink` | `() => void`                                           | 用于从编辑器中移除链接的函数 |

## 工具函数

### `canSetLink(editor)`

检查当前编辑器状态下是否可以设置链接。

```tsx
import { canSetLink } from '@/components/tiptap-ui/link-popover'

const canSet = canSetLink(editor)
if (canSet) {
  console.log('Link can be applied to current selection')
}
```

### `isLinkActive(editor)`

检查编辑器中当前是否有处于活动状态的链接。

```tsx
import { isLinkActive } from '@/components/tiptap-ui/link-popover'

const isActive = isLinkActive(editor)
if (isActive) {
  console.log('A link is currently selected')
}
```

## 键盘快捷键

链接弹出框支持以下键盘操作：

- **Enter**：将当前 URL 应用为链接（焦点位于 URL 输入框中时）
- **Escape**：关闭弹出框（弹出框的标准行为）
