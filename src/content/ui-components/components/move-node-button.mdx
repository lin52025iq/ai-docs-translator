适用于 Tiptap 编辑器的无障碍移动节点按钮。支持键盘快捷键和智能选择处理，可在编辑器中重新排列选中的节点或块。

<CodeDemo isScrollable src="https://template.tiptap.dev/preview/tiptap-ui/move-node-button" />

## 安装

通过 Tiptap CLI 添加此组件：

```bash
npx @tiptap/cli@latest add move-node-button
```

## 组件

### `<MoveNodeButton />`

一个预构建的 React 组件，可在编辑器中向上或向下移动节点。

#### 用法

```tsx
import { MoveNodeButton } from '@/components/tiptap-ui/move-node-button'
import { useEditor } from '@tiptap/react'

export default function MyEditor() {
  const editor = useEditor({
    // your editor configuration
  })

  return (
    <>
      <MoveNodeButton
        editor={editor}
        direction="up"
        text="Move Up"
        hideWhenUnavailable={true}
        showShortcut={true}
        onMoved={(direction) => console.log(`Node moved ${direction}!`)}
      />
      <MoveNodeButton
        editor={editor}
        direction="down"
        text="Move Down"
        hideWhenUnavailable={true}
        showShortcut={true}
        onMoved={(direction) => console.log(`Node moved ${direction}!`)}
      />
    </>
  )
}
```

#### 属性

| 名称                  | 类型                                  | 默认值       | 说明                                             |
| --------------------- | ------------------------------------- | ------------ | ------------------------------------------------ |
| `editor`              | `Editor \| null`                      | `undefined`  | Tiptap 编辑器实例                                |
| `direction`           | `"up" \| "down"`                      | **必填**     | 节点移动方向                                     |
| `text`                | `string`                              | `undefined`  | 按钮的可选文本标签                               |
| `hideWhenUnavailable` | `boolean`                             | `false`      | 无法移动时隐藏按钮                               |
| `onMoved`             | `(direction: "up" \| "down") => void` | `undefined`  | 移动成功后触发的回调                             |
| `showShortcut`        | `boolean`                             | `false`      | 显示键盘快捷键标记（如果有）                     |

## Hooks

### `useMoveNode()`

自定义 Hook，可完全控制渲染和行为，用于构建自己的移动节点按钮。

#### 用法

```tsx
import { useMoveNode } from '@/components/tiptap-ui/move-node-button'
import { parseShortcutKeys } from '@/lib/tiptap-utils'
import { Badge } from '@/components/ui/badge'
import { useEditor } from '@tiptap/react'

function MyMoveNodeButton({ direction }: { direction: 'up' | 'down' }) {
  const editor = useEditor({
    // your editor configuration
  })

  const { isVisible, handleMoveNode, canMoveNode, label, shortcutKeys, Icon } = useMoveNode({
    editor,
    direction,
    hideWhenUnavailable: true,
    onMoved: (direction) => console.log(`Node moved ${direction}!`),
  })

  if (!isVisible) return null

  return (
    <button onClick={handleMoveNode} disabled={!canMoveNode} aria-label={label}>
      <Icon />
      {label}
      {shortcutKeys && <Badge>{parseShortcutKeys({ shortcutKeys })}</Badge>}
    </button>
  )
}
```

#### 属性

| 名称                  | 类型                                  | 默认值       | 说明                                             |
| --------------------- | ------------------------------------- | ------------ | ------------------------------------------------ |
| `editor`              | `Editor \| null`                      | `undefined`  | Tiptap 编辑器实例                                |
| `direction`           | `"up" \| "down"`                      | **必填**     | 节点移动方向                                     |
| `hideWhenUnavailable` | `boolean`                             | `false`      | 无法执行移动时隐藏按钮                           |
| `onMoved`             | `(direction: "up" \| "down") => void` | `undefined`  | 移动成功后触发的回调                             |

#### 返回值

| 名称             | 类型            | 说明                                                               |
| ---------------- | --------------- | ------------------------------------------------------------------ |
| `isVisible`      | `boolean`       | 是否应渲染按钮                                                     |
| `canMoveNode`    | `boolean`       | 是否可以沿指定方向移动节点                                         |
| `handleMoveNode` | `() => boolean` | 移动所选节点的函数                                                 |
| `label`          | `string`        | 按钮的无障碍标签文本                                               |
| `shortcutKeys`   | `string`        | 对应方向的键盘快捷键                                               |
| `Icon`           | `React.FC`      | 移动按钮的图标组件（AlignTopIcon/AlignBottomIcon）                 |

## 工具函数

### `canMoveNode(editor, direction)`

检查当前编辑器状态下，节点是否可以沿指定方向移动。

#### 参数

- `editor` (`Editor | null`) - Tiptap 编辑器实例
- `direction` (`"up" | "down"`) - 要检查的方向

#### 返回值

`boolean` - 如果节点可以沿指定方向移动，则为 true；否则为 false

#### 用法

```tsx
import { canMoveNode } from '@/components/tiptap-ui/move-node-button'
import type { Editor } from '@tiptap/react'

const canMoveUp = canMoveNode(editor, 'up')
const canMoveDown = canMoveNode(editor, 'down')
```

### `moveNode(editor, direction)`

以编程方式沿指定方向移动选中的节点或块。

#### 参数

- `editor` (`Editor | null`) - Tiptap 编辑器实例
- `direction` (`"up" | "down"`) - 节点的移动方向

#### 返回值

`boolean` - 如果移动成功，则为 true；否则为 false

#### 用法

```tsx
import { moveNode } from '@/components/tiptap-ui/move-node-button'
import type { Editor } from '@tiptap/react'

const success = moveNode(editor, 'up')
if (success) {
  console.log('Node moved successfully!')
}
```

### `shouldShowButton(props)`

根据编辑器状态和配置，确定是否应显示移动按钮。

#### 参数

- `props` - 配置对象
  - `editor` (`Editor | null`) - Tiptap 编辑器实例
  - `direction` (`"up" | "down"`) - 要检查的方向
  - `hideWhenUnavailable` (`boolean`) - 移动不可用时是否隐藏按钮

#### 返回值

`boolean` - 如果应显示按钮，则为 true；否则为 false

#### 用法

```tsx
import { shouldShowButton } from '@/components/tiptap-ui/move-node-button'
import type { Editor } from '@tiptap/react'

const shouldShow = shouldShowButton({
  editor,
  direction: 'up',
  hideWhenUnavailable: true,
})
```

## 键盘快捷键

移动节点按钮支持以下键盘快捷键：

- **Cmd/Ctrl + Shift + Arrow Up**：将选中的节点上移
- **Cmd/Ctrl + Shift + Arrow Down**：将选中的节点下移

使用 `<MoveNodeButton />` 组件或 `useMoveNode()` Hook 时，系统都会自动注册这些快捷键。这些快捷键适用于任何块级节点，包括段落、标题、引用块和代码块。
