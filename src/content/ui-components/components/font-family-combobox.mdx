适用于 Tiptap 编辑器的可搜索字体选择器。触发按钮会显示当前字体；打开后会显示模糊搜索框，以及按类别分组的字体，每种字体都以其自身字形进行预览。“默认字体”选项会移除任何行内字体设置。

这是 `font-family-dropdown-menu` 的增强型可搜索替代方案，并与 `@tiptap/extension-text-style` 中的 `FontFamily` 标记配合使用。该组件**不依赖特定字体目录**：你可以传入自己的 `fonts`、`categories` 和 `defaultFont`，也可以使用内置的网页安全默认值。所有编辑器逻辑都封装在 `useFontFamilyCombobox` Hook 中。

## 安装

通过 Tiptap CLI 添加此组件：

```bash
npx @tiptap/cli@latest add font-family-combobox
```

## 组件

### `<FontFamilyCombobox />`

基于 Ariakit 的菜单与组合框复合组件构建的预置可搜索字体选择器。

#### 用法

```tsx
export default function MyEditor() {
  return (
    <FontFamilyCombobox
      editor={editor}
      hideWhenUnavailable={true}
      onOpenChange={(isOpen) => console.log('Picker', isOpen ? 'opened' : 'closed')}
    />
  )
}
```

要使用自己的字体目录，请传入 `fonts`、`categories` 和 `defaultFont`。每个选项的 `category` 都会与类别 `id` 匹配；选项中的可选属性 `fallbackFor` 可让导入的系统字体（例如 `"Arial"`）映射到内置字体系列。

```tsx
const fonts = [
  { value: 'inter', label: 'Inter', family: 'Inter', hint: 'UI sans', category: 'sans-serif', default: true },
  { value: 'georgia', label: 'Georgia', family: 'Georgia, serif', hint: 'Serif', category: 'serif' },
]
const categories = [
  { id: 'sans-serif', label: 'Sans-serif' },
  { id: 'serif', label: 'Serif' },
]

<FontFamilyCombobox editor={editor} fonts={fonts} categories={categories} defaultFont={fonts[0]} />
```

#### 属性

此组件还会将其他 `Button` 属性（`type` 除外）传递给触发按钮。

| 名称                  | 类型                   | 默认值                        | 说明                                                         |
| --------------------- | ---------------------- | ----------------------------- | ------------------------------------------------------------ |
| `editor`              | `Editor \| null`       | `undefined`                   | Tiptap 编辑器实例。                                          |
| `fonts`               | `FontFamilyOption[]`   | `defaultFontFamilyOptions`    | 选择器中提供的字体。                                         |
| `defaultFont`         | `FontFamilyOption`     | `defaultFontFamilyOption`     | 未应用行内字体时，文档回退使用的字体。                       |
| `categories`          | `FontFamilyCategory[]` | `defaultFontFamilyCategories` | 要显示的类别分组，根据每种字体的 `category` 进行匹配。       |
| `hideWhenUnavailable` | `boolean`              | `false`                       | 无法应用字体系列时隐藏选择器。                               |
| `onOpenChange`        | `(boolean) => void`    | `undefined`                   | 选择器打开或关闭时调用的回调。                               |

#### 类型

```tsx
interface FontFamilyOption {
  label: string // display name in the picker
  value: string // stable identifier
  family: string // CSS font-family applied to the document; previewed in this typeface
  hint?: string // short descriptor under the label, e.g. "Calibri-like"
  category: string // group id (matched against a FontFamilyCategory)
  default?: boolean // marks the default option (no inline font)
  fallbackFor?: string[] // system fonts this family stands in for on import
}

interface FontFamilyCategory {
  id: string
  label: string
}
```

## Hooks

### `useFontFamilyCombobox()`

一个无头 Hook，提供构建自定义字体选择器所需的选择状态和操作。

#### 用法

```tsx
function MyFontPicker() {
  const { isVisible, triggerLabel, selectFont, selectDefault, filterFonts } = useFontFamilyCombobox(
    { editor, hideWhenUnavailable: true },
  )

  if (!isVisible) return null

  const results = filterFonts('geo') // ranked matches for a search query
  // …render your own UI using selectFont(font) / selectDefault()
}
```

#### 属性

| 名称                  | 类型                 | 默认值                    | 说明                                                   |
| --------------------- | -------------------- | -------------------------- | ------------------------------------------------------ |
| `editor`              | `Editor \| null`     | `undefined`                | Tiptap 编辑器实例。                                    |
| `fonts`               | `FontFamilyOption[]` | `defaultFontFamilyOptions` | 可供选择的字体。                                       |
| `defaultFont`         | `FontFamilyOption`   | `defaultFontFamilyOption`  | 未设置行内字体时，文档回退使用的字体。                 |
| `hideWhenUnavailable` | `boolean`            | `false`                    | 字体系列不可用时隐藏选择器。                           |

#### 返回值

| 名称               | 类型                                    | 说明                                                        |
| ------------------ | --------------------------------------- | ----------------------------------------------------------- |
| `isVisible`        | `boolean`                               | 是否应渲染选择器。                                          |
| `canToggle`        | `boolean`                               | 当前状态下是否可以应用字体系列。                            |
| `isActive`         | `boolean`                               | 是否启用了显式行内字体（而非默认字体）。                    |
| `fonts`            | `FontFamilyOption[]`                    | 配置的字体。                                                |
| `defaultFont`      | `FontFamilyOption`                      | 配置的默认字体。                                            |
| `selectionState`   | `FontFamilySelectionState`              | 当前选区的字体状态（`default` / `font` / `mixed`）。        |
| `activeFontFamily` | `string`                                | 当前选区应用的 `font-family`（默认状态下为空）。            |
| `activeFont`       | `FontFamilyOption \| undefined`         | 当前字体对应的选项（如果存在）。                            |
| `triggerLabel`     | `string`                                | 触发按钮的标签（当前字体、`Mixed` 或 `Default · …`）。      |
| `selectFont`       | `(font: FontFamilyOption) => void`      | 为当前选区应用字体系列。                                    |
| `selectDefault`    | `() => void`                            | 移除所有行内字体设置（使用文档默认字体）。                  |
| `filterFonts`      | `(query: string) => FontFamilyOption[]` | 根据搜索词对已配置的字体进行排序。                          |

## 工具

### 默认字体目录

```tsx
import {
  defaultFontFamilyOptions,
  defaultFontFamilyCategories,
  defaultFontFamilyOption,
} from '@/components/tiptap-ui/font-family-combobox'
```

一组网页安全字体（Arial、Verdana、Tahoma、Times New Roman、Georgia、Courier New），按 Sans-serif / Serif / Monospace 分组，因此无需加载任何 Web 字体即可直接使用此组件。

### 辅助函数

```tsx
import {
  filterFontsByQuery,
  findFontByFamily,
  resolveFontFamily,
  getActiveFontOption,
  getFontFamilySelectionState,
  getFontFamilyTriggerLabel,
} from '@/components/tiptap-ui/font-family-combobox'

filterFontsByQuery(fonts, 'geo') // ranked matches (blank query → unchanged order)
findFontByFamily(fonts, 'Georgia') // the option whose family matches, or undefined
resolveFontFamily(fonts, 'Arial') // map a system font through each option's fallbackFor
getActiveFontOption(fonts, 'Inter') // resolve an applied family to an option
getFontFamilySelectionState(editor) // { kind: 'default' | 'font' | 'mixed', fontFamily }
getFontFamilyTriggerLabel(state, defaultFont, fonts) // the trigger label string
```

## 要求

### 依赖项

- `@tiptap/react` — Tiptap React 核心集成
- `@tiptap/pm` — 用于读取选区字体标记的 ProseMirror 模型和状态
- `match-sorter` — 为搜索框提供模糊匹配排序
- `@tiptap/extension-text-style` — 提供此选择器所应用的 `FontFamily` 标记

### 引用的组件

- `use-tiptap-editor`（Hook）
- `use-composed-ref`（Hook）
- `font-family-dropdown-menu`（组件 — 共享编辑器辅助函数）
- `button`（基础组件）
- `combobox`（基础组件）
- `input`（基础组件）
- `menu`（基础组件）
- `check-icon`（图标）
- `chevron-down-icon`（图标）
