这是一款功能增强的 Tiptap 编辑器表格节点组件，提供用于操作行和列的表格手柄，以及单元格对齐控件。它支持添加、删除、移动和复制，并具备高级表格管理功能、响应式样式和无障碍功能。

<CodeDemo isScrollable src="https://template.tiptap.dev/preview/tiptap-node/table-node" />

## 安装

通过 Tiptap CLI 添加此组件：

```bash
npx @tiptap/cli@latest add table-node
```

## 使用

### 基本集成

按照以下步骤为 Tiptap 编辑器添加表格功能：

**1. 导入所需的扩展和组件：**

```tsx
import { Highlight } from '@tiptap/extension-highlight'
import { TextStyle } from '@tiptap/extension-text-style'

import { NodeBackground } from '@/components/tiptap-extension/node-background-extension'
import { NodeAlignment } from '@/components/tiptap-extension/node-alignment-extension'

import { TableKit } from '@/components/tiptap-node/table-node/extensions/table-node-extension'
import { TableHandleExtension } from '@/components/tiptap-node/table-node/extensions/table-handle'

import { TableTriggerButton } from '@/components/tiptap-node/table-node/ui/table-trigger-button'
import { TableHandle } from '@/components/tiptap-node/table-node/ui/table-handle/table-handle'
import { TableSelectionOverlay } from '@/components/tiptap-node/table-node/ui/table-selection-overlay'
import { TableCellHandleMenu } from '@/components/tiptap-node/table-node/ui/table-cell-handle-menu'
import { TableExtendRowColumnButtons } from '@/components/tiptap-node/table-node/ui/table-extend-row-column-button'

// Import required styles
import '@/components/tiptap-node/table-node/styles/prosemirror-table.scss'
import '@/components/tiptap-node/table-node/styles/table-node.scss'
```

**2. 将扩展添加到编辑器配置中：**

```tsx
const editor = useEditor({
  extensions: [
    StarterKit,
    TableKit.configure({
      table: {
        resizable: true, // Enable column resizing
      },
    }),
    TableHandleExtension, // Required for row/column manipulation
    NodeAlignment, // For cell alignment
    NodeBackground, // For cell background colors
    TextStyle, // For text styling
    Highlight.configure({ multicolor: true }), // For highlighting
  ],
  content: '<p>Your content here</p>',
})
```

**3. 定义稳定的单元格菜单，然后将表格组件添加到编辑器中：**

<Callout title="传入稳定的 cellMenu 引用" variant="warning">
  在模块作用域中定义 `cellMenu` 组件（或使用 `useMemo` 包装它）。内联箭头函数
  `cellMenu={(props) => <TableCellHandleMenu ... />}` 会在每次渲染时创建新的组件类型，
  导致整个菜单子树重新挂载；对于频繁重新渲染的编辑器，这可能会引发 `Maximum update depth exceeded` 错误。
</Callout>

```tsx
// Module scope — stable identity across renders.
const CellMenu = (props) => (
  <TableCellHandleMenu
    editor={props.editor}
    onMouseDown={(e) => props.onResizeStart?.('br')(e)}
  />
)
```

```tsx
<EditorContext.Provider value={{ editor }}>
  {/* Add table button to your toolbar */}
  <div className="toolbar">
    <TableTriggerButton />
  </div>

  <EditorContent editor={editor} />

  {/* Add these components outside EditorContent for proper positioning */}
  <TableHandle />
  <TableSelectionOverlay showResizeHandles={true} cellMenu={CellMenu} />
  <TableExtendRowColumnButtons />
</EditorContext.Provider>
```

**完成！** 现在，编辑器已具备完整的表格功能，包括：

- 可视化插入表格
- 通过手柄操作行和列
- 选择和调整单元格大小
- 用于表格操作的上下文菜单

如需查看包含所有功能的完整示例，请参阅下方的 [TableNode 组件示例](#lesstablenode-greater)。

## 创建表格

### `<TableTriggerButton />`

**用于在编辑器中插入表格的主要组件。** 此按钮会打开交互式网格选择器，用户可以在插入表格前直观地选择表格的尺寸。

#### 主要功能

- **可视化网格选择器**：通过交互式网格界面选择表格尺寸
- **快速插入**：点击即可立即创建最多 8×8 的表格（可自定义）
- **无障碍支持**：完整支持键盘导航和 ARIA 标签

#### 用法

```tsx
import { TableTriggerButton } from '@/components/tiptap-node/table-node/ui/table-trigger-button'

function MyToolbar() {
  return (
    <TableTriggerButton
      editor={editor}
      maxRows={8}
      maxCols={8}
      hideWhenUnavailable={true}
      text="Insert Table"
      onInserted={(rows, cols) => console.log(`Inserted ${rows}×${cols} table`)}
    />
  )
}
```

#### 属性

- `editor?: Editor | null` - 编辑器实例
- `hideWhenUnavailable?: boolean` - 无法插入表格时隐藏（默认值：false）
- `maxRows?: number` - 网格选择器中的最大行数（默认值：8）
- `maxCols?: number` - 网格选择器中的最大列数（默认值：8）
- `onInserted?: (rows: number, cols: number) => void` - 成功插入后的回调
- `text?: string` - 可选文本，与图标一同显示
- 所有标准按钮属性（className、disabled 等）

#### 使用 Hook 自定义实现

如需自定义按钮实现，请使用 `useTableTriggerButton` Hook：

```tsx
import { useTableTriggerButton } from '@/components/tiptap-node/table-node/ui/table-trigger-button'

function CustomTableButton() {
  const {
    isVisible,
    canInsert,
    isOpen,
    setIsOpen,
    hoveredCell,
    handleCellHover,
    handleCellClick,
    resetHoveredCell,
    label,
    Icon,
  } = useTableTriggerButton({
    editor,
    hideWhenUnavailable: true,
    maxRows: 10,
    maxCols: 10,
    onInserted: (rows, cols) => {
      console.log(`Created ${rows}×${cols} table`)
    },
  })

  if (!isVisible) return null

  return (
    <button onClick={() => setIsOpen(true)} disabled={!canInsert}>
      <Icon /> {label}
    </button>
  )
}
```

## 表格操作组件

每个组件都提供 React 组件和可组合的 Hook 两种形式：

### 行/列操作组件

#### `<TableAddRowColumnButton />` / `useTableAddRowColumn()`

在表格中的指定位置添加行或列。

**属性：**

- `editor?: Editor | null` - 编辑器实例
- `index?: number` - 行/列索引
- `orientation?: Orientation` - "row" 或 "column"
- `direction?: "before" | "after"` - 在指定索引之前或之后添加
- `tablePos?: number` - 表格在文档中的位置
- `hideWhenUnavailable?: boolean` - 操作不可用时隐藏
- `onAdded?: () => void` - 成功添加后的回调

**用法：**

```tsx
import { TableAddRowColumnButton } from '@/components/tiptap-node/table-node/ui/table-add-row-column-button'

function MyToolbar() {
  return <TableAddRowColumnButton orientation="row" direction="after" />
}
```

#### `<TableDeleteRowColumnButton />` / `useTableDeleteRowColumn()`

从表格中删除行或列。

**属性：**

- `editor?: Editor | null`
- `index?: number`
- `orientation?: Orientation`
- `tablePos?: number`
- `hideWhenUnavailable?: boolean`
- `onDeleted?: () => void`

**用法：**

在表格中向上/下或向左/右移动行或列。

**属性：**

- `editor?: Editor | null`

- `orientation?: Orientation`
- `direction?: "up" | "down" | "left" | "right"`
- `tablePos?: number`

### 直接使用 Hook

所有按钮组件都有对应的 Hook，可用于构建自定义 UI：

```tsx
import { useTableDeleteRowColumn } from '@/components/tiptap-node/table-node/ui/table-delete-row-column-button'

function CustomDeleteButton() {
  const { isVisible, canDeleteRowColumn, handleDelete, label, Icon } = useTableDeleteRowColumn({
    orientation: 'row',
    hideWhenUnavailable: true,
  })

  if (!isVisible) return null

  return (
    <button onClick={handleDelete} disabled={!canDeleteRowColumn}>
      <Icon /> {label}
    </button>
  )
}
```

每个 Hook 都会返回：

- `isVisible: boolean` - 是否应显示该操作
- `can[Action]: boolean` - 是否可以执行该操作
- `handle[Action]: () => boolean` - 执行该操作
- `label: string` - 操作的 UI 标签
- `Icon: ComponentType` - 操作对应的图标组件

## 分页支持

表格节点内置了集成功能，因此兼容 [Pages 扩展](/pages/getting-started/overview)。在编辑器中注册 Pages 后，表格会自动按行跨页拆分：列宽、合并单元格和单元格边框都会保留；跨越分页符的纵向合并（rowspan）单元格会延续到下一页；高于页面内容区域的单元格则会变为可滚动，以确保分页保持稳定。

无需额外配置——表格会自动检测 Pages 扩展并进行适配。未使用 Pages 时，表格的渲染效果与之前完全相同。

<Callout title="Pages Pro 用户" variant="info">
  如果你直接使用 `@tiptap-pro` Pages 包（而不是这些复制粘贴式 UI 组件）进行开发，请改用专用的 `@tiptap-pro/extension-pages-tablekit` 包，详见
  [在 Pages 中使用 TableKit](/pages/guides/table-with-pages)。
</Callout>

## 相关扩展

- **Node Alignment 扩展** - 单元格对齐功能所必需
- **UniqueID 扩展** - 可选；示例模板使用此扩展为表格分配唯一 ID（其他块级节点也会使用）
- **Color 扩展** - 用于设置单元格背景颜色
- **TextStyle 扩展** - 用于设置单元格中的文本样式
