为 Tiptap 编辑器中的各种列表类型设置样式，包括有序列表、无序列表和任务列表。

<CodeDemo isScrollable src="https://template.tiptap.dev/preview/tiptap-node/list-node" />

## 安装

你可以通过 Tiptap CLI 添加节点组件：

```bash
npx @tiptap/cli@latest add list-node
```

## 用法

ListNode 为编辑器中的不同类型列表提供样式。要使用它，请将其引入项目，并确保使用 Tiptap 的列表扩展。

```tsx
import { useEditor, EditorContent } from '@tiptap/react'
import { TaskList } from '@tiptap/extension-task-list'
import { TaskItem } from '@tiptap/extension-task-item'
import { StarterKit } from '@tiptap/starter-kit'

import '@/components/tiptap-node/list-node/list-node.scss'

export default function EditorWithLists() {
  const editor = useEditor({
    extensions: [
      StarterKit,
      TaskList,
      TaskItem.configure({
        nested: true,
      }),
    ],
    content: `
      <ul>
        <li>Unordered list item</li>
        <li>Another unordered item</li>
      </ul>

      <ol>
        <li>Ordered list item</li>
        <li>Another ordered item</li>
      </ol>

      <ul data-type="taskList">
        <li data-type="taskItem" data-checked="true">Completed task</li>
        <li data-type="taskItem" data-checked="false">Pending task</li>
      </ul>
    `,
  })

  return <EditorContent editor={editor} />
}
```

## 功能

- 为有序列表、无序列表和任务列表提供一致的样式
- 支持正确的嵌套和恰当的缩进
- 为任务列表提供自定义复选框样式
- 复选框可交互，点击后会响应
- 已完成的任务会显示删除线
- 支持深色模式
