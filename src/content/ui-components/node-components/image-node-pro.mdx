适用于 Tiptap 编辑器的增强型图片节点组件。支持拖动调整大小、可编辑说明文字、键盘安全导航、浮动工具栏控件、图片对齐选项、下载功能、自适应样式和无障碍交互模式。

## 安装

通过 Tiptap CLI 添加组件：

```bash
npx @tiptap/cli@latest add image-node-pro floating-element toolbar
```

<Callout title="源代码在哪里？" variant="info">
  上方预览是一个实时演示。该命令会安装 Image Node Pro，以及下方示例所用的 `FloatingElement`
  和 `Toolbar` 包装组件。Tiptap UI Components 以可编辑源文件的形式提供，并复制到你的项目中（位于
  `@/components/…` 下），而不是作为 npm 包提供。因此，导入路径会指向你自己的代码库中的文件，而不是
  `node_modules` 中的模块。
</Callout>

### 更新现有安装

UI Components 会复制到你的项目中，因此现有安装不会自动更新。若要获取完整的图片、浮动元素和工具栏修复，
请启用覆盖并重新安装：

```bash
npx @tiptap/cli@latest add image-node-pro floating-element toolbar -o
```

<Callout title="请先检查本地自定义内容" variant="warning">
  `-o` 标志会覆盖已安装的组件文件。运行更新前，请先提交或检查本地自定义内容。
</Callout>

## 用法

```tsx
import { EditorContent, EditorContext, useEditor } from '@tiptap/react'
import { StarterKit } from '@tiptap/starter-kit'
import { Image } from '@/components/tiptap-node/image-node/image-node-extension'
import { ImageNodeFloating } from '@/components/tiptap-node/image-node/image-node-floating'
import { Toolbar, ToolbarGroup } from '@/components/tiptap-ui-primitive/toolbar'
import { FloatingElement } from '@/components/tiptap-ui-utils/floating-element'

import '@/components/tiptap-node/image-node/image-node.scss'

export default function ImageEditor() {
  const editor = useEditor({
    immediatelyRender: false,
    extensions: [StarterKit, Image],
    content: '<img src="/images/example.png" alt="Image" data-align="center" />',
  })

  return (
    <EditorContext.Provider value={{ editor }}>
      <EditorContent editor={editor} />

      <FloatingElement>
        <Toolbar variant="floating">
          <ToolbarGroup>
            <ImageNodeFloating />
          </ToolbarGroup>
        </Toolbar>
      </FloatingElement>
    </EditorContext.Provider>
  )
}
```

这里必须使用 `EditorContext.Provider`，因为 `ImageNodeFloating` 渲染的操作会从上下文中读取编辑器。`FloatingElement`
会相对于所选图片定位控件，而 `Toolbar` 则提供符合无障碍要求的工具栏交互模式。

## 功能

- 拖动调整大小：将鼠标悬停在图片上，拖动任一侧的手柄即可设置图片宽度
- 可编辑图片说明文字
- 带对齐控制的浮动工具栏
- 图片下载功能
- 删除节点按钮
- 对齐选项（左对齐、居中、右对齐）
- 序列化无说明文字和带说明文字的图片时，保留已配置的 HTML 属性
- 增强的无障碍支持
- 自适应图片尺寸
- 选中状态高亮
- 在节点前后插入内容后，仍能稳定选中图片
- 在无说明文字的图片周围进行键盘导航，以及进入或离开可见说明文字
- 图片删除和调整大小具有可预测的撤销边界
- 说明文字和调整大小控件支持只读模式

### 选中和说明文字行为

Image Node Pro 会在周围内容发生变化时跟踪图片在文档中的位置，因此即使在图片前插入或编辑区块，点击图片仍会创建节点选区。
在键盘导航时，不带说明文字的图片会像原子区块一样处理：光标会跳过隐藏的说明文字内容，而不会进入不可见的文本位置。可见说明文字仍可编辑和导航。

当焦点离开图片或按下 `Escape` 时，空说明文字会关闭。已填写的说明文字会保持显示，包括在只读编辑器中。图片删除和调整大小的提交分别具有独立的撤销边界，因此第一次撤销会恢复已删除的图片或之前的尺寸，而不会同时撤销最近一次说明文字编辑。

### 键盘行为

| 按键                                              | 行为                                                                                                                                |
| ------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `ArrowUp`、`ArrowDown`、`ArrowLeft`、`ArrowRight` | 在无说明文字的图片周围移动，不进入隐藏的说明文字内容；在可见说明文字的边界处进入或离开说明文字。                                    |
| `Enter`                                           | 离开已选中的图片或说明文字，并移至图片后的现有段落或新段落中。                                                                      |
| `Shift+Enter`、`Mod+Enter`                        | 如果编辑器的 schema 支持硬换行，则在编辑说明文字时插入硬换行。                                                                      |
| `Backspace`、`Delete`                             | 在说明文字中正常编辑文本。在图片边界处，先选中图片；再次按下按键即可删除所选图片。                                                   |
| `Escape`                                          | 返回图片节点选中状态；如果说明文字为空，则将其关闭。                                                                                |
| `Mod+A`                                           | 在非空说明文字中，先选中说明文字内容，然后扩展为选中整个文档。                                                                      |

浮动图片工具栏采用水平循环焦点导航。按 `Tab` 进入工具栏，使用 `ArrowLeft`、`ArrowRight`、`Home` 和 `End` 在控件间移动，
然后按 `Enter`（或按钮上的原生 `Space`）激活当前聚焦的控件。按 `Tab` 和 `Shift+Tab` 会离开工具栏，不会将焦点限制在工具栏内。

### HTML 输入和输出

不带说明文字的图片会序列化为 `<img>` 元素。带有可见或已填写说明文字的图片会序列化为一个 `<figure>`，其中包含一个 `<img>` 和一个 `<figcaption>`。在这两种形式中，已配置的 `HTMLAttributes` 都会应用于序列化后的 `<img>`。

解析 HTML 时，正数 `width` 和 `height` 值会规范化为数字；无效、为零或负数的尺寸会被忽略。`allowBase64` 选项会一致地应用于独立图片和 figure 内的图片。只有当 figure 恰好包含一个有效的直接子级 `<img>` 时，才会将其视为带说明文字的单张图片。包含多张图片的 figure 不会折叠为一个节点；符合条件的图片仍会作为独立图片保留。

## 扩展

### `Image`（增强版）

扩展 Tiptap Image 扩展，支持行内说明文字内容、figure 解析和序列化、对齐属性、隔离式键盘行为，以及可跟踪的可调整大小 React 节点视图。

## 浮动工具栏组件

`ImageNodeFloating` 会渲染图片操作组。将它挂载在 `FloatingElement` 和 `Toolbar` 中后，每当选中图片时，控件都会显示。

### `<ImageNodeFloating />`

组合用于所选图片的对齐、说明文字、下载、替换和删除操作。

### `<DeleteNodeButton />`

从编辑器中删除所选图片节点。

### `<ImageDownloadButton />`

将图片下载到用户的设备。

### `<ImageAlignButton />`

通过左对齐、居中和右对齐选项控制图片对齐方式。

### `<ImageCaptionButton />`

显示或隐藏所选图片的可编辑说明文字。

### `<ImageUploadButton />`

当编辑器 schema 包含 `imageUpload` 扩展时，替换所选图片。如果没有该扩展，替换操作会保持隐藏。

## 工作原理

图片节点系统通过多个相互集成的层协同工作：

1. **增强显示**：扩展基础 Tiptap Image 扩展，添加额外样式和自适应行为
2. **浮动工具栏**：选中图片时显示上下文相关控件
3. **调整大小**：鼠标悬停在图片上时，可通过两侧的拖动手柄交互式设置图片宽度
4. **对齐系统**：通过左对齐、居中和右对齐选项管理图片位置
5. **节点管理**：通过工具栏操作处理图片删除和下载
6. **状态集成**：与 Tiptap 的节点系统和命令架构无缝集成

如上所示，挂载 `FloatingElement`、`Toolbar` 和 `ImageNodeFloating` 后，选中图片会打开浮动工具栏，其中包含对齐、说明文字、下载、可选的替换和删除控件。

## 要求

### 依赖项

- `@tiptap/core` - 核心类型和 HTML 属性工具
- `@tiptap/extension-image` - 核心图片扩展
- `@tiptap/pm` - ProseMirror 模型、选区、事务和历史记录工具
- `@tiptap/react` - React 集成
- `sass` - SCSS 编译器开发依赖
- `sass-embedded` - Embedded Sass 开发依赖

### 引用的组件

`image-node-pro` registry 项会自动安装以下直接 registry 依赖：

- `image-node`（节点组件和样式）
- `use-tiptap-editor`（Hook）
- `tiptap-utils`（库）
- `delete-node-button`（组件）
- `image-download-button`（组件）
- `image-align-button`（组件）
- `image-caption-button`（组件）
- `image-upload-button`（组件）
- `refresh-ccw-icon`（图标）
- `separator`（基础组件）
- `styles`（共享样式）

快速入门安装命令会单独添加 `floating-element` 和 `toolbar`，因为它们用于组合 Image Node Pro 周围的上下文工具栏，而不是由图片节点本身导入。
