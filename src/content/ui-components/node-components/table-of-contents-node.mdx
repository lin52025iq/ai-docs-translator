这是一套功能全面的 Tiptap 编辑器目录（TOC）组件。此软件包提供可嵌入编辑器内容中的行内 TOC 节点，以及带进度指示器、用于文档导航的浮动侧边栏组件。

<CodeDemo isScrollable src="https://template.tiptap.dev/preview/tiptap-node/toc-node" />

## 安装

通过 Tiptap CLI 添加组件：

```bash
npx @tiptap/cli@latest add toc-node
```

## 使用

### 基本集成

按照以下步骤为 Tiptap 编辑器添加目录功能：

**1. 导入所需的扩展和组件：**

```tsx
import { Heading } from '@tiptap/extension-heading'
import { TableOfContents } from '@tiptap/extension-table-of-contents'
import { TocNode, TocSidebar, TocShowTitleButton } from '@/components/tiptap-node/toc-node'
import { TocProvider, useToc } from '@/components/tiptap-node/toc-node/context/toc-context'

// Import required styles
import '@/components/tiptap-node/toc-node/toc-node.scss'
import '@/components/tiptap-node/toc-node/ui/toc-sidebar/toc-sidebar.scss'
```

**2. 将扩展添加到编辑器配置中：**

```tsx
function EditorComponent() {
  const { setTocContent } = useToc()

  const editor = useEditor({
    extensions: [
      StarterKit,
      Heading.configure({
        levels: [1, 2, 3, 4, 5, 6],
      }),
      TableOfContents.configure({
        getIndex: (headingNode) => headingNode.attrs.id,
        onUpdate: (content) => {
          setTocContent(content) // Update TOC state
        },
      }),
      TocNode.configure({
        topOffset: 80,
        maxShowCount: 20,
        showTitle: true,
      }),
    ],
    content: '<p>Your content here</p>',
  })
}
```

**3. 将 TOC 组件添加到编辑器中：**

```tsx
import { TocProvider } from '@/components/tiptap-node/toc-node/context/toc-context'
import { TocSidebar } from '@/components/tiptap-node/toc-node'
;<TocProvider>
  <EditorContext.Provider value={{ editor }}>
    {/* Toolbar with TOC button */}
    <div className="toolbar">
      <button onClick={() => editor?.commands.insertTocNode()}>Insert TOC</button>
      <TocShowTitleButton editor={editor} />
    </div>

    <div className="editor-layout">
      <EditorContent editor={editor} />

      {/* Floating sidebar */}
      <TocSidebar maxShowCount={20} topOffset={80} />
    </div>
  </EditorContext.Provider>
</TocProvider>
```

**完成！** 现在，编辑器已具备以下功能：

- 可插入文档的行内 TOC 节点
- 带进度指示器的浮动 TOC 侧边栏
- 自动检测标题并支持导航
- 支持 URL 哈希，可深层链接

如需查看包含所有功能的完整示例，请参阅下方的[完整示例](#complete-example)部分。

## 创建目录

### 插入 TOC 节点

TOC 系统提供两种主要的目录展示方式：

#### 1. 行内 TOC 节点

可放置在文档内容任意位置的行内节点：

```tsx
// Insert programmatically
editor.commands.insertTocNode({
  maxShowCount: 10,
  topOffset: 60,
  showTitle: true,
})
```

#### 2. 浮动 TOC 侧边栏

与编辑器并排浮动的侧边栏组件：

```tsx
<TocSidebar maxShowCount={20} topOffset={80} className="my-toc-sidebar" />
```

## 组件

### `<TocNode />` 扩展

**可直接嵌入文档的行内目录节点。** 此扩展会创建一个可拖动、可选中的块，并在标题发生变化时自动更新。

#### 主要功能

- **自动更新**：自动反映文档中的标题变化
- **显示可自定义**：可控制显示的标题数量、标题名称是否显示以及滚动偏移量
- **智能导航**：点击即可平滑滚动到对应标题
- **空状态**：没有标题时显示提示信息
- **深度规范化**：正确构建标题层级

#### 用法

```tsx
import { TocNode } from '@/components/tiptap-node/toc-node'
import { TableOfContents } from '@tiptap/extension-table-of-contents'

const editor = useEditor({
  extensions: [
    TableOfContents.configure({
      getIndex: (headingNode) => headingNode.attrs.id,
      onUpdate: (content) => {
        // Handle updates
      },
    }),
    TocNode.configure({
      topOffset: 80,
      maxShowCount: 20,
      showTitle: true,
      HTMLAttributes: {
        class: 'my-custom-toc',
      },
    }),
  ],
})

// Insert the node
editor.commands.insertTocNode({
  maxShowCount: 15,
  topOffset: 60,
})
```

#### 配置选项

| 选项             | 类型                  | 默认值  | 描述                                                                  |
| ---------------- | --------------------- | ------- | --------------------------------------------------------------------- |
| `topOffset`      | `number`              | `0`     | 滚动到标题时距离视口顶部的偏移量（像素）                              |
| `maxShowCount`   | `number`              | `20`    | TOC 中最多显示的标题数量                                              |
| `showTitle`      | `boolean`             | `true`  | 是否显示“目录”标题                                                    |
| `HTMLAttributes` | `Record<string, any>` | `{}`    | 要添加到 TOC 节点元素的 HTML 属性                                     |

#### 命令

此扩展提供 `insertTocNode` 命令：

```tsx
// Insert with default settings
editor.commands.insertTocNode()

// Insert with custom attributes
editor.commands.insertTocNode({
  maxShowCount: 10,
  topOffset: 100,
  showTitle: false,
})
```

### `<TocSidebar />`

**显示目录并带有可视化进度指示器的浮动侧边栏组件。** 此组件提供始终可见的导航面板，并支持高级状态管理和顺滑滚动。

#### 主要功能

- **进度轨道**：可视化进度指示器，显示文档中的当前位置
- **多层级活动状态**：
  1. 手动点击（最高优先级）
  2. 滚动位置跟踪
  3. 光标/选区位置
  4. 第一个标题（回退选项）
- **智能滚动**：仅当目标标题不可见时才滚动
- **URL 哈希支持**：页面加载时从 URL 恢复滚动位置
- **平滑过渡**：活动状态切换时带有动画效果

#### 用法

```tsx
import { TocProvider } from '@/components/tiptap-node/toc-node/context/toc-context'
import { TocSidebar } from '@/components/tiptap-node/toc-node'

function MyEditor() {
  return (
    <TocProvider>
      <div className="editor-container">
        <EditorContent editor={editor} />
        <TocSidebar maxShowCount={20} topOffset={80} className="custom-sidebar" />
      </div>
    </TocProvider>
  )
}
```

#### 属性

| 属性                        | 类型     | 默认值 | 描述                                           |
| --------------------------- | -------- | ------ | ---------------------------------------------- |
| `maxShowCount`              | `number` | `20`   | TOC 中最多显示的标题数量                       |
| `topOffset`                 | `number` | `0`    | 相对于编辑器容器顶部的偏移量（像素）            |
| `className`                 | `string` | -      | 附加的 CSS 类名                                |
| 所有标准 HTML div 属性      | -        | -      | 支持所有 `HTMLAttributes<HTMLDivElement>`       |

#### 活动状态逻辑

侧边栏会智能判断要突出显示哪个标题：

1. **手动点击**：用户点击 TOC 项目时，该项目保持活动状态
2. **滚动检测**：手动导航完成后，切换为基于滚动位置的检测
3. **光标位置**：突出显示光标当前所在位置对应的标题
4. **回退选项**：其他条件均不满足时，显示第一个标题

### `<TocShowTitleButton />`

**用于切换 TOC 节点标题显示状态的工具栏按钮。** 仅当编辑器中选中了 TOC 节点时，此按钮才会显示。

#### 用法

```tsx
import { TocShowTitleButton } from '@/components/tiptap-node/toc-node'

function MyToolbar() {
  return (
    <div className="toolbar">
      <TocShowTitleButton
        editor={editor}
        text="Show Title"
        hideWhenUnavailable={true}
        onToggle={(isActive) => {
          console.log('Title visibility:', isActive)
        }}
      />
    </div>
  )
}
```

#### 属性

| 属性                      | 类型                        | 默认值  | 描述                                      |
| ------------------------- | --------------------------- | ------- | ----------------------------------------- |
| `editor`                  | `Editor \| null`            | -       | TipTap 编辑器实例                         |
| `text`                    | `string`                    | -       | 可选文本，与图标一起显示                  |
| `hideWhenUnavailable`     | `boolean`                   | `false` | 未选中 TOC 节点时是否隐藏按钮             |
| `onToggle`                | `(active: boolean) => void` | -       | 切换状态时触发的回调                      |
| 所有标准按钮属性          | -                           | -       | 支持所有 `ButtonProps`                    |

#### 使用 Hook 自定义实现

如需自定义按钮实现，请使用 `useTocShowTitle` hook：

```tsx
import { useTocShowTitle } from '@/components/tiptap-node/toc-node'

function CustomShowTitleButton() {
  const { isVisible, isActive, canToggle, handleToggle, label, Icon } = useTocShowTitle({
    editor,
    hideWhenUnavailable: true,
    onToggle: (isActive) => {
      console.log('Title visibility:', isActive)
    },
  })

  if (!isVisible) return null

  return (
    <button onClick={handleToggle} disabled={!canToggle} aria-label={label} data-active={isActive}>
      <Icon /> {label}
    </button>
  )
}
```

此 hook 会返回：

- `isVisible: boolean` - 是否应显示按钮
- `isActive: boolean` - 标题当前是否可见
- `canToggle: boolean` - 是否可以执行切换操作
- `handleToggle: () => boolean` - 执行切换操作
- `label: string` - 按钮的 UI 标签
- `Icon: ComponentType` - 按钮的图标组件

## 上下文与 Hooks

### `<TocProvider />`

用于管理 TOC 状态并向所有子组件提供导航方法的上下文提供程序。

#### 用法

```tsx
import { TocProvider } from '@/components/tiptap-node/toc-node/context/toc-context'

function App() {
  return (
    <TocProvider>
      <YourEditorComponents />
    </TocProvider>
  )
}
```

### `useToc()`

在提供程序内的任意组件中访问 TOC 状态和方法。

#### API

```tsx
const {
  tocContent, // TableOfContentData | null
  setTocContent, // (value: TableOfContentData | null) => void
  navigateToHeading, // (item, options?) => void
  normalizeHeadingDepths, // <T>(items: T[]) => number[]
} = useToc()
```

#### 方法

**navigateToHeading(item, options?)**

滚动到指定标题并更新编辑器选区。

```tsx
navigateToHeading(item, {
  topOffset: 80, // Offset from top (pixels)
  behavior: 'smooth', // 'smooth' | 'auto'
})
```

参数：

- `item: TableOfContentDataItem` - 要导航到的标题项目
- `options.topOffset?: number` - 相对于视口顶部的偏移量（默认值：0）
- `options.behavior?: ScrollBehavior` - 滚动行为（默认值：'smooth'）

**normalizeHeadingDepths(items)**

规范化标题深度，以正确构建层级结构。这样可以确保标题仅嵌套在级别编号较小的前置标题下，避免出现不正确的结构。

```tsx
const items = [
  { level: 2, textContent: 'Section 1' },
  { level: 4, textContent: 'Subsection' }, // h4 can't be child of h2
  { level: 3, textContent: 'Another Section' },
]

const depths = normalizeHeadingDepths(items)
// Returns: [1, 2, 2]
// The h4 is adjusted to be at the same depth as a properly nested h3
```

算法：

1. 重新设定所有级别，使最小级别变为 1（根级别）
2. 对每个标题，查找最近的、级别更小的前置标题
3. 如果找到，则将其嵌套在该父标题下（父标题深度 + 1）
4. 如果没有找到，则将其视为根级项目（深度 = 1）

## 完整示例

以下是一个集成所有组件的完整示例：

```tsx
import { useEditor, EditorContent, EditorContext } from '@tiptap/react'
import { StarterKit } from '@tiptap/starter-kit'
import { Heading } from '@tiptap/extension-heading'
import { TableOfContents } from '@tiptap/extension-table-of-contents'
import { TocProvider, useToc } from '@/components/tiptap-node/toc-node/context/toc-context'
import { TocNode, TocSidebar, TocShowTitleButton } from '@/components/tiptap-node/toc-node'

import '@/components/tiptap-node/toc-node/toc-node.scss'
import '@/components/tiptap-node/toc-node/ui/toc-sidebar/toc-sidebar.scss'

function EditorComponent() {
  const { setTocContent } = useToc()

  const editor = useEditor({
    extensions: [
      StarterKit,
      Heading.configure({
        levels: [1, 2, 3, 4, 5, 6],
      }),
      TableOfContents.configure({
        getIndex: (headingNode) => headingNode.attrs.id,
        onUpdate: (content) => {
          setTocContent(content)
        },
      }),
      TocNode.configure({
        topOffset: 80,
        maxShowCount: 20,
        showTitle: true,
      }),
    ],
    content: `
      <h1 id="introduction">Introduction</h1>
      <p>Welcome to this comprehensive document about table of contents...</p>
      <h2 id="getting-started">Getting Started</h2>
      <p>Let's begin by installing the required packages...</p>
      <h3 id="installation">Installation</h3>
      <p>Run the following command to install...</p>
      <h3 id="configuration">Configuration</h3>
      <p>Configure your editor with these options...</p>
      <h2 id="usage">Usage</h2>
      <p>Here's how to use the TOC components...</p>
      <h3 id="inline-toc">Inline TOC Node</h3>
      <p>Insert a TOC node directly in your document...</p>
      <h3 id="sidebar-toc">Sidebar TOC</h3>
      <p>Add a floating sidebar for navigation...</p>
      <h2 id="advanced">Advanced Features</h2>
      <p>Explore advanced functionality...</p>
    `,
  })

  return (
    <EditorContext.Provider value={{ editor }}>
      <div className="editor-wrapper">
        {/* Toolbar */}
        <div className="toolbar">
          <button
            onClick={() => editor?.commands.insertTocNode()}
            disabled={!editor?.can().insertTocNode()}
          >
            Insert TOC
          </button>
          <TocShowTitleButton editor={editor} text="Toggle Title" hideWhenUnavailable={true} />
        </div>

        {/* Editor with Sidebar */}
        <div className="editor-content-wrapper">
          <EditorContent editor={editor} className="editor-content" />
          <TocSidebar maxShowCount={20} topOffset={80} className="editor-toc-sidebar" />
        </div>
      </div>
    </EditorContext.Provider>
  )
}

export default function App() {
  return (
    <TocProvider>
      <EditorComponent />
    </TocProvider>
  )
}
```

```scss

  padding-left: calc(var(--toc-depth, 1) * 1rem);

.toc-sidebar-item {
  // Adjust for sidebar (depth 1 = no indent)
  padding-left: calc((var(--toc-depth, 1) - 1) * 0.75rem);

  // Optional: Add visual indicator for depth

    content: '';
    display: inline-block;
    width: calc(var(--toc-depth, 1) * 4px);
    height: 2px;
    background: currentColor;
    margin-right: 0.5rem;
    opacity: 0.3;
  }
}
```
