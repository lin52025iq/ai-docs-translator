## 安装

你可以通过 Tiptap CLI 添加此节点组件：

```bash
npx @tiptap/cli@latest add blockquote-node
```

## 用法

BlockquoteNode 主要是一个样式组件，可改善编辑器中引用块的显示效果。要使用它，只需将其添加到项目中，并确保使用 Tiptap 的 Blockquote 扩展。

```tsx
import { useEditor, EditorContent } from '@tiptap/react'
import { StarterKit } from '@tiptap/starter-kit'

import '@/components/tiptap-node/paragraph-node/paragraph-node.scss'
import '@/components/tiptap-node/blockquote-node/blockquote-node.scss'

export default function EditorWithBlockquote() {
  const editor = useEditor({
    immediatelyRender: false,
    extensions: [StarterKit],
    content: `
      <h2>Blockquote Example</h2>
      <blockquote>
        This is a blockquote. It can contain <strong>bold text</strong>, <em>italic text</em>.
      </blockquote>
    `,
  })

  return <EditorContent editor={editor} />
}
```

## 功能

- 引用块的语法高亮样式
- 支持深色模式
- 恰当的间距和边距
- 使用等宽字体提升可读性
