## 安装

可以通过 Tiptap CLI 添加此基础组件

```bash
npx @tiptap/cli@latest add toolbar
```

## 使用方法

```tsx
import { Toolbar, ToolbarGroup, ToolbarSeparator } from '@/components/tiptap-ui-primitive/toolbar'
import { Button } from '@/components/tiptap-ui-primitive/button'
import { BoldIcon } from '@/components/tiptap-icons/bold-icon'
import { ItalicIcon } from '@/components/tiptap-icons/italic-icon'
import { Spacer } from '@/components/tiptap-ui-primitive/spacer'

export default function MyComponent() {
  return (
    <Toolbar variant="fixed">
      <ToolbarGroup>
        <Button data-style="ghost">
          <BoldIcon className="tiptap-button-icon" />
        </Button>
        <Button data-style="ghost">
          <ItalicIcon className="tiptap-button-icon" />
        </Button>
      </ToolbarGroup>

      <ToolbarSeparator />

      <ToolbarGroup>
        <Button data-style="ghost">Format</Button>
      </ToolbarGroup>

      <Spacer />

      <ToolbarGroup>
        <Button data-style="primary">Save</Button>
      </ToolbarGroup>
    </Toolbar>
  )
}
```

## 属性

### Toolbar

| 名称      | 类型                  | 默认值    | 说明             |
| --------- | --------------------- | --------- | ---------------- |
| variant   | 'fixed' \| 'floating' | 'fixed'   | 工具栏样式变体   |
| data-plain | boolean               | undefined | 是否使用简洁样式 |

### ToolbarSeparator

| 名称        | 类型                       | 默认值     | 说明       |
| ----------- | -------------------------- | ---------- | ---------- |
| orientation | 'horizontal' \| 'vertical' | 'vertical' | 分隔符方向 |

## 键盘行为

工具栏采用水平焦点依次移动模式。禁用的控件会被跳过，包括工具栏打开期间其禁用状态发生变化的控件。

| 按键                      | 行为                                             |
| ------------------------- | ------------------------------------------------ |
| `ArrowLeft`, `ArrowRight` | 在可用控件之间移动，并在两端循环。               |
| `Home`, `End`             | 移至第一个或最后一个可用控件。                   |
| `Enter`                   | 激活当前聚焦的控件。                             |
| `Space`                   | 按照浏览器的标准行为激活聚焦的原生按钮。         |
| `Tab`, `Shift+Tab`        | 离开工具栏，而不是在其控件之间循环切换。         |

工具栏不会拦截 `Escape`；所属的浮动元素或菜单可以处理此按键。
