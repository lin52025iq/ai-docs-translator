Menu 是一个基于 Ariakit 构建的强大菜单组件，支持分层导航、搜索、筛选和完整的键盘无障碍操作。非常适合用于命令面板、下拉菜单和复杂的导航系统。

<CodeDemo isScrollable src="https://template.tiptap.dev/preview/tiptap-ui-primitive/menu" />

## 安装

你可以通过 Tiptap CLI 添加此基础组件

```bash
npx @tiptap/cli@latest add menu
```

## 用法

```tsx
import {
  Menu,
  MenuContent,
  MenuItem,
  MenuGroup,
  MenuGroupLabel,
  MenuButton,
  MenuButtonArrow,
  useComboboxValueState,
} from '@/components/tiptap-ui-primitive/menu'
import { Button } from '@/components/tiptap-ui-primitive/button'
import { ComboboxList } from '@/components/tiptap-ui-primitive/combobox'

export default function MyComponent() {
  const [searchValue] = useComboboxValueState()

  return (
    <Menu trigger={<Button>Open Menu</Button>}>
      <MenuContent>
        <ComboboxList>
          <MenuGroup>
            <MenuGroupLabel>Actions</MenuGroupLabel>
            <MenuItem
              onClick={() => console.log('Cut')}
              render={<Button data-style="ghost">Cut</Button>}
            />
            <MenuItem
              onClick={() => console.log('Copy')}
              render={<Button data-style="ghost">Copy</Button>}
            />
            <MenuItem
              onClick={() => console.log('Paste')}
              render={<Button data-style="ghost">Paste</Button>}
            />
          </MenuGroup>
        </ComboboxList>
      </MenuContent>
    </Menu>
  )
}
```

## 组件

### Menu

负责处理状态管理和上下文的根菜单提供器。

| 名称           | 类型                         | 默认值 | 说明                                     |
| -------------- | ---------------------------- | ------- | ------------------------------------------- |
| trigger        | `React.ReactNode`            | -       | 用于触发菜单的元素              |
| value          | `string`                     | -       | 当前搜索值（用于可搜索菜单） |
| onOpenChange   | `(open: boolean) => void`    | -       | 菜单打开状态变化时调用的回调       |
| onValueChange  | `(value: string) => void`    | -       | 搜索值变化时调用的回调          |
| onValuesChange | `(values: string[]) => void` | -       | 多选时调用的回调                |
| open           | `boolean`                    | -       | 受控的打开状态                       |

### MenuContent

用于容纳菜单项，并负责定位和样式设置。

| 名称           | 类型                                                      | 默认值 | 说明                         |
| -------------- | --------------------------------------------------------- | ------- | ----------------------------------- |
| onClickOutside | `(event: MouseEvent \| TouchEvent \| FocusEvent) => void` | -       | 在菜单外部点击时调用的回调 |

### MenuItem

可单独选择的菜单项。

| 名称         | 类型                 | 默认值 | 说明                             |
| ------------ | -------------------- | ------- | --------------------------------------- |
| group        | `string`             | -       | 菜单项所属组的标识符           |
| name         | `string`             | -       | 菜单项的名称标识符            |
| parentGroup  | `string`             | -       | 父级组的标识符                 |
| preventClose | `boolean`            | false   | 选中时阻止菜单关闭 |
| render       | `React.ReactElement` | -       | 自定义渲染元素                   |

## Hooks

### useComboboxValueState

用于访问和更新可搜索菜单中搜索值的 Hook。

```tsx
const [searchValue, setSearchValue] = useComboboxValueState()
```

**返回值：** `readonly [string, (value: string) => void]`

### useMenuPlacement

用于获取当前菜单定位方向的 Hook。

```tsx
const side = useMenuPlacement()
```

**返回值：** `string` - 当前方向（"top"、"bottom"、"left"、"right"）

### useMenuItemClick

用于处理菜单项点击，并可选择阻止菜单关闭的 Hook。

```tsx
const handleClick = useMenuItemClick(menu, preventClose)
```

**参数：**

- `menu?: Ariakit.MenuStore` - 菜单存储实例
- `preventClose?: boolean` - 是否阻止菜单关闭

## 筛选与搜索

Menu 组件提供强大的筛选功能：

### filterMenuItems

根据搜索条件筛选菜单项的实用函数。

```tsx
import { filterMenuItems } from '@/components/tiptap-ui-primitive/menu'

const filteredItems = filterMenuItems({ items: menuItems, label: 'Actions' }, searchValue)
```

### filterMenuGroups

筛选整个菜单组的实用函数。

```tsx
import { filterMenuGroups } from '@/components/tiptap-ui-primitive/menu'

const filteredGroups = filterMenuGroups(menuGroups, searchValue)
```
