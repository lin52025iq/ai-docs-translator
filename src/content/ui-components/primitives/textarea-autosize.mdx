这是一个基于 `react-textarea-autosize` 构建的自动调整大小文本区域组件，可根据内容自动调整高度，并内置服务端渲染兼容性和流畅的过渡效果。

## 安装

你可以通过 Tiptap CLI 添加此基础组件：

```bash
npx @tiptap/cli@latest add textarea-autosize
```

## 用法

```tsx
import { TextareaAutosize } from '@/components/tiptap-ui-primitive/textarea-autosize'

export default function MyComponent() {
  const [value, setValue] = React.useState('')

  return (
    <div>
      {/* 基本的自动调整大小文本区域 */}
      <TextareaAutosize
        value={value}
        onChange={(e) => setValue(e.target.value)}
        placeholder="开始输入……我会随着内容增长！"
      />

      {/* 设置最小行数和最大行数的文本区域 */}
      <TextareaAutosize minRows={3} maxRows={8} placeholder="最少 3 行，最多 8 行" />

      {/* 自定义调整大小行为的文本区域 */}
      <TextareaAutosize
        minRows={2}
        maxRows={10}
        cacheMeasurements={true}
        placeholder="缓存测量结果以提升性能"
      />
    </div>
  )
}
```

## 属性

### TextareaAutosize

基于 `react-textarea-autosize` 构建，并额外支持 SSR。

| 名称     | 类型                           | 默认值   | 描述         |
| -------- | ------------------------------ | -------- | ------------ |
| minRows  | `number`                       | 1        | 最小行数     |
| maxRows  | `number`                       | Infinity | 最大行数     |
| value    | `string`                       | -        | 受控值       |
| onChange | `(event: ChangeEvent) => void` | -        | 变更事件处理器 |

## 依赖项

- **react-textarea-autosize**：提供自动调整大小功能的底层库
- **use-isomorphic-layout-effect**：用于实现 SSR 兼容布局副作用的自定义 Hook
