## 安装

你可以通过 Tiptap CLI 添加此基础组件。

```bash
npx @tiptap/cli@latest add button
```

## 用法

```tsx
import { Button } from '@/components/tiptap-ui-primitive/button'
import { BoldIcon } from '@/components/tiptap-icons/bold-icon'

export default function MyComponent() {
  return (
    <Button
      data-style="ghost"
      data-active-state="on"
      tooltip="Bold"
      shortcutKeys="Ctrl+B"
      onClick={() => console.log('Bold clicked')}
    >
      <BoldIcon className="tiptap-button-icon" />
      <span className="tiptap-button-text">Bold</span>
    </Button>
  )
}
```

## 属性

### Button

| 名称              | 类型                            | 默认值    | 说明                                           |
| ----------------- | ------------------------------- | --------- | ---------------------------------------------- |
| variant           | 'ghost' \| 'primary' \| 'check' | undefined | 视觉样式，或 `check` 功能变体                   |
| size              | 'small' \| 'default' \| 'large' | undefined | 按钮尺寸                                       |
| tooltip           | ReactNode                       | undefined | 工具提示中显示的内容                           |
| shortcutKeys      | string                          | undefined | 工具提示中显示的键盘快捷键                     |
| showTooltip       | boolean                         | true      | 设置了 `tooltip` 时，是否渲染工具提示容器       |
| data-style        | string                          | undefined | 按钮样式；提供 `variant` 时由其设置             |
| data-active-state | 'on' \| 'off'                   | undefined | 按钮激活状态                                   |
| data-size         | string                          | undefined | 按钮尺寸；提供 `size` 时由其设置                |
| data-appearance   | string                          | undefined | 按钮外观                                       |
| data-disabled     | boolean                         | undefined | 视觉上的禁用状态                               |

按钮会将其他所有 `ButtonHTMLAttributes<HTMLButtonElement>` 属性转发给底层元素。

### Check 变体

`variant="check"` 会渲染复选框样式的切换按钮：一行全宽布局，左侧为标签，右侧为勾选指示器。它默认使用小尺寸的 ghost 样式，提供 `role="checkbox"`，并自行渲染指示器，因此你只需提供标签和状态。

通过 `aria-checked` 控制状态。该属性默认为 `false`，也接受值 `"mixed"`：

```tsx
import { useState } from 'react'
import { Button } from '@/components/tiptap-ui-primitive/button'
import { CaseSensitiveIcon } from '@/components/tiptap-icons/case-sensitive-icon'

export default function MatchCaseOption() {
  const [matchCase, setMatchCase] = useState(false)

  return (
    <Button
      variant="check"
      aria-checked={matchCase}
      onClick={() => setMatchCase((current) => !current)}
    >
      <CaseSensitiveIcon className="tiptap-button-icon" />
      <span className="tiptap-button-text">区分大小写</span>
    </Button>
  )
}
```

此变体会在元素上设置 `data-variant="check"`，并将指示器渲染为 `.tiptap-button-check`，因此两者都可用于样式设置。其颜色来自 `button-colors.scss` 中的 `--tt-button-check-*` 自定义属性，并会安装 `check-icon` 组件。
