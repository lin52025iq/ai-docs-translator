## 许可证和源代码

Tiptap [UI 组件](/ui-components/components/overview)遵循其所基于的[编辑器扩展](/editor/extensions/overview)的相同许可证。

- 如果扩展是开源的（例如 Bold、Heading 或 Image），对应的 UI 组件也采用 MIT 许可证。
- 你可以自由查看源代码、复制代码，并按自己的需要进行定制。

部分组件是为付费的 **Tiptap 功能**构建的，例如评论或版本历史记录。

- 这些组件**不是**开源的。
- 大多数组件包含依赖 Tiptap 后端服务的前端逻辑。
- 使用这些组件需要订阅或试用 Tiptap Cloud。

无论组件属于哪种类型（免费或连接云服务），你都可以查看其源代码，并根据自己的使用场景进行调整。

<Callout title="Tiptap Cloud 功能" variant="hint">
  我们将从开源组件开始。Tiptap Cloud 功能对应的组件将逐步推出。
</Callout>

## 如何安装组件

Tiptap UI 组件不会以 npm 包的形式发布。[CLI](/ui-components/getting-started/cli) 会将组件复制到你的项目中，作为由你拥有并可编辑的源文件：

```bash
npx @tiptap/cli@latest add <component>
```

每个组件还会自动引入其依赖的其他组件、hooks、图标、库和样式。因此，已安装组件的导入路径（例如 `@/components/tiptap-node/image-node/image-node-extension`）会指向你自己代码库中的文件，而不是 `node_modules` 中的模块。若要获取这些页面上的演示所用的全部内容，请使用上述命令安装对应组件或模板；每个组件页面都会在 **引用的组件** 下列出其引用的文件。

## 设计默认值

组件采用朴素的设计风格，能够自然融入你的设计。它们使用中性的样式：颜色简洁、间距基础，不带强烈的视觉倾向。你可以直接使用，也可以根据品牌风格进行定制。

所有组件的设计一致且协调，因此同时使用多个组件时，无需额外调整，它们也能很好地搭配在一起。

- 无需复杂的覆盖规则或 `!important` 技巧
- 直接编辑代码即可，因为这些组件本就旨在供你分支或扩展

## 组件与基础元素

你可以在 Tiptap 编辑器中集成 UI 元素，打造出色的编辑体验。该库提供了不同类型的构建模块：**组件**、**节点组件**和**基础元素**。

### 组件

现成的、针对特定功能的 React 组件，例如标题下拉菜单。每个 UI 组件通常都与一个 Tiptap 扩展配套使用（例如，**ListButton** 依赖于列表相关扩展），并使用 React hooks 与编辑器状态交互。

- **与扩展配合使用**：要使用某个组件（例如 `HeadingDropdownMenu`），请确保在编辑器中启用了对应的 Tiptap 扩展（例如 `@tiptap/extension-heading`）。
- **利用 hooks**：许多组件会在内部使用 hooks（例如 `useTiptapEditor` 或 `useFloatingElement`），以便与编辑器状态同步、处理定位或管理键盘导航。你也可以在自己的自定义组件中使用这些 hooks。
- **易于定制**：这些组件默认采用简约样式，能够融入你的设计。你可以完全覆盖或扩展它们。每个组件的源代码都可公开查看，你可以直接编辑，无需使用 `!important` 技巧。

### 基础元素

低级 UI 元素，例如 `Button`、`DropdownMenu`、`Popover` 和 `Spacer`。它们是许多 UI 组件的基础，负责处理无障碍功能和基本行为。你可以组合这些基础元素来创建自己的编辑器控件，或进一步定制现有组件。
