### 添加样式

组件样式使用 SCSS 编写。使用 Tiptap CLI 安装组件或模板时，SCSS 编译器（`sass` 或 `sass-embedded`）会自动安装。如果你选择手动设置，则需要手动安装。

<Callout title="样式会自动添加" variant="info">
  安装第一个 Tiptap UI 组件时，CLI 会自动将所需的{' '}
  <code>.scss</code> 导入语句注入项目的全局样式表。大多数情况下，{' '}
  <strong>无需手动设置</strong>。
</Callout>

<Callout title="Bun 项目会自动将 SCSS 转换为 CSS" variant="warning">
如果你使用 <strong>Bun</strong>，CLI 会在安装时将所有 <code>.scss</code> 文件转换为 <code>.css</code> 文件，并相应地更新导入语句。项目将使用：

```css
@import './styles/_variables.css';
@import './styles/_keyframe-animations.css';
```

</Callout>

#### 样式导入位置

CLI 会将以下导入语句注入全局样式表：

```css
@import '<path-to-styles>/_variables.scss';
@import '<path-to-styles>/_keyframe-animations.scss';
```

如果你使用自定义入口样式表，请确保其中包含这些导入语句。

#### 特定框架的设置

以下是 CLI 为各框架添加全局样式表导入语句的位置。

#### Next.js（App Router）

注入到以下文件之一：

- `app/globals.css`
- `src/app/globals.css`

文件：`app/globals.css` 或 `src/app/globals.css`

```css
@import '<path-to-styles>/_variables.scss';
@import '<path-to-styles>/_keyframe-animations.scss';
```

#### Vite + React

注入到：

- `src/index.css`

文件：`src/index.css`

```css
@import '<path-to-styles>/_variables.scss';
@import '<path-to-styles>/_keyframe-animations.scss';
```

具体路径可能会因项目结构而略有不同。

#### Astro

注入到全局样式表，通常是：

- `src/styles/global.css`，或你指定为全局样式表的文件

文件：`src/styles/global.css`（或你的自定义入口文件）

```css
@import '<path-to-styles>/_variables.scss';
@import '<path-to-styles>/_keyframe-animations.scss';
```

#### Laravel（Vite）

注入到：

- `resources/css/app.css`

文件：`resources/css/app.css`

```css
@import '<path-to-styles>/_variables.scss';
@import '<path-to-styles>/_keyframe-animations.scss';
```

#### React Router（原生 React）

注入到：

- `src/index.css`

文件：`src/index.css`

```css
@import '<path-to-styles>/_variables.scss';
@import '<path-to-styles>/_keyframe-animations.scss';
```
