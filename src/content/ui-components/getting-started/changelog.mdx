# 更新日志

本文件将记录此项目的所有重要变更。

## [2026-08-01]

### 新增

- **搜索和替换**：新增开源的搜索和替换面板，支持防抖实时高亮、从 1 开始的结果计数、循环导航、区分大小写和全字匹配选项、带示例模式的正则表达式搜索、可控的面板位置和打开状态、替换及全部替换操作，以及 `Mod+F`、方向键和 `Enter` 快捷键。在结果间切换时只更新高亮，因此编辑器选区和工具栏状态会保持原样。运行 `npx @tiptap/cli@latest add search-and-replace` 即可安装。
- **按钮**：新增可复用的 `check` 变体，这是一种复选框样式的切换按钮，会提供 `role="checkbox"`、自身的勾选指示器，并在小尺寸下默认使用 ghost 样式。通过 `aria-checked` 控制其状态，该属性也接受 `mixed`。
- **简单编辑器模板**：模板现已内置搜索和替换功能，包含工具栏触发按钮和停靠在工具栏下方的面板。

### 修复

- **工具栏焦点循环**：现在只有当焦点已位于工具栏内时，工具栏才会将焦点恢复到其中的项目，因此从工具栏打开的面板和弹出框可以保留它们所请求的焦点。
- **链接弹出框**：`autoOpenOnLinkActive` 现在还要求编辑器处于聚焦状态，因此在程序化更改选区（例如通过搜索面板进行的更改）后，即使链接处于激活状态，也不会再打开弹出框。

现有安装可运行 `npx @tiptap/cli@latest add button toolbar link-popover -o` 来更新已变更的组件。如果你在 2026-07-31（即本条目发布的前一天）安装了搜索和替换面板，请将 `search-and-replace` 也加入列表，以获取结果导航行为。`-o` 标志会覆盖已安装的组件文件，因此请先检查本地自定义内容。

## [2026-07-24]

### 修复

- **Image Node Pro**：修复了周边文档编辑后图像选区过期的问题，阻止原生光标导航进入隐藏标题，并增强了 Chromium、Firefox 和 WebKit 中对重复点击、标题生命周期、删除、调整大小及只读状态切换的处理。
- **Image Node Pro HTML**：保留了无标题和带标题图像的已配置 HTML 属性，规范化有效的图像尺寸，一致地应用 `allowBase64`，并防止多个图像组成的 figure 被合并为单个图像节点。
- **图像浮动工具栏**：在点击图像后刷新由选区驱动的可见状态，使工具栏在图像已选中时也能可靠地重新打开。

### 变更

- **Image Node Pro 键盘和撤销行为**：新增可预测的方向键导航、对标题边界处 `Enter`、`Backspace`、`Delete` 和 `Escape` 的处理、逐步全选，以及图像删除和调整大小各自独立的撤销边界。
- **工具栏键盘导航**：新增水平焦点循环、循环方向键导航、使用 `Home` 和 `End` 导航至首项或末项、禁用控件跟踪，以及正常的 `Tab` 和 `Shift+Tab` 退出行为。
- **删除节点按钮**：保留由扩展处理的 Backspace 行为，仅在共享删除操作成功后阻止浏览器默认行为，并将节点删除隔离为独立的撤销步骤。

现有安装可运行 `npx @tiptap/cli@latest add image-node-pro floating-element toolbar -o`，更新整套已复制的源文件。`-o` 标志会覆盖已安装的组件文件，因此请先检查本地自定义内容。

## [2026-07-09]

### 新增

- **表格节点**：支持 Pages 扩展。当编辑器注册了 Pages 扩展时，表格现在会按行跨页拆分，同时保留列宽、合并单元格和边框；跨分页符的 rowspan 单元格会继续延伸，而超大单元格则会变为可滚动，以保持分页稳定。无需配置；未启用 Pages 时，行为保持不变。

### 修复

- **表格选区叠层**：`cellMenu` 属性现在必须传入稳定的组件引用。传入内联箭头函数会导致菜单在每次渲染时都获得新的组件身份，从而重新挂载其子树，并可能抛出“Maximum update depth exceeded”错误。请在模块作用域中定义单元格菜单（或对其进行记忆化）；叠层和单元格菜单也会避免冗余更新菜单打开状态。
- **编辑器生命周期**：增强了 `comment`、`text-align` 和 `undo-redo` 组件及 `tiptap-utils` 对已销毁或已卸载编辑器的处理；新增 `isDestroyed`/已挂载视图检查，并在调用 `editor.can()` 时加入错误处理，以防止在销毁过程中发生异常。

## [2026-03-26]

### 新增

- **TOC**：新增支持，可为目录（TOC）节点预览查找最近的可滚动父元素。

### 变更

- **TOC**：优化目录（TOC）中的标题组织方式，提升性能和可读性。

## [2026-03-25]

### 新增

- **缩进支持**：为编辑器新增 `indent` 和 `outdent` 命令，允许用户调整块级内容的缩进级别。目前此功能仅适用于类 Notion 模板。

## [2026-02-19]

### 变更

- **AI 菜单**：为 `<AiMenu>` 新增 `anchorToSelection` 属性，可将菜单锚定到当前文本选区，并使菜单占满编辑器宽度。

## [2026-02-10]

### 修复

- **工具栏按钮**：修复了按钮可见性逻辑的问题：未设置 `hideWhenUnavailable` 时，按钮会被错误地隐藏。现在按钮默认始终显示；只有当 `hideWhenUnavailable={true}` 且所需扩展或 schema 不可用时，才会隐藏。
- **链接弹出框**：在 `setMark("link")` 外添加错误处理，以防编辑器处于某些状态时出现未捕获异常。
- **转换为下拉菜单**：补上缺失的 `!editor.isEditable` 检查，防止在只读编辑器中显示下拉菜单。
- **标题节点**：修复 `margin-top` 的移除逻辑，使其能正确作用于首个标题以及前面有 ProseMirror widget（例如装饰或节点视图）的标题。
- **颜色高亮**：将 `toggleMark("highlight", { color })` 改为正确的 `toggleHighlight({ color })` 命令，以确保切换行为正确。

### 变更

- **`-c` 标志的 CLI 身份验证检查**：CLI 现在会在使用 `-c`（组件）标志时验证 `.npmrc` 身份验证，避免未通过身份验证的用户遇到无提示失败。
- **自动生成 `scss.d.ts`**：通过 CLI 安装包含 SCSS 文件的组件时，现在会自动创建 SCSS 类型声明。
- **嵌套列表样式**：新增对深层嵌套列表（最多 8 层）的样式循环：
  - 有序列表：`decimal → lower-alpha → lower-roman → decimal → ...`
  - 无序列表：`disc → circle → square → disc → ...`
- **颜色高亮的 `useColorValue` 属性**：新增支持使用原始十六进制颜色值代替 CSS 变量，使高亮功能可在不支持 CSS 自定义属性的环境中使用。
- **标题下拉菜单**：新增对自定义 `children` 属性的支持，允许使用方覆盖默认的图标加箭头渲染方式。
- **行内图像**：段落中的图像现在会以 `inline-block` 方式显示。

### 移除

- **评论页面演示**：移除了 `/comments` 和 `/preview/templates/comments` 路由及所有相关组件。
