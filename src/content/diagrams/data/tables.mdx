## 快速入门

启用 [`chart.linkTables`](/diagrams/data/tables#following-a-table) 后，将选区放在表格中并调用：

```ts
editor.commands.insertLinkedChart({ type: 'bar' })
```

## 跟随表格

若要让图表和示意图跟随表格，请启用选项
[`chart.linkTables`](/diagrams/api-reference/options#linktables)。此选项会为每个表格添加 `chartTableId` 属性，
以便图表之后能重新找到对应表格。未启用时，使用表格调用 `insertLinkedChart`、`linkChartToTable` 和
`setChartLayout` 会返回 `false`。

跟随表格的图表会与表格编辑一起纳入同一个撤销步骤，因此一次撤销即可同时还原两者。表格可以位于文档中的任意位置，而 `listTables()` 会列出图表可跟随的表格。图表数据通过
[数据源](/diagrams/data/sources) `document-table` 从表格中读取。

## 表格的读取方式

`insertLinkedChart`、`linkChartToTable` 和 `updateLinkedTable` 接受 `header` 和 `range`。

| 选项             | 类型                                 | 说明                                                                                              |
| ---------------- | ------------------------------------ | ------------------------------------------------------------------------------------------------- |
| `header`         | `'auto' \| 'first-row' \| 'none'`    | 列名所在位置。默认为 `'auto'`                                                                      |
| `range.rows`     | `{ from?, to? }` 或其数组            | 要读取的数据行，从表头下方的第 0 行开始计数                                                        |
| `range.columns`  | `(number \| { from?, to? })[]`       | 要读取的列，从第 0 列开始计数，例如 `[0, { from: 2 }]`。读取的第一列用于命名类别                    |

| `header`      | 列名所在位置                                                                                     |
| ------------- | ------------------------------------------------------------------------------------------------ |
| `'auto'`      | 第一行；当该行由表头单元格组成，或除第一列外不含数字时使用                                        |
| `'first-row'` | 第一行，无论其中包含什么                                                                         |
| `'none'`      | 每一行都是数据。列名使用默认值                                                                   |

- 范围的起止位置均包含在内。
- 负数从末尾开始计数。`-1` 表示最后一行，因此 `{ to: -2 }` 会排除汇总行。
- 空行不计入。
- 多个范围按给定顺序读取。
- 重复指定的行或列只读取一次。
- 未指定 `range` 时，表格中的单元格选区就是范围：读取选区覆盖的行和列，并将表格的第一列作为标签。
- `header` 和 `range` 会存储在图表的数据源地址中，并应用于之后对表格的每次编辑。

## 命令

可将表格转换为图表，或将图表转换回表格；也可以将图表转换为保留其数据的图片：

### convertTableToChart

将选区中的表格替换为使用其数据生成的图表。

```ts
editor.commands.convertTableToChart({ type: 'bar' })
```

| 选项   | 类型        | 说明                                      |
| ------ | ----------- | ----------------------------------------- |
| `type` | `ChartType` | 图表类型。默认为 `chart.defaultType`       |
| `pos`  | `number`    | 表格中的位置。默认为当前选区               |

没有表格时返回 `false`。

### convertChartToTable

将图表替换为包含其数据的普通表格。

```ts
editor.commands.convertChartToTable()
```

| 选项  | 类型     | 说明                     |
| ----- | -------- | ------------------------ |
| `pos` | `number` | 图表的位置。默认为选中的图表 |

schema 中没有表格时返回 `false`。

### insertLinkedChart

插入一个跟随表格的图表。

```ts
editor.commands.insertLinkedChart({
  table: editor.storage.diagrams.listTables()[0].pos,
  type: 'bar',
  columns: { label: 'Month', series: ['Retail'] },
})

// 不带表头且排除最后一行的表格
editor.commands.insertLinkedChart({
  table,
  header: 'none',
  range: { rows: { to: -2 } },
  columns: { label: 0, series: [2] },
})

// 仅读取第一行、最后两行，以及第 0、3、4 列
editor.commands.insertLinkedChart({
  table,
  range: { rows: [{ to: 0 }, { from: -2 }], columns: [0, { from: 3, to: 4 }] },
})
```

| 选项      | 类型                                                          | 说明                                                                  |
| --------- | ------------------------------------------------------------- | --------------------------------------------------------------------- |
| `type`    | `ChartType`                                                   | 图表类型。默认为 `chart.defaultType`                                  |
| `table`   | `number`                                                      | 表格在 `listTables()` 中对应的位置。默认为选区所在的表格               |
| `columns` | `{ label?: string \| number, series?: (string \| number)[] }` | 按表头单元格中的文本或从 0 开始的位置指定列                           |
| `header`  | `'auto' \| 'first-row' \| 'none'`                             | 参见[表格的读取方式](/diagrams/data/tables#how-the-table-is-read)     |
| `range`   | `{ rows?, columns? }`                                         | 参见[表格的读取方式](/diagrams/data/tables#how-the-table-is-read)     |
| `title`   | `string`                                                      | 图表标题                                                              |
| `below`   | `boolean`                                                     | `false` 会将图表放在表格上方。默认为 `true`                           |

`columns.label` 用于命名类别，`columns.series` 指定要绘制的列。未指定 `columns` 时，第一列作为标签，其余列都会绘制。对于不带表头的表格，也可以按位置指定列；位置按 `range` 读取的列计数。

图表处于链接状态时，其数据为只读。

没有表格、未启用 `chart.linkTables`，或指定的列名不在表头中、列位置不在表格范围内时，返回 `false`。

### updateLinkedTable

更改图表或示意图读取其所跟随表格的方式，并重新读取表格。

```ts
editor.commands.updateLinkedTable({ header: 'none' })
editor.commands.updateLinkedTable({ header: undefined, range: { rows: { from: 1 } } })
```

| 选项     | 类型                              | 说明                                                                  |
| -------- | --------------------------------- | --------------------------------------------------------------------- |
| `header` | `'auto' \| 'first-row' \| 'none'` | 参见[表格的读取方式](/diagrams/data/tables#how-the-table-is-read)     |
| `range`  | `{ rows?, columns? }`             | 参见[表格的读取方式](/diagrams/data/tables#how-the-table-is-read)     |
| `pos`    | `number`                          | 图表或示意图的位置。默认为当前选中的对象                              |

- 将某个键设为 `undefined` 会使其恢复默认值。
- 未提供某个键时，会保留其当前值。
- 图表的标签列和系列列会保持不变：只要原列仍在读取范围内，就继续使用该列；否则改用相同位置的列。因此，更换表头后，这些列设置仍会保留。
- `listCharts()` 会通过 `tableRead` 报告当前值，`listDiagrams()` 则会在 `link` 中报告这些值。

图表或示意图未跟随表格，或其表格已不存在时，返回 `false`。对于示意图，如果它引用的列已不存在，也会返回 `false`。

### setChartLayout

决定图表的表格是否位于文档中，以及是否显示图表。

```ts
editor.commands.setChartLayout({ layout: 'with-table' })
```

| 选项     | 类型                                 | 说明                           |
| -------- | ------------------------------------ | ------------------------------ |
| `layout` | `'chart' \| 'with-table' \| 'table'` | 文档中显示的内容，见下文       |
| `pos`    | `number`                             | 图表的位置。默认为选中的图表   |

| `layout`       | 文档中显示的内容                                                                                             |
| -------------- | ------------------------------------------------------------------------------------------------------------ |
| `'chart'`      | 图表。图表包含自己的数据，不跟随任何表格                                                                     |
| `'with-table'` | 图表及其所跟随的表格。两者各自保留在文档中的原位置                                                           |
| `'table'`      | 仅显示表格。图表仍在文档中，隐藏在表格正下方，并继续跟随该表格                                               |

命令的行为取决于图表当前的布局：

| 当前布局       | 目标布局       | 行为                                                                                                                         |
| -------------- | -------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `'chart'`      | `'with-table'` | 在图表正上方插入包含图表数据的表格。图表随之跟随该表格，类似 `insertLinkedChart`                                      |
| `'chart'`      | `'table'`      | 插入该表格，并将图表隐藏在表格正下方                                                                                         |
| `'with-table'` | `'table'`      | 隐藏图表。如果图表位于其他位置，则将其移至所跟随表格的正下方                                                                   |
| `'table'`      | `'with-table'` | 在图表原位置重新显示图表                                                                                                     |
| 任意布局       | `'chart'`      | 保留表格上次提供的数据，并取消跟随任何表格。移除该表格，除非仍有其他图表或示意图跟随它                                     |

- 图表和表格的位置不属于布局的一部分。移动任一节点即可移动它。
- 标题、渲染器及其余规格都会保留，即使图表处于隐藏状态也不例外。切换到其他布局后，图表会按原样重新显示。
- 此更改只需一个撤销步骤即可还原。
- 隐藏的图表不会包含在 `exportAll` 和 `exportDocx` 中。在 HTML 中，其 `<figure>` 带有 `hidden` 属性。
- 删除或移动表格会重新显示图表。
- 若只保留表格而不保留图表，请使用 `convertChartToTable`。
- `listCharts()` 会通过 `layout` 报告当前布局。

如果操作完成后图表具有指定布局，则返回 `true`，即使它原本就已是该布局。以下情况会返回 `false`：

- 设置为 `'with-table'` 或 `'table'` 时，schema 中没有表格节点，或未启用 `chart.linkTables`。
- 设置为 `'with-table'` 或 `'table'` 时，图表未跟随表格，而是链接到其他只读数据源，例如只读 CSV URL。
- 设置为 `'table'` 时，表格正下方已经有另一个隐藏图表，或该图表无法放置在此处。

### linkChartToTable

让图表跟随文档中已有的表格，无论该表格位于何处。

```ts
const [table] = editor.storage.diagrams.listTables()
if (table) editor.commands.linkChartToTable({ table: table.pos })
```

| 选项       | 类型                              | 说明                                                                  |
| ---------- | --------------------------------- | --------------------------------------------------------------------- |
| `table`    | `number`                          | 表格的位置，与 `listTables()` 报告的位置一致                         |
| `pos`      | `number`                          | 图表的位置。默认为选中的图表                                          |
| `readOnly` | `boolean`                         | `false` 会使图表在链接期间仍可编辑数据。默认为 `true`                 |
| `header`   | `'auto' \| 'first-row' \| 'none'` | 与 [`insertLinkedChart`](/diagrams/data/tables#insertlinkedchart) 相同 |
| `range`    | `{ rows?, columns? }`             | 与 [`insertLinkedChart`](/diagrams/data/tables#insertlinkedchart) 相同 |

如果表格没有 id，则会为其分配一个。图表会立即读取表格数据。

操作后，图表的布局为 `'with-table'`，与 `setChartLayout({ layout: 'with-table' })` 相同。两者的区别在于，`linkChartToTable` 会用已有表格的数据替换图表数据，而 `setChartLayout` 会根据图表数据创建一个新表格，并将其放在图表正上方。

未启用 `chart.linkTables`、指定位置上没有表格，或表格是以表格形式显示的 Quick Input 时，返回 `false`。
