```txt
Month | Online | Retail

```

## 类型行

仅包含图表类型（例如 `bar`、`pie`，或通过 `chartTypes` 注册的类型）的第一行称为类型行。大小写和前后空格都不影响识别。

- **没有类型行时**，图表采用传给命令的类型，例如 `insertChartFrom` 的 `type` 选项。如果没有指定，则采用 `chart.defaultType`。
- **类型行优先于** `type` 选项，因此仅凭文本就能确定图表类型。
- **类型行会保留在文本中。** `editChartAsText` 会将其写回为第一行，而 `setDiagramInputType` 会重写该行。

## 如何读取各行

| 规则       | 读取方式                                                                                 |
| ---------- | ---------------------------------------------------------------------------------------- |
| 分隔符     | 逗号、分号、竖线和制表符，通过 `chart.delimiters` 选项设置                                 |
| 表头       | 如果第一行除第一列外不包含数字，则将其视为表头                                           |
| `{H}`      | 放在单元格前，将该单元格标记为表头单元格                                                 |
| 标签       | 第一列包含标签                                                                           |
| `{L}`      | 放在单元格前，将该单元格标记为标签                                                       |
| 空单元格   | 表示缺失值                                                                               |
| 非数字     | 非数字单元格会保留为文本                                                                 |
| 引号       | 用双引号括起来的单元格可以包含分隔符                                                     |
| 列表       | 开头的项目符号或数字（`•`、`-`、`*`、`1.`）会被忽略，因此粘贴的列表会按行读取             |
| 单列数据   | 不含任何分隔符的行会被视为一个值序列，并依次标记为 1、2、3 等                             |

因此，`Month | Sales` 会被视为表头，而 `Jan | 2` 会被视为数据行。对于包含数字的表头，例如 `Region | 2025 | 2026`，请在各单元格前加上 `{H}`。

### 由哪个分隔符拆分

包含有效分隔符的第一行决定整个文本使用的分隔符。如果某行包含多个分隔符，制表符、竖线或分号的优先级高于逗号。因此，`Jan ; 1,5` 会按分号拆分，并将 `1,5` 读取为数字。

### 数字

- 当 `decimalSeparator: 'auto'` 时，`1.5` 会被读取为 1.5；如果分隔符不是逗号，`1,5` 也会被读取为 1.5。
- 将 `decimalSeparator` 设为 `'.'` 或 `','`，即可指定小数分隔符。
- 不会识别千位分隔符。

### 错误

引号打开后未闭合会导致所在行报错，例如：`第 3 行：引号已打开但未闭合。`

## 在代码中

`insertChartFrom`、`updateChartFrom` 和[面向 AI 模型的工具](/diagrams/guides/ai)都使用相同的文本：

```ts
editor.commands.insertChartFrom({ format: 'chart-syntax', content: 'bar\nJan | 42\nFeb | 48' })
```

`editor.storage.diagrams.read({ format: 'chart-syntax' })` 会使用输入时采用的分隔符，以图表语法写出图表数据：

| 分隔符   | 写出形式          |
| -------- | ----------------- |
| 竖线     | `\|`              |
| 制表符   | 裸制表符           |
| 其他分隔符 | 分隔符后加一个空格 |
