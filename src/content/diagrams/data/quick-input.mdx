## 快速开始

行数据会生成图表。第一行可以指定图表类型：

```txt
bar
Month | Online | Retail
Jan   | 42     | 30
Feb   | 48     | 28
```

Mermaid 内容会生成图示：

```txt
flowchart LR
  idea[Idea] --> draft[Draft]
```

要确认，请按 Escape，或在最后一行为空时按 Enter。编辑[图表](/diagrams/charts/editing)或[图示](/diagrams/flow-diagrams/editing)中的文本时，Escape 的作用正好相反：它会关闭输入框并丢弃更改。

## 文本会转换成什么

| 快速输入中的文本                                  | 转换结果 | 说明                                                              |
| ---------------------------------------------- | -------- | ----------------------------------------------------------------- |
| 行数据，可选地带有 `bar` 之类的类型行             | 图表     | [编写图表](/diagrams/data/quick-input#writing-a-chart)             |
| Mermaid 图表，例如 `pie` 或 `sankey`             | 图表     | Mermaid 图表，类型和标题取自其标头                                |
| 其他任何 Mermaid 图示                            | 图示     | [编写图示](/diagrams/data/quick-input#writing-a-diagram)           |
| 粘贴的 draw.io XML 或 BPMN XML                  | 图示     | 其源内容                                                          |

在行数据（例如 `Dogs, 3`）上方的 `pie` 是类型行，不是 Mermaid。快速输入读取文本时，遵循与[粘贴](/diagrams/data/pasting#how-pasted-text-is-read)相同的规则。

快速输入是一个名为 `diagramInput` 的节点。你可以用下面的命令通过自定义工具栏来控制它。

## 编写图表

图表使用 [Chart 语法](/diagrams/data/chart-syntax)编写：行数据，以及可用于指定类型的第一行。该页面介绍了标头规则、默认类型、分隔符、数字和引号。

## 编写图示

图示使用各自的语言编写。快速输入会保留你输入的文本。

- **Mermaid**，例如 `flowchart LR`，并包含一行 `A --> B`。第一行指定图示类型。参见[图示](/diagrams/flow-diagrams/overview)。
- **draw.io XML 或 BPMN XML**，从绘制图示的工具中复制并粘贴。参见 [draw.io](/diagrams/renderers/drawio) 和 [BPMN](/diagrams/renderers/bpmn)。

## 重新转换为文本

`editChartAsText` 和 `editDiagramAsText` 会再次在快速输入中打开图表或 Mermaid 图示。如果更改第一行，图表会变成另一种图表类型，或变成图示。

## 快速输入中的按键

在 macOS 上，Mod 表示 Cmd；在其他系统上表示 Ctrl。

| 按键              | 在快速输入中的作用                                                |
| ----------------- | ----------------------------------------------------------------- |
| Enter             | 换行。在最后一行为空时，生成图表或图示                            |
| Shift-Enter       | 换行，即使最后一行为空也一样                                      |
| Mod-Enter, Escape | 生成图表或图示                                                    |
| Mod-Shift-A       | 选中快速输入中的所有内容                                          |
| Mod-A             | 仍然会选中整个文档                                                |
| Backspace         | 快速输入为空时，将其移除                                          |

如果第一行只有类型名称（例如 `pie` 或 `bar`），按 Enter 会开始新的一行，而类型名称仍保留为类型行。在单独的类型行下方，快速输入会显示该类型的示例行，直到你输入一行数据。

### 快速输入关闭时

- **将选区移出快速输入**会生成图表或图示，效果与确认相同。
- **空的快速输入**会变成空段落。
- **无法读取的文本**会使快速输入保持打开状态，并且 `confirmDiagramInput` 会返回 `false`。

## 代码块中的 Mod-Enter

用于确认快速输入的按键也可以将代码块转换为图表或图示。

- [Mermaid 图表源代码](/diagrams/charts/overview#importmermaidchart)，例如 `pie` 或 `sankey-beta`，会变成图表，效果与 `convertCodeBlockToChart` 相同。
- 其他 Mermaid 源代码会变成图示，效果与 `convertCodeBlockToDiagram` 相同。
- 对于其他类型的代码块，该按键仍执行原有操作。在 Tiptap 中，也就是离开代码块。

规范中带有 `code: true` 的任何节点都视为代码块。使用 [`codeBlockShortcut`](/diagrams/api-reference/options#codeblockshortcut) 选项可以设置其他按键；若不需要按键，则设为 `false`。

## 命令

### confirmDiagramInput

将打开的快速输入或以表格形式显示的快速输入转换为图表或图示。

```ts
editor.commands.confirmDiagramInput()
```

| 选项  | 类型     | 描述                                         |
| ----- | -------- | -------------------------------------------- |
| `pos` | `number` | 输入内容中的一个位置。默认为当前选区的位置   |

`detectDiagramInput` 会决定文本的转换结果。如果 schema 中包含 `flowDiagram` 节点，Mermaid 图示源代码、draw.io XML 或 BPMN XML 会转换为图示。

没有打开的输入框，或文本无法读取时，返回 `false`。

### setDiagramInputType

设置打开的输入框将生成的图表类型。如果已有类型行，会将其改写为新类型。

```ts
editor.commands.setDiagramInputType('bar')
```

| 参数   | 类型        | 描述                                               |
| ------ | ----------- | -------------------------------------------------- |
| `type` | `ChartType` | 内置图表类型，或通过 `chartTypes` 注册的类型       |

类型未知或没有打开的输入框时，返回 `false`。

### setDiagramInputView

在文本字段和可填写的表格之间切换打开的输入框视图。切换时会保留已输入的内容。

```ts
editor.commands.setDiagramInputView('table')
```

| 参数   | 类型                        | 描述                                           |
| ------ | --------------------------- | ---------------------------------------------- |
| `view` | `'chart-syntax' \| 'table'` | `'chart-syntax'` 表示文本字段，`'table'` 表示表格 |

表格视图要求 schema 中包含表格节点。

没有打开的输入框，或 schema 中不包含表格却指定了 `'table'` 时，返回 `false`。

### setDiagramInputDelimiter

设置打开的快速输入使用指定的分隔符拆分文本，而不是自动检测分隔符。

```ts
editor.commands.setDiagramInputDelimiter(';')
```

| 参数        | 类型             | 描述                                                   |
| ----------- | ---------------- | ------------------------------------------------------ |
| `delimiter` | `string \| null` | 已配置的 `delimiters` 之一。`null` 表示恢复自动检测   |

该设置在快速输入保持打开期间有效。生成的图表会记住用于拆分文本的分隔符。

没有打开的快速输入，或指定的分隔符未配置时，返回 `false`。

### editChartAsText

将图表转换为快速输入，并以 Chart 语法显示其数据。

```ts
editor.commands.editChartAsText()
```

| 选项  | 类型     | 描述                                   |
| ----- | -------- | -------------------------------------- |
| `pos` | `number` | 图表的位置。默认为选中的图表           |

确认快速输入后，图表会恢复其 spec、Renderer 和 Data Source。

关联数据源为只读的图表会返回 `false`。

### editDiagramAsText

将 Mermaid 图示转换为包含其源内容的快速输入。

```ts
editor.commands.editDiagramAsText()
```

| 选项  | 类型     | 描述                                   |
| ----- | -------- | -------------------------------------- |
| `pos` | `number` | 图示的位置。默认为选中的图示           |

确认后，文本会像其他文本一样进行读取。`bar` 之类的类型行下方如果有行数据，就会生成图表。对于保留原有类型（例如流程图）的图示，其标题、描述、视图和节点位置都会恢复。

draw.io 和 BPMN 图示，以及由表格绘制的图示，都会返回 `false`。

### editChartAsTable

将图表转换为包含其数据的表格，以便编辑数据。

```ts
editor.commands.editChartAsTable()
```

| 选项  | 类型     | 描述                                   |
| ----- | -------- | -------------------------------------- |
| `pos` | `number` | 图表的位置。默认为选中的图表           |

将选区移出表格后，表格会重新变成图表。

对于只读图表，或 schema 中不包含表格时，返回 `false`。
