每列都有一个 `id`、一个 `label` 和一个 `role`：`'label'` 表示用于命名各行的列，`'series'` 表示数值列。每一行都是一个单元格列表，每列对应一个单元格。

## 绘制哪些列

图表数据会保留所有列。图表规范中的 `encoding` 字段是图表的设置，其中保存了图表在编辑器和所有导出内容中要绘制的列的 id：

| 字段       | 说明                                                                                                 |
| ---------- | ---------------------------------------------------------------------------------------------------- |
| `label`    | 用于命名各行的列                                                                                     |
| `series`   | 要绘制的列，按此顺序排列                                                                             |
| `seriesIn` | `'rows'` 会交换行和列，参见 [`setChartSeriesIn`](/diagrams/data/overview#setchartseriesin)            |

- 未设置 `label` 时，具有 `'label'` 角色的列用于命名各行。
- 未设置 `series` 时，其他所有具有 `'series'` 角色的列都会绘制。
- 如果某个 id 不在数据中，则会被忽略，因此即使数据源重命名了列，图表仍可绘制。
- 如果 `series` 中没有任何 id 存在于数据中，则会绘制所有系列。
- 同步会替换所有列并保留 `encoding`，参见[数据源](/diagrams/data/sources#showing-only-some-columns)。

使用 [`updateChartSpec`](/diagrams/charts/appearance#updatechartspec) 或以下命令设置 `encoding`。

## 命令

### updateChartData

替换图表数据。

```ts
editor.commands.updateChartData({ data })
```

| 选项   | 类型        | 说明                                     |
| ------ | ----------- | ---------------------------------------- |
| `data` | `ChartData` | 新的图表数据                             |
| `pos`  | `number`    | 图表的位置。默认为当前选中的图表         |

当 `pos` 处或当前选中位置没有图表，或者图表关联的数据源为只读且新数据与当前数据不同时，返回 `false`。

### setChartLabelColumn

将某一列设为行名列。`encoding.series` 会设为图表类型可绘制的其他所有列。

```ts
editor.commands.setChartLabelColumn({ label: 'region' })
```

| 选项    | 类型     | 说明                                     |
| ------- | -------- | ---------------------------------------- |
| `label` | `string` | 用于命名各行的列的 id                    |
| `pos`   | `number` | 图表的位置。默认为当前选中的图表         |

对于大多数类型，可绘制的列是具有 `'series'` 角色的列。对于使用 `matrix` 形状读取行的类型（例如 `matrix` 图表类型），则会使用所有列；参见[注册自定义图表类型](/diagrams/renderers/custom-chart-types#fields-of-a-chart-type)。选择第一列时，会从 `encoding` 中移除 `label` 和 `series`。`encoding.seriesIn` 始终保留。

如果数据中不存在指定的列，则返回 `false`。

### setChartSeriesIn

决定数据中的每列还是每行代表一个系列。一个系列是一组图表要绘制的数值，例如一条线或一种颜色的柱形。

```ts
editor.commands.setChartSeriesIn({ seriesIn: 'rows' })
```

| 选项       | 类型                  | 说明                                                |
| ---------- | --------------------- | --------------------------------------------------- |
| `seriesIn` | `'columns' \| 'rows'` | 默认值为 `'columns'`。`'rows'` 会交换二者          |
| `pos`      | `number`              | 图表的位置。默认为当前选中的图表                    |

设为 `'rows'` 时，每一行会成为一个以其标签命名的系列，每个绘制的列则会成为一个类别。以这份数据的柱形图为例：

```txt
Month | Visitors
Jan   | 120
Feb   | 150
Mar   | 170
```

| `seriesIn`  | 类别          | 每个类别中的柱形       |
| ----------- | ------------- | ---------------------- |
| `'columns'` | Jan, Feb, Mar | 一根柱形：Visitors     |
| `'rows'`    | Visitors      | 三根柱形：Jan, Feb, Mar |

只有 `spec.encoding.seriesIn` 会改变。`label` 和 `series` 会保留。交换后，`spec.series` 的样式会以行标签为键，`spec.palette` 则会按系列的绘制顺序为其配色。

### updateChartFrom

根据已注册格式的内容替换数据和规范。以图表语法、图表 JSON 或 Mermaid 格式读取图表，修改文本后再写回：

<CodeDemo isPro viewer view="preview" path="/Extensions/DiagramsFormats" />

```ts
editor.commands.updateChartFrom({ format: 'chart-syntax', content: 'Jan | 2\nFeb | 3' })
```

| 选项      | 类型     | 说明                                     |
| --------- | -------- | ---------------------------------------- |
| `format`  | `string` | 已注册格式的 id                          |
| `content` | `string` | 该格式的内容                             |
| `pos`     | `number` | 图表的位置。默认为当前选中的图表         |

如果无法读取内容，或图表为只读，则返回 `false`。

### updateChartFromGrid

根据字符串网格替换数据。

```ts
editor.commands.updateChartFromGrid({ grid })
```

| 选项  | 类型         | 说明                                     |
| ----- | ------------ | ---------------------------------------- |
| `grid` | `string[][]` | 第 0 行为表头，第 0 列为标签             |
| `pos` | `number`     | 图表的位置。默认为当前选中的图表         |

可将它与 [`readGrid`](/diagrams/api-reference/storage#reading-a-charts-data) 搭配使用，以便通过输入字段编辑数据。粘贴到[当前选中图表](/diagrams/data/pasting#onto-a-selected-chart)上的电子表格行也会通过此命令处理。

在与 `updateChartData` 相同的情况下返回 `false`。

### updateChartFromTable

根据表格 JSON 替换数据。

```ts
editor.commands.updateChartFromTable({ table })
```

| 选项    | 类型       | 说明                                     |
| ------- | ---------- | ---------------------------------------- |
| `table` | `JSONNode` | 以 JSON 表示的表格节点                   |
| `pos`   | `number`   | 图表的位置。默认为当前选中的图表         |

可将它与 [`readTable`](/diagrams/api-reference/storage#reading-a-charts-data) 搭配使用；该方法会以表格 JSON 的形式返回图表数据。

在与 `updateChartData` 相同的情况下返回 `false`。
