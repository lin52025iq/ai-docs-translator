图表会存储**地址**（用于说明数据来源）和**快照**（最近一次读取的数据副本）。图表根据快照绘制，因此即使离线、导出后，或无法访问数据源的用户也能看到图表。

## 快速开始

```ts
editor.commands.linkChartSource({
  provider: 'url-csv',
  address: { url: 'https://example.com/sales.csv' },
  readOnly: true,
})
```

## 文档中存储的内容

| 属性       | 说明                                                            |
| ---------- | --------------------------------------------------------------- |
| `source`   | `{ provider, address, mode, readOnly }`                         |
| `syncedAt` | 最近一次从数据源获取数据的 ISO 时间，或 `null`                   |

`listCharts()` 会返回这两项。

## 已连接或已分离

`mode` 的值为 `'linked'` 或 `'detached'`，表示图表是否跟随其数据源。

**已连接**（`mode: 'linked'`）。`linkChartSource`、`syncChartData`、`requestSync`、`relinkChartSource`，以及通过 `subscribe` 推送变更的数据提供程序（参见[编写数据提供程序](/diagrams/data/sources#writing-a-provider)）会从数据源读取快照。在两次同步之间，图表显示最近的快照。以 `readOnly: false` 连接的图表也可以手动编辑。

**已分离**（`mode: 'detached'`）。`detachChartSource` 会停止跟随数据源，同时保留快照和地址，因此你可以再次编辑数据。`relinkChartSource` 会重新跟随数据源，并用数据源返回的内容替换当前数据。

## 只读

`readOnly` 是一个独立标志，仅在图表处于连接状态时生效。设为 `readOnly: true` 时，更改数据的命令会返回 `false`，因此下一次同步不会覆盖本地编辑。图表规范仍可编辑。分离时该标志会保持原值，重新连接后再次生效。

## 仅显示部分列

同步会替换所有列。若只想显示其中一部分，请使用 `updateChartSpec` 设置 [`encoding`](/diagrams/data/overview#which-columns-are-drawn)。此设置在每次同步后都会保留。

```ts
editor.commands.updateChartSpec({ spec: { encoding: { label: 'region', series: ['revenue'] } } })
```

## 图表何时同步

同步会从数据源读取数据，并将新快照写入图表。

- **快照不会加入撤销历史记录**，因此撤销操作不会连同你的编辑一起撤销同步。
- **每次同步都会设置 `syncedAt`**，即使数据没有变化也是如此。因此，文档会记录最近一次检查数据的时间。在版本比较中，这会被视为更改，参见[版本](/diagrams/guides/versions)。
- **无法读取数据源时**，图表会保留当前快照。扩展会将错误以及 `{ provider, address }` 传递给 `onSourceError` 选项。
- **每个执行同步的客户端都需要注册相应的数据提供程序。**未注册该程序的客户端会显示快照，但无法读取数据源。

若要同步所有从 URL 读取数据的图表：

```ts
await editor.storage.diagrams.requestSync({ provider: 'url-csv', address: { url } })
```

扩展不会按计划自动同步。你的应用可以自行安排同步，例如使用 `setInterval`。请遵守所读取服务的限制。

## 内置数据提供程序

| 数据提供程序  | 地址                      | 读取内容                                                     |
| ------------- | ------------------------- | ------------------------------------------------------------ |
| `url-csv`     | `{ url }` 或 URL 字符串   | CSV，通过 `fetch` 选项读取                                   |
| `url-json`    | `{ url }` 或 URL 字符串   | JSON：对象数组、数组的数组或图表数据                         |
| `document-table` | `{ tableId }`          | 同一文档中的表格                                             |

### 读取 URL

URL 必须是绝对 URL，且使用 `http:` 或 `https:` 协议。如果设置了 [`allowSourceUrl`](/diagrams/api-reference/options#allowsourceurl) 选项，URL 还必须通过该选项的检查。服务器必须允许你的应用网页读取文件（CORS）。已发布的 Google Sheet 就符合这一条件。

以下情况下读取会失败，图表会保留当前数据：

- 地址不是符合上述要求的 URL。
- 服务器返回错误状态码。
- 请求被阻止。
- 返回的是 HTML 页面，而非文件。许多主机在无法识别某个地址时，会返回状态码 200 的 HTML 页面。

### 读取表格

跟随文档中表格的图表使用 `document-table`，参见[表格](/diagrams/data/tables)。

## 编写数据提供程序

<CodeDemo isPro viewer view="preview" path="/Extensions/DiagramsCustomSource" />

数据提供程序是一个包含 `id` 和 `read` 函数的对象。将其传入 `sources` 选项，或在运行时通过 `editor.storage.diagrams.registerSource(provider)` 添加：

```ts
import type { ChartSourceProvider } from '@tiptap-pro/extension-diagrams'

const salesApi: ChartSourceProvider = {
  id: 'sales-api',
  read: async (address, { fetch }) => {
    const { region } = address as { region: string }
    const response = await fetch(`/api/sales?region=${encodeURIComponent(region)}`)
    const rows: { month: string; total: number }[] = await response.json()
    return {
      columns: [
        { id: 'month', label: 'Month', role: 'label' },
        { id: 'total', label: 'Total', role: 'series' },
      ],
      rows: rows.map((row) => [row.month, row.total]),
    }
  },
  describe: (address) => `Sales, ${(address as { region: string }).region}`,
}
```

| 成员                                    | 必需 | 说明                                                                                                   |
| --------------------------------------- | ---- | ------------------------------------------------------------------------------------------------------ |
| `id`                                    | 是   | 图表存储为 `provider` 的值                                                                             |
| `read(address, context)`                | 是   | 返回图表数据或其 Promise。抛出错误以报告问题                                                           |
| `subscribe(address, onChange, context)` | 否   | 适用于会推送变更的数据源：每当状态更新时调用 `onChange(data)`，并返回一个用于停止订阅的函数             |
| `describe(address)`                     | 否   | 在用户界面中显示的标签                                                                                 |

- `context` 包含 `fetch`、`decimalSeparator` 和 `editor`。如果应用设置了 `allowSourceUrl`，其中还会包含 `allowUrl`。
- 若要报告错误，请抛出带有易于理解的错误消息的 `ChartSourceError`。
- 扩展会为每个已连接的地址保留一个订阅，并将每次变更写入所有连接到该地址的图表。

文档会存储地址，并与所有打开该文档的人共享。切勿在其中放入凭据。需要密钥或令牌的数据提供程序，应在创建时从你的应用获取这些信息。

[Google Sheets、Excel 和 Airtable](/diagrams/guides/spreadsheets)分别提供了适用于这些服务的数据提供程序，并介绍了各服务所需的设置。

## 命令

### linkChartSource

将图表连接到数据源。

```ts
editor.commands.linkChartSource({
  provider: 'url-csv',
  address: { url: 'https://example.com/sales.csv' },
  readOnly: true,
})
```

| 选项       | 类型        | 说明                                                                                         |
| ---------- | ----------- | -------------------------------------------------------------------------------------------- |
| `provider` | `string`    | 已注册数据提供程序的 ID，例如 `'url-csv'`                                                     |
| `address`  | `unknown`   | 数据提供程序读取数据的位置，格式须符合其要求                                                 |
| `readOnly` | `boolean`   | 连接期间，数据只能通过数据源更改。默认值为 `false`                                           |
| `data`     | `ChartData` | 初始快照。若未提供，则会读取数据源，并在数据到达时写入快照                                   |
| `pos`      | `number`    | 图表的位置。默认为当前选中的图表                                                             |

数据提供程序未知时返回 `false`。

### syncChartData

写入新快照。

```ts
editor.commands.syncChartData({
  source: { provider: 'url-csv', address: { url: 'https://example.com/sales.csv' } },
})
```

| 选项     | 类型                    | 说明                                                           |
| -------- | ----------------------- | -------------------------------------------------------------- |
| `data`   | `ChartData`             | 新快照。若未提供，则先读取数据源                               |
| `source` | `{ provider, address }` | 将数据写入所有连接到该数据源的图表。若未提供，则只写入一个图表 |
| `pos`    | `number`                | 图表的位置。默认为当前选中的图表                               |

没有匹配的图表，或图表没有数据源且未提供 `data` 时，返回 `false`。

### detachChartSource

停止跟随数据源，同时保留快照和地址。

```ts
editor.commands.detachChartSource()
```

| 选项 | 类型     | 说明                         |
| ---- | -------- | ---------------------------- |
| `pos` | `number` | 图表的位置。默认为当前选中的图表 |

图表没有数据源时返回 `false`。

### relinkChartSource

重新跟随并读取数据源。

```ts
editor.commands.relinkChartSource()
```

| 选项 | 类型     | 说明                         |
| ---- | -------- | ---------------------------- |
| `pos` | `number` | 图表的位置。默认为当前选中的图表 |

图表没有数据源时返回 `false`。
