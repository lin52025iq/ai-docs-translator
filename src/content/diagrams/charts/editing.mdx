## 重命名文本

| 双击的文本                     | 写入该文本的命令及写入位置                         |
| ------------------------------ | -------------------------------------------------- |
| 标题                           | `updateChartSpec`，写入 `spec.title`               |
| 坐标轴标题                     | `updateChartAxis`，写入该坐标轴的 `title`          |
| 图例中的系列名称               | `updateChartData`，写入该列的表头                  |
| 分类标签或饼图扇区             | `updateChartData`，写入该行的标签单元格            |

**确认和取消。** 按 Enter，或将焦点移出文本字段，即可写入文本，并作为一步撤销操作处理。按 Escape 会关闭文本字段，不做任何更改。

**列 ID。** 重命名表头时，列会保留其 ID，因此 `spec.series` 仍会应用于该列。

**以行作为系列。** 当 `encoding.seriesIn: 'rows'` 时，系列名称是行的标签单元格，分类标签则是列标题。

**只读数据。** 对于链接到只读 Data Source 的图表，只有标题和坐标轴标题会打开文本字段。系列和分类来自数据源。

**支持此功能的渲染器。** 并非所有渲染器都支持此功能。
[图表中的文本](/diagrams/renderers/custom#text-in-the-chart)说明了哪些渲染器支持此功能。

**值标签。** 值轴上的数字不会被存储，因此双击这些数字不会打开任何内容。

## 未绘制图表时

`@tiptap-pro/extension-diagrams/core` 中的 `renameChartDataText` 可重命名 Chart Data 中的系列或分类。它会返回新的 Chart Data；如果目标不是该数据中的系列或分类，则返回 `null`。

```ts
import { parseChartSyntax, renameChartDataText } from '@tiptap-pro/extension-diagrams/core'

const { data } = parseChartSyntax('Month | Sales\nJan | 2\nFeb | 4')
const renamed = renameChartDataText({
  data,
  target: { kind: 'series', column: 'sales' },
  text: 'Revenue',
})
editor.commands.updateChartData({ data: renamed ?? data })
```
