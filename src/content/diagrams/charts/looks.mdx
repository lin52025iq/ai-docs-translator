## 快速开始

```ts
import { chartLook } from '@tiptap-pro/extension-diagrams'

const [first, second] = editor.storage.diagrams.listCharts()

// 将第一个图表的外观应用到第二个图表
const look = chartLook(first.spec, first.data)
editor.commands.applyChartLook({ look, pos: second.pos })

// 插入一个使用相同外观的新折线图
editor.commands.insertChart({ type: 'line', data: second.data, look })

// 模板还会包含图表类型
const template = chartLook(first.spec, first.data, { type: true })
editor.commands.insertChart({ data: second.data, look: template })
```

[`listCharts()`](/diagrams/api-reference/storage) 会返回文档中的所有图表。

## 外观包含的内容

`chartLook(spec, data, { references?, type? })` 会获取图表的外观，包括：

- `style`、`palette`、`background`、`border` 和 `legend`
- 网格线和坐标轴线
- 分类轴的标签布局
- 各数据系列的线条样式，按位置对应：第一个系列的样式会应用到第一个系列
- 参考线

标题、范围、步长和数据仍由各图表自身保留。

| 选项         | 类型      | 说明                                               |
| ------------ | --------- | -------------------------------------------------- |
| `references` | `boolean` | `false` 表示不包含参考线。默认为 `true`            |
| `type`       | `boolean` | `true` 表示同时获取图表类型。默认为 `false`        |

应用外观时，图表会保留外观未设置的所有字段。包含图表类型的外观可用作模板：应用该外观或基于它创建的图表都会变成相应类型。传递给 `insertChart` 的 `type` 优先于外观中的类型。

## 保存外观

外观是普通的 JSON。你的应用可以按用户或团队保存外观，并在之后传回。

`readChartLook(value)` 会像检查 Chart Spec 一样检查已保存的外观，并移除不属于外观的内容。`applyChartLook` 和 `insertChart` 会自动调用它。

应用外观会将其中的字段复制到图表中，因此即使没有保存的外观，文档也能保持完整。

## 外观与样式

[样式](/diagrams/guides/styling#styles)与外观不同。图表通过 id（`spec.style`）指定样式，而不是复制样式字段。更改已注册的样式后，所有指定了该样式的图表都会随之更改。

## 命令

### applyChartLook

为图表应用外观，该外观可以取自另一个图表，也可以是之前保存的外观。

```ts
editor.commands.applyChartLook({ look, pos: second.pos })
```

| 选项  | 类型        | 说明                                      |
| ----- | ----------- | ----------------------------------------- |
| `look` | `ChartLook` | 外观，可通过 `chartLook` 获取或使用已保存的外观 |
| `pos` | `number`    | 图表的位置。默认为当前选中的图表          |

如果 `pos` 处没有图表，或当前未选中任何图表，则返回 `false`。
