## 快速开始

```ts
editor.commands.updateChartSpec({ spec: { title: 'Revenue', border: true, caption: true } })
```

## 图表规范字段

| 字段          | 类型                          | 说明                                                                                                                                       |
| ------------- | ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `title`       | `string`                      | 显示在图表上方                                                                                                                           |
| `description` | `string`                      | 替代文本和无障碍说明                                                                                                               |
| `caption`     | `boolean`                     | 为 `true` 时，在图表下方显示说明文字                                                                                 |
| `legend`      | `ChartLegend`                 | `{ show, position }`。`show` 为 `boolean`，`position` 可为 `'top'`、`'right'`、`'bottom'` 或 `'left'`。未设置时，图例显示在底部 |
| `palette`     | `string[]`                    | 此图表各数据系列的颜色，使用 CSS 颜色值。未设置时，依次使用样式中的颜色、`--tt-chart-series-1` 及后续自定义属性    |
| `background`  | `string`                      | 图表背景的纯色 CSS 颜色值，例如十六进制、`rgb()`、`hsl()` 或命名颜色。未设置时使用 `--tt-chart-background`                           |
| `border`      | `boolean`                     | 为 `true` 时，使用 `--tt-chart-border-color` 为图表添加边框                                                                                              |
| `style`       | `string`                      | 已注册样式的 ID，例如 `'ocean'`。参见[样式](/diagrams/guides/styling#styles)                                                        |
| `stacked`     | `boolean`                     | 为 `true` 时，柱形和面积图会相互叠放，而不是并排显示                                                                          |
| `innerRadius` | `number`                      | 环形图中心孔洞的半径，占圆环半径的 `0` 到 `0.9`。默认值为 `0.55`                                                                           |
| `orientation` | `'vertical' \| 'horizontal'`  | `'horizontal'` 会将柱形横向显示。参见[横向柱形图](/diagrams/charts/appearance#horizontal-bars)                                    |
| `series`      | `Record<string, SeriesStyle>` | 按列 ID 设置折线图或面积图的数据系列线条样式。参见[数据系列线条样式](/diagrams/charts/appearance#series-line-styles)                       |
| `encoding`    | `ChartEncoding`               | `{ label?, series?, seriesIn? }`：指定要绘制的列。参见[要绘制哪些列](/diagrams/charts/appearance#which-columns-are-drawn)     |
| `size`        | `FigureSize`                  | `{ width, ratio, locked }`，参见 [`setDiagramSize`](/diagrams/guides/size-and-view#setdiagramsize)                                                 |
| `hidden`      | `boolean`                     | 仅显示图表所跟随的表格时，该值为 `true`。由 `setChartLayout` 设置。表格移除后，此字段也会移除                           |

`type` 和 `range`（仪表图的刻度）请参见[图表](/diagrams/charts/overview#chart-types)。`axes` 请参见
[坐标轴](/diagrams/charts/axes)，`references` 请参见[参考线和参考带](/diagrams/charts/references)。`renderer` 包含仅某个渲染器支持的选项，参见
[更换渲染器时](/diagrams/renderers/overview#when-the-renderer-changes)。

- `palette`、`background` 和 `border` 会覆盖 `style` 中的设置。
- 未知的 `style` ID 会被忽略。
- 未设置 `show` 的 `legend` 会显示。`legend` 未设置有效的 `position` 时，会显示在底部。
- `palette` 或 `background` 中不安全的 CSS 颜色值会被丢弃。可能会加载资源的值（例如 `url()`）不属于颜色。

## 横向柱形图

`spec.orientation: 'horizontal'` 会将柱形图或组合图中的柱形横向显示，类别沿左侧向下排列。未设置此项或设为 `'vertical'` 时，柱形会竖直显示。

```ts
editor.commands.updateChartSpec({ spec: { orientation: 'horizontal' } })
```

并非所有渲染器都支持横向柱形图。请参见 [ECharts](/diagrams/renderers/echarts#chart-types) 和 [D3](/diagrams/renderers/d3#chart-types) 支持的图表类型，以及 [Mermaid 的限制](/diagrams/renderers/mermaid#limits)。

其他图表类型会忽略 `orientation`，因此更改图表类型时可以保留此项设置。与倾斜显示的标签相比，较长的类别名称在横向柱形图上更易于阅读。

`spec.series` 按列 ID 设置折线图或面积图中各数据系列的绘制方式：
`{ [columnId]: { line?, width?, marker?, smooth? } }`。未单独设置的列会采用渲染器的默认值。

```ts
editor.commands.updateChartSpec({
  spec: { series: { forecast: { line: 'dashed', marker: 'none' } } },
})
```

| 字段     | 值                                                  |
| -------- | --------------------------------------------------- |
| `line`   | `'solid'`、`'dashed'` 或 `'dotted'`                 |
| `width`  | 描边宽度，单位为 CSS 像素，范围为 0.5 到 8。默认值为 2 |
| `marker` | 每个数据值处显示的标记：`'none'`、`'circle'` 或 `'square'`    |
| `smooth` | 为 `true` 时，在数据值之间绘制曲线             |

`updateChartSpec` 会整体替换 `series`。请传入所有需要保留的条目。

[ECharts](/diagrams/renderers/echarts#chart-types) 和 [D3](/diagrams/renderers/d3#chart-types) 渲染器会绘制所有字段。Mermaid 渲染器不支持带有 `series` 的折线图，参见其[限制](/diagrams/renderers/mermaid#limits)。
Word 在折线图中会绘制全部四种样式，在面积图边缘则不会绘制任何一种。

## 要绘制哪些列

`encoding` 按列 ID 指定图表要绘制的列。图表数据会保留所有列。参见[要绘制哪些列](/diagrams/data/overview#which-columns-are-drawn)。

## 外框的呈现位置

背景会应用于所有渲染器和所有导出格式。边框和说明文字会显示在编辑器、HTML 和 Word 文档中。导出为 SVG 或图像时，图表会像在编辑器中一样带有内边距、边框和说明文字。

## 选择渲染器

图表由已注册的渲染器之一绘制。可以使用 `setChartRenderer` 指定渲染器。否则，扩展会自动选择一个，参见[哪个渲染器负责绘制图表](/diagrams/renderers/overview#which-renderer-draws-a-chart)。更换渲染器只会改变绘制方式，不会影响图表数据或图表规范。

## 命令

### updateChartSpec

修改图表规范中的字段，并保留其余字段。将字段设为 `undefined` 会移除该字段。

```ts
editor.commands.updateChartSpec({ spec: { title: 'Revenue', stacked: undefined } })
```

| 选项   | 类型             | 说明                                          |
| ------ | ---------------- | ---------------------------------------------------- |
| `spec` | `ChartSpecPatch` | 要修改的字段                                 |
| `pos`  | `number`         | 图表的位置。默认为当前选中的图表 |

无效字段（例如无效的颜色值）会被丢弃。如果 `pos` 处没有图表，或未选中任何图表，则返回 `false`。

### setChartRenderer

设置用于绘制图表的渲染器。设为 `null` 则恢复默认值。

```ts
editor.commands.setChartRenderer({ renderer: 'd3' })
```

| 选项       | 类型             | 说明                                          |
| ---------- | ---------------- | ---------------------------------------------------- |
| `renderer` | `string \| null` | 已注册渲染器的 ID，或 `null`           |
| `pos`      | `number`         | 图表的位置。默认为当前选中的图表 |

如果 `pos` 处没有图表，或未选中任何图表，则返回 `false`。
