## 快速入门

```ts
editor.commands.insertFromText({ text: 'Month | Sales\nJan | 2\nFeb | 3' })
```

[`insertFromText`](/diagrams/data/pasting#insertfromtext) 会像粘贴文本一样读取文本，因此这些行会转换为图表。行的格式遵循[图表语法](/diagrams/data/chart-syntax)。

## 图表类型

图表将类型存储在 `spec.type` 中。大多数类型以相同方式读取图表数据。一列是标签列，通常是第一列：其中的单元格为各行命名，例如 `Jan` 和 `Feb`。其他每个数值列都是一个系列，可绘制为一条线、一组柱形或一组点。

最后一列说明图表在 [Word 文档](/diagrams/export#word)中的呈现方式：可在 Word 中重新设置样式的原生 Word 图表、图像或 Word 表格。

| 类型                      | 行的读取方式                                                                                                | 在 Word 文档中的形式 |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------- | ------------------ |
| `line`、`area`、`scatter` | 一列标签以及一个或多个系列                                                                            | Word 图表         |
| `bar`                     | 同上。`spec.orientation: 'horizontal'` 会将柱形横向排列                                           | Word 图表         |
| `combo`                   | 同上。请参阅[组合图表](/diagrams/charts/overview#combo-charts)                                             | Word 图表         |
| `radar`                   | 每行对应一条辐射线，从中心向外延伸，行标签作为其名称。每个系列对应一条闭合线             | Word 图表         |
| `pie`、`doughnut`         | 一列标签和一个系列，表示整体中的各部分                                                              | Word 图表         |
| `funnel`                  | 每个阶段一个标签和一个数值，按宽度从大到小排列                                                                    | 图像              |
| `gauge`                   | 一个数值。`spec.range: { min, max }` 设置其范围，默认值为 `0` 到 `100`                                    | 图像              |
| `treemap`、`tree`         | 标签以路径形式表示，每行一个数值。`Europe / Germany` 表示 Germany 位于 Europe 下方                            | 图像              |
| `sankey`、`network`       | 每行一条连接。标签列表示连接的起点，下一列表示终点，第三列表示权重 | 图像              |
| `matrix`                  | 网格中的文字，请参阅 [矩阵](/diagrams/charts/overview#matrix)                                                  | Word 表格         |

- 并非所有渲染器都能绘制所有类型。如果某个渲染器无法绘制某种类型，图表会交由下一个支持该类型的渲染器处理。请参阅[选择渲染器](/diagrams/charts/appearance#choosing-the-renderer)。
- 如果 Sankey 图中的连接会形成闭环，则会将其丢弃。
- 通过 [`chartTypes`](/diagrams/api-reference/options#charttypes) 选项注册的类型会被存储、提供给 AI 模型，并由任何列出该类型的渲染器绘制。
- 如果编辑器不认识某个类型，该类型会原样保留在文档中。

### 组合图表

组合图表将部分系列绘制为柱形，其他系列绘制为线条。可按系列通过列 ID 选择绘制方式：

| 字段                        | 值                                           |
| ---------------------------- | ------------------------------------------------ |
| `spec.series[columnId].as`   | `'bar'`（默认）或 `'line'`                    |
| `spec.series[columnId].axis` | `'right'` 会将系列放在第二个数值轴上 |

### 矩阵

`matrix` 是由文字组成的网格，例如 RACI 矩阵。标签列存放任务，其他每列代表一个角色，每个单元格存放一个字母。

```txt
Task   | Lead | Team | Board
Plan   | A    | R    | I
Build  | C    | R    |
```

每种不同的单元格文本都会从系列颜色中分配一种颜色。R、A、C 和 I 按此顺序优先。ECharts 渲染器可以绘制矩阵。矩阵不能写成 Mermaid。

## 图表的存储方式

图表的属性包含重新绘制图表所需的全部信息：

| 属性    | 内容                                                                                          |
| ------------ | ------------------------------------------------------------------------------------------------ |
| `data`       | 图表数据：`columns`（`id`、`label`、`role`，其中 `role` 为 `label` 或 `series`）以及 `rows`                  |
| `spec`       | 图表规范，请参阅[图表规范字段](/diagrams/charts/appearance#chart-spec-fields)               |
| `renderer`   | 为此图表选择的渲染器 ID；默认值为 `null`                          |
| `source`     | 读取数据所用的数据源；若无则为 `null`                                                |
| `delimiter`  | 输入数据时使用的分隔符，以便再次以文本形式编辑时数据外观保持不变 |
| `previewUrl` | 可选的图像 URL，会写入 HTML 输出                                               |

文档不会存储绘制出的图表、图表在屏幕上的绘制尺寸或其加载状态。你设置的尺寸会存储在 `spec.size` 中。

### 在 HTML 中

图表是一个 `<figure data-type="chart">`。其数据为 `<table>`，因此导出为 HTML 或 Markdown 时数字会保留，屏幕阅读器也可以读取。图表标题是 `<figcaption>`。图表规范和数据源以 JSON 格式存储在 `<figure>` 的 `data-tt-chart-*` 属性中，请参阅[数据属性](/diagrams/api-reference/selectors#data-attributes)。

## 命令

### insertChart

在当前选区或 `pos` 位置插入图表，并选中该图表。

```ts
editor.commands.insertChart({
  type: 'bar',
  data: {
    columns: [
      { id: 'month', label: 'Month', role: 'label' },
      { id: 'revenue', label: 'Revenue', role: 'series' },
    ],
    rows: [
      ['Jan', 120],
      ['Feb', 150],
    ],
  },
})
```

| 选项      | 类型                  | 说明                                                                                       |
| ----------- | --------------------- | ------------------------------------------------------------------------------------------------- |
| `data`      | `ChartData`           | 图表数据                                                                                    |
| `spec`      | `Partial<ChartSpec>`  | 图表规范。如果两者都设置了某个字段，则优先使用 `spec` 中的值                                           |
| `type`      | `ChartType`           | `spec.type` 的快捷设置                                                                          |
| `renderer`  | `string \| null`      | 用于绘制图表的渲染器 ID。`null` 表示使用默认渲染器                                      |
| `source`    | `ChartSource \| null` | 图表所依赖的数据源                                                                 |
| `delimiter` | `string \| null`      | 输入数据时使用的分隔符                                                             |
| `pos`       | `number`              | 插入位置。默认为当前选区                                              |
| `look`      | `ChartLook`           | 图表初始使用的已保存样式，请参阅 [`applyChartLook`](/diagrams/charts/looks#applychartlook) |

如果选区中有空段落，则会将其替换。如果选中了图表，新图表会插入到它后面。

### insertChartFrom

插入以已注册格式编写的图表。

```ts
editor.commands.insertChartFrom({
  format: 'chart-syntax',
  content: 'Month | Revenue\nJan | 120\nFeb | 150',
})
```

| 选项     | 类型             | 说明                                                     |
| ---------- | ---------------- | --------------------------------------------------------------- |
| `format`   | `string`         | `'chart-json'`、`'chart-syntax'`、`'mermaid'` 或你添加的格式 |
| `content`  | `string`         | 该格式的文本                                         |
| `type`     | `ChartType`      | 当内容未指定类型时使用的类型               |
| `renderer` | `string \| null` | 用于绘制图表的渲染器 ID                             |
| `pos`      | `number`         | 插入位置。默认为当前选区            |

如果无法读取内容，则返回 `false`。

### importMermaidChart

从 Mermaid 图表源码插入图表。

```ts
editor.commands.importMermaidChart({ source: 'pie\n  "Dogs" : 386\n  "Cats" : 85' })
```

| 选项   | 类型     | 说明                                          |
| -------- | -------- | ---------------------------------------------------- |
| `source` | `string` | Mermaid 源码                                   |
| `pos`    | `number` | 插入位置。默认为当前选区 |

Mermaid 的大多数图表类型会绘制为示意图。以下五种类型包含数值，因此会转换为数据可编辑的图表：

| 首行           | 图表类型      | 数据                                                         |
| -------------- | --------------- | ------------------------------------------------------------ |
| `pie`          | `pie`           | 每个扇区对应一行                                              |
| `xychart-beta` | `bar` 或 `line` | 每个 x 轴类别对应一行；每个柱形或线条对应一个系列          |
| `sankey-beta`  | `sankey`        | 每条流对应一行：来源、目标、数值                        |
| `radar-beta`   | `radar`         | 每个坐标轴对应一行，每条曲线对应一个系列。保留 `min` 和 `max` |
| `treemap-beta` | `treemap`       | 每个节点对应一行且包含数值；标签为路径，如 `A / B`     |

- 图表标题取自 `title`；对于 Sankey 图和树状图，则取自 frontmatter。
- Mermaid 用于设置图表颜色的内容（`classDef`、`showLegend`、`ticks`、`graticule`）不会保留。
- `toMermaidSource` 和 `mermaid` 格式可以将图表转换回 Mermaid 源码，支持的仍是上述五种类型。
- Mermaid 的饼图、雷达图和树状图不识别负号，因此无法显示小于零的数值。将这类图表转换回 Mermaid 时，负值饼图扇区或树状图节点会被省略，负值雷达图数值则会写为零。

粘贴 Mermaid 图表源码时会运行此命令，请参阅[粘贴](/diagrams/data/pasting#how-pasted-text-is-read)。

对于其他 Mermaid 示意图，此命令返回 `false`。

### convertCodeBlockToChart

将代码块替换为其[Mermaid 图表源码](/diagrams/charts/overview#importmermaidchart)所描述的图表。

```ts
if (editor.can().convertCodeBlockToChart()) editor.commands.convertCodeBlockToChart()
```

| 选项 | 类型     | 说明                                                 |
| ------ | -------- | ----------------------------------------------------------- |
| `pos`  | `number` | 代码块内的位置。默认为当前选区 |

其规范中包含 `code: true` 的任何节点都视为代码块。在代码块中按 Mod-Enter 也会运行此命令，请参阅[在代码块中按 Mod-Enter](/diagrams/data/quick-input#mod-enter-in-a-code-block)。

如果代码块包含其他内容，则返回 `false`。

### insertDiagramInput

在当前选区打开一个空的[快速输入](/diagrams/data/quick-input)，效果与输入[`触发符`](/diagrams/api-reference/options#trigger)相同。

```ts
editor.chain().focus().insertDiagramInput({ type: 'pie' }).run()
```

| 选项 | 类型        | 说明                                                                            |
| ------ | ----------- | -------------------------------------------------------------------------------------- |
| `type` | `ChartType` | 快速输入初始使用的图表类型。默认为 `chart.defaultType` 选项 |

如果 schema 中没有 `diagramInput` 节点，则返回 `false`。
