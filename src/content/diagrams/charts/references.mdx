## 快速开始

使用 `updateChartSpec` 设置参考线和区间带。新列表会替换旧列表，设为 `undefined` 则会将其移除。

```ts
editor.commands.updateChartSpec({
  spec: {
    references: [
      { value: 200, label: 'Target', color: '#dc2626' },
      { from: 80, to: 120, label: 'Corridor', color: '#16a34a' },
    ],
  },
})
```

## 字段

`spec.references` 中的每个条目都是一个 `ChartReference`：

| 字段         | 类型                              | 说明                                                                     |
| ------------ | --------------------------------- | ------------------------------------------------------------------------ |
| `value`      | `number`                          | 在此数值处绘制一条线。优先于 `from` 和 `to`                               |
| `from`, `to` | `number`                          | 绘制这两个数值之间的区间带，而不是使用 `value`                            |
| `label`      | `string`                          | 显示在线上方，或显示在区间带顶部内侧                                      |
| `labelAt`    | `'start' \| 'end'`                | 标签显示在分类轴的哪一端。默认值：`'end'`                                 |
| `color`      | `string`                          | CSS 颜色。区间带会使用该颜色的浅色调。未指定时使用主题的标签颜色           |
| `line`       | `'solid' \| 'dashed' \| 'dotted'` | 仅适用于线条。默认值：`'dashed'`                                          |
| `width`      | `number`                          | 仅适用于线条：0.5 到 4 CSS 像素。默认值：1.5                              |

如果条目既没有 `value`，`from` 和 `to` 也不同时存在且数值不同，该条目就会被丢弃。每张图表最多保留 20 个条目。

## 绘制方式

区间带绘制在数据系列后方。线条和所有标签都绘制在数据系列上方。对于带有 `background` 的图表，标签会带有与背景同色的描边，因此即使标签覆盖在柱形上也能清晰辨认。

如果参考值超出数据范围，数值轴会扩展以显示它。对于水平柱状图，参考线会竖直显示。在带有第二坐标轴的组合图中，参考线和区间带属于左侧坐标轴。

## 支持绘制的图表和渲染器

参考线和区间带适用于折线图、柱状图、面积图、散点图和组合图。它们可由 [ECharts](/diagrams/renderers/echarts#chart-types) 和 [D3](/diagrams/renderers/d3#chart-types) 渲染器绘制。Mermaid 渲染器不支持此类图表，详见其[限制](/diagrams/renderers/mermaid#limits)。

Word 图表不支持参考线，因此 `exportDocx` 会将图表导出为图像，并在备注中说明这一点。
