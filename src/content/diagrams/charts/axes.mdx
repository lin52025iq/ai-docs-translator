## 快速开始

```ts
editor.commands.updateChartAxis({ axis: 'y', changes: { step: 25 } })
editor.commands.updateChartAxis({ axis: 'x', changes: { labels: { angle: 45 } } })
```

## 坐标轴字段

`x` 是类别轴，`y` 是数值轴。即使条形横向排列，这一对应关系也不变。

| 字段         | 坐标轴 | 类型             | 说明                                                                                                                                   |
| ------------ | ------ | ---------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `title`      | 两者   | `string`         | 坐标轴标题                                                                                                                             |
| `min`, `max` | 两者   | `number`         | 数值轴的范围；对于 x 轴包含数值的散点图，也用于设置其 x 轴范围。未设置时由数据决定                                                     |
| `step`       | `y`    | `number`         | 两个刻度之间的间隔，也就是两条数值网格线之间的间隔。参见[刻度间隔](/diagrams/charts/axes#tick-step)                                     |
| `grid`       | 两者   | `ChartStroke`    | 绘图区中的网格线，分别对应每个类别（`x`）或数值（`y`）。参见[网格线和坐标轴线](/diagrams/charts/axes#grid-and-axis-lines)               |
| `line`       | 两者   | `ChartStroke`    | 坐标轴线本身                                                                                                                           |
| `labels`     | `x`    | `CategoryLabels` | 指定显示哪些类别标签以及标签的旋转角度。参见[类别标签](/diagrams/charts/axes#category-labels)                                          |

## 网格线和坐标轴线

`grid` 和 `line` 都是 `ChartStroke`，用于指定线条的绘制方式：

| 字段    | 类型                                          | 说明                                                                                                  |
| ------- | --------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| `line`  | `'none' \| 'solid' \| 'dashed' \| 'dotted'` | 线条的绘制方式。`'none'` 表示不绘制                                                                    |
| `width` | `number`                                      | 0.5 到 4 CSS 像素。默认值为 1                                                                           |
| `color` | `string`                                      | CSS 颜色。未设置时，使用主题中的网格线颜色或坐标轴颜色                                                 |
| `every` | `number`                                      | 仅适用于类别网格线，参见[在部分类别处绘制网格线](/diagrams/charts/axes#grid-lines-at-some-categories)   |
| `at`    | `number[]`                                    | 仅适用于类别网格线，参见[在部分类别处绘制网格线](/diagrams/charts/axes#grid-lines-at-some-categories)   |

未设置 `grid` 和 `line` 时，图表默认具有：

- 数值处的网格线；
- 类别处没有网格线，但散点图的类别为数值时除外；
- 类别轴线；
- 没有数值轴线。

### 不绘制网格线的情况

如果网格线与坐标轴线重合，则只绘制坐标轴线。因此，数值网格在类别轴所在位置不绘制线条，类别网格也不会沿数值轴绘制线条。如果使用 `x.line: { line: 'none' }` 隐藏类别轴，图表底部将完全没有线条。

当数值低于 0 时，类别轴会在 0 处穿过绘图区。此时，数值网格线仍会绘制在最低数值处。

### 在部分类别处绘制网格线

类别网格（`x.grid`）还接受 `every` 和 `at`：

| 字段    | 说明                                                                                 |
| ------- | ------------------------------------------------------------------------------------ |
| `every` | `every: 3` 从第一个类别开始，每隔三个类别绘制一条线                                   |
| `at`    | `at: [1, 4, 5]` 仅在指定类别处绘制线条，类别从 0 开始计数。此设置优先于 `every`       |

在条形图中，类别网格线沿条形边缘绘制，因此网格线的数量比类别多一条。对于 `every` 和 `at`，最后一个条形右侧边缘的线计作下一个类别。若有 4 个条形，该线的编号为 4。

数值网格不接受这两个字段。x 轴为数值的散点图也不接受这两个字段。

```ts
editor.commands.updateChartAxis({
  axis: 'y',
  changes: { grid: { line: 'dotted', color: '#94a3b8' } },
})
editor.commands.updateChartAxis({ axis: 'x', changes: { grid: { line: 'solid', width: 0.5 } } })
editor.commands.updateChartAxis({ axis: 'x', changes: { grid: { line: 'solid', every: 3 } } })
```

## 类别标签

`x.labels` 是一个 `CategoryLabels` 对象，可隐藏或旋转类别标签，适用于窄图表上的长标签。`every` 和 `at` 的类别选择方式与[网格线](/diagrams/charts/axes#grid-lines-at-some-categories)相同。

| 字段    | 类型       | 说明                                                      |
| ------- | ---------- | --------------------------------------------------------- |
| `every` | `number`   | `{ every: 2 }` 从第一个标签开始，每隔一个标签显示一个      |
| `at`    | `number[]` | `{ at: [0, 5, 11] }` 仅显示指定标签，标签从 0 开始计数     |
| `angle` | `number`   | 将标签逆时针旋转，角度范围为 -90 到 90 度                 |

- 只会隐藏标签，类别、对应的条形和数据点仍会保留。
- 设置 `angle: 45` 时，标签向右上方倾斜，末端位于对应类别处，因此较长的名称可以并排显示。
- 未设置 `every` 或 `at` 时，可能重叠的标签会被隐藏。

```ts
editor.commands.updateChartAxis({ axis: 'x', changes: { labels: { every: 3 } } })
```

## 刻度间隔

`y.step: 25` 会在 0、25、50 等位置设置刻度、标签和数值网格线。

- 坐标轴两端会调整到完整的间隔值，除非通过 `min` 或 `max` 固定端点。
- 如果某个间隔会产生超过 100 个刻度，则会被忽略。
- 带有第二坐标轴的组合图中，该间隔适用于左侧坐标轴。

## 哪些图表会绘制坐标轴

折线图、条形图、面积图、散点图和组合图支持所有字段。雷达图支持两个字段：`y.grid` 设置环线，`x.line` 设置辐射线。默认情况下，两者都会绘制。

[ECharts](/diagrams/renderers/echarts#chart-types) 和 [D3](/diagrams/renderers/d3#chart-types) 渲染器会绘制所有字段。Mermaid 渲染器不支持设置了这些字段的图表，详见其[限制](/diagrams/renderers/mermaid#limits)。自定义渲染器也可以像内置渲染器一样绘制坐标轴，参见[规范中需要遵循的内容](/diagrams/renderers/custom#what-to-honor-in-the-spec)。

### 在 Word 文档中

Word 会根据规范绘制相应内容，也支持 `every`，但不支持 `at`。

- 当颜色值为 `#rrggbb` 格式时，Word 会使用该颜色；否则使用主题颜色。
- 类别轴线设置为 `'none'` 时，沿该轴的网格线仍会保留。
- `step` 会成为数值轴的主要单位。
- `labels.every` 会转换为标签间隔设置。
- `labels.angle` 会转换为标签旋转角度。
- Word 中没有与 `labels.at` 对应的设置，因此会显示每个标签。

## 命令

### updateChartAxis

修改 `spec.axes.x` 或 `spec.axes.y` 中的字段，并保留其他字段。将字段设为 `undefined` 会移除该字段。

```ts
editor.commands.updateChartAxis({ axis: 'y', changes: { title: 'EUR', min: 0 } })
```

| 选项      | 类型                 | 说明                                                                     |
| --------- | -------------------- | ------------------------------------------------------------------------ |
| `axis`    | `'x' \| 'y'`         | 类别轴（`x`）或数值轴（`y`）                                             |
| `changes` | `Partial<ChartAxis>` | 要修改的字段，参见[坐标轴字段](/diagrams/charts/axes#axis-fields)        |
| `pos`     | `number`             | 图表的位置。默认为当前选中的图表                                         |

如果 `pos` 处没有图表，或没有选中图表，则返回 `false`。
