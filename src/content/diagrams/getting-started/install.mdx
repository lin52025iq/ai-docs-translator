## 安装

1. [联系我们的团队](https://tiptap.dev/contact-sales?form=pilot-program)，加入 Tiptap Diagrams 试点计划。
2. 按照[私有注册表指南](/guides/pro-extensions)配置包管理器。
3. 安装 Diagrams 包，以及所用每个渲染器对应的图表库：

```bash
npm install @tiptap-pro/extension-diagrams
npm install echarts
```

| 包                           | 类型                   | 版本                                 |
| ---------------------------- | ---------------------- | ------------------------------------ |
| `@tiptap/core`, `@tiptap/pm` | 对等依赖               | 3.31 或更高版本                      |
| `echarts`                    | 可选对等依赖           | `^6.0.0`                             |
| `d3`                         | 可选对等依赖           | `^7.9.0`                             |
| `d3-sankey`                  | 可选对等依赖           | `^0.12.3`，用于 D3 桑基图             |
| `mermaid`                    | 可选对等依赖           | `>=11.16.1 <12`                      |
| `pele`                       | 可选对等依赖           | `1.6.0`，用于 Pele 渲染器            |

以下示例还会用到 `@tiptap/starter-kit` 和 `@tiptap/extension-table`。如果编辑器中还没有这些包，也请安装。

draw.io 和 BPMN 渲染器会从你提供的文件中加载对应的图表库。请参阅 [draw.io](/diagrams/renderers/drawio) 和 [BPMN](/diagrams/renderers/bpmn)。[渲染器](/diagrams/renderers/overview)页面列出了所有渲染器。

## 第一个图表

在演示中，先将行作为文本输入，再将其插入为图表，最后更改图表类型：

<CodeDemo isPro viewer view="preview" path="/Extensions/DiagramsInsertChart" />

```ts
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import { TableKit } from '@tiptap/extension-table'
import { Diagrams, chartStyleRules } from '@tiptap-pro/extension-diagrams'
import { echartsRenderer } from '@tiptap-pro/extension-diagrams/echarts'

const style = document.createElement('style')
style.textContent = chartStyleRules()
document.head.append(style)

const editor = new Editor({
  element: document.querySelector('#editor'),
  extensions: [
    StarterKit,
    TableKit,
    Diagrams.configure({
      renderers: [echartsRenderer()],
      chart: { defaultType: 'bar' },
    }),
  ],
})

editor.commands.insertChartFrom({
  format: 'chart-syntax',
  content: 'Month | Revenue\nJan | 120\nFeb | 150\nMar | 110',
})
```

此时，编辑器中会有一个包含三根柱子的柱状图，并且该图表处于选中状态。

- `chartStyleRules()` 返回图表所需的样式表。
- `TableKit` 是可选的。使用它可以将图表转换为表格，也可以再转换回来。
- `chart: { defaultType: 'bar' }` 会将新图表的类型设为 `bar`。请参阅
  [`defaultType`](/diagrams/api-reference/options#defaulttype)。
- `chart-syntax` 是[图表语法](/diagrams/data/chart-syntax)：每行一条数据，单元格之间用 `|` 分隔。

## 更改图表

`updateChartSpec` 和 `updateChartAxis` 可更改当前选中的图表，例如[第一个图表](#第一个图表)中插入的图表：

```ts
editor.commands.updateChartSpec({ spec: { type: 'line', title: 'Revenue' } })
editor.commands.updateChartAxis({ axis: 'y', changes: { title: 'EUR', min: 0 } })
```

图表规格定义了图表如何展示数据，包括类型、标题、颜色和坐标轴。如果没有选中的图表，这两个命令都会返回 `false`。每次更改都会作为一个[命令](/diagrams/api-reference/commands)执行，因此用户可以撤销更改，协作者也会收到更改。AI 模型可通过[工具](/diagrams/guides/ai)调用这些命令。

## 从快速输入创建第二个图表

1. 在空段落中输入 `:::`，打开[快速输入](/diagrams/data/quick-input)，这是文档中的一个文本输入框。
2. 输入数据行，例如 `Apr | 130`。
3. 在末尾的空行按 Enter。

## 第一个图示

流程图需要图示渲染器。Mermaid 是一个根据文本绘制图示的图表库；要使用 Mermaid 渲染器，需要安装 `mermaid`：

```bash
npm install mermaid@11
```

下面的示例使用[第一个图表](#第一个图表)中的编辑器，加入 Mermaid 图示渲染器和图示样式，并插入一个流程图：

```ts
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import { TableKit } from '@tiptap/extension-table'
import { Diagrams, chartStyleRules, flowDiagramStyleRules } from '@tiptap-pro/extension-diagrams'
import { echartsRenderer } from '@tiptap-pro/extension-diagrams/echarts'
import { mermaidDiagramRenderer } from '@tiptap-pro/extension-diagrams/mermaid'
import rendererUrl from '@tiptap-pro/extension-diagrams/mermaid-renderer?url&no-inline'
import mermaidUrl from 'mermaid/dist/mermaid.min.js?url'

const style = document.createElement('style')
style.textContent = chartStyleRules() + flowDiagramStyleRules()
document.head.append(style)

const editor = new Editor({
  element: document.querySelector('#editor'),
  extensions: [
    StarterKit,
    TableKit,
    Diagrams.configure({
      renderers: [echartsRenderer()],
      diagramRenderers: [mermaidDiagramRenderer({ mermaidUrl, rendererUrl })],
      chart: { defaultType: 'bar' },
    }),
  ],
})

editor.commands.insertFlowDiagram({
  source: 'flowchart LR\n  order[Order placed] --> ship[Shipped]',
  title: 'Order flow',
})
```

编辑器会显示一个包含两个方框的流程图，并且该图示处于选中状态。

Mermaid 会在沙盒 iframe 中绘制图示，所需的两个文件由打包工具提供：`mermaidUrl` 指向 Mermaid，`rendererUrl` 指向使用 Mermaid 进行绘制的脚本。在 Vite 中，`?url` 会返回文件的 URL；`no-inline` 可避免小文件被转换为 iframe 无法加载的 data URL。[Mermaid 渲染器](/diagrams/renderers/mermaid#quick-start)介绍了如何配置其他打包工具。

## 入口点

每个渲染器都是包的独立入口点，因此打包产物只会包含你使用的图表库。

| 导入路径                                                                | 包含内容                                                                                                                            |
| ----------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `@tiptap-pro/extension-diagrams`                                        | `Diagrams`、其节点和命令、数据源、导出、样式以及供 AI 模型使用的工具                                                                  |
| `@tiptap-pro/extension-diagrams/core`                                   | 图表数据类型、解析器和格式，以及 Word 写入器。它不依赖 Tiptap 或 DOM，因此可在服务器或 worker 中运行                                  |
| `@tiptap-pro/extension-diagrams/export`                                 | 在浏览器中将 SVG 转换为 PNG、WebP 或可下载文件                                                                                        |
| `@tiptap-pro/extension-diagrams/theme`                                  | 在浏览器中从 CSS 自定义属性读取图表和图示颜色                                                                                         |
| [`@tiptap-pro/extension-diagrams/echarts`](/diagrams/renderers/echarts) | 使用 ECharts 绘制的图表                                                                                                              |
| [`@tiptap-pro/extension-diagrams/d3`](/diagrams/renderers/d3)           | 使用 D3 绘制的图表                                                                                                                   |
| [`@tiptap-pro/extension-diagrams/mermaid`](/diagrams/renderers/mermaid) | 使用 Mermaid 绘制的图表和图示                                                                                                        |
| [`@tiptap-pro/extension-diagrams/drawio`](/diagrams/renderers/drawio)   | draw.io 图示                                                                                                                         |
| [`@tiptap-pro/extension-diagrams/bpmn`](/diagrams/renderers/bpmn)       | BPMN 流程模型                                                                                                                        |
| [`@tiptap-pro/extension-diagrams/pele`](/diagrams/renderers/pele)       | 由 Pele 在 Web Worker 中绘制的 Mermaid 图示。Pele 比 mermaid.js 更小                                                                  |
