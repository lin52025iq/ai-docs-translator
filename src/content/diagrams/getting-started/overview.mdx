Diagrams 扩展可为 Tiptap 编辑器添加图表和示意图。只需安装一个软件包
`@tiptap-pro/extension-diagrams`，并添加一个扩展 `Diagrams`。要安装扩展并插入第一个图表，请从[快速入门](/diagrams/getting-started/install)开始。

## 它能添加什么

该扩展会添加两个节点：

| 节点          | 显示内容                                      | 文档中存储的内容                 |
| ------------- | --------------------------------------------- | -------------------------------- |
| `chart`       | 柱状图、折线图、饼图或其他图表                | 图表数据和设置                   |
| `flowDiagram` | 流程图、时序图或 BPMN 流程模型                | 源文本，例如 Mermaid 代码        |

文档存储的是数据，而不是图片。你选择的图表库会在浏览器中绘制每个图表和示意图。即使切换到其他图表库，图表的外观会有所不同，但文档内容保持不变。

## 你可以用它做什么

- **根据输入的行创建图表。** 在空段落中输入 `:::`，然后每行输入一条数据，例如 `Jan | 2`。你也可以将表格转换为图表。[数据](/diagrams/data/overview)
- **修改图表。** 随时更改图表类型、标题、颜色和坐标轴。
  [图表](/diagrams/charts/overview)
- **插入示意图。** 以文本形式编写流程图、时序图或 BPMN 流程模型。你可以直接在示意图中编辑 Mermaid 图表的文本。[示意图](/diagrams/flow-diagrams/overview)
- **导出。** 将图表和示意图保存为图片，或将所有图表放入 Word 文档。
  [导出](/diagrams/export)
- **让 AI 模型处理图表和示意图。** 为模型提供工具，以便插入、读取和修改图表及示意图。[模型工具](/diagrams/guides/ai)

## 本文档中的术语

| 术语         | 含义                                                                                                                                                                       |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 图表数据     | 图表以行和列形式存储的值。[数据](/diagrams/data/overview)                                                                                                                  |
| 图表配置     | 图表的设置，例如类型、标题、颜色和坐标轴。[图表](/diagrams/charts/overview)                                                                                               |
| 图表语法     | 一种简洁的图表数据输入方式：每行代表一条数据，单元格之间以 `\|` 分隔，例如 `Jan \| 2`。[图表语法](/diagrams/data/chart-syntax)                                           |
| 快速输入     | 在空段落开头输入 `:::` 时出现的文本输入框。在其中输入的内容会转换为图表或示意图。[快速输入](/diagrams/data/quick-input)                                                   |
| 渲染器       | 扩展与某个绘图库（例如 ECharts 或 Mermaid）之间的适配器。你需要为使用的每个绘图库注册一个渲染器。[渲染器](/diagrams/renderers/overview)                                  |
| 数据源       | 文档外部的图表数据来源，例如 URL 上的 CSV 文件。[数据源](/diagrams/data/sources)                                                                                          |

## 文档中的代码

存储在文档中的代码（例如 Mermaid 源码）不会在应用的网页中运行：

- [Mermaid](https://mermaid.js.org)、[draw.io](https://www.drawio.com) 和
  [BPMN](https://bpmn.io) 示意图会在沙盒 iframe 中绘制。
- [Pele](/diagrams/renderers/pele) 会在 Web Worker 中绘制 Mermaid 示意图。
- 自定义 D3 代码是你在应用中注册的函数。图表只存储其名称。
