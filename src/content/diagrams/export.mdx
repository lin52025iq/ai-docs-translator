## 文件

```ts
import { downloadBlob } from '@tiptap-pro/extension-diagrams/export'

const { blob, svg, width, height, alt } = await editor.storage.diagrams.export(
  { pos },
  { format: 'png', scale: 2, background: '#ffffff' },
)
downloadBlob(blob, 'chart.png')
```

### 导出内容

第一个参数 `target` 可以是以下其中一种：

| 目标                        | 导出内容                 |
| --------------------------- | ------------------------ |
| `{ pos? }`                  | 文档中的图表或示意图     |
| `{ data, spec, renderer? }` | 不在任何文档中的图表数据 |

示意图由其示意图渲染器绘制。`renderer` 和 `size` 选项不适用于示意图。示意图的颜色来自 `--tt-flow-diagram-*` 自定义属性。

### 选项

| 选项         | 类型                                 | 默认值                                                                  | 说明                                 |
| ------------ | ------------------------------------ | ----------------------------------------------------------------------- | ------------------------------------ |
| `format`     | `'svg' \| 'png' \| 'webp' \| 'jpeg'` | `'svg'`                                                                 | 文件格式                             |
| `scale`      | `number`                             | `2`                                                                     | 图像中每个 SVG 单位对应的像素数      |
| `background` | `string \| null`                     | `null`                                                                  | 图表后方的填充色                     |
| `renderer`   | `string`                             | 图表使用的渲染器                                                        | 使用其他渲染器进行绘制               |
| `theme`      | `ChartTheme`                         | 页面主题                                                                | 使用 `ChartTheme`，而非页面自定义属性 |
| `size`       | `{ width: number; height: number }`  | `{ width: 800, height: 450 }`；或宽度为 800、高度按图表自身的 `ratio` 确定 | 绘制尺寸                             |
| `scheme`     | `'light' \| 'dark'`                  | `'light'`                                                               | 绘制所用的配色方案，不受页面显示效果影响 |

### 返回内容

| 字段              | 内容                     |
| ----------------- | ------------------------ |
| `blob`            | 文件                     |
| `svg`             | SVG                      |
| `width`, `height` | 绘图尺寸                 |
| `alt`             | 用于 `alt` 属性的标题和说明 |
| `renderer`        | 绘制时使用的渲染器       |
| `raster`          | 渲染器绘制像素时为 `true` |

- **SVG 使用具体颜色值**，而非 `var(…)`，因此在页面之外显示时效果也相同。
- **绘制像素的渲染器**（例如在 canvas 上绘制的渲染器）也可以导出。其 SVG 中包含的是图像而非形状，因此缩放时会失真。参见[自定义渲染器](/diagrams/renderers/custom#members)。（原文：Your own Renderer）
- **PNG、WebP 和 JPEG 文件**需要浏览器。
- **ECharts 和 D3 图表的 SVG**可以在服务器上生成。

`@tiptap-pro/extension-diagrams/export` 还提供 `svgToBlob`、`svgToImage`、`toDataUrl`、`readSvgSize`、`inlineSvgStyles` 和 `rasterToSvg`。

## Word

有三种方式可以将图表放入 Word 文档：

| 方式                                                                                                         | Word 文件包含的内容                                                                 |
| ------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------- |
| `editor.storage.diagrams.exportDocx()`                                                                       | 仅包含图表和示意图，不含文档其余内容。Word 能绘制的图表会作为原生 Word 图表，示意图则作为图像 |
| [`toPortableContent`](/diagrams/export#a-whole-document) 与 `ExportDocx`                                     | 整个文档。每个图表可以是图像、表格或两者兼有；每个示意图可以是图像或其源内容             |
| [将 `toPortableContent` 与 `charts: 'native'` 配合使用，再调用 `addNativeCharts`](/diagrams/export#native-word-charts) | 整个文档，包含原生 Word 图表                                                         |

原生 Word 图表是由 Word 自行绘制的图表。你可以在 Word 中重新设置其样式；点击“编辑数据”会在 Excel 中打开图表数据。

### 仅导出图表和示意图

`exportDocx` 会创建一个新的 Word 文件，其中仅包含图表和示意图：

```ts
const { blob, notes } = await editor.storage.diagrams.exportDocx({
  targets: [{ pos }],
  title: 'Report',
})
downloadBlob(blob, 'charts.docx')
for (const note of notes) console.info(note.title ?? 'All charts', note.message)
```

| 选项           | 类型                 | 说明                                                         |
| -------------- | -------------------- | ------------------------------------------------------------ |
| `targets`      | `ChartTarget[]`      | 要写入的图表和示意图，按指定顺序排列                         |
| `title`        | `string`             | 图表上方的标题                                               |
| `fallbackFont` | `string`             | 页面字体不可用时 Word 使用的字体。默认值为 `'Arial'`         |
| `images`       | `'auto' \| 'always'` | 图表何时转换为图像，参见[将图表作为图像](/diagrams/export#charts-as-images) |

### 文件包含的内容

- **每个目标**按顺序转换为原生 Word 图表（数据保存在嵌入的工作簿中）、Word 表格或图像，具体如下所述。
- **示意图**会转换为 PNG 图像，缩放至页面宽度，并以其标题作为题注。
- **未指定 `targets` 时**，文件会按文档顺序包含所有有数据且未隐藏在其表格后方的图表，以及所有有源内容的示意图。
- **没有内容可写入或无法写入任何内容时**，Promise 会被拒绝。
- **带有 `caption` 的图表**后面会跟随其说明，样式为 Word 的“题注”样式。
- **每个图表和图像**的替代文本都包含其标题和说明。
- **`matrix`** 会转换为带底色的 Word 表格。
- **系列颜色和字体**取自页面。参见[样式设置](/diagrams/guides/styling)。（原文：Styling）

### 将图表作为图像

`images` 用于决定何时将图表转换为 PNG 图像，而非原生 Word 图表：

| `images`   | 图表的转换方式                                                                                         |
| ---------- | ------------------------------------------------------------------------------------------------------ |
| `'always'` | 由其渲染器按图表尺寸绘制为 PNG 图像                                                                   |
| `'auto'`   | 如果 Word 支持该类型，则转换为 Word 图表或 Word 表格；其他类型以及下述两种情况则转换为图像            |
| 未设置     | 由 [`docxImages`](/diagrams/api-reference/options#docximages) 选项决定                                  |

使用 `'auto'` 时，如果 Word 图表的显示效果与编辑器不同，图表也会转换为图像：

- x 轴为数值的散点图，因为 Word 会让 x 值间距相等；
- 带有参考线的图表，因为 Word 图表不支持参考线。

如果无法绘制图像（例如没有渲染器能够绘制该图表），而图表类型受 Word 支持，则会将图表转换为 Word 图表，并附带一条说明。其他类型的图表则会被省略，并附带一条说明。

### 说明

`notes` 会逐条列出 Word 中的显示效果与编辑器不同之处，每条说明各占一句。扩展会根据图表数据和 Chart Spec 生成这些说明，因此无需打开文件就能查看。每条说明包含 `pos`、`title` 和 `message`。说明涵盖以下情况：

- Word 不支持的字体（`pos: null`）；
- 包含多个系列的饼图或圆环图，Word 只显示第一个系列；
- Word 忽略 x 轴范围；
- 背景色、系列颜色或坐标轴颜色不是十六进制值；
- 仅在部分类别显示的网格线或标签，在 Word 中会显示在每个类别上；
- 类别轴线被省略时的值网格线；
- 带有系列样式的面积图边缘，Word 会按其自身的线条样式绘制；
- 仅有一个渲染器支持的选项；
- 链接图表在 Word 中保存的是数据快照；
- `matrix` 会作为 Word 表格处理；
- 图表被写入为图像，以及当其类型受 Word 支持时转换为图像的原因；
- 因无法绘制图像而被省略或写入为 Word 图表的图表；
- 示意图在 Word 中作为图像处理，或因无法绘制而被省略。

### 不执行导出

`@tiptap-pro/extension-diagrams/core` 中的这些函数可以在不写入文件的情况下，告知你 Word 会如何处理内容：

| 函数                                                       | 返回值                                                   |
| ---------------------------------------------------------- | -------------------------------------------------------- |
| `wordForm(type, images?)`                                  | 某种类型会转换成什么：`'chart'`、`'table'` 或 `'image'`    |
| `wordChartForm(data, spec, images?)`                       | 单个图表会转换成什么：`'chart'`、`'table'` 或 `'image'`   |
| `wordLimitations(data, spec, { theme, source?, images? })` | 单个图表对应的说明列表，与 `notes` 相同                   |

## 整个文档

不识别 `chart` 和 `flowDiagram` 节点的转换器会将它们省略。`@tiptap-pro/extension-diagrams/core` 中的 `toPortableContent` 会返回文档副本，其中的图表和示意图均由各种转换器都能识别的节点构成，例如表格、图像和段落。应导出这个副本。

以下示例使用 `@tiptap-pro/extension-export-docx` 导出副本，并通过 Tiptap 的 Convert 服务进行处理：

```ts
import { Editor } from '@tiptap/core'
import { ConvertKit } from '@tiptap-pro/extension-convert-kit'
import { toPortableContent } from '@tiptap-pro/extension-diagrams/core'
import { ExportDocx } from '@tiptap-pro/extension-export-docx'

const file = await new Promise((resolve, reject) => {
  const exporter = new Editor({
    element: null,
    content: toPortableContent(editor.getJSON()),
    extensions: [
      ConvertKit,
      ExportDocx.configure({ token: 'CONVERT_TOKEN', onCompleteExport: resolve, onError: reject }),
    ],
  })
  exporter.commands.exportDocx()
})
```

`toPortableContent` 无需浏览器，因此也可以在服务器上运行。`CONVERT_TOKEN` 是你的 Convert API 令牌。有关其选项，请参阅 export-docx 文档。

### 副本包含的内容

| 文档中的内容                   | 副本中的内容                                                                                                                                    |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 图表                           | 若有图像，则包含图像；同时将图表数据作为表格。没有图像时，标题位于表格上方。图表将说明显示为题注时，说明位于下方 |
| 隐藏在其后表格下方的图表       | 无，因为表格已经存在                                                                                                                            |
| 示意图                         | 如果 `imageFor` 返回图像，则包含该图像；否则包含标题及以代码格式呈现的源内容行                                                                   |
| 已打开的 Quick Input           | 以代码格式呈现的文本行                                                                                                                          |

只有当应用通过 `uploadImage` 上传图表图像时，图表才会有图像；`uploadImage` 会设置 `previewUrl`。否则，副本会将图表数据作为表格保存。

`matrix` 单元格的颜色由其 `background` 属性决定，文本颜色则由 `textStyle` 标记决定。能读取这些属性的转换器会保留颜色。

### 选项

| 选项               | 值                                                                                                                                                         | 默认值                                       |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| `charts`           | `'both'`、`'image'`（图像；没有图像时为表格）、`'table'` 或 `'native'`（参见[原生 Word 图表](/diagrams/export#native-word-charts)） | `'both'`                                     |
| `imageFor`         | `(figure) => url \| null`，返回图表或示意图的图像。`figure` 的结构为 `{ kind, attrs }`                                                                      | 图表的 `previewUrl`                          |
| `sources`          | `'paragraphs'`（每行一个以代码格式呈现的段落）或 `'codeBlock'`                                                                                             | `'paragraphs'`                               |
| `names`            | 你为 `table`、`tableRow`、`tableHeader`、`tableCell`、`paragraph`、`image`、`codeBlock` 指定的节点名称                                                     | StarterKit 和 `@tiptap/extension-table` 中的名称 |
| `decimalSeparator` | 表格数字使用 `'.'` 或 `','` 作为小数分隔符                                                                                                                 | `'.'`                                        |
| `theme`            | 用于设置 `matrix` 图表单元格颜色的 `ChartTheme`                                                                                                            | `defaultChartTheme`                          |

`'paragraphs'` 可在会省略代码块的转换器中保留示意图源内容。对于会写入代码块的转换器（例如 Markdown 或 HTML 转换器），请使用 `'codeBlock'`。

### 原生 Word 图表

使用 `charts: 'native'` 时，对于 Word 能自行绘制的图表类型，会以标记行代替图像和表格。这些类型包括条形图、折线图、面积图、散点图、饼图、圆环图、雷达图和组合图。随后，任何转换器都可以写入 Word 文件。之后，`addNativeCharts` 会将每个标记替换为原生 Word 图表。

```ts
import { Editor } from '@tiptap/core'
import { ConvertKit } from '@tiptap-pro/extension-convert-kit'
import { addNativeCharts, toPortableContent } from '@tiptap-pro/extension-diagrams/core'
import { ExportDocx } from '@tiptap-pro/extension-export-docx'

const doc = editor.getJSON()
const exported = await new Promise((resolve, reject) => {
  const exporter = new Editor({
    element: null,
    content: toPortableContent(doc, { charts: 'native' }),
    extensions: [
      ConvertKit,
      ExportDocx.configure({
        token: 'CONVERT_TOKEN',
        exportType: 'buffer',
        onCompleteExport: resolve,
        onError: reject,
      }),
    ],
  })
  exporter.commands.exportDocx()
})
const docx = addNativeCharts({ docx: exported, doc })
```

- **其他类型**的处理方式与 `'both'` 相同。
- **传给 `addNativeCharts` 的文档**必须与传给 `toPortableContent` 的文档相同。它会按相同顺序查找图表。
- **`addNativeCharts` 还接受 `theme` 和 `fallbackFont`。**`theme` 用于设置图表的颜色和字体，默认值为 `defaultChartTheme`。`fallbackFont` 是 Word 无法使用主题字体时采用的字体，默认值为 `'Arial'`，与 `exportDocx` 相同。
- **转换器拆分或更改的标记**会保留为文本。

## 命令

### convertChartToImage

将图表替换为其图像。该图像是一个节点，其类型由 `imageNodeName` 选项指定。

```ts
editor.commands.convertChartToImage({ format: 'svg', keepData: true })
```

| 选项       | 类型                                 | 说明                                                                                                                               |
| ---------- | ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| `format`   | `'svg' \| 'png' \| 'webp' \| 'jpeg'` | 图像格式。默认值为 `'png'`                                                                                                         |
| `keepData` | `boolean`                            | 图像会保留图表数据，因此可通过 [`convertImageToChart`](/diagrams/export#convertimagetochart) 还原图表。除非设为 `false`，否则会保留数据 |
| `pos`      | `number`                             | 图表位置。默认使用当前选中的图表                                                                                                   |

- **图像会通过 `uploadImage` 上传**；如果未提供该函数，则会以内嵌数据 URL 的形式保存。
- **图表会在图像准备就绪后被替换**，除非期间图表已发生变化。
- **图像会按两倍尺寸导出**，从而在高像素密度屏幕上保持清晰。
- **当图像节点具有 `width` 属性时**（如 `@tiptap/extension-image`），该命令会将其设置为图表宽度，图像也会按此尺寸显示。

为图像设置 `max-width: 100%`，使其在窄屏上缩小：

```css
.tiptap img {
  max-width: 100%;
  height: auto;
}
```

### convertImageToChart

将通过 `keepData` 创建的图像还原为图表。

```ts
editor.commands.convertImageToChart()
```

| 选项  | 类型     | 说明                         |
| ----- | -------- | ---------------------------- |
| `pos` | `number` | 图像位置。默认使用当前选中的图像 |

### redrawChartImage

根据图像保留的图表，使用当前样式、渲染器和配色方案重新绘制通过 `keepData` 创建的图像。

```ts
editor.commands.redrawChartImage({ pos })
```

| 选项     | 类型                                 | 说明                         |
| -------- | ------------------------------------ | ---------------------------- |
| `format` | `'svg' \| 'png' \| 'webp' \| 'jpeg'` | 图像格式。默认值为 `'png'`   |
| `pos`    | `number`                             | 图像位置。默认使用当前选中的图像 |

- **图像会保留**其其他属性以及其中保存的图表。
- **新文件准备就绪后，只会更改图像文件、文本和宽度**，除非期间图像已发生变化。

如果图像未保留任何图表，或没有渲染器能绘制该类型，则返回 `false`。
