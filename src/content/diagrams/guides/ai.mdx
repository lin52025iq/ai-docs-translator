## 快速开始

向模型提供图表工具和示意图工具。对每个工具调用，使用相应的运行函数进行响应：

```ts
import {
  getChartToolDefinitions,
  getDiagramToolDefinitions,
  runChartTool,
  runDiagramTool,
} from '@tiptap-pro/extension-diagrams'

const tools = [...getChartToolDefinitions(editor), ...getDiagramToolDefinitions(editor)]

// A call to a chart tool
const result = runChartTool(editor, name, input)
// A call to a diagram tool
const other = runDiagramTool(editor, name, input)
```

## 函数

| 函数                                  | 返回值                                                                                                   |
| ------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `getChartToolDefinitions(editor)`     | 图表工具的工具定义（`name`、`description`、`inputSchema`），参见[图表工具](/diagrams/guides/ai#charts) |
| `runChartTool(editor, name, input)`   | 运行一个图表工具后返回 `{ ok, output, pos? }`                                                            |
| `getDiagramToolDefinitions(editor)`   | [示意图工具](/diagrams/guides/ai#diagrams)的工具定义                                                      |
| `runDiagramTool(editor, name, input)` | 运行一个示意图工具后返回 `{ ok, output, pos? }`                                                          |

## 调用返回什么

| 字段     | 类型      | 说明                                                                                              |
| -------- | --------- | ------------------------------------------------------------------------------------------------- |
| `ok`     | `boolean` | 调用是否成功                                                                                      |
| `output` | `string`  | JSON；如果失败，则为一条告知模型如何修正调用的消息                                                 |
| `pos`    | `number`  | 插入或更新操作写入的图表或示意图的位置。`output` 末尾也会标明该位置                                |

## 图表

图表工具包括 `insertChart`、`insertLinkedChart`、`updateChart`、`readChart`、`listCharts` 和 `describeChartCapabilities`。这些工具的定义会将编辑器支持的格式和渲染器列为枚举值。

### 仅支持此编辑器能够绘制的图表

这些工具不会插入任何未注册渲染器能够绘制的图表。`type` 枚举会列出已注册渲染器能够绘制的图表类型，而 `describeChartCapabilities` 会列出每个渲染器支持的类型。

以下调用会被拒绝，且不会写入任何内容：

- 插入渲染器无法绘制的图表
- 使用未注册的 `renderer`，或使用无法绘制该图表类型的渲染器
- 调用 `updateChart` 将图表类型改为任何渲染器都无法绘制的类型

答复会指出可改用的类型或渲染器：

```json
{
  "ok": false,
  "output": "No Renderer here draws \"sankey\" charts. Use one of these types: line, bar, pie."
}
```

### 读取数据源的图表

`insertLinkedChart` 工具会插入图表，并使用 `linkChartSource` 将其链接到[数据源](/diagrams/data/sources)，例如 URL 上的 CSV 文件。同名命令 [`insertLinkedChart`](/diagrams/data/tables#insertlinkedchart) 则不同：它会创建一个跟随文档中表格的图表。该工具无法实现这一点，因为它不提供 `document-table` 数据源。

| 参数       | 类型      | 说明                                                                         |
| ---------- | --------- | ---------------------------------------------------------------------------- |
| `provider` | `string`  | 数据源。枚举值为已注册的数据源，但不包括 `document-table`                    |
| `address`  | `object`  | 数据源读取位置，例如 URL 上的 CSV 或 JSON 文件对应的 `{ url }`               |
| `type`     | `string`  | 图表类型，可选                                                               |
| `title`    | `string`  | 图表标题，可选                                                               |
| `readOnly` | `boolean` | 除非值为 `false`，否则图表为只读                                             |

调用返回后，数据才会到达。读取失败时会触发 `onSourceError`。只有当应用设置了 [`allowSourceUrl`](/diagrams/api-reference/options#allowsourceurl) 时，工具才会链接 `url-csv` 和 `url-json`，且只能链接到该选项允许的 URL。`allowSourceUrl` 决定请求可以发往何处，而不限制 URL 中包含的内容。
模型仍可能将文档文本放入允许的 URL 中，例如作为查询参数。因此，只允许访问你信任其能够处理文档内容的主机。

## 示意图

示意图工具包括 `insertDiagram`、`updateDiagram`、`readDiagram` 和 `listDiagrams`。模型会编写其已熟悉的 Mermaid。`listDiagrams` 会列出每个示意图的 `format`。读取或更改 draw.io 或 BPMN 示意图时，会将其整个 XML 作为整体处理。

[Mermaid 图表类型](/diagrams/charts/overview#importmermaidchart)（例如饼图）属于图表。使用此类图表的示意图工具调用会被拒绝，并提示模型改用 `insertChart`。

### 格式和渲染器

- **`insertDiagram` 可创建 Mermaid 或 BPMN。** 对于 BPMN，调用需传入 `format: 'bpmn'`。如果未传入 `format`，则会创建 Mermaid；但如果编辑器支持绘制 BPMN 而不支持 Mermaid，则会创建 BPMN。
- **`insertDiagram` 不支持 draw.io。** 其 `format` 枚举值为 `mermaid` 和 `bpmn`。模型可以使用 `readDiagram` 和 `updateDiagram` 读取和更改现有的 draw.io 示意图。
- **这些工具会像命令一样写入源数据，无论注册了哪些渲染器。** 即使当前没有任何渲染器能够绘制某种格式或类型，工具仍会写入它。`output` 会告知模型该内容在此编辑器中显示为不可用。
