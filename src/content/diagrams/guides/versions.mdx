## 比较哪些内容

图表会根据其数据、规格、渲染器、数据源、分隔符，以及上次读取该数据源的时间进行比较。[使用 Tiptap Compare]( /diagrams/guides/versions#with-tiptaps-compare) 下方的表格说明了各项在何时会发生变化。
示意图会根据其源文本、格式、标题、说明、视图和选项进行比较。如果切换到代码视图不应算作变更，请将
`'view'` 添加到 `ignoreAttributes`。

## 使用 Tiptap Compare

`@tiptap-pro/compare` 会比较两个文档的 JSON。图表或示意图的属性不同时，会将其报告为已更改的块。省略那些仅影响显示或编辑的属性，避免它们被报告为变更：

```ts
import { compareDocuments } from '@tiptap-pro/compare'

const changeset = compareDocuments({
  schema: editor.schema,
  docA: olderVersion,
  docB: newerVersion,
  diffOptions: {
    // Compare's defaults, plus a chart's uploaded preview image and a table's Quick Input view
    ignoreAttributes: ['id', 'data-thread-id', '_hash', 'previewUrl', 'diagramInput'],
  },
})
```

| 属性                         | 发生变化的情况                                                   | 在比较中的结果                                                       |
| --------------------------- | --------------------------------------------------------------- | ----------------------------------------------------------------- |
| `data`                      | 值被编辑，或同步带来了不同的数据                                 | 变更                                                              |
| `spec`                      | 类型、标题、颜色、坐标轴或引用发生变化                           | 变更                                                              |
| `renderer`                  | 选择了另一个渲染器，但数据保持不变                               | 变更                                                              |
| `source`                    | 数据源被关联或解除关联，或其地址发生变化                         | 变更                                                              |
| `delimiter`                 | 使用不同的分隔符以文本形式更改了行                               | 变更。将 `'delimiter'` 添加到 `ignoreAttributes` 可忽略此项        |
| `syncedAt`                  | 图表读取其数据源时，即使数据相同也会发生                         | 变更。将 `'syncedAt'` 添加到 `ignoreAttributes` 可忽略此项         |
| `previewUrl`                | 变更后上传了预览图                                               | 忽略                                                              |
| `diagramInput`（在表格上）    | 该表格被用作 Quick Input 的表格视图                              | 忽略                                                              |

## 描述图表中的变更

`@tiptap-pro/extension-diagrams/core` 中的 `describeChartChange` 会告诉你图表内部发生了什么变化，便于在变更旁显示类似“February: 4 → 5, type: bar → line”的说明：

```ts
import { describeChartChange } from '@tiptap-pro/extension-diagrams/core'

const change = describeChartChange({ before: olderChart.attrs, after: newerChart.attrs })

if (change.changed) {
  const cells =
    change.data?.cells.map(
      (cell) => `${cell.row} ${cell.column}: ${cell.before} → ${cell.after}`,
    ) ?? []
  const fields = change.spec.map(
    (field) => `${field.path}: ${String(field.before)} → ${String(field.after)}`,
  )
  console.log([...cells, ...fields].join(', '))
}
```

它会返回：

| 字段                             | 内容                                                                              |
| -------------------------------- | --------------------------------------------------------------------------------- |
| `changed`                        | 下方任意内容是否存在差异                                                          |
| `data`                           | `{ columnsAdded, columnsRemoved, rowsAdded, rowsRemoved, cells }`，或 `null`      |
| `spec`                           | 每个发生变化的规格字段对应的 `{ path, before, after }`，例如 `axes.y.min`           |
| `renderer`, `source`, `syncedAt` | `{ before, after }`；未发生变化时为 `null`                                        |

- **行**：如果每一行的标签都不同，则使用标签命名；否则使用行的位置命名。
- **单元格**：使用其所在行和列标题命名。
- **来自任何文档的属性**均可使用，包括在 `syncedAt` 成为独立属性之前创建的文档。
- **无法读取的属性**会被视为空图表。
