## 功能

| 函数                                                                                   | 作用                                                                                     |
| -------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| [`readText({ pos? })`](/diagrams/api-reference/storage#reading-a-charts-data)          | 返回图表或示意图的文本及其格式                                                           |
| [`updateFromText({ text, pos? })`](/diagrams/guides/split-view#updatefromtext)         | 根据文本更改图表或示意图                                                                 |
| [`highlightSource(text, format)`](/diagrams/api-reference/selectors#highlighted-source) | 将文本作为 HTML 返回，并为各部分着色；该函数来自 `@tiptap-pro/extension-diagrams/core` |

## 读取文本

```ts
const current = editor.storage.diagrams.readText({ pos })
// { format: 'chart-syntax', text: 'bar\nMonth | Revenue\nJan | 120' }
```

对于图表，`readText` 会返回其类型行以及[图表语法](/diagrams/data/chart-syntax)中的各行，并按分隔符拆分，格式与快速输入中显示的一致。格式为 `'chart-syntax'`。对于示意图，它会按示意图自身的格式返回源文本：`'mermaid'`、`'drawio'` 或 `'bpmn'`。如果 `pos` 处没有图表或示意图，且当前也未选中图表或示意图，则返回 `null`。

## 写回文本

### updateFromText

根据文本更改图表或示意图；该文本与 `readText` 返回的文本相同。

```ts
editor.commands.updateFromText({ pos, text: 'pie\nDogs, 3\nCats, 2' })
```

| 选项   | 类型     | 说明                       |
| ------ | -------- | -------------------------- |
| `text` | `string` | 文本                       |
| `pos`  | `number` | 图表或示意图的位置。默认为当前选中的图表或示意图 |

- **图表**会像快速输入一样读取文本：文本可以是可选类型行下方的图表语法各行，也可以是 [Mermaid 图表](/diagrams/charts/overview#importmermaidchart)。图表的数据和类型会随之更改。对于 Mermaid 图表，文本还会设置源文本中指定的内容，例如标题或坐标轴。图表规范的其余部分（例如颜色）保持不变。
- **示意图**会将文本作为新的源文本，就像 `updateFlowDiagram` 一样。
- **命令无法读取的文本**（例如未闭合的引号）不会产生任何更改，命令会返回 `false`。请将文本保留在文本框中并标记为无效，以免丢失用户输入的内容。
- **数据只读的图表**（例如来自关联数据源的图表）无法写入新数据，命令会返回 `false`。

## 跟踪选区

当选区移至另一个图表或示意图，或图表在其他位置发生更改时，请重新读取文本。跳过由文本框自身引起的更新，以保留用户输入的文本。

```ts
const textField = document.createElement('textarea')
document.body.append(textField)

let pos = editor.storage.diagrams.listCharts()[0]?.pos ?? null
if (pos !== null) textField.value = editor.storage.diagrams.readText({ pos })?.text ?? ''
let typing = false

editor.on('transaction', ({ transaction }) => {
  // A command that changes a chart replaces its node. Mapping with -1 keeps pos at its start.
  if (pos !== null) pos = transaction.mapping.map(pos, -1)
  const { node, from } = editor.state.selection
  if (node && ['chart', 'flowDiagram'].includes(node.type.name)) pos = from
  if (!typing && pos !== null) {
    textField.value = editor.storage.diagrams.readText({ pos })?.text ?? ''
  }
})

textField.addEventListener('input', () => {
  if (pos === null) return
  typing = true
  const valid = editor.commands.updateFromText({ pos, text: textField.value })
  typing = false
  textField.toggleAttribute('data-invalid', !valid)
})
```

## 为文本着色

`highlightSource` 会将文本作为 HTML 返回。每个部分都位于一个 `<span>` 中，其类名类似于 `tiptap-diagram-source-keyword`。该函数会为图表语法和 Mermaid 着色。draw.io 和 BPMN XML 应保留为纯文本。

```ts
import { highlightSource } from '@tiptap-pro/extension-diagrams/core'

const { delimiters, chartTypes } = editor.storage.diagrams.describeCapabilities()
code.innerHTML = highlightSource(text, 'chart-syntax', {
  delimiters,
  types: chartTypes.map((type) => type.id),
})
```

将 `tiptap-diagram-source` 类添加到包裹 HTML 的元素上。这样，[快速输入](/diagrams/api-reference/selectors#highlighted-source)中的源文本着色也会应用于此处，并适用于浅色和深色模式。对于用户可以编辑的文本框，可以在包含 HTML 的 `<pre>` 上方覆盖一个透明的 `<textarea>`，并使两者使用相同的字体、内边距和行高。演示示例就是这样实现的。

[`sourceHighlighting`](/diagrams/api-reference/options#sourcehighlighting) 选项只会关闭快速输入和示意图代码视图中的着色，不会关闭自定义文本框中的着色。
