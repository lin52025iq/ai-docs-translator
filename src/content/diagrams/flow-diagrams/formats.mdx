## 格式

| `format`    | 源内容                       | 绘制方式                                                                                              |
| ----------- | ---------------------------- | ----------------------------------------------------------------------------------------------------- |
| `'mermaid'` | Mermaid 文本                 | 由 mermaid.js 或 Pele 绘制，参见 [Mermaid 图表](/diagrams/flow-diagrams/formats#mermaid-diagrams)          |
| `'drawio'`  | draw.io XML                  | 由 draw.io 图表渲染器绘制，参见 [draw.io 图表](/diagrams/flow-diagrams/formats#drawio-diagrams) |
| `'bpmn'`    | 带布局的 BPMN 2.0 XML        | 由 BPMN 图表渲染器绘制，参见 [BPMN 图表](/diagrams/flow-diagrams/formats#bpmn-diagrams)         |
| 其他 ID     | 按原样存储                   | 由支持该格式的图表渲染器绘制，参见[其他格式](/diagrams/flow-diagrams/formats#other-formats)  |

## Mermaid 图表

`format: 'mermaid'` 的图表包含 Mermaid 文本，按你输入的内容存储，但不包含
`%%{…}%%` 指令和 frontmatter。请参阅[源内容即数据](/diagrams/flow-diagrams/overview#source-is-data)。

```ts
editor.commands.insertFlowDiagram({ source: 'flowchart LR\n  A --> B', title: 'Order process' })
```

源内容以 Mermaid 图表类型开头，例如 `flowchart` 或 `sequenceDiagram`。
[Mermaid 图表类型](/diagrams/flow-diagrams/overview#mermaid-kinds)列出了图表可以包含的所有类型。

为其注册以下两种图表渲染器之一：
[`mermaidDiagramRenderer`](/diagrams/renderers/mermaid#diagrams) 或
[`peleDiagramRenderer`](/diagrams/renderers/pele)。
[与 mermaid.js 对比](/diagrams/renderers/pele#next-to-mermaidjs)介绍了两者的区别。

## draw.io 图表

`format: 'drawio'` 的图表包含 draw.io XML。[draw.io 图表渲染器](/diagrams/renderers/drawio)会绘制该图表，并连接 draw.io
编辑器，以便你对其进行修改。其页面提供了演示，以及[源内容的规则](/diagrams/renderers/drawio#what-a-drawio-source-is)。

```ts
editor.commands.insertFlowDiagram({ source: drawioXml, format: 'drawio', title: 'Order process' })
```

## BPMN 图表

`format: 'bpmn'` 的图表包含带布局的 BPMN 2.0 XML，并按原样存储。[BPMN 图表渲染器](/diagrams/renderers/bpmn)会绘制该图表，并连接 bpmn-js
建模器，以便你对其进行修改。其页面提供了演示和源内容规则。

```ts
editor.commands.insertFlowDiagram({ source: bpmnXml, format: 'bpmn', title: 'Payment check' })
```

## 其他格式

你可以使用自己的图表渲染器来绘制自定义格式。关于 ID 规则、大小限制，以及没有渲染器绘制该格式时会发生什么，请参阅
[自定义格式](/diagrams/renderers/custom-diagrams#a-format-of-your-own)。
