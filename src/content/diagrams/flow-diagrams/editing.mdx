## 图表中的文本

在可编辑的编辑器中，双击 Mermaid 图表中的文本会在其上方打开文本框。
文本框中会显示该文本。

- **按 Enter，或离开文本框时，**文本会通过 `updateFlowDiagram` 写入源代码。
- **按 Escape** 会关闭文本框，不做任何更改。
- **只有文本会发生变化。**形状和线条由源代码决定。
- **由表格绘制的图表**不会打开文本框。其文本属于表格。

自定义图表渲染器需要实现
[`editing`](/diagrams/renderers/custom-diagrams#editing-in-the-diagram)。

### 双击可以编辑什么

| 类型      | 双击后打开的内容                       | 写入形式                                                              |
| --------- | ------------------------------------- | --------------------------------------------------------------------- |
| 流程图    | 一个形状                               | 首次出现时写为 `id["text"]`，或写为 `id@{ … }` 中的 `label:`           |
| 流程图    | 边上的文本                             | `-->\|"text"\|`，或在边采用相应形式时写为 `-- "text" -->`             |
| 时序图    | 顶部或底部的参与者                     | `participant id as text`；必要时会在首次出现前声明                     |
| 时序图    | 一条消息                               | 冒号后的文本                                                          |
| 状态图    | 一个状态                               | `state "text" as id`，或首个 `id : text` 行                           |
| 类图      | 一个类名                               | `class id["text"]`。id 保持不变，因此关系和成员不受影响                |
| 其他类型  | 源代码中只出现一次的文本               | 在原位置替换该文本                                                    |

对于其他类型，扩展会在源代码中查找被点击的文本。这适用于时间线中的时段和事件、看板中的列和卡片、思维导图中的节点，以及旅程图或甘特图中的任务和分区。

文本必须在源代码中恰好出现一次，且是完整的条目，不能只是较长文本的一部分。条目可以从行首、括号或引号之后、`:` 或 `,` 等分隔符之后，或 `title` 或 `section` 之后开始。条目在右括号、引号、分隔符或行尾结束。

- **重复出现的文本**不会打开任何内容。例如，在 gitGraph 中，分支名称会同时出现在 `branch dev` 和 `checkout dev` 中。双击该分支不会打开文本框，两处文本都保持不变。
- **Mermaid 添加的文本**（例如计数）不在源代码中，因此不会打开任何内容。
- **新文本中如果包含 `:`, `;`, `,`, `|`, `%`, `#`, `"`, `<`, `>`, 括号或换行符，**在这些图表类型中不会写入，因为这会导致文本以外的内容发生变化。
- **没有文本的边**没有可供双击的内容。请在源代码中为其添加文本，或使用
  [`renameMermaidLabel`](/diagrams/flow-diagrams/editing#without-an-editor)。
- **写在同一条语句中的边**（例如 `A & B --> C`）共用同一文本。
- **文本中的直双引号**会转换为弯引号（“ ”）。

## 移动形状

在可编辑的编辑器中，你可以拖动 Mermaid 流程图中的形状来移动它。

- **拖动形状旁边的空白区域**会平移放大的图表，详见[大小和视图](/diagrams/guides/size-and-view)。
- **偏移量**会按图表单位以 10 为步长对齐。
- **松开指针时，**偏移量会通过
  [`setDiagramNodePosition`](/diagrams/flow-diagrams/editing#setdiagramnodeposition) 一次性写入。撤销一次即可将形状移回原位。
- **要将所有形状移回原位，**请调用 [`resetDiagramPositions`](/diagrams/flow-diagrams/editing#resetdiagrampositions)。

### 移动后的形状如何绘制

Mermaid 会先根据源代码布局图表，然后在编辑器和所有导出结果中，按偏移量绘制已移动的形状。

- **已移动形状的连线**会从边框到边框直线绘制，标签位于中间。
- **未移动形状之间的连线**会保持原有走向。
- **子图的边框**会保持在布局确定的位置，即使你将形状移出子图也一样。
- **当形状移出图表边缘时，**图表会随之扩大。

### 偏移量的保存位置

偏移量按节点 id 存储在 `options.positions` 中。

- **在源代码中重命名 id** 会导致偏移量丢失。
- **源代码中已不存在的 id** 不会移动任何内容。
- **更改源代码**不会清除偏移量。
- **只有流程图**可以这样移动。其他 Mermaid 类型的形状，以及 draw.io 和 BPMN 图表中的形状，都无法这样移动。自定义图表渲染器需要实现
  [`nodeAt` 和 `movePositions`](/diagrams/renderers/custom-diagrams#editing-in-the-diagram)。

## 图表中的线条

你可以在 Mermaid 图表的源代码中使用 `linkStyle` 设置线条样式。源代码之外没有可供编辑的文本框。

```txt
flowchart LR
  a --> b --> c
  linkStyle 0 stroke-dasharray: 5 5, stroke-width: 2px
```

## 命令

### setDiagramNodePosition

将所选 Mermaid 流程图中的一个形状（或 `pos` 指定位置的图表中的形状）移离布局确定的位置。

```ts
editor.commands.setDiagramNodePosition({ nodeId: 'ship', dx: 40, dy: 60 })
```

| 选项     | 类型     | 描述                                                                    |
| -------- | -------- | ----------------------------------------------------------------------- |
| `nodeId` | `string` | 源代码中为形状指定的 id，例如 `ship[Shipped]` 中的 `ship`               |
| `dx`     | `number` | 水平偏移量，单位为图表单位                                              |
| `dy`     | `number` | 垂直偏移量，单位为图表单位。`0, 0` 会将形状移回原位                     |
| `pos`    | `number` | 图表的位置。默认为当前选中的图表                                        |

如果图表不是 Mermaid 流程图、id 中包含空格或除 `-` 和 `_` 以外的标点，或者偏移量不是数字或超出 10,000，则返回 `false`。

### resetDiagramPositions

将所有已移动的形状移回布局确定的位置。

```ts
editor.commands.resetDiagramPositions()
```

| 选项  | 类型     | 描述                             |
| ----- | -------- | -------------------------------- |
| `pos` | `number` | 图表的位置。默认为当前选中的图表 |

如果图表中没有已移动的形状，则返回 `false`。

## 不使用编辑器

`@tiptap-pro/extension-diagrams/core` 中的这些函数可以直接操作源代码，无需编辑器或已绘制的图表：

| 函数                                        | 返回值                                                                                                                                                      |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `renameMermaidLabel(source, target, label)` | 替换指定文本并保留其他所有字符后的源代码；如果源代码不是目标类型、目标不在源代码中，或标签为空，则返回 `null`                                                |
| `renameMermaidNode(source, nodeId, label)`  | 等同于将目标类型设为 `'node'` 时调用 `renameMermaidLabel`                                                                                                    |
| `renameMermaidText(source, text, label)`    | 等同于将目标类型设为 `'text'` 时调用 `renameMermaidLabel`                                                                                                    |
| `isRenamableMermaidText(source, text)`      | 判断该文本是否在源代码中恰好作为完整条目出现一次，因此可以重命名                                                                                              |
| `flowDiagramPositions(diagram)`             | 以 `{ [nodeId]: { dx, dy } }` 的形式返回偏移量，并忽略无效条目                                                                                               |

```ts
import { renameMermaidLabel } from '@tiptap-pro/extension-diagrams/core'

const source = renameMermaidLabel(
  'flowchart LR\n  A[Order] --> B{Paid?}',
  { kind: 'edge', id: 'L_A_B_0' },
  'placed',
)
// 'flowchart LR\n  A[Order] -->|"placed"| B{Paid?}'
```

`target` 的格式为 `{ kind, id }`：

| `kind`                                | `id`                                                                      |
| ------------------------------------- | ------------------------------------------------------------------------- |
| `'node'`                              | 流程图形状的 id                                                           |
| `'edge'`                              | Mermaid 为流程图边指定的 id：`L_<from>_<to>_<n>`，其中 `n` 从 0 开始，表示同一对节点之间边的序号 |
| `'participant'`、`'state'`、`'class'` | 对应元素的 id                                                              |
| `'message'`                           | 消息的位置，从 `'0'` 开始                                                  |
| `'text'`                              | 其他类型中的文本本身。该文本必须在源代码中恰好作为完整条目出现一次             |
