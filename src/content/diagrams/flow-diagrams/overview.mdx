`flowDiagram` 节点以以下三种格式之一存储图表文本（称为 source）：

- Mermaid 文本，用于流程图、时序图、甘特图、思维导图以及[其他所有 Mermaid 类型](/diagrams/flow-diagrams/overview#mermaid-kinds)。
- draw.io XML，用于在 draw.io 编辑器中使用形状绘制的图表。
- BPMN XML，用于业务流程模型。

## 快速入门

安装程序包和用于绘制 Mermaid 图表的库 mermaid.js。此示例还使用了 `@tiptap/core` 和 `@tiptap/starter-kit`。如果项目尚未安装它们，也请一并安装：

```bash
npm install @tiptap-pro/extension-diagrams mermaid
```

然后为 Mermaid 注册一个图表渲染器，并插入第一个图表：

```ts
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import { Diagrams, chartStyleRules, flowDiagramStyleRules } from '@tiptap-pro/extension-diagrams'
import { mermaidDiagramRenderer } from '@tiptap-pro/extension-diagrams/mermaid'
import rendererUrl from '@tiptap-pro/extension-diagrams/mermaid-renderer?url&no-inline'
import mermaidUrl from 'mermaid/dist/mermaid.min.js?url'

const style = document.createElement('style')
style.textContent = chartStyleRules() + flowDiagramStyleRules()
document.head.append(style)

const editor = new Editor({
  element: document.querySelector('#editor'),
  extensions: [
    StarterKit,
    Diagrams.configure({
      diagramRenderers: [mermaidDiagramRenderer({ mermaidUrl, rendererUrl })],
    }),
  ],
})

editor.commands.insertFlowDiagram({
  source: 'flowchart LR\n  A[Order] --> B{Paid?}\n  B -->|yes| C[Ship]',
  title: 'How an order moves',
})
```

图表渲染器使用一个库绘制图表，正如[渲染器](/diagrams/renderers/overview)使用一个库绘制图表。将它传入 `diagramRenderers` 选项即可。[Mermaid](/diagrams/renderers/mermaid#quick-start)介绍了 `mermaidUrl`、`rendererUrl` 和 `?url` 导入。

## Mermaid 类型

Mermaid source 的第一行会标明其类型，例如 `flowchart` 或 `sequenceDiagram`。Mermaid 图表可以是 Mermaid 11.17 支持的任何类型，但会变成[图表数据可视化](/diagrams/flow-diagrams/overview#diagram-or-chart)的五种类型除外。`MERMAID_DIAGRAM_KINDS` 列出了这些类型，`mermaidDiagramKind(source)` 会返回 source 的类型。

| 类型            | 第一行                                                                           |
| --------------- | -------------------------------------------------------------------------------- |
| `flowchart`     | `flowchart`、`graph`                                                             |
| `sequence`      | `sequenceDiagram`                                                                |
| `state`         | `stateDiagram-v2`、`stateDiagram`                                                |
| `class`         | `classDiagram`、`classDiagram-v2`                                                |
| `er`            | `erDiagram`                                                                      |
| `journey`       | `journey`                                                                        |
| `gantt`         | `gantt`                                                                          |
| `mindmap`       | `mindmap`                                                                        |
| `timeline`      | `timeline`                                                                       |
| `quadrant`      | `quadrantChart`                                                                  |
| `git`           | `gitGraph`                                                                       |
| `kanban`        | `kanban`                                                                         |
| `architecture`  | `architecture-beta`、`architecture`                                              |
| `block`         | `block-beta`、`block`                                                            |
| `c4`            | `C4Context`、`C4Container`、`C4Component`、`C4Dynamic`、`C4Deployment`           |
| `requirement`   | `requirementDiagram`、`requirement`                                              |
| `packet`        | `packet-beta`、`packet`                                                          |

| `ishikawa`      | `ishikawa-beta`、`ishikawa`                                                      |

| `swimlane`      | `swimlane-beta`                                                                  |

| `eventModeling` | `eventmodeling`                                                                  |

Mermaid 的两种图表渲染器 mermaid.js 和 [Pele](/diagrams/renderers/pele#next-to-mermaidjs) 都能绘制此列表中的所有类型。对于没有已注册图表渲染器支持的类型，请参阅[哪个渲染器可以绘制图表](/diagrams/renderers/custom-diagrams#which-renderer-draws-a-diagram)。[在图表中编辑](/diagrams/flow-diagrams/editing)列出了可以在图表中更改文本的类型。

## 图表还是数据可视化

Mermaid 的 `pie`、`xychart`、`sankey`、`radar` 和 `treemap` 会成为 `chart` 节点，其数据可以编辑；请参阅 [`importMermaidChart`](/diagrams/charts/overview#importmermaidchart)。[列表](/diagrams/flow-diagrams/overview#mermaid-kinds)中的其他类型都会成为图表。对于数据可视化 source，[`insertFlowDiagram`](/diagrams/flow-diagrams/overview#insertflowdiagram) 和 [`updateFlowDiagram`](/diagrams/flow-diagrams/overview#updateflowdiagram) 会拒绝处理。

## 图表的存储方式

| 属性          | 内容                                                                          |
| ------------- | ----------------------------------------------------------------------------- |
| `format`      | `'mermaid'`、`'drawio'`、`'bpmn'`，或图表渲染器可绘制的格式 ID                |
| `source`      | Mermaid 文本（最多 50,000 个字符）或 XML                                      |
| `title`       | 显示在图表下方的标题，或 `null`                                                |
| `description` | 替代文本和无障碍描述，或 `null`                                                |
| `view`        | `'diagram'` 显示绘制后的图表，`'code'` 显示 source                            |
| `options`     | 除 source 外的设置，见下表。其他设置会原样保留                                 |

| `options` 中的键 | 内容                                                                                         |
| ---------------- | -------------------------------------------------------------------------------------------- |
| `size`           | 图表大小，请参阅 [setDiagramSize](/diagrams/guides/size-and-view#setdiagramsize)             |
| `link`           | 用于绘制图表的表格                                                                           |
| `positions`      | 移动过的形状的偏移量，请参阅[移动形状](/diagrams/flow-diagrams/editing#moving-shapes)         |

文档不会存储绘制后的图表、图表在屏幕上的大小或其加载状态。

### Source 是数据

source 不会作为代码在应用的网页中运行。写入图表时，扩展会移除 `%%{init: …}%%` 指令和 frontmatter 区块，因此文档无法改变 Mermaid 的运行方式。frontmatter 中的 `title` 会成为图表标题，除非你另行指定标题。颜色来自页面的 CSS，而不是 source。

### HTML 和纯文本中的表示

在 HTML 中，图表是一个 `<figure data-type="flow-diagram">`。其中的 `<pre><code class="language-mermaid">` 保存 source，`<figcaption>` 保存标题。draw.io 图表使用 `language-drawio`，BPMN 图表使用 `language-bpmn`。

不使用此扩展生成的 HTML 或 Markdown 导出会将 source 保留为代码块。将该 HTML 粘贴到安装了此扩展的编辑器中，即可还原为图表。

在纯文本中，Mermaid 图表表示为 `[diagram: title]`，后面跟着 source。其他格式的图表只表示为 `[diagram: title]`；如果没有标题，则表示为 `[diagram]`。

## 更改图表

使用[命令](/diagrams/flow-diagrams/overview#commands)更改图表：

```ts
editor.commands.updateFlowDiagram({ source: 'sequenceDiagram\n  A->>B: Hello' })
editor.commands.setFlowDiagramView({ view: 'code' })
```

你可以创建自己的表单，让用户输入时在每次输入后调用 `updateFlowDiagram`。每次调用都是一个撤销步骤。

每次更改后都会重新绘制图表。如果较新的更改完成后，较早的绘制才完成，则会丢弃较早的结果。Mermaid source 存在语法错误时，会显示错误状态及错误信息，直到 source 再次有效。

### 切换所有图表的视图或 source

每个图表都有自己的视图。若要像 Mermaid 演示一样一次切换所有图表，请对每个图表串联调用 `setFlowDiagramView`：

```ts
const chain = editor.chain()
for (const { pos } of editor.storage.diagrams.listDiagrams()) {
  chain.setFlowDiagramView({ pos, view: 'code' })
}
chain.run()
```

## 列出、缩放和导出图表

### 列出图表

`editor.storage.diagrams.listDiagrams()` 会返回所有图表及以下信息：

| 字段       | 内容                                                                                              |
| ---------- | ------------------------------------------------------------------------------------------------- |
| `pos`      | 图表的位置                                                                                        |
| 属性       | 图表的属性                                                                                        |
| `kind`     | Mermaid 图表的类型；如果 source 为空、不是可绘制的类型或是 XML，则为 `null`                       |
| `drawable` | 该格式的图表渲染器是否能够绘制此 source                                                           |

### 缩放和最大化

`setZoom`、`getZoom`、`setMaximized` 和 `getMaximized` 接受图表的位置，与它们接受数据可视化图表的位置相同。请参阅[大小和视图](/diagrams/guides/size-and-view)。

### 导出

`export({ pos })`、`exportAll()` 和 `exportDocx()` 导出图表的方式与导出数据可视化图表相同。在 Word 中，图表是 PNG 图像。[导出](/diagrams/export)介绍了可用选项和返回内容。

mermaid.js、draw.io 和 BPMN 图表渲染器只能在浏览器中绘制图表。在服务器上，对图表调用 `export` 会抛出异常，而 `exportDocx` 会在备注中说明并省略该图表。Pele 的 [`renderPeleDiagram`](/diagrams/renderers/pele#on-a-server) 仍可在服务器上绘制 Mermaid source。

## 命令

### insertFlowDiagram

在当前选区或 `pos` 处插入图表；除非 `select` 为 `false`，否则会选中该图表。

```ts
editor.commands.insertFlowDiagram({
  source: 'flowchart LR\n  order[Order placed] --> ship[Shipped]',
  title: 'Order flow',
})
```

| 选项          | 类型             | 说明                                                                                                                 |
| ------------- | ---------------- | -------------------------------------------------------------------------------------------------------------------- |
| `source`      | `string`         | Mermaid source、设置 `format: 'drawio'` 时的 draw.io XML，或设置 `format: 'bpmn'` 时的 BPMN 2.0 XML。允许为空 source |
| `format`      | `string`         | `'mermaid'`（默认）、`'drawio'`、`'bpmn'`，或已注册图表渲染器列出的其他格式                                          |
| `title`       | `string \| null` | 图表标题                                                                                                             |
| `description` | `string \| null` | 替代文本和无障碍描述                                                                                                 |
| `pos`         | `number`         | 插入位置，默认为当前选区                                                                                             |
| `select`      | `boolean`        | `false` 会保留当前选区；默认为 `true`                                                                                |

如果选区中有一个空段落，则会将其替换。[粘贴](/diagrams/data/pasting)图表 source 时会运行此命令。

对于 Mermaid 数据可视化 source（`pie`、`xychart`、`sankey`、`radar`、`treemap`）、[列表](/diagrams/flow-diagrams/overview#mermaid-kinds)中没有的类型（例如 `zenuml`），以及设置 `format: 'drawio'` 或 `'bpmn'` 但 source 不是相应 XML 的情况，此命令会返回 `false`。

### updateFlowDiagram

更改选中的图表或 `pos` 处图表的 source、格式、标题或描述。未提供的字段会保留原值。

```ts
editor.commands.updateFlowDiagram({ title: 'Order flow, revised' })
```

| 选项          | 类型             | 说明                                                                                              |
| ------------- | ---------------- | ------------------------------------------------------------------------------------------------- |
| `source`      | `string`         | 新 source。对于根据表格绘制的图表，更改后图表会保留新 source，不再跟随表格                        |
| `format`      | `string`         | 新格式。需要提供该格式的 `source`                                                                 |
| `title`       | `string \| null` | 新标题。`null` 会移除标题                                                                          |
| `description` | `string \| null` | 新描述。`null` 会移除描述                                                                          |
| `pos`         | `number`         | 图表位置，默认为选中的图表                                                                          |

如果新 source 不是相应格式可绘制的类型，或者更改 `format` 时没有提供 `source`，则会返回 `false` 且不做任何更改。

### setFlowDiagramView

显示绘制后的图表或其 source。

```ts
editor.commands.setFlowDiagramView({ view: 'code' })
```

| 选项  | 类型                  | 说明                                                           |
| ----- | --------------------- | -------------------------------------------------------------- |
| `view` | `'diagram' \| 'code'` | `'diagram'` 显示绘制后的图表，`'code'` 显示 source             |
| `pos`  | `number`              | 图表位置，默认为选中的图表                                     |

视图会存储在文档中，因此所有打开文档的人都会看到相同的视图。

### convertCodeBlockToDiagram

将当前选区或 `pos` 处的代码块替换为使用其中 Mermaid source 生成的图表，并选中该图表。

```ts
if (editor.can().convertCodeBlockToDiagram()) editor.commands.convertCodeBlockToDiagram()
```

| 选项 | 类型     | 说明                                             |
| ---- | -------- | ------------------------------------------------ |
| `pos` | `number` | 代码块内的位置，默认为当前选区                   |

在代码块中按 Mod-Enter 也会运行此命令，请参阅[在代码块中按 Mod-Enter](/diagrams/data/quick-input#mod-enter-in-a-code-block)。

如果代码块中包含数据可视化 source，或内容不是 Mermaid 图表，则会返回 `false`。
