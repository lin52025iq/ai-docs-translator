## 快速开始

```bash
npm install mermaid@11
```

该渲染器支持 Mermaid 11.16.1 及之后的 11.x 版本。它不接受 Mermaid 12，因为 Mermaid 12 绘制现有图示的方式有所不同。

```ts
import { mermaidRenderer } from '@tiptap-pro/extension-diagrams/mermaid'
import mermaidUrl from 'mermaid/dist/mermaid.min.js?url'
import rendererUrl from '@tiptap-pro/extension-diagrams/mermaid-renderer?url&no-inline'

Diagrams.configure({ renderers: [mermaidRenderer({ mermaidUrl, rendererUrl })] })
```

`?url` 导入方式适用于 Vite，并会返回文件的 URL。`no-inline` 可避免 Vite 将小文件转换为 iframe 无法加载的 `data:` URL。使用其他打包器时，请自行提供这两个文件，并传入它们的 URL。

## 选项

| 选项          | 类型             | 说明                                                                                              |
| ------------- | ---------------- | ------------------------------------------------------------------------------------------------- |
| `mermaidUrl`  | `string`         | 必填。Mermaid 单文件构建产物 `mermaid/dist/mermaid.min.js` 的 URL，版本需为 11.16.1 或更高且低于 12 |
| `rendererUrl` | `string`         | 必填。`@tiptap-pro/extension-diagrams/mermaid-renderer` 的 URL，即在 iframe 中绘图的脚本             |
| `scriptNonce` | `string \| null` | 使用基于 nonce 的内容安全策略的页面所需的 nonce。默认值为 `null`                                     |
| `id`          | `string`         | 图表存储使用的 id。默认值为 `'mermaid'`                                                              |
| `label`       | `string`         | 菜单中显示的名称。默认值为 `'Mermaid'`                                                               |

## 限制

对于下面这些图表，Mermaid 渲染器会放弃处理，由其他已注册的渲染器绘制。如果没有其他渲染器能绘制该类型的图表，最终仍会由 Mermaid 绘制，具体情况见第二列。请参阅[渲染器放弃处理图表时](/diagrams/renderers/overview#when-a-renderer-declines-a-chart)。

| 图表                                                                                                                                                          | Mermaid 的绘制结果                                                              |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| 包含多个系列的柱状图                                                                                                                                          | 柱子彼此重叠，且没有图例                                                        |
| `spec.orientation: 'horizontal'` 的柱状图                                                                                                                     | 柱子竖直排列                                                                    |
| 设置了 `spec.series` 的折线图                                                                                                                                 | 普通线条。Mermaid 不支持虚线、线宽、标记或曲线                                  |
| 带有样式化网格线或轴线、`axes.y.step`、`axes.x.labels` 或 `references` 的图表，例如带有样式化圆环或辐射线的雷达图（`axes.y.grid`、`axes.x.line`）             | 不显示这些设置                                                                  |
| 值小于零的雷达图或树图                                                                                                                                        | Mermaid 不识别负号。雷达图会将值显示为零，树图则会忽略该值                      |
| 顶层有无子节点的节点的树图，例如 `Gifts \| 30` 与 `Products / Books \| 40` 并列                                                                               | 此类节点会合并到同一部分，该部分以值列命名                                      |
| 面积图或散点图                                                                                                                                               | 不绘制。图表会显示 [`unavailable`](/diagrams/api-reference/options#unavailable) 返回的内容 |

无论还注册了哪些渲染器，Mermaid 绘制以下图表时也会有这些不同之处：

- **圆环图**会按饼图绘制。
- **缺失值**会按零绘制。
- **闭合成环的桑基图连线**会被省略。其他渲染器也会省略这类连线。
- **桑基图标题**由渲染器绘制在图表上方，因为 Mermaid 不会绘制标题。
- **雷达图图例**始终位于右上角。`legend.show: false` 可将其隐藏。
- **双击文本**不会打开任何内容。你无法[重命名图表中的文本](/diagrams/charts/editing)。
- **无法在服务器上导出**，因为 `toSVG` 需要浏览器。

## 导入 Mermaid

Mermaid 的 `pie`、`xychart`、`sankey-beta`、`radar-beta` 和 `treemap-beta` 源码可以转换为可编辑数据的图表，方法是使用 [`importMermaidChart`](/diagrams/charts/overview#importmermaidchart) 或[粘贴](/diagrams/data/pasting)。转换后的图表可由任意图表渲染器绘制，因此无需使用 Mermaid 渲染器。

## 图示

同一入口点提供的 `mermaidDiagramRenderer` 可绘制 Mermaid 图示。它支持图示包含的全部 25 种 [Mermaid 类型](/diagrams/flow-diagrams/overview#mermaid-kinds)，例如流程图、时序图、类图、甘特图、思维导图和时间线。

```ts
import { mermaidDiagramRenderer, mermaidRenderer } from '@tiptap-pro/extension-diagrams/mermaid'

Diagrams.configure({
  renderers: [mermaidRenderer({ mermaidUrl, rendererUrl })],
  diagramRenderers: [mermaidDiagramRenderer({ mermaidUrl, rendererUrl })],
})
```

- **选项**与 `mermaidRenderer` 相同。
- **它使用的沙盒 iframe** 与 `mermaidRenderer` 相同。如果同时注册两者，Mermaid 只会加载一次。
- **颜色和字体**来自 `--tt-flow-diagram-*` 自定义属性，而非源代码。请参阅[图示](/diagrams/flow-diagrams/overview)，其中也包含演示。
- **它只能在浏览器中绘制**，与图表渲染器一样。

[Pele](/diagrams/renderers/pele) 是另一个用于 Mermaid 源码的图示渲染器。它在 Web Worker 中绘制，也支持在服务器上绘制。
