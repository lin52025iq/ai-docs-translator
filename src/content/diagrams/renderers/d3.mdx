## 快速开始

```bash
npm install d3
```

```ts
import { d3Renderer } from '@tiptap-pro/extension-diagrams/d3'

Diagrams.configure({ renderers: [d3Renderer()] })
```

## 图表类型

D3 渲染器可绘制折线图、柱状图、面积图、散点图、饼图、圆环图、雷达图、组合图、树形图和网络图；还可通过 [`d3-sankey`](/diagrams/renderers/d3#sankey-charts) 绘制桑基图。

- **网络图**使用力导向模拟进行布局。模拟从固定的起点运行固定步数，因此相同的数据每次都会以相同的方式绘制。
- **`orientation: 'horizontal'`** 会将柱状图的柱子横向排列。组合图的柱子仍保持竖直。
- [系列线条样式](/diagrams/charts/appearance#series-line-styles)和[坐标轴](/diagrams/charts/axes)的**所有字段**，以及[参考线](/diagrams/charts/references)，都会绘制出来。
- **双击文本**可重命名，参见[在图表中编辑](/diagrams/charts/editing)。

## 选项

| 选项             | 类型                           | 说明                                                                                                       |
| ---------------- | ------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| `id`             | `string`                       | 图表存储的 ID。默认值为 `'d3'`                                                                               |
| `label`          | `string`                       | 菜单中显示的名称。默认值为 `'d3'`                                                                               |
| `customizers`    | `Record<string, D3Customizer>` | 按名称注册、用于修改绘制后图表的函数。默认值为 `{}`。参见[自定义器](/diagrams/renderers/d3#customizers) |
| `measureText`    | `(text, fontSize) => number`   | 返回标签的宽度，以获取精确的标签宽度。未提供时，宽度将通过估算得出                                 |
| `createDocument` | `() => Document`               | 当没有 `document` 时（例如在服务器上），为 `toSVG` 提供一个 `Document`                                        |
| `sankey`         | `d3-sankey` 模块                | 用于绘制桑基图                                                                                                 |

## 桑基图

```bash
npm install d3-sankey
```

```ts
import * as sankey from 'd3-sankey'

d3Renderer({ sankey })
```

如果未提供 `sankey`，D3 渲染器的类型列表中不会包含 `sankey`，桑基图将由其他渲染器绘制。

## 自定义器

自定义器是一个按名称注册的函数。图表通过该名称引用它：

```ts
d3Renderer({
  customizers: {
    highlightMax(svg, { data }) {
      // change the drawn SVG element: add marks, reorder, restyle
    },
  },
})

editor.commands.updateChartSpec({ spec: { renderer: { d3: { customizer: 'highlightMax' } } } })
```

自定义器接收绘制后的 `SVGSVGElement` 和 `{ data, spec, theme, size }`。每次绘制后都会运行，包括在编辑器中绘制和导出时。

文档中只会存储自定义器的名称，不会存储其代码。如果图表引用的自定义器在当前编辑器中不存在，绘制时将不会使用自定义器。

## 导出和服务器

在浏览器中，`toSVG` 无需额外设置。在服务器上，请传入 DOM 实现：

```ts
import { parseHTML } from 'linkedom'

d3Renderer({
  createDocument: () => parseHTML('<!doctype html><html><body></body></html>').document,
})
```
