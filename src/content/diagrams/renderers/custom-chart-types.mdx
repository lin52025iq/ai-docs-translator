## 快速入门

```ts
import { Diagrams, chartLinks, type ChartRenderer } from '@tiptap-pro/extension-diagrams'

const chordRenderer: ChartRenderer = {
  id: 'chord',
  label: 'Chord',
  types: ['chord'],
  mount(target, input) {
    // chartLinks(input.data) gives { nodes, links }, read the way sankey and network read them.
    // Draw into target, then return { update, destroy }.
  },
  async toSVG(input) {
    // ...
  },
}

Diagrams.configure({
  renderers: [echartsRenderer(), chordRenderer],
  chartTypes: [
    {
      id: 'chord',
      label: 'Chord',
      shape: 'graph',
      word: 'image',
      description: 'Flows between groups drawn around a circle: from, to and how much.',
    },
  ],
})
```

[成员](/diagrams/renderers/custom#members)介绍了 Renderer 的其他内容。

## 图表类型的字段

| 字段          | 类型                                                                        | 说明                                                                                                                      |
| ------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `id`          | `string`                                                                    | 图表存储在 `spec.type` 中的内容：字母、数字、`_` 和 `-`，最多 64 个字符                                                    |
| `label`       | `string`                                                                    | 用于菜单                                                                                                                  |
| `shape`       | `'cartesian' \| 'radial' \| 'single' \| 'hierarchy' \| 'matrix' \| 'graph'` | 数据布局：该类型读取列和行的方式。快速输入会显示这种布局的示例行                                                          |
| `word`        | `'chart' \| 'table' \| 'image'`                                             | Word 文档保存此类型图表的方式：作为 Word 图表、Word 表格或图像。请使用 `'image'`（见下文）                                |
| `description` | `string`                                                                    | 可选。供用于选择类型的 AI 模型参考的一句话说明                                                                            |

`shape` 的数据布局：

| `shape`     | 列和行                                   | 内置类型示例       |
| ----------- | ---------------------------------------- | ------------------ |
| `cartesian` | 一列标签和一个或多个系列                 | line、bar、radar、combo |
| `radial`    | 一列标签和一个系列，表示整体的各个部分   | pie、funnel        |
| `single`    | 一个值                                   | gauge              |
| `hierarchy` | 标签以路径形式表示（如 `A / B`），每个叶节点对应一个值 | treemap、tree      |
| `matrix`    | 网格中的词语                             | matrix (RACI)      |
| `graph`     | 一列源、一列目标，每条连接对应一个值     | sankey、network    |

### Word 图表和表格

该扩展仅为内置类型生成 Word 图表或 Word 表格。自定义类型在 Word 中会成为图像，即使设置了
`word: 'chart'` 或 `word: 'table'` 也是如此。因此请将其设为
`word: 'image'`。关于 Word 中的导出结果，请参阅[导出](/diagrams/export)。

## 注册的类型会出现在哪里

- **快速输入。** 可以在 `:::` 后输入该类型。
- **`setDiagramInputType`** 可以选择该类型。
- **AI 模型。** 工具和 `describeCapabilities()` 会向 AI 模型提供该类型。
- **内置类型 id。** 使用内置类型 id 的条目会替换该类型的定义，例如其标签和说明。

## 像内置类型一样读取行

| 函数                   | 读取行的方式             | 返回值                                                                                   |
| ---------------------- | ------------------------ | ---------------------------------------------------------------------------------------- |
| `chartHierarchy(data)` | 与内置 `hierarchy` 类型相同 | 一个 `{ name, path, value, total, children }` 树，路径示例：`Europe / Germany`            |
| `chartLinks(data)`     | 与内置 `graph` 类型相同     | `{ nodes, links }`，每行对应一条连接                                                     |
