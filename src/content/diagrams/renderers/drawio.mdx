## 快速开始

```ts
import { Diagrams } from '@tiptap-pro/extension-diagrams'
import { drawioDiagramRenderer } from '@tiptap-pro/extension-diagrams/drawio'
import rendererUrl from '@tiptap-pro/extension-diagrams/drawio-renderer?url&no-inline'
import viewerUrl from './vendor/drawio/viewer-static.min.js?url'

Diagrams.configure({
  diagramRenderers: [drawioDiagramRenderer({ viewerUrl, rendererUrl })],
})
```

## 选项

| Option        | Type             | Description                                                                                                                                                                   |
| ------------- | ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `viewerUrl`   | `string`         | 必填。draw.io 查看器，即 draw.io 发布版本中的 `viewer-static.min.js`（位于 `jgraph/drawio` 仓库的 `src/main/webapp/js/`）。它不在 npm 上，因此需要自行提供服务 |
| `rendererUrl` | `string`         | 必填。作为文件提供的 `@tiptap-pro/extension-diagrams/drawio-renderer`。使用 Vite 时，添加 `?url&no-inline`                                                                     |
| `scriptNonce` | `string \| null` | 用于采用 nonce 的内容安全策略的页面                                                                                                                                           |
| `id`          | `string`         | 默认值为 `'drawio'`                                                                                                                                                            |
| `label`       | `string`         | 默认值为 `'draw.io'`                                                                                                                                                           |

## draw.io 源是什么

`format: 'drawio'` 格式的图表包含 draw.io XML：

```ts
editor.commands.insertFlowDiagram({ source: drawioXml, format: 'drawio', title: 'Order process' })
```

- **源**是一个 `<mxfile>` 或独立的 `<mxGraphModel>`。
- **文档存储**一个 `<mxfile>`，其中的页面是纯 XML，因此你可以读取和比较存储的文本。
- **独立模型**会转换为包含一个页面的文件。
- **经过 draw.io 压缩的页面**会被解压缩。无法解压缩的页面则保持原样。
- **粘贴**作为文本的 draw.io XML 会生成 draw.io 图表。

对于其他任何内容，以及长度超过 1,000,000 个字符的源，`insertFlowDiagram` 和 `updateFlowDiagram` 都会返回 `false`。

`updateFlowDiagram({ source, format })` 会更改图表格式，例如 Mermaid 图表从 draw.io 编辑器返回时。更改格式时，必须在同一次调用中提供新的 `source`。

## 绘制方式

draw.io 查看器会在每个页面中运行于一个隐藏的 iframe 内，并设置 `sandbox="allow-scripts"`，且策略禁止所有网络请求。首次绘制 draw.io 图表时会加载查看器，其大小约为 4.4 MB，压缩后约为 940 kB。绘制耗时数十毫秒，结果会按源缓存。

### 图表的显示效果

- **颜色。** 图表保留绘制时使用的颜色。`--tt-flow-diagram-*` 自定义属性不会应用到图表上。
- **背景。** 图表使用自身背景绘制；如果没有背景，则使用白色背景。
- **配色方案。** 在 draw.io 支持的情况下，SVG 会遵循页面的浅色或深色配色方案。
- **HTML 标签**会被绘制。
- **标签中的链接**不起作用，因为图表会以图像形式显示。
- **来自 AWS、Azure、Cisco 等库的图形模板**会绘制为空框。查看器无法在沙盒中加载这些图形模板文件。
- 图表中的**图像**必须使用 `data:` URL。

### 导出时

- **PNG、WebP、JPEG 和 Word。** 标签会以纯文本形式显示。标签中以 HTML 编写的粗体、颜色和换行都会丢失。
- **在服务器上。** draw.io 图表无法导出，因为查看器需要在浏览器中排版文本。

## 在 draw.io 编辑器中编辑

此入口模块通过 JSON 嵌入模式连接 draw.io 编辑器。你需要创建对话框和 iframe；此软件包会提供编辑器保存的内容。

```ts
import { connectDrawioEditor, drawioEditorUrl } from '@tiptap-pro/extension-diagrams/drawio'

const frame = document.createElement('iframe')
frame.src = drawioEditorUrl() // https://embed.diagrams.net/?embed=1&proto=json…
dialog.append(frame)

const connection = connectDrawioEditor(frame, {
  source: diagram.source,
  title: diagram.title ?? undefined,
  onSave: (source) => editor.commands.updateFlowDiagram({ pos, source, format: 'drawio' }),
  onExit: () => {
    connection.destroy()
    dialog.close()
  },
})
```

### drawioEditorUrl(options?)

构建编辑器 URL。

| Option        | Type                     | Description                                                                                                                    |
| ------------- | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| `base`        | `string`                 | draw.io 编辑器。默认值为 `https://embed.diagrams.net/`。可指向你自己的副本，避免图表发送到第三方来源 |
| `saveAndExit` | `boolean`                | 在“保存”旁提供“保存并退出”选项。默认值为 `true`                                                                              |
| `params`      | `Record<string, string>` | 添加编辑器 URL 参数，例如 `lang`                                                                                               |

### connectDrawioEditor(frame, options)

在 `frame` 中用编辑器打开图表。返回 `{ destroy }`。

| Option                     | Type                         | Description                                                                                              |
| -------------------------- | ---------------------------- | -------------------------------------------------------------------------------------------------------- |
| `source`                   | `string`                     | 要打开的 draw.io XML。为空时会打开空白页面                                                                |
| `mermaid`                  | `string`                     | 改为打开 Mermaid 源码。编辑器会将其转换为 draw.io 图形，并将 `subgraph` 转换为泳道                         |
| `title`                    | `string`                     | 显示在编辑器标题栏中                                                                                      |
| `onSave(source, { exit })` | `(source, { exit }) => void` | 必填。点击“保存”时会传入 XML；点击“保存并退出”时还会传入 `exit: true`                                      |
| `onExit()`                 | `() => void`                 | 必填。编辑器关闭时调用；点击“保存并退出”后也会调用                                                        |
| `onAutosave(source)`       | `(source) => void`           | 设置后，每次更改后都会传入 XML 并调用                                                                     |
| `onError(message)`         | `(message) => void`          | 编辑器无法打开源，或收到的内容不是 draw.io XML 时调用                                                     |

- **图表**只会发送到 iframe URL 的来源。
- **消息**只会从该 iframe 及其来源读取。
- **`onSave` 收到的内容**会像存储的 draw.io 源一样进行规范化处理。请参阅[draw.io 源是什么](/diagrams/renderers/drawio#what-a-drawio-source-is)。
- **编辑器操作的是副本。** 如果其他人在编辑器打开期间修改了同一图表，下一次保存会覆盖他们的更改。

### 从 Mermaid 转换为 draw.io

使用 `mermaid` 选项打开 Mermaid 图表，并使用 `format: 'drawio'` 保存。图表会转换为 draw.io 格式。只能通过撤销操作恢复为 Mermaid。

### 自行托管编辑器

draw.io 编辑器是一个静态 Web 应用，以 `jgraph/drawio` Docker 镜像发布：

```sh
docker run --rm -p 8080:8080 jgraph/drawio
```

```ts
frame.src = drawioEditorUrl({ base: 'http://localhost:8080/' })
```

- 图表只会发送到该来源，不会传到 draw.io 的服务器。
- 如果你的页面通过 HTTPS 提供服务，也要通过 HTTPS 提供编辑器。
- 其他方面没有变化。嵌入协议与 `embed.diagrams.net` 上的协议相同。
- 无需互联网连接也可以编辑。不过，标签中的 Web 字体和在线图形库仍需要网络连接。
- 将镜像版本固定到某个标签。更新镜像时，也要一并更新作为 `viewerUrl` 提供的查看器，确保编辑器和查看器读取相同的 XML。
