## 快速开始

```ts
import { Diagrams } from '@tiptap-pro/extension-diagrams'
import { d3Renderer } from '@tiptap-pro/extension-diagrams/d3'
import { echartsRenderer } from '@tiptap-pro/extension-diagrams/echarts'

Diagrams.configure({
  renderers: [echartsRenderer(), d3Renderer()],
  defaultRenderer: 'echarts',
})
```

此扩展不捆绑任何图表库。每个库都需要作为同级依赖安装，或通过你提供的脚本加载，
并且须遵循该库自身的许可证使用。

## 该使用哪个渲染器

图表渲染器用于绘制图表，并通过 `renderers` 传入。图示渲染器用于绘制一种或多种
图示格式，例如 Mermaid 或 BPMN，并通过 `diagramRenderers` 传入。你可以分别注册多个渲染器。图示会由第一个接受其源内容的图示渲染器绘制，详见
[哪个渲染器会绘制图示](/diagrams/renderers/custom-diagrams#which-renderer-draws-a-diagram)。

| 渲染器                                 | 绘制内容                                                                           | 适用场景                                                                 |
| -------------------------------------- | ------------------------------------------------------------------------------------ | -------------------------------------------------------------------------- |
| [ECharts](/diagrams/renderers/echarts) | 图表：所有内置类型                                                                   | 支持最多图表类型，以及在服务器上处理 SVG 文件                            |
| [D3](/diagrams/renderers/d3)           | 图表：大多数类型，以及使用 `d3-sankey` 的桑基图                                      | 通过代码修改图表，以及在带有 DOM 的服务器上处理 SVG 文件                  |
| [Mermaid](/diagrams/renderers/mermaid) | 图表：饼图、折线图、竖向柱状图、桑基图、雷达图、矩形树图。图示：所有 Mermaid 类型     | 为图表和图示采用统一的 Mermaid 风格                                        |
| [Pele](/diagrams/renderers/pele)       | 图示：所有 Mermaid 类型                                                              | 无需 iframe 的 Mermaid 图示，加载体积更小，也可在服务器上使用             |
| [draw.io](/diagrams/renderers/drawio)  | 图示：draw.io XML                                                                    | 在 draw.io 编辑器中绘制和修改的图示                                        |
| [BPMN](/diagrams/renderers/bpmn)       | 图示：BPMN 2.0 XML                                                                   | BPMN 工具可读取的流程模型                                                  |

## 哪个渲染器会绘制图表

图表可以通过其 id 指定渲染器，该 id 由
[`setChartRenderer`](/diagrams/charts/appearance#setchartrenderer) 设置。扩展会按以下顺序选择一个已注册的图表渲染器：

1. 图表指定的渲染器（如果已注册且能绘制该图表类型）。
2. 否则，使用 `defaultRenderer`（如果它能绘制该类型）。
3. 否则，使用第一个能绘制该类型的已注册渲染器。

图表的根元素会通过 `data-tt-chart-renderer` 标明绘制它的渲染器。

### 渲染器不接受绘制某个图表时

渲染器可以拒绝绘制其支持的某种类型的图表。例如，[Mermaid 渲染器](/diagrams/renderers/mermaid#limits)会拒绝绘制包含多个系列的柱状图。

- **其他渲染器支持该类型。** 上述顺序中的下一个渲染器会绘制该图表。
- **没有其他渲染器支持该类型。** 最后仍会由拒绝绘制的渲染器绘制该图表。
- **图表保留原有选择。** 它仍会指定之前指定的渲染器。
- **导出时使用 `renderer` 选项。** 即使该渲染器拒绝绘制，也会照常使用它。

### 没有渲染器支持该类型时

图表会显示 [`unavailable`](/diagrams/api-reference/options#unavailable) 返回的内容。其数据仍会保留在文档中。

### 更换渲染器时

- **只有绘制效果会变化。** 图表数据和图表规范保持不变。
- **某个渲染器的选项**如果由图表存储在 `spec.renderer[id]` 下，其他渲染器会忽略这些选项。
- **颜色和字体**对所有渲染器都来自相同的 `--tt-chart-*` 自定义属性。
  详见[样式设置](/diagrams/guides/styling)。

图示会交由第一个支持其格式且未拒绝绘制的图示渲染器处理。详见
[哪个渲染器会绘制图示](/diagrams/renderers/custom-diagrams#which-renderer-draws-a-diagram)。

## 自定义渲染器

你可以使用任意库创建自己的图表渲染器。它接收图表数据和图表规范，而不会接收文档。

- [自定义渲染器](/diagrams/renderers/custom)介绍了完整的图表渲染器及其成员。
- [在画布上绘制的渲染器](/diagrams/renderers/custom-canvas)会绘制 PNG。所有导出文件（包括 SVG）都由它生成。
- [图表类型](/diagrams/renderers/custom-chart-types)介绍如何添加图表类型。
- [图示渲染器](/diagrams/renderers/custom-diagrams)用于绘制图示格式。
