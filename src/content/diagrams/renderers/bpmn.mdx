## 快速开始

```ts
import { Diagrams } from '@tiptap-pro/extension-diagrams'
import { bpmnDiagramRenderer } from '@tiptap-pro/extension-diagrams/bpmn'
import rendererUrl from '@tiptap-pro/extension-diagrams/bpmn-renderer?url&no-inline'
import viewerUrl from 'bpmn-js/dist/bpmn-viewer.production.min.js?url&no-inline'

Diagrams.configure({
  diagramRenderers: [bpmnDiagramRenderer({ viewerUrl, rendererUrl })],
})

editor.commands.insertFlowDiagram({ source: bpmnXml, format: 'bpmn', title: 'Payment check' })
```

bpmn-js 不是此软件包的依赖项。请自行安装，将其捆绑文件作为文件提供，并遵守其许可协议。

## 选项

| 选项          | 类型             | 说明                                                                                       |
| ------------- | ---------------- | ------------------------------------------------------------------------------------------ |
| `viewerUrl`   | `string`         | 必填。bpmn-js 捆绑文件：`bpmn-js/dist/bpmn-viewer.production.min.js`。也可以使用建模器捆绑文件。 |
| `rendererUrl` | `string`         | 必填。`@tiptap-pro/extension-diagrams/bpmn-renderer`，需作为文件提供。使用 Vite 时，添加 `?url&no-inline`。 |
| `scriptNonce` | `string \| null` | 用于采用基于 nonce 的内容安全策略的页面                                                     |
| `id`          | `string`         | 默认值：`'bpmn'`                                                                            |
| `label`       | `string`         | 默认值：`'BPMN'`                                                                            |

## 绘制方式

每个页面中，bpmn-js 都在一个 iframe 中运行，该 iframe 使用 `sandbox="allow-scripts"`，并采用禁止网络请求的策略。由于 bpmn-js 会在绘制时测量标签，iframe 会被放置在屏幕之外。第一个 BPMN 图表加载时会加载它，之后每次绘制结果都会按源内容缓存。

- **布局。** XML 必须包含布局（BPMN DI），就像由建模器保存的内容一样。没有布局的流程不会绘制。
- **颜色。** 图表会在独立页面上以黑色绘制在白色背景上。`--tt-flow-diagram-*` 自定义属性不会传递到该页面。
- **PNG、WebP、JPEG 和 Word 导出。** 标签是 SVG 文本，因此导出文件中的图表外观与编辑器中一致。
- **在服务器上。** 无法导出 BPMN 图表，因为 bpmn-js 需要在浏览器中排版文本。

### bpmn.io 署名

渲染器的规则要求添加带有 bpmn.io 徽标的“Powered by bpmn.io”链接。该链接显示在图表下方，并会绘制到每个导出文件中。`rendererRules` 无法将其移除。请参阅[渲染器规则](/diagrams/renderers/custom#rules-of-your-renderer)。

## BPMN 源内容的格式

- **根元素**是命名空间 `http://www.omg.org/spec/BPMN/20100524/MODEL` 中的 `definitions`，可以使用任意前缀。根元素会声明该命名空间。
- **XML 的结尾**是根元素的闭合标签，例如 `</bpmn:definitions>`。
- **文档会按原样存储源内容**，包括布局。只会移除字节顺序标记以及 XML 前后的空白。
- **允许源内容为空**，适用于尚未建模的流程。
- **粘贴 BPMN XML 文本**会生成 BPMN 图表。
- **`detectDiagramInput`** 对此类内容返回 `{ kind: 'bpmn' }`。

对于其他任何内容，以及超过 1,000,000 个字符的源内容，`insertFlowDiagram` 和 `updateFlowDiagram` 都会返回 `false`。

## 在建模器中编辑

`connectBpmnEditor` 会在你创建的 iframe 中运行 bpmn-js 建模器。该 iframe 仅启用脚本沙盒，并会在其中打开图表。对话框、iframe 和按钮都由你构建。需要时，软件包会提供 XML。

```ts
import { connectBpmnEditor } from '@tiptap-pro/extension-diagrams/bpmn'
import rendererUrl from '@tiptap-pro/extension-diagrams/bpmn-renderer?url&no-inline'
import fontUrl from 'bpmn-js/dist/assets/bpmn-font/css/bpmn-embedded.css?url&no-inline'
import bpmnStyleUrl from 'bpmn-js/dist/assets/bpmn-js.css?url&no-inline'
import diagramStyleUrl from 'bpmn-js/dist/assets/diagram-js.css?url&no-inline'
import modelerUrl from 'bpmn-js/dist/bpmn-modeler.production.min.js?url&no-inline'

const frame = document.createElement('iframe')
dialog.append(frame)

const connection = connectBpmnEditor(frame, {
  modelerUrl,
  rendererUrl,
  styleUrls: [diagramStyleUrl, bpmnStyleUrl, fontUrl],
  source: diagram.source,
  onReady: () => (saveButton.disabled = false),
})

saveButton.onclick = async () => {
  const source = await connection.save()
  editor.commands.updateFlowDiagram({ pos, source, format: 'bpmn' })
  connection.destroy()
  dialog.close()
}
```

### connectBpmnEditor(frame, options)

| 选项               | 类型                | 说明                                                                                                      |
| ------------------ | ------------------- | --------------------------------------------------------------------------------------------------------- |
| `modelerUrl`       | `string`            | 必填。bpmn-js 建模器捆绑文件：`bpmn-js/dist/bpmn-modeler.production.min.js`                                |
| `rendererUrl`      | `string`            | 必填。`@tiptap-pro/extension-diagrams/bpmn-renderer`，即渲染器使用的同一文件                                |
| `styleUrls`        | `readonly string[]` | 必填。建模器的样式表：`diagram-js.css`、`bpmn-js.css` 和 `bpmn-font/css/bpmn-embedded.css`                   |
| `scriptNonce`      | `string \| null`    | 用于采用基于 nonce 的内容安全策略的页面                                                                   |
| `source`           | `string`            | 要打开的 BPMN XML。留空则会打开一个带有开始事件的新流程                                                  |
| `onReady()`        | `() => void`        | 图表打开并可供编辑时调用                                                                                  |
| `onChange()`       | `() => void`        | 建模器每次发生更改后调用                                                                                  |
| `onError(message)` | `(message) => void` | 建模器加载失败或无法打开源内容时调用                                                                      |

它会返回 `{ save, destroy }`：

| 函数        | 返回值                                                                                                             |
| ----------- | ------------------------------------------------------------------------------------------------------------------ |
| `save()`    | 一个 Promise，解析为当前图表的 BPMN XML。如果建模器发送的内容不是 BPMN，则 Promise 会被拒绝                         |
| `destroy()` | 无返回值。停止监听并清空 iframe。iframe 仍归你所有                                                                 |

请使用嵌入式字体样式表，因为建模器的字体必须来自 `data:` URL 或样式表所在的源。

建模器处理的是副本。如果其他人在图表打开期间修改了同一图表，下次保存时会覆盖他们的更改。
