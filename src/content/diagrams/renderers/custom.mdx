## 图表渲染器

此渲染器直接使用 SVG 绘制柱状图，无需依赖库：

```ts
import type { ChartRenderer, ChartRenderInput } from '@tiptap-pro/extension-diagrams'

const SVG = 'http://www.w3.org/2000/svg'

function escapeXml(text: string): string {
  return text
    .replace(/&/g, '&amp;')
    .replace(/</g, '&lt;')
    .replace(/>/g, '&gt;')
    .replace(/"/g, '&quot;')
}

function barsSvg({ data, spec, theme, size }: ChartRenderInput): string {
  const series = data.columns.flatMap((column, index) =>
    column.role === 'series' ? [{ ...column, index }] : [],
  )
  const colors = spec.palette ?? theme.series
  const values = data.rows
    .flatMap((row) => series.map((column) => row[column.index]))
    .filter((cell): cell is number => typeof cell === 'number')
  const max = Math.max(1, ...values)
  const band = size.width / Math.max(1, data.rows.length)
  const bar = band / (series.length + 1)
  const plot = size.height - 24

  const bars = data.rows.flatMap((row, rowIndex) => [
    ...series.map((column, seriesIndex) => {
      const value = typeof row[column.index] === 'number' ? (row[column.index] as number) : 0
      const height = (value / max) * plot
      const x = rowIndex * band + bar * (seriesIndex + 0.5)
      return `<rect x="${x}" y="${plot - height}" width="${bar}" height="${height}" fill="${colors[seriesIndex % colors.length]}"/>`
    }),
    `<text x="${rowIndex * band + band / 2}" y="${size.height - 6}" text-anchor="middle" fill="${theme.labelColor}" font-family="${escapeXml(theme.fontFamily)}" font-size="${theme.fontSize}">${escapeXml(String(row[0] ?? ''))}</text>`,
  ])

  return `<svg xmlns="${SVG}" width="${size.width}" height="${size.height}" viewBox="0 0 ${size.width} ${size.height}">${bars.join('')}</svg>`
}

export const plainBarsRenderer: ChartRenderer = {
  id: 'plain-bars',
  label: 'Plain bars',
  types: ['bar'],
  // Leaves stacked bars to the next Renderer that draws bar charts
  draws: ({ spec }) => !spec.stacked,
  mount(target, input) {
    const draw = (next: ChartRenderInput) => {
      const svg = new DOMParser().parseFromString(barsSvg(next), 'image/svg+xml').documentElement
      target.replaceChildren(target.ownerDocument.importNode(svg, true))
    }
    draw(input)
    return { update: draw, destroy: () => target.replaceChildren() }
  },
  async toSVG(input) {
    return barsSvg(input)
  },
}
```

### 注册渲染器

```ts
import { Diagrams } from '@tiptap-pro/extension-diagrams'
import { echartsRenderer } from '@tiptap-pro/extension-diagrams/echarts'

Diagrams.configure({
  renderers: [echartsRenderer(), plainBarsRenderer],
})

editor.commands.setChartRenderer({ renderer: 'plain-bars' })
```

指定 `plain-bars` 的图表会由它绘制。其他图表仍使用各自的渲染器。请参阅[哪个渲染器会绘制图表](/diagrams/renderers/overview#which-renderer-draws-a-chart)。

### 成员

| 成员                    | 类型                                                                  | 说明                                                                                                                                            |
| ----------------------- | --------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                    | `string`                                                              | 图表将其存储为 `renderer` 的值                                                                                                                  |
| `label`                 | `string`                                                              | 可选。用于菜单                                                                                                                                |
| `types`                 | `readonly ChartType[]`                                                | 此渲染器可绘制的图表类型                                                                                                                        |
| `draws({ data, spec })` | `(chart) => boolean`                                                  | 可选。对于此渲染器无法良好绘制的支持类型图表，返回 `false`，交由其他渲染器处理                                                                   |
| `rules`                 | `RendererRules`                                                       | 可选。请参阅[渲染器规则](/diagrams/renderers/custom#rules-of-your-renderer)                                                                      |
| `mount(target, input)`  | `(target, input) => ChartRenderHandle \| Promise<ChartRenderHandle>` | 在 `target`（编辑器内的元素）中绘制，并返回 `{ update, destroy }`                                                                                |
| `toSVG(input)`          | `(input) => Promise<string>`                                          | 返回带有具体颜色的独立 SVG 字符串，供 `export` 使用                                                                                             |
| `toImage(input)`        | `(input) => Promise<Blob>`                                            | 返回尺寸为 `input.size` 的 PNG。若绘图所用的库基于 canvas，请参阅[基于 canvas 绘图的渲染器](/diagrams/renderers/custom-canvas)                   |

渲染器必须实现 `toSVG` 或 `toImage` 其中之一；所有导出文件都由其返回值生成。无论使用哪种方式，外框、署名和尺寸都相同。

- **使用 `toSVG` 时**，类型为 `VectorChartRenderer`。内置渲染器都属于此类型。
- **使用 `toImage` 时**，类型为 `RasterChartRenderer`。此时 SVG 文件中包含的是 PNG，而不是图形；`export` 返回 `raster: true`。

`mount` 返回 `{ update, destroy }`。数据、规格、主题或尺寸发生变化时，扩展会用新输入调用 `update(input)`。`destroy()` 会移除 `mount` 添加的内容。

### 渲染器接收的内容

`input` 的类型为 `ChartRenderInput`：

| 字段      | 类型                | 说明                                                               |
| --------- | ------------------- | ------------------------------------------------------------------ |
| `data`    | `ChartData`         | 图表数据，仅包含规格所选的列                                       |
| `spec`    | `ChartSpec`         | 图表规格                                                           |
| `theme`   | `ChartTheme`        | 用于绘图的具体值，见下文                                           |
| `size`    | `{ width, height }` | 单位为像素                                                         |
| `animate` | `boolean`           | 图表绘制或变更时可能会动则为 `true`。文件中不会出现此字段           |

`theme` 包含 `series` 颜色、`background`、`axisColor`、`gridColor`、`labelColor`、`titleColor`、`fontFamily`、`fontSize`、`titleSize`、`titleWeight`、`legendGap` 和 `legendMarkerSize`。这些都是已解析的值，也包括深色配色方案下的值。请使用这些值绘图，而不要使用 `var(…)`，这样图表才能与页面匹配并正确导出。除非调用方指定 `scheme: 'dark'`，否则 `toSVG` 和 `toImage` 接收的是浅色配色。

当编辑器中的 [`animation`](/diagrams/api-reference/options#animation) 选项开启，且用户的系统未要求减少动态效果时，`animate` 为 `true`。

渲染器不会读取文档、表格或数据源。类型化行、图表所跟随的表格，以及 URL 的快照，都会作为图表数据传入 `input.data`。请参阅[数据](/diagrams/data/overview)。

### 渲染器不得执行的操作

- 执行来自文档的代码。
- 插入来自文档的标记。
- 将标签、标题等文本作为 HTML 设置。文本是数据，应将其作为文本设置。

### 规格中需要遵循的内容

| 规格字段             | 绘制要求                                                                                                                  |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `type`               | 仅绘制 `types` 中的类型。对于无法绘制的变体，通过 `draws` 返回 `false`                                                     |
| `palette`            | 使用此字段，而不是 `theme.series`                                                                                          |
| `stacked`            | 堆叠柱状图或面积图的系列                                                                                                |
| `orientation`        | `'horizontal'`：将柱状图的柱子横向放置                                                                                    |
| `axes`, `references` | 绘制网格线和轴线、按 `axes.y.step` 设置刻度，以及指定值处的线和带。若无法绘制，则通过 `draws` 拒绝处理                     |
| `range`              | 仪表图的 `{ min, max }`                                                                                                    |
| `legend`, `title`    | 显示或隐藏图例和标题                                                                                                        |
| `series`             | 折线图或面积图中各系列的线条样式、宽度、标记和曲线平滑设置。若无法绘制，则通过 `draws` 拒绝处理                            |
| `renderer[id]`       | 图表在 `id` 下为你的渲染器单独存储的选项                                                                                    |

`@tiptap-pro/extension-diagrams/core` 中的这些函数可用于计算坐标轴，其方式与内置渲染器相同：

| 函数                                             | 返回值                                                                                                          |
| ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| `hasAxisLines(type)`                             | 对折线图、柱状图、面积图、散点图和组合图返回 `true`；这些类型的轴线由 `spec.axes` 设置                          |
| `hasRadarLines(type)`                            | 对雷达图返回 `true`；其环线（`y.grid`）和辐射线（`x.line`）由 `spec.axes` 设置                                   |
| `valueExtent(series, stacked)`                   | 数值轴必须涵盖的最小值和最大值，包括 0                                                                           |
| `valueAxisScale(spec, extent)`                   | 数值轴的 `{ min, max, ticks, fixed }`，包含步长和[参考线](/diagrams/charts/references)                           |
| `resolveAxisStrokes(spec, numericCategories?)`   | 绘制出的网格线和轴线，其中每个字段都已确定                                                                       |

### 图表中的文本

用户可以双击图表中的文本（例如标题）并直接重命名。请参阅[在图表中编辑](/diagrams/charts/editing)。ECharts 和 D3 渲染器支持此功能。Mermaid 渲染器不支持，因此双击不会打开任何内容。

如果 `mount` 返回的句柄包含 `onTextDoubleClick`，你的渲染器就支持此功能。该函数接收一个监听器，并返回一个用于移除该监听器的函数。双击时，使用 `ChartTextHit` 调用监听器：

| 字段     | 类型              | 说明                                                                      |
| -------- | ----------------- | ------------------------------------------------------------------------- |
| `target` | `ChartTextTarget` | 被点击的文本，见下文                                                      |
| `text`   | `string`          | 绘制出的文本                                                              |
| `box`    | `ChartTextBox`    | 页面像素坐标中的 `x`、`y`、`width`、`height`，取自 `getBoundingClientRect` |

| 目标                                   | 文本                                                     |
| -------------------------------------- | -------------------------------------------------------- |
| `{ kind: 'title' }`                    | 标题                                                     |
| `{ kind: 'axis', axis: 'x' \| 'y' }`  | 轴标题。`x` 是分类轴，也可以位于侧边                     |
| `{ kind: 'series', column }`           | 系列名称，由 `input.data` 中的列 ID 标识                 |
| `{ kind: 'category', row }`            | 分类标签或饼图扇区，由 `input.data` 中的行标识           |

```ts
mount(target, input) {
  const svg = draw(input)
  target.append(svg)
  const listeners = new Set<(hit: ChartTextHit) => void>()
  svg.addEventListener('dblclick', event => {
    const title = event.target instanceof Element ? event.target.closest('.title') : null
    if (!title) return
    const { x, y, width, height } = title.getBoundingClientRect()
    const hit: ChartTextHit = {
      target: { kind: 'title' },
      text: title.textContent ?? '',
      box: { x, y, width, height },
    }
    listeners.forEach(listener => listener(hit))
  })
  return {
    update: next => {},
    destroy: () => svg.remove(),
    onTextDoubleClick: listener => {
      listeners.add(listener)
      return () => listeners.delete(listener)
    },
  }
}
```

在只读编辑器中，编辑器不会打开文本字段；对于只读数据中的系列或分类，也不会打开文本字段。

## 渲染器规则

库的许可证可能要求显示署名，也可能限制可导出的文件格式。渲染器通过 `rules` 声明这些规则，扩展会在图表或图示出现的任何位置应用它们。图示渲染器也使用相同的 `rules`，例如 [BPMN 渲染器](/diagrams/renderers/bpmn#the-bpmnio-attribution)。

```ts
export const creditedRenderer: ChartRenderer = {
  ...plainBarsRenderer,
  id: 'credited-bars',
  rules: {
    attribution: {
      label: 'Drawn with Example',
      href: 'https://example.com',
      logo: '<svg viewBox="0 0 16 16">…</svg>',
    },
    exports: ['svg', 'png', 'docx'],
  },
}
```

| 规则          | 类型                                                        | 说明                                                      |
| ------------- | ----------------------------------------------------------- | --------------------------------------------------------- |
| `attribution` | `{ label: string, href: string, logo?: string }`            | 显示在每个图表或图示上的署名，详见下文                    |
| `exports`     | `readonly ('svg' \| 'png' \| 'webp' \| 'jpeg' \| 'docx')[]` | `export` 可以生成的格式。不设置列表时，允许所有格式       |

### attribution 的作用

- **在编辑器中**，它是位于图表或图示下方的链接（`tiptap-chart-attribution`、`tiptap-flow-diagram-attribution`）。
- **在每个导出的 SVG、PNG、WebP、JPEG 和 Word 图像中**，其标签都会绘制在右下角。
- **`logo`** 是独立的 SVG 标记，高度为 16 像素。

### exports 的作用

- **不在列表中的格式**会导致 `export` 抛出异常。
- **未包含 `docx` 时**，`exportDocx` 会在备注中说明并省略图示，而图表则会导出为原生 Word 图表。

### 添加规则

你添加的规则只能让渲染器受到更多限制。`withRendererRules(renderer, rules)` 会返回添加了规则的渲染器。`rendererRules` 选项可按渲染器 ID 添加规则。

```ts
import { Diagrams, withRendererRules } from '@tiptap-pro/extension-diagrams'

Diagrams.configure({
  renderers: [withRendererRules(plainBarsRenderer, { exports: ['svg', 'png'] })],
  rendererRules: {
    drawio: { attribution: { label: 'draw.io', href: 'https://www.drawio.com' } },
  },
})
```

- **渲染器声明的署名**会保留，不能移除。
- **你添加的署名**仅在渲染器未声明署名时生效。
- **允许的格式**是两个列表都允许的格式。
- **`editor.storage.diagrams.rulesFor(renderer)`** 会返回当前生效的规则。
- **ECharts、D3、Mermaid 和 draw.io 的内置渲染器**不声明署名，并允许所有格式。
