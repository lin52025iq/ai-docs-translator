```ts
editor.commands.updateChartSpec({ spec: { type: 'area', stacked: true } })
editor.chain().focus().insertDiagramInput({ type: 'pie' }).run()
```

## 每条命令的行为

带有 `pos` 参数的命令会作用于该位置的图表或示意图。不带 `pos` 时，则作用于当前选中的图表或示意图。如果没有可操作的对象，命令会返回 `false`，且不做任何更改。

读取图表或示意图无需使用命令。读取它们的函数位于
[`editor.storage.diagrams`](/diagrams/api-reference/storage)。
