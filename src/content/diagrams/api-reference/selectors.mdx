## 类

| Class                              | Element                                                                                                                                                                 |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `tiptap-chart`                     | 编辑器中图表的根元素，带有 `role="figure"` 和取自描述或标题的 `aria-label`                                                                                              |
| `tiptap-chart-viewport`            | 位于画布周围。图表放大时，可在其中滚动                                                                                                                                    |
| `tiptap-chart-zoom-box`            | 位于视口和画布之间，占据放大后图表的空间                                                                                                                                    |
| `tiptap-chart-canvas`              | 图表在文本中所占的区域                                                                                                                                                |
| `tiptap-chart-stage`               | 渲染器绘制内容的元素。应用 `minRenderWidth` 时会缩小                                                                                                                      |
| `tiptap-chart-caption`             | 图表下方：当规范中设置 `caption: true` 时显示描述                                                                                                                        |
| `tiptap-chart-text-input`          | 双击图表中的文本时弹出的输入框，可用于重命名该文本（[编辑图表中的文本](/diagrams/charts/editing)）                                                                        |
| `tiptap-chart-attribution`         | 图表下方：渲染器规则要求显示的链接。没有链接时为 `hidden`（[渲染器的规则](/diagrams/renderers/custom#rules-of-your-renderer)）                                           |
| `tiptap-chart-error`               | 绘制失败时显示的消息                                                                                                                                                     |
| `tiptap-chart-unavailable`         | [`unavailable`](/diagrams/api-reference/options#unavailable) 返回的内容；此处没有渲染器可绘制图表时显示                                                                      |
| `tiptap-diagram-input`             | 快速输入框，用于输入图表语法                                                                                                                                                |
| `tiptap-diagram-input-placeholder` | 在快速输入框中，显示在注明类型的首行下方：输入某行之前显示 `placeholder` 选项中的示例行                                                                                     |
| `tiptap-chart-resize-handle`       | 调整图表大小的控点；启用 `resizable` 后，在选中图表时显示                                                                                                                  |

## 数据属性

### 图表上的属性

位于 `.tiptap-chart` 上：

| Attribute                 | Values                                                                               |
| ------------------------- | ------------------------------------------------------------------------------------ |
| `data-tt-chart-type`      | 图表的 `spec.type`：`line`、`bar`、`radar`、`sankey`……或你注册的类型                     |
| `data-tt-chart-renderer`  | 绘制图表的渲染器 ID                                                                   |
| `data-tt-chart-state`     | `idle`、`empty`、`loading`、`ready`、`unavailable`、`error`                          |
| `data-tt-chart-source`    | `none`、`linked`、`detached`                                                         |
| `data-tt-chart-readonly`  | 数据为只读时存在                                                                      |
| `data-tt-chart-legend`    | `top`、`right`、`bottom`、`left`、`none`                                             |
| `data-tt-chart-selected`  | 选中图表时存在                                                                        |
| `data-tt-chart-zoom`      | `fit` 或缩放比例，例如 `1.5`（`setZoom`）                                             |
| `data-tt-chart-maximized` | 图表覆盖窗口显示时存在（`setMaximized`）                                               |
| `data-tt-chart-border`    | 规范中设置 `border: true` 时存在                                                      |
| `data-tt-chart-hidden`    | 仅显示图表所跟随的表格时存在。此时不显示图表                                           |
| `data-tt-chart-panning`   | 拖动放大后的图表时存在（`setPan`）                                                    |
| `data-tt-chart-sized`     | 规范中设置了 `size` 时存在                                                           |
| `data-tt-chart-align`     | 对于未居中的定尺寸图表，值为 `left` 或 `right`（`setDiagramAlign`）                    |
| `data-tt-chart-resizing`  | 拖动控点时存在                                                                        |

### 调整大小控点上的属性

| Element                       | Attribute              | Values                                                   |
| ----------------------------- | ---------------------- | -------------------------------------------------------- |
| `.tiptap-chart-resize-handle` | `data-tt-chart-resize` | `left`、`right`、`bottom`、`bottom-left`、`bottom-right` |

### 快速输入框上的属性

位于 `.tiptap-diagram-input` 上：

| Attribute                    | Values                                                                                                                                 |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `data-tt-diagram-input-type` | 快速输入框将生成的图表类型                                                                                                               |
| `data-tt-chart-delimiter`    | `comma`、`semicolon`、`pipe`、`tab`、`none`：用于拆分所输入内容的分隔符，由 `setDiagramInputDelimiter` 设置或自动检测                         |
| `data-tt-chart-placeholder`  | 快速输入框为空时显示的 `placeholder` 选项文本，通过 `::before` 显示                                                                         |

### HTML 输出和其他节点上的属性

| Attribute                    | Element                                                                                                 |
| ---------------------------- | ------------------------------------------------------------------------------------------------------- |
| `data-tt-chart-spec`         | JSON 格式的图表规范，位于 `figure[data-type="chart"]` 上                                                  |
| `data-tt-chart-link`         | JSON 格式的数据源，位于 `figure[data-type="chart"]` 上                                                    |
| `data-tt-chart-synced-at`    | 上次从数据源读取数据的时间，以 ISO 时间格式表示，位于 `figure[data-type="chart"]` 上                         |
| `data-tt-chart-renderer`     | 选定的渲染器，位于 `figure[data-type="chart"]` 上                                                         |
| `data-tt-chart-delimiter`    | 输入数据时使用的分隔符，位于 `figure[data-type="chart"]` 上                                                |
| `data-tt-diagram-input`      | 用作图表输入的表格上的属性                                                                                 |
| `data-tt-chart-table-id`     | 图表所跟随的表格上的属性                                                                                   |
| `data-tt-chart-image-source` | 使用 `keepData` 从图表生成的图像上的属性                                                                   |
| `data-tt-attribution`        | 图表或示意图导出的 SVG 中 `<a>` 上的属性；渲染器要求提供来源链接时使用                                         |

- **图表规范中的 `palette`** 会覆盖该图表的系列颜色。系列颜色即数据系列（例如柱形或折线）的颜色。

#### 导出和 Word 中的字体

- **导出的图像**只能使用导出该图像的计算机上已安装的字体。
- **页面加载的 Web 字体**无法用于导出的图像。
- **原生 Word 图表**只指定一种字体：它会使用 Word 自带的 `--tt-chart-font-family` 中第一个字体系列（`WORD_FONTS`）、对应的通用字体系列，或 `fallbackFont`（`'Arial'`）。
- **`wordFontFor(fontFamily)`** 会告知 Word 是否会使用与页面不同的字体。

### 高亮的源文本

源文本在快速输入框、Mermaid 示意图的代码视图以及任何带有 `tiptap-diagram-source` 类的元素中都会着色，例如你自己的源文本编辑器。选项 [`sourceHighlighting`](/diagrams/api-reference/options#sourcehighlighting) 只会关闭快速输入框和代码视图中的颜色，不影响你自己的元素。

| Class                            | Part                   | Color property                 | Light default |
| -------------------------------- | ---------------------- | ------------------------------ | ------------- |
| `tiptap-diagram-source-keyword`  | 示意图或图表类型、语句关键字 | `--tt-diagram-source-keyword`  | `#1e40af`     |
| `tiptap-diagram-source-label`    | 形状中的标签、引号内容和第一列 | `--tt-diagram-source-label`    | `#3f6212`     |
| `tiptap-diagram-source-number`   | 数字                   | `--tt-diagram-source-number`   | `#7c2d12`     |
| `tiptap-diagram-source-operator` | 箭头、分隔符、括号、冒号 | `--tt-diagram-source-operator` | `#52525b`     |
| `tiptap-diagram-source-comment`  | 注释（`%%`）            | `--tt-diagram-source-comment`  | `#4b4b53`     |

- **每种颜色的深色值**均按默认颜色的相同方式推导。在两种配色方案下，每种颜色与输入框背景的对比度都至少为 4.5:1。
- **要取消某一部分的着色**，请将其属性设为 `inherit`。

## 示意图

示意图（`flowDiagram` 节点，参见[示意图](/diagrams/flow-diagrams/overview)）采用相同模式，但使用自己的名称。

### 示意图类

| Class                               | Element                                                                                                                                                                          |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `tiptap-flow-diagram`               | 编辑器中示意图的根元素，带有 `role="figure"` 和取自描述或标题的 `aria-label`                                                                                                       |
| `tiptap-flow-diagram-viewport`      | 位于画布周围。示意图放大时，可在其中滚动                                                                                                                                            |
| `tiptap-flow-diagram-zoom-box`      | 位于视口和画布之间，占据放大后示意图的空间                                                                                                                                            |
| `tiptap-flow-diagram-canvas`        | 以 `<img>` 的形式承载绘制好的示意图                                                                                                                                               |
| `tiptap-flow-diagram-code`          | 视图为 `code` 时显示的源文本，用来替代绘制好的示意图                                                                                                                                 |
| `tiptap-flow-diagram-caption`       | 示意图下方：标题                                                                                                                                                                  |
| `tiptap-flow-diagram-attribution`   | 示意图下方：示意图渲染器规则要求显示的链接。没有链接时为 `hidden`                                                                                                                    |
| `tiptap-flow-diagram-error`         | 绘制失败时显示的消息                                                                                                                                                              |
| `tiptap-flow-diagram-unavailable`   | [`unavailable`](/diagrams/api-reference/options#unavailable) 返回的内容；此处没有渲染器可绘制示意图时显示                                                                              |
| `tiptap-flow-diagram-resize-handle` | 调整示意图大小的控点；启用 `resizable` 后，在选中示意图时显示                                                                                                                       |
| `tiptap-flow-diagram-label-input`   | 双击任意类型的 Mermaid 示意图中的文本时弹出的输入框，可用于编辑该文本。draw.io 或 BPMN 中没有此输入框（[编辑示意图](/diagrams/flow-diagrams/editing)）                                  |
