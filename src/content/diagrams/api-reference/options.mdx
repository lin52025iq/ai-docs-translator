## 渲染器

### renderers

`ChartRenderer[]` · 默认值 `[]`

可用于绘制图表的渲染器。请参阅[渲染器](/diagrams/renderers/overview)。如果没有渲染器，图表会显示 [`unavailable`](/diagrams/api-reference/options#unavailable) 返回的内容。

### diagramRenderers

`DiagramRenderer[]` · 默认值 `[]`

可用于绘制示意图的渲染器。请参阅[示意图](/diagrams/flow-diagrams/overview)。如果没有示意图渲染器，示意图会显示 [`unavailable`](/diagrams/api-reference/options#unavailable) 返回的内容。

| 示意图渲染器             | 导入路径                                  |
| ------------------------ | ----------------------------------------- |
| `mermaidDiagramRenderer` | `@tiptap-pro/extension-diagrams/mermaid`  |
| `drawioDiagramRenderer`  | `@tiptap-pro/extension-diagrams/drawio`   |
| `bpmnDiagramRenderer`    | `@tiptap-pro/extension-diagrams/bpmn`     |

### defaultRenderer

`string | null` · 默认值 `null`

用于绘制未指定渲染器的图表的渲染器 ID。如果未设置，图表将使用第一个能够绘制其类型的已注册渲染器。

### chartTypes

`{ id, label, shape, word, description? }[]` · 默认值 `[]`

添加到内置图表类型中的类型。若新增类型的 ID 与某个内置类型相同，则会替换该内置类型。请参阅[注册自定义图表类型](/diagrams/renderers/custom-chart-types)。

### rendererRules

`Record<string, { attribution?, exports? }>` · 默认值 `{}`

按渲染器 ID 指定要添加到渲染器声明规则中的规则。这些规则只能让渲染器受到更多限制。请参阅[添加规则](/diagrams/renderers/custom#adding-rules)。

## 数据

### sources

`ChartSourceProvider[]` · 默认值 `[]`

添加到内置 `url-csv`、`url-json` 和 `document-table` 中的数据源提供程序。请参阅[数据源](/diagrams/data/sources)。

### formats

`ChartFormat[]` · 默认值 `[]`

添加到 `chart-json`、`chart-syntax` 和 `mermaid` 中的文本格式。格式的结构为 `{ id, description, mediaType, schema?, example, parse, serialize }`。若新增格式的 ID 与某个内置格式相同，则会替换该内置格式。

### fetch

`typeof globalThis.fetch | null` · 默认值 `globalThis.fetch`

URL 提供程序用于读取数据的 `fetch` 函数。可以传入自定义函数以添加凭据或通过代理访问。

### allowSourceUrl

`((url: URL) => boolean) | null` · 默认值 `null`

决定 `url-csv` 和 `url-json` 可以读取哪些 URL。如果未设置，它们可以读取任何绝对 `http:` 或 `https:` URL，而 AI 工具 `insertLinkedChart` 会拒绝 URL 数据源。请参阅[读取 URL](/diagrams/data/sources#reading-a-url)。

```ts
Diagrams.configure({
  allowSourceUrl: (url) => url.hostname === 'data.example.com',
})
```

### onSourceError

`((error, { provider, address }) => void) | null` · 默认值 `null`

数据源无法读取时调用。图表会保留上一次的快照。请参阅[数据源](/diagrams/data/sources)。

## 输入

### trigger

`string` · 默认值 `':::'`

在空段落开头输入此文本时，会打开快速输入。

### codeBlockShortcut

`string | false` · 默认值 `'Mod-Enter'`

按下此键可将光标所在代码块中的 Mermaid 源码转换为图表或示意图，也可确认快速输入。设为 `false` 则不添加快捷键。请参阅[在代码块中使用 Mod-Enter](/diagrams/data/quick-input#mod-enter-in-a-code-block)。

## 显示

### resizable

`boolean` · 默认值 `false`

设为 `true` 后，在编辑器可编辑时，选中的图表或示意图上会显示缩放手柄。各手柄的功能请参阅[缩放手柄](/diagrams/guides/size-and-view#resize-handles)。

### lazyRendering

`boolean` · 默认值 `true`

设为 `true` 后，只有当图表或示意图进入视口半个屏幕范围内时才会绘制。每个动画帧最多开始绘制一个图表或示意图。

- 对远离视口的图表或示意图所做的更改（例如编辑、同步数据源或更换主题）会等到其再次接近视口时才绘制。
- 绘制之前，图表会保留其高度，示意图则只有几行高。
- 导出会自行绘制，不受此选项影响。
- 如果没有 `IntersectionObserver`，则会像设为 `false` 一样绘制所有图表和示意图。

设为 `false` 后，文档打开时会绘制所有图表和示意图，但仍然每帧绘制一个。适用于需要整体打印或截取的页面，以及 DOM 实现中的 `IntersectionObserver` 始终不触发的测试。

### animation

`boolean` · 默认值 `true`

设为 `true` 后，渲染器可以在首次绘制图表，以及图表数据或规格发生变化时播放动画。设为 `false` 后，所有图表都会直接绘制为最终状态。

- ECharts 渲染器会播放动画。
- D3 和 Mermaid 渲染器不会播放动画，示意图也不会播放动画。
- 如果查看者的系统要求减少动态效果（`prefers-reduced-motion: reduce`），则无论此选项如何设置，都不会播放动画。
- 导出内容不会播放动画。

### sourceHighlighting

`boolean` · 默认值 `true`

为快速输入中的文本以及 Mermaid 示意图代码视图中的文本着色，包括关键字、标签、数字、箭头、分隔符和注释。设为 `false` 后，文本将统一显示为一种颜色。颜色及其对应的类请参阅[高亮源码](/diagrams/api-reference/selectors#highlighted-source)。你自己的文本字段也可以通过 [`highlightSource`](/diagrams/guides/split-view) 显示这些高亮效果。

### styles

`ChartStyle[]` · 默认值 `[]`

除内置样式外，图表还可以在 `spec.style` 中指定这些样式。若新增样式的 ID 与某个内置样式相同，则会替换该内置样式。请参阅[样式](/diagrams/guides/styling#styles)。

```ts
Diagrams.configure({
  styles: [
    {
      id: 'brand',
      label: 'Brand',
      palette: ['#0b5fff', '#ff7a00'],
      appearance: { fontFamily: 'Inter, sans-serif' },
    },
  ],
})
```

### colorScheme

`'auto' | 'light'` · 默认值 `'auto'`

图表和示意图的绘制配色方案。`'auto'` 使用网页的配色方案，详见[深色配色方案](/diagrams/guides/styling#dark-color-scheme)。`'light'` 则无论页面配色如何，始终使用浅色绘制。

### unavailable

`(figure) => string | HTMLElement | null` · 默认值：一条说明图表或示意图无法在此处绘制的句子

没有已注册的渲染器能够绘制图表类型、示意图格式或 Mermaid 源码类型时，用于指定图表或示意图的替代显示内容。返回字符串、元素或 `null`，即可分别显示相应内容或不显示任何内容。数据会原样保留在文档中，除非你主动显示，否则不会显示。

此函数接收 `figure` 和 `{ kind, reason, pos, title, type?, format? }`：

| 字段     | 值                                                                                                                         |
| -------- | -------------------------------------------------------------------------------------------------------------------------- |
| `kind`   | `'chart'` 或 `'flowDiagram'`                                                                                               |
| `reason` | `'no-renderer'`；如果没有已注册的渲染器能够绘制该类型，则为 `'unsupported-kind'`                                            |
| `pos`    | 其位置，可用于命令或[存储函数](/diagrams/api-reference/storage)。不在文档中时为 `null`                                      |
| `title`  | 标题，或 `null`                                                                                                            |
| `type`   | 图表的类型                                                                                                                 |
| `format` | 示意图的格式                                                                                                               |

若要让用户打开数据，可返回一个按钮，在用户按下时读取数据：使用 [`read`](/diagrams/api-reference/storage) 或 `readTable` 读取图表数据，使用 `listDiagrams` 读取示意图源码。此处的 `openDialog` 是你自己的对话框。你也可以直接在原位置显示数据。

```ts
Diagrams.configure({
  unavailable: (figure) => {
    const button = document.createElement('button')
    button.textContent = `Show the ${figure.kind === 'chart' ? 'data' : 'source'}`
    button.addEventListener('click', () => {
      const text =
        figure.kind === 'chart'
          ? editor.storage.diagrams.read({ pos: figure.pos ?? -1, format: 'chart-syntax' })
          : editor.storage.diagrams.listDiagrams().find((diagram) => diagram.pos === figure.pos)
              ?.source
      openDialog(text ?? '')
    })
    return button
  },
})
```

## 导出

### docxImages

`'auto' | 'always'` · 默认值 `'auto'`

调用时未传入 `images` 参数的情况下，`exportDocx` 如何写入图表。`'auto'` 会在 Word 能正确显示图表时写入 Word 图表或 Word 表格，否则写入图像。`'always'` 会将所有图表写为图像。请参阅[将图表导出为图像](/diagrams/export#charts-as-images)。

### uploadImage

`((blob, { alt, width, height, format }) => Promise<string>) | null` · 默认值 `null`

上传由 `convertChartToImage` 创建的图像并返回其 URL。如果未设置，图像将以 data URL 的形式存储。

### imageNodeName

`string` · 默认值 `'image'`

`convertChartToImage` 创建的图像节点名称。

## 节点

### chart

`Partial<ChartOptions> | false` · 默认值 `{}`

`chart` 节点的选项，详见 [chart 节点](/diagrams/api-reference/options#the-chart-node)。设为 `false` 可禁用图表。

### flowDiagram

`Partial<FlowDiagramOptions> | false` · 默认值 `{}`

`flowDiagram` 节点的选项。`FlowDiagramOptions` 的结构为 `{ HTMLAttributes }`，用于设置示意图根元素的 HTML 属性，默认值为 `{}`。设为 `false` 可禁用示意图。

在共享文档中，如果某个客户端将此选项设为 `false`，它会删除所有客户端的示意图；除非该客户端将 `@tiptap/extension-collaboration` 3.33.0 和 `@tiptap/y-tiptap` 3.2.0 或更高版本中的 `enableContentCheck: true` 设为启用。请参阅[未安装 `Diagrams` 的客户端](/diagrams/guides/collaboration#a-client-without-diagrams)。

## chart 节点

这些选项放在 `chart` 下。

### defaultType

`ChartType` · 默认值 `'line'`

新图表的默认类型，适用于未指定其他类型的情况，例如在快速输入中或将表格转换为图表时。

### placeholder

`string | (({ type, shape, delimiter }) => string) | false` · 默认值：快速输入中与图表类型对应的示例行，以及提示 `Enter twice to finish`

快速输入为空时显示的提示。

```ts
Diagrams.configure({
  chart: {
    placeholder: ({ type }) => (type === 'pie' ? 'Label, share' : 'Label, value, value …'),
  },
})
```

- 快速输入的图表类型发生变化时，会再次调用此函数。
- `shape` 是图表类型读取的行布局，使用 `chartTypes` 注册的类型也适用。请参阅[注册自定义图表类型](/diagrams/renderers/custom-chart-types)。
- 提示中的换行会保留。
- 设为 `false` 则不显示提示。

### delimiters

`string[]` · 默认值 `[',', ';', '|', '\t']`

图表语法可用于分隔单元格的分隔符。

### decimalSeparator

`'auto' | '.' | ','` · 默认值 `'auto'`

图表行中的数字的读取方式。请参阅[数字](/diagrams/data/chart-syntax#numbers)。

### linkTables

`boolean` · 默认值 `false`

允许图表关联同一文档中的表格，支持使用 `insertLinkedChart`、`linkChartToTable` 和 `setChartLayout`。此选项会向表格节点添加 `chartTableId` 属性。请参阅[表格](/diagrams/data/tables)。

### minRenderWidth

`number | null` · 默认值 `null`

当编辑器文本宽度小于此像素值时，图表会以此宽度绘制，再缩小以适应可用空间，文本也会随之缩小。

```ts
Diagrams.configure({ chart: { minRenderWidth: 560 } })
```

在手机上，图表会保留宽屏布局，而不会挤进狭窄空间。

- 缩放比例不会低于 60%。若低于此比例，图表布局会更加紧凑，并省略会发生重叠的类别标签；除非 `axes.x.labels` 指定了要显示的标签。
- 设为 `null` 时，始终按显示宽度绘制。
- 最大化的图表和导出内容会按各自的尺寸绘制。

### HTMLAttributes

`Record<string, unknown>` · 默认值 `{}`

图表根元素的 HTML 属性。

## 对 schema 的要求

表格命令和快速输入中的表格视图会使用注册为 `table`、`tableRow`、`tableHeader` 和 `tableCell` 的节点，例如 `@tiptap/extension-table` 提供的节点。如果没有这些节点，相应命令会返回 `false`。

`convertChartToImage` 需要使用由 `imageNodeName` 指定名称的图像节点。

此扩展会向这些节点添加属性，但不会以这些名称注册自己的节点。
