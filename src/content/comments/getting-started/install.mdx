## 访问私有仓库
Comments 扩展发布在 Tiptap 的私有 npm 仓库中。请按照[私有仓库指南](/guides/pro-extensions)集成此扩展。


```bash
npm install @tiptap-pro/extension-comments
```

## 集成 Comments 扩展

通过 npm 或其他包管理器安装 `comments` 扩展后，可将其注册到编辑器实例的 `extensions` 属性中，以便在编辑器中使用。

Comments 扩展由多个组件组成，包括节点和插件。要启用所有必需功能，请使用 `CommentsKit` 扩展。

```js
import { CommentsKit } from '@tiptap-pro/extension-comments'

const editor = new Editor({
  ...
  extensions: [
    ...,
    CommentsKit,
  ]
})
```

这会将所有必需的扩展添加到编辑器中。由于 Threads 是**云端**或**本地部署**功能，你还需要向 Comments 扩展传入一个 `TiptapCollabProvider` 实例。

```js
const collabProvider = new TiptapCollabProvider({
  // your provider options
})

const editor = new Editor({
  ...
  extensions: [
    ...,
    CommentsKit.configure({
      provider: collabProvider,
    }),
  ]
})
```

现在，编辑器已准备好支持 Threads。
