`Comments` 扩展支持用户在编辑器中创建讨论串和评论。讨论串可用于讨论文档的特定部分，也可以在特定章节添加单条评论。

你可以通过 [Comments REST API](/comments/integrate/rest-api) 访问和管理评论，也可以通过 [webhooks](/comments/integrate/webhook) 接收评论，从而创建通知系统，并支持从编辑器外部添加评论。

## 评论功能

- 添加行内评论、文档评论或侧边栏评论
- 对文本、节点、自定义节点或多个选定节点进行评论
- 支持在评论中使用富文本（例如粗体、表情符号）
- 解决、编辑或删除评论
- 支持离线评论
- 处理重叠评论
- 直接在评论中提及用户
- 当用户被提及时，通过 Webhook 触发自定义通知服务
- 使用 Comments API 以编程方式管理评论
