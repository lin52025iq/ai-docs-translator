在编辑器外部为文档创建评论线程分为两步：先通过 [Comments REST API](/comments/integrate/rest-api) 创建线程，然后在文档的 Tiptap JSON 中用 `inlineThread` 标记包裹目标内容，将线程关联到文档中的某个位置。

仅调用 REST API 还不够。如果文档中没有 `inlineThread` 标记，编辑器就无法知道线程对应的是哪些内容，因此也不会在编辑器界面中显示该线程。

<Callout title="正在使用编辑器实例？" variant="info">
  如果你有活动的编辑器实例，建议使用 [`setThread` 编辑器命令](/comments/integrate/editor-commands#setthread-content-data-commentdata)。它可以一步完成线程创建和 `inlineThread` 标记添加。
</Callout>

## 工作流程概览

1. 通过 REST API **创建线程**。响应中包含线程的 `id`。
2. **更新文档 JSON**，用 `inlineThread` 标记包裹要关联到线程的内容，并将 `data-thread-id` 设置为与该 `id` 相同的值。
3. **（可选）通过 REST API** 向线程添加更多评论。

## 第 1 步：创建线程

向 `/api/documents/:identifier/threads` 发送 `POST` 请求。`content` 字段会成为线程中的第一条评论，`data` 可用于存放你想与线程关联的任意元数据（例如作者）。

```bash
curl --location 'https://YOUR_APP_ID.collab.tiptap.cloud/api/documents/{document_id}/threads' \\
--header 'Content-Type: application/json' \\
--header 'Authorization: {{Authorization}}' \\
--data '{
    "content": "Is \"Capabilities\" the correct wording here?",
    "data": { "authorId": "123" }
}'
```

响应中会包含新创建的线程及其 `id`。请保存此 ID，下一步会用到。

示例响应：

```json
{
    "comments": [
        {
            "id": "2f5e54cf-cd3e-48a0-994c-48efa064111d",
            "createdAt": "2026-01-01T12:00:00.000Z",
            "updatedAt": "2026-01-01T12:00:00.000Z",
            "data": {
                "authorId": "123"
            },
            "content": "Is \"Capabilities\" the correct wording here?"
        }
    ],
    "id": "f290f5c4-fc22-4a58-b697-f0f2a10d2d95",
    "createdAt": "2026-01-01T12:00:00.000Z",
    "updatedAt": "2026-01-01T12:00:00.000Z"
}
```

## 第 2 步：将线程关联到文档中的内容

要在编辑器中显示线程，请在文档的 Tiptap JSON 中用 `inlineThread` 标记包裹相关范围。`data-thread-id` 属性必须与 API 返回的线程 `id` 相同。

```json
{
  "type": "doc",
  "content": [
    {
      "type": "heading",
      "attrs": { "level": 1 },
      "content": [
        { "type": "text", "text": "Welcome to " },
        {
          "type": "text",
          "text": "Tiptap Comments",
          "marks": [
            {
              "type": "inlineThread",
              "attrs": {
                "data-thread-id": "f290f5c4-fc22-4a58-b697-f0f2a10d2d95"
              }
            }
          ]
        }
      ]
    }
  ]
}
```

具体如何应用此修改，取决于文档的存储位置：

- **由 Document server 管理的文档。** 使用 [内容注入 API](/collaboration/documents/content-injection)，在协作实时进行的同时，为 Tiptap JSON 添加 `inlineThread` 标记。
- **正在导入或生成的文档。** 生成 JSON 时添加 `inlineThread` 标记（例如，将带有评论锚点的 DOCX 等源格式转换为 JSON 时），然后用生成的 JSON 初始化 Document server。

## 第 3 步：向线程添加更多评论

向现有线程添加评论无需更改文档 JSON。直接向线程发送请求即可：

```bash
curl --location 'https://YOUR_APP_ID.collab.tiptap.cloud/api/documents/{document_id}/threads/{thread_id}/comments' \\
--header 'Content-Type: application/json' \\
--header 'Authorization: {{Authorization}}' \\
--data '{
    "content": "Replying to the thread",
    "data": { "authorId": "123" }
}'
```

`content` 字段用于存放评论正文。如果前端将评论渲染为富文本，请传入 Tiptap JSON，而不是纯字符串。
