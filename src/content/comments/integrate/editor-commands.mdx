Comments Editor API 专注于在编辑器中管理评论的客户端交互，支持直接操作和自定义评论讨论串。

对于服务器端操作，请使用 [Comments REST API](/comments/integrate/rest-api)，在编辑器外管理讨论串和评论。

## 所有评论编辑器命令

| 命令              | 说明                                                             |
| ----------------- | ---------------------------------------------------------------- |
| `setThread`       | 创建一个新的讨论串，可选提供用户和内容数据                       |
| `removeThread`    | 删除指定的讨论串，也可选择将其从 Yjs 文档中移除                   |
| `updateThread`    | 更新讨论串的特定属性，例如“已读”状态                             |
| `selectThread`    | 将编辑器焦点移至指定的讨论串                                     |
| `unselectThread`  | 取消当前选中讨论串的焦点                                         |
| `resolveThread`   | 将讨论串标记为已解决                                             |
| `unresolveThread` | 将讨论串从已解决状态恢复为未解决状态                             |
| `createComment`   | 在讨论串中添加评论，可提供内容和用户数据等详细信息               |
| `updateComment`   | 修改现有评论的内容和元数据                                       |
| `removeComment`   | 从讨论串中删除指定评论                                           |

## 与讨论串交互

### setThread( content, data, commentData )

在当前选区创建一个新的讨论串。

```js
editor.commands.setThread({
  content: 'This is a new thread',
  data: { authorId: '123' },
  commentData: { authorId: '123' },
})
```

### removeThread( id, deleteThread )

删除具有指定 ID 的讨论串。如果未提供 ID，则删除当前选区中的讨论串。如果将 `deleteThread` 设为 `true`，还会从 Yjs 文档中删除该讨论串。

```js
editor.commands.removeThread({
  id: '101',
  deleteThread: true,
})
```

### updateThread( id, data )

更新具有指定 ID 的讨论串属性。

```js
editor.commands.updateThread({
  id: '101',
  data: { seen: true },
})
```

### selectThread( options )

选中具有指定 ID 的讨论串。

```js
editor.commands.selectThread({
  id: '101',
})
```

#### 选项

- `id`（string）：要选中的讨论串 ID。
- `selectAround`（boolean，默认值：false）：如果为 true，则选中讨论串周围的内容。
- `focus`（boolean，默认值：true）：如果为 true，则在选中讨论串后聚焦编辑器。
- `scrollIntoView`（boolean，默认值：true）：如果为 true，则滚动编辑器，使选中的讨论串进入视野。
- `updateSelection`（boolean，默认值：true）：如果为 true，则将编辑器选区更新为选中的讨论串。
- `triggerClick`（boolean，默认值：false）：如果为 true，则模拟点击。

### unselectThread()

取消选中当前已选中的讨论串。

```js
editor.commands.unselectThread()
```

### resolveThread( id )

将具有指定 ID 的讨论串标记为已解决。

```js
editor.commands.resolveThread({
  id: '101',
})
```

### unresolveThread( id )

将具有指定 ID 的讨论串恢复为未解决状态。

```js
editor.commands.unresolveThread({
  id: '101',
})
```

## 管理评论

### createComment( threadId, content, data )

在具有指定讨论串 ID 的讨论串中创建一条新评论。

```js
editor.commands.createComment({
  threadId: '101',
  content: 'This is a new comment',
  data: { authorId: '123' },
})
```

### updateComment( threadId, id, content, data )

更新指定讨论串中具有指定 ID 的评论。

```js
editor.commands.updateComment({
  threadId: '101',
  id: '456',
  content: 'Now this is the new content',
  data: { edited: true },
})
```

### removeComment( threadId, id )

从具有指定讨论串 ID 的讨论串中删除指定 ID 的评论。

```js
editor.commands.removeComment({
  threadId: '101',
  id: '456',
})
```
