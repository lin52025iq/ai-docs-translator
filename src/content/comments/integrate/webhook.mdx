设置并管理 Webhook，改善 Comments 集成。Comments Webhook 的常见用途包括：

- 在讨论串创建、解决、更新或删除时发送通知。
- 在评论添加、更新或删除时通知用户。
- 配合 [mention 扩展](/editor/extensions/nodes/mention)，在用户于评论中被提及时向其发送电子邮件或通知。

## 启用评论事件

对于 2024 年 3 月 1 日之后创建的账户，Comments Webhook 默认已启用。否则，你可能仍在使用较旧版本的 Webhook 系统，需要手动升级：

1. 如果你之前实现过 Collaboration Webhook，请在处理收到的 Webhook 时检查 `type` 和 `trigger` 字段。（[文档](/collaboration/core-concepts/webhooks)）
2. 前往你的 [Collaboration 设置](https://cloud.tiptap.dev/v2/configuration/document-server)。
3. 在 Webhooks 部分，点击 **升级**。

此升级是必要的，因为多个新事件将被路由到同一个 Webhook 端点，并通过新的 `type` 和 `trigger` 字段加以区分。

## 配置 Webhook

配置用于接收 Comments 通知的 Webhook：

1. 前往账户中的 [Collaboration 设置](https://cloud.tiptap.dev/v2/configuration/document-server)。
2. 在 Webhooks 部分，添加所需的端点 URL。

添加 URL 后，Webhook 会立即生效。你将开始接收指定事件的通知，不会有任何延迟。

## Webhook 事件

Comments Webhook 会针对 Comments 扩展中与讨论串和评论相关的各种事件触发通知。相关操作一旦在评论中发生，就会立即触发这些事件。

- `comment.added`
- `comment.updated`
- `comment.deleted`
- `thread.created`（仅当讨论串创建时没有首条评论才会触发，通常是通过我们的“create thread” API 创建时。使用 Tiptap 官方扩展时，你只会看到 `comment.added`）
- `thread.resolved`
- `thread.updated`
- `thread.deleted`
