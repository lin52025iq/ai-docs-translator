评论线程身份验证器会在协作文档中强制执行评论线程和评论的所有权规则。启用后，用户只能编辑和删除自己的评论线程和评论；创建评论线程时，系统会自动分配已通过身份验证的用户 ID。

<Callout title="需要 JWT 身份验证" variant="hint">
  评论线程身份验证依赖 [JWT 身份验证](/collaboration/getting-started/authenticate) 来识别用户。请确保 JWT 中包含 `sub` 声明，且其值为唯一的用户标识符。
</Callout>

## 启用评论线程身份验证

通过 [Settings API](/collaboration/operations/configure) 将 `thread_authenticator` 设置为 `1`，即可启用评论线程身份验证器：

```bash
curl --location --request PUT 'https://YOUR_APP_ID.collab.tiptap.cloud/api/admin/settings/thread_authenticator' \
--header 'Authorization: YOUR_SECRET_FROM_SETTINGS_AREA' \
--header 'Content-Type: text/plain' \
-d '1'
```

在自托管实例上，也可以将环境变量 `COLLAB_THREAD_AUTHENTICATOR` 设置为 `1`。

## 工作原理

启用后，评论线程身份验证器会拦截所有修改评论线程或评论的文档更新，并根据已通过身份验证的用户身份对其进行验证。

### 自动分配用户 ID

用户创建评论线程或评论时，身份验证器会自动将其用户 ID（来自 JWT 的 `sub` 声明）分配给该评论线程和评论。此过程会自动完成，无需修改客户端。

### 所有权强制规则

以下规则适用于所有评论线程和评论操作：

| 操作 | 规则 |
|-----------|------|
| **创建评论线程** | 允许。系统会自动分配已通过身份验证的用户 ID。 |
| **编辑评论线程** | 只有评论线程所有者可以编辑。 |
| **删除评论线程** | 只有评论线程所有者可以删除。 |
| **解决/取消解决评论线程** | 所有者始终可以解决评论线程。非所有者则取决于其访问级别（见下文）。 |
| **创建评论** | 允许。系统会自动分配已通过身份验证的用户 ID。 |
| **编辑评论** | 只有评论所有者可以编辑。 |
| **删除评论** | 只有评论所有者可以删除。 |

如果用户尝试执行未授权的操作，服务器会拒绝该更新并返回未授权错误。

<Callout title="没有用户 ID 的评论线程" variant="default">
  在启用评论线程身份验证器之前创建的评论线程和评论可能没有分配用户 ID，因此任何人都可以编辑或删除它们。用户修改此类评论线程后，系统会为其分配该用户的 ID。
</Callout>

## 解决他人的评论线程

默认情况下，拥有写入或评论权限的所有用户都可以解决自己不拥有的评论线程。这适用于需要审核者或编辑者将讨论标记为已解决的工作流程。

若要禁止仅有评论权限的用户解决他人的评论线程，请将 `commentonly_disallow_resolve_foreign_threads` 设置为 `1`：

```bash
curl --location --request PUT 'https://YOUR_APP_ID.collab.tiptap.cloud/api/admin/settings/commentonly_disallow_resolve_foreign_threads' \
--header 'Authorization: YOUR_SECRET_FROM_SETTINGS_AREA' \
--header 'Content-Type: text/plain' \
-d '1'
```

解决他人评论线程的权限矩阵如下：

| 访问级别 | 默认行为 | 将 `commentonly_disallow_resolve_foreign_threads` 设置为 `1` 时 |
|---|---|---|
| 写入权限 | 可以解决 | 可以解决 |
| 仅评论权限 | 可以解决 | 不能解决 |

无论此设置如何，评论线程所有者始终可以解决自己的评论线程。

## 配置参考

| 设置 | 环境变量 | 默认值 | 说明 |
|---|---|---|---|
| `thread_authenticator` | `COLLAB_THREAD_AUTHENTICATOR` | `0`（已禁用） | 设置为 `1` 以启用评论线程身份验证。 |
| `commentonly_disallow_resolve_foreign_threads` | `COLLAB_COMMENTONLY_DISALLOW_RESOLVE_FOREIGN_THREADS` | `0`（允许） | 设置为 `1`，以禁止仅有评论权限的用户解决自己不拥有的评论线程。 |

这两项设置均可通过 [Settings API](/collaboration/operations/configure) 或环境变量进行配置。
