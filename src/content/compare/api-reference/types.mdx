Compare 软件包导出用于处理变更集、变更、差异建议、文档历史记录和序列化模式的 TypeScript 类型。实用工具和命令的参数接口与各自的 API 一并说明。

## `TrackedChangeMetadata`

存储在由变更集创建的跟踪变更上的元数据。

```ts
interface TrackedChangeMetadata extends ChangeMetadata {
  id: string
  type: 'add' | 'delete' | 'replace' | 'markChange'
  userId: string | null
  createdAt: string | null
  updatedAt: string | null
  userMetadata: unknown
  markChanges?: TrackedChangeMarkMutation[]
}
```

`TrackedChangeMarkMutation` 描述格式变更，其中包含 `operation`（`'added' | 'removed'`）、`markName` 和 `markAttrs`。

## `TrackedChangeData`

将已编码跟踪变更的元数据与其在生成文档中的范围关联起来。

```ts
interface TrackedChangeData {
  metadata: TrackedChangeMetadata
  range: Range
}
```

## `TrackedChangesDocumentFactoryResult`

`TrackedChangesDocumentFactory.fromChangeset` 返回的结果。

```ts
interface TrackedChangesDocumentFactoryResult {
  doc: JSONContent
  trackedChanges: TrackedChangeData[]
}
```

## `JSONFragment`

ProseMirror 片段的 JSON 表示。

```ts
type JSONFragment = JSONContent[] | null
```

## `ChangesetJSON`

`Changeset` 的可序列化为 JSON 的表示。

```ts
interface ChangesetJSON {
  fragmentA: JSONFragment
  fragmentB: JSONFragment
  changes: Change[]
}
```

## `ChangeMetadata`

附加到变更或文档步骤的任意元数据。

```ts
/**
 * 附加到步骤的任意非空元数据。
 *
 * 比较相邻步骤时，元数据会被视为浅层对象。
 */
type ChangeMetadata = Record<string, unknown>
```

## `Change`

表示两个文档之间的一处差异。

```ts
/**
 * 表示两个文档之间的一处变更。
 */
interface Change {
  /** 原始文档 (`docA`) 中发生变更的范围。 */
  rangeA: Range
  /** 已变更文档 (`docB`) 中与之对应的范围。 */
  rangeB: Range
  /** 内容范围。默认值：`'inline'`。 */
  scope?: ChangeScope
  /** 是否将多个行内变更合并为一个块级变更。 */
  isInlineGroup?: boolean
  /** 与产生此变更的步骤相关联的元数据。 */
  metadata?: ChangeMetadata
  /** 包含在此变更中的后续变更。 */
  nestedChanges?: NestedChange[]
}
```

## `ChangeScope`

变更覆盖行内内容还是块级内容。

```ts
type ChangeScope = 'inline' | 'block'
```

## `NestedChange`

包含在父级 `Change` 中的后续变更。其范围是最终文档 (`docB`) 中的绝对位置。

```ts
interface NestedChange {
  range: Range
  metadata: ChangeMetadata
  scope: ChangeScope
}
```

## `DiffOptions`

控制文档和片段比较的计算方式。

```ts
/** 控制筛选和差异计算行为的选项。 */
type DiffOptions = {
  /** 在行内模式下简化相邻变更。默认值：`false`。 */
  simplifyChanges?: boolean
  /** 比较前要移除的属性。默认值：`['id', 'data-thread-id', '_hash']`。 */
  ignoreAttributes?: string[]
  /** 比较前要移除的标记。默认值：`['inlineThread']`。 */
  ignoreMarks?: string[]
  /** 比较前要展开或移除的节点类型。 */
  ignoreNodes?: string[]
  /** 分隔变更的最小未变更范围。默认值：`5`。 */
  changeMergeDistance?: number | null
  /** 在智能模式下将行内变更归为块级变更的阈值。默认值：`2`。 */
  groupInlineChanges?: number
  /** 比较模式。默认值：`'smart'`。 */
  mode?: 'inline' | 'block' | 'smart'
  /** 应将其完整行内变更转换为块级变更的节点类型。 */
  expandBlockChanges?: string[]
}
```

## `DiffSuggestion`

表示在编辑器中显示的替换建议。

```ts
/** 对一段编辑器内容提出的变更建议。 */
interface DiffSuggestion {
  /** 建议的唯一标识符。 */
  id: string
  /** 建议影响的编辑器内容范围。 */
  range: Range
  /** 替换内容。 */
  content: Slice
  /** 可选的自定义元数据。 */
  metadata?: Record<string, any>
  /** 建议的渲染选项。 */
  displayOptions?: DisplayOptions
  /** 此建议是否将多个行内变更归为一组。 */
  isInlineGroup?: boolean
  /** 可通过文档事务映射的范围。 */
  mappableRange?: MappableRange
  /** 在此建议中显示的信息性变更。 */
  nestedChanges?: DiffSuggestionNestedChange[]
}
```

## `DiffSuggestionNestedChange`

包含在差异建议中的嵌套变更。

```ts
interface DiffSuggestionNestedChange extends NestedChange {
  mappableRange?: MappableRange
}
```

## `DisplayOptions`

控制差异建议的默认渲染方式。

```ts
/** 在编辑器中显示差异建议的选项。 */
interface DisplayOptions {
  /** 是否显示替换内容。默认值：`true`。 */
  showReplacement?: boolean
  /** 是否显示行内分组中的子变更。默认值：`true`。 */
  showSubChanges?: boolean
  /** 原始内容装饰的额外 HTML 属性。 */
  attributes?: Record<string, any>
  /** 替换内容装饰的额外 HTML 属性。 */
  replacementAttributes?: Record<string, any>
  /** 行内子变更装饰的额外 HTML 属性。 */
  subChangeAttributes?: Record<string, any>
  /** 替换内容中子变更的额外 HTML 属性。 */
  replacementSubChangeAttributes?: Record<string, any>
  /** 返回显式嵌套变更的 HTML 属性。 */
  getNestedChangeAttributes?: (options: NestedChangeAttributesOptions) => Record<string, string>
  /** 将建议渲染为 ProseMirror 装饰的函数。 */
  renderDecorations?: RenderDecorations
}
```

`getNestedChangeAttributes` 会接收嵌套变更、其可执行操作的父级建议，以及该父级建议是否处于选中状态。如果返回值中包含 `class`，Compare 会将其追加到默认的嵌套变更类名中。

```ts
interface NestedChangeAttributesOptions {
  nestedChange: DiffSuggestionNestedChange
  suggestion: DiffSuggestion
  isSelected: boolean
}
```

## 自定义装饰渲染

使用这些类型和 `DisplayOptions.renderDecorations`，以替换或调整默认渲染方式。

```ts
/** 传递给 `defaultRenderDecorations` 的选项。 */
interface DefaultRenderDecorationsOptions {
  /** 是否渲染主要内容和子变更装饰。默认值：`true`。 */
  showMainDecorations?: boolean
  /** 是否渲染替换内容。默认值：`true`。 */
  showReplacement?: boolean
  /** 是否渲染行内分组中的子变更。默认值：`true`。 */
  showSubChanges?: boolean
  /** 原始内容装饰的额外 HTML 属性。 */
  attributes?: Record<string, any>
  /** 替换内容装饰的额外 HTML 属性。 */
  replacementAttributes?: Record<string, any>
  /** 行内子变更装饰的额外 HTML 属性。 */
  subChangeAttributes?: Record<string, any>
  /** 替换内容中子变更的额外 HTML 属性。 */
  replacementSubChangeAttributes?: Record<string, any>
}

/** 传递给自定义差异建议渲染器的值。 */
interface RenderDecorationsOptions {
  /** 建议占据的范围。 */
  range: Range
  /** 建议是否处于选中状态。 */
  isSelected: boolean
  /** 正在渲染的建议。 */
  suggestion: DiffSuggestion
  /** 使用可选的覆盖选项渲染默认装饰。 */
  defaultRenderDecorations: (options?: DefaultRenderDecorationsOptions) => Decoration[]
}

/** 将建议渲染为 ProseMirror 装饰的函数。 */
type RenderDecorations = (options: RenderDecorationsOptions) => Decoration[]
```

## `Step`

表示 `StepSequence` 中的一次状态转换。

```ts
/** 步骤序列中的一次文档状态转换。 */
interface Step {
  /** 应用步骤前的文档状态。 */
  before: Node
  /** 应用步骤后的文档状态。 */
  after: Node
  /** 与步骤相关联的元数据。 */
  metadata: ChangeMetadata
  /** 缓存的变更；如果需要计算，则为 `null`。 */
  changes: Change[] | null
  /** 缓存的受影响区域；如果不可用，则为 `null`。 */
  changedArea: Change | null
}
```

## `StepSequenceJSON`

`StepSequence` 的可序列化为 JSON 的状态。

```ts
/** 步骤序列的可序列化为 JSON 的状态。 */
type StepSequenceJSON = {
  /** 应用任何步骤之前的文档状态。 */
  before: ReturnType<Node['toJSON']>
  /** 每个已记录步骤之后的文档状态。 */
  docs: Array<ReturnType<Node['toJSON']>>
  /** 每个已记录步骤的元数据。 */
  metadata: ChangeMetadata[]
  /** 每个已记录步骤的缓存变更。 */
  changes: Array<Change[] | null>
  /** 每个已记录步骤的缓存受影响区域。 */
  changedAreas: Array<Change | null>
}
```
