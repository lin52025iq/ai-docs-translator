Compare 使用 CSS 类渲染默认的差异界面。调用 [`compareDocuments`](/compare/api-reference/commands#comparedocuments) 或 [`compareVersions`](/compare/api-reference/commands#compareversions) 等命令时，可以通过 `displayOptions` 添加自己的类或属性。

```ts
editor.commands.compareDocuments({
  docA,
  docB,
  displayOptions: {
    attributes: { class: 'my-added-content' },
    replacementAttributes: { class: 'my-removed-content' },
  },
})
```

## 默认 CSS 类

每条差异建议都会渲染当前文档内容和建议的替换内容。以下类会应用于这些元素。

### 当前内容

- `.diff-suggestion` — 应用于每个当前内容元素。
- `.diff-suggestion--selected` — 在选中建议时应用。
- `.diff-suggestion--change-group` — 在建议包含分组的行内更改时应用。

如果建议由更改组创建且包含子更改，则子更改会包含以下类：

- `.diff-suggestion-sub-change` — 应用于组中的每个单独更改。
- `.diff-suggestion-sub-change--selected` — 在选中建议时，应用于当前内容的子更改。

嵌套更改显示在审阅视图的当前内容一侧，并带有以下类：

- `.diff-suggestion-nested-change` — 应用于每个嵌套更改。
- `.diff-suggestion-nested-change--inline` — 在嵌套更改包含行内内容时应用。
- `.diff-suggestion-nested-change--block` — 在嵌套更改包含块级内容时应用。
- `.diff-suggestion-nested-change--selected` — 在选中父级建议时应用。

使用 `displayOptions.getNestedChangeAttributes` 为嵌套更改添加属性。返回的 `class` 会追加到这些默认类中。

### 建议内容

- `.diff-suggestion-diff` — 应用于每个建议内容元素。
- `.diff-suggestion-diff--selected` — 在选中建议时应用。
- `.diff-suggestion-diff--change-group` — 在建议包含分组的行内更改时应用。

如果建议由更改组创建且包含子更改，则子更改会包含以下类：

- `.diff-suggestion-diff-sub-change` — 应用于组中的每个单独的建议内容更改。
- `.diff-suggestion-diff-sub-change--selected` — 在选中建议时，应用于建议内容的子更改。

## 自定义建议渲染

[`renderDecorations`](/compare/api-reference/types#custom-decoration-rendering) 选项可让您完全控制建议的渲染方式。它是一个接收 [DiffSuggestion 对象](/compare/api-reference/types#diffsuggestion)并返回 [ProseMirror 装饰项](https://prosemirror.net/docs/ref/#view.Decorations)列表的函数。

```ts
editor.commands.compareDocuments({
  docA,
  docB,
  displayOptions: {
    renderDecorations({ suggestion }) {
      return [
        Decoration.inline(suggestion.range.from, suggestion.range.to, {
          class: 'custom-decoration',
        }),
      ]
    },
  },
})
```

要将自定义装饰项与 Compare 扩展显示的默认装饰项结合使用，请使用 `defaultRenderDecorations` 选项：

```ts
editor.commands.compareDocuments({
  docA,
  docB,
  displayOptions: {
    renderDecorations({ suggestion, isSelected, defaultRenderDecorations }) {
      return [
        Decoration.inline(suggestion.range.from, suggestion.range.to, {
          class: 'custom-decoration',
        }),
        ...defaultRenderDecorations({
          attributes: isSelected
            ? {
                class: 'custom-selected-class',
              }
            : {},
        }),
      ]
    },
  },
})
```

## 渲染自定义节点视图

如果 [Tiptap 节点视图](/editor/extensions/custom-extensions/node-views)位于差异建议中，并且您希望为其应用不同样式，请使用 [`getSuggestionNodeViewContext` 工具函数](/compare/api-reference/utilities#getsuggestionnodeviewcontext)。

该函数会返回有关建议的实用上下文信息。请在 [API 参考](/compare/api-reference/utilities#getsuggestionnodeviewcontext)中了解详情。

```tsx
import { getSuggestionNodeViewContext } from '@tiptap-pro/compare'
import Heading from '@tiptap/extension-heading'
import { NodeViewWrapper, ReactNodeViewRenderer } from '@tiptap/react'

const CustomHeading = Heading.extend({
  addNodeView() {
    return ReactNodeViewRenderer(({ decorations }) => {
      const { suggestion, isSelected, isReplacement } = getSuggestionNodeViewContext(decorations)

      return (
        <NodeViewWrapper style={{ position: 'relative' }}>
          {suggestion && (
            <span>
              Suggestion {suggestion.id} is {isSelected ? 'selected' : 'not selected'} and rendered
              in the {isReplacement ? 'replacement' : 'document'}.
            </span>
          )}
        </NodeViewWrapper>
      )
    })
  },
})
```
