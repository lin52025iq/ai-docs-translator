使用这些命令前，请先将 `Compare` 扩展添加到编辑器中。

## `compareDocuments`

比较两个 Tiptap JSON 文档并显示差异。

此命令等同于依次调用 [`compareDocuments`](/compare/api-reference/utilities#comparedocuments) 和 [`displayChangeset`](/compare/api-reference/commands#displaychangeset)。

### 参数 (`CompareDocumentsOptions`)

- `docA` (`JSONContent`)：原始文档。
- `docB` (`JSONContent`)：已更改的文档。
- `diffOptions?` (`DiffOptions`)：控制比较行为的选项。
- `displayOptions?` (`DisplayOptions`)：控制渲染差异的选项。

### 返回值 (`boolean`)

- `boolean`：比较文档并创建差异建议后返回 `true`。

## `compareFragments`

比较两个 Tiptap JSON 片段并显示差异。

此命令等同于依次调用 [`compareFragments`](/compare/api-reference/utilities#comparefragments) 和 [`displayChangeset`](/compare/api-reference/commands#displaychangeset)。

### 参数 (`CompareFragmentsOptions`)

- `fragmentA` (`JSONContent[] | null`)：原始片段。
- `fragmentB` (`JSONContent[] | null`)：已更改的片段。
- `diffOptions?` (`DiffOptions`)：控制比较行为的选项。
- `displayOptions?` (`DisplayOptions`)：控制渲染差异的选项。

### 返回值 (`boolean`)

- `boolean`：比较片段并创建差异建议后返回 `true`。

## `compareSteps`

比较一系列文档步骤并显示差异。

此命令等同于依次调用 [`compareSteps`](/compare/api-reference/utilities#comparesteps) 和 [`displayChangeset`](/compare/api-reference/commands#displaychangeset)。

### 参数 (`CompareStepsOptions`)

- `stepSequence` (`StepSequence`)：要比较的步骤序列。每个步骤都可以包含关联元数据，例如完成该步骤的用户。
- `compareMetadata?` (`(a: ChangeMetadata, b: ChangeMetadata) => boolean`)：决定相邻步骤是否可以分组。
- `diffOptions?` (`DiffOptions`)：控制比较行为的选项。
- `displayOptions?` (`DisplayOptions`)：控制渲染差异的选项。

### 返回值 (`boolean`)

- `boolean`：比较步骤并创建差异建议后返回 `true`。

## `compareVersions`

比较两个 Yjs 版本更新并显示差异。

此命令等同于依次调用 [`compareVersions`](/compare/api-reference/utilities#compareversions) 和 [`displayChangeset`](/compare/api-reference/commands#displaychangeset)。

### 参数 (`CompareVersionsOptions`)

- `versionA` (`Uint8Array`)：较早的 Yjs v2 更新。
- `versionB` (`Uint8Array`)：较新的 Yjs v2 更新。
- `diffOptions?` (`DiffOptions`)：控制比较行为的选项。
- `compareMetadata?` (`(a: ChangeMetadata, b: ChangeMetadata) => boolean`)：决定相邻更改是否可以分组。
- `field?` (`string`)：Yjs 文档字段。默认值：`'default'`。
- `permanentUserDataMapField?` (`string`)：共享用户数据映射字段。默认值：`'__tiptapcollab__users'`。
- `enableDebugging?` (`boolean`)：启用提取日志。默认值：`false`。
- `displayOptions?` (`DisplayOptions`)：控制渲染差异的选项。

### 返回值 (`boolean`)

- `boolean`：比较版本并创建差异建议后返回 `true`。

## `displayChangeset`

在编辑器中将变更集显示为审阅建议。编辑器显示当前文档（`Changeset.docB`），每条建议都会提供原始文档（`Changeset.docA`）中对应的内容。

### 参数 (`DisplayChangesetOptions`)

- `changeset` (`Changeset`)：要显示的比较结果。
- `displayOptions?` (`DisplayOptions`)：控制渲染差异的选项。

### 返回值 (`boolean`)

- `boolean`：加载变更集并创建差异建议后返回 `true`。

## `displayChangesetAsTrackedChanges`

将变更集作为[修订](/tracked-changes/getting-started/overview)建议加载。编辑器显示已更改的文档（`Changeset.docB`），并将新增、删除、替换和格式更改编码为修订。任何已显示的差异建议都会被清除。

### 参数 (`DisplayChangesetAsTrackedChangesOptions`)

- `changeset` (`Changeset`)：要显示的比较结果。

### 返回值 (`boolean`)

- `boolean`：加载文档并创建修订后返回 `true`。

## `setDiffSuggestions`

设置要显示的差异建议列表。

### 参数

- `diffSuggestions` (`DiffSuggestion[]`)：要显示的建议。传入空数组即可清除建议。

### 返回值 (`boolean`)

- `boolean`：替换当前活动建议后返回 `true`。

## `acceptDiffSuggestion`

接受一条差异建议。停止显示该建议，并保持文档当前状态不变。

### 参数

- `diffSuggestionId` (`string`)：要接受的建议 ID。

### 返回值 (`boolean`)

- `boolean`：找到并接受建议时返回 `true`；否则返回 `false`。

## `rejectDiffSuggestion`

拒绝一条差异建议。将建议中的替换内容应用到文档，以恢复到之前的版本。

### 参数

- `diffSuggestionId` (`string`)：要拒绝的建议 ID。

### 返回值 (`boolean`)

- `boolean`：找到并拒绝建议时返回 `true`；否则返回 `false`。

## `acceptAllDiffSuggestions`

接受所有活动建议，或接受经过筛选的一组建议。

### 参数 (`AllDiffSuggestionsOptions`)

- `filter?` (`(diffSuggestion: DiffSuggestion) => boolean`)：选择要接受的建议。默认接受所有建议。

### 返回值 (`boolean`)

- `boolean`：处理所选建议后返回 `true`。

## `rejectAllDiffSuggestions`

拒绝所有活动建议，或拒绝经过筛选的一组建议。

### 参数 (`AllDiffSuggestionsOptions`)

- `filter?` (`(diffSuggestion: DiffSuggestion) => boolean`)：选择要拒绝的建议。默认拒绝所有建议。

### 返回值 (`boolean`)

- `boolean`：处理所选建议后返回 `true`。
