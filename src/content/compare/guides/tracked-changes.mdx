## 比较文档

在用于显示比较结果的编辑器中添加 `Compare` 和 `TrackedChanges`。使用 `compareDocuments` 工具比较文档，然后将结果传递给编辑器命令 `displayChangesetAsTrackedChanges`。

```ts
import { Editor } from '@tiptap/core'
import { Compare, compareDocuments } from '@tiptap-pro/compare'
import { TrackedChanges } from '@tiptap-pro/extension-tracked-changes'

// The editor where the diff will be displayed
const editor = new Editor({
  extensions: [
    Compare,
    TrackedChanges.configure({ enabled: true }),
    // ...other extensions shared by both documents
  ],
})

const changeset = compareDocuments({
  schema: editor.schema,
  docA, // Original Tiptap JSON document
  docB, // Changed Tiptap JSON document
})

editor.commands.displayChangesetAsTrackedChanges({ changeset })
```

现在，编辑器会将两个文档之间的更改显示为修订建议。使用[修订命令](/tracked-changes/api-reference/commands)来[接受或拒绝这些建议](/tracked-changes/usage/basic-usage#accepting-and-rejecting-suggestions)。

<Callout title="必须启用修订" variant="warning">
  调用 `displayChangesetAsTrackedChanges` 命令前，请确保已启用修订。例如，可以这样初始化扩展：`TrackedChanges.configure({ enabled: true })`
</Callout>

## 比较版本

使用 [`compareVersions`](/compare/api-reference/utilities#compareversions) 比较两个 Yjs 版本更新。然后，你可以使用修订建议在编辑器中显示差异。

```ts
import { compareVersions } from '@tiptap-pro/compare'

const changeset = compareVersions({
  schema: editor.schema,
  versionA, // Older Yjs update
  versionB, // Newer Yjs update
})

editor.commands.displayChangesetAsTrackedChanges({ changeset })
```

`compareVersions` 工具会捕获每项更改的用户归属信息，并将其存储在该更改元数据的 `userId` 属性中。这些信息会自动传递到修订建议中，因此修订审阅界面可以显示每项更改的作者。

如需详细了解如何获取和显示版本更新，请参阅[比较版本](/compare/guides/compare-versions)指南。

## 在服务器上创建修订

如果需要在没有编辑器实例的情况下创建包含修订的文档（例如在服务器路由或 Web Worker 中），请使用 `TrackedChangesDocumentFactory`。在客户端序列化文档之前，schema 必须包含修订扩展。请参阅[在服务器上比较文档](/compare/guides/server-compare)，了解如何将文档和 schema 发送到服务器。

```ts
import {
  compareDocuments,
  deserializeSchema,
  TrackedChangesDocumentFactory,
} from '@tiptap-pro/compare'

const schema = deserializeSchema(serializedSchema)
const changeset = compareDocuments({ schema, docA, docB })

const { doc, trackedChanges } = new TrackedChangesDocumentFactory().fromChangeset({
  changeset,
  schema,
})
```

`doc` 是一份编码了修订的 Tiptap JSON 文档。`trackedChanges` 包含每项已编码更改的元数据和文档范围，可用于其他服务器端处理。
