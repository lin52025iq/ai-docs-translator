## 安装

首先，[联系我们的团队](https://tiptap.dev/contact-sales)购买 Compare 插件并将其添加到您的套餐中。

获得访问权限后，按照[私有注册表指南](/guides/pro-extensions)配置包管理器。

然后安装软件包：

```bash
npm install @tiptap-pro/extension-split-view @tiptap-pro/extension-tracked-changes
```

## 连接编辑器

主编辑器是编辑器内容的唯一真实来源。创建另外两个编辑器，分别显示分栏视图的左侧和右侧窗格。在三个编辑器中都添加 `TrackedChanges` 扩展，并在对应两个窗格的编辑器中添加 `SplitView`。

```ts
import { Editor } from '@tiptap/core'
import { TrackedChanges } from '@tiptap-pro/extension-tracked-changes'
import { SplitView, createSplitView } from '@tiptap-pro/extension-split-view'

const mainEditor = new Editor({
  extensions: [
    // ... other extensions
    TrackedChanges,
  ],
  content: '<p>Start writing here.</p>',
})

const beforeEditor = new Editor({
  extensions: [
    // ... other extensions
    TrackedChanges,
    SplitView,
  ],
})

const afterEditor = new Editor({
  extensions: [
    // ... other extensions
    TrackedChanges,
    SplitView,
  ],
})

let manager = createSplitView({ mainEditor, beforeEditor, afterEditor })
```

内容由主编辑器管理。`createSplitView()` 会将两个窗格连接到主编辑器。所有三个编辑器之间都会同步编辑以及接受/拒绝操作。

## 排列窗格

打开分栏视图时隐藏主编辑器。为两个窗格设置相同的顶部内边距，并使用共享的滚动容器。

```html
<div id="main" hidden></div>
<div id="split">
  <div id="before"></div>
  <div id="after"></div>
</div>
```

```css
#split {
  display: grid;
  grid-template-columns: minmax(0, 1fr) minmax(0, 1fr);
  overflow: auto;
}

#split[hidden] {
  display: none;
}
```

灰色占位块用于填补高度差或缺失的内容块。两个占位块的底部外边距均采用下一个内容块前两个间距中较大的那个，间距根据您的 CSS 测量。高度为零的占位块可以增加间距，而不显示灰色方块。占位块不会保存到文档中。

## 切换视图

销毁管理器即可停止同步并移除窗格过滤。编辑器本身会继续运行。

```ts
manager.destroy()
document.querySelector('#split')?.setAttribute('hidden', '')
document.querySelector('#main')?.removeAttribute('hidden')
```

要返回分栏视图，请重新连接。两个窗格都会接收主编辑器中的当前文档。

```ts
document.querySelector('#main')?.setAttribute('hidden', '')
document.querySelector('#split')?.removeAttribute('hidden')
manager = createSplitView({ mainEditor, beforeEditor, afterEditor })
```

组件卸载时，销毁全部三个编辑器。每个编辑器都有自己的撤销历史记录；分栏视图不提供共享撤销功能。

## 与 Pages 扩展搭配使用

要比较分页文档，请在分栏视图的两个窗格中添加 `Pages` 扩展，并确保页面格式、页边距、页眉、页脚和缩放比例一致。Split View 会自动检测 Pages，并确保内容块在跨页时保持对齐。请使用共享的水平滚动容器。

## API 参考

### `SplitView`

与 `TrackedChanges` 一起安装在两个窗格中。无需配置。在 `createSplitView()` 连接编辑器之前，此扩展不会激活。

### `createSplitView(options): SplitViewManager`

返回一个 `SplitViewManager`。传入三个不同且已挂载、模式相同的编辑器。一个编辑器只能属于一个活动的管理器。

| 选项           | 类型                                               | 说明                                  |
| -------------- | -------------------------------------------------- | ------------------------------------- |
| `mainEditor`   | `Editor`                                           | 提供初始文档。                        |
| `beforeEditor` | `Editor`                                           | 显示删除内容和未更改的内容。          |
| `afterEditor`  | `Editor`                                           | 显示新增内容和未更改的内容。          |
| `createSpacer` | `(options: SplitViewSpacerOptions) => HTMLElement` | 可选的自定义占位元素。                |

[节点类型提议](/tracked-changes/usage/advanced-usage#node-type-changes)会在前侧窗格中显示原始内容块类型及其属性，在后侧窗格中显示提议的类型及其属性。内联格式更改在两个窗格中都会显示。三个编辑器都会保留完整文档，包括在某个窗格中隐藏的内容。再次连接相同的编辑器之前，请先销毁现有管理器。

### 管理器方法

| 方法                | 返回值                  | 说明                                                                                           |
| ------------------- | ----------------------- | ---------------------------------------------------------------------------------------------- |
| `getMainEditor()`   | `Editor \| undefined`  | 返回主编辑器。                                                                                 |
| `getBeforeEditor()` | `Editor \| undefined`  | 返回前侧窗格的编辑器。                                                                         |
| `getAfterEditor()`  | `Editor \| undefined`  | 返回后侧窗格的编辑器。                                                                         |
| `update()`          | `void`                  | 自定义布局或 CSS 更改后，安排一次对齐更新。                                                     |
| `destroy()`         | `void`                  | 停止同步、移除占位块和过滤，并释放资源。可安全地重复调用。                                     |

销毁后，获取器会返回 `undefined`。销毁任何已连接的编辑器也会销毁管理器。内容更改、尺寸调整、图像加载和字体加载都会自动更新对齐。

### 设置占位块样式

默认占位块是一个类名为 `tiptap-split-view-spacer` 的 `div`。使用 CSS 设置其背景：

```css
#split {
  --tiptap-split-view-spacer-background: #eee;
}
```

要使用自定义元素，请提供 `createSpacer`：

```ts
manager.destroy()
manager = createSplitView({
  mainEditor,
  beforeEditor,
  afterEditor,
  createSpacer({ document }) {
    const spacer = document.createElement('div')
    spacer.style.background = '#eee'
    return spacer
  },
})
```

`SplitViewSpacerOptions` 包含 `document: Document` 和 `side: 'original' | 'modified'`。`createSpacer` 回调应返回一个 `HTMLElement`；管理器会控制其高度、边距和可见性。自定义元素不会自动获得默认类名。
