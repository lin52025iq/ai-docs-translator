运行 Compare 包不需要 Tiptap Editor 实例。文档比较可以在 [Web Worker](https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API) 中运行，也可以在服务器上运行。

首先，创建要比较的两个文档：

```ts
import { Editor } from '@tiptap/core'

const editorA = new Editor()
const docA = editorA.toJSON()

const editorB = new Editor()
const docB = editorB.toJSON()
```

要比较两个文档，Compare 包需要编辑器 schema。要通过网络发送 schema，请先将其序列化：

```ts
import { serializeSchema } from '@tiptap-pro/compare'

const serializedSchema = serializeSchema(editorA.schema)

const response = await fetch('/api/compare', {
  method: 'POST',
  body: JSON.stringify({ docA, docB, schema: serializedSchema }),
})
```

然后，在服务器上反序列化 schema，并使用 [`compareDocuments`](/compare/api-reference/utilities#comparedocuments) 工具比较这两个文档。

[`compareDocuments`](/compare/api-reference/utilities#comparedocuments) 工具会返回一个 [`Changeset`](/compare/api-reference/utilities#changeset)。`Changeset` 包含两个文档，以及一个描述它们之间差异的 `Change` 对象列表。`Changeset` 可序列化为 JSON，因此你可以将其 JSON 表示形式存储在数据库中，或发送给客户端显示。

```ts
import { compareDocuments, deserializeSchema } from '@tiptap-pro/compare'

export async function POST(request: Request) {
  const { docA, docB, schema: serializedSchema } = await request.json()
  const schema = deserializeSchema(serializedSchema)
  const changeset = compareDocuments({ schema, docA, docB })
  const changesetJSON = changeset.toJSON()

  return Response.json(changesetJSON)
}
```

回到客户端后，你可以还原 `Changeset` 对象并显示它。

```ts
import { Editor } from '@tiptap/core'
import { Changeset } from '@tiptap-pro/compare'

// 从服务器响应中获取 changeset
const changesetJSON = await response.json()
const changeset = Changeset.fromJSON(changesetJSON)

// 显示 changeset
const diffEditor = new Editor()
diffEditor.commands.displayChangeset({ changeset })
```

此外，还有一个 [`compareVersions` 工具](/compare/api-reference/utilities#compareversions)，可用于在服务器上比较两个版本。

## 性能建议

### 在单独的进程中运行文档比较

比较大型文档需要大量计算资源。此外，文档比较是一个同步过程，运行时会阻塞事件循环。因此，请避免在客户端或服务器的主线程上运行文档比较，而应在单独的进程中运行：

- 在客户端，使用 [Web Worker](https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API)。
- 在服务器上，使用 [worker 线程](https://nodejs.org/api/worker_threads.html)，或使用带有 worker 池的消息队列。

### 缓存差异结果

`compareDocuments` 工具会返回一个 [`Changeset`](/compare/api-reference/utilities#changeset)。`Changeset` 是可序列化为 JSON 的对象，可以进行缓存。如果你的应用经常比较两个文档，请缓存 `Changeset`，避免重复比较。

以上建议也适用于其他比较 API，例如 [`compareVersions`](/compare/api-reference/utilities#compareversions)。
