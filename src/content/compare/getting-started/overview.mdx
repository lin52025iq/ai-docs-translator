**Tiptap Compare** 可查找并显示两份文档之间的更改，或同一文档两个版本之间的更改。

<CodeDemo isPro path="/Extensions/CompareDocuments" />

Tiptap Compare 是无头的：您可以完全控制更改的显示方式和样式。比较过程本身无需编辑器实例，因此可以部署在客户端或服务器端。

## 安装

首先，[联系我们的团队](https://tiptap.dev/contact-sales)，购买 Compare 附加组件并将其添加到您的套餐中。

获得使用权限后，请按照[私有注册表指南](/guides/pro-extensions)配置您的包管理器。

然后安装该包：

```bash
npm install @tiptap-pro/compare
```

将 `Compare` 扩展添加到用于显示两份文档之间更改的编辑器中。

```ts
import { Compare } from '@tiptap-pro/compare'

const editor = new Editor({
  extensions: [
    Compare,
    // ...other extensions
  ],
})
```
