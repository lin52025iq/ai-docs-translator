使用 [Y IndexedDB](https://docs.yjs.dev/ecosystem/database-provider/y-indexeddb) 扩展，即可轻松为协作编辑器添加离线功能。这个来自 Y.js 生态系统的工具可为编辑器提供离线数据存储和同步能力。

## 集成离线支持

首先，将 Y IndexedDB 适配器添加到项目中：

```bash
npm install y-indexeddb
```

将 Y IndexedDB 与 Y 文档连接，以便在本地存储文档。

```typescript
import { Editor } from '@tiptap/core'
import Collaboration from '@tiptap/extension-collaboration'
import * as Y from 'yjs'
import { IndexeddbPersistence } from 'y-indexeddb'

const ydoc = new Y.Doc()

// 设置 IndexedDB，以便在本地存储 Y 文档
new IndexeddbPersistence('example-document', ydoc)

const editor = new Editor({
  extensions: [
    // 其他扩展...
    Collaboration.configure({
      document: ydoc,
    }),
  ],
})
```

IndexedDB 适配器会确保文档的每次更改都存储在浏览器本地。这意味着即使关闭标签页、断开网络连接或离线编辑，您的工作也会得到保存。恢复联网后，这些更改会自动同步。
