Tiptap v3 是一次包含重大破坏性变更的版本升级。本指南将帮助你把 Tiptap v2 项目升级到版本 3。

## 破坏性变更

### 包变更

- 已移除 UMD 构建（现在使用 tsup）

部分包可能已被移除或重命名，因此你可能需要更新导入和依赖项。以下是一些常见变更：

```diff
Table packages
- import Table from '@tiptap/extension-table'
- import TableRow from '@tiptap/extension-table-row'
- import TableCell from '@tiptap/extension-table-cell'
- import TableHeader from '@tiptap/extension-table-header'
+ import { Table, TableRow, TableCell, TableHeader } from '@tiptap/extension-table'

List packages
- import BulletList from '@tiptap/extension-bullet-list'
- import OrderedList from '@tiptap/extension-ordered-list'
- import ListItem from '@tiptap/extension-list-item'
- import ListKeymap from '@tiptap/extension-list-keymap'
- import TaskList from '@tiptap/extension-task-list'
- import TaskItem from '@tiptap/extension-task-item'
+ import { BulletList, OrderedList, ListItem, ListKeymap, TaskList, TaskItem } from '@tiptap/extension-list'

Extensions
- import Focus from '@tiptap/extension-focus'
- import Placeholder from '@tiptap/extension-placeholder'
- import History from '@tiptap/extension-history'
- import Dropcursor from '@tiptap/extension-dropcursor'
- import Gapcursor from '@tiptap/extension-gapcursor'
- import CharacterCount from '@tiptap/extension-character-count'
+ import { Focus, Placeholder, UndoRedo, Dropcursor, Gapcursor, CharacterCount } from '@tiptap/extensions'

CollaborationCursor
- import CollaborationCursor from '@tiptap/extension-collaboration-cursor'
+ import CollaborationCaret from '@tiptap/extension-collaboration-caret'

Collaboration History
- import CollaborationHistory from '@tiptap-pro/extension-collaboration-history'
+ import Snapshot from '@tiptap-pro/extension-snapshot'

React Menus
- import { BubbleMenu, FloatingMenu } from '@tiptap/react'
+ import { BubbleMenu, FloatingMenu } from '@tiptap/react/menus'

Vue 3 Menus
- import { BubbleMenu, FloatingMenu } from '@tiptap/vue-3'
+ import { BubbleMenu, FloatingMenu } from '@tiptap/vue-3/menus'

Vue 2 Menus
- import { BubbleMenu, FloatingMenu } from '@tiptap/vue-2'
+ import { BubbleMenu, FloatingMenu } from '@tiptap/vue-2/menus'
```

### 菜单系统

所有浮动元素的定位方案都已从 Tippy.js 替换为 Floating UI。这会影响以下内容：

- @tiptap/extension-bubble-menu
- @tiptap/extension-drag-handle
- @tiptap/extension-drag-handle-react
- @tiptap/extension-drag-handle-vue-2
- @tiptap/extension-drag-handle-vue-3
- @tiptap/extension-floating-menu
- @tiptap/extension-mention
- @tiptap/suggestion
- @tiptap-pro/extension-emoji

迁移示例：

```tsx
// Before
import { BubbleMenu } from '@tiptap/react'

const menu = <BubbleMenu tippyOptions={{ duration: 100 }}>{/* menu content */}</BubbleMenu>

// After
import { BubbleMenu } from '@tiptap/react/menus'
import { offset } from '@floating-ui/dom'
const menu = (
  <BubbleMenu
    options={{
      offset: 6,
      placement: 'top',
    }}
  >
    {/* menu content */}
  </BubbleMenu>
)
```

- 新增必需依赖：`@floating-ui/dom`。使用以下命令安装：

```bash
npm install @floating-ui/dom@^1.6.0
```

如果你使用了 `tippy.js`，请务必将其卸载，因为现在已不再需要它。

```bash
npm uninstall tippy.js
```

### API 变更与文本样式更新

- `mergeNestedSpanStyles` 现在默认值为 `true`
- 新增文本样式扩展：
  - `font-size`
  - `background-color`
  - `line-height`
- 新增 `TextStyleKit` API，可用于配置多个扩展

现在可以使用新的 `TextStyleKit`，更轻松地进行配置：

```ts
import { TextStyleKit } from '@tiptap/extension-text-style'

new Editor({
  extensions: [
    TextStyleKit.configure({
      backgroundColor: {
        types: ['textStyle'],
      },
      color: {
        types: ['textStyle'],
      },
      fontFamily: {
        types: ['textStyle'],
      },
      fontSize: {
        types: ['textStyle'],
      },
      lineHeight: {
        types: ['textStyle'],
      },
    }),
  ],
})
```

### 新增 `shouldRerenderOnTransaction`

`@tiptap/react` 的 Editor 配置现在包含 `shouldRerenderOnTransaction`，用于控制组件是否重新渲染。

在 3.0.0 之前，Editor 会在每次事务引发状态更新时重新渲染。这便于持续跟踪 editor 对象，但可能会影响渲染性能。

`shouldRerenderOnTransaction` 默认处于禁用状态。要启用它，请在 editor 配置中将 `shouldRerenderOnTransaction` 设为 `true`。

升级后，依赖 Editor 状态的 UI 元素可能会变得无响应。解决方法包括禁用此选项（可能会影响性能），或像下面这样手动跟踪状态：

```js
function MyEditor() {
  const [selection, setSelection] = useState({ from: 0, to: 0 });

  const editor = useEditor({
    // Editor configuration
    onTransaction({ transaction }) {
      setSelection({
        from: transaction.selection.from,
        to: transaction.selection.to,
      });
    },
  });
}
```

你也可以使用 `useEditorState` 提取整个状态，或选择要提取的特定值。

```js
const { currentSelection } = useEditorState({
  editor,
  selector: (snapshot) => {
    return { currentSelection: snapshot.editor.state.selection }
  },
})
```

这样便可以显式提取和管理状态，以供依赖该状态的 UI 逻辑使用。

### 命令变更

- `clearContent` 和 `setContent` 现在默认会触发更新
- `setContent` 的签名已变更为 (content, options)
- `insertContent` 的行为已调整，以避免在文本节点开头将其拆分

### NodeView 变更

NodeViewRendererProps 中的 `getPos` 函数现在可能返回 `undefined`。请更新代码以处理这种情况：

```ts
// Before
const pos = nodeViewProps.getPos()

// After
const pos = nodeViewProps.getPos()
if (pos !== undefined) {
  // use pos
}
```

### 已移除的功能

- 已移除 `editor.getCharacterCount()` 方法
- 已从 placeholder 扩展中移除 `considerAnyAsEmpty` 选项

## 新功能

### 扩展包

新的 `@tiptap/extensions` 包整合了多个实用扩展：

- [CharacterCount](/editor/extensions/functionality/character-count)
- [Dropcursor](/editor/extensions/functionality/dropcursor)
- [Gapcursor](/editor/extensions/functionality/gapcursor)
- [History](/editor/extensions/functionality/undo-redo)（现已更名为 `UndoRedo`）
- [Placeholder](/editor/extensions/functionality/placeholder)
- [TrailingNode](/editor/extensions/functionality/trailing-node)
- [Focus](/editor/extensions/functionality/focus)
- [Selection](/editor/extensions/functionality/selection)

这会自动更新项目中的导入语句。

迁移示例：

```diff
- import CharacterCount from '@tiptap/extension-character-count'
+ import { CharacterCount } from '@tiptap/extensions'
```

### 服务端渲染

改进了 SSR 支持，现在可以在服务端运行 editor 而不进行渲染：

```ts
const editor = new Editor({
  element: null, // opt-in to SSR
  content: {
    type: 'doc',
    content: [
      /* ... */
    ],
  },
  extensions: [
    /* ... */
  ],
})
```

### Mark 视图

新增对 [mark 视图](https://prosemirror.net/docs/ref/#view.MarkView) 的支持，可用于在 editor 中为 mark 渲染自定义视图。这对于渲染 mark 的自定义 UI 很有用，例如为文本颜色 mark 提供颜色选择器，或为链接 mark 提供链接编辑器。

支持 React 和 Vue 3 框架。

```ts
// Plain JS
import { Mark } from '@tiptap/core'

Mark.create({
  // Other options...
  addMarkView() {
    return ({ mark, HTMLAttributes }) => {
      const dom = document.createElement('b')
      const contentDOM = document.createElement('span')

      dom.appendChild(contentDOM)

      return {
        dom,
        contentDOM,
      }
    }
  },
})

// React
import { Mark } from '@tiptap/core'
import { ReactMarkViewRenderer } from '@tiptap/react'

Mark.create({
  // ... other options
  addMarkView() {
    return ReactMarkViewRenderer(YourComponent)
  },
})

// Vue 3
import { Mark } from '@tiptap/core'
import { VueMarkViewRenderer } from '@tiptap/vue-3'

Mark.create({
  addMarkView() {
    return VueMarkViewRenderer(Component)
  },
})
```

### 其他改进

- 新增删除事件跟踪
- HTML 解析现在使用 happy-dom-without-node
- 新增节点/mark 属性验证支持
- 改进了事务处理性能

## StarterKit 更新

StarterKit 现在默认包含以下扩展：

- [Link](/editor/extensions/marks/link)
- [ListKeymap](/editor/extensions/functionality/listkeymap)
- [Underline](/editor/extensions/marks/underline)

如果你单独安装了这些扩展，可以将它们移除：

```diff
- import Link from '@tiptap/extension-link'
- import ListKeymap from '@tiptap/extension-list-keymap'
- import Underline from '@tiptap/extension-underline'
```

如果你曾在 StarterKit 配置中禁用这些扩展，也请务必更新禁用的扩展名称：

```diff
const editor = new Editor({
  extensions: [
    StarterKit.configure({
-      history: false, // disable history
+      undoRedo: false // disable undo/redo (previously history)
    })
  ]
})
```

## 迁移步骤

1. 更新依赖项

   - 移除依赖 UMD 的代码
   - 安装 `@floating-ui/dom`（用于气泡菜单和浮动菜单）
   - 将 Tiptap 包更新到 v3

2. 更新菜单实现

   - 将 `tippyOptions` 替换为 Floating UI 选项
   - 更新菜单导入，使用 `/menus` 后缀

3. 检查 NodeView 的用法

   - 添加对 `getPos` 返回 `undefined` 的检查

4. 更新扩展

   - 在适用情况下迁移到 `@tiptap/extensions`
   - 移除冗余的 `StarterKit` 扩展
   - 更新文本样式配置

5. 检查命令用法

   - 更新 `setContent` 调用，以使用新的签名
   - 检查 `clearContent` 在默认触发更新时的行为
