Tiptap 是 TinyMCE 的强大替代方案。从 TinyMCE 迁移到 Tiptap 非常简单。本指南将逐步带你完成迁移过程。

## 内容迁移

### HTML 内容兼容性

TinyMCE 通常以 HTML 格式存储内容，因此迁移到 Tiptap 十分顺畅。Tiptap 无需转换即可直接使用 HTML 内容：

```ts
// Your existing TinyMCE content
const existingContent = '<p>Hello <strong>world</strong>!</p>'

// Use directly in Tiptap
const editor = new Editor({
  content: existingContent,
  extensions: [StarterKit],
})
```

虽然 HTML 完全可用，但我们建议将其转换为 Tiptap 的 JSON 格式，以提升性能和可读性。若要批量转换现有内容，可使用 [HTML 工具](/editor/api/utilities/html)以编程方式将 HTML 转换为 JSON。

## 编辑器设置

### 安装

首先，安装 Tiptap 及其依赖项：

```bash
npm install @tiptap/core @tiptap/starter-kit
```

Tiptap 支持所有现代前端 UI 框架，例如 React 和 Vue。请按照[安装指南](/editor/getting-started/install)中的框架专属说明进行操作。

### 编辑器基本设置

将 TinyMCE 初始化代码替换为 Tiptap：

```ts
// TinyMCE (before)
tinymce.init({
  selector: '#editor',
  plugins: 'lists link image table code',
  toolbar: 'undo redo | bold italic | bullist numlist | link image',
})

// Tiptap (after)
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'

const editor = new Editor({
  element: document.querySelector('#editor'),
  extensions: [StarterKit],
  content: '<p>Hello World!</p>',
})
```

## 扩展

### 了解 Tiptap 的扩展系统

Tiptap 使用模块化扩展系统，其架构与 TinyMCE 的插件体系类似。每项功能都是一个可独立配置的扩展。

[StarterKit](/editor/extensions/functionality/starterkit) 是一组基础扩展，你可以根据需要添加或移除其他扩展。

在[扩展指南](/editor/extensions/overview)中查看所有可用扩展，或[创建自定义扩展](/editor/extensions/custom-extensions)，以支持自定义功能和 HTML 元素。

### 常见 TinyMCE 插件的对应项

| TinyMCE 插件 | Tiptap 扩展 | 说明 |
| -------------- | --------------------------------------- | ---------------------- |
| `lists`        | `BulletList`, `OrderedList`, `ListItem` | 包含在 StarterKit 中 |
| `link`         | `Link`                                  | 包含在 StarterKit 中 |
| `image`        | `Image`                                 | 可单独使用 |
| `table`        | `Table`                                 | 可单独使用 |
| `code`         | `Code`, `CodeBlock`                     | 包含在 StarterKit 中 |
| `textcolor`    | `TextStyle`, `Color`                    | 可单独使用 |
| `fontsize`     | `TextStyle`, `FontSize`                 | 可单独使用 |
| `align`        | `TextAlign`                             | 可单独使用 |

### 扩展配置

```ts
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import Image from '@tiptap/extension-image'
import Table from '@tiptap/extension-table'
import TableRow from '@tiptap/extension-table-row'
import TableHeader from '@tiptap/extension-table-header'
import TableCell from '@tiptap/extension-table-cell'

const editor = new Editor({
  extensions: [
    StarterKit,
    // Add and configure extensions
    Image.configure({
      inline: true,
      allowBase64: true,
    }),
    Table.configure({
      resizable: true,
    }),
    TableRow,
    TableHeader,
    TableCell,
  ],
})
```

### 自定义扩展

对于 TinyMCE 自定义插件，你可以创建自定义 Tiptap 扩展。详细说明请参阅[自定义扩展指南](/editor/extensions/custom-extensions)。

## UI 实现

### 工具栏实现

在 Tiptap 中，TinyMCE 的工具栏配置需要转换为自定义 UI 组件：

```tsx
// TinyMCE toolbar config
toolbar: 'undo redo | bold italic | bullist numlist'

// Tiptap equivalent (React example)
function Toolbar({ editor }) {
  if (!editor) return null

  return (
    <div className="toolbar">
      <button onClick={() => editor.chain().focus().undo().run()} disabled={!editor.can().undo()}>
        Undo
      </button>
      <button onClick={() => editor.chain().focus().redo().run()} disabled={!editor.can().redo()}>
        Redo
      </button>
      <button
        onClick={() => editor.chain().focus().toggleBold().run()}
        className={editor.isActive('bold') ? 'active' : ''}
      >
        Bold
      </button>
      <button
        onClick={() => editor.chain().focus().toggleItalic().run()}
        className={editor.isActive('italic') ? 'active' : ''}
      >
        Italic
      </button>
    </div>
  )
}
```

### 菜单系统

TinyMCE 的上下文菜单可以替换为 Tiptap 的 BubbleMenu 和 FloatingMenu：

```tsx
import { BubbleMenu } from '@tiptap/react'

function MyEditor() {
  const editor = useEditor({
    extensions: [StarterKit],
  })

  return (
    <>
      <EditorContent editor={editor} />
      <BubbleMenu editor={editor}>
        <button
          onClick={() => editor.chain().focus().toggleBold().run()}
          className={editor.isActive('bold') ? 'active' : ''}
        >
          Bold
        </button>
        <button
          onClick={() => editor.chain().focus().toggleItalic().run()}
          className={editor.isActive('italic') ? 'active' : ''}
        >
          Italic
        </button>
      </BubbleMenu>
    </>
  )
}
```
