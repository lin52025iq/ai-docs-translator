Tiptap 是一款广受欢迎的 Quill 替代方案，从 Quill 迁移到 Tiptap 非常简单。本指南将帮助你顺利从 Quill 的 Delta 格式过渡到 Tiptap 的扩展系统。

## 内容迁移

### HTML 内容兼容性

Quill 使用 Delta 格式存储内容，迁移到 Tiptap 时需要先将其转换为 HTML：

```ts
// Convert Quill Delta to HTML first
const quill = new Quill('#temp-editor')
quill.setContents(existingDeltaContent)
const htmlContent = quill.root.innerHTML

// Use HTML content in Tiptap
const editor = new Editor({
  content: htmlContent,
  extensions: [StarterKit],
})
```

如果你已经有 Quill 输出的 HTML，可以直接使用：

```ts
// Your existing Quill HTML content
const existingContent = '<p>Hello <strong>world</strong>!</p>'

// Use directly in Tiptap
const editor = new Editor({
  content: existingContent,
  extensions: [StarterKit],
})
```

虽然 HTML 完全可用，但我们建议将其转换为 Tiptap 的 JSON 格式，以提升性能和可读性。若要批量转换现有内容，可以使用 [HTML 工具](/editor/api/utilities/html)以编程方式将 HTML 转换为 JSON。

## 编辑器配置

### 安装

首先，安装 Tiptap 及其依赖项：

```bash
npm install @tiptap/core @tiptap/starter-kit
```

Tiptap 支持 React 和 Vue 等所有现代前端 UI 框架。请参阅我们的[安装指南](/editor/getting-started/install)，按照相应框架的说明进行安装。

### 基本编辑器配置

将 Quill 初始化代码替换为 Tiptap：

```ts
// Quill (before)
const quill = new Quill('#editor', {
  theme: 'snow',
  modules: {
    toolbar: [
      ['bold', 'italic', 'underline'],
      ['link', 'image'],
      [{ list: 'ordered' }, { list: 'bullet' }],
      [{ header: [1, 2, 3, false] }],
    ],
  },
})

// Tiptap (after)
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'

const editor = new Editor({
  element: document.querySelector('#editor'),
  extensions: [StarterKit],
  content: '<p>Hello World!</p>',
})
```

## 扩展

### 了解 Tiptap 的扩展系统

Tiptap 使用模块化的扩展系统，与 Quill 的模块系统类似。每项功能都是独立的扩展，可以进行配置和自定义。

[StarterKit](/editor/extensions/functionality/starterkit) 集合了所有基础扩展，你可以根据需要添加或移除其他扩展。

在我们的[扩展指南](/editor/extensions/overview)中查看所有可用扩展；也可以[创建自己的扩展](/editor/extensions/custom-extensions)，以支持自定义功能和 HTML 元素。

### 常见 Quill 模块对应项

| Quill 功能 | Tiptap 扩展 | 说明 |
| --------------------- | --------------------------------------- | ---------------------- |
| 粗体 | `Bold` | 包含在 StarterKit 中 |
| 斜体 | `Italic` | 包含在 StarterKit 中 |
| 下划线 | `Underline` | 包含在 StarterKit 中 |
| 链接 | `Link` | 包含在 StarterKit 中 |
| 图片 | `Image` | 可单独使用 |
| 列表（项目符号/有序） | `BulletList`、`OrderedList`、`ListItem` | 包含在 StarterKit 中 |
| 标题 | `Heading` | 包含在 StarterKit 中 |
| 引用块 | `Blockquote` | 包含在 StarterKit 中 |
| 代码块 | `CodeBlock` | 包含在 StarterKit 中 |
| 删除线 | `Strike` | 包含在 StarterKit 中 |
| 颜色 | `TextStyle`、`Color` | 可单独使用 |
| 背景 | `TextStyle`、`Highlight` | 可单独使用 |
| 对齐 | `TextAlign` | 可单独使用 |

### 配置扩展

```ts
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import Image from '@tiptap/extension-image'
import TextAlign from '@tiptap/extension-text-align'
import { Color } from '@tiptap/extension-color'
import TextStyle from '@tiptap/extension-text-style'

const editor = new Editor({
  extensions: [
    StarterKit,
    Image.configure({
      inline: true,
      allowBase64: true,
    }),
    TextAlign.configure({
      types: ['heading', 'paragraph'],
    }),
    TextStyle,
    Color.configure({
      types: [TextStyle.name, ListItem.name],
    }),
  ],
})
```

### 自定义扩展

对于 Quill 的自定义模块或 blot，可以创建自定义 Tiptap 扩展。详细说明请参阅我们的[自定义扩展指南](/editor/extensions/custom-extensions)。

## UI 实现

### 工具栏实现

在 Tiptap 中，Quill 的工具栏配置需要通过自定义 UI 组件来实现：

```tsx
// Quill toolbar config
toolbar: [
  ['bold', 'italic', 'underline'],
  ['link', 'image'],
  [{ list: 'ordered' }, { list: 'bullet' }],
  [{ header: [1, 2, 3, false] }],
]

// Tiptap equivalent (React example)
function Toolbar({ editor }) {
  if (!editor) return null

  return (
    <div className="toolbar">
      <div className="toolbar-group">
        <button
          onClick={() => editor.chain().focus().toggleBold().run()}
          className={editor.isActive('bold') ? 'active' : ''}
        >
          Bold
        </button>
        <button
          onClick={() => editor.chain().focus().toggleItalic().run()}
          className={editor.isActive('italic') ? 'active' : ''}
        >
          Italic
        </button>
        <button
          onClick={() => editor.chain().focus().toggleUnderline().run()}
          className={editor.isActive('underline') ? 'active' : ''}
        >
          Underline
        </button>
      </div>

      <div className="toolbar-group">
        <button
          onClick={() => {
            const url = window.prompt('URL')
            if (url) {
              editor.chain().focus().extendMarkRange('link').setLink({ href: url }).run()
            }
          }}
          className={editor.isActive('link') ? 'active' : ''}
        >
          Link
        </button>
        <button
          onClick={() => {
            const url = window.prompt('Image URL')
            if (url) {
              editor.chain().focus().setImage({ src: url }).run()
            }
          }}
        >
          Image
        </button>
      </div>

      <div className="toolbar-group">
        <button
          onClick={() => editor.chain().focus().toggleOrderedList().run()}
          className={editor.isActive('orderedList') ? 'active' : ''}
        >
          Numbered List
        </button>
        <button
          onClick={() => editor.chain().focus().toggleBulletList().run()}
          className={editor.isActive('bulletList') ? 'active' : ''}
        >
          Bullet List
        </button>
      </div>

      <div className="toolbar-group">
        <select
          onChange={(e) => {
            const level = parseInt(e.target.value)
            if (level === 0) {
              editor.chain().focus().setParagraph().run()
            } else {
              editor.chain().focus().toggleHeading({ level }).run()
            }
          }}
          value={
            editor.isActive('heading', { level: 1 })
              ? 1
              : editor.isActive('heading', { level: 2 })
                ? 2
                : editor.isActive('heading', { level: 3 })
                  ? 3
                  : 0
          }
        >
          <option value={0}>Normal</option>
          <option value={1}>Heading 1</option>
          <option value={2}>Heading 2</option>
          <option value={3}>Heading 3</option>
        </select>
      </div>
    </div>
  )
}
```

### 气泡工具栏（Quill 的气泡主题）

使用 Tiptap 的 BubbleMenu 复刻 Quill 的气泡主题：

```tsx
import { BubbleMenu, useEditor } from '@tiptap/react'

function MyEditor() {
  const editor = useEditor({
    extensions: [StarterKit],
  })

  return (
    <>
      <EditorContent editor={editor} />
      <BubbleMenu editor={editor}>
        <button
          onClick={() => editor.chain().focus().toggleBold().run()}
          className={editor.isActive('bold') ? 'active' : ''}
        >
          Bold
        </button>
        <button
          onClick={() => editor.chain().focus().toggleItalic().run()}
          className={editor.isActive('italic') ? 'active' : ''}
        >
          Italic
        </button>
        <button
          onClick={() => {
            const url = window.prompt('URL')
            if (url) {
              editor.chain().focus().extendMarkRange('link').setLink({ href: url }).run()
            }
          }}
          className={editor.isActive('link') ? 'active' : ''}
        >
          Link
        </button>
      </BubbleMenu>
    </>
  )
}
```
