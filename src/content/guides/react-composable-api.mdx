Tiptap 提供了声明式的 `<Tiptap>` 组件，可简化编辑器的设置，并自动向所有子组件提供上下文。这个可组合 API 是基于 hook 的 `useEditor` + `<EditorContent />` 方案的替代选择，让你能够以更符合 React 惯用方式的形式使用 Tiptap。

## 何时使用可组合 API

在以下情况下，可组合 API 是理想选择：

- 希望采用更具声明性、以组件为基础的方式
- 需要从多个子组件访问编辑器
- 相较于手动传递 props，更倾向于自动管理上下文
- 正在构建复杂的编辑器 UI（工具栏、菜单、侧边栏、区块）

对于较简单的用例，或者需要更直接控制的场景，[基于 hook 的 useEditor 方案](/editor/getting-started/install/react)可能更合适。

## 安装

使用可组合 API 前，请确保已在 React 项目中安装 Tiptap。请按照 [React 安装指南](/editor/getting-started/install/react)配置所需的依赖项。

## 使用 Tiptap 组件

`<Tiptap>` 组件是根级 Provider，通过 React context 将编辑器实例提供给所有子组件。

### 基本设置

新建一个 React 组件，并从 `@tiptap/react` 导入 `Tiptap` 组件和 `useEditor`（菜单组件从 `@tiptap/react/menus` 导入）：

```tsx
// src/Editor.tsx
"use client"

import { Tiptap, useEditor } from '@tiptap/react'
import { BubbleMenu, FloatingMenu } from '@tiptap/react/menus'
import StarterKit from '@tiptap/starter-kit'

function Editor() {
  const editor = useEditor({
    extensions: [StarterKit],
    content: '<p>Hello World!</p>',
  })

  if (!editor) return null

  return (
    <Tiptap editor={editor}>
      <Tiptap.Content />

      <BubbleMenu editor={editor}>
        <button>Bold</button>
        <button>Italic</button>
      </BubbleMenu>

      <FloatingMenu editor={editor}>
        <button>Add heading</button>
      </FloatingMenu>
    </Tiptap>
  )
}

export default Editor
```

### 可用的子组件

| 组件 | 说明 |
| --- | --- |
| `Tiptap.Content` | 渲染编辑器内容区域，替代 `<EditorContent editor={editor} />`。 |

菜单组件需从 `@tiptap/react/menus` 单独导入。

## 在子组件中访问编辑器

可组合 API 的一项主要优势是，子组件无需逐层传递 props 即可访问编辑器。

### 使用 useTiptap hook

`useTiptap` hook 会从 context 返回编辑器实例。

```tsx
import { useTiptap } from '@tiptap/react'

function MenuBar() {
  const { editor } = useTiptap()

  if (!editor) return null

  return (
    <div className="menu-bar">
      <button
        onClick={() => editor.chain().focus().toggleBold().run()}
        className={editor.isActive('bold') ? 'is-active' : ''}
      >
        Bold
      </button>
      <button
        onClick={() => editor.chain().focus().toggleItalic().run()}
        className={editor.isActive('italic') ? 'is-active' : ''}
      >
        Italic
      </button>
    </div>
  )
}
```

然后，可以在 `<Tiptap>` 组件中的任意位置添加菜单栏：

```tsx
<Tiptap editor={editor}>
  <MenuBar />
  <Tiptap.Content />
</Tiptap>
```

### 使用 useTiptapState 获取响应式状态

对于对性能敏感的组件，可以使用 `useTiptapState` 订阅编辑器状态的特定部分。这样，在无关状态发生变化时，就能避免不必要的重新渲染。

```tsx
import { useTiptapState } from '@tiptap/react'

function WordCount() {
  const { editor } = useTiptap()

  const wordCount = useTiptapState((state) => {
    const text = state.editor.state.doc.textContent
    return text.split(/\s+/).filter(Boolean).length
  })

  if (!editor) {
    return null
  }

  return <span>{wordCount} words</span>
}
```

选择器函数接收一个 `EditorStateSnapshot`，并且应只返回组件所需的数据。只有选定值发生变化时，组件才会重新渲染。

## 服务端渲染（SSR）

可组合 API 与服务端渲染配合使用十分顺畅。由于编辑器实例只会在客户端创建，你可以在实例创建完成前暂缓渲染：

```tsx
"use client"

import { Tiptap, useEditor } from '@tiptap/react'
import StarterKit from '@tiptap/starter-kit'

export function MyEditor() {
  const editor = useEditor({
    extensions: [StarterKit],
    content: '<p>Hello World!</p>',
  })

  if (!editor) {
    return <div className="skeleton">Loading editor...</div>
  }

  return (
    <Tiptap editor={editor}>
      <Tiptap.Content />
    </Tiptap>
  )
}
```

## 性能注意事项

可组合 API 在设计时充分考虑了性能：

- **自动优化上下文**：编辑器上下文会进行记忆化处理，以避免不必要的重新渲染
- **选择性订阅**：使用 `useTiptapState` 仅订阅所需的状态

如需了解更多性能优化建议，请参阅 [React 性能指南](/guides/performance)。

## 向后兼容性

`<Tiptap>` 组件会自动提供 `EditorContext`，因此，为了兼容现有代码，你可以在其中使用 `useCurrentEditor` hook：

```tsx
import { useCurrentEditor } from '@tiptap/react'

function EditorJSONPreview() {
  const { editor } = useCurrentEditor()

  if (!editor) return null

  return <pre>{JSON.stringify(editor.getJSON(), null, 2)}</pre>
}
```

不过，对于新代码，我们建议使用 `useTiptap()`。

## API 参考

### Tiptap 组件

根级 Provider 组件，通过 React context 提供编辑器实例。

**Props：**

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `editor` | `Editor \| null` | 来自 `useEditor()` 的编辑器实例 |
| `children` | `ReactNode` | 子组件 |

**示例：**

```tsx
<Tiptap editor={editor}>
  <Tiptap.Content />
</Tiptap>
```

### useTiptap hook

返回 Tiptap context 的值。

**返回值：**

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `editor` | `Editor \| null` | 编辑器实例 |

**示例：**

```tsx
const { editor } = useTiptap()

if (!editor) return null
```

### useTiptapState hook

使用选择器函数订阅编辑器状态的一个切片。

**签名：**

```tsx
const value = useTiptapState(selector, equalityFn?)
```

**参数：**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `selector` | `(state: EditorStateSnapshot) => T` | 用于选择状态的函数 |
| `equalityFn` | `(a: T, b: T) => boolean` | 可选的相等性函数，用于控制重新渲染 |

**示例：**

```tsx
const isBold = useTiptapState((state) =>
  state.editor.isActive('bold')
)
```

## 比较：可组合 API 与基于 Hook 的方案

| 特性 | 可组合 API | 基于 Hook 的方案 |
| --- | --- | --- |
| 设置复杂度 | 低——声明式组件 | 中——手动传递 props |
| 上下文管理 | 自动 | 通过 EditorContext.Provider 手动管理 |
| 子组件访问 | 通过 `useTiptap()` 轻松访问 | 需要逐层传递 props 或使用 context |
| SSR 支持 | 条件渲染（`if (!editor)`） | 手动检查 null 值 |
| 性能 | 使用 `useTiptapState` 优化 | 使用 `useEditorState` 优化 |
| 适用场景 | 包含许多子组件的复杂 UI | 简单 UI 或需要直接控制的场景 |
