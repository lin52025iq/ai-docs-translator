Tiptap Pro 扩展为 Tiptap 编辑器提供高级功能，例如版本管理和 AI 辅助内容生成。访问 Pro 扩展需要 Tiptap 账户。Snapshots、Comments 等部分扩展，以及 AI Toolkit 的某些功能，还需要有效订阅。

Tiptap Pro 和 Cloud 扩展可解锁协作、版本历史记录、评论、AI 辅助编辑等功能。你可以使用个人访问令牌，从 Tiptap 的私有 NPM 注册表安装这些扩展。

<Callout title="安全警告" variant="warning">
  请像保护密码一样保护身份验证令牌，以防止未经授权的使用。每个 Tiptap 用户都有一个唯一且永不过期的身份验证令牌。我们建议为 CI/CD 应用创建专用用户。
</Callout>

## 获取访问令牌

1. 登录 Tiptap 账户（或[注册](https://cloud.tiptap.dev/register)）。
2. 开始 Tiptap 方案的[试用或订阅](https://cloud.tiptap.dev/v2/billing)。
3. 从[我的功能 → Pro 扩展](https://cloud.tiptap.dev/v2/features/pro-extensions)复制个人 NPM 令牌。

## 为每个项目配置身份验证

在项目根目录下的包管理器配置中添加注册表和令牌。

<Callout title="提示" variant="info">
  将 `TIPTAP_PRO_TOKEN` 设为环境变量，以避免将凭据提交到代码库。
</Callout>

### npm、pnpm 或 Yarn Classic

创建或更新 .npmrc：

```
@tiptap-pro:registry=https://registry.tiptap.dev/
//registry.tiptap.dev/:_authToken=${TIPTAP_PRO_TOKEN}
```

### Yarn Modern（Yarn 2+）

创建或更新 .yarnrc.yml：

```
npmScopes:
 tiptap-pro:
   npmAlwaysAuth: true
   npmRegistryServer: "https://registry.tiptap.dev/"
   npmAuthToken: ${TIPTAP_PRO_TOKEN}
```

将 `.npmrc` 或 `.yarnrc.yml` 添加到 `.gitignore`。

<Callout title="警告" variant="hint">
  如果直接在配置文件中指定身份验证令牌，这样做对于防止凭据泄露至关重要。
</Callout>

为项目配置好身份验证后，你就可以像安装其他 Editor 扩展一样安装 Pro 扩展。

如果使用环境变量，请在安装时传入身份验证令牌：

```
TIPTAP_PRO_TOKEN=actual-auth-token npm install --save @tiptap-pro/extension-comments
```

## 配置全局身份验证

你可以通过更新用户级别的包管理器配置文件，一次性为**所有**项目设置身份验证。这对于 CI/CD 环境很有用。

1. 登录 Tiptap 账户（或创建一个免费账户）。
2. 开始 Tiptap 方案的[试用或订阅](https://cloud.tiptap.dev/v2/billing)。
3. （可选）为 CI/CD 流水线[邀请团队成员](https://cloud.tiptap.dev/v2/team/members)。
4. 从[我的功能 → Pro 扩展](https://cloud.tiptap.dev/v2/features/pro-extensions)复制个人 NPM 令牌。

### npm 或 Yarn Classic

```bash
npm config set "@tiptap-pro:registry" https://registry.tiptap.dev/
npm config set "//registry.tiptap.dev/:_authToken" actual-auth-token
```

### Yarn Modern

```bash
yarn config set --home npmScopes.@tiptap-pro.npmRegistryServer "https://registry.tiptap.dev/"
yarn config set --home npmScopes.@tiptap-pro.npmAlwaysAuth "true"
yarn config set --home npmScopes.@tiptap-pro.npmAuthToken "actual-auth-token"
```

### pnpm

```bash
pnpm config set --global "@tiptap-pro:registry" https://registry.tiptap.dev/
pnpm config set "//registry.tiptap.dev/:_authToken" actual-auth-token
```

现在，你可以在任何代码库中安装任意 Tiptap Pro 扩展：

```
npm install --save @tiptap-pro/extension-comments
```
