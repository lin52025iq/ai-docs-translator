应用应在服务器上使用环境的私钥为自己的令牌签名，私钥绝不能离开服务器。

以下是快速设置指南。完整参考请参阅[身份验证](/authentication)和[在 Collaboration 中进行身份验证和授权](/collaboration/getting-started/authenticate)。

## 为令牌签名

在服务器上使用环境的私钥为令牌签名，私钥绝不能离开服务器。Collaboration 令牌会设置 `aud: "Documents"`，并携带 `permissions`，用于指定用户可以访问哪些文档。

```typescript
import { SignJWT, importPKCS8 } from 'jose'

const privateKey = await importPKCS8(process.env.TIPTAP_PRIVATE_KEY, 'ES256')

const jwt = await new SignJWT({
  permissions: [{ action: 'Documents:Write', resource: '*' }],
})
  .setProtectedHeader({ alg: 'ES256' })
  .setIssuer(process.env.TIPTAP_ENVIRONMENT_ID)
  .setSubject('user-identifier')
  .setAudience(['Documents'])
  .setExpirationTime('30m')
  .sign(privateKey)
// 将此令牌放入 provider 的 `token` 字段中。切勿向前端公开私钥。
```

其他语言的示例请参阅[为令牌签名](/authentication#signing-the-token)；有关短期令牌和撤销，请参阅[处理令牌过期](/collaboration/getting-started/authenticate#handle-token-expiry)。

## 限制对特定文档的访问

若要将令牌的访问范围限定为特定文档，请将权限的 `resource` 设置为文档名称，或使用 `prefix` 约束匹配一组文档：

```typescript
const jwt = await new SignJWT({
  permissions: [
    {
      action: 'Documents:Write',
      resource: '*',
      constraints: { prefix: '1500c624-8f9f-496a-b196-5e5dd8ec3c25/' },
    },
  ],
})
  .setProtectedHeader({ alg: 'ES256' })
  .setIssuer(process.env.TIPTAP_ENVIRONMENT_ID)
  .setAudience(['Documents'])
  .setExpirationTime('30m')
  .sign(privateKey)
```

这将授予用户访问其前缀下所有文档的权限。关于此前的 `allowedDocumentNames` 模型，请参阅[旧版身份验证](/authentication/legacy)。
