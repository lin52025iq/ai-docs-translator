首先，Tiptap v1 已不再受支持，也不会再收到任何更新。

如果你仍在使用 Tiptap v1，可以在[这里](https://v1.tiptap.dev/)查看文档，但我们强烈建议你升级到版本 2。

是的，将你最喜欢的文本编辑器升级到新的 API 是件繁琐的事，不过我们确保你有足够的理由升级到最新版本。

- IDE 中的自动补全（感谢 TypeScript）
- 出色的文档，包含 100 多个页面和 100 多个交互式示例
- 持续活跃的开发、正在开发的新功能，以及每周发布的新版本
- 大量全新扩展
- 经过充分测试的代码库

新的 API 看起来会让你很熟悉，但其中确实有很多变化。为了让升级更轻松，以下是你需要了解的所有内容：

## 卸载 Tiptap v1

整个包结构都发生了变化，我们甚至换用了另一个 npm 命名空间，因此在升级到 Tiptap 2 之前，你需要彻底移除旧版本。

否则你可能会遇到异常，例如“似乎加载了多个版本的 prosemirror-model”。

```bash
npm uninstall tiptap tiptap-commands tiptap-extensions tiptap-utils
```

## 安装 Tiptap v2

卸载旧版 Tiptap 后，安装新的 Vue 2 包、ProseMirror 库和 starter kit：

```bash
npm install @tiptap/vue-2 @tiptap/pm @tiptap/starter-kit
```

## 保持 Tiptap v2 为最新版本

我们会持续发布 Tiptap 更新。

遗憾的是，npm 没有内置工具可以轻松更新依赖，不过你可以使用 `npm-check` 包：

```bash
npm install -g npm-check
npm-check -u
```

## 显式注册 Document、Text 和 Paragraph 扩展

Tiptap 1 曾通过默认设置 `useBuiltInExtensions: true` 隐藏了一些必需的扩展。该设置已被移除，你需要导入所有扩展。请务必显式导入至少 [`Document`](/editor/extensions/nodes/document)、[`Paragraph`](/editor/extensions/nodes/paragraph) 和 [`Text`](/editor/extensions/nodes/text) 扩展。

```js
import Document from '@tiptap/extension-document'
import Paragraph from '@tiptap/extension-paragraph'
import Text from '@tiptap/extension-text'

new Editor({
  extensions: [
    Document,
    Paragraph,
    Text,
    // all your other extensions
  ],
})
```

我们还移除了一些设置：`dropCursor`、`enableDropCursor` 和 `enableGapCursor`。它们现在是独立的扩展：[`Dropcursor`](/editor/extensions/functionality/dropcursor) 和 [`Gapcursor`](/editor/extensions/functionality/gapcursor)。你可能会想加载它们；如果不需要，忽略这一点即可。

## 大多数扩展都采用了新名称

我们改用了小驼峰命名法，因此许多类型名称都发生了变化。如果你将内容存储为 JSON，就需要遍历内容并重命名这些类型。为此带来的不便，我们深表歉意。

| 旧类型                 | 新类型                 |
| ---------------------- | ---------------------- |
| ~~`bullet_list`~~      | `bulletList`           |
| ~~`code_block`~~       | `codeBlock`            |
| ~~`hard_break`~~       | `hardBreak`            |
| ~~`horizontal_rule`~~  | `horizontalRule`       |
| ~~`list_item`~~        | `listItem`             |
| ~~`ordered_list`~~     | `orderedList`          |
| ~~`table_cell`~~       | `tableCell`            |
| ~~`table_header`~~     | `tableHeader`          |
| ~~`table_row`~~        | `tableRow`             |
| ~~`todo_list`~~        | `taskList`（新名称！） |
| ~~`todo_item`~~        | `taskItem`（新名称！） |

## 已移除的方法

我们移除了 `.state()` 方法。不过不用担心，你仍然可以通过 `editor.state` 访问状态。

## 新的扩展 API

如果你为项目构建了自定义扩展，就需要重写它们以适配新的 API。不过不用担心，你的大部分工作仍然可以保留。`schema`、`commands`、`keys`、`inputRules` 和 `pasteRules` 的工作方式与以前相同，只是注册方式不同。

```js
import { Node } from '@tiptap/core'

const CustomExtension = Node.create({
  name: 'custom_extension',
  addOptions() {
    …
  },
  addAttributes() {
    …
  },
  parseHTML() {
    …
  },
  renderHTML({ node, HTMLAttributes }) {
    …
  },
  addCommands() {
    …
  },
  addKeyboardShortcuts() {
    …
  },
  addInputRules() {
    …
  },
  // and more …
})
```

请阅读我们的指南，了解[构建自定义扩展的各种实用细节](/editor/extensions/custom-extensions)。

## 设置和方法已重命名

[我们重命名了许多设置和方法](/editor/api/editor)。希望你可以通过查找和替换迁移到新的 API。以下是变更列表：

| 旧名称           | 新名称      |
| ---------------- | ----------- |
| ~~`autoFocus`~~  | `autofocus` |

## 命令已重命名

所有新扩展都提供了用于设置、取消设置和切换样式的专用命令。因此，`.bold()` 现在改为 `.toggleBold()`。此外，我们改用了小驼峰命名法，下面列出了一些示例。还有，`todo_list` 已重命名为 `taskList`，为此带来的不便，我们深表歉意。

| 旧命令                   | 新命令                          |
| ------------------------ | ------------------------------- |
| `.redo()`                | `.redo()`（没有变化）           |
| `.undo()`                | `.undo()`（没有变化）           |
| ~~`.todo_list()`~~       | `.toggleTaskList()`（新名称！） |
| ~~`.blockquote()`~~      | `.toggleBlockquote()`           |
| ~~`.bold()`~~            | `.toggleBold()`                 |
| ~~`.bullet_list()`~~     | `.toggleBulletList()`           |
| ~~`.code()`~~            | `.toggleCode()`                 |
| ~~`.code_block()`~~      | `.toggleCodeBlock()`            |
| ~~`.hard_break()`~~      | `.setHardBreak()`               |
| ~~`.heading()`~~         | `.toggleHeading()`              |
| ~~`.horizontal_rule()`~~ | `.setHorizontalRule()`          |
| ~~`.italic()`~~          | `.toggleItalic()`               |
| ~~`.link()`~~            | `.toggleLink()`                 |
| ~~`.ordered_list()`~~    | `.toggleOrderedList()`          |
| ~~`.paragraph()`~~       | `.setParagraph()`               |
| ~~`.strike()`~~          | `.toggleStrike()`               |
| ~~`.underline()`~~       | `.toggleUnderline()`            |
| …                        | …                               |

## MenuBar、BubbleMenu 和 FloatingMenu

请阅读专门的[菜单创建指南](/editor/getting-started/style-editor/custom-menus)，了解如何迁移菜单。

## 现在可以串联命令

现在，大多数命令都可以合并为一次调用。在大多数情况下，这比单独调用函数更简洁。下面以将选中文本设为粗体为例：

```js
editor.chain().focus().toggleBold().run()
```

需要使用 `.chain()` 开始新的命令链，并使用 `.run()` 实际执行其中的所有命令。请阅读 API 文档，进一步了解[新的 Tiptap 命令](/editor/api/commands)。

## 不再对每个命令都调用 .focus()

在 Tiptap 1 中，我们尝试隐藏 `.focus()` 命令，并在每个命令上都执行它。这在某些使用场景中会造成问题，例如你希望运行命令，但不希望聚焦编辑器。

在 Tiptap v2 中，你需要显式调用 `focus()`，而且很多时候可能都需要这样做。示例如下：

```js
editor.chain().focus().toggleBold().run()
```

## 事件回调的参数更少

新的事件回调参数更少了。现在你应该可以通过 `this.` 访问相同的信息。[在这里了解更多事件相关内容。](/editor/api/events)

## 协同编辑

协同编辑的参考实现现在使用 Y.js。这是完全不同的一套实现。你仍然可以使用 Tiptap 1 的扩展，但需要自行将其适配到新的扩展 API。如果你完成了适配，别忘了与我们分享，这样我们就可以在这里添加链接！

请阅读我们的指南，进一步了解[全新的协同编辑体验](/collaboration/getting-started/install)。

## Mark 不再支持 Node View

对于 Mark，ProseMirror 对 Node View 的[支持并不完善](https://discuss.prosemirror.net/t/there-is-a-bug-in-marks-nodeview/2722/2)。Tiptap 1 中也有一个[相关问题](https://github.com/ueberdosis/tiptap/issues/613)。因此，我们在 Tiptap 2 中移除了这项支持。
