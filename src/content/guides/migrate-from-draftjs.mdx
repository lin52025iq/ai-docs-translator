Tiptap 是 Draft.js 的热门替代方案，从 Draft.js 迁移到 Tiptap 非常简单。本指南将帮助你从 Draft.js 的不可变状态模型过渡到 Tiptap 的扩展系统。

## 内容迁移

### HTML 内容兼容性

Draft.js 使用 ContentState，需要将其转换为 HTML 才能用于 Tiptap：

```ts
// Convert Draft.js ContentState to HTML
import { convertFromRaw } from 'draft-js'
import { stateToHTML } from 'draft-js-export-html'

// If you have ContentState
const htmlContent = stateToHTML(contentState)

// If you have raw state (JSON)
const contentState = convertFromRaw(rawContentState)
const htmlContent = stateToHTML(contentState)

// Use HTML content in Tiptap
const editor = new Editor({
  content: htmlContent,
  extensions: [StarterKit],
})
```

如果你已经有 Draft.js 输出的 HTML，可以直接使用：

```ts
// Your existing Draft.js HTML content
const existingContent = '<p>Hello <strong>world</strong>!</p>'

// Use directly in Tiptap
const editor = new Editor({
  content: existingContent,
  extensions: [StarterKit],
})
```

虽然 HTML 可以正常使用，但我们建议将其转换为 Tiptap 的 JSON 格式，以提升性能和可读性。要批量转换现有内容，可以使用 [HTML 工具](/editor/api/utilities/html)以编程方式将 HTML 转换为 JSON。

## 编辑器设置

### 安装

首先，安装 Tiptap 及其依赖：

```bash
npm install @tiptap/core @tiptap/starter-kit
```

Tiptap 支持所有现代前端 UI 框架，例如 React 和 Vue。请按照[安装指南](/editor/getting-started/install)中针对相应框架的说明进行安装。

### 基本编辑器设置

将 Draft.js 编辑器替换为 Tiptap：

```tsx
// Draft.js (before)
import React, { useState } from 'react'
import { Editor, EditorState, RichUtils } from 'draft-js'

function MyDraftEditor() {
  const [editorState, setEditorState] = useState(EditorState.createEmpty())

  const handleKeyCommand = (command) => {
    const newState = RichUtils.handleKeyCommand(editorState, command)
    if (newState) {
      setEditorState(newState)
      return 'handled'
    }
    return 'not-handled'
  }

  return (
    <Editor
      editorState={editorState}
      onChange={setEditorState}
      handleKeyCommand={handleKeyCommand}
    />
  )
}

// Tiptap (after)
import { useEditor, EditorContent } from '@tiptap/react'
import StarterKit from '@tiptap/starter-kit'

function MyTiptapEditor() {
  const editor = useEditor({
    extensions: [StarterKit],
    content: '<p>Hello World!</p>',
  })

  return <EditorContent editor={editor} />
}
```

## 扩展

### 了解 Tiptap 的扩展系统

Tiptap 采用模块化扩展系统，与 Draft.js 的实体和装饰器系统类似。每项功能都是一个独立的扩展，并提供清晰的 API。

[StarterKit](/editor/extensions/functionality/starterkit) 集成了所有基础扩展，你可以根据需要添加或移除其他扩展。

查看[扩展指南](/editor/extensions/overview)了解所有可用扩展，或[创建自己的扩展](/editor/extensions/custom-extensions)以支持自定义功能和 HTML 元素。

### Draft.js 常见功能的对应项

| Draft.js 功能 | Tiptap 扩展 | 说明 |
| ---------------------- | ------------------------- | ---------------------- |
| 粗体行内样式 | `Bold` | 已包含在 StarterKit 中 |
| 斜体行内样式 | `Italic` | 已包含在 StarterKit 中 |
| 下划线行内样式 | `Underline` | 已包含在 StarterKit 中 |
| 代码行内样式 | `Code` | 已包含在 StarterKit 中 |
| 链接实体 | `Link` | 已包含在 StarterKit 中 |
| 图片实体 | `Image` | 需单独安装 |
| 标题块 | `Heading` | 已包含在 StarterKit 中 |
| 引用块 | `Blockquote` | 已包含在 StarterKit 中 |
| 代码块 | `CodeBlock` | 已包含在 StarterKit 中 |
| 无序列表 | `BulletList`, `ListItem` | 已包含在 StarterKit 中 |
| 有序列表 | `OrderedList`, `ListItem` | 已包含在 StarterKit 中 |

### 配置扩展

```ts
import { useEditor } from '@tiptap/react'
import StarterKit from '@tiptap/starter-kit'
import Image from '@tiptap/extension-image'
import { Color } from '@tiptap/extension-color'
import TextStyle from '@tiptap/extension-text-style'
import Highlight from '@tiptap/extension-highlight'

const editor = useEditor({
  extensions: [
    StarterKit,
    Image.configure({
      inline: true,
      allowBase64: true,
    }),
    TextStyle,
    Color.configure({
      types: [TextStyle.name],
    }),
    Highlight.configure({
      multicolor: true,
    }),
  ],
})
```

## UI 实现

### 工具栏实现

基于 Draft.js RichUtils 的工具栏可以转换为 Tiptap UI 组件：

```tsx
// Draft.js toolbar (before)
import { RichUtils } from 'draft-js'

function DraftToolbar({ editorState, onChange }) {
  const toggleInlineStyle = (style) => {
    onChange(RichUtils.toggleInlineStyle(editorState, style))
  }

  const toggleBlockType = (blockType) => {
    onChange(RichUtils.toggleBlockType(editorState, blockType))
  }

  return (
    <div>
      <button onClick={() => toggleInlineStyle('BOLD')}>Bold</button>
      <button onClick={() => toggleInlineStyle('ITALIC')}>Italic</button>
      <button onClick={() => toggleBlockType('header-one')}>H1</button>
    </div>
  )
}

// Tiptap equivalent (React example)
function Toolbar({ editor }) {
  if (!editor) return null

  return (
    <div className="toolbar">
      <button
        onClick={() => editor.chain().focus().toggleBold().run()}
        className={editor.isActive('bold') ? 'active' : ''}
      >
        Bold
      </button>
      <button
        onClick={() => editor.chain().focus().toggleItalic().run()}
        className={editor.isActive('italic') ? 'active' : ''}
      >
        Italic
      </button>
      <button
        onClick={() => editor.chain().focus().toggleHeading({ level: 1 }).run()}
        className={editor.isActive('heading', { level: 1 }) ? 'active' : ''}
      >
        H1
      </button>
    </div>
  )
}
```

### 行内工具栏

创建一个类似于 Draft.js 行内样式工具栏的行内工具栏：

```tsx
import { BubbleMenu } from '@tiptap/react'

function MyEditor() {
  const editor = useEditor({
    extensions: [StarterKit],
  })

  return (
    <>
      <EditorContent editor={editor} />
      <BubbleMenu editor={editor}>
        <button
          onClick={() => editor.chain().focus().toggleBold().run()}
          className={editor.isActive('bold') ? 'active' : ''}
        >
          Bold
        </button>
        <button
          onClick={() => editor.chain().focus().toggleItalic().run()}
          className={editor.isActive('italic') ? 'active' : ''}
        >
          Italic
        </button>
        <button
          onClick={() => editor.chain().focus().toggleUnderline().run()}
          className={editor.isActive('underline') ? 'active' : ''}
        >
          Underline
        </button>
      </BubbleMenu>
    </>
  )
}
```

### 替换实体（节点视图）

Draft.js 实体可以替换为 Tiptap 的[节点视图](/editor/extensions/custom-extensions/node-views)：

```tsx
// Draft.js entity (before)
const LinkEntity = (props) => {
  const { url } = props.contentState.getEntity(props.entityKey).getData()
  return <a href={url}>{props.children}</a>
}

// Tiptap Node View (after)
import { Node } from '@tiptap/core'
import { ReactNodeViewRenderer } from '@tiptap/react'

const LinkComponent = ({ node }) => {
  return <a href={node.attrs.href}>{node.textContent}</a>
}

const CustomLink = Node.create({
  name: 'customLink',

  addNodeView() {
    return ReactNodeViewRenderer(LinkComponent)
  },
})
```
