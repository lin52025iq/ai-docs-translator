## 为文档添加初始内容

若要为文档添加初始内容（或创建空文档），可以使用我们的创建文档 API。

请注意，你需要将 `APP_ID` 和 `DOCUMENT_NAME` 替换为自己的值，并将 `YOUR_JWT` 替换为携带 `Documents:Api:All` 权限的签名令牌（参见[身份验证](/authentication)）。请将该令牌保存在服务器端，因为它授予完整的 API 访问权限。`APP_ID` 是你的文档服务器 ID，在 [Cloud 控制台](https://cloud.tiptap.dev/v2/configuration/document-server)中标记为“Document server ID”。
如果只想创建空文档，可以将空数组作为 `content` 发送。

请求负载应为 Tiptap JSON，可通过调用 `editor.getJSON()` 获取（参见[获取 JSON](/guides/output-json-html#option-1-json)）。

```curl
curl --location \
'https://APP_ID.collab.tiptap.cloud/api/documents/DOCUMENT_NAME?format=json' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer YOUR_JWT' \
--data '{
    "type": "doc",
    "content": [
      {
        "type": "paragraph",
        "attrs": {
          "indent": 0,
          "textAlign": "left"
        },
        "content": [
          {
            "text": "This is my initial content.",
            "type": "text"
          }
        ]
      }
    ]
}'
```

## 更新文档的全部内容

更新文档很简单：获取当前的 JSON 文档，对其进行修改，然后将其发送回我们即可。

使用以下请求获取当前的 JSON 文档。

```curl
curl --location \
'https://APP_ID.collab.tiptap.cloud/api/documents/DOCUMENT_NAME?format=json' \
--header 'Authorization: Bearer YOUR_JWT' \
```

现在，你可以修改 JSON，然后将其发送回我们。我们会计算新 JSON 与文档当前状态之间的差异，并以协作方式应用这些更改。
如果只想更新单个节点，请参阅[更新文档中的单个节点](#更新文档中的单个节点)。

```curl
curl --location --request PATCH \
'https://APP_ID.collab.tiptap.cloud/api/documents/DOCUMENT_NAME?format=json' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer YOUR_JWT' \
--data 'UPDATED_JSON'
```

## 更新文档中的单个节点

使用以下请求获取当前的 JSON 文档。

```curl
curl --location \
'https://APP_ID.collab.tiptap.cloud/api/documents/DOCUMENT_NAME?format=json' \
--header 'Authorization: Bearer YOUR_JWT'
```

现在，你可以找到要更新的节点，并在 JSON 中进行修改。然后，你需要以完整的 Tiptap JSON 格式，仅将更新后的节点发送回我们。
要指定要更新的节点，需要传递查询参数 `nodeAttributeName` 和 `nodeAttributeValue`。例如，如果你使用我们的 unique-id 扩展，且目标节点的 `id` 属性值为 `12345`，则需要传递 `nodeAttributeName=id&nodeAttributeValue=12345`。请注意，这仅适用于顶层节点。

```curl
curl --location --request PATCH \
'https://APP_ID.collab.tiptap.cloud/api/documents/DOCUMENT_NAME?format=json&nodeAttributeName=id&nodeAttributeValue=12345' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer YOUR_JWT' \
--data 'UPDATED_JSON'
```

下面是 `UPDATED_JSON` 的示例。只包含要更新的节点，并省略其他所有节点（即 `content` 数组中的其他节点）。

```json
{
    "type": "doc",
    "content": [
      {
        "type": "paragraph",
        "attrs": {
          "id": "12345"
        },
        "content": [
          {
            "text": "The API will update the node that matches the query filters (nodeAttributeName and nodeAttributeValue from the query) with the content of this node.",
            "type": "text"
          }
        ]
      }
    ]
}
```

## 删除文档中的节点

若要删除文档中的整个节点，可以发送如下请求。

请务必将 `ATTR_NAME` 和 `ATTR_VALUE` 替换为自己的值，例如 `id` 和 `12345`。

```curl
curl --location --request PATCH \
'https://APP_ID.collab.tiptap.cloud/api/documents/DOCUMENT_NAME?format=json&nodeAttributeName=ATTR_NAME&nodeAttributeValue=ATTR_VALUE&mode=delete' \
--header 'Authorization: Bearer YOUR_JWT'
```

## 更新文档中节点的属性

若要更新节点的属性，可以发送如下请求。
请注意，此操作会删除请求中未包含的所有属性。如果不希望如此，可以在 URL 中添加 `mergeAttributes=1`。

请务必将 `ATTR_NAME` 和 `ATTR_VALUE` 替换为自己的值，例如 `id` 和 `12345`。

```curl
curl --location --request PATCH \
'https://APP_ID.collab.tiptap.cloud/api/documents/DOCUMENT_NAME?format=json&nodeAttributeName=ATTR_NAME&nodeAttributeValue=ATTR_VALUE&mode=attrs' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer YOUR_JWT' \
--data '{
    "level": 3
}'
```
