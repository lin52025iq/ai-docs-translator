通过 REST API 配置文档服务器的运行时设置，直接管理您的环境。

这些设置可让您修改密钥、Webhook URL 等内容。尤其是在项目需求或安全协议发生变化时，无需重启应用即可进行调整。

## 设置概览

以下设置可动态调整：

| 键                            | 说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ------------------------------ |---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `secret`                       | [JWT 密钥](/collaboration/getting-started/authenticate)，首次启动时自动生成                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `api_secret`                   | 用于 Authorization 标头的 API 密钥，首次启动时自动生成                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `allowed_origins`              | 根据提供的值（以逗号分隔）验证 `Origin` 标头，例如 `https://test.tiptap.dev,https://*.tiptap.dev`；未设置时，不启用验证                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `authentication_disabled`      | 设为 `1` 可禁用身份验证，设为 `0` 可启用（默认值：`0`）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `webhook_url`                  | 用于接收 Webhook 回调的 URL                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `webhook_loader_url`           | 用于初始加载文档的可选 Webhook URL。详情请参阅 [Webhook](/collaboration/core-concepts/webhooks#loader-webhook)。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `webhook_version`              | Webhook 版本                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `webhook_awareness`            | 启用用于跟踪用户活动的 awareness Webhook，追踪 `user.connected` 和 `user.disconnected` 事件（`1` 表示启用，`0` 表示禁用）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `webhook_log_errors_only`      | 仅记录 Webhook 错误；不记录成功的 Webhook 日志                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `webhook_events`               | 要接收的 Webhook 触发事件允许列表，以逗号分隔，例如 `document.saved,content.changed`。未设置时，会发送除 `content.changed` 之外的所有事件；`*` 表示发送所有事件，`none` 表示不发送任何事件。请参阅 [Webhook](/collaboration/core-concepts/webhooks#choosing-which-events-you-receive)。 |
| `content_fields`               | 指定哪些 Yjs 字段会被视为 `content.changed` 事件以及 `changedFields` 负载键中的内容。未设置时，所有名称不以 `__tiptapcollab__` 开头的字段都会被视为内容。设置该值会替换此规则，而不是缩小其范围，因此设置为 `__tiptapcollab__threads` 会将评论活动计入内容变更。请参阅 [Webhook](/collaboration/core-concepts/webhooks#choosing-which-fields-count-as-content)。 |
| `default_auto_versioning`      | 设为 `1` 可启用自动版本控制，设为 `0` 可禁用（默认值：`0`）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `default_auto_versioning_interval` | 自动版本控制的间隔时间，单位为秒（默认值：`30` 秒）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `auto_versioning_all_fragments` | 设为 `1` 后，版本控制会监听文档中任意片段/字段的变更（默认值为 `0`，此时仅监视 `default` 片段）。此设置同时影响自动版本控制和手动版本控制；设为 `0` 时，手动版本控制需要 `force=true`。更改此设置后，必须由服务器重新加载文档才能生效。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `jwt_explicit_access` | 设为 `1` 后，如果 JWT 中未设置 `allowedDocumentNames`，则禁止访问文档。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `skip_s3_health_check` | 设为 `1` 可关闭 S3 健康检查（仅限本地部署）。如果您的 S3 存储不支持 `getCalledIdentity`，此设置会很有用。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `name`                         | 用于标识实例的名称                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `webhook_include_ydoc_state`   | 设为 `1` 后，在所有 `document.saved` Webhook 中包含完整的 Yjs 文档                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `thread_authenticator`   | 设为 `1` 可启用线程身份验证器。线程/评论会自动关联 JWT 中的用户 ID，并且无法编辑或删除其他用户的线程。不过，通常仍可解决其他用户的线程（除非通过下方设置禁用此功能）。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `user_mapping_authenticator`   | 设为 `1` 后，强制要求记录在编辑归属信息中的用户身份与已验证 JWT 的 `sub` 匹配。启用后，客户端只能为自己的 `sub` 注册用户映射；尝试映射、覆盖或删除其他用户的身份都会被拒绝。启用此设置时，**客户端必须将 `TiptapCollabProvider.user` 设为与其 JWT `sub` 相同的值**，否则连接会被拒绝。此设置可保护[版本元数据](/collaboration/documents/snapshot#automatic-version-metadata)中的 `changesBy` 字段以及任何其他使用用户映射的功能。需要启用 JWT 身份验证。 |
| `commentonly_disallow_resolve_foreign_threads`   | 设为 `1` 后，评论专用连接不能解决其他用户的线程。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `webhook_include_fields`   | 设为 `1` 后，在 Webhook 中包含自定义 Yjs 字段（请参阅 [Webhook](/collaboration/core-concepts/webhooks#custom-fields)）。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |

## 通过 API 管理设置

协作平台提供了简单易用的 API 来管理这些设置。将 `:key` 替换为要更新的设置键，将 `YOUR_APP_ID` 替换为文档服务器 ID（在 [Cloud 控制面板](https://cloud.tiptap.dev/v2/configuration/document-server)中标记为“Document server ID”）。

### 创建或覆盖设置

使用以下请求添加或更新设置：

```bash
curl --location --request PUT 'https://YOUR_APP_ID.collab.tiptap.cloud/api/admin/settings/:key' \
--header 'Authorization: YOUR_SECRET_FROM_SETTINGS_AREA' --header 'Content-Type: text/plain' \
-d 'your value'
```

此端点可互换使用 `PUT`、`PATCH` 和 `POST`。如果设置不存在，这三种方法都会创建该设置；如果设置已存在，则会覆盖其值。

### 列出当前设置

使用以下请求获取所有当前设置的列表：

```bash
curl --location 'https://YOUR_APP_ID.collab.tiptap.cloud/api/admin/settings' \
--header 'Authorization: YOUR_SECRET_FROM_SETTINGS_AREA'
```

### 获取特定设置

使用以下请求获取某个设置的值：

```bash
curl --location 'https://YOUR_APP_ID.collab.tiptap.cloud/api/admin/settings/:key' \
--header 'Authorization: YOUR_SECRET_FROM_SETTINGS_AREA'
```

### 删除设置

使用以下请求删除某个设置：

```bash
curl --location --request DELETE 'https://YOUR_APP_ID.collab.tiptap.cloud/api/admin/settings/:key' \
--header 'Authorization: YOUR_SECRET_FROM_SETTINGS_AREA'
```

## 服务器性能指标

使用 `/api/statistics` 端点收集服务器性能数据，包括文档总数、并发连接峰值、过去 30 天的连接总数以及累计连接数。
更多信息请参阅[指标](/collaboration/operations/metrics)页面。

```bash
curl --location 'https://YOUR_APP_ID.collab.tiptap.cloud/api/statistics' \
--header 'Authorization: YOUR_SECRET_FROM_SETTINGS_AREA'
```
