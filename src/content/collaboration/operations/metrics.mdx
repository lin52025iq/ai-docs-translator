Tiptap Collaboration API 提供多个端点，用于访问服务器和各个文档的实时统计数据及运行状况信息。云端控制台也提供简化版指标。

这些端点有助于排查问题、监控服务器性能，或构建分析仪表板，以了解用户交互情况和系统状态。将统计数据集成到监控系统中，可以主动管理协作环境的运行状况。

<Callout title="查看 Postman 集合" variant="hint">
  访问我们的 [Postman
  集合](https://www.postman.com/tiptap-platform/workspace/tiptap-workspace/request/33042171-1adccc70-772c-464a-8602-1303659f9af6)，试用 REST API。
</Callout>

## 访问 API

REST API 可通过自定义 URL 直接从文档服务器访问：

```bash
https://YOUR_APP_ID.collab.tiptap.cloud/
```

将 `YOUR_APP_ID` 替换为文档服务器 ID。该 ID 在[云端控制台](https://cloud.tiptap.dev/v2/configuration/document-server)中标记为“Document server ID”。

### 身份验证
在请求的 `Authorization` 标头中添加 API 密钥，以验证 API 请求。您可以在 Tiptap 云端控制台的[设置](https://cloud.tiptap.dev/v2/configuration/document-server)中找到 API 密钥。

### 文档标识符
如果文档标识符包含斜杠（`/`），请将其编码为 `%2F`，例如使用 `encodeURIComponent`。

## 服务器统计数据端点

此端点提供 Tiptap Collaboration 服务器的基本统计数据，帮助了解整体活动和使用情况指标。

```bash
GET /api/statistics
```

<Callout title="注意" variant="hint">
  最近 30 天的连接总数和生命周期内的连接总数以字符串形式呈现，因为它们在内部以 BigInt 值表示。
</Callout>

**示例：** 服务器统计数据
```json
{
  "totalDocuments": 4,
  "totalConnections30d": "3",
  "maxConcurrentConnections30d": 3,
  "lifetimeConnections": "144",
  "currentConnectionsCount": 3,
  "currentLoadedDocumentsCount": 1,
  "openDocuments": ["testdocument"],
  "connectionsPerDocument": {
    "testdocument": 3
  },
  "version": "3.33.0"
}
```

## 文档统计数据端点

根据文档标识符获取特定文档的统计数据。使用此端点监控文档的实时用户参与情况。

```bash
GET /api/documents/:identifier/statistics
```

**示例：** 名为 :identifier 的文档的统计数据

```json
{
  "currentConnections": 2,
  "connectedIps": ["127.0.0.1", "10.100.1.23"]
}
```

## 服务器运行状况端点

使用此调用检查服务器的存活状态、就绪状态，以及与数据库和 Redis 等关键组件的连接情况。

```bash
GET /health
```

**示例：** Redis 出现问题

```bash
HTTP 500:

DB:ok
REDIS:fail
```

**示例：** 未检测到 Redis
```bash
HTTP 200:

DB:ok
REDIS:inactive
```
