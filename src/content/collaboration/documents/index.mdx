Collaboration 文档是 Tiptap Collaboration 的基础，采用 Yjs 格式存储内容、评论、版本和元数据等所有信息。

通常，用户通过 REST API 管理这些文档，或使用 Collaboration Webhook 跟踪变更，接收详细更新。Tiptap 会将文档转换为 HTML 或 JSON，因此你无需直接处理 Yjs 格式。

- **托管文档：** 可选择云端、专属云或本地部署。
- **文档 REST API：** 以编程方式创建、更新和删除文档。
- **Webhook：** 自动响应实时文档和评论事件。
- **文档版本管理与比较：** 通过自动或手动版本管理跟踪文档变更，并直观比较不同快照之间的差异。
- **内容注入：** 使用 REST API 在服务器端修改文档内容，即使协作会话正在进行也可以操作。

## 集成文档

使用 Tiptap 将文档集成到编辑器和应用程序中非常简单。只需在设置中添加 Tiptap Collaboration Provider，文档便会自动存储并由 Tiptap Collaboration 管理。

集成后，你便可立即使用所有文档功能，例如存储协作文档、管理版本历史记录、使用 REST API 和注入内容。

<Callout title="注意" variant="hint">
  之后，你可以轻松地将文档从我们的云端迁移到本地服务器。
</Callout>

1. **集成 Tiptap Editor：** 按照[安装指南](/collaboration/getting-started/install)设置编辑器。
2. **启用套餐：** 开始[免费试用或选择订阅套餐](https://cloud.tiptap.dev/v2/billing)。
3. **添加环境。** 在[控制面板](https://cloud.tiptap.dev/)中，点击“添加环境”按钮，输入名称，并选择距离用户最近的区域。
4. **检查配置。** 保存环境后，文档服务器便会启动。前往[配置页面](https://cloud.tiptap.dev/v2/configuration/document-server)，复制文档服务器 ID、API 密钥和其他连接信息。

现在，你已准备好使用文档功能。

## 获取和管理文档

使用 [REST API](/collaboration/documents/rest-api) 以 `JSON` 或 `HTML` 格式获取文档，轻松将其集成到你的系统中。若要及时了解变更，请配置 [Webhook](/collaboration/core-concepts/webhooks) 来接收实时通知。

**跟踪文档变更：** Tiptap Collaboration 中的 [Snapshot](/collaboration/documents/snapshot) 扩展会按指定间隔自动捕获并存储文档快照。它也支持手动创建版本，方便用户详细跟踪变更和文档演进过程。

**比较快照：** [比较快照](/collaboration/documents/snapshot-compare)扩展可直观比较文档的两个版本，突出显示变更及其作者，帮助你了解文档随时间发生的修改。

**注入内容：** 使用 [Patch Document 端点](/collaboration/documents/content-injection)更新活动文档的内容，即使用户正在协作，也可以在服务器端进行修改。
