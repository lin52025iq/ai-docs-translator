Snapshot Compare 可并排显示两个文档版本，并突出显示所有更改。你可以用它跟踪编辑、审阅贡献并恢复到早期状态。

## 访问私有 registry

Snapshot Compare 扩展发布在 Tiptap 私有 npm registry 中。请按照[私有 registry 指南](/guides/pro-extensions)集成此扩展。如果你已经验证过 Tiptap 账户，可直接前往 [#安装](#install)。

## 安装

从我们的私有 registry 安装此扩展：

```bash
npm install @tiptap-pro/extension-snapshot-compare
```

## 设置

你可以使用以下选项配置 `SnapshotCompare` 扩展：

| 设置                 | 类型                   | 默认值     | 说明                                           |
| -------------------- | ---------------------- | ---------- | ---------------------------------------------- |
| provider             | `TiptapCollabProvider` | `null`     | Collaboration provider 实例                    |
| mapDiffToDecorations | `function`             | `() => {}` | 控制如何将差异映射为用于显示其内容的 decoration |

请注意，你需要向 `TiptapCollabProvider` 提供 `user` 标识符，因为此信息用于优化差异计算。

```js
const provider = new TiptapCollabProvider({
  // ...
  user: 'your user identifier' // 必填！请注意，我们会使用用户标识符优化差异计算，因此务必提供。
})

const editor = new Editor({
  // ...
  extensions: [
    // ...
    SnapshotCompare.configure({
      provider,
    }),
  ],
})
```

#### 使用 `mapDiffToDecorations` 设置差异 decoration

此扩展提供默认映射（`defaultMapDiffToDecorations`），用于将差异表示为 ProseMirror decorations。
若要进行更复杂的集成并获得更多控制权，可以通过 `mapDiffToDecorations` 选项自定义此映射。

**示例：** 为行内插入内容应用自定义预设背景色

```ts
SnapshotCompare.configure({
  mapDiffToDecorations: ({ diff, tr, editor, defaultMapDiffToDecorations }) => {
    if (diff.type === 'inline-insert') {
      // 返回 ProseMirror decoration（一个或多个）或 null
      return Decoration.inline(
        diff.from,
        diff.to,
        {
          class: 'diff',
          style: {
            backgroundColor: diff.attribution.color.backgroundColor,
          },
        },
        // 将 diff 作为 decoration 的 spec 传入，这是 `extractAttributeChanges` 所必需的
        { diff },
      )
    }

    // 回退到默认映射
    return defaultMapDiffToDecorations({
      diff,
      tr,
      editor,
      attributes: {
        // 为 decorations 添加自定义属性
        'data-tiptap-user-id': myUserIdMapping[diff.attribution.userId],
      },
    })
  },
})
```

## 存储

`SnapshotCompare` 存储对象包含以下属性：

| 键              | 类型                  | 说明                         |
| --------------- | --------------------- | ---------------------------- |
| isPreviewing    | `boolean`             | 指示差异视图是否处于活动状态 |
| diffs           | `Diff[]`              | 差异视图中显示的差异         |
| previousContent | `JSONContent \| null` | 应用差异视图之前的内容       |

使用 `isPreviewing` 属性检查差异视图当前是否处于活动状态：

```ts
if (editor.storage.snapshotCompare.isPreviewing) {
  // 差异视图当前处于活动状态
}
```

使用 `diffs` 属性访问差异视图中显示的差异：

```ts
editor.storage.snapshotCompare.diffs
```

扩展内部使用 `previousContent` 属性，在退出差异视图时恢复内容。通常，你无需直接操作此属性。

## 命令

| 命令              | 说明                                    |
| ----------------- | --------------------------------------- |
| `compareVersions` | 比较两个版本，并在编辑器中呈现差异      |
| `showDiff`        | 根据变更跟踪转换，在编辑器中显示差异    |
| `hideDiff`        | 隐藏差异并恢复先前的内容                |

### compareVersions

使用 `compareVersions` 命令计算并显示两个文档版本之间的差异。

```ts
editor.chain().compareVersions({
  fromVersion: 1,
})
```

#### 选项

你可以传入其他选项，以便更好地控制差异计算过程：

| 键                | 说明                                                       |
| ----------------- | ---------------------------------------------------------- |
| `fromVersion`     | 比较起始版本。`fromVersion` 和 `toVersion` 的顺序可灵活设置 |
| `toVersion`       | 比较目标版本（默认：最新版本）                             |
| `hydrateUserData` | 为每位用户的更改添加上下文数据                             |
| `onCompare`       | 手动处理差异计算结果                                       |
| `enableDebugging` | 启用详细日志以便排查问题                                   |

#### 使用 `hydrateUserData` 添加元数据

每个差异都有一个 `attribution` 字段，你可以通过 `hydrateUserData` 回调函数添加其他元数据。

<Callout title="注意" variant="info">
  请注意，`userId` 由 `TiptapCollabProvider` 填充，应当用于识别进行更改的用户。如果 provider 未提供 `user` 字段，`userId` 将为 `null`。[有关详细信息，请参阅 TiptapCollabProvider 文档](/collaboration/provider/integration)。
</Callout>

**示例：** 根据用户为差异添加颜色标记

```ts
const colorMapping = new Map([
  ['user-1', '#ff0000'],
  ['user-2', '#00ff00'],
  ['user-3', '#0000ff'],
])

editor.chain().compareVersions({
  fromVersion: 1,
  toVersion: 3,
  hydrateUserData: ({ userId }) => {
    return {
      color: {
        backgroundColor: colorMapping.get(userId),
      },
    }
  },
})

editor.storage.snapshotCompare.diffs[0].attribution.color.backgroundColor // '#ff0000'
```

#### 使用 `onCompare` 自定义差异计算过程

如果需要更好地控制差异计算过程，可以使用 `onCompare` 选项接收结果并自行处理。

**示例：** 按用户筛选差异

```ts
editor.chain().compareVersions({
  fromVersion: 1,
  toVersion: 3,
  onCompare: (ctx) => {
    if (ctx.error) {
      // 处理差异计算过程中发生的错误
      console.error(ctx.error)
      return
    }

    // 筛选差异，只显示特定用户所做的更改
    const diffsToDisplay = ctx.diffSet.filter((diff) => diff.attribution.userId === 'user-1')

    editor.commands.showDiff(ctx.tr, { diffs: diffsToDisplay })
  },
})
```

### showDiff

使用 `showDiff` 命令和变更跟踪转换（`tr`）在编辑器中显示差异。此转换表示自上一个快照以来对文档所做的所有更改。你可以使用此转换在编辑器中显示差异。

通常，在使用 `compareVersions` 的 `onCompare` 自定义或筛选差异后，会使用此命令。

`showDiff` 命令会暂时将当前编辑器内容替换为差异视图，显示两个版本之间的差异。它还会暂存编辑器当前显示的内容，以便之后恢复。

```ts
// 在编辑器中显示变更跟踪转换记录的更改
editor.commands.showDiff(tr)
```

### 选项

你可以传入其他选项来控制差异的显示方式：

| 键    | 说明               |
| ----- | ------------------ |
| diffs | 要可视化的差异数组 |

**示例：** 显示指定差异

```ts
// 仅显示 ID 为 'user-1' 的用户所做的差异
const diffsToDisplay = tr.toDiff().filter((diff) => diff.attribution.userId === 'user-1')

editor.commands.showDiff(tr, { diffs: diffsToDisplay })
```

### hideDiff

使用 `hideDiff` 命令隐藏差异并恢复先前的内容。

```ts
// 隐藏差异视图并恢复先前的内容
editor.commands.hideDiff()
```

## 添加样式

Snapshot Compare 扩展会为差异视图中的元素应用类，以便你为插入和删除的文本设置样式。请参阅本页顶部的[代码示例](#page-title)，了解如何为差异视图设置样式的完整示例。

### 基本差异样式

此扩展会为差异元素应用以下属性：

- `data-diff-type="inline-insert"` - 用于插入的文本
- `data-diff-type="inline-delete"` - 用于删除的文本
- `data-diff-type="inline-update"` - 用于更新的文本
- `data-diff-type="block-insert"` - 用于插入的块
- `data-diff-type="block-delete"` - 用于删除的块

你可以使用 CSS 选择器，根据这些 data 属性选中相应元素。

以下是为插入和删除文本设置基本样式的示例：

```css
/* 未涉及用户时，默认使用红色和绿色 */
/* 设置插入文本的样式 */
[data-diff-type='inline-insert'],
[data-diff-type='inline-update'],
[data-diff-type='block-insert'] {
  background-color: green;
}

/* 设置删除文本的样式 */
[data-diff-type='inline-delete'],
[data-diff-type='block-delete'] {
  background-color: red;
  text-decoration: line-through;
}
```

### 重置删除文本的标记样式

应用样式标记（例如 **粗体**、_斜体_ 或 `code`）时，删除的文本（即应用格式之前的文本）也可能带有该格式。这是因为删除的文本位于格式对应的 HTML 标签内。为避免这种情况，请重置已删除内容内部的标记样式。

首先，重置已删除内容外层标记的样式。

```scss
/* 重置已删除内容的 strong/粗体格式 */
strong {
  [data-diff-type='inline-delete'],
  [data-diff-type='block-delete'] {
    font-weight: normal;
  }
}

/* 重置已删除内容的斜体格式 */
em {
  [data-diff-type='inline-delete'],
  [data-diff-type='block-delete'] {
    font-style: normal;
  }
}

/* 重置已删除内容的代码格式 */
code {
  [data-diff-type='inline-delete'],
  [data-diff-type='block-delete'] {
    font-family: sans-serif;
  }
}
```

接下来，如果已删除内容内部包含标记标签，则重新为其应用标记样式。这样可以确保已删除内容的格式正确。

```scss
/* 确保标记样式在已删除内容内部正确生效 */
[data-diff-type='inline-delete'],
[data-diff-type='block-delete'] {
  strong {
    font-weight: bold;
  }
  em {
    font-style: italic;
  }
  code {
    font-family: monospace;
  }
}
```

### 用户归属样式

如果有用户归属信息，你可以根据进行更改的用户为差异设置样式：

```css
/* 为带有用户归属信息的差异设置样式 */
[data-diff-user-id] {
  position: relative;
}

/* 显示用户名的工具提示 */
[data-diff-user-id]::before {
  content: attr(data-diff-user-id);
  position: absolute;
  visibility: hidden;
}

[data-diff-user-id]:hover::before {
  visibility: visible;
}
```

## 使用 NodeView（高级）

使用[自定义节点视图](/editor/extensions/custom-extensions/node-views)时，默认的差异映射可能无法按预期工作。你可以自定义映射，并直接在自定义节点视图中呈现差异。

使用 `extractAttributeChanges` 辅助函数提取节点属性更改。这样你就可以访问节点更改前后的属性，从而在自定义节点视图中突出显示属性变化。

<Callout title="注意" variant="info">
  如果你自行将差异映射到 decorations，需要将 `diff` 作为 decoration 的 `spec` 传入。这是 `extractAttributeChanges` 正常工作的必要条件。
</Callout>

**示例：** 自定义标题节点视图以显示更改

```ts
import { extractAttributeChanges } from '@tiptap-pro/extension-snapshot-compare'

const Heading = BaseHeading.extend({
  addNodeView() {
    return ReactNodeViewRenderer(({ node, decorations }) => {
      const { before, after, isDiffing } = extractAttributeChanges(decorations)

      return (
        <NodeViewWrapper style={{ position: 'relative' }}>
          {isDiffing && before.level !== after.level && (
            <span
              style={{
                position: 'absolute',
                right: '100%',
                fontSize: '14px',
                color: '#999',
                backgroundColor: '#f0f0f070',
              }}
              // 显示 level 属性的差异
            >
              #<s>{before.level}</s>
              {after.level}
            </span>
          )}
          <NodeViewContent as={`h${node.attrs.level ?? 1}`} />
        </NodeViewWrapper>
      )
    })
  },
})
```

## 技术细节

### Diff

`Diff` 是表示文档更改的对象，包含以下属性：

| 属性                  | 类型                                                                                                                    | 说明                                                                                       |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| `type`                | `'inline-insert'` \| `'inline-delete'` \| `'block-insert'` \| `'block-delete'` \| `'inline-update'` \| `'block-update'` | 所做更改的类型                                                                             |
| `from`                | `number`                                                                                                                | 更改的起始位置                                                                             |
| `to`                  | `number`                                                                                                                | 更改的结束位置                                                                             |
| `content`             | `Fragment`                                                                                                              | 已添加或删除的内容                                                                         |
| `attribution`         | `Attribution`                                                                                                           | 更改的元数据，例如进行更改的用户                                                           |
| `attributes?`         | `Record<string, any>`                                                                                                   | 更改**之后**的属性；仅适用于 `'inline-update'` 和 `'block-update'` 差异                     |
| `previousAttributes?` | `Record<string, any>`                                                                                                   | 更改**之前**的属性；仅适用于 `'inline-update'` 和 `'block-update'` 差异                     |

### DiffSet

`DiffSet` 是一个 `Diff` 对象数组，其中每个对象对应一项具体更改，例如插入、删除或更新。你可以遍历数组检查单项更改，或根据差异类型应用自定义逻辑。

```ts
const diffsToDisplay = diffSet.filter((diff) => diff.attribution.userId === 'user-1')

// 在编辑器中显示筛选后的差异
editor.commands.showDiff(tr, { diffs: diffsToDisplay })
```

### Attribution

`Attribution` 对象包含更改的元数据，包括以下属性：

| 属性     | 类型                      | 说明                       |
| -------- | ------------------------- | -------------------------- |
| `type`   | `'added'` \| `'removed'`  | 指示所做更改的类型         |
| `userId` | `string` \| `undefined`   | 进行更改的用户 ID          |
| `id`     | `Y.ID` \| `undefined`     | 进行更改的用户的 Y.js 客户端 ID |

你可以扩展 `Attribution` 接口以添加其他属性：

```ts
declare module '@tiptap-pro/extension-snapshot-compare' {
  interface Attribution {
    userName: string
  }
}
```

### ChangeTrackingTransform

`ChangeTrackingTransform` 是一个用于记录文档更改的类（基于 ProseMirror 的 `Transform`）。
它表示一个转换，其步骤描述了文档从一个版本变为另一个版本时发生的所有更改。它包含以下属性：

| 属性     | 类型                   | 说明                       |
| -------- | ---------------------- | -------------------------- |
| `steps`  | `ChangeTrackingStep[]` | 表示文档更改的一组步骤     |
| `doc`    | `Node`                 | 应用更改**之后**的文档     |
| `before` | `Node`                 | 应用更改**之前**的文档     |

### ChangeTrackingStep

`ChangeTrackingStep` 是一个表示单项文档更改的类，基于 ProseMirror 的 `ReplaceStep` 类。它包含以下属性：

| 属性          | 类型          | 说明                           |
| ------------- | ------------- | ------------------------------ |
| `attribution` | `Attribution` | 更改的元数据，例如进行更改的用户 |

### 类型

以下是 `SnapshotCompare` 扩展的完整 TypeScript 定义：

```ts
declare module '@tiptap/core' {
  interface Commands<ReturnType> {
    snapshotCompare: {
      /**
       * 根据变更跟踪转换，在编辑器中显示差异
       */
      showDiff: (tr: ChangeTrackingTransform, options?: { diffs?: DiffSet }) => ReturnType
      /**
       * 隐藏差异并恢复先前的内容
       */
      hideDiff: () => ReturnType
      /**
       * 比较两个版本，并在编辑器中呈现差异
       */
      compareVersions: <
        T extends Pick<Attribution, 'color'> & Record<string, any> = Pick<Attribution, 'color'> &
          Record<string, any>,
      >(options: {
        /**
         * 差异比较的起始版本
         */
        fromVersion: number
        /**
         * 差异比较的目标版本
         * 如果未提供，则使用最新快照
         */
        toVersion?: number
        /**
         * 为每位用户的更改添加上下文数据
         */
        hydrateUserData?: (context: {
          /**
           * 事件类型
           */
          type: 'added' | 'removed'
          /**
           * 操作此内容的用户 ID
           */
          userId: string | undefined
          /**
           * 内容的 yjs 标识符
           */
          id?: y.ID
        }) => T
        /**
         * 如果提供，则可自定义将差异呈现到编辑器中的行为。
         * @note 默认行为是立即显示差异。
         */
        onCompare?: (
          context:
            | {
                error?: undefined
                /**
                 * 编辑器实例
                 */
                editor: Editor
                /**
                 * 包含归属元数据的所有更改转换
                 */
                tr: ChangeTrackingTransform<Attribution & T>
                /**
                 * 以差异数组表示的更改
                 */
                diffSet: DiffSet<Attribution & T>
              }
            | {
                error: Error
              },
        ) => void
        /**
         * 详细记录差异计算过程，帮助定位问题
         */
        enableDebugging?: boolean
      }) => ReturnType
    }
  }
}

export type SnapshotCompareOptions = {
  /**
   * Tiptap provider 实例。扩展需要它来计算差异，但显示差异时不需要。
   * 也可以传入 TiptapCollabProvider 实例。
   */
  provider: TiptapCollabProvider | null
  /**
   * 用于控制如何将差异映射为 decoration，以显示该差异的内容
   */
  mapDiffToDecorations?: (options: {
    /**
     * 要映射为 decoration 的差异
     */
    diff: Diff
    /**
     * 编辑器实例
     */
    editor: Editor
    /**
     * 变更跟踪转换
     */
    tr: ChangeTrackingTransform
    /**
     * 将差异映射为 decoration 的默认实现
     */
    defaultMapDiffToDecorations: typeof defaultMapDiffToDecorations
  }) => ReturnType<typeof defaultMapDiffToDecorations>
}

export type SnapshotCompareStorageInactive = {
  /**
   * 差异视图当前是否处于活动状态
   */
  isPreviewing: false
  /**
   * 应用差异视图之前的内容
   */
  previousContent: null
  /**
   * 已应用的变更跟踪转换
   * 当前为空，因为差异视图未处于活动状态
   */
  diffs: DiffSet
  /**
   * 已应用的变更跟踪转换
   */
  tr: null
}

export type SnapshotCompareStorageActive = {
  /**
   * 差异视图当前是否处于活动状态
   */
  isPreviewing: true
  /**
   * 应用差异视图之前的内容
   */
  previousContent: JSONContent
  /**
   * 已应用的变更跟踪转换
   */
  diffs: DiffSet
  /**
   * 已应用的变更跟踪转换
   */
  tr: ChangeTrackingTransform
}

export type SnapshotCompareStorage = SnapshotCompareStorageInactive | SnapshotCompareStorageActive
```
