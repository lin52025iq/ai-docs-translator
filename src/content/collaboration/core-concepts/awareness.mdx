由 Yjs 提供支持的 Tiptap Collaboration 中的 Awareness，可帮助你实时共享协作空间内用户的活动信息，包括用户在线状态、光标位置和自定义用户状态等。

Awareness 的核心是使用自己的无冲突复制数据类型（CRDT），确保所有用户共享的元信息保持一致并即时同步，同时不保留这些状态的历史记录。

你可以在 [Yjs 的 Awareness 文档](https://docs.yjs.dev/getting-started/adding-awareness)中了解更多信息。

## 必要的 Provider 事件

Awareness 更新会触发特定的 [Provider 事件](/collaboration/provider/events)，以便根据用户操作和在线状态构建交互功能：

- `awarenessUpdate`：此事件表示用户处于活跃状态。即使状态没有实际变化，也会触发此事件，作为“心跳”告知其他人该用户仍在文档中。
- `awarenessChange`：当 Awareness 状态新增、更新或删除时，此事件会发出通知，涵盖本地更改和远程用户的更改。

这些事件可用作集成自定义 Awareness 功能的钩子。

## 集成 Awareness

设置好[协作环境](/collaboration/getting-started/install)后，即可集成 Awareness。Collaboration Provider 原生支持 Awareness。

首先，使用相关信息更新 Awareness 状态。下面以用户姓名、光标颜色和鼠标位置为例。

### 设置 Awareness 字段

为用户设置姓名、颜色和鼠标位置。以下仅为示例，你可以使用任何与应用相关的数据。

```typescript
// 设置当前用户的 Awareness 字段
provider.setAwarenessField('user', {
  // 分享任意信息
  name: 'Kevin James',
  color: '#ffcc00',
})
```

### 监听更改

设置事件监听器，以跟踪所有已连接用户的 Awareness 状态变化：

```typescript
// 监听所有用户状态的更新
provider.on('awarenessChange', ({ states }) => {
  console.log(states)
})
```

接下来，你就可以在浏览器控制台中查看这些更新。

### 跟踪鼠标移动

接下来，我们会在应用中添加事件监听器来跟踪鼠标移动，并相应地更新 Awareness 信息。

```typescript
document.addEventListener('mousemove', (event) => {
  // 分享任意信息
  provider.setAwarenessField('user', {
    name: 'Kevin James',
    color: '#ffcc00',
    mouseX: event.clientX,
    mouseY: event.clientY,
  })
})
```

用户移动鼠标时，你可以在浏览器控制台中查看连续触发的事件。

## 添加光标和选区

完成基本的 Awareness 设置后，可以考虑在编辑器中添加 [Collaboration Caret](/editor/extensions/functionality/collaboration-caret) 扩展。此扩展会在编辑器中显示所有参与用户的光标位置、文本选区和个性化信息（例如姓名和颜色）。
