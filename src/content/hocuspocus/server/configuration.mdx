## 简介

目前只需传入少量设置。大多数功能都通过 [hooks](/hocuspocus/server/hooks) 控制。

## 设置

| 设置            | 描述                                                                                                                          | 默认值   |
|--------------------|--------------------------------------------------------------------------------------------------------------------------------------|-----------------|
| `name`             | 实例名称，用于日志记录。                                                                                           |                 |
| `port`             | 服务器监听的端口。                                                                                                | `80`            |
| `address`          | 服务器绑定的主机/接口，例如 `127.0.0.1`。如果未设置，服务器会监听所有接口。                    |                 |
| `timeout`          | 连接健康检查间隔，单位为毫秒。v4 中从 30 秒增加到 60 秒。                                                  | `60000 (= 60s)` |
| `debounce`         | 在指定时间内（毫秒）对 `onStoreDocument` hook 的调用进行防抖处理。否则，每次更新都会被持久化。 | `2000 (= 2s)`   |
| `maxDebounce`      | 确保至少每隔指定时间（毫秒）调用一次 `onStoreDocument`。                                                        | `10000 (= 10s)` |
| `quiet`            | 默认情况下，服务器会显示启动界面。设为 `false` 时，服务器将静默启动。                                         | `false`         |
| `websocketOptions` | 传递给底层 WebSocket 服务器的选项（例如 `{ maxPayload: 1024 * 1024 }`）。v4 中移入了配置对象。     | `{}`            |
| `maxUnauthenticatedQueueSize`     | 单个连接尚未通过身份验证时，所有文档合计可缓冲的最大字节数。超出后将关闭连接。请参阅[身份验证前的资源限制](#pre-authentication-resource-limits)。 | `5242880 (= 5 MiB)` |
| `maxUnauthenticatedQueueMessages` | 单个连接尚未通过身份验证时，所有文档合计可缓冲的最大消息数。超出后将关闭连接。                                                                            | `1000`              |
| `maxPendingDocuments`             | 单个连接在任何文档通过身份验证之前可以打开的不同文档的最大数量。超出后将关闭连接。                                                                                          | `100`               |

## 用法

```js
import { Server } from '@hocuspocus/server'

const server = new Server({
  name: 'hocuspocus-fra1-01',
  port: 1234,
  timeout: 60000,
  debounce: 5000,
  maxDebounce: 30000,
  quiet: true,
  websocketOptions: { maxPayload: 1024 * 1024 },
})

server.listen()
```

## 泛型 Context 类型

从 v4 开始，服务器支持泛型 `Context` 类型参数，可在所有 hooks 中实现端到端类型安全：

```ts
import { Server } from '@hocuspocus/server'

interface MyContext {
  userId: string
  permissions: string[]
}

const server = new Server<MyContext>({
  async onAuthenticate({ token }) {
    // Return value is typed as MyContext
    return { userId: '123', permissions: ['read', 'write'] }
  },
  async onChange({ context }) {
    // context.userId is typed as string
    console.log(context.userId)
  },
})
```

泛型默认值为 `any`，因此不显式指定类型的现有代码仍可正常工作。

## 身份验证前的资源限制

身份验证完成前收到的消息会按连接缓存在内存中。如果不加限制，未经身份验证的客户端可能会耗尽服务器内存（参见 [GHSA-xwhh-v746-pj9m](https://github.com/ueberdosis/hocuspocus/security/advisories/GHSA-xwhh-v746-pj9m)）。以下三个设置用于限制缓冲量，任一限制超出时都会立即关闭连接：

- `maxUnauthenticatedQueueSize`（默认值为 5 MiB）——每个连接缓冲的总字节数。
- `maxUnauthenticatedQueueMessages`（默认值为 1000）——每个连接缓冲的总消息数。
- `maxPendingDocuments`（默认值为 100）——单个连接一次可以打开的、尚未通过身份验证的不同文档数。每个待处理文档都有自己的队列和 hook 负载，因此，即使客户端将数据分散到许多文档名称上，也无法绕过每个连接的队列限制。

此外，在连接首次完成某个文档的身份验证之前，空闲 `timeout` 会作为*绝对*的身份验证前期限执行（从建立连接时开始计时，不会因收到入站流量而重置）。首次成功完成身份验证后，在该 WebSocket 连接的剩余生命周期内，`timeout` 将恢复为常规的空闲超时行为。

```js
import { Server } from '@hocuspocus/server'

const server = new Server({
  maxUnauthenticatedQueueSize: 5 * 1024 * 1024, // 5 MiB
  maxUnauthenticatedQueueMessages: 1000,
  maxPendingDocuments: 100,
})

server.listen()
```
