## 用法

使用 Hocuspocus 有两种方式：使用内置服务器，或使用其他框架，例如 [Express](/hocuspocus/server/examples#express)。

从 v4 开始，Hocuspocus 支持多种运行时：Node.js（使用 `ws` 或 `uWebSockets.js`）、Bun、Deno 和 Cloudflare Workers。内置的 `Server` 类在 Node.js 中的用法与之前相同；在其他运行时中，请直接使用 `Hocuspocus`，并将任意 `WebSocketLike` 实例传递给 `handleConnection()`。需要 Node.js 22 或更高版本。

### Hocuspocus Server

使用内置服务器时，请确保从 `@hocuspocus/server` 导入 `Server`。按照[配置](/hocuspocus/server/configuration)中的说明配置服务器。内置服务器会启动 Web 服务器和 WebSocket 服务器。

```js
import { Server } from "@hocuspocus/server";

const server = new Server({
  port: 1234,
});

server.listen();
```

你可以通过 Web 服务器访问 Hocuspocus 实例并调用它的[方法](/hocuspocus/server/usage#methods)。

```js
// …

server.hocuspocus.getDocumentsCount();
```

#### 停止服务器

调用 `server.destroy()` 可正常关闭服务器，例如在 `SIGINT` / `SIGTERM` 处理程序中、测试期间，或在开发过程中进行热重载时。

```js
server.destroy();
```

### Hocuspocus

如前所述，你可以不使用内置服务器，直接使用 Hocuspocus。请确保从 `@hocuspocus/server` 包导入 `Hocuspocus`。

```js
import { Hocuspocus } from "@hocuspocus/server";

// Configure hocuspocus
const hocuspocus = new Hocuspocus({
  name: "hocuspocus-fra1-01",
})

// …
```

请参阅[示例](/hocuspocus/server/examples)了解更多信息。


## 方法

### Server

| 方法                      | 说明                   |
|--------------------------|------------------------|
| `listen(port, callback)` | 启动服务器。           |
| `destroy()`              | 停止服务器。           |

### Hocuspocus

| 方法                                            | 说明                           |
|-------------------------------------------------|--------------------------------|
| `configure(configuration)`                     | 传入自定义设置。               |
| `handleConnection(incoming, request, context)` | 将服务器绑定到现有服务器实例。 |
| `getDocumentsCount()`                          | 获取活动文档的总数             |
| `getConnectionsCount()`                        | 获取活动连接的总数             |
| `closeConnections(documentName?)`              | 关闭所有连接，或关闭特定文档的连接。 |
| `openDirectConnection(documentName, context)`  | 创建与文档的本地连接。         |
