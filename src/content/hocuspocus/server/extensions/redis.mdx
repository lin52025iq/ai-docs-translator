使用 Redis 扩展可以对 Hocuspocus 进行水平扩展。你可以在负载均衡器后启动多个服务器实例，并通过 Redis 同步更改和 Awareness 状态。Hocuspocus 会通过 Redis 将收到的所有更新传播到其他实例，从而将更新转发给所有 Hocuspocus 实例上的所有客户端。

Redis 扩展不会持久化数据；它只在实例之间同步数据。要存储文档，请使用 [Database](/hocuspocus/server/extensions/database) 扩展。

请注意，所有 Hocuspocus 实例都会处理所有消息。因此，如果你想通过启动多个服务器来降低 CPU 负载，就不应该通过 Redis 将它们连接起来。

感谢 [@tommoor](https://github.com/tommoor) 编写了该扩展的初始实现。

## 安装

使用以下命令安装 Redis 扩展：

```bash
npm install @hocuspocus/extension-redis
```

## 配置

有关 Redis 和 Redis 集群所有可用选项的完整文档，请参阅
[ioredis API 文档](https://github.com/luin/ioredis/blob/master/API.md)。

```js
import { Server } from "@hocuspocus/server";
import { Redis } from "@hocuspocus/extension-redis";

const server = new Server({
  extensions: [
    new Redis({
      // [required] Hostname of your Redis instance
      host: "127.0.0.1",

      // [required] Port of your Redis instance
      port: 6379,

      // [optional] Maximum time in milliseconds to wait for the current state
      // from another instance when loading a document. Defaults to 1000.
      awaitInitialSyncTimeout: 1000,
    }),
  ],
});

server.listen();
```

### 加载时保持状态一致

当某个实例加载的文档已在另一个实例上打开时，Redis 扩展会等待该实例发送当前状态。这样可以确保新连接的客户端和直接连接能够收到尚未持久化的更改。如果没有其他实例打开该文档，加载过程不会延迟。

`awaitInitialSyncTimeout` 选项用于限制扩展等待的最长时间，单位为毫秒。默认值为 `1000`。将其设为 `0` 可禁用等待，改为使用发送后即不再等待的同步方式。

## 用法

Redis 扩展与数据库扩展配合使用效果良好。某个实例存储文档后，该文档会对其他所有实例锁定，以避免写入冲突。

```js
import { Server } from "@hocuspocus/server";
import { Logger } from "@hocuspocus/extension-logger";
import { Redis } from "@hocuspocus/extension-redis";
import { SQLite } from "@hocuspocus/extension-sqlite";

// Server 1
const server = new Server({
  name: "server-1", // make sure to use unique server names
  port: 1234,
  extensions: [
    new Logger(),
    new Redis({
      host: "127.0.0.1", // make sure to use the same Redis instance :-)
      port: 6379,
    }),
    new SQLite(),
  ],
});

server.listen();

// Server 2
const anotherServer = new Server({
  name: "server-2",
  port: 1235,
  extensions: [
    new Logger(),
    new Redis({
      host: "127.0.0.1",
      port: 6379,
    }),
    new SQLite(),
  ],
});

anotherServer.listen();
```
