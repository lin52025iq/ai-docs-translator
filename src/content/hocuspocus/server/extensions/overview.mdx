## 目录

我们已经创建了一些非常实用的扩展，强烈建议你了解一下：

| 扩展 | 描述 |
|------|------|
| [Database](/hocuspocus/server/extensions/database) | 通用数据库驱动，可轻松调整以适配任何数据库。 |
| [Logger](/hocuspocus/server/extensions/logger) | 为 Hocuspocus 添加日志记录功能。 |
| [Redis](/hocuspocus/server/extensions/redis) | 使用 Redis 实现 Hocuspocus 的水平扩展。 |
| [SQLite](/hocuspocus/server/extensions/sqlite) | 将文档持久化到 SQLite。 |
| [Throttle](/hocuspocus/server/extensions/throttle) | 按 IP 限制连接频率。 |
| [Webhook](/hocuspocus/server/extensions/webhook) | 通过 webhook 将文档变更发送到你的 API。 |
| [S3](/hocuspocus/server/extensions/s3) | 将文档持久化到 Amazon S3 或任何兼容 S3 的存储服务。 |
