## 简介

为了提供一流的开发者体验和用户体验，我们为 Hocuspocus 投入了数百小时的无偿工作。您的资助有助于让这项工作在财务上越来越可持续。这样我们就能提供有用的支持、维护所有软件包、及时更新，并为 Hocuspocus 开发新功能和扩展。

回馈开源社区，[在 GitHub 上赞助我们](https://github.com/sponsors/ueberdosis)吧！♥

- 投资 Hocuspocus 的未来
- 回馈开源社区
- 在您的 GitHub 个人资料中表达支持

听起来不错？[在 GitHub 上赞助我们！](https://github.com/sponsors/ueberdosis)

## 常见问题

### 我无法使用 GitHub。如何支持你们？

如果您是公司，不想使用 GitHub、没有信用卡，或者需要我们提供正式发票，请通过 [humans@tiptap.dev](mailto:humans@tiptap.dev) 联系我们。

我们也开通了 [OpenCollective](https://opencollective.com/tiptap)，您可以通过银行转账、PayPal 或信用卡捐款。美国公司的捐款可抵税。

### 我想咨询。你们的收费标准是什么？

如果您遇到问题、有疑问、想讨论某件事，或有其他需要，请[使用 GitHub issues](https://github.com/ueberdosis/hocuspocus/issues)，让整个社区都能了解相关内容。其他事项请通过 [humans@tiptap.dev](mailto:humans@tiptap.dev) 联系我们。我们可以承接数量有限的定制开发和咨询项目。
