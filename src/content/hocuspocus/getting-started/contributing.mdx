没有活跃的社区，Hocuspocus 将一事无成。我们一直欢迎大家贡献，今后也会如此。在提交贡献之前，有几点需要了解：

## 欢迎提交的内容

- 作为 bug 报告提交的失败回归测试
- 改进文档，例如修正错别字、添加章节
- 为现有扩展添加新功能，例如增加可配置选项
- 说明充分且不破坏兼容性的核心代码更改

## 不会合并的内容

- 我们之后需要支持和维护的新扩展

## 提交想法

请先创建一个 issue，概述你的想法。我们会尽快回复，并告知你的贡献是否有机会被合并。

## 设置开发环境

在官方仓库中进行试验并不难。你需要安装 [Git](https://github.com/git-guides/install-git) 和 [Node 与 NPM](https://nodejs.org/en/download/)。接下来按以下步骤操作：

1. 将代码克隆到本地：`$ git clone git@github.com:ueberdosis/hocuspocus.git`
3. 安装依赖：`$ npm install`
4. 构建软件包 `$ npm run build:packages`
3. 启动开发环境：`$ npm run start`
4. 在你喜欢的浏览器中打开 http://localhost:3000。
5. 开始动手试试吧！

编译并监视更改：

```sh
npm run build:watch
```

## 如何在开发项目中使用本地 hocuspocus 软件包

如果想在项目中使用本地 hocuspocus 软件包，请按以下步骤操作。我试过使用 `npm link`，但由于重复导入 yjs，始终无法稳定运行。以下是我目前唯一成功的方法：

在此（hocupsocus）仓库中执行以下命令来编译源代码：

`$ rollup -c -w`

然后……

```bash
$ cd other_project # execute the following commands within the other project that should include local
 # hocuspocus dependencies. Replace `provider` by the package that you want to replace.
 # Replace HOCUSPOCUS_LOCAL_REPO_PATH by the path of "this" repo.
$ rm -Rf node_modules/yjs node_modules/@hocuspocus/provider
$ ln -s HOCUSPOCUS_LOCAL_REPO_PATH/packages/provider node_modules/@hocuspocus/provider
$ ln -s HOCUSPOCUS_LOCAL_REPO_PATH/node_modules/yjs ./node_modules/yjs
```

还是不行？→ 执行 `rm -Rf node_modules && npm install`，然后再试一次。


## 错误测试
你的拉取请求会自动运行所有现有测试。提交拉取请求前，请确保所有测试均通过。你的拉取请求会通过 GitHub Workflow 自动运行所有测试。

- 启动 Redis 服务器：`$ docker run -d --name hocuspocus-redis -p 6379:6379 redis:7`
- 在本地运行所有测试：`$ npm run test`
- 运行单个软件包的所有测试：`$ npm run test -- tests/PACKAGE_NAME`
