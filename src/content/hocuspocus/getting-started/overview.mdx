Hocuspocus 是一套帮助你在应用中实现协作功能的工具。它基于 [Y.js](https://github.com/yjs/yjs)（由 Kevin Jahns 开发），非常适合实时同步和合并客户端的更改。你也可以用它构建离线优先应用，稍后再同步更改。我们会确保解决冲突并始终保持数据同步。

## 什么是 Y.js？

Y.js 能够实时、无冲突地合并用户所做的更改。与其他实现相比，它的性能极高，甚至可以说远胜于其他方案（Joseph Gentle，前 Google Wave 工程师，[来源](https://josephg.com/blog/crdts-are-the-future/)）。

对于这种无冲突复制数据类型（CRDT）来说，更改的应用顺序并不重要。这有点像 Git：更改在何时提交并不重要。此外，每一份数据副本的地位都相同。

借助它，你可以构建高性能实时应用，为现有应用添加协作功能，同步感知状态，并采用离线优先的设计思路。

## Hocuspocus 服务器

使用 Y.js 时，你可以选择任意网络协议，将更改发送给其他客户端；其中最常用的是 WebSocket。Hocuspocus 服务器是一个 WebSocket 后端，提供了快速上手、将 Y.js 集成到现有基础架构中，以及扩展至百万用户所需的一切。

## 功能

- 无冲突地合并更改
- 更改何时到达都无关紧要
- 可以同步整个应用状态
- 协作式文本编辑（支持 Tiptap、Slate、Quill、Monaco 或 ProseMirror）
- 可集成到现有应用中
- 将更改发送到 Webhook
- 借助 Redis 扩展至数百万用户
- 使用 TypeScript 编写
- 可在 Node.js、Bun、Deno 和 Cloudflare Workers 上运行（v4 起支持）
- 通过 [`@hocuspocus/provider-react`](/hocuspocus/provider/react) 提供一流的 React 绑定
