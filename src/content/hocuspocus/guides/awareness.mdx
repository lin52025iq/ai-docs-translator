## 简介

借助 Awareness，可以共享所有当前在线用户的信息。Awareness 允许你同步用户名称、光标位置，甚至复杂 3D 世界中的坐标。它底层有自己的 CRDT，但不会保留更新历史。你可以在 [Yjs 关于 Awareness 的文档](https://docs.yjs.dev/getting-started/adding-awareness)中了解更多信息。

## 设置状态
传入一个键和一个值，即可设置当前用户的 Awareness 信息。你可以自由传入想要与其他用户共享的数据。下面的示例在 `user` 键下设置了名称和十六进制颜色值：

你也可以在[提供程序的事件部分](/hocuspocus/provider/events)了解相关事件：`awarenessUpdate` 和 `awarenessChange`。

## 设置状态

```js
// 设置当前用户的 awareness 字段
provider.setAwarenessField("user", {
  name: "Kevin Jahns",
  color: "#ffcc00",
});
```

## 监听变化

注册事件监听器，以接收并响应变化。这不仅适用于你自己的状态，也适用于所有已连接用户的 Awareness 状态：

```js
// 监听所有用户状态的更新
provider.on("awarenessUpdate", ({ states }) => {
  console.log(states);
});
```

## 用法

前面都是一些零散的小片段。下面是一个完整的示例，展示如何在应用中使用：

```js
import * as Y from 'yjs'
import { HocuspocusProvider } from '@hocuspocus/provider'

// 设置提供程序
provider = new HocuspocusProvider({
  url: "ws://127.0.0.1:1234",
  name: "awareness-example",
  document: new Y.Doc(),
  // 监听更新…
  onAwarenessUpdate: ({ states }) => {
    console.log(states);
  },
});

// 例如，监听鼠标移动
 document.addEventListener("mousemove", (event) => {
  // 共享任意信息
  provider.setAwarenessField("user", {
    name: "Kevin Jahns",
    color: "#ffcc00",
    mouseX: event.clientX,
    mouseY: event.clientY,
  });
});
```
