要持久化文档，必须让服务器执行以下操作：

1. 在 `onStoreDocument` 钩子中存储文档（它与 `onChange` 相同，但已配置防抖）。
2. 使用 `onLoadDocument` 钩子从数据库加载文档。

实际上，你甚至不必使用这两个钩子！我们已经基于它们创建了一个简单的抽象，即[数据库扩展](/hocuspocus/server/extensions/database)。

- [数据库扩展](/hocuspocus/server/extensions/database) - 适用于任何数据库的通用数据库驱动程序
- [SQLite 扩展](/hocuspocus/server/extensions/sqlite) - 开箱即用的 SQLite 持久化方案
- [S3 扩展](/hocuspocus/server/extensions/s3) - 将文档存储在 Amazon S3 或兼容 S3 的服务中

不过，如果你想深入了解，这里有一个使用钩子的示例（这有助于熟悉相关概念）。

```ts
import { debounce } from "debounce";
import { Server } from "@hocuspocus/server";
import { Doc } from "yjs";

let debounced;

const server = new Server({
  async onStoreDocument(data) {
    // Save to database. Example:
    // saveToDatabase(data.document, data.documentName);
  },

  async onLoadDocument(data): Doc {
    return loadFromDatabase(data.documentName) || createInitialDocTemplate();
  },
});

server.listen();

function createInitialDocTemplate() {
  return new Doc();
  // do anything you want here
}
```

## 常见问题：应该以什么格式保存文档？

使用 Uint8Array，[这是 Yjs 编码文档时采用的格式](https://docs.yjs.dev/api/document-updates)。
如果有需要，你也可以**另外**以 JSON 等其他格式持久化文档。

注意：不要将 Y.Doc 存储为 JSON，并在用户连接时再将其重新创建为 YJS 二进制格式。这样会导致更新合并出现问题，并且新连接时内容会重复。必须将数据存储为二进制格式，才能使用 YJS 格式。
