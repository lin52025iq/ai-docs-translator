## 简介

通过 `onAuthenticate` 钩子，你可以检查客户端是否已通过身份验证，并有权查看当前文档。在实际应用中，这通常会涉及向 API 发起请求、查询数据库或执行其他操作。

## 示例

如果抛出错误或返回被拒绝的 Promise，客户端连接将被终止（参见[服务器钩子生命周期](/hocuspocus/server/hooks#lifecycle)）。如果客户端已通过身份验证并获得授权，你也可以返回上下文数据，例如用户 ID，供其他钩子使用。不过，这并非必需。

有关此钩子及其负载的详细信息，请参阅对应的[章节](/hocuspocus/server/hooks#on-authenticate)。

```js
import { Server } from "@hocuspocus/server";

const server = new Server({
  async onAuthenticate(data) {
    const { token } = data;

    // 示例：检查用户是否使用从客户端传来的令牌通过身份验证
    if (token !== "super-secret-token") {
      throw new Error("Not authorized!");
    }

    // 你可以设置上下文数据，供其他钩子使用
    return {
      user: {
        id: 1234,
        name: "John",
      },
    };
  },
});

server.listen();
```

在客户端，你可以将 `token` 参数作为 Hocuspocus 选项之一传入，如下所示：

```js
new HocuspocusProvider({
  url: "ws://127.0.0.1:1234",
  name: "example-document",
  document: ydoc,
  token: "super-secret-token",
});
```

## 只读模式

如果你希望限制当前用户只能读取文档及其更新，而不能应用更新，可以使用 `onAuthenticate` 钩子负载中的 `connection` 属性：

```js
import { Server } from "@hocuspocus/server";

const usersWithWriteAccess = ["jane", "john", "christina"];

const server = new Server({
  async onAuthenticate(data): Doc {
    // 示例代码：通过请求参数检查当前用户是否具有写入权限。在实际应用中，
    // 通常会根据令牌从数据库中获取用户信息
    if (!usersWithWriteAccess.includes(data.requestParameters.get("user"))) {
      // 将连接设为只读
      data.connection.readOnly = true;
    }
  },
});

server.listen();
```
