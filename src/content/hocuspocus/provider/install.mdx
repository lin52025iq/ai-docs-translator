## 简介
Hocuspocus 服务器已经运行起来了吗？现在可以试用 Hocuspocus Provider 了！通过 npm 安装，只需几行代码即可开始使用。

## 安装 Provider

```bash
npm install yjs @hocuspocus/provider
```

## 用法
要使用它，请创建一个新的 Y.js 文档（如果还没有的话），并将其连接到 Hocuspocus Provider。

```js
import * as Y from 'yjs'
import { HocuspocusProvider } from '@hocuspocus/provider'

const ydoc = new Y.Doc()

const provider = new HocuspocusProvider({
  url: 'ws://127.0.0.1:1234',
  name: 'example-document',
  document: ydoc,
})
```

完成！现在，Y.js 文档已连接到 Hocuspocus 服务器。对 Y.js 文档所做的更改会同步给所有其他已连接的用户。

如果你正在构建 React 应用，可以查看 [React 绑定](/hocuspocus/provider/react)——它们将 Provider 封装为组件和 Hooks，因此你无需手动管理生命周期。
