## 简介

事件是响应不同状态的好方法，例如 Provider 成功连接时。你可以选择在初始化时或之后绑定事件监听器，由你决定。

## 方式 1：配置
将事件监听器传递给构造函数，可确保它们在初始化期间注册。

```js
const provider = new HocuspocusProvider({
  url: "ws://127.0.0.1:1234",
  name: "example-document",
  document: ydoc,
  onOpen() {
    // …
  },
  onConnect() {
    // …
  },
  onAuthenticated() {
    // …
  },
  onAuthenticationFailed: ({ reason }) => {
    // …
  },
  onStatus: ({ status }) => {
    // …
  },
  onMessage: ({ event, message }) => {
    // …
  },
  onOutgoingMessage: ({ message }) => {
    // …
  },
  onSynced: ({ state }) => {
    // …
  },
  onClose: ({ event }) => {
    // `event` has `code` and `reason` (since v4)
    // …
  },
  onDisconnect: ({ event }) => {
    // …
  },
  onDestroy() {
    // …
  },
  onAwarenessUpdate: ({ added, updated, removed }) => {
    // …
  },
  onAwarenessChange: ({ states }) => {
    // …
  },
  onStateless: ({ payload }) => {
    // ...
    // the provider can also send a custom message to the server: provider.sendStateless('any string payload')
  },
  onMaxAttemptsFailed: ({ error }) => {
    // Only relevant if you set `maxAttempts`. Handled by the underlying
    // HocuspocusProviderWebsocket – see the section below.
  }
});
```

## 方式 2：绑定
有时你可能想在初始化后注册事件监听器，即使只是在初始化后立即注册。绑定和解绑事件监听器也很方便。

### 绑定事件监听器

```js
const provider = new HocuspocusProvider({
  // …
});

provider.on("synced", () => {
  // …
});
```

### 解绑事件监听器

```js
const onMessage = () => {
  // A new message comes in
};

// Bind …
provider.on("onMessage", onMessage);

// … and unbind.
provider.off("onMessage", onMessage);
```

## 事件列表

| Name                 | Description                                                               |
| -------------------- | ------------------------------------------------------------------------- |
| open                 | 创建 WebSocket 连接时触发。                                                |
| connect              | Provider 成功连接到服务器时触发。                                           |
| authenticated        | 客户端成功通过身份验证时触发。                                               |
| authenticationFailed | 客户端身份验证失败时触发。                                                  |
| status               | 连接状态发生变化时触发。                                                    |
| message              | 收到消息时触发。                                                          |
| outgoingMessage      | 即将发送消息时触发。                                                       |
| synced               | Y.js 文档完成初始同步时触发。                                               |
| close                | WebSocket 连接关闭时触发。                                                 |
| disconnect           | Provider 断开连接时触发。                                                  |
| destroy              | 即将销毁 Provider 时触发。                                                 |
| awarenessUpdate      | Awareness 更新时触发（参见 https://docs.yjs.dev/api/about-awareness）      |
| awarenessChange      | Awareness 发生变化时触发（参见 https://docs.yjs.dev/api/about-awareness）  |
| stateless            | 收到无状态消息时触发。                                                     |

## HocuspocusProviderWebsocket 事件

上面的事件属于表示单个文档的 `HocuspocusProvider`。其底层的 WebSocket 连接（即 `HocuspocusProviderWebsocket`）可能由多个文档共享，并且有一个自己的事件：

| Name              | Description                                                                              |
| ----------------- | ------------------------------------------------------------------------------------------ |
| maxAttemptsFailed | 所有 `maxAttempts` 次重连尝试均失败且 Provider 停止重试时触发。                          |

此事件不会转发给文档 Provider，因此请在 socket 上绑定监听器：

```js
provider.configuration.websocketProvider.on("maxAttemptsFailed", ({ error }) => {
  // …
});
```

只要让 Provider 创建自己的 socket，也可以将 `onMaxAttemptsFailed` 传递给 `HocuspocusProvider` 构造函数。请参阅[如何响应重连失败](/hocuspocus/provider/configuration#reacting-to-failed-reconnects)。
