Provider 是 Y.js 中用于建立不同用户之间通信或在浏览器中缓存更新的方式。Hocuspocus 自带 Provider；自 v2 起，由于支持通过同一 WebSocket 连接多路复用并同步多个文档，因此不再兼容其他 y-provider。

它支持 WebSocket 消息身份验证、可在控制台输出详细信息的调试模式、更多事件钩子、不同的重新连接策略、更完善的错误处理，以及便于使用的 Awareness 协议 API。

所有 Y.js Provider 都可以一起使用，包括 Hocuspocus Provider、原版 [y-websocket](https://github.com/yjs/y-websocket) Provider、[y-webrtc](https://github.com/yjs/y-webrtc)、用于浏览器内缓存的 [y-indexeddb](https://github.com/yjs/y-indexeddb)，以及仍在开发中的 [y-dat](https://github.com/yjs/y-dat)。你可以将 Hocuspocus Provider 与 y-webrtc 和其他 y-provider 一起使用，但使用 Hocuspocus 时必须使用我们的 HocuspocusProvider；除 Hocuspocus 外的服务器实现可能也无法正常工作。不过，如果你想与 Hocuspocus 和其他服务器同步，可以实例化多个 Provider。
