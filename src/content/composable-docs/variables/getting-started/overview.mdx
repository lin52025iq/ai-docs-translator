**变量**可让你在编辑器中显示客户姓名或计算得出的总额等值。值发生变化时，所有对该变量的引用都会自动更新。

文档会保存对变量的引用，而变量的值由你的应用管理。你也可以[将变量绑定到插槽](/composable-docs/variables/guides/bind-slots)，以保持可编辑内容同步。

## 安装

首先，[联系我们的团队](https://tiptap.dev/contact-sales?form=pilot-program)，加入 Tiptap Composable Docs 试点计划。

然后，按照[私有注册表指南](/guides/pro-extensions)配置包管理器。

接着，安装软件包：

```bash
npm install @tiptap/core @tiptap/starter-kit @tiptap-pro/extension-variable
```

## 定义并显示变量

首先，导入编辑器和扩展：

```ts
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import { Variable } from '@tiptap-pro/extension-variable'
```

定义名为 `customer` 的变量，并将扩展添加到编辑器中：

```ts
const editor = new Editor({
  extensions: [
    StarterKit,
    Variable.configure({
      variables: { customer: 'Ada' },
    }),
  ],
  content: '<p></p>',
})
```

在当前选区插入引用。它会显示 **Ada**：

```ts
editor.commands.insertVariable({ name: 'customer' })
```

更新变量值。现在，所有对 `customer` 的引用都会显示 **Grace**：

```ts
editor.commands.setVariable({ name: 'customer', value: 'Grace' })
```

## 在运行时添加和管理变量

创建编辑器时，你不必预先知道所有变量。之后可以使用 `addVariable()` 添加值或解析器，再插入引用：

```ts
editor.commands.addVariable({ name: 'company', value: 'Acme' })
editor.commands.insertVariable({ name: 'company' })

editor.commands.addVariable({
  name: 'customerLabel',
  value: ({ getText }) => `${getText('customer')} at ${getText('company')}`,
})
editor.commands.insertVariable({ name: 'customerLabel' })
```

如果名称为空或已注册，`addVariable()` 会返回 `false`。使用 `setVariable()` 更新现有值，或使用 `setVariables()` 替换值或解析器：

```ts
editor.commands.setVariable({ name: 'company', value: 'Tiptap' })
editor.commands.setVariables({
  variables: { customerLabel: ({ getText }) => getText('customer').toUpperCase() },
})
```

使用 `removeVariable()` 移除变量。请先移除依赖它的解析器，或使用 `removeVariables()` 将它们一并移除：

```ts
editor.commands.removeVariable({ name: 'customerLabel' })
editor.commands.removeVariable({ name: 'company' })
```

移除变量后，现有引用仍会保留在文档中，并显示为空值。再次添加同名变量即可恢复显示。运行时定义属于此编辑器实例，不会保存到文档中，也不会因撤销文档操作而还原。对于绑定的插槽，移除变量会[将其恢复为插槽内容](/composable-docs/variables/api-reference/extension#removevariable)。

有关批量注册、移除及失败行为，请参阅[命令参考](/composable-docs/variables/api-reference/extension#commands)。

## 值和解析器

你可以直接定义值，也可以使用函数计算值，这种函数称为**解析器**。使用 `get()` 读取另一个变量的原始值，或使用 `getText()` 将其作为字符串读取。在编辑器中，将 `Variable.configure(...)` 替换为：

```ts
Variable.configure({
  variables: {
    customer: 'Ada',
    quantity: 3,
    greeting: ({ getText }) => `Hello, ${getText('customer')}!`,
  },
})
```

使用此配置时，更改 `customer` 也会更新 `greeting`：

```ts
editor.commands.setVariable({ name: 'customer', value: 'Grace' })
// greeting becomes "Hello, Grace!"
```

值也可以是对象或数组。不是 Tiptap 内容的对象会以 JSON 格式显示：

```ts
editor.commands.setVariable({
  name: 'customer',
  value: { name: 'Ada', company: 'Acme' },
})
```

若要分别显示姓名和公司，请使用 `get('customer')` 为每个属性定义解析器，然后插入对这些变量的引用。`customer.name` 这类名称不会自动查找对象属性。

使用 Tiptap JSON 显示带格式的内容：

```ts
editor.commands.setVariable({
  name: 'customer',
  value: { type: 'text', text: 'Ada', marks: [{ type: 'bold' }] },
})
```

## 将变量值连接到外部数据源

解析器可以读取应用中的数据。创建一个客户对象、一个读取其姓名的解析器，以及一个用于显示姓名的编辑器：

```ts
let customer = { name: 'Ada' }

const refreshEditor = new Editor({
  extensions: [
    StarterKit,
    Variable.configure({
      variables: { customer: () => customer.name },
    }),
  ],
  content: '<p></p>',
})
refreshEditor.commands.insertVariable({ name: 'customer' })
```

监听应用事件并刷新解析器：

```ts
const events = new EventTarget()
const refresh = () => refreshEditor.commands.refreshVariables({ names: ['customer'] })
events.addEventListener('customer-change', refresh)
```

更改数据后，发送事件。编辑器现在会显示 **Grace**：

```ts
customer = { name: 'Grace' }
events.dispatchEvent(new Event('customer-change'))
```

销毁编辑器时移除事件监听器：

```ts
refreshEditor.on('destroy', () => events.removeEventListener('customer-change', refresh))
```

## 保存的内容

文档保存的是变量名称，而不是变量值。每个编辑器都提供自己的变量值。

[绑定插槽](/composable-docs/variables/guides/bind-slots)中的文本会作为普通文档内容保存。
