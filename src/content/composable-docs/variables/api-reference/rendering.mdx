变量是内联的、不可编辑的节点。你可以为默认视图设置样式，也可以扩展 `Variable` 并使用自己的 NodeView。

## 默认标记和样式

```html
<span data-type="variable" data-variable="greeting" contenteditable="false">Hello, Ada!</span>
```

| 属性              | 值                                     |
| ----------------- | -------------------------------------- |
| `data-type`       | 始终为 `'variable'`。                   |
| `data-variable`   | 变量名称；未设置时为 `''`。             |
| `contenteditable` | 始终为 `'false'`。                      |

默认情况下没有 CSS 类或样式。使用 `HTMLAttributes`（`Record<string, string>`，默认值为 `{}`）添加外层元素属性：

```ts
Variable.configure({
  HTMLAttributes: { class: 'my-variable' },
})
```

在样式表中为 `.my-variable` 或 `[data-type='variable']` 设置样式。必需属性优先级更高。选中节点时，ProseMirror 可能会添加 `ProseMirror-selectednode`。

## 自定义 NodeView

注册自定义扩展，而不是注册 `Variable`：

```ts
const CustomVariable = Variable.extend({
  addNodeView() {
    return ReactNodeViewRenderer(MyVariableView)
  },
})
```

`ReactNodeViewRenderer` 来自 `@tiptap/react`。JavaScript 和 Vue 使用各自标准的 [Tiptap NodeView API](/editor/extensions/custom-extensions/node-views)。

- 保留 `variable` 节点名称、`name` 属性以及内联、原子节点行为。
- 使用不可编辑的 `span` 包装元素，不要包含 `contentDOM` 或 `NodeViewContent`。
- 使用 `getVariable({ editor, name })` 读取初始值。订阅 [`variablesUpdate`](/composable-docs/variables/api-reference/extension#listen-for-changes) 事件以刷新该值；即使节点属性没有变化，变量值也可能发生变化。
- 视图负责管理自己的标记和属性。视图销毁时，移除监听器和渲染内容。

## 渲染值

默认视图会使用编辑器的自定义 NodeView 渲染 Tiptap JSON，将普通对象渲染为 JSON 文本，并将其他值渲染为文本。在自己的视图中也可以使用相同的辅助函数：

```ts
import { renderVariableValue } from '@tiptap-pro/extension-variable'

const rendered = renderVariableValue({ editor, value })
container.replaceChildren(rendered.dom)
```

替换渲染结果或移除视图之前，请释放其中嵌套的 NodeView：

```ts
rendered.destroy()
```

此操作会渲染一个快照。值发生变化时，请重新渲染。由于该值位于文档之外，嵌套的 NodeView 调用 `getPos()` 时会得到 `undefined`。请参阅[辅助函数的类型定义](/composable-docs/variables/api-reference/extension#rendervariablevalue)。

## HTML 序列化

`addNodeView` 控制编辑器 UI。`renderHTML` 只会导出一个空引用以及任何已配置的 `HTMLAttributes`：

```html
<span name="greeting" data-type="variable"></span>
```

`name` 属性会保留变量名称；`data-type` 用于解析器识别该变量。仅用于视图的属性和值不会导出。自定义的 `renderHTML` 和 `parseHTML` 实现应保留此行为。

绑定插槽使用[插槽渲染](/composable-docs/slots/api-reference/rendering)。由显式值或解析器控制的插槽在编辑器中会带有 `contenteditable="false"`、`aria-readonly="true"` 和 `data-variable-readonly="true"` 属性。

内容保护会用自己的视图替换被隐藏的引用；请始终使用 `getVariable` 读取当前值，以确保隐藏值不会泄露。
