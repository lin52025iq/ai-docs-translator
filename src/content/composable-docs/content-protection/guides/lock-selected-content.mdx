若要让用户选择任意内容并将其锁定：

1. 在架构中定义一个[自定义 Mark 或 Node](/editor/extensions/custom-extensions/create-new)，并添加一条编辑器命令，将其应用于选区。
2. 定义一条[保护规则](/composable-docs/content-protection/api-reference/policy)，用于选择带有该 Mark 或 Node 的内容，并将权限设为 `edit: false`，使其内容无法编辑。使用 `target: 'mark'` 可保护带标记的内容及其 Mark；使用 `target: 'node'` 可保护 Node、其属性及其全部内容。
