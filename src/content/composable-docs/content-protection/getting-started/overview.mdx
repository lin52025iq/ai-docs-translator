内容保护用于控制用户可以编辑或读取文档中的哪些部分。通过策略为节点、标记、属性和内容定义权限。

<Callout title="仅限客户端" variant="info">
  内容保护仅在客户端生效。如需服务端内容保护，请[联系我们](https://tiptap.dev/contact-sales?form=pilot-program)。
</Callout>

## 安装

首先，[联系我们的团队](https://tiptap.dev/contact-sales?form=pilot-program)，申请加入内容保护试点计划。

获得访问权限后，请按照[私有注册表设置指南](/guides/pro-extensions)操作，然后安装此软件包：

```bash
npm install @tiptap/core @tiptap/starter-kit @tiptap/y-tiptap yjs @tiptap-pro/extension-content-protection
```

将扩展添加到编辑器中。

```ts
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import {
  ContentProtection,
  type ContentProtectionPolicy,
} from '@tiptap-pro/extension-content-protection'

const policy: ContentProtectionPolicy = {
  version: 1,
  rules: [
    {
      selector: { target: 'node', node: { types: ['heading'] } },
      permissions: { edit: false },
    },
  ],
}

const editor = new Editor({
  extensions: [StarterKit, ContentProtection.configure({ policy })],
})
```

提供一个用于定义可编辑内容的[策略](/composable-docs/content-protection/api-reference/policy)。

你也可以在编辑器运行时更新内容保护规则：

```ts
editor.commands.setContentProtectionPolicy({ policy })
```

请参阅 [API 参考](/composable-docs/content-protection/api-reference/extension)和[策略语言](/composable-docs/content-protection/api-reference/policy)。

## 协作

内容保护支持 [Tiptap 协作](/editor/extensions/functionality/collaboration)。每位协作者都可以使用不同的本地策略。本地编辑会根据该策略进行检查；协作绑定传入的更新则会被接受，以确保所有编辑器与共享文档保持同步。这包括初始同步和协作撤销/重做，即使当前本地策略会拒绝相应的编辑也不例外。读取权限仍会控制每位协作者可以查看和复制的内容。

```ts
import Collaboration from '@tiptap/extension-collaboration'

const editor = new Editor({
  extensions: [
    StarterKit.configure({ undoRedo: false }),
    Collaboration.configure({ document: ydoc }),
    ContentProtection.configure({ policy: localPolicy }),
  ],
})
```

这里，`ydoc` 是连接到协作服务提供程序的共享 Y.Doc，`localPolicy` 是你的应用为该用户指定的策略。要使用此配置，请安装 `@tiptap/extension-collaboration`。策略仅保存在本地，不会存储在共享文档中。这些客户端权限不会授权传入的协作更新；请在你的应用和协作服务中强制实施对共享文档的访问控制。
