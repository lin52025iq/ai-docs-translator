从 `@tiptap-pro/extension-content-protection` 导入这些函数。每个函数都接受一个选项对象。直接传入策略 JSON；独立工具函数会根据文档或事务的架构验证策略，无效策略会抛出 `ProtectionConfigurationError`。

`Editor` 来自 `@tiptap/core`；`Node` 和 `Schema` 来自 `@tiptap/pm/model`；`Transaction` 来自 `@tiptap/pm/state`。

## `validateContentProtectionPolicy`

验证策略语法；如果提供了架构，还会验证所引用的类型和属性。

### 参数

- `policy` (`unknown`)：要验证的值。
- `schema?` (`Schema`)：用于检查名称的架构。省略时仅检查语法。

### 返回值（`{ valid: boolean; issues: PolicyIssue[] }`）

- `valid` (`boolean`)：验证是否通过。
- `issues` (`PolicyIssue[]`)：配置错误；验证通过时为空。

## `checkProtectedTransaction`

根据编辑器当前启用的策略检查事务，但不应用事务或触发事件。编辑器中必须包含 `ContentProtection`。

### 参数

- `editor` (`Editor`)：包含当前启用策略的编辑器。
- `transaction` (`Transaction`)：根据编辑器当前状态创建的事务。

### 返回值（`ProtectionCheck`）

权限结果、违规项和当前修订版本。缺少扩展或起始文档不匹配时会抛出 `ProtectionInputError`。分发事务时会再次检查权限。

## `checkContentProtectionTransaction`

在没有编辑器的情况下检查事务。

### 参数

- `policy` (`ContentProtectionPolicy`)：要评估的策略。
- `transaction` (`Transaction`)：拟议的事务。

### 返回值（`ProtectionCheck`）

权限结果和违规项。两个修订版本均为 `null`。输入不兼容时会抛出 `ProtectionInputError`。

## `getProtection`

汇总编辑器中的读取和编辑权限。需要 `ContentProtection`。

### 参数

- `editor` (`Editor`)：要检查的编辑器。
- `range?` (`{ from: number; to: number }`)：要汇总的范围。默认值：当前选区。

### 返回值（`PermissionSummary`）

汇总权限和匹配的规则标识符。折叠范围会检查光标处的文本插入权限；如需检查特定编辑，请使用事务检查函数。

## `summarizeContentProtection`

在没有编辑器的情况下汇总权限。

### 参数

- `policy` (`ContentProtectionPolicy`)：要评估的策略。
- `document` (`Node`)：要检查的文档。
- `range` (`{ from: number; to: number }`)：要汇总的范围。

### 返回值（`PermissionSummary`）

汇总读取和编辑权限。输入无效时会抛出 `ProtectionInputError`。

## `explainProtection`

说明编辑器中某个现有目标的权限。需要 `ContentProtection`。

### 参数

- `editor` (`Editor`)：要检查的编辑器。
- `subject` (`ProtectionSubject`)：要检查的节点、属性或带标记的范围。

### 返回值（`ProtectionExplanation`）

读取/编辑权限判定以及外围的隐藏规则。目标无效或缺少扩展时会抛出 `ProtectionInputError`。

## `explainContentProtection`

在没有编辑器的情况下说明权限。

### 参数

- `policy` (`ContentProtectionPolicy`)：要评估的策略。
- `document` (`Node`)：要检查的文档。
- `subject` (`ProtectionSubject`)：要检查的现有目标。

### 返回值（`ProtectionExplanation`）

读取/编辑权限判定以及外围的隐藏规则。输入无效时会抛出 `ProtectionInputError`。

## `getReadableContent`

创建一个展示用树结构和纯文本，并用占位符替换已隐去的区域。

### 参数

- `document` (`Node`)：要检查的文档。
- `policy` (`ContentProtectionPolicy`)：要评估的策略。
- `range?` (`{ from: number; to: number }`)：要包含的内容。默认值：整个文档。
- `redactionText?` (`string`)：替换文本。默认值：`'[Hidden content]'`。不会自动读取编辑器选项。

### 返回值（`ReadableContent`）

- `content` (`ReadableNode[]`)：可见内容和已隐去的区域。这不是 Tiptap JSON，不得传递给 `setContent`。
- `text` (`string`)：可见文本；文本块之间以及硬换行处以换行符分隔。非文本叶节点使用 `U+FFFC`；隐藏区域使用 `redactionText`。末尾不会添加换行符。

输入无效时会抛出 `ProtectionInputError`。此函数不会更改文档、解析外部值、生成 HTML 或调用 `renderRedaction`。

请参阅[结果类型](/composable-docs/content-protection/api-reference/types)和[策略类型](/composable-docs/content-protection/api-reference/policy)。
