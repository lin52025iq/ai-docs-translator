`@tiptap-pro/extension-content-protection` 导出的类型。另请参阅[策略类型](/composable-docs/content-protection/api-reference/policy)和[遮蔽类型](/composable-docs/content-protection/api-reference/rendering)。

## `PolicyDocumentOptions`

用于检查文档的实用工具所共用的输入。

### 属性

- `policy` (`ContentProtectionPolicy`)：要评估的策略。
- `document` (`Node`)：要检查的文档。

## `PolicyIssue`

一项配置错误或输入错误。

### 属性

- `path` (`string`)：无效值的位置。
- `code` (`'invalidFormat' | 'unsupportedVersion' | 'duplicateRuleId' | 'unknownNodeType' | 'unknownMarkType' | 'unknownAttribute'`)：错误类别。
- `message` (`string`)：易于理解的说明。

## `ProtectionConfigurationError`

继承自 `Error`。实用工具或扩展收到无效策略时抛出。

### 属性

- `issues` (`PolicyIssue[]`)：配置诊断信息。
- `name` (`string`)：错误类名称。
- `message` (`string`)：错误摘要。

## `ProtectionInputError`

继承自 `ProtectionConfigurationError`。实用工具输入无效、架构不兼容或扩展状态缺失时抛出。

### 属性

- `issues` (`PolicyIssue[]`)：输入诊断信息。
- `name` (`string`)：错误类名称。
- `message` (`string`)：错误摘要。

## `ProtectionOperationKind`

正在检查的变更类型。

| 值                      | 操作                   |
| ----------------------- | ---------------------- |
| `'insertNode'`          | 插入节点。             |
| `'removeNode'`          | 移除节点。             |
| `'changeNodeType'`      | 更改节点类型。         |
| `'moveNode'`            | 移动节点。             |
| `'changeChildren'`      | 更改直接子节点序列。   |
| `'insertText'`          | 插入文本。             |
| `'removeText'`          | 移除文本。             |
| `'changeAttribute'`     | 更改节点属性。         |
| `'addMark'`             | 添加标记。             |
| `'removeMark'`          | 移除标记。             |
| `'changeMarkAttribute'` | 更改标记属性。         |

## `ProtectionOperation`

描述文档中受影响的部分，但不包含其内容。

### 属性

- `kind` (`ProtectionOperationKind`)：变更类别。
- `from` (`number`)：事务发生前文档中的起始位置。
- `to` (`number`)：该文档中的结束位置。新插入的内容映射到其插入位置。
- `nodeType?` (`string`)：受影响的节点类型（如适用）。
- `markType?` (`string`)：受影响的标记类型（如适用）。
- `attribute?` (`string`)：受影响的属性（如适用）。

## `PermissionDecision`

对一项权限进行解析后的结果。

### 属性

- `allowed` (`boolean`)：是否授予该权限。
- `ruleIds` (`string[]`)：按声明顺序排列的获胜规则 ID（仅包含具有 ID 的规则）。
- `ruleIndexes` (`number[]`)：获胜规则从零开始的索引，包含匿名规则。
- `reasons` (`string[]`)：按声明顺序排列的获胜规则原因；未提供的原因会被省略。

## `ProtectionViolation`

拒绝一项事务的原因。

### 属性

- `code` (`'editDenied' | 'readDenied' | 'unsupportedStep'`)：拒绝类别。
- `operation` (`ProtectionOperation | null`)：被拒绝的操作；对于不受支持的 Step，为 `null`。
- `ruleIds` (`string[]`)：获胜规则 ID（如有提供）。
- `ruleIndexes` (`number[]`)：获胜规则从零开始的索引。
- `reasons` (`string[]`)：匹配的拒绝说明。

## `ProtectionCheck`

检查拟议事务的结果。

### 属性

- `allowed` (`boolean`)：所有操作均获准时为 `true`。
- `violations` (`ProtectionViolation[]`)：按确定性的位置/操作顺序排列的拒绝项；全部获准时为空。
- `documentRevision` (`number | null`)：编辑器文档版本；纯检查时为 `null`。
- `policyRevision` (`number | null`)：编辑器策略版本；纯检查时为 `null`。

## `ProtectionRejection`

继承自 `ProtectionCheck`，并将 `allowed` 设为 `false`。

## `PermissionSummary`

某个范围的汇总权限。如果某区域的文本可编辑、但属性受保护，则 `edit` 可能为 `'some'`。

### 属性

- `read` (`'all' | 'some' | 'none'`)：该范围有多少内容可读。
- `edit` (`'all' | 'some' | 'none'`)：评估的编辑操作中，全部、部分或没有被允许。
- `ruleIds` (`string[]`)：产生影响的规则 ID（如有提供）。
- `ruleIndexes` (`number[]`)：产生影响的规则从零开始的索引。

## `ProtectionSubject`

要说明的现有目标，由 `target` 区分。

| `target`                                              | 其他属性                                                                                                          |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `'node'`、`'nodeType'`、`'nodeContent'`、`'children'` | `pos` (`number`)：节点的起始位置；对于文档根节点为 `-1`。                                                         |
| `'attribute'`                                         | `pos` (`number`)：节点位置。`name` (`string`)：属性名称。                                                         |
| `'mark'`、`'markType'`、`'markContent'`               | `from` (`number`)、`to` (`number`)：标记范围。`type` (`string`)：标记名称。                                      |
| `'markAttribute'`                                     | `from` (`number`)、`to` (`number`)：标记范围。`type` (`string`)：标记名称。`name` (`string`)：属性名称。         |

指定的标记必须覆盖整个范围。位置无效、标记不存在或属性名称未知时，会抛出 `ProtectionInputError`。

## `ProtectionExplanation`

针对某个目标的权限判定。

### 属性

- `subject` (`ProtectionSubject`)：被检查的目标。
- `read` (`PermissionDecision | null`)：读取权限判定；对于 `children` 为 `null`。
- `edit` (`PermissionDecision`)：有效的编辑权限判定，包括读取限制。
- `concealedBy` (`string[]`)：隐藏此目标的外层拒绝读取规则的 ID。匿名规则没有可纳入的 ID。

## `PolicyUpdate`

已安装的策略变更。

### 属性

- `policy` (`ContentProtectionPolicy`)：新策略。
- `policyRevision` (`number`)：更新后的版本。

## `ContentProtectionRejectedEvent`

继承自 `ProtectionRejection`，并包含 `editor` (`Editor`)：拒绝该事务的编辑器。此事件包含诊断信息，不包含事务或隐藏内容。

## `ContentProtectionPolicyUpdateEvent`

继承自 `PolicyUpdate`，并包含 `editor` (`Editor`)：策略发生变更的编辑器。

## `ContentProtectionPolicyErrorEvent`

### 属性

- `editor` (`Editor`)：拒绝策略更新的编辑器。
- `issues` (`PolicyIssue[]`)：配置诊断信息。

## `ReadableMark`

可读投影中的可见标记。

### 属性

- `type` (`string`)：标记类型名称。
- `attrs?` (`Record<string, JsonValue>`)：可见标记属性。

## `ReadableNode`

呈现树中的一个条目，由 `kind` 区分。它不是 Tiptap JSON 节点。

### `kind: 'node'`

- `type` (`string`)：可见节点类型，或用于部分隐藏内容的投影包装节点。
- `attrs?` (`Record<string, JsonValue>`)：可见节点属性。
- `marks?` (`ReadableMark[]`)：可见标记。
- `content` (`ReadableNode[]`)：可读子节点。

### `kind: 'text'`

- `text` (`string`)：可见文本。
- `marks` (`ReadableMark[]`)：可见标记。

### `kind: 'redacted'`

- `inline` (`boolean`)：占位符是否处于行内位置。
- `label` (`string`)`：通过 `redactionText` 提供的中性替换文本。

遮蔽条目不包含原始类型、ID、属性、标记、文本或内容长度。

## `ReadableContent`

[`getReadableContent`](/composable-docs/content-protection/api-reference/utilities#getreadablecontent) 的输出。

### 属性

- `content` (`ReadableNode[]`)：呈现树；必要时保留部分祖先包装节点。
- `text` (`string`)：该树的纯文本表示。
