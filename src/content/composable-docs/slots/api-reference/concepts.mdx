Slot 将其规则存储在 `attrs.config` 中。请求验证时，规则会报告无效内容；它们不会阻止编辑或更改 schema。

## `SlotConfig`

### 属性

- `label?` (`string`)：无障碍名称。省略时：使用 Slot ID。
- `instructions?` (`string`)：面向应用的说明。省略时：无。
- `placeholder?` (`string`)：Slot 为空时仅供视图显示的文本。省略时：无。
- `defaultContent?` (`JSONContent[]`)：插入时未提供 `content` 的初始内容。省略时：该类型的空内容。
- `required?` (`boolean`)：空内容是否会导致验证失败。默认值：`false`。
- `allowedBlocks?` (`SlotContentType[]`)：允许的直接非 Slot 块级子节点。省略时：允许任何已安装的块类型。`[]`：不允许任何类型。
- `allowedInline?` (`SlotContentType[]`)：允许的非文本、非 Slot 行内后代节点。省略时：允许任何已安装的行内类型。`[]`：不允许任何类型。
- `allowText?` (`boolean`)：是否允许文本。默认值：`true`。
- `allowedMarks?` (`SlotContentType[]`)：允许的 Mark。省略时：允许任何已安装的 Mark。`[]`：不允许任何 Mark。
- `constraints?` (`SlotConfig['constraints']`)：下文列出的值约束。省略时：不限制值。
- `nesting?` (`SlotConfig['nesting']`)：下文列出的嵌套 Slot 规则。默认值：`{ allowed: false }`。
- `validators?` (`ValidatorReference[]`)：应用级检查。默认值：`[]`。
- `crossFieldRules?` (`CrossFieldRule[]`)：涉及其他字段的检查。默认值：`[]`。
- `metadata?` (`Record<string, JsonValue>`): 由应用管理的 JSON。默认值：无元数据；此包不会为其赋予任何含义。

```ts
const config: SlotConfig = {
  required: true,
  allowedBlocks: [{ type: 'paragraph' }],
  constraints: { maxLength: 600 },
}
```

### `constraints`

- `minLength?` (`number`)：最小文本长度，以 Unicode 码点计。省略时：无最小值。
- `maxLength?` (`number`)：最大文本长度，以 Unicode 码点计。省略时：无最大值。
- `minChildren?` (`number`)：块级 Slot 的最少直接子节点数。省略时：无最小值。
- `maxChildren?` (`number`)：块级 Slot 的最多直接子节点数。省略时：无最大值。
- `pattern?` (`{ source: string; flags?: string; message?: string }`)：正则表达式测试。省略时：不检查模式。
- `values?` (`string[]`)：允许的精确文本值。省略时：不限制。`[]`：任何非空值均无效。

计数值必须是非负整数；最小值不能大于最大值。子节点计数包括嵌套 Slot，以及空块级 Slot 中的空段落。

### `constraints.pattern`

- `source` (`string`)：JavaScript 正则表达式源码。若要匹配全文，请添加 `^` 和 `$`。
- `flags?` (`string`)：`i`、`m`、`s`、`u` 的组合。默认值：`''`。不支持有状态标志 `g` 和 `y`。
- `message?` (`string`)：失败消息。省略时：使用内置消息。

### `nesting`

- `allowed` (`boolean`)：是否允许后代 Slot。
- `kinds?` (`SlotKind[]`)：允许的后代类型。省略时：在符合 schema 的前提下允许两种类型。`[]`：不允许任何类型。
- `maxDepth?` (`number`)：拥有者下方最多允许的 Slot 边数。直接嵌套的 Slot 深度为 `1`。省略时：不设上限。

所有祖先的嵌套限制均适用。行内 Slot 不能包含块级 Slot。

## `SlotContentType`

### 属性

- `type` (`string`)：schema 中 Node 或 Mark 的准确名称。
- `attributes?` (`Record<string, JsonValue[]>`)：各属性允许的值。省略时：不限制属性。每个值列表都必须非空。

允许列表中的条目之间采用 OR 关系；单个条目内的属性之间采用 AND 关系。值按结构化 JSON 相等性比较，不进行类型强制转换。

`allowedBlocks` 检查直接的非 Slot 子节点。嵌套 Slot 由 `nesting` 检查，而非块级允许列表。行内、文本和 Mark 规则会检查后代节点，但遇到嵌套 Slot 时停止；嵌套 Slot 使用自己的配置。

## `ValidatorReference`

### 属性

- `name` (`string`)：已配置的 `validators` 注册表中的键。
- `params?` (`JsonValue`)：验证器参数。默认值：`null`。

## `CrossFieldRule`

### 属性

- `id?` (`string`)：可选的诊断标识符，在所属对象内唯一。未提供 ID 时，诊断使用 `ruleIndex`。
- `validator` (`string`)：`crossFieldValidators` 中的键。
- `fields` (`string[]`)：引用的 Slot ID，包括所属对象自身的 ID。
- `params?` (`JsonValue`)：验证器参数。默认值：`null`。

每条规则在其所属对象处评估一次。发现的问题只能指向已声明的字段。参见[自定义验证器](/composable-docs/slots/api-reference/validation#slotvalidator)。

## 默认值和标识

- 显式提供的插入内容（包括 `[]`）会覆盖 `defaultContent`。
- 默认内容仅在创建时复制。加载、清空或更改配置都不会重新填充 Slot。
- 嵌套的默认 Slot 会获得新的 ID；内部跨字段引用会相应重新映射。
- 复制/粘贴会创建新的 Slot ID，并重新映射所复制片段内的引用。外部引用保持不变。
- 内部拖动移动会保留 ID。本地剪切/粘贴在 ID 不再被使用时可以保留 ID。
- 导入内容中缺失或重复的 ID 会原样保留并报告诊断。请显式使用 `repairSlotIds`。

## 值 Slot 配置

值 Slot 与内容 Slot 共用 `label`、`instructions`、`placeholder`、`required`、`validators`、`crossFieldRules` 和 `metadata`。此外还接受：

- `defaultValue?` (`JsonValue`)：插入时未提供 `value` 的初始答案。省略时：`null`。显式值（包括 `null`）会覆盖它。清空后不会恢复此默认值。
- `input?` (`SlotInput`)：输入呈现方式。省略时：文本输入框。

`SlotInput` 包含 `type: string`、可选的 `options: { value: string; label: string }[]`，以及可选的 `props: Record<string, JsonValue>`。`props` 供应用渲染器使用。内置输入类型和输出约定见[值 Slot 指南](/composable-docs/slots/guides/value-slots#built-in-inputs)。

不存在 `valueType`。自定义渲染器可以接受多种 JSON 值。内容设置（`defaultContent`、`allowedBlocks`、`allowedInline`、`allowText`、`allowedMarks`、`nesting` 和子节点计数约束）不能用于值 Slot。文本约束仅在答案为字符串时适用。选择项会在验证期间检查。

## 配置错误

未知键、无效 JSON、格式错误的模式和无效计数都会产生配置问题。基于 schema 的检查还会报告未知的 Node 和 Mark 类型。应用特定数据请使用 `metadata`。

`allowedBlocks`、`constraints.minChildren` 和 `constraints.maxChildren` 仅适用于块级 Slot。在行内 Slot 上使用这些设置属于配置错误。创建命令会拒绝此类配置；导入的文档会保留这些配置，以便在验证诊断中报告。

请参阅 [`validateSlotConfig`](/composable-docs/slots/api-reference/validation#validateslotconfig)，了解如何在赋值前检查配置。
