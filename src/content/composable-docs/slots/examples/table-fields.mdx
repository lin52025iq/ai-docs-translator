此示例使用[内容保护](/composable-docs/content-protection/getting-started/overview)来限制用户可以编辑的内容。用户可以向表格中添加和删除行，也可以编辑表格内容，但不能编辑表格以外的内容、添加列或编辑表头。

此演示使用插槽将表格单元格定义为字段：每个表格字段都包含一个插槽，可在其中填入内容并在之后进行验证。
