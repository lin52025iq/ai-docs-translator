值插槽可让你在插槽中存储任意 JSON 值，而不仅限于 Tiptap 内容。你可以将这些值显示为文本输入框、复选框等表单字段，也可以构建自己的自定义输入控件。

## 插入值插槽

创建插槽时，传入 `mode: 'value'` 即可创建值插槽：

```ts
editor.commands.insertSlot({
  mode: 'value',
  kind: 'inline',
  id: 'priority',
  value: null,
  config: {
    label: 'Priority',
    placeholder: 'Choose a priority',
    input: {
      type: 'select',
      options: [
        { value: 'normal', label: 'Normal' },
        { value: 'urgent', label: 'Urgent' },
      ],
    },
  },
})
```

使用 `kind: 'block'` 可将控件放在独立的块中。如果不传入 `mode: 'value'`，插入的将是普通内容插槽。

值可以是任意有限的 JSON：`null`、字符串、布尔值、数字、数组或对象。使用[验证](/composable-docs/slots/guides/validate-submission)来强制满足应用的要求。

## 内置输入控件

Slot 扩展内置了一组输入类型。你也可以创建自己的自定义输入控件。

设置 `config.input.type` 来选择控件。不传入 `input` 时，默认使用文本输入框。

| 类型       | 控件               | 存储的值                         | 选项类型（`config.input.options`）         |
| ---------- | ------------------ | -------------------------------- | ----------------------------------------- |
| `text`     | 原生文本输入框     | `string`                         | 不使用                                    |
| `textarea` | 多行文本输入框     | `string`                         | 不使用                                    |
| `number`   | 原生数字输入框     | `string`，包括 `''`              | 不使用                                    |
| `date`     | 原生日期输入框     | `string`，例如 `'2026-10-14'`    | 不使用                                    |
| `checkbox` | 原生复选框         | `boolean`                        | 不使用                                    |
| `select`   | 单选下拉框         | `string` 选项值                  | `{ value: string; label: string }[]`      |
| `radio`    | 单选按钮列表       | `string` 选项值                  | `{ value: string; label: string }[]`      |

`SlotInput.options` 是可选项。只有 select 和 radio 控件会使用它；它们存储的是所选选项的 `value`，而不是 `label`。

对于单选按钮组，将 `config.input` 设置为：

```ts
{
  type: 'radio',
  options: [
    { value: 'standard', label: 'Standard' },
    { value: 'express', label: 'Express' },
  ],
}
```

每个插槽都是独立的单选按钮组。如需多选，请使用自定义 NodeView，例如演示中的标签选择器。

数字输入控件将值存储为字符串，因为浏览器可能会在数字输入不完整时返回 `''`。

## 读取和更新值

```ts
import { getSlot } from '@tiptap-pro/extension-slot'

editor.commands.setSlotValue({ id: 'priority', value: 'urgent' })
// 清空插槽会将其值设为 null。
editor.commands.clearSlot({ id: 'priority' })

// 以原子批次更新多个插槽值。
editor.commands.setSlotValues({
  values: [
    { id: 'priority', value: 'urgent' },
    { id: 'name', value: 'Alex' },
  ],
})

const slot = getSlot({ snapshot: editor.storage.slot.snapshot, id: 'priority' })
if (slot?.mode === 'value') console.log(slot.value)
```

插槽支持协作。启用协作后，插槽的更新会实时同步给协作文档的其他用户。

## 混用自定义和默认 NodeView

按照完整教程构建自定义切换按钮及其界面：

- [使用原生 JavaScript 创建自定义输入控件](#create-a-custom-input-with-vanilla-javascript)
- [使用 React 创建自定义输入控件](#create-a-custom-input-with-react)

在 `addNodeView()` 中选择渲染器，并将内置控件作为回退选项：

```ts
import { Slot, InlineValueSlot, createDefaultSlotValueView } from '@tiptap-pro/extension-slot'

const CustomValueSlot = InlineValueSlot.extend({
  addNodeView() {
    return (props) => {
      if (props.node.attrs.config?.input?.type === 'rating') {
        return createRatingView(props)
      }
      return createDefaultSlotValueView(props)
    }
  },
})

Slot.configure({ inlineValueSlot: CustomValueSlot })
```

`createRatingView` 是应用代码。演示中使用原生按钮实现。对于块级视图，请使用 `BlockValueSlot` 和 `blockValueSlot` 选项。保留原始节点名称和叶节点 schema。不要提供 `contentDOM` 或 `NodeViewContent`。

在自定义视图中，`createSlotValueController({ editor, getPos })` 提供：

- `getValue()` 和 `setValue(value)`，用于读取和写入答案。
- `getState()`，用于获取 `value`、`config`、`editable` 和 `available` 的稳定快照。
- `subscribe(listener)`，用于在文档和权限发生变化后更新界面。
- `focus()`，在输入控件获得焦点时选中插槽。
- `destroy()`，在移除原生视图时释放订阅。

自定义视图应当：

- 在 `editable` 为 `false` 时禁用控件。
- 当 `setValue` 返回 `false`（写入被拒绝）时，渲染当前状态。
- 将输入事件限制在控件内，并处理文本输入的 IME 组合输入。
- 在移除视图时释放订阅。

如果更改配置会选择不同的渲染器，请在 NodeView 的 `update` 方法中返回 `false`，以便 Tiptap 再次运行 `addNodeView` 工厂函数。输入类型发生变化时，默认视图会这样处理。

## 使用原生 JavaScript 创建自定义输入控件

构建一个在 **On** 和 **Off** 之间切换并存储布尔值的按钮。原生按钮支持使用 Enter 和空格键操作。

### 1. 创建界面

创建 `toggle-slot.js`。使用值控制器读取值、执行受保护的写入，并响应权限变化：

```js
import {
  BlockValueSlot,
  createDefaultSlotValueView,
  createSlotValueController,
} from '@tiptap-pro/extension-slot'

function createToggleView({ editor, getPos, node }) {
  const slot = createSlotValueController({ editor, getPos })
  const dom = document.createElement('div')
  dom.contentEditable = 'false'
  const button = document.createElement('button')
  button.type = 'button'
  dom.append(button)

  function render() {
    const { value, editable, available } = slot.getState()
    const on = value === true
    button.textContent = `${slot.getState().config?.label ?? 'Notifications'}: ${on ? 'On' : 'Off'}`
    button.setAttribute('aria-pressed', String(on))
    button.disabled = !available || !editable
  }

  button.addEventListener('focus', () => slot.focus())
  button.addEventListener('click', () => {
    slot.setValue(slot.getValue() !== true)
    render() // 写入被拒绝时，也会恢复当前状态。
  })
  const unsubscribe = slot.subscribe(render)
  render()

  return {
    dom,
    update(nextNode) {
      return nextNode.type === node.type && nextNode.attrs.config?.input?.type === 'toggle'
    },
    stopEvent: () => true,
    ignoreMutation: () => true,
    destroy() {
      unsubscribe()
      slot.destroy()
    },
  }
}
```

`subscribe` 会在值或权限发生变化时更新按钮。它不会立即调用 `render`，因此需要自行调用一次。`focus()` 会选中插槽；浏览器会让按钮保持焦点。

### 2. 注册自定义渲染器

将以下内容添加到同一文件中。为 `toggle` 输入使用自定义渲染器，内置输入则继续使用默认渲染器：

```js
export const ToggleSlot = BlockValueSlot.extend({
  addNodeView() {
    return (props) =>
      props.node.attrs.config?.input?.type === 'toggle'
        ? createToggleView(props)
        : createDefaultSlotValueView(props)
  },
})
```

输入类型改变时，视图的 `update` 会返回 `false`，以便 Tiptap 选择其他渲染器。保留叶节点 schema：不要添加 `contentDOM`。

### 3. 配置编辑器并插入插槽

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import { Slot } from '@tiptap-pro/extension-slot'
import { ToggleSlot } from './toggle-slot.js'

const editor = new Editor({
  element: document.querySelector('#editor'),
  extensions: [StarterKit, Slot.configure({ blockValueSlot: ToggleSlot })],
  content: '<p>Notification preferences</p>',
})

editor.commands.insertSlot({
  mode: 'value',
  kind: 'block',
  id: 'notifications',
  value: false,
  config: { label: 'Notifications', input: { type: 'toggle' } },
})
```

将编辑器挂载到 `<div id="editor"></div>` 中。点击按钮，或聚焦按钮后按空格键：`attrs.value` 会在 `true` 和 `false` 之间切换。撤销会还原上一个答案。启用[内容保护](/composable-docs/slots/guides/fill-only)后，锁定的插槽会自动禁用按钮。

`toggle` 是应用自定义的输入类型，不是内置类型。存储的值仍是普通 JSON，导出的 HTML 会渲染静态答案。

## 使用 React 创建自定义输入控件

使用 React 组件构建与 [JavaScript 教程](#create-a-custom-input-with-vanilla-javascript)相同的布尔切换控件。按钮无需自定义键盘处理程序即可支持 Enter 和空格键。

使用 `@tiptap/react` 中的 `ReactNodeViewRenderer` 渲染组件。插槽包本身不依赖 React 或 Vue。

### 1. 创建组件

创建 `ToggleSlot.jsx`。使用 `useSyncExternalStore` 连接控制器，以便文档和权限发生变化时更新界面：

```jsx
import { useMemo, useSyncExternalStore } from 'react'
import { NodeViewWrapper, ReactNodeViewRenderer } from '@tiptap/react'
import {
  BlockValueSlot,
  createDefaultSlotValueView,
  createSlotValueController,
} from '@tiptap-pro/extension-slot'

function ToggleView({ editor, getPos }) {
  const slot = useMemo(() => createSlotValueController({ editor, getPos }), [editor, getPos])
  const { value, config, editable, available } = useSyncExternalStore(
    slot.subscribe,
    slot.getState,
    slot.getState,
  )
  const on = value === true

  return (
    <NodeViewWrapper contentEditable={false}>
      <button
        type="button"
        aria-pressed={on}
        disabled={!available || !editable}
        onFocus={() => slot.focus()}
        onClick={() => slot.setValue(slot.getValue() !== true)}
      >
        {config?.label ?? 'Notifications'}: {on ? 'On' : 'Off'}
      </button>
    </NodeViewWrapper>
  )
}
```

- `setValue` 使用与内置控件相同的受保护命令。
- 按钮根据控制器状态渲染，因此写入被拒绝时，显示的答案不会改变。
- React 会在组件卸载时取消订阅。当最后一个订阅者离开时，控制器会释放其编辑器监听器，包括 React Strict Mode 清理期间的情况。

不要添加 `NodeViewContent`：值插槽没有可编辑的子内容。

### 2. 注册 React 渲染器

将以下内容添加到 `ToggleSlot.jsx`。仅为 `toggle` 输入使用 React，并保留内置控件：

```jsx
export const ToggleSlot = BlockValueSlot.extend({
  addNodeView() {
    const renderToggle = ReactNodeViewRenderer(ToggleView, {
      update: ({ newNode, updateProps }) => {
        if (newNode.attrs.config?.input?.type !== 'toggle') return false
        updateProps()
        return true
      },
    })

    return (props) =>
      props.node.attrs.config?.input?.type === 'toggle'
        ? renderToggle(props)
        : createDefaultSlotValueView(props)
  },
})
```

输入类型改变时返回 `false`，Tiptap 就可以选择其他渲染器。

### 3. 挂载编辑器并插入插槽

```jsx
import { EditorContent, useEditor } from '@tiptap/react'
import StarterKit from '@tiptap/starter-kit'
import { Slot } from '@tiptap-pro/extension-slot'
import { ToggleSlot } from './ToggleSlot.jsx'

export function NotificationEditor() {
  const editor = useEditor({
    extensions: [StarterKit, Slot.configure({ blockValueSlot: ToggleSlot })],
    content: '<p>Notification preferences</p>',
    immediatelyRender: false,
  })

  return (
    <>
      <button
        type="button"
        disabled={!editor}
        onClick={() =>
          editor.commands.insertSlot({
            mode: 'value',
            kind: 'block',
            id: 'notifications',
            value: false,
            config: { label: 'Notifications', input: { type: 'toggle' } },
          })
        }
      >
        Add notifications toggle
      </button>
      <EditorContent editor={editor} />
    </>
  )
}
```

点击一次 **Add notifications toggle**，然后用鼠标、Enter 或空格键操作切换控件。其 `attrs.value` 会在 `true` 和 `false` 之间切换；撤销会还原上一个答案。插入其他切换控件时，请使用唯一的插槽 ID。

添加[内容保护](/composable-docs/slots/guides/fill-only)以限制编辑。该组件会自动遵循控制器的 `editable` 状态。

**使用 Vue？** 改用 `VueNodeViewRenderer`。在 setup 中创建控制器，将 `getState()` 的结果复制到 `shallowRef`，通过 `subscribe` 更新该 ref，并在 `onBeforeUnmount` 中取消订阅和销毁控制器。渲染不含 `NodeViewContent` 的 `NodeViewWrapper`。

## 验证

验证会检查答案，但不会阻止用户草拟无效值。例如，可以将姓名设为必填项，并在提交前进行检查：

```ts
import { isSlotValidationCurrent, validateEditorSlots } from '@tiptap-pro/extension-slot'

editor.commands.insertSlot({
  mode: 'value',
  kind: 'block',
  id: 'name',
  value: null,
  config: { label: 'Your name', required: true, input: { type: 'text' } },
})

// 在应用的提交处理程序中运行。
const result = await validateEditorSlots({ editor })
if (isSlotValidationCurrent({ editor, result })) {
  if (result.valid) {
    save(editor.getJSON()) // 应用自己的持久化函数。
  } else {
    console.log(result.issues) // 在相关输入控件旁显示这些问题。
  }
}
```

- 空姓名或仅包含空白字符的姓名无法通过验证，但用户仍可以草拟该值。
- `required` 会将 `null`、空字符串和空数组视为空值。`false` 和 `0` 都算作已填写的答案；如果复选框必须处于勾选状态，请使用自定义验证器。
- Select 和 radio 的答案必须与某个选项值匹配。`allowedBlocks` 和 `defaultContent` 等内容设置不适用于值插槽。

有关自定义验证器和已取消的验证，请参阅[提交前验证](/composable-docs/slots/guides/validate-submission)。

## 内容保护

使用内容保护，让用户填写答案，同时保护文档结构和插槽配置。插入插槽后，仅允许编辑 `name` 插槽：

```ts
import { createSlotFillingPolicy } from '@tiptap-pro/extension-slot'

// 需要在编辑器的 extensions 中添加 ContentProtection。
editor.commands.setContentProtectionPolicy({
  policy: createSlotFillingPolicy({ editableSlotIds: ['name'] }),
})
```

用户可以更改插槽的值，但不能删除插槽或更改其配置。使用值控制器时，内置和自定义输入控件遵循相同的权限。

有关保护设置，请参阅[仅填充编辑](/composable-docs/slots/guides/fill-only)。
