调用 `insertSlot` 命令可向文档添加新插槽。

```ts
// Inserts new slot at the selection
editor.commands.insertSlot()
```

插槽有两种类型：

- **行内插槽**可以包含文本等行内内容
- **块级插槽**采用块布局，可包含一个或多个段落、标题或其他块级节点。

若要将选中的文本转换为插槽并保留其内容，请调用 [`wrapInSlot`](/composable-docs/slots/api-reference/commands#wrapinslot)。省略 `range` 时，该命令会使用编辑器当前的选区；若要包裹文档中的特定范围，请传入 `range: { from, to }`：

```ts
editor.commands.wrapInSlot({
  kind: 'inline',
  id: 'customer',
  config: { label: 'Customer name', placeholder: 'Enter a name', required: true },
})
```

选择完整的块时，请使用 `kind: 'block'`。`insertSlot` 会替换选中的内容，而不是将其包裹起来。

`wrapInSlot` 与 `insertSlot` 一样接受 `id` 和 `config`。省略 `id` 可自动生成一个 ID。包裹操作会保留选中的内容；此命令没有用于转换内容或推导配置的回调选项。你的应用可以先检查选区，再将所选配置传给该命令。

创建插槽时，可以定义其类型和多项属性，例如唯一 ID、标签，以及用于限制可接受内容的一组规则。

```ts
editor.commands.insertSlot({
  kind: 'inline',
  id: 'customer',
  config: {
    label: 'Customer name',
    required: true,
    constraints: { maxLength: 120 },
  },
})
```

之后，可以在插槽内输入内容，或调用 `fillSlot` 命令来填充插槽。

```ts
editor.commands.fillSlot({
  id: 'customer',
  // Tiptap JSON content
  content: [{ type: 'text', text: 'Sam Rivera' }],
})
```

其他实用命令：

- `clearSlot({ id })` 清空插槽。
- `dissolveSlot({ id })` 移除插槽包装并保留其内容，将其转换为普通文档内容。
- `removeSlot({ id })` 移除插槽及其内容。

默认启用两种快捷创建方式：

- 输入 `{{{` 可立即创建一个空的行内插槽，并将光标置于其中。
- 在空段落中输入 `[[[` 可立即创建一个块级插槽，并将光标置于其空段落中。

无需输入结束分隔符，也无需按 Enter。设置 `Slot.configure({ shortcuts: false })` 可禁用所有 Slot 输入规则。[输入规则解析器](/composable-docs/slots/api-reference/extension#resolveinputruleslot)可以配置、填充新插槽，或拒绝创建新插槽。

若要将分隔符之间的文本也转换为行内插槽，请配置一对分隔符：

```ts
Slot.configure({
  shortcuts: { inline: { open: '{{', close: '}}' } },
})
```

输入 `{{Ada}}` 会创建一个包含“Ada”的行内插槽。这对分隔符始终会创建行内插槽，即使当前段落为空也是如此。`{{{` 和 `[[[` 创建快捷方式仍保持启用。请参阅[快捷方式配置](/composable-docs/slots/api-reference/extension#slotshortcuts)，了解如何自定义或禁用各项规则。
