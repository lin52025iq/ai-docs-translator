Slot 可以包含用于描述哪些内容有效的规则。

<CodeDemo isPro path="/Examples/SlotValidation" />

当应用需要检查内容时（例如保存或提交表单之前），调用 `validateEditorSlots`。提交是应用层的操作，并非 Slot 内置事件。

验证会读取快照并返回检查结果；它不会解析或改写 Slot 值。只有在调用验证 API 时，才会运行内置检查和已注册的异步验证器。编辑会使之前的结果失效，并取消正在进行的编辑器验证，但不会自动启动新一轮验证。

若要在输入时进行验证，请注册编辑器的 `update` 监听器，并对 `validateEditorSlots` 调用进行防抖处理。处理已取消的验证，仅显示当前结果，并在 UI 卸载时移除监听器和待处理的计时器。自动调度由宿主负责；系统没有内置的自动验证选项。

```ts
import { isSlotValidationCurrent, validateEditorSlots } from '@tiptap-pro/extension-slot'

try {
  const result = await validateEditorSlots({ editor })
  if (!isSlotValidationCurrent({ editor, result })) {
    showMessage('The document changed. Please submit again to validate the latest values.')
  } else if (result.valid) {
    save(editor.getJSON())
  } else {
    showIssues(result.issues)
  }
} catch (error) {
  if (error instanceof Error && error.name === 'AbortError') {
    showMessage('Validation was cancelled. Please submit again.')
  } else {
    throw error
  }
}
```

`isSlotValidationCurrent` 会检查结果是否仍与编辑器当前的文档和验证设置相符。

在 `attrs.config` 中定义必填要求、长度、内容类型和模式：

```ts
const config = {
  required: true,
  constraints: {
    pattern: { source: '^ORD-\\d{4}$', message: 'Use ORD-0000' },
  },
}

editor.commands.insertSlot({ config })
```

对于特定于应用的检查，请持久化验证器名称并注册其实现：

```ts
Slot.configure({
  validators: {
    registeredPerson: async ({ slot, signal }) => {
      const found = await directory.find(slot.text, { signal })
      return found
        ? []
        : [
            {
              code: 'custom.person',
              message: 'Choose a registered person.',
            },
          ]
    },
  },
})

// When the slot is created, include the custom validator
editor.commands.insertSlot({
  config: {
    validators: [{ name: 'registeredPerson' }],
  },
})
```

验证可能是异步的，因此会传入 AbortSignal（`signal` 字段），以便在验证期间文档被编辑时取消验证过程。

对于涉及多个字段的检查，请在所属 Slot 中添加 `crossFieldRules` 条目，并注册 `crossFieldValidators` 函数。[了解详情，请参阅 API 参考](/composable-docs/slots/api-reference/validation#crossfieldvalidator)。

如果部分验证器缺失或执行失败，`validateEditorSlots` 会返回 `status: 'unavailable'`。

有关验证的更多信息，请参阅 [API 参考](/composable-docs/slots/api-reference/validation#slotvalidator)。
