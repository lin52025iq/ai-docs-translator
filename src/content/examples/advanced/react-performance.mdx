## React 与 Tiptap 编辑器集成

在 React 中使用 Tiptap 时，最常见的性能问题是编辑器重新渲染过于频繁。本演示展示了默认编辑器与使用 `shouldRerenderOnTransaction` 优化渲染后的差异。

## 在不影响性能的情况下获取编辑器状态信息

如果你需要访问编辑器状态，又不想触发重新渲染，可以使用 `useEditorState` hook。这样，你就能读取编辑器状态，而不会触发组件重新渲染。

[点击此处](/editor/getting-started/install/react#reacting-to-editor-state-changes)了解更多。
