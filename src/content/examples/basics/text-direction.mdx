Tiptap 内置支持从右向左（RTL）的语言和双向文本。本示例演示如何设置全局文本方向，以及如何控制各个节点的文本方向。

## 功能

- **全局方向控制**：为所有内容设置默认文本方向（`ltr`、`rtl` 或 `auto`）
- **逐节点设置方向**：使用命令覆盖特定节点的方向
- **双向文本**：正确呈现 LTR 和 RTL 混合内容
- **多语言**：支持英语、阿拉伯语、希伯来语等语言

`auto` 设置对双向内容尤其有用，因为它会根据每个节点中的第一个强方向字符自动检测文本方向。

## 使用方法

### 设置全局方向

为编辑器配置默认文本方向：

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'

const editor = new Editor({
  extensions: [StarterKit],
  textDirection: 'auto', // 或 'ltr'、'rtl'
})
```

### 使用命令控制方向

覆盖特定内容的方向：

```js
// 将所选文本设为 RTL 方向
editor.commands.setTextDirection('rtl')

// 将所选文本设为 LTR 方向
editor.commands.setTextDirection('ltr')

// 使用自动检测
editor.commands.setTextDirection('auto')

// 移除方向覆盖
editor.commands.unsetTextDirection()
```
