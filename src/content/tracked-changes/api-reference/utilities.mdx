该扩展提供用于查询建议和导出基础文档 JSON 的实用函数。

## findSuggestions()

查找文档中的所有建议，可选择性地进行筛选。

| 参数 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `editor` | `Editor` | — | Tiptap 编辑器实例 |
| `markName` | `string` | `'suggestion'` | 建议标记的名称 |
| `options` | `FindSuggestionsOptions` | `{}` | 可选筛选条件（见下文） |

### 选项

| 选项 | 类型 | 描述 |
| --- | --- | --- |
| `type` | `SuggestionType` | 按[建议类型](/tracked-changes/api-reference/types#suggestiontype)筛选 |
| `userId` | `string` | 按用户 ID 筛选 |
| `id` | `string` | 按建议 ID 筛选 |

### 返回值

`Suggestion[]` — 在文档中找到的建议数组。

```js
import { findSuggestions } from '@tiptap-pro/extension-tracked-changes'

// Find all suggestions
const allSuggestions = findSuggestions(editor)

// Find suggestions by type
const insertions = findSuggestions(editor, 'suggestion', { type: 'add' })
const deletions = findSuggestions(editor, 'suggestion', { type: 'delete' })
const replacements = findSuggestions(editor, 'suggestion', { type: 'replace' })
const splits = findSuggestions(editor, 'suggestion', { type: 'split' })

// Find suggestions by user
const userSuggestions = findSuggestions(editor, 'suggestion', { userId: 'user-123' })
```

## findSuggestionById()

按 ID 查找指定建议。

| 参数 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `editor` | `Editor` | — | Tiptap 编辑器实例 |
| `id` | `string` | — | 要查找的建议 ID |
| `markName` | `string` | `'suggestion'` | 建议标记的名称 |

### 返回值

`Suggestion | undefined` — 找到时返回该建议，否则返回 `undefined`。

```js
import { findSuggestionById } from '@tiptap-pro/extension-tracked-changes'

const suggestion = findSuggestionById(editor, 'suggestion-123')

if (suggestion) {
  console.log(`Found suggestion: ${suggestion.text}`)
}
```

## findSuggestionRanges()

查找建议覆盖的所有文档范围。当建议跨越格式边界时，单个建议可能跨越多个文本节点。

| 参数 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `editor` | `Editor` | — | Tiptap 编辑器实例 |
| `id` | `string` | — | 要查找的建议 ID |
| `markName` | `string` | `'suggestion'` | 建议标记的名称 |

### 返回值

`Array<{ from: number; to: number }>` — 此建议覆盖的位置范围数组。相邻范围会自动合并。

```js
import { findSuggestionRanges } from '@tiptap-pro/extension-tracked-changes'

const ranges = findSuggestionRanges(editor, 'suggestion-123')
// Returns: [{ from: 10, to: 25 }, { from: 30, to: 35 }]
```

## getSuggestionAtSelection()

获取当前选区位置处的建议。适用于基于标记的建议（文本）和基于属性的建议（原子节点）。

| 参数 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `editor` | `Editor` | — | Tiptap 编辑器实例 |
| `markName` | `string` | `'suggestion'` | 建议标记的名称 |

### 返回值

`Suggestion | undefined` — 当前光标位置处的建议；如果没有，则返回 `undefined`。

```js
import { getSuggestionAtSelection } from '@tiptap-pro/extension-tracked-changes'

const suggestion = getSuggestionAtSelection(editor)

if (suggestion) {
  // Show accept/reject buttons in your UI
  showSuggestionPopup(suggestion)
}
```

获取指定文档位置处的建议。

```js
const suggestion = getSuggestionAtPosition(editor, 42)
```

## findSuggestionsInRange()

查找与指定文档范围重叠的所有建议。

| 参数 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `editor` | `Editor` | — | Tiptap 编辑器实例 |
| `from` | `number` | — | 范围的起始位置 |
| `to` | `number` | — | 范围的结束位置 |
| `filters` | `{ userId?: string; type?: SuggestionType }` | `undefined` | 可选筛选条件 |
| `markName` | `string` | `'suggestion'` | 建议标记的名称 |

### 返回值

`Suggestion[]` — 与该范围重叠的建议数组。

```js
import { findSuggestionsInRange } from '@tiptap-pro/extension-tracked-changes'

// Find all suggestions between positions 10 and 50
const suggestions = findSuggestionsInRange(editor, 10, 50)

// With filters
const userInsertions = findSuggestionsInRange(editor, 10, 50, {
  userId: 'user-123',
  type: 'add',
})
```

## suggestionExists()

检查建议是否仍存在于文档中。

| 参数 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `editor` | `Editor` | — | Tiptap 编辑器实例 |
| `suggestionId` | `string` | — | 要检查的建议 ID |
| `markName` | `string` | `'suggestion'` | 建议标记的名称 |

### 返回值

`boolean` — 如果建议存在，则为 `true`。

```js
import { suggestionExists } from '@tiptap-pro/extension-tracked-changes'

if (suggestionExists(editor, 'suggestion-123')) {
  // Suggestion is still in the document
}
```

## acceptSuggestions()

按 ID 接受多个建议。每条建议会单独处理。

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `editor` | `Editor` | Tiptap 编辑器实例 |
| `suggestionIds` | `string[]` | 要接受的建议 ID 数组 |

### 返回值

`boolean` — 如果至少接受了一条建议，则为 `true`。

```js
import { acceptSuggestions } from '@tiptap-pro/extension-tracked-changes'

acceptSuggestions(editor, ['suggestion-1', 'suggestion-2', 'suggestion-3'])
```

## rejectSuggestions()

按 ID 拒绝多个建议。每条建议会单独处理。

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `editor` | `Editor` | Tiptap 编辑器实例 |
| `suggestionIds` | `string[]` | 要拒绝的建议 ID 数组 |

### 返回值

`boolean` — 如果至少拒绝了一条建议，则为 `true`。

```js
import { rejectSuggestions } from '@tiptap-pro/extension-tracked-changes'

rejectSuggestions(editor, ['suggestion-1', 'suggestion-2'])
```

## withoutTrackedChanges()

通过在副本上拒绝所有待处理建议，返回基础文档。建议添加的内容会被移除，建议删除的内容会被恢复，替换则会还原为原始内容。待处理的格式、属性、节点类型、列表嵌套和块拆分更改也会被还原。节点类型提案会恢复原始类型和属性，同时保留拒绝其他建议后的当前内容。

| 选项 | 类型 | 描述 |
| --- | --- | --- |
| `content` | `string \| JSONContent` | HTML 或完整的文档 JSON 对象。不支持 JSON 字符串和内容数组。 |
| `schema` | `Schema` | 源文档的 ProseMirror schema，包含 `TrackedChanges` 以及所有自定义节点和标记。 |

两个选项均为必填项。选项类型导出为 [`WithoutTrackedChangesOptions`](/tracked-changes/api-reference/types#withouttrackedchangesoptions)。

### 返回值

`JSONContent` — 完整的文档 JSON 对象，不包含建议标记或保留的跟踪属性，并包含值为 null 的跟踪默认属性。拒绝建议后，其他内容、标记和属性会按照 schema 的表示方式予以保留。

此实用函数不会更改输入内容或源编辑器，包括待处理建议、选区、历史记录、回调、评论串和协作提供程序。也支持不含待处理建议的内容。对于相同的内容和 schema，重复导出会生成深度相等的 JSON。

```js
import { withoutTrackedChanges } from '@tiptap-pro/extension-tracked-changes'

const base = withoutTrackedChanges({
	content: editor.getJSON(),
	schema: editor.schema,
})

// HTML input also returns JSON.
const baseFromHTML = withoutTrackedChanges({
	content: editor.getHTML(),
	schema: editor.schema,
})
```

例如，在 `Hello` 后有一个待处理的 ` world` 插入建议时，生成的基础 JSON 只包含 `Hello`。该插入建议仍会在源编辑器中保持待处理状态。

### 不使用编辑器

不依赖 DOM 即可处理 JSON 输入。使用 `getSchema` 和源文档中使用的相同扩展（包括自定义扩展）构建 schema。

```js
import { getSchema } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import { TrackedChanges, withoutTrackedChanges } from '@tiptap-pro/extension-tracked-changes'

const schema = getSchema([StarterKit, TrackedChanges])

const base = withoutTrackedChanges({
	content: { type: 'doc', content: [{ type: 'paragraph' }] },
	schema,
})
```

### 限制和错误

HTML 输入需要 DOM 环境，并会保留文本空白。自定义 HTML 渲染器必须保留建议数据，以便解析器恢复基础内容。对于先前导出时已丢弃或 schema 不支持的数据，HTML 无法恢复。

对于无效的文档 JSON、缺少跟踪 schema 支持，或无法还原的建议，此实用函数会抛出错误。没有 DOM 时传入 HTML 也会抛出错误。若导出失败，源内容不会改变。

行内原子建议必须使用节点属性。非文本节点上的建议标记会导致错误。显式的列表嵌套增量必须是非零安全整数；`sink` 对应正数，`lift` 对应负数。旧文档仍支持省略增量或将其设为 null。

只有待处理的建议会被还原。此实用函数无法撤销已接受的更改或未通过跟踪功能进行的编辑。

## generateSuggestionId()

生成唯一的建议 ID。通过组合时间戳和随机字符串确保唯一性。

### 返回值

`string` — 格式为 `suggestion-{timestamp}-{random}` 的唯一建议 ID。

```js
import { generateSuggestionId } from '@tiptap-pro/extension-tracked-changes'

const id = generateSuggestionId()
// Returns: 'suggestion-1706621696789-k7x2m9p'
```

## getTimestamp()

获取当前时间，返回 ISO 8601 时间戳字符串。

### 返回值

`string` — ISO 8601 格式的当前时间字符串。

```js
import { getTimestamp } from '@tiptap-pro/extension-tracked-changes'

const timestamp = getTimestamp()
// Returns: '2024-01-30T12:34:56.789Z'
```

## getSuggestionHTMLAttributes()

从实时的 ProseMirror 节点读取建议数据，并返回对应的 `data-suggestion-*` DOM 属性，可安全地展开到 NodeView 的根元素上。

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `node` | `Node` | NodeView 组件中作为 `node` 属性接收的 ProseMirror 节点 |

### 返回值

`SuggestionHTMLAttributes` — 仅包含从 `node.attrs` 派生的 `data-suggestion-*` 属性的对象。值为 `null` 或 `undefined` 的键会被省略，因此非建议节点会返回 `{}`。

生成的属性如下：

| 输出键 | 来源（`node.attrs`） |
| --- | --- |
| `data-suggestion-id` | `suggestionId` |
| `data-suggestion-type` | `suggestionType` |
| `data-suggestion-user` | `suggestionUserId` |
| `data-suggestion-created` | `suggestionCreatedAt` |
| `data-suggestion-updated` | `suggestionUpdatedAt` |
| `data-suggestion-user-metadata` | `suggestionUserMetadata`（序列化为 JSON） |
| `data-suggestion-nesting-delta` | `suggestionNestingDelta` |

节点类型提案还会根据 `suggestionNodeTypeChange` 生成 `data-suggestion-node-type-change`，即使删除或拆分使用的是节点的主要建议标识也是如此。对于独立的类型提案，该辅助函数也会提供常见的 `attributeChange` 标识属性。

### 为什么使用 `node` 而不是 `HTMLAttributes`

NodeView 中的 `HTMLAttributes` 属性在创建时计算一次，之后不会更新。将它传给此实用函数会导致建议状态改变时属性过时，例如收到远程协作更新，或建议被接受或拒绝之后。`node` 属性是响应式的真实数据源，每次渲染都会更新，因此请始终传入 `node`。

### 用法

```jsx
import { getSuggestionHTMLAttributes } from '@tiptap-pro/extension-tracked-changes'

function MyNodeView({ node }) {
  const suggestionAttrs = getSuggestionHTMLAttributes(node)

  return (
    <div {...suggestionAttrs}>
      Your content here
    </div>
  )
}
```

如需了解将 NodeView 与 Tracked Changes 集成的详细指导，请参阅 [NodeView 支持指南](/tracked-changes/guides/nodeview-support)。
