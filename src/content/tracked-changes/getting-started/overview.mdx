Tracked Changes 扩展为协作编辑工作流启用建议模式。启用后，所有编辑都会显示为提案，可接受或拒绝，类似于文字处理软件中的修订跟踪功能。

## 功能

该扩展可追踪八种类型的更改：

- **插入**（`add`）— 添加到文档中的新内容
- **删除**（`delete`）— 标记为要删除的现有内容
- **替换**（`replace`）— 同时删除并替换为新内容
- **标记更改**（`markChange`）— 应用于现有文本的格式或其他标记级更改
- **属性更改**（`attributeChange`）— 更新现有节点的属性，例如图像的 `src` 或自定义节点的配置
- **块拆分**（`split`）— 块末尾拆分使用 `splitKind: 'insertion'`。现有内容中的拆分使用 `splitKind: 'structural'`。
- **列表缩进**（`sink`）— 按 Tab 键将列表项向内缩进一级
- **列表减少缩进**（`lift`）— 按 Shift-Tab 将列表项向外移一级

每条建议都包含元数据，例如创建者、创建时间和唯一标识符。

## 主要功能

- **建议模式** — 按用户启用或关闭追踪
- **接受和拒绝** — 逐条、批量、按范围或按用户审阅建议
- **建议分组** — 连续的编辑会自动合并为一条建议
- **块拆分追踪** — 可分别接受或拒绝插入型拆分和结构型拆分
- **嵌套建议** — 其他作者在待处理建议中进行的编辑会作为独立建议叠加，而不会覆盖原建议
- **支持协作** — 可与基于 Yjs 的实时协作功能配合使用
- **集成评论** — 将建议关联到评论串，支持审阅工作流
- **支持原子节点** — 追踪图像、水平线等非文本内容的更改
- **支持表格** — 追踪行、单元格和列的插入与删除，包括单元格选择
- **完整的查询 API** — 以编程方式查找、筛选和检查建议
