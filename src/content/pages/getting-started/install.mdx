## 安装 Pages 及其配套包

Pages 扩展**不包含**节点和标记的 schema。要使用它，还需要安装：

- **`@tiptap-pro/extension-convert-kit`**：适用于任何 Pages 或 Conversion 工作流的标准编辑器套件。ConvertKit 会注册兼容 DOCX 的 schema（段落、标题、列表、图片、标记），既能渲染手动编写的内容，也能渲染通过 Tiptap Conversion 导入的内容。
- **`@tiptap-pro/extension-pages-tablekit`**：支持分页的表格。由于 ConvertKit 内置的表格并非为分页而设计，因此必须安装此包；在 Pages 中使用 ConvertKit 的表格会导致布局错乱。

从私有仓库安装全部三个 Pro 包：

```bash
npm install @tiptap-pro/extension-convert-kit \
            @tiptap-pro/extension-pages-tablekit \
            @tiptap-pro/extension-pages
```

<Callout title="为什么 ConvertKit 和 TableKit 需要分别安装" variant="info">
  `@tiptap-pro/extension-pages` 和 `@tiptap-pro/extension-pages-pagekit` 都不会重新导出
  ConvertKit。它们是彼此独立、可组合使用的包。如果之后采用
  [PageKit](/pages/guides/pagekit-usage)，仍需单独安装 ConvertKit。
</Callout>

## 集成 Pages 扩展

在编辑器中注册这三个扩展，并禁用 ConvertKit 的表格组件，以便由 PagesTableKit 的 `TableKit` 接管：

```ts
import { Editor } from '@tiptap/core'
import { ConvertKit } from '@tiptap-pro/extension-convert-kit'
import { TableKit } from '@tiptap-pro/extension-pages-tablekit'
import { Pages } from '@tiptap-pro/extension-pages'

const editor = new Editor({
  extensions: [
    ConvertKit.configure({ table: false }),
    TableKit,
    Pages.configure({
      pageFormat: 'A4',
      header: 'My document',
      footer: 'Page {page} of {total}',
    }),
  ],
})
```

你最先会用到的三个选项是 `pageFormat`、`header` 和 `footer`。完整选项列表请参阅 [API 参考](/pages/core-concepts/options)；有关首页、奇偶页以及富内容页眉和页脚的设置，请参阅[页面页眉和页脚](/pages/core-concepts/page-header-footer)。

## 身份验证

Pages 本身不会发起网络请求，也不需要凭据。在 Pages 上添加 Tiptap Conversion（导入 DOCX、导出 PDF 等）后，就需要签名令牌。设置方法请参阅 [Conversion 安装指南](/conversion/getting-started/install)。其中的配置可以直接沿用，无需修改。
