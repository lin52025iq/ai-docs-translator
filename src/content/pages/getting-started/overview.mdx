Tiptap Pages 是 Tiptap 的分页编辑层。它可在任意 Tiptap 编辑器上添加分页边界、页面格式、页眉、页脚、分页符和缩放功能。借助它，读者可以像使用文字处理器那样撰写报告、信件、合同或书籍。

## 功能介绍

- **分页布局**：内容会在所选格式（A4、Letter 或自定义格式）的视觉页面间流动。
- **页面格式和页边距**：内置格式提供合理的默认值，自定义格式对象则让你完全掌控布局。
- **页眉和页脚**：可将其定义为静态文本、HTML 字符串或 Tiptap JSON。支持 `{page}` 和 `{total}` 占位符，也可以像 Word 一样，为首页以及奇数页和偶数页分别设置不同的内容区域。
- **脚注**：类似 Word 的脚注，显示在每页页脚上方，自动编号，并在内容重新排版时随其引用移动。参见[脚注](/pages/core-concepts/footnotes)。
- **尾注**：类似 Word 的尾注，集中放在文档末尾，使用小写罗马数字自动编号，并支持就地编辑。参见[尾注](/pages/core-concepts/endnotes)。
- **就地编辑**：双击页眉、页脚、脚注或尾注区域，即可在叠加层中打开功能完整的 Tiptap 编辑器。
- **缩放**：支持 `[0.25, 4]` 范围内的视觉缩放，不会影响文档内容或导出结果。
- **分页符**：可以通过 [PageBreak 扩展](/pages/core-concepts/page-break-node)插入显式分页符，也可以让 Pages 自动分页。

## 安装时需要一并添加的内容

Pages **不提供节点和标记的 schema**。使用它时还需要安装：

- **`@tiptap-pro/extension-convert-kit`**：适用于 Conversion 和 Pages 工作流的标准编辑器套件。ConvertKit 会注册兼容 DOCX 的 schema（段落、标题、列表、图片、标记）。
- **`@tiptap-pro/extension-pages-tablekit`**：支持分页的表格。此套件为必需项，因为 ConvertKit 内置的表格并非为分页设计。

```bash
npm install @tiptap-pro/extension-convert-kit \
            @tiptap-pro/extension-pages-tablekit \
            @tiptap-pro/extension-pages
```

```ts
import { Editor } from '@tiptap/core'
import { ConvertKit } from '@tiptap-pro/extension-convert-kit'
import { TableKit } from '@tiptap-pro/extension-pages-tablekit'
import { Pages } from '@tiptap-pro/extension-pages'

const editor = new Editor({
  extensions: [
    ConvertKit.configure({ table: false }),
    TableKit,
    Pages.configure({
      pageFormat: 'A4',
      header: 'My document',
      footer: 'Page {page} of {total}',
    }),
  ],
})
```

完整操作流程请参阅[安装指南](/pages/getting-started/install)。

## 支持的功能

- 内置页面格式：A4、A3、A5、Letter、Legal、Tabloid。你也可以定义尺寸和页边距任意的自定义格式。
- 页眉和页脚内容支持纯文本、HTML 或 Tiptap JSON，并支持 `{page}` / `{total}` 占位符。
- 可以像 Word 一样，为首页以及奇数页和偶数页设置不同的页眉和页脚。
- 类似 Word 的[脚注](/pages/core-concepts/footnotes)：每页都有脚注区域，自动连续编号，并随引用重新排版、占用页面空间。
- 类似 Word 的[尾注](/pages/core-concepts/endnotes)：文档末尾有一个尾注列表，使用小写罗马数字自动编号，并在页面间流动，同时保留完整的页面装饰元素。
- 可在专用叠加层中实时编辑页眉、页脚、脚注和尾注。这些内容会与主文档一起参与协作。参见[为 Pages 添加协作功能](/pages/guides/collaboration-with-pages)。
- 程序化控制：打开或关闭页眉、页脚、脚注或尾注编辑器，响应页面格式变化或缩放变化。
- 可在配置时或运行时锁定或解锁各叠加层的编辑权限，使用 `editableHeader` / `editableFooter` / `footnotes.editable` / `endnotes.editable` 选项，以及 `setHeaderEditable` / `setFooterEditable` / `setFootnotesEditable` / `setEndnotesEditable` 命令。
- 通过 [PagesTableKit](/pages/guides/pages-tablekit)使用支持分页的表格。表格会按比例缩小以适应页面；精确高度的行会被裁切；声明的宽度会保留；带有合并单元格的表格中，每个单元格也会保持在其所属列中。
- 支持与 Tiptap Conversion 往返转换：导入的 DOCX 页眉、页脚、脚注和尾注会自动应用；导出的 DOCX、PDF、ODT 和 EPUB 文件会保留页眉、页脚和分页。DOCX 导出会写入真正的 Word 脚注和尾注。

## 不支持的功能

以下是明确记录的限制，并非 bug。如果你的工作流依赖其中任何一项，请将其视为设计边界。

- **大于一页的不可拆分块会导致布局陷入无限循环。** 这是采用 Pages 前最重要的一项限制。图形、定位容器、嵌套表格和大多数其他块格式上下文（BFC）元素都无法跨页拆分。布局只能将整个块移到下一页。如果块比页面本身还高，就无法放入下一页；布局会不断尝试将其后移，始终无法稳定。结果是编辑器失去响应。这是当前跨页拆分内容方式的硬性限制，并非近期路线图中的待办事项。完整说明（包括检测和避免此问题的方法）请参阅[限制](/pages/core-concepts/limitations#oversized-non-splittable-blocks-cause-an-infinite-layout-loop)。较高的**表格行**是例外：[行拆分](/pages/guides/row-fragmentation)支持将其拆分到多个页面，包括含有合并单元格或嵌套表格的行。
- **不支持按页设置样式，也不支持页面模板。** 所有页面使用相同的布局和视觉样式。
- **不集成浏览器打印功能。** 如需生成可直接打印的输出，请使用 [Conversion 扩展和 REST 端点](/conversion/getting-started/overview)。

## 使用前须知

- **Beta 阶段。** Pages 正在积极开发中。如果你的项目依赖它，请锁定精确的套件版本，因为次版本更新可能引入不兼容变更。
- **像素值采用 CSS 像素。** API 中的所有尺寸都对应标准浏览器 CSS 像素（1 英寸为 96 px）。`cmToPixels` 和 `inchToPixels` 工具函数支持精确往返转换，方便你使用现实世界的度量单位进行创作。
- **就地编辑支持协作。** 双击页眉或页脚会打开完整的 Tiptap 编辑器，该编辑器与主文档处于同一协作会话中。

## 不应期待的功能

- **Pages 本身不是完整的编辑器。** 它是一个布局叠加层。请搭配 `ConvertKit` 提供文档 schema，并搭配 `extension-pages-tablekit` 中的 `TableKit` 处理表格。
- **Pages 本身不负责 DOCX 导入或导出。** 它是一个渲染目标。要与文件进行往返转换，请搭配 [Conversion](/conversion/getting-started/overview) 扩展：使用 `extension-import-docx` 导入，使用 `extension-export-docx`、`extension-export-pdf` 等扩展导出。
- **Pages 不负责分页内容的表格渲染。** 请使用 [PagesTableKit](/pages/guides/pages-tablekit)，不要使用开源的 `@tiptap/extension-table` 或 ConvertKit 内置的表格。
