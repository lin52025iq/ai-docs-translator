`pageFormat` 选项用于控制文档中每一页的尺寸和页边距。这有助于让内容保持一致、专业，尤其是在打印或导出时。

## 内置格式

Pages 使用标准 CSS 像素（1 英寸为 96 像素），因此下方的尺寸与浏览器实际渲染的尺寸一致。Pages 扩展会在内部保留小数像素值，以避免布局误差累积；此处显示的整数经过四舍五入，便于阅读。

| 名称      | 尺寸 (cm)       | 尺寸 (px)       | 页边距 (cm：上、右、下、左)             | 页边距 (px)   |
| --------- | --------------- | --------------- | -------------------------------------- | -------------- |
| `A4`      | 21.0 × 29.7     | 794 × 1123      | 2.5, 2.0, 2.5, 2.0                     | 95, 76, 95, 76 |
| `A3`      | 29.7 × 42.0     | 1123 × 1587     | 2.5, 2.0, 2.5, 2.0                     | 95, 76, 95, 76 |
| `A5`      | 14.8 × 21.0     | 559 × 794       | 2.0, 1.5, 2.0, 1.5                     | 76, 57, 76, 57 |
| `Letter`  | 21.59 × 27.94   | 816 × 1056      | 2.54, 2.54, 2.54, 2.54                 | 96, 96, 96, 96 |
| `Legal`   | 21.59 × 35.56   | 816 × 1345      | 2.54, 2.54, 2.54, 2.54                 | 96, 96, 96, 96 |
| `Tabloid` | 27.94 × 43.18   | 1056 × 1633     | 2.54, 2.54, 2.54, 2.54                 | 96, 96, 96, 96 |

每种内置格式都提供默认的页边距和尺寸。如需自定义，请定义自己的格式对象。请参阅下文的[自定义页面格式](#custom-page-formats)。

## 使用内置格式

```js
Pages.configure({
  pageFormat: 'Letter',
})
```

### 使用内置格式常量

你也可以导入内置页面格式常量，以获得更好的自动补全和类型安全：

```js
import { PAGE_FORMATS } from '@tiptap-pro/extension-pages'

Pages.configure({
  pageFormat: PAGE_FORMATS.Letter,
})
```

这与使用字符串字面量等效：

```js
Pages.configure({
  pageFormat: 'Letter',
})
```

任选你喜欢的方式即可。

## 自定义页面格式

<CodeDemo isPro path="/Extensions/PagesCustomPageFormat" />

你可以提供页面格式对象，并设置所需的尺寸和页边距，从而定义自定义页面格式：

```js
Pages.configure({
  pageFormat: {
    id: 'custom-page-format',
    width: cmToPixels(22.94),
    height: cmToPixels(35.18),
    margins: {
      top: cmToPixels(2.54),
      right: cmToPixels(2.54),
      bottom: cmToPixels(2.54),
      left: cmToPixels(2.54),
    },
  },
})
```

<Callout title="提示" variant="info">
  在此示例中，我们使用 [`cmToPixels`](/pages/utilities/cm-to-pixels) 实用工具，以厘米为单位定义页面尺寸和页边距，方便使用常见的印刷尺寸。请参阅[实用工具参考](/pages/utilities/cm-to-pixels)，详细了解 <code>cmToPixels</code>。
</Callout>

## 页面边距

你可以使用自定义页面格式来调整页面边距。内置格式的页边距是固定的，但你可以创建带有自定义页边距的格式：

```js
Pages.configure({
  pageFormat: {
    id: 'custom-layout',
    width: 794, // px
    height: 1123, // px
    margins: {
      top: 60, // px
      right: 40, // px
      bottom: 60, // px
      left: 40, // px
    },
  },
})
```

## 以编程方式更改页面格式

编辑器初始化后，可以使用 `setPageFormat` 命令更改页面格式：

```js
// Switch to a built-in format
editor.commands.setPageFormat('A4')

// Switch to a custom format
editor.commands.setPageFormat({
  id: 'custom-wide-page-format',
  width: cmToPixels(27.94),
  height: cmToPixels(43.18),
  margins: {
    top: cmToPixels(2.54),
    right: cmToPixels(2.54),
    bottom: cmToPixels(2.54),
    left: cmToPixels(2.54),
  },
})
```

## 监听页面格式变更

使用 `onPageFormatChange` 回调，在页面格式发生更改时执行相应操作：

```js
Pages.configure({
  pageFormat: 'A4',
  onPageFormatChange: (pageFormat) => {
    console.log('Page format changed to:', pageFormat)
    // Update your UI, save the preference, etc.
  },
})
```

<Callout title="灵活性" variant="info">
  使用自定义页面格式，你可以完全控制页面尺寸和页边距，从而创建所需的精确布局。
</Callout>
