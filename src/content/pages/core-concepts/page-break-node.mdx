PageBreak 扩展（`@tiptap-pro/extension-pagebreak`）会添加一个块级原子节点，用于在文档中插入显式分页符。根据是否使用 [Pages 扩展](/pages/getting-started/overview)，它有两种工作模式。

<CodeDemo isPro path="/Extensions/Pages" />

## 两种工作模式

### 标准模式（不使用 Pages）

不使用 Pages 扩展时，PageBreak 会呈现为一条带居中标签的虚线横线，清晰标示分页符的位置，适用于最终需要打印或导出的内容。

### Pages 模式（使用 Pages）

检测到 Pages 扩展后，PageBreak 会自动切换行为。它不再呈现为可见分隔线，而是显示为不可见的填充元素，扩展以填满当前页面的剩余高度，并将后续所有内容推至下一页。这种行为与 Microsoft Word 的分页符类似。

<Callout title="自动检测">
  PageBreak 会自动检测 Pages 扩展，无需额外配置。只需注册这两个扩展，即可自动应用正确的模式。
</Callout>

## 安装

```bash
npm install @tiptap-pro/extension-pagebreak
```

## 基本用法

将 PageBreak 用作独立扩展，可显示分页符标记。搭配 [ConvertKit](/conversion/import/docx/convertkit) 使用，以配置编辑器的 schema：

```ts
import { Editor } from '@tiptap/core'
import { ConvertKit } from '@tiptap-pro/extension-convert-kit'
import { PageBreak } from '@tiptap-pro/extension-pagebreak'

const editor = new Editor({
  extensions: [ConvertKit, PageBreak],
})
```

## 与 Pages 搭配使用

同时注册 PageBreak 和 Pages 后，PageBreak 会自动以 Pages 模式运行。使用标准的 [Pages 组合](/pages/getting-started/install)（ConvertKit + TableKit + Pages），并同时添加 PageBreak：

```ts
import { Editor } from '@tiptap/core'
import { ConvertKit } from '@tiptap-pro/extension-convert-kit'
import { TableKit }   from '@tiptap-pro/extension-pages-tablekit'
import { Pages }      from '@tiptap-pro/extension-pages'
import { PageBreak }  from '@tiptap-pro/extension-pagebreak'

const editor = new Editor({
  extensions: [
    ConvertKit.configure({ table: false }),
    TableKit,
    Pages.configure({ pageFormat: 'A4' }),
    PageBreak,
  ],
})
```

## 通过 PageKit 使用

使用 [PageKit](/pages/guides/pagekit-usage) 时，默认会包含 PageBreak。若要禁用它，请传入 `pagebreak: false`：

```js
import { PageKit } from '@tiptap-pro/extension-pages-pagekit'

PageKit.configure({
  pages: { pageFormat: 'A4' },
  pagebreak: false, // Disable PageBreak
})
```

## 选项

| 选项             | 类型                      | 默认值           | 描述                                            |
| ---------------- | ------------------------- | -------------- | ----------------------------------------------- |
| `label`          | `string`                  | `'Page break'` | 分页符可视标记中显示的标签文本（仅限标准模式）  |
| `nextNodeType`   | `string`                  | `'paragraph'`  | 在文档末尾插入分页符时，分页符后插入的节点类型  |
| `HTMLAttributes` | `Record<string, unknown>` | `{}`           | 应用于分页符节点的自定义 HTML 属性              |

### 配置示例

```js
PageBreak.configure({
  label: 'New page',
  nextNodeType: 'heading',
})
```

## 命令

### insertPageBreak

在当前选区插入分页符。插入后，光标会定位到分页符后面的节点中。

```js
editor.commands.insertPageBreak()

// Or in a chain
editor.chain().focus().insertPageBreak().run()
```

## 键盘快捷键

| 快捷键      | 命令         |
| ----------- | ------------ |
| `Mod-Enter` | 插入分页符   |

这与 Microsoft Word 中插入分页符的快捷键约定一致。

<Callout title="快捷键优先级">
  ConvertKit 内置的 `HardBreak` 扩展也会绑定 `Mod-Enter`。请在扩展数组中将 PageBreak 注册在 ConvertKit **之后**，这样 PageBreak 的快捷键就会优先生效。
</Callout>

## DOCX 兼容性

导入包含分页符的 `.docx` 文件时，Tiptap [转换服务](/conversion/import/docx/editor-extension)会生成 `pageBreak` 节点。这些节点与此扩展的节点类型直接对应，因此导入的文档会保留分页符的位置。

导出时，分页符会转换为 DOCX 输出中的 `<w:br w:type="page"/>`，生成标准的 Word 分页符。有关设置详情，请参阅 [DOCX 导出分页符指南](/conversion/export/docx/page-breaks)。
