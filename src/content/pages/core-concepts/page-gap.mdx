`pageGapBackground` 和 `pageGap` 选项可用于更改页面间区域的背景颜色以及页面之间的间距。这有助于在视觉上区分页面，或使其与应用的背景颜色设计保持一致。

## 如何设置页面间距背景

可以在扩展的 `.configure()` 配置中设置页面间距背景的初始值：

```js
Pages.configure({
  pageGapBackground: '#f8f8f8', // 页面间显示浅灰色
})
```

之后，随时可以使用编辑器提供的 `setPageGapBackground(color: string)` 命令来更改页面间距的颜色：

```js
editor.commands.setPageGapBackground(pageGapBackground)
// 还应执行此操作！
document.body.style.backgroundColor = pageGapBackground
```

<Callout title="实用提示">
  你还应将 body（或编辑器容器）的背景颜色改为与页面间距背景相同，因为页面间距背景仅应用于页面间距本身，不会应用于整个文档或 Tiptap 编辑器。
</Callout>

## 页面间距

- 设置页面之间的间隔。
- 默认值：`50`（像素）

### 初始配置

```js
Pages.configure({
  pageGap: 20, // 单位：像素
})
```

### 编辑器命令

```js
editor.commands.setPageGap(20) // 单位：像素
```

<Callout title="提示">
  `pageGap` 属性只会影响页面之间的间隔，不会影响页面本身。
</Callout>
