`PAGE_FORMATS` 常量提供了一组预定义的页面格式（如 A4、A3、Letter 等），包含实际尺寸和推荐页边距，并已转换为像素。这有助于快速设置 Tiptap Pages 扩展中的 `pageFormat` 选项或自定义布局。

## 导入

```js
import { PAGE_FORMATS } from '@tiptap-pro/extension-pages'
```

## API

```ts
PAGE_FORMATS: {
  [format: string]: {
    id: string
    width: number // in pixels
    height: number // in pixels
    margins: {
      top: number
      right: number
      bottom: number
      left: number
    }
  }
}
```

## 可用格式

像素值采用标准 CSS 像素（1 英寸等于 96 像素）。这些常量在内部保留小数精度；下表中的整数为便于阅读而四舍五入后的值。

| 格式        | 宽度 (px) | 高度 (px) | 页边距 (px：上 / 右 / 下 / 左) |
| ----------- | --------- | --------- | ------------------------------ |
| **A4**      | 794       | 1123      | 95 / 76 / 95 / 76              |
| **A3**      | 1123      | 1587      | 95 / 76 / 95 / 76              |
| **A5**      | 559       | 794       | 76 / 57 / 76 / 57              |
| **Letter**  | 816       | 1056      | 96 / 96 / 96 / 96              |
| **Legal**   | 816       | 1345      | 96 / 96 / 96 / 96              |
| **Tabloid** | 1056      | 1633      | 96 / 96 / 96 / 96              |

如需了解以厘米为单位的实际尺寸，请参阅[页面格式](/pages/core-concepts/page-format)。
