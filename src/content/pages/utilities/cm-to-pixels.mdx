`cmToPixels` 辅助函数可轻松将厘米转换为像素。如果你想以厘米为单位设置页面或边距大小，并需要将其转换为像素以用于 Tiptap Pages 扩展中的 `pageFormat` 选项或自定义布局，这个函数会非常有用。

## 导入

```js
import { cmToPixels } from '@tiptap-pro/extension-pages'
```

## API

```ts
cmToPixels(cm: number, dpi?: number): number
```

- `cm`：要转换的厘米值。
- `dpi`（可选）：每英寸点数。如果未提供，该工具会自动检测当前环境的 DPI。
- **返回值：**等效的像素值（已四舍五入）。
