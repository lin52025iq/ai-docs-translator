`inchToPixels` 辅助函数可轻松将英寸转换为像素。如果你想用英寸定义页面或边距大小，并需要将其转换为像素，以便用于 Tiptap Pages 扩展的 `pageFormat` 选项或自定义布局，这个函数就很有用。

## 导入

```js
import { inchToPixels } from '@tiptap-pro/extension-pages'
```

## API

```ts
inchToPixels(inches: number, dpi?: number): number
```

- `inches`：要转换的英寸值。
- `dpi`（可选）：每英寸点数。如果未提供，该工具会自动检测当前环境的 DPI。
- **返回值：**对应的像素值（四舍五入）。
