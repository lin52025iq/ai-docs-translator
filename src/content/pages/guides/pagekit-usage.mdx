PageKit 是一个便捷扩展，它将 `Pages`、支持分页的 `TableKit` 和 `PageBreak` 封装在一起，只需注册一次即可统一配置。默认情况下，**仅注册 Pages 和 PageBreak**。`TableKit` 需要主动启用：传入任意选项对象（例如 `table: {}`）即可启用。PageKit **不包含** `ConvertKit`；ConvertKit 是需要单独安装、与 PageKit 配合使用的程序包。

## 1. 安装 ConvertKit 和 PageKit

PageKit 捆绑了三个与 Pages 相关的扩展，但你仍需单独安装 `ConvertKit`，以提供编辑器的节点和标记 schema。

```bash
npm install @tiptap-pro/extension-convert-kit \
            @tiptap-pro/extension-pages-pagekit
```

## 2. 将 ConvertKit 和 PageKit 添加到编辑器

```ts
import { Editor } from '@tiptap/core'
import { ConvertKit } from '@tiptap-pro/extension-convert-kit'
import { PageKit } from '@tiptap-pro/extension-pages-pagekit'

const editor = new Editor({
  extensions: [
    ConvertKit.configure({ table: false }),
    PageKit.configure({
      pages: {
        pageFormat: 'A4',
        header: '我的项目',
        footer: '第 {page} 页，共 {total} 页',
      },
      table: {
        // 启用 PageKit 捆绑的 TableKit。传入 `{}` 使用默认值，或在此传入 TableKitOptions。
        // 不设置此键（或设为 `false`）时，不会注册表格。
        table: { resizable: true }, // 传递给底层的 Table 扩展
      },
      pagebreak: {
        // 传递给 PageBreak（可选）
        label: '分页符',
      },
    }),
  ],
})
```

<Callout title="为什么要禁用 ConvertKit 的表格" variant="info">
  启用 PageKit 的 `table` 选项后，它会注册来自
  <code>@tiptap-pro/extension-pages-tablekit</code> 的分页安全型 `TableKit`。ConvertKit 自带一套表格扩展
  （支持 DOCX，但不支持分页），因此我们在这里将其禁用，改用 PageKit 的表格。
  ConvertKit 的表格和 PageKit 的表格接受相同的 DOCX 单元格属性，因此无论使用哪一种，导入的内容
  都能正确呈现。
</Callout>

<Callout title="工作原理" variant="info">
  PageKit 会为你配置 Pages、TableKit 和 PageBreak 扩展。将 Pages 选项放在
  <code>pages</code> 下，将 Table 选项放在 <code>table</code> 下，将 PageBreak 选项
  放在 <code>pagebreak</code> 下。
</Callout>

## 禁用 PageBreak

如果不需要显式分页符，可以禁用 PageBreak 扩展：

```ts
PageKit.configure({
  pages: { pageFormat: 'A4' },
  pagebreak: false, // 禁用 PageBreak
})
```

## 3. 何时使用 PageKit？

- 如果同时需要分页和表格，使用 PageKit 可以最快完成配置。
- 如果需要深度自定义 TableKit 或 Pages，请改为分别导入并配置它们。有关不使用捆绑配置的方法，请参阅 [PagesTableKit 指南](/pages/guides/pages-tablekit)。
