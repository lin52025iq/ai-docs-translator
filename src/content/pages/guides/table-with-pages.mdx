要在分页编辑器中添加表格，应使用 `@tiptap-pro/extension-pages-tablekit` 包中的 TableKit 扩展。为了正确地将表格拆分到多个页面，我们对表格的行为和布局进行了大幅修改，因此使用该扩展可确保与分页功能完全兼容。

## 1. 安装 Pages 技术栈

表格、ConvertKit（编辑器的 schema）和 Pages 本身分别通过独立的包发布。请安装这三个包：

```bash
npm install @tiptap-pro/extension-convert-kit \
            @tiptap-pro/extension-pages-tablekit \
            @tiptap-pro/extension-pages
```

## 2. 将 ConvertKit、TableKit 和 Pages 添加到编辑器

```ts
import { Editor } from '@tiptap/core'
import { ConvertKit } from '@tiptap-pro/extension-convert-kit'
import { TableKit } from '@tiptap-pro/extension-pages-tablekit'
import { Pages } from '@tiptap-pro/extension-pages'

const editor = new Editor({
  extensions: [
    ConvertKit.configure({ table: false }),
    TableKit,
    Pages.configure({
      /* ... */
    }),
  ],
})
```

<Callout title="为什么要禁用 ConvertKit 的表格" variant="info">
  ConvertKit 自带一套表格功能（支持 DOCX，但不适用于分页）。PagesTableKit 的
  `TableKit` 是适用于分页的替代方案，并支持与 ConvertKit 表格相同的 DOCX 单元格属性。
  禁用其中一个，再注册另一个即可。
</Callout>

<Callout title="最佳实践" variant="info">
  使用 Pages 时，务必使用来自 <code>@tiptap-pro/extension-pages-tablekit</code> 的 `TableKit` 扩展。
  请勿使用开源的 `@tiptap/extension-table` 或 ConvertKit 内置的表格，因为它们都与 Pages 扩展生成的布局不兼容。
</Callout>

## 3. 表格功能

- 所提供的 TableKit 扩展与开源版本的功能和行为完全一致，也可以扩展以满足你的需求。
- 表格能够正确分页，并随文档一起导出为 DOCX。

<Callout title="扩展 Pages 的 TableKit 扩展" variant="default">
  扩展来自{' '}
  <code>@tiptap-pro/extension-pages-tablekit</code> 的 TableKit 扩展时请务必谨慎，因为其布局经过了大幅修改，扩展操作可能会破坏表格拆分逻辑。
</Callout>
