## 1. 安装 Pages 组件包

使用 Pages 时，以下三个 Pro 组件包通常需要一起安装：

```bash
npm install @tiptap-pro/extension-convert-kit \
            @tiptap-pro/extension-pages-tablekit \
            @tiptap-pro/extension-pages
```

<Callout title="为什么需要这三个组件包" variant="info">
  `@tiptap-pro/extension-convert-kit` 提供编辑器的节点和标记模式（段落、标题、列表、图像、标记）。`@tiptap-pro/extension-pages-tablekit` 提供适用于分页的表格；这是必需的，因为 ConvertKit 内置的表格并非为分页设计。`@tiptap-pro/extension-pages` 则提供页面布局本身。请先登录 Tiptap 私有 npm 注册表；设置方法请参阅 [Pro 扩展指南](/guides/pro-extensions)。
</Callout>

## 2. 使用 Pages 设置编辑器

```ts
import { Editor } from '@tiptap/core'
import { ConvertKit } from '@tiptap-pro/extension-convert-kit'
import { TableKit } from '@tiptap-pro/extension-pages-tablekit'
import { Pages } from '@tiptap-pro/extension-pages'

const editor = new Editor({
  extensions: [
    ConvertKit.configure({ table: false }),
    TableKit,
    Pages.configure({
      pageFormat: 'A4',
      pageGap: 40,
      header: 'My Project',
      footer: 'Page {page} of {total}',
      pageGapBackground: '#f8f8f8',
    }),
  ],
})
```

<Callout title="最佳实践" variant="info">
  在设置初期就添加 Pages，确保文档结构和布局从一开始就保持一致。之后可以通过命令更改页面格式、页眉和页脚；如果文档在编写时没有考虑分页，之后再为其添加 Pages 就会比较困难。
</Callout>

## 3. 添加 DOCX 导出功能

安装 DOCX 导出扩展：

```bash
npm install @tiptap-pro/extension-export-docx
```

将其添加到编辑器中：

```ts
import { ExportDocx } from '@tiptap-pro/extension-export-docx'

const editor = new Editor({
  extensions: [
    ConvertKit.configure({ table: false }),
    TableKit,
    Pages.configure({
      /* ... */
    }),
    ExportDocx,
  ],
})
```

### 3a. 配置 DOCX 导出

DOCX 导出扩展完全在浏览器中运行：无需令牌，也不会调用服务器。通过 `onCompleteExport` 回调配置扩展，该回调会接收导出结果：

```ts
import { ExportDocx } from '@tiptap-pro/extension-export-docx'

ExportDocx.configure({
  // Required. The exported file is delivered through this callback.
  onCompleteExport: (result) => {
    const blob = new Blob([result], {
      type: 'application/vnd.openxmlformats-officedocument.wordprocessingml.document',
    })
    const url = URL.createObjectURL(blob)
    const a = document.createElement('a')
    a.href = url
    a.download = 'document.docx'
    a.click()
    URL.revokeObjectURL(url)
  },
  // Optional: 'blob' (default), 'buffer', 'string', etc.
  exportType: 'blob',
  // Optional: override paragraph, heading, table styles, etc.
  styleOverrides: {},
  // Optional: define DOCX serialisation for any custom Tiptap nodes you've added.
  customNodes: [],
})
```

<Callout title="必需项" variant="warning">
  必须配置 `onCompleteExport`。导出操作不会直接返回结果，而是将结果传递给此回调，供你下载、上传或进一步处理。
</Callout>

## 4. 导出文档

通过编辑器的命令链触发导出：

```ts
editor.commands.exportDocx()
```

<Callout title="往返转换不会保证字节完全一致" variant="info">
  DOCX 导出能够忠实保留内容，但并非无损转换。少数功能（下标/上标标记、段落行高、浮动表格）在往返转换时可能不够完美。完整列表请参阅[功能支持矩阵](/conversion/getting-started/feature-support-matrix)。
</Callout>

## 5. 将 DOCX 文件导入编辑器

添加导入扩展，让用户能够将 Word 文档载入分页编辑器：

```bash
npm install @tiptap-pro/extension-import-docx
```

```ts
import { ImportDocx } from '@tiptap-pro/extension-import-docx'

const editor = new Editor({
  extensions: [
    ConvertKit.configure({ table: false }),
    TableKit,
    Pages.configure({
      /* ... */
    }),
    ExportDocx.configure({
      /* ... */
    }),
    ImportDocx.configure({
      token: 'YOUR_JWT', // A JWT generated by your server
      // Optional: where the import service should upload images extracted from the document
      // imageUploadConfig: { url: 'https://your-server.com/upload-image' },
    }),
  ],
})
```

要触发导入，请传入来自 `<input type="file" />` 的 `File`：

```ts
editor
  .chain()
  .importDocx({
    file,
    onImport(context) {
      if (context.error) {
        // Handle the failure (toast, log, retry, etc.)
        return
      }
      context.setEditorContent(context.content)
    },
  })
  .run()
```

如果导入的文档带有页眉和页脚，Pages 扩展会自动识别；无需额外配置，它们就会显示在每个渲染页面的顶部和底部。

页眉和页脚中的 Word 页码会导入为 `{page}` 和 `{numpages}` 占位符。Pages 会立即渲染 `{page}`。默认情况下，Pages 使用 `{total}` 表示总页数，因此需要将其重命名以匹配导入内容。将第 2 步中的 `Pages.configure` 配置块替换为以下内容，其中添加了重命名设置，并将页脚更新为新的占位符名称：

```ts
Pages.configure({
  pageFormat: 'A4',
  pageGap: 40,
  header: 'My Project',
  footer: 'Page {page} of {numpages}',
  pageGapBackground: '#f8f8f8',
  placeholders: { total: 'numpages' },
})
```

重命名后，Pages 和 DOCX 导出都会将 `{numpages}` 视为总页数占位符，`{total}` 将不再生效。

<Callout title="如何获取令牌" variant="hint">
  设置方法请参阅 [Conversion 安装指南](/conversion/getting-started/install)，有关如何签发令牌，请参阅[身份验证](/authentication)。请在服务器端签发令牌，切勿在浏览器中公开签名密钥。
</Callout>
