# compactEvents

`compactEvents` 会在保留语义的同时，精简事件数组中冗长的流式序列。可用它在持久化前缩减日志，或简化服务器发送事件（SSE）流的后处理。

```ts
import { compactEvents, EventType, type BaseEvent } from "@ag-ui/client"

const compacted: BaseEvent[] = compactEvents(events)
```

## API

```ts
function compactEvents(events: BaseEvent[]): BaseEvent[]
```

## 功能

- 文本消息：对同一 `messageId` 的 `TEXT_MESSAGE_START` → `TEXT_MESSAGE_CONTENT*` → `TEXT_MESSAGE_END` 事件进行分组，并将所有 `delta` 块拼接为一个 `TEXT_MESSAGE_CONTENT` 事件。
- 工具调用：对同一 `toolCallId` 的 `TOOL_CALL_START` → `TOOL_CALL_ARGS*` → `TOOL_CALL_END` 事件进行分组，并将所有 `delta` 块拼接为一个 `TOOL_CALL_ARGS` 事件。
- 交错事件：开始与结束事件之间出现的其他事件会被移到该序列之后，使流式块保持连续。
- 直接保留：所有其他事件（状态、自定义事件等）均保持不变。

## 示例

处理前：

```ts
[
  { type: EventType.TEXT_MESSAGE_START, messageId: "m1", role: "assistant" },
  { type: EventType.TEXT_MESSAGE_CONTENT, messageId: "m1", delta: "Hello" },
  { type: EventType.TEXT_MESSAGE_CONTENT, messageId: "m1", delta: " " },
  { type: EventType.CUSTOM, name: "thinking" },
  { type: EventType.TEXT_MESSAGE_CONTENT, messageId: "m1", delta: "world" },
  { type: EventType.TEXT_MESSAGE_END, messageId: "m1" },
]
```

处理后：

```ts
[
  { type: EventType.TEXT_MESSAGE_START, messageId: "m1", role: "assistant" },
  { type: EventType.TEXT_MESSAGE_CONTENT, messageId: "m1", delta: "Hello world" },
  { type: EventType.TEXT_MESSAGE_END, messageId: "m1" },
  { type: EventType.CUSTOM, name: "thinking" },
]
```

工具调用的压缩方式与此类似，会合并 `TOOL_CALL_ARGS` 块。

## 适用场景

- 持久化事件历史（存储更少的帧，含义不变）
- 为分析或导出准备快照
- 减少测试或调试输出中的冗余

## 元数据

合并一组连续的 delta 事件时，也会按键合并其[元数据](/concepts/metadata)，并以最后一次写入的值为准，因此压缩后的流会产生与原始流相同的元数据。首个 delta 之后到达的元数据——无论来自后续 delta 还是重放的开始事件——都会按到达顺序附加到合并后的事件上，因为压缩会先输出开始事件。

压缩会对事件重新排序，使每个流中的事件保持在一起；但这种重新排序通常无法保留语义。两个并行工具调用的结束事件若到达顺序与开始事件相反，它们在 assistant 消息的 `toolCalls` 数组中的顺序就会互换，但各自仍保留原有元数据。更重要的是，中断某个流的事件会被移到该流之后输出。因此，在消息处理过程中到达的 `MESSAGES_SNAPSHOT` 会在该消息自身的事件之后重放，并覆盖这些事件产生的结果——包括追加的内容和合并后的元数据。如果依赖完全一致的重放结果，请避免在流尚未结束时插入快照。

## 备注与限制

- 此工具专注于消息流和工具调用流。它不会修改状态事件（`STATE_SNAPSHOT`/`STATE_DELTA`），也不会生成消息快照。
- 有关背景和更广泛模式（分支、规范化），请参阅[序列化](/concepts/serialization)。
